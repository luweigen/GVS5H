The answer has a clean closed form: choose which k of the n-1 adjacent positions are "equal" (C(n-1, k)), pick the first element (m ways), and each of the remaining n-1-k "different" boundaries has (m-1) choices. So answer = C(n-1, k) * m * (m-1)^(n-1-k) mod (1e9+7). Since n, m ≤ 1e5, precompute factorials and inverse factorials up to n-1 for O(1) binomial queries, and use fast modular exponentiation. Handle edge cases like m=1 (then (m-1)^0 = 1 works only when k = n-1; pow(0,0) must be treated as 1).
