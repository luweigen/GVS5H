We need max over i<j of D_prefix(i) + D_suffix(j+1) + distinct count in middle segment (i+1..j). Prefix and suffix distinct counts are trivially precomputed in O(N). The middle distinct count can be maintained with a sliding window: fix the right end j, and as j grows, the set of valid left cuts i corresponds to a window; we need max of P[i] over i in a valid range where the window (i+1..j) has a manageable distinct count — but distinct count varies, so instead we use the classic trick: for each right end j, the middle distinct count equals (number of distinct in 1..j) minus those whose last occurrence ≤ i. So total = P[i] + S[j+1] + D(j) - (distinct values in 1..j whose last occurrence position ≤ i). Define for each i a value f(i) = P[i] - (count of values whose last occurrence in prefix j is ≤ i); as j moves, we update a segment tree over i: when a value's last occurrence moves from p to j, we add -1 to range [p, j-1] for i (since for i ≥ p, that value is no longer counted... careful sign). Then answer = max over j of S[j+1] + D(j) + max_{i < j} f(i). Segment tree with range add and range max gives O(N log N).
