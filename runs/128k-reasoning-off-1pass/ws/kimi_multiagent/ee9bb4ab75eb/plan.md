Build a trie over all words, storing at each node the count of words passing through it and the top two "best depths" achievable by picking k words whose LCA is that node (i.e., k words sharing that prefix). The answer for the full array is, for each node with count >= k, the node's depth; the global answer is the max such depth. For each removed index i, we need the max depth over nodes whose remaining count (after removing word i) is still >= k. Precompute per-node counts, then for each word walk its trie path: nodes on the path lose one count, so the candidate answer is the max over (a) nodes not on the path with count >= k (their depth) and (b) nodes on the path with count-1 >= k. Use prefix/suffix maxima along each word's path plus a global max of qualifying node depths to answer in O(total length).
