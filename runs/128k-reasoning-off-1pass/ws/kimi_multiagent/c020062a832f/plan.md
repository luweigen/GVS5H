Adding k (mod M) rotates each value; a pair (i,j) with i<j changes its inversion status only when one of A_i+k, A_j+k wraps past M. For each pair, the contribution flips exactly once as k goes 0→M-1, at k = M - max(A_i, A_j) if A_i ≠ A_j (pairs with equal values never invert). So answer(k) = base + (#pairs that flipped by k), where base = inversions at k=0 and each k gets a delta equal to the number of pairs whose flip point equals k. Compute base with a Fenwick tree, and count flip points via a difference array over k using value frequencies: for threshold t = M - max, pairs with max value v contribute at k = M - v; count such pairs per v using frequency prefix sums. Total work is O((N+M) log M).
