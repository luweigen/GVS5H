For any fixed window of length x, the minimum cost to make all its elements equal is achieved by bringing every element to the window's median; this cost can be computed for all windows in O(n log x) using two heaps with lazy deletion (or a sorted structure). The problem then reduces to choosing at least k non-overlapping length-x intervals with minimum total cost, which is a weighted interval scheduling variant solvable by DP: dp[i][j] = min cost to select j intervals using the first i positions, with transition dp[i][j] = min(dp[i-1][j], dp[i-x][j-1] + cost[i-x..i-1]). Since k <= 15, the DP is O(n*k) which is efficient. Edge cases: "at least k" means we can take the min over j >= k, but since costs are non-negative, exactly k is optimal.
