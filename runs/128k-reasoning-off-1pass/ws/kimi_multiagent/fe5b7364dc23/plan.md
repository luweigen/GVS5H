We need sum over all subarrays of (subarray sum)^K with K ≤ 10. Expand (S_r − S_{l−1})^K via binomial theorem: the total answer becomes a double sum over l≤r of C(K,j) S_r^j (−S_{l−1})^{K−j}. Swap the order of summation: for each r, we need prefix aggregates over l−1 = t < r of (−S_t)^{K−j}, which can be maintained with a Fenwick/segment tree over prefix-sum values — but prefix sums are huge, so instead we process r in order keeping a running array of powers. Concretely, maintain cnt[m] = sum over t<r of (−S_t)^m mod p, updated in O(K) per step by adding the new prefix sum's powers; then answer accumulates sum_j C(K,j) S_r^j · cnt[K−j]. This gives O(NK) time, easily fast enough. All arithmetic is mod 998244353, with binomial coefficients precomputed for K ≤ 10.
