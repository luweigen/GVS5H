Model the problem as a shortest-path problem on a doubled state graph: each state is (vertex, orientation) where orientation 0 means edges are as given and 1 means all edges are reversed. Moving along an edge costs 1 and stays in the same orientation; reversing all edges costs X and flips the orientation while staying at the same vertex. Since edge weights are only 1 and X (non-negative), run Dijkstra from state (1, 0) over 2N states with 2M + 2N implicit edges. The answer is min(dist[N][0], dist[N][1]). Use adjacency lists for both the original and reversed graphs, and a 64-bit integer type since costs can exceed 2^32.
