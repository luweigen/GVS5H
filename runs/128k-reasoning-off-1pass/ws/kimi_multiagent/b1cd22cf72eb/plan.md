We need to reduce lengths to final values u_i ≤ U_i, d_i ≤ D_i minimizing total reduction, with u_i + d_i = H constant and |u_i − u_{i+1}| ≤ X. For a fixed H, the optimal u_i is the pointwise maximum sequence satisfying u_i ≤ U_i, u_i ≥ H − D_i, and the Lipschitz constraint |u_i − u_{i+1}| ≤ X; this is computable via forward/backward propagation (feasible iff lower ≤ upper after propagation). Cost for fixed H is sum(U_i + D_i) − N·H, so we want the largest feasible H. Since feasibility is monotone in H (if H feasible, any H′ ≤ H feasible), binary search H over [0, max(U_i + D_i)] and answer with the max feasible H.
