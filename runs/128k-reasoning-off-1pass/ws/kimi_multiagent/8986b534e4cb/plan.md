Each person with |S-T|>1 forces a sign pattern on the prefix-sum array P (stamina at towns): P(S)=P(T)=0 and P strictly positive between, so traversing from min to max, the differences d_j = P(j+1)-P(j) must be +1 on the first step, -1 on the last step, with free signs inside; equivalently each person demands that road signs along [min,max) form a "mountain" (up then down) with at least one up and one down. Two people conflict iff their intervals force opposite signs on some shared edge position class — this reduces to checking, per query range, whether the induced constraints on edges are consistent, which can be characterized as a 2-coloring/interval-overlap condition on the set of intervals. The consistency of a set of such "mountain" intervals turns out to depend only on pairwise (or chain) conflicts: intervals that strictly interleave (a<c<b<d with same orientation demands) create contradictions. So we precompute, for each index i as right endpoint, the smallest left endpoint L for which [L,i] is feasible, using conflict edges between persons (i<j conflict if intervals interleave in a forbidden way), giving a sliding-window structure: maintain max over conflict pairs. Then each query [L,R] is Yes iff the precomputed "earliest valid left" for R is ≤ L, answerable in O(1) after O(M log M) preprocessing with a segment tree / sparse structure over conflict pairs.
