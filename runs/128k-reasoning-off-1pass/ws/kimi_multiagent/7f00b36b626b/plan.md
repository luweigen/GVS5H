The key insight is that lcm(a,b) <= threshold implies both a,b <= threshold, so any value greater than threshold is an isolated node. For values <= threshold, instead of checking O(n²) pairs, we connect each value to its multiples: for each value v present, iterate over multiples m = 2v, 3v, ... <= threshold, and if m is present, union v with m (since lcm(v, m) = m <= threshold). This is a classic Union-Find over a harmonic series, giving O(threshold log threshold) union operations. Finally, count distinct roots among all elements (elements > threshold each form their own component).
