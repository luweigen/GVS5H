The condition means black cells form a Young-diagram (Ferrers) shape anchored at the top-left: there is a non-increasing row-length sequence a[1..N] (0..N), cell (x,y) is black iff y <= a[x]. Equivalently, the boundary between black and white is a monotone path, and a cell (x,y) is black iff x + y <= t for the "anti-diagonal" view only when the shape is a staircase — but in general we need: for any black cell, all cells up or left of it are black; for any white cell, all cells down or right of it are white. So feasibility reduces to checking no given black cell has a given white cell weakly above-left of it, i.e., no pair with B at (x1,y1), W at (x2,y2) with x2<=x1 and y2<=y1. Additionally, even without conflicting pairs, we must confirm a monotone boundary exists separating all B's from all W's: define for each row the max black column and min white column; the shape exists iff we can pick non-increasing a[x] with maxB[x] <= a[x] < minW[x] (treating missing as 0 / N+1). Since constraints only come from given cells, we can compute per-row lower bound L[x]=max black y, upper bound U[x]=min white y - 1, fill unspecified rows by propagating: a[x] must satisfy a[x] >= a[x+1]... actually non-increasing means a[1] >= a[2] >= ... So feasibility: there exists non-increasing a with L[x] <= a[x] <= U[x]. This is checkable by scanning: maintain feasible range for a[x] given previous value.
