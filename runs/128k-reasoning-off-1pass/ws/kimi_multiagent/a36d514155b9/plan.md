The total sum over all arrangements can be decomposed into row contributions and column contributions, since Manhattan distance splits into |x1-x2| + |y1-y2|. For a fixed pair of rows (or columns), count how many arrangements have pieces in both rows, and multiply by the row distance; the number of such arrangements depends only on combinatorial counts. Precompute binomial coefficients C(total_cells, k-2) style terms using factorials up to m*n (≤ 1e5), then sum over all row pairs and column pairs in O(m^2 + n^2) — but m,n can be 1e5 each while m*n ≤ 1e5, so one dimension is small; still, derive closed-form sums over pairs to get O(m + n). Use the identity that sum over pairs of rows of |i-j| weighted by arrangements reduces to formulas with prefix sums or direct closed forms.
