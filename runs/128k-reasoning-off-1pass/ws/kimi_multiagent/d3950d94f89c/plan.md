Root the tree at 0 and run a single DFS that maintains the current root-to-node path as a sliding window with all-unique values. Track each value's last occurrence depth (or index along the current path) so that when a duplicate value is encountered, the window start can jump past the previous occurrence—this is the classic "longest substring without repeating characters" applied along a root-to-leaf path. For each node, the best special path ending at that node is determined by the current window start: length = dist[node] - dist[start], nodes = depth[node] - depth[start] + 1. Update the global answer preferring longer length, then fewer nodes. Use a dict (or array sized to max value) for last-seen positions and restore state on backtrack. Total complexity is O(n).
