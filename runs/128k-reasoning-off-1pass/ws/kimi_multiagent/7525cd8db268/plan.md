For a fixed set of pairs, a subarray [l, r] is invalid iff it contains both endpoints of some pair; equivalently, for each right endpoint r, the left endpoint l must be greater than max over pairs (a,b) of min(a,b) where max(a,b) <= r. So valid subarrays ending at r = r - maxForbidden[l], computable in O(n + m) with a sweep. Removing one pair only affects positions between its two endpoints, so we can compute, for each position i (as the smaller endpoint), the top two "blocking values" contributed by pairs starting at i; the gain from removing a pair is the difference between the best and second-best blockers summed over the affected range. Use difference arrays to accumulate these gains in O(n + m) total.
