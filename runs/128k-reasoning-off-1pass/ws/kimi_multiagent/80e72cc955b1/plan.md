Each operation reduces two numbers by dividing by 4 (floor). For a single number x, the number of times it must be divided by 4 to reach 0 is f(x) = floor(log4(x)) + 1 (for x >= 1). Since each operation handles exactly two numbers, the minimum operations for an array is max(max f(x), ceil(sum of f(x) / 2)). For a range [l, r], f is constant on intervals [4^k, 4^(k+1)-1], so we can compute sum and max of f over the range in O(log r) per query by iterating over power-of-4 blocks. Sum over all queries, being careful that the per-query answer uses the ceiling-of-half formula.
