We need to find the minimum operations to make all character counts equal. Since we can delete, insert, or increment characters (a→b→...→z), we should try each possible target frequency k (from 0 to max count) and compute the cost to make all 26 letters have exactly k occurrences. For each letter with count c, if c > k we can delete extras or increment them to help reach k for later letters; if c < k we can insert or use increments from earlier letters. This becomes a flow-like problem where increments can only move forward in the alphabet. We can solve it greedily or with DP for each k, taking the minimum over all k.
