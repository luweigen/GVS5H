We need the longest path starting at a cell with value 1, continuing along one of 4 diagonal directions with the expected alternating sequence (2,0,2,0,...), optionally making exactly one clockwise 90° turn at some point (including possibly zero-length second leg). Brute force walking from every 1 in every direction is O(n*m*max(n,m)) = up to 5e8, too slow, so we precompute DP tables. For each cell and each of the 4 diagonal directions, compute the length of the longest valid continuation (matching the alternating sequence based on parity of steps) in that direction, and similarly the longest continuation after a clockwise turn. Then for each starting cell/direction, walk the first leg and at each valid prefix combine with the turned-leg DP, taking the max. With memoized recursion per (cell, direction, parity/turn-state) this becomes O(n*m*states).
