This is the classic edit-distance-with-threshold problem (AtCoder "Operate K"). Since K ≤ 20, we only need to know whether the Levenshtein distance is ≤ K, which is only possible when |len(S) − len(T)| ≤ K. Compute the DP row by row, keeping only cells within the band |i − j| ≤ K around the diagonal, since any cell with |i−j| > K has distance > K. Use a rolling array of dicts (or offset lists) for O((N+M)·K) time and O(K) memory. Early-exit if a whole row exceeds K, and finally compare dp[N][M] with K.
