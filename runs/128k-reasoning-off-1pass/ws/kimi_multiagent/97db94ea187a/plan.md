The condition means the BFS layering from vertex 1 has equal total size in even and odd layers; since N is even, this is equivalent to choosing a bipartition of the vertices with 1 on one side, both sides of size N/2, and requiring the graph be connected with no edges inside either side (edges only across the cut). So the answer for each M is: (number of connected bipartite graphs with bipartition (A,B), 1∈A, |A|=|B|=N/2, with M edges) times C(N-1, N/2 - 1), the number of ways to choose the rest of A. To count connected bipartite graphs by edge count, use the standard total-minus-disconnected recurrence over the component containing vertex 1: fix the component's sides (a vertices of A including 1, b vertices of B), count all bipartite graphs on that component times all bipartite graphs on the remainder, and subtract. All counting polynomials (degrees up to N/2 squared ≤ 225) are convolutions computed with plain integer arithmetic mod P, which is fast enough for N ≤ 30.
