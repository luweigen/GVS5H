For each index i, the answer is the maximum d dividing A_i such that at least K elements of A are multiples of d (since we can pick A_i plus K-1 other multiples of d). So compute cnt[d] = number of array elements divisible by d for all d up to max(A) using a frequency array and a divisor-sieve accumulation in O(M log M). Then for each A_i, the answer is the largest divisor d of A_i with cnt[d] >= K; to answer fast, precompute best[x] = largest divisor d of x satisfying cnt[d] >= K, via another sieve pass: for each qualifying d, update multiples of d. Overall O(M log M + N), which fits N ≤ 1.2e6, A_i ≤ 1e6. Use fast I/O and flat arrays (lists of ints) in Python, with careful loop optimization.
