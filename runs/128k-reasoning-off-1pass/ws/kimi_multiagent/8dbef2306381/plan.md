This is a reachability problem on a line with steps in [A, B] (B ≤ 20) and blocked intervals. Since N is huge but M is small, we only need to track reachable positions near the ends of blocked intervals. Key insight: the set of reachable positions forms intervals; after a blocked segment, the reachable set "restarts" from positions reachable by jumping over the block. We can process each blocked interval: compute the reachable set just after it given the reachable set just before it, using the fact that within a gap of free squares, reachability with steps in [A,B] eventually becomes a contiguous interval (Frobenius-style / interval propagation). Use DP over small windows: maintain reachable set as a set of positions modulo nothing—rather, propagate intervals: from a reachable interval [l, r], one step gives [l+A, r+B]; iterating, the reachable set in free space becomes a union of intervals that merge once r + A ≤ l' + B + 1, i.e., after enough steps it becomes contiguous. Since B ≤ 20, we can simulate step-by-step over offsets within a bounded window (at most ~B*(B) steps) to compute the reachable set right after each blocked interval, then check if N is reachable from the last reachable set.
