## worker: Implement the complete solution in Python: parse S
- **Model**: A valid parenthesis sequence is an ordered rooted forest (virtual root holds top-level components; each matched pair is a node whose children are the components directly inside it).
- **Operation effect**: The flip-reverse on a valid substring maps `(A)` → `(rev(A))` and `AB` → `rev(B) rev(A)`, where `rev` is the same flip-reverse (an involution on valid sequences). Applying it to a two-component substring swaps adjacent siblings; adjacent transpositions generate the full symmetric group, so we can arbitrarily permute the children of any node (including the virtual root). Hence the reachable strings are exactly all ordered trees with the same *unordered* rooted-tree shape.
- **Counting**: The number of distinct ordered trees = product over all nodes of the number of distinct permutations of its multiset of child subtrees, where two subtrees are "identical" iff they are isomorphic as unordered rooted trees. For a node with k children and group multiplicities m₁, m₂, …, the count is k! / ∏ mᵢ!.
- **Canonical labels**: Bottom-up, label(node) = id of the sorted tuple of child labels (dict from tuple → id). This gives unordered-isomorphism classes deterministically in O(N log N) total.
- **Implementation details**: Iterative stack parse (O(N)); iterative post-order via reversed preorder; factorials and inverse factorials precomputed up to N+1 mod 998244353; answer accumulated as `fact[k] * ∏ inv_fact[m]`.
