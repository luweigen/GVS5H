Factor the equation: x³ − y³ = (x−y)(x²+xy+y²) = N. Let d = x−y ≥ 1; then d must divide N, and writing x = y+d gives 3y² + 3dy + d² = N/d, a quadratic in y. Since x²+xy+y² ≥ x−y (for positive x,y), we get d² ≤ N, so d ≤ 10⁹ — too many to enumerate directly, but the number of divisors of N ≤ 10¹⁸ is small (≤ ~10⁵), so enumerate divisors d of N with d ≤ N^(1/3)... actually d ≤ cube root condition: d³ < N roughly, so only divisors up to N^(1/3) ≈ 10⁶ need checking, and we can find them by trial division up to N^(1/3) ≈ 10⁶ which is feasible. For each divisor d with d³ < N (ensuring positive y possible), solve the quadratic via integer square root of the discriminant 12N/d − 3d², check y = (−3d + sqrt(D))/6 is a positive integer, and output (y+d, y).
