The key insight is that deleting all occurrences of a value x only helps if x is negative (removing positive values never increases the max subarray sum). For each distinct negative value x, we need the maximum subarray sum of the array with all x's removed. We can compute this efficiently by processing positions grouped by value: for each negative value x, run a Kadane-like scan where elements equal to x act as "reset points" (they split the array into segments), and the answer for x is the max subarray sum over the concatenation of segments between occurrences of x. Since each element belongs to exactly one value's "reset" computation, the total work across all negative values is O(n) per value naively — instead, observe that for value x, the max subarray sum of the filtered array equals the max over segments (between consecutive x's) of (max subarray sum that may span multiple segments joined by skipping x).
