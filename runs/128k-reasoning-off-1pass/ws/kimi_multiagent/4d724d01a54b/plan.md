Each adjacent swap at position i costs i, and sorting requires each inversion to be "resolved" by swaps. Key insight: an element moving left from position j to position i must cross each boundary k in [i, j-1] exactly once, paying sum of k; elements only move left (moving right is never beneficial since each inversion needs exactly one crossing). So the answer is: for each element P_j = v, its final position is v, and if v < j it must cross boundaries v..j-1, contributing sum_{k=v}^{j-1} k. Sum over all elements where v < j. This can be computed with prefix sums in O(N).
