We need the k-th lexicographic permutation where adjacent elements alternate in parity. Since n ≤ 100, we cannot enumerate permutations; instead we build the answer position by position using combinatorial counting. At each step, try candidate values in increasing order, count how many valid completions exist given the prefix (which fixes the required parity pattern of the remaining slots), and skip blocks smaller than k. The count of completions depends only on how many odd/even numbers remain and the parity required at the next position: if the remaining multiset can fill the remaining alternating slots (counts of each parity must match the slots' parity demands), the number of completions is (odd_remaining)! × (even_remaining)!, otherwise 0. Use arbitrary-precision integers (Python) and cap counts above k to avoid waste; factorials up to 100 are fine.
