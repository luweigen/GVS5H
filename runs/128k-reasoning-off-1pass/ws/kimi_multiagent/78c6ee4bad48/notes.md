
## ideation
The core difficulty is understanding the reachability structure of the operation. Key insight: the operation on four consecutive pieces (a,b,c,d) maps (b,c) → (a+d-c, a+d-b), which preserves b+c and keeps ordering. In terms of gaps g_j = x_{j+1} - x_j, the operation reverses three consecutive gaps (g_i, g_{i+1}, g_{i+2}) → (g_{i+2}, g_{i+1}, g_i). This is a transposition of gaps at positions i and i+2, which preserves the parity of gap indices. Within each parity class (odd-indexed gaps and even-indexed gaps), adjacent transpositions generate the full symmetric group, so gaps can be arbitrarily permuted within each parity class. The total sum is N*x_1 + Σ_j (N-j)*g_j, where weights (N-j) decrease with j. To minimize, within each parity class, assign larger gaps to positions with smaller weights (larger j) — i.e., sort gaps in each parity class and match largest gaps with smallest weights (rearrangement inequality).

Pitfalls: (1) Need to confirm that adjacent transpositions within a parity class are actually achievable — swapping gaps at positions j and j+2 within the same parity class requires the operation at index j, and to swap "adjacent" elements of a parity class (positions j and j+2) we directly use operation at j which swaps exactly those two while fixing the middle. Yes — the operation at i swaps g_i and g_{i+2} while keeping g_{i+1} fixed. So each parity class can be permuted arbitrarily via adjacent transpositions. (2) x_1 itself never changes? Actually the leftmost piece position can change... no — gaps determine positions given x_1. Does x_1 ever change? The operation moves pieces i+1 and i+2, never the leftmost piece (piece 1 can only be moved if it's the (i+1)-th or (i+2)-th, requiring i=0 or i=-1, impossible). So x_1 is invariant. (3) Large numbers: N up to 2e5, coordinates up to 1e12, sum can be ~2e17, use Python int (fine).

- Operation on four consecutive pieces (a,b,c,d): b → a+d-c, c → a+d-b. New gaps: (a+d-c-a, a+d-b-(a+d-c), d-(a+d-b)) = (d-c, c-b, b-a). So gaps (g_i, g_{i+1}, g_{i+2}) → (g_{i+2}, g_{i+1}, g_i): swaps gaps at positions i and i+2, fixing the middle. This preserves parity classes of gap indices and generates full symmetric group within each class (adjacent transpositions within a class).
- x_1 is invariant (piece 1 never moves). Sum = n*x_1 + Σ (n-1-j)*g_j with weights decreasing in j.
- By rearrangement inequality, within each parity class assign largest gaps to smallest weights (largest j). Implementation sorts each class descending and assigns to positions in decreasing j order.
