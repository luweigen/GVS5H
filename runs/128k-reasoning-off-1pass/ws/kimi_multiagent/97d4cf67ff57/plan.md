A subgraph of a tree that is itself a tree must be a connected vertex subset with all induced edges kept (a subtree). In such a subtree, a vertex's degree is 1 (leaf) or 4 (internal), so every included vertex keeps either exactly 1 or exactly 4 of its neighbors within the chosen set. Root the tree arbitrarily and run a tree DP where each state describes how the parent edge is used and how many children are kept, so that each vertex ends with total kept-degree in {1,4}. Because a vertex may have many children, combine children with a small knapsack-style DP over counts 0..4, tracking the best total vertices. The answer is the maximum valid subtree size over all roots/states, or -1 if none exists.
