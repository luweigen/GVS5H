Model each row as a W-bit mask. Choosing row flips r_i and column flips c_j makes cell (i,j) equal A_ij XOR r_i XOR c_j. For a fixed column-flip vector c, each row independently picks r_i to minimize its popcount, contributing min(popcount(m XOR c), W - popcount(m XOR c)). Since W ≤ 18, we can enumerate all 2^W column-flip vectors c and sum these per-row minima, taking the overall minimum. To do this efficiently over H up to 2e5, compress rows into frequency counts per mask (size ≤ 2^W), then compute f[c] = sum over masks of freq[mask] * min(popcount(mask XOR c), W - that). This is a XOR-convolution-style computation; with 2^W ≤ 262144 and W ≤ 18, an O(W * 2^W) SOS-like transform or direct O(4^W) may be too big, so use the structure: min(p, W-p) depends only on popcount of (mask XOR c). Precompute g[k] = min(k, W-k) and compute h[c] = sum_mask freq[mask] * g[popcount(mask XOR c)] via subset-sum (FWT) per popcount layer, or simply iterate masks with nonzero freq and update via popcount — worst case O(2^W * 2^W) is too slow, so use the Walsh-Hadamard approach: g depends on popcount, expand via Krawtchouk polynomials; simpler: do FWT of freq, and FWT of kernel k[d] = g[popcount(d)] — but kernel isn't XOR-convolution kernel of popcount directly... Actually h = freq ⊛ k where XOR convolution, computable via FWT in O(W 2^W). Answer is min over c of h[c].
