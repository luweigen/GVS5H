Since target has at most 4 elements, enumerate all non-empty subsets of target and compute the LCM of each subset; a single nums element raised to a multiple of that LCM covers every target in the subset. For each subset, precompute the minimum cost over all nums elements: cost = (ceil(nums[i]/LCM)*LCM - nums[i]), which is O(|nums| * 2^|target|) and fits constraints. Then run a subset DP over target masks: dp[mask] = min over submask of dp[mask ^ submask] + cost[submask], using each nums element at most once implicitly because we partition the mask (note: one nums element can cover multiple targets, and different subsets in the partition would need distinct elements — but since cost[submask] could reuse the same element, we must verify; a safer DP iterates elements, but with only 4 targets the partition DP is standard for this problem as each subset's cost is achievable independently and optimal solutions assign disjoint elements per subset in a partition when needed — workers should validate this with examples). Return dp[full_mask].
