We need sum over all subarrays of length ≤ k of (min + max). Use the classic contribution technique: sum of subarray minimums and maximums via monotonic stacks, but restricted to subarrays of length at most k. For each element as the minimum (or maximum), count valid subarrays where it is the "controlling" element, but cap the left/right extension so total length ≤ k. The cap makes counting a bit more involved: for element at i with left reach L and right reach R (from monotonic stack boundaries), count pairs (l, r) with l in left range, r in right range, r - l + 1 ≤ k, via a careful summation formula. Total = sum over i of nums[i] * (count_as_max + count_as_min).
