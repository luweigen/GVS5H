The problem: partition a tree with NK vertices into N vertex-disjoint paths, each containing exactly K vertices (K-1 edges). Total vertices ≤ 2×10^5, so we need near-linear or O(V log V) solution.

Core difficulties:
1. **K=1**: trivially Yes (each vertex is its own path).
2. **K=2**: equivalent to perfect matching on a tree — solvable greedily by matching leaves with parents bottom-up.
3. **K≥3**: much harder. A path of K vertices has structure; the natural greedy is "peel" paths containing leaves.

Key structural insight: In any valid decomposition, consider a leaf ℓ of the tree. Its path in the decomposition must go from ℓ through its unique neighbor chain. If we root the tree, each path either lies entirely within a "vertical" chain or bends at some LCA (path goes up from one subtree, through a vertex, down into another subtree). This makes the problem resemble matching/grouping subtrees.

Candidate greedy approach (leaf peeling): Root tree arbitrarily. Process leaves: a leaf ℓ must belong to a path. The path containing ℓ, if it goes "upward only," is forced to be ℓ, parent(ℓ), ..., K-1 ancestors up. But paths can bend (go up then down into a sibling subtree), so the path isn't always forced. However, a known technique for such "path partition" problems: repeatedly take a deepest leaf, walk up K-1 steps (if possible), and check that this segment is "clean" (no branching that would strand vertices).
