We need to count substrings divisible by their last digit. The key insight is that for a substring ending at index `i` with digit `d = s[i]`, we need to know how many starting positions `j` make the number `s[j..i]` divisible by `d`. Since divisibility rules depend on the divisor, we handle digits differently: for 1, 2, 5, all prefixes work; for 3, 9, we need digit sums; for 4, 8, we need the last 2 or 3 digits; for 6, we need divisibility by both 2 and 3; for 7, we need actual modular arithmetic. We can iterate through the string and maintain running values (prefix mod 3, mod 9, last 2 digits mod 4, last 3 digits mod 8, mod 7) to count valid substrings ending at each position in O(1) or O(log) time per position.
