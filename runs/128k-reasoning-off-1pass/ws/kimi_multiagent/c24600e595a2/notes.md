**Model.** Each operation flips one bit and pays the current weighted sum S = Σ A_k C_k (after the flip). Total cost = Σ_i C_i · T_i where T_i = number of operations after which bit i is 1.

**Structural results (proven by exchange arguments):**
1. *All down-flips precede all up-flips:* swapping an adjacent up-then-down pair to down-then-up strictly reduces cost by C_j + C_k. Within downs, sort by C descending; within ups, ascending (adjacent exchange).
2. *No index flipped more than needed:* required flips (A_i≠B_i) exactly once; optional 1→1 indices either never or twice (down in phase 1, up in phase 2); 0→0 indices never (removing an up...down pair only lowers intervening costs).
3. *Closed form:* for down-set D and up-set U, total = PairsMin(D) + PairsMin(U) + Σ_{U} C_i + (inactive optionals)·m, where PairsMin(S) = Σ_{pairs} min(C_i,C_j) and m = |D|+|U|.
4. *Prefix property:* if optional i is active and j inactive with C_j > C_i, swapping them changes cost by at most −(C_j−C_i) < 0 (using |D|+|U| = m to bound pair-term growth). Hence the optimal active set is a prefix of optionals sorted by C descending.

**Algorithm.** Compute Total(0) directly (PairsMin via sorted order: Σ v_i·(k−1−i)). Then activate optionals one by one (descending C) using the incremental formula:
Δ_t = c·(#{DR ≥ c} + t−1) + Σ_{DR < c} C + c·(#{UR ≥ c} + t−1) + Σ_{UR < c} C + c + 2·suffix_{t+1} − c·m_{t−1},
with binary search + prefix sums on sorted DR/UR. Track the minimum over all prefixes t = 0..K.

**Verification.** Hand-checked against Sample 1 (16: Total(0)=16, Total(1)=18), Sample 2 (0), and the counterexample that breaks the naive "flip each once" idea (A=(1,1,1), B=(0,0,1), C=(1,1,100): direct=201, using the C=100 shield=103 — formula reproduces both).
