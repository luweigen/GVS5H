A good caption is a concatenation of blocks of identical characters, each block having length at least 3. Since operations only change a character by ±1 per step, the cost to turn a segment into a uniform character c is the sum of absolute alphabet distances to c. This suggests a DP over positions where each block has length 3, 4, or 5 (any length ≥ 6 can be split into smaller blocks of 3–5, which is never worse and helps lexicographic minimality). For each segment and target character, the cheapest uniform fill uses the median character of the segment; we precompute these costs and resulting strings. Finally, run DP minimizing (cost, result string) lexicographically as a tie-break, reconstructing the answer.
