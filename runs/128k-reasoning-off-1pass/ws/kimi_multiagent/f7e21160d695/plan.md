The minimax distance f(x,y) equals the maximum edge weight on the path between x and y in any Minimum Spanning Tree (Kruskal reconstruction). Build a Kruskal reconstruction tree (2N-1 nodes, each internal node weighted by the edge that merged its children); then f(x,y) = weight of LCA(x,y) in this tree. To minimize the sum over a free permutation of B, sort the multiset {f(A_i, B_j)} pairing greedily: for each A_i we need distances to all B_j — but K can be N, so we need structure. Key observation: pairing to minimize sum of costs where cost depends on LCA depth — sort A-side and B-side "signatures" and match in sorted order (rearrangement inequality) if cost is monotone in a single parameter. Compute for each vertex its "depth profile" and reduce to sorting/matching via the reconstruction tree structure, then verify with samples.
