We need to count all monotone (right/up) paths within a rectangle [0,W]×[0,H] minus the interior rectangle (L..R)×(D..U) (points with L≤x≤R and D≤y≤U are removed). The total number of paths equals the sum over all valid starting points of the number of monotone paths from that point, which equals the sum over all valid endpoints of paths ending there; equivalently, count all pairs (s,t) of valid points with s≤t coordinatewise and a monotone path between them avoiding the hole. Since moves only go right/up, a path from s to t is blocked by the hole only if the monotone rectangle [s.x,t.x]×[s.y,t.y] intersects the hole in a way that forces passage through it — actually any path from s to t stays inside the bounding box, so it's valid iff no forced crossing; the standard approach: total paths = sum over all valid points p of f(p) where f(p) = number of paths starting at p = sum over valid q≥p of C(dx+dy,dx) minus paths passing through hole. Use complement/inclusion: count paths in full grid minus those passing through at least one hole point; paths through the hole can be counted via entry/exit edges: paths entering hole through left/bottom boundary and exiting through right/top. A cleaner decomposition: total = (paths never touching hole) = sum over starts s of g(s) where g(s) counts paths from s avoiding hole; compute via DP over the hole boundary using the fact that the hole is a rectangle: paths from s to t avoiding hole = total(s,t) − paths via hole, where via-hole paths factor as s→entry point on hole's left/bottom edge, through hole, exit from top/right edge. Plan: derive formula splitting valid region into regions around the hole and use prefix sums of binomials; implement O((W+H) log) or O(N) with precomputed factorials up to W+H.
