XOR constraints decompose per bit, so solve each bit independently as a 2-coloring problem on a graph with N vertices: each constraint says bit b of A_{X_i} XOR bit b of A_{Y_i} equals bit b of Z_i. Build one DSU-with-parity (weighted union-find) over all constraints at once to detect inconsistency and find connected components; each component then has two possible assignments (flip or not) per bit. For each component and each bit, count how many vertices would have the bit set in each of the two phases and choose the phase with the smaller count (ties break toward 0), which minimizes the total sum since bits are independent and weights are separable. Reconstruct A by summing chosen bits per vertex.
