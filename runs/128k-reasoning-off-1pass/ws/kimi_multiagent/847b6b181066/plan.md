Track the set of smoke positions implicitly: smoke at time t+0.5 consists of cells whose "birth time" k (0 ≤ k ≤ t, where smoke generated at time k+0 after wind k... actually generated after wind step k if origin empty) satisfies that the net displacement of winds S[k+1..t] equals (R,C). Equivalently, define prefix displacement P[i] = sum of first i wind vectors; smoke born at origin right after step k (or at time 0, k=0) reaches (R,C) at time t+0.5 iff P[t] - P[k] = (R,C), i.e., P[k] = P[t] - (R,C). Smoke is generated at origin after step k iff no smoke sits at origin at that moment, i.e., no earlier birth j ≤ k-1... actually origin occupancy at time k+0.5 (before generation) is whether some birth j with P[j] = P[k]... origin has smoke iff P[k] - P[j] = 0 for some active birth j, i.e., P[j] = P[k]. So generation at step k happens iff P[k] ∉ {P[j] : j born}. Maintain a set of birth prefix-values; iterate t=1..N, answer 1 iff P[t]-(R,C) is in the birth set, then check if P[t] is in the birth set—if not, add P[t] as a new birth. Birth at time 0 corresponds to P[0]=(0,0) initially in the set.
