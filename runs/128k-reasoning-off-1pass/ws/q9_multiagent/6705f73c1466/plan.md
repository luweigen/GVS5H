The problem asks for the minimum number of swaps to make all '1's contiguous. This is equivalent to moving all '1's to a specific target window of length $K$ (where $K$ is the total count of '1's) with minimal cost. The cost to move a set of items to a target position is minimized when the target position aligns with the median of the items' current positions. We will first collect the indices of all '1's, then iterate through all possible contiguous windows of length $K$ in the string. For each window, we calculate the cost to move the '1's into it by summing the absolute differences between their current indices and their target indices within the window. The minimum of these costs across all windows is the answer.
