The problem requires selecting up to 4 non-overlapping intervals to maximize total weight, with ties broken by the lexicographically smallest index array. Since the number of intervals to pick is small (at most 4), we can use dynamic programming where the state tracks the number of intervals picked and the end position of the last picked interval. To handle the large coordinate range (up to 10^9), we will compress coordinates or simply sort intervals by end time and use the sorted order for DP transitions. We need to store not just the maximum weight but also the actual indices to reconstruct the lexicographically smallest solution. The DP state will be `dp[k][i]` representing the max weight using exactly `k` intervals where the last interval is `i`. We will precompute suffix maximums for the remaining intervals to efficiently find the best next interval. Finally, we will iterate through all possible last intervals for each count (1 to 4) and reconstruct the path that yields the maximum weight and is lexicographically smallest.
