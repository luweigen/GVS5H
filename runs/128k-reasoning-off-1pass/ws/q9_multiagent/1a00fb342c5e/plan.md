We will model the problem as a system of linear equations over GF(2) where each variable $A_i$ corresponds to a node and each constraint $A_{X_i} \oplus A_{Y_i} = Z_i$ corresponds to an edge with weight $Z_i$. We use a Disjoint Set Union (DSU) with path compression and an additional `xor_val` array to track the XOR distance from each node to its representative. We iterate through all constraints; if a conflict is found (the calculated XOR distance between two nodes in the same component does not match $Z_i$), we output -1. If no conflicts exist, we assign $A_i = 0$ for all unconnected components and solve for connected components by setting the representative to 0 and propagating values to minimize the sum (since $A_i$ must be non-negative, and the system is homogeneous relative to the representative choice, setting the representative to 0 yields the minimal non-negative solution for that component).
