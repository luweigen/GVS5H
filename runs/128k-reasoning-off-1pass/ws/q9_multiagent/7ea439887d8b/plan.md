The problem asks for the minimum cost to travel from vertex 1 to vertex N in a directed graph where we can either move along an edge (cost 1) or reverse all edges (cost X). Since reversing edges flips the direction of every edge, the state space can be modeled as a graph with two layers: Layer 0 represents the original edge directions, and Layer 1 represents the reversed edge directions. Transitions within a layer correspond to moving along edges (cost 1), while transitions between layers correspond to reversing all edges (cost X). We can solve this using Dijkstra's algorithm on this 2-layer graph, starting from (1, 0) and targeting (N, 0) or (N, 1), taking the minimum of the two.
