The problem asks for the sum of Manhattan distances between all pairs of pieces across all valid arrangements. Since the grid is rectangular and the pieces are identical, the total sum can be decomposed into the sum of horizontal distances and vertical distances independently. For each dimension (rows and columns), we calculate the contribution of the distance between every pair of occupied cells multiplied by the number of ways to place the remaining pieces. This reduces the 2D problem to two 1D problems: one for the row indices and one for the column indices. We can precompute the number of ways to choose `i` items from `N` slots using combinations, then iterate through possible distances in each dimension to accumulate the total sum modulo 10^9 + 7.
