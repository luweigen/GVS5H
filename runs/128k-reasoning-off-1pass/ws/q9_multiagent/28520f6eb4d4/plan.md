The problem asks for the maximum height $h$ at coordinate 0 such that we cannot see *all* buildings. This is equivalent to finding the minimum height $h_{min}$ required to see the "hardest" building (the one that requires the highest vantage point to be visible given the buildings in between). If even at height 0 all buildings are visible, the answer is -1. We can iterate through each building $i$ and calculate the minimum height at $x=0$ required to see building $i$. A building $i$ is visible from $(0, h)$ if the line of sight from $(0, h)$ to some point on building $i$ does not intersect any building $j$ where $X_j < X_i$. The critical constraint for building $i$ comes from the building $j$ ($j < i$) that maximizes the slope required to clear it. Specifically, for a fixed $i$, we need to find $j < i$ that maximizes the slope $(H_j - h) / (X_j - 0)$ relative to the target point on $i$. Actually, it's simpler: to see building $i$, the line from $(0, h)$ to $(X_i, H_i)$ must not be blocked by any $j < i$. The condition is that for all $j < i$, the point $(X_i, H_i)$ must be "above" the line segment from $(0, h)$ to $(X_j, H_j)$? No, visibility means there exists *some* point on building $i$ visible. The optimal point on building $i$ to see is usually the top $(X_i, H_i)$ if we are looking from the left, but actually, if a building blocks the top, it might block the whole thing. Wait, the definition says "exists a point Q on building i". If the line from $(0, h)$ to $(X_i, H_i)$ is blocked by $j$, maybe a lower point on $i$ is visible? Yes. However, since buildings are vertical segments, if the top is blocked, the bottom is definitely blocked (assuming $h \ge 0$). So we just need to see the top $(X_i, H_i)$. The condition for $(X_i, H_i)$ to be visible is that for all $j < i$, the slope from $(0, h)$ to $(X_i, H_i)$ must be greater than the slope from $(0, h)$ to $(X_j, H_j)$. That is, $(H_i - h)/X_i > (H_j - h)/X_j$. Rearranging, we get a lower bound on $h$ for each $j$. We calculate this lower bound for all $j < i$ and take the maximum. Then we do this for all $i$ and find the global minimum $h$ that fails to see at least one building. If the global minimum required to see *all* is $\le 0$, then at $h=0$ we see all, so output -1. Otherwise, the answer is that global minimum.
