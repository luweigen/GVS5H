The problem asks for the final rating after $N$ contests for $Q$ different initial ratings. Since the rating changes depend on the current rating falling within specific intervals $[L_i, R_i]$, and the maximum possible rating is relatively small ($5 \times 10^5 + N$), we can precompute the answer for every possible starting rating. We will use a difference array (or sweep-line) technique to efficiently calculate how many times each rating interval contributes to the total increase. Specifically, for each contest $i$, we increment a counter for the range $[L_i, R_i]$. After processing all contests, we compute the prefix sums of this counter array to determine the total number of times a rating increases for any starting value $X$. Finally, we answer each query in $O(1)$ time by looking up the precomputed value.
