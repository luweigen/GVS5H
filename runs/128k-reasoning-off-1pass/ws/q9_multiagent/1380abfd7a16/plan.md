The problem asks us to simulate inserting numbers $1$ through $N$ into an array at specific positions $P_i$. A direct simulation using a list or array would be $O(N^2)$ because each insertion requires shifting elements, which is too slow for $N \le 5 \times 10^5$. Instead, we should process the operations in reverse order, from $N$ down to $1$. When considering the insertion of number $i$, we know its final position relative to the elements that were inserted *after* it (which are $i+1, \dots, N$). Since those later elements have already been placed in their final spots, we can determine the exact index for $i$ in the final array by counting how many of those later elements fall before the target position $P_i$. We can use a Fenwick tree (Binary Indexed Tree) to efficiently count these elements and find the correct empty slot.
