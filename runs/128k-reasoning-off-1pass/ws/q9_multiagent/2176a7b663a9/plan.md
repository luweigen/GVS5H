The problem asks for the minimum weight path in the complement of an interval graph. It is a known property that the diameter of the complement of an interval graph is at most 2. Therefore, the shortest path between any two vertices $s$ and $t$ is either a direct edge (if the intervals are disjoint) or a path of length 2 through a common neighbor $k$ (where $k$ is disjoint from both $s$ and $t$). If no such path exists, the answer is -1. We can solve this efficiently by:
1. Checking if $s$ and $t$ are directly connected (i.e., $[L_s, R_s] \cap [L_t, R_t] = \emptyset$). If so, the answer is $W_s + W_t$.
2. If not, we search for a vertex $k$ such that $k$ is disjoint from both $s$ and $t$. This requires finding $k$ in the intersection of two sets of intervals: those disjoint from $s$ and those disjoint from $t$. The condition "disjoint from $s$" means $L_k > R_s$ or $R_k < L_s$. We need to find the minimum $W_k$ in the union of four regions defined by the intersection of these conditions.
3. To efficiently query the minimum weight in these regions, we can use a Merge Sort Tree (a Segment Tree where each node stores a sorted list of pairs $(R_i, W_i)$ for intervals with $L_i$ in that node's range). This allows us to perform 2D range minimum queries in $O(\log^2 N)$.
4. We process all queries and output the results.
