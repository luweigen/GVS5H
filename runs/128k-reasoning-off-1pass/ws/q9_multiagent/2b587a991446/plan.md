The problem asks for the minimum moves to swap two pieces on a graph without them occupying the same vertex simultaneously. This is a shortest path problem on a state space where a state is defined by the positions of piece A and piece B. Since the graph is unweighted, Breadth-First Search (BFS) is the optimal algorithm. The state space size is at most $N \times N$, which fits within memory limits ($2 \times 10^5$ vertices implies roughly $4 \times 10^{10}$ states, but we only visit reachable states; however, a direct $N^2$ array is too large). Instead, we can use a hash map (dictionary in Python) to store visited states $(u, v)$ and their distances. The BFS starts at $(S, T)$ and explores all valid moves (moving A or B to an adjacent node) ensuring the new state doesn't have $u=v$. The first time we reach $(T, S)$, we return the distance. If the queue empties without reaching the target, output -1.
