The problem requires finding the maximum GCD of a subset of size $K$ that includes $A_i$ for each $i$. Since $A_i \le 10^6$, we can iterate over all possible GCD values $g$ from $1$ to $10^6$. For each $g$, we count how many numbers in the input array are multiples of $g$. If the count is at least $K$, then $g$ is a candidate answer for any $A_i$ that is itself a multiple of $g$. To solve efficiently, we first compute the frequency of each number, then use a sieve-like method to count multiples for every $g$. Finally, for each $A_i$, we check divisors of $A_i$ in descending order; the first divisor $d$ that has at least $K$ multiples in the array is the answer for $A_i$.
