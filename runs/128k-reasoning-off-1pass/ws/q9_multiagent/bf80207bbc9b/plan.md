The problem asks for the minimum sum of 1s in a grid after flipping arbitrary rows and columns. Since $W$ is very small ($W \le 18$), we can iterate through all $2^W$ possible patterns of column flips. For a fixed set of column flips, the decision to flip each row becomes independent: we simply check if flipping a row reduces the number of 1s in that row given the current column state. We calculate the total sum for each column flip pattern and take the minimum.
