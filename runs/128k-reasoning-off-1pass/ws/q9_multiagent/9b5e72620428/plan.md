The key insight is that the sum $S = A_i + B_i$ must be the same for all $i$. For any pair $(A_i, B_i)$ where neither is -1, the sum $A_i + B_i$ is fixed. If there are multiple such fixed pairs, their sums must be equal; otherwise, it's impossible. If there are no fixed pairs, we can choose any non-negative sum $S$ and fill the -1s accordingly, which is always possible. If there is exactly one fixed pair, we can choose $S = A_i + B_i$ and fill the rest. If there are fixed pairs with different sums, output No.
