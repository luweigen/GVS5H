1. A "400 number" is of the form $p^{2a} q^{2b}$ where $p, q$ are distinct primes and $a, b \geq 1$. This can be rewritten as $(p^a q^b)^2$ is not quite right because the exponents are separate. Actually, it's $N = p^{2a} q^{2b}$. Let $x = p^a$ and $y = q^b$. Then $N = x^2 y^2 = (xy)^2$? No, $p^{2a} q^{2b} = (p^a q^b)^2$. So every 400 number is a perfect square.
2. Furthermore, if $N = k^2$, then the prime factorization of $k$ determines the exponents in $N$. If $k = p^a q^b$ with $p \neq q$, then $N = p^{2a} q^{2b}$. The distinct prime factors of $N$ are $p$ and $q$ (exactly 2). The exponent of $p$ in $N$ is $2a$ (even) and $q$ is $2b$ (even). So $N$ is a 400 number if and only if $N = k^2$ where $k$ is a product of exactly two distinct primes raised to some positive integer powers. In other words, $k$ has exactly two distinct prime factors.
3. So the problem reduces to: Find the largest perfect square $k^2 \leq A$ such that $k$ has exactly two distinct prime factors.
4. Since $A \leq 10^{12}$, $k \leq 10^6$. We can precompute all integers $k \in [1, 10^6]$ that have exactly two distinct prime factors.
5. For each query $A$, we want the largest $k \leq \lfloor \sqrt{A} \rfloor$ such that $k$ is a "2-distinct-prime-factor" number. Then the answer is $k^2$.
6. We can precompute a boolean array or a list of valid $k$'s up to $10^6$. Then for each query, compute $S = \lfloor \sqrt{A} \rfloor$, and find the largest valid $k \leq S$. We can use binary search on the sorted list of valid $k$'s or a precomputed "largest valid $\leq x$" array.
