1. **Graph Analysis**: The graph $G$ is the complement of the interval graph formed by the given intervals. Two vertices are connected if their intervals do not overlap.
2. **Connectivity and Shortest Path**: Since edge weights are not directly on edges but on vertices, the weight of a path is the sum of the weights of the vertices in the path. We need the minimum weight path, which is equivalent to finding the shortest path in a graph where node weights contribute to the path cost.
3. **Key Insight**: In such graphs, if the graph is connected, the minimum weight path between $s$ and $t$ often involves going through the vertex with the smallest weight in the connected component, if possible. Specifically, if $s$ and $t$ are in the same connected component, the minimum path weight is $\min(W_s + W_t + \min_{v \in C, v \neq s, v \neq t} W_v, W_s + W_t)$ if they are directly connected, or more generally, the path might go through the minimum weight node in the component.
4. **Component Identification**: We can identify connected components of $G$. However, explicitly building $G$ is too slow ($O(N^2)$). Instead, we use the property that the complement of an interval graph is a comparability graph or can be analyzed using sweep-line techniques.
5. **Efficient Component Finding**: We can use a disjoint-set union (DSU) or BFS/DFS on the implicit graph. A better approach is to note that two intervals are connected if they are disjoint. The connected components of the complement of an interval graph can be found by sorting intervals and using a sweep-line to find connections.
6. **Minimum Weight Path Calculation**: For each connected component, precompute the two smallest vertex weights. For a query $(s, t)$, if they are in different components, output -1. If in the same component, the minimum path weight is $W_s + W_t + \min(0, \text{min\_weight\_in\_component} - \max(W_s, W_t) \text{ if path through min node is shorter})$. Actually, the shortest path in an unweighted graph with node weights is often just $W_s + W_t$ if they are adjacent, or $W_s + W_{min} + W_t$ if going through the minimum node is better and possible. We need to check if $s$ and $t$ are adjacent or if a path through the minimum node exists.
