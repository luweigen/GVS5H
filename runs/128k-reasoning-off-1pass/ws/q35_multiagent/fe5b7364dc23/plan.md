To solve this problem efficiently, we need to compute the sum of the K-th powers of all subarray sums. A naive approach would take O(N^2) which is too slow for N up to 2*10^5. However, since K is very small (K <= 10), we can expand the K-th power of a subarray sum using the multinomial theorem or by maintaining coefficients for each power of prefix sums. Specifically, let S_i be the prefix sum A_1 + ... + A_i. The sum of subarray A[l..r] is S_r - S_{l-1}. We need to compute sum_{1<=l<=r<=N} (S_r - S_{l-1})^K. Expanding this using the binomial theorem gives sum_{j=0}^K binom(K, j) S_r^j (-1)^{K-j} S_{l-1}^{K-j}. We can iterate through r from 1 to N, and maintain the sum of S_{l-1}^p for all l-1 < r (i.e., for all previous prefix indices) for each power p from 0 to K. This allows us to compute the contribution of each r in O(K) time, leading to an overall O(NK) solution.
