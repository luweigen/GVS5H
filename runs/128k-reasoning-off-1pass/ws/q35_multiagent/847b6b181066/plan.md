The key observation is that smoke only exists at cells that were reachable from (0,0) at some previous time $t' < t$ and then drifted to $(R,C)$ by time $t$. Specifically, smoke generated at time $t'$ (after the wind at step $t'$ blows) will be at position $(R,C)$ at time $t+0.5$ if the net displacement from $t'+1$ to $t$ moves the smoke from $(0,0)$ to $(R,C)$. Let $D_k$ be the displacement vector after step $k$. The position of smoke generated at time $t'$ at time $t$ is $D_t - D_{t'}$. We need $D_t - D_{t'} = (R,C)$, i.e., $D_{t'} = D_t - (R,C)$. We can precompute the cumulative displacements $D_t$ for $t=0 \dots N$. For each $t$, we check if the value $D_t - (R,C)$ has appeared as a cumulative displacement $D_{t'}$ for any $t' < t$. If yes, smoke exists. We use a hash set to store seen cumulative displacements and update it after each step.
