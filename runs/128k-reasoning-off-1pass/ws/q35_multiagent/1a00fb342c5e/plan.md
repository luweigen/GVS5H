1. Model the problem as a system of XOR equations over a graph with N nodes and M edges. Each constraint $A_{X_i} \oplus A_{Y_i} = Z_i$ represents an edge between $X_i$ and $Y_i$ with weight $Z_i$.
2. Decompose the graph into connected components. For each component, pick an arbitrary root node and assign it a value (initially 0 to minimize sum, but we must check consistency). Then, propagate the values to all other nodes in the component using BFS/DFS. If a contradiction is found (i.e., a node is reached with two different required values), output -1.
3. For each connected component, the values of all nodes are determined relative to the root's value. Specifically, $A_v = A_{root} \oplus D_v$, where $D_v$ is the XOR sum of edge weights along the path from root to $v$.
4. To minimize the total sum $\sum A_i$, we need to choose the optimal value for each component's root. Let the component have nodes $v_1, \dots, v_k$ with precomputed offsets $D_{v_j}$. We want to minimize $\sum_{j=1}^k (R \oplus D_{v_j})$ where $R$ is the root value.
5. Since the XOR operation works bitwise independently, we can determine the optimal bits of $R$ from most significant to least significant (or independently per bit). For each bit position $b$, count how many nodes in the component have the $b$-th bit of $D_v$ set to 0 ($c_0$) and 1 ($c_1$). If we set the $b$-th bit of $R$ to 0, the contribution to the sum from this bit is $c_1 \cdot 2^b$. If we set it to 1, the contribution is $c_0 \cdot 2^b$. Choose the bit value that minimizes this contribution.
6. Construct the final sequence using the optimal root values for each component and print it.
