We need to answer many queries about the final rating after applying N conditional increments. A contest i increments the current rating if it lies in [L_i, R_i]. The rating only increases (by 1 each time), never decreases, so the process is monotonic. We can pre‑compute, for every possible rating x in [1, 5e5], the number of contests that would trigger at rating x. Since the rating only grows, the triggers at a higher rating are a subset (or equal) of the triggers at a lower rating: if a contest's interval does not contain x, it will not contain any y > x. This monotonicity lets us compute an array f[x] = total increments starting from x, using a sweep from high to low: for each contest, increment a difference array at L_i and decrement at R_i+1; then prefix‑sum to get the count of contests active at each rating x, and accumulate f[x] = f[x+1] + count[x].

Once f is built, each query X returns X + f[X] in O(1). The whole solution is O(N + MAX_R + Q).
