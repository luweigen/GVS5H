Model the problem as a shortest path on a graph with 2N states: each vertex v appears in two layers — `v0` (original orientation) and `v1` (reversed orientation). Moving along an edge in the current orientation costs 1 (i.e., from `v0` to `u0` if edge v→u exists, or from `v1` to `u1` if edge u→v existed originally). Reversing the entire graph costs X and transitions every vertex from layer 0 to layer 1 (and from 1 to 0). Run Dijkstra from `(1,0)` to any of the N states in layer 0 or 1. The answer is the minimum distance to vertex N in either layer. Complexity: O((N+M) log N), suitable for 2×10^5.
