We can delete only a prefix where all elements are equal. So we must gather equal values to the left to form deletable runs. Each deletion removes an entire run of equal values at the front. Between deletions we may need to swap adjacent elements to bring the next needed value to the front. The minimum number of swaps equals the number of inversions where a larger-valued run appears before a smaller-valued run in the sequence of compressed runs (where consecutive equal values are merged). After sorting these runs by value ascending, the total inversions of moves can be computed using a Fenwick tree over values (1..N). Answer = (#deletions) + (#inversions).
