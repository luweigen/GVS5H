To find the shortest palindrome having S as a prefix, we need the longest suffix of S that is already a palindrome. Append to S the reverse of the prefix that does not belong to this palindromic suffix. Compute the longest palindromic suffix using string matching: create a string `T = S + '#' + reverse(S)` and run KMP to get the prefix function array; the last value gives the length of the longest prefix of S that is also a suffix of reverse(S), which corresponds to the longest palindromic suffix of S. Then construct the answer as `S + reverse(S[: n - l])`. The algorithm runs in O(N) time and O(N) memory, suitable for N up to 500,000.
