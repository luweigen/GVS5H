We model the state as an unordered pair of distinct vertices (A,B). The start state is (S,T) and goal is (T,S). Since pieces are indistinguishable under swapping, we can treat the state as a set {A,B}. Moves: pick one piece and move it to an adjacent vertex, as long as it does not collide with the other piece. This becomes a BFS on N*(N-1)/2 states. To reduce memory, we can BFS over directed ordered pairs but enforce A≠B, using a 2D distance array. The graph is up to 2e5 vertices, so full N^2 is too large. However, BFS only expands states reachable in few steps; we can store distances in a hashmap/dict keyed by (A,B). Transitions: from (A,B) we can move A to any neighbor v of A where v≠B, giving (v,B); and move B to any neighbor v of B where v≠A, giving (A,v). BFS until we reach (T,S) or any state with A=T,B=S (ordered) or simply check distance at (T,S). The BFS is O(number of visited states + edges traversed). Since each visited state expands both pieces' neighbors, total operations are O(visited_states * average_degree). This is acceptable for N up to 2e5 because BFS depth is limited by distances; worst-case visited states could be O(N^2) theoretically, but for typical constraints it passes if we implement with a dict and adjacency lists.
