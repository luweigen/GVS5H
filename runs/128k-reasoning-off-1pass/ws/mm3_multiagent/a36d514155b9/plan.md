We need the sum, over all subsets of size k from an m×n grid, of pairwise Manhattan distances. By linearity, sum_{pairs} expected Manhattan distance × C(N-2, k-2) total arrangements (choose remaining k-2 cells from N-2). Manhattan = |x_i - x_j| + |y_i - y_j|, so we can handle rows and columns independently. For each row r and row s, count cells in each, multiply by |r-s|, sum over all row pairs; same for columns. Multiply each by C(N-2, k-2) and by k*(k-1) (since sum over pairs = k(k-1) times average). Actually cleaner: total = (k*(k-1)) * C(N-2, k-2) * (row_contrib + col_contrib) mod M. row_contrib = Σ_{i<j} c_i c_j (j-i), where c_r = n (cells in row r). This reduces to O(m+n) via prefix sums: for each row with value v=n, contribution = v * (i*cum - prefix_sum). Similarly for columns. Precompute factorials up to N=10^5 for binomial. Final answer mod 1e9+7.
