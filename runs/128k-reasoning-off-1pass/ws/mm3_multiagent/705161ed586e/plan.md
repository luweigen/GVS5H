We need to transform a string into one where every maximal run of the same character has length ≥ 3, using ±1 character changes, minimizing total cost (operations) and breaking ties by smallest lexicographic result. This is a DP problem over positions: for each position, consider all possible target characters (any of the 26 letters reachable from the original within the allowed ±1 step chain, but we can keep state simply as the target character). State: dp[i][c] = min cost to transform prefix of length i into a good string ending with a run of character c of length k (1, 2, or ≥3). Transition: append c at position i with cost |original[i] - c|, update run length. For lexicographic tie-breaking, we store the actual resulting string (or reconstruct later) and pick smallest. To reduce states, we only need to consider characters that are either the original or neighbors (since moving further gives higher cost and is dominated when better solutions exist nearby). However, to be safe and correct, we can consider all 26 letters; n ≤ 5e4, so 26*3*26 ≈ 2000 states, transitions O(26*26) per position = O(26²·n) ≈ 3.4e7 which is acceptable. We keep for each state the (cost, string) pair, pruning by cost and lexicographic order. At the end, pick best state where run length ≥ 3, else empty string.
