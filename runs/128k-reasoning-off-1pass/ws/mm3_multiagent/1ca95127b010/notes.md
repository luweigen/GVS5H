
## ideation
The problem asks whether two binary strings S and T can be made identical by repeatedly swapping adjacent blocks of X zeros and Y ones (Operation A) or Y ones and X zeros (Operation B). The key observation is that the rewriting rule `0^X 1^Y -> 1^Y 0^X` (and its reverse) is confluent and terminating. Thus, each connected component of the state graph has a unique normal form that can be obtained by repeatedly applying Operation A until no `0^X 1^Y` pattern remains. If S and T reduce to the same normal form, they are reachable; otherwise, they are not.

To compute the normal form efficiently for N up to 5e5, we operate on the run-length encoding of the string. We represent the string as a doubly linked list of runs (type, length). We repeatedly find a zero-run of length ≥ X immediately followed by a one-run of length ≥ Y, apply the operation (which splits the runs and merges adjacent same-type runs), and continue. The process terminates because the sum of positions of 1s strictly decreases. The number of operations is O(N), so an O(N) simulation using a linked list is feasible.
