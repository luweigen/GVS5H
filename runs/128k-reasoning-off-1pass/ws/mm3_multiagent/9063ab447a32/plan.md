We need to maximize total count ∑k_i subject to ∑k_i^2·P_i ≤ M, with k_i non‑negative integers. Sort P_i increasingly. The function f(t)=⌊√(M/t)⌋ is a cheap upper bound on sum of k_i if we could split cost per unit linearly. We'll binary search answer X. For a given X, we need to check if we can pick k_i ≥ 0 integers with ∑k_i = X and ∑k_i^2·P_i ≤ M. Greedy: assign k_i = min(X, ⌊√(M/P_i)⌋) to the cheapest products first, then reduce if total exceeds X. This works because for a fixed number of items, the minimum sum of k_i^2 is achieved by making the k_i's as equal as possible. The check is O(N) per mid, binary search needs ≤ 60 iterations (N up to 2e5, M up to 1e18 → X up to ~1e14). Overall O(N log M).
