We need to find a downward (root-to-descendant) path where all node values are unique, maximizing total edge length sum. We perform DFS from root 0, maintaining a stack of current path segments. For each node, we must trim the path from its left until the value of current node hasn't appeared in the current path (since duplicates break uniqueness). Because it's a tree rooted at 0, "downward" means following parent→child direction; we simply traverse using parent tracking. While walking, for each node we can compute the longest valid path ending at this node: its total length = sum of lengths along trimmed path. Keep a global maximum length and among those paths the minimum number of nodes. Use a position map (value → index in stack) to quickly know how far to trim.
