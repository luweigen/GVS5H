We need for each index i the maximum GCD achievable by selecting K elements that include A_i. The key observation: the GCD of K numbers is some divisor d of A_i, and the set must contain at least K-1 other numbers all divisible by d. So the answer for i is the largest divisor d of A_i such that the count of numbers in A divisible by d is at least K. We can precompute, for every value v from 1 to maxA, how many A_j are divisible by v using a frequency array and a multiple-counting pass (like a sieve). Then for each A_i we factor it (or enumerate its divisors) and pick the largest divisor d with count[d] >= K. Since maxA ≤ 1e6, this is fast. Complexity is O(maxA log maxA + N * d(A_i)) where d(A_i) is the number of divisors (≤ ~240 for 1e6), well within limits. Use fast I/O.
