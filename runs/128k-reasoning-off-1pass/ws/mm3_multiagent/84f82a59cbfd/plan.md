The problem requires finding the largest integer N ≤ A such that N has exactly 2 distinct prime factors p and q, and both p and q appear with even exponent in N. Equivalently, N = p^(2a) * q^(2b) for distinct primes p,q and positive integers a,b. We can precompute all such numbers up to 10^12, then answer each query by binary searching this sorted list. Generating all numbers: iterate over all squares of primes p² up to 10^12, and for each p², multiply by q² for all distinct primes q > p such that p²·q² ≤ 10^12. Sorting and binary search gives O(log N) per query. With Q up to 2·10^5 this is well within limits.
