The number of good arrays can be computed by choosing which `k` adjacent positions (out of `n-1`) are equal, then assigning values to the resulting groups. There are `n-k` groups (segments between equalities) of consecutive equal elements. The first group can take any of `m` values, and each subsequent group can take any of `m-1` values (any value except the previous group's value to maintain the non-equal condition). So the answer is `C(n-1, k) * m * (m-1)^(n-k-1)` mod `10^9+7`. We'll precompute factorials and inverse factorials up to `n` to compute combinations efficiently with Fermat's little theorem, then use fast modular exponentiation for the power term.
