We need to count the number of arithmetic progressions of length 3 (A, B, C) with A < B < C from a set S of N distinct positive integers (1 ≤ S_i ≤ 10^6). This is equivalent to counting pairs (A, C) in S with A < C and A + C = 2B for each B in S. We can solve this efficiently using a convolution (FFT). We represent the set S as a binary array f where f[x] = 1 if x ∈ S else 0. The convolution g = f * f gives g[k] = number of ordered pairs (a, b) in S with a + b = k. For any B in S, the number of valid pairs (A, C) with A < C and A + C = 2B is (g[2B] - 1) // 2. Summing this over all B in S gives the answer. Since max(S) ≤ 10^6, the FFT size is about 2^21, which is fast in Python with numpy.
