We need to generate the k-th lexicographically smallest alternating permutation of [1..n] (or report none). Because k can be up to 1e15, we cannot enumerate. The key is to precompute DP counts of how many ways the remaining unused numbers (split by parity) can be placed to satisfy the alternation constraint. Let a = number of remaining odds, b = number of remaining evens. Let dp[a][b][lastParity] be the number of valid completions (0/1 for odd/even) given the last placed number's parity. The DP is O(n^2) and easily fits (n ≤ 100). Then we construct the answer greedily: at each position i, we try unused numbers in increasing order; for each candidate x we compute remaining a,b, lastParity (first position has no constraint), and skip if parity matches lastParity. The number of completions after picking x is dp[a][b][parity(x)]. Subtract from k; if k ≤ count we fix that number and continue; else subtract and try the next. If we finish all positions we have a valid permutation. If k exceeds total at any branch we finally return [].
