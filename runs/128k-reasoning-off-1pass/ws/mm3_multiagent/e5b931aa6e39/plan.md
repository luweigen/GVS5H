We need to find positive integers x>y such that x^3 - y^3 = N, with N up to 1e18. The identity (x-y)(x^2+xy+y^2)=N suggests iterating over possible differences d = x - y, since d divides N and grows slowly. For each divisor d of N, solve the cubic equation x^3 - (x-d)^3 = N, which simplifies to 3dx^2 - 3d^2 x + d^3 = N. Solving for x gives a quadratic: 3d x^2 - 3d^2 x + (d^3 - N) = 0. We can iterate d from 1 upward while 3d^3 <= N (since x > d, so x^3 - (x-d)^3 >= 3d^3). For each d dividing N, compute discriminant D = 9d^4 - 12d(d^3 - N) = 9d^4 - 12d^4 + 12dN = 12dN - 3d^4 = 3d(4N - d^3). Check if D is a perfect square, then compute x = (3d^2 + sqrt(D)) / (6d). If x is integer and y = x - d > 0, output (x, y). If no solution found, output -1.
