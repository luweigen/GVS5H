The problem is the classic edit distance (Levenshtein distance) decision version: we must decide whether the edit distance between strings S and T is at most K (K ≤ 20). Since |S|,|T| ≤ 5·10^5, a full O(|S|·|T|) DP is impossible. However K is tiny, so we can use the classic "bounded edit distance" DP limited to a band of width 2K+1 around the diagonal. We compute DP[i][j] for the minimal edit distance using only states where |i-j| ≤ K, using rolling arrays for memory. This is O(K·min(|S|,|T|)) which is ≤ ~10^7, easily fast enough.
