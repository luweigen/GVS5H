We need to partition the array into `k` non-overlapping subarrays of length `x` and choose a target value for each subarray (any integer, not necessarily present) so the sum of absolute differences to that target is minimized. For a fixed starting index `i` of a length-`x` subarray, the optimal target is the median of `nums[i..i+x-1]` and the cost is the sum of absolute deviations to the median. We can precompute these costs for all windows using a sliding-window median with two multisets (small/large) that store elements with their indices; the median and total deviation updates are O(log x) amortized per step, giving O(n log x) overall.

To choose `k` non-overlapping windows, we use DP over the array: `dp[t][i]` = min cost to place `t` subarrays ending at or before position `i`. Transitions consider placing the `t`-th subarray starting at `j = i-x+1`, with cost `cost[j]` precomputed. We keep a running minimum of `dp[t-1][j-1] + cost[j]` as we slide. Complexity: O(k·n) which is fine since `k ≤ 15` and `n ≤ 10^5`.
