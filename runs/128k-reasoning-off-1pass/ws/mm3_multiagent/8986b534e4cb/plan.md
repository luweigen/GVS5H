We model each person as an interval on the line of indices (0 to N-1). The condition for a set of people to be feasible reduces to acyclicity of a directed graph G on the left endpoints L of the intervals. For each L, we compute MF(L) as the maximum right endpoint of forward intervals starting at L, and MB(L) as the maximum right endpoint of backward intervals starting at L. There is a directed edge from L1 to L2 if and only if L1 < MB(L2) and L2 < MF(L1). The set of people is feasible iff G is acyclic. We need to answer Q range queries, each asking if G is acyclic for the people in [L,R]. We can preprocess the people into a segment tree where each node stores a map from L to (MF, MB) for the people in that segment. For a query, we merge the maps from O(log M) segment tree nodes to get the full set of L's and their MF, MB values. Then we need to check if the resulting graph G is acyclic. We can check acyclicity by attempting a topological sort on G. Since the number of nodes (L's) in a query can be up to O(M), we need to build G efficiently. We can build G by, for each L1 in the map, finding all L2 in the map such that L2 < MF(L1) and MB(L2) > L1. We can precompute for each L2 its MB(L2), and then for each L1, we can query a segment tree over the L's to find those L2 that satisfy the conditions. However, this might be O(M^2) in the worst case. We can use the fact that the graph is defined by intervals, and we can check for cycles by looking for a sequence of L's that forms a cycle.
