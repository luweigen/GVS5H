We need to count connected components where edges exist when lcm of two numbers ≤ threshold. The threshold is at most 2*10^5, which is small compared to nums values (up to 10^9). The key insight: if a number exceeds the threshold, it can only be connected to other numbers > threshold if their lcm ≤ threshold — but lcm of two numbers each > threshold is > threshold, so such numbers are isolated. For numbers ≤ threshold, edges depend on lcm ≤ threshold. We can use Union-Find (DSU) to merge pairs efficiently. For each number ≤ threshold, we can iterate over its multiples up to threshold and check if that multiple exists in a hash map. If yes, union the two indices. Finally count distinct DSU roots. For numbers > threshold, they are never united with anything (isolated components).
