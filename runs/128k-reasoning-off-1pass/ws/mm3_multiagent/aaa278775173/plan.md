We need to find the longest V-shaped diagonal path in a grid of 0/1/2 values. The path must start at a cell with value 1, then follow the repeating pattern 2,0,2,0,... while moving along one of the four diagonal directions. At most one clockwise 90° turn is allowed, and the turn must be to another diagonal direction (preserving the 2,0 pattern). We will iterate over every cell that contains 1 as a possible start, and over all four initial diagonal directions, then perform DFS/DP with memoization. The state is (row, col, direction_index, turn_used, step_index), where step_index tells which value (2 or 0) is expected next. The answer is the maximum length over all valid paths. We can implement this recursively with memoization or iteratively using BFS, but recursion with memoization is simpler and efficient for n,m ≤ 500.
