Model each box as a state (r,b) with r,b ∈ {0,1}. The operation on i sends red to P_i, blue to Q_i. Since values are only 0/1, each ball moves deterministically along a cycle in the combined permutation over the 2N-dimensional state space. The goal is to empty all boxes except X, i.e., we need to bring all balls to box X. A box can be emptied only if every ball that ever lands in it can be forwarded without ever being “stuck” (i.e., when we operate on a box, the balls in hand are exactly those currently in the box). This is possible iff box X is reachable from every other box following the deterministic forward map, and additionally each box we need to empty must never receive a ball after it has been operated on (equivalently, we must process boxes in reverse reachability order). We can check reachability via inverse permutation; the set of boxes that eventually flow into X is S = {v : following inverse edges from X reaches v}. All balls initially in S must end at X, which is possible. For each box in S \ {X}, the operation can be performed exactly once, in the order of a topological sort of the reverse reachability DAG. The answer is the size of S minus 1, or 0 if S is empty. If any ball starts outside S, it's impossible => -1.
