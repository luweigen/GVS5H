We model the problem as a directed graph on 26 letters, where an edge `x -> y` exists if there is some position `i` where `S[i]=x` and `T[i]=y`. Performing an operation (replace all `x` with `y`) effectively "merges" the node `x` into `y`. A valid sequence exists iff this graph has no directed cycle (otherwise some letter would need to become something that must become it back, impossible). The minimum number of operations equals the number of connected components in the graph (considering nodes that actually appear in `S` or are targets) that need to be merged, which is `total_edges - cycles_removed`. A simpler counting: let `cnt` be the number of distinct letters in `S` that have at least one outgoing edge (i.e., appear on the left side). If the graph is a DAG, answer = number of nodes that appear in `S` minus number of connected components among them. The standard solution: count the number of distinct source letters `src` (letters appearing in S that are mapped to something). Also count the number of edges. In a DAG, minimum operations = `src - (number of strongly connected components)`. Since each SCC in this graph is at most size 1 (no multi-edges from same source to different targets, and no cycles), actually we can use a simpler approach: the answer is the number of distinct letters in `S` minus the number of letters that are not mapped from any source but are only targets, or more precisely: build adjacency, run DFS to detect cycles. If a cycle exists, output `-1`. Otherwise, answer = number of distinct source letters minus number of source letters that already map to themselves (self-loops that don't need operation). This matches the well-known Codeforces problem solution.

We will implement: collect all pairs (S[i], T[i]) where S[i] != T[i]. Build adjacency list for those. Detect cycle via DFS on 26 nodes (only those with edges). If cycle found → -1. Otherwise, answer = number of unique source letters (those with at least one edge). This is because each source letter needs exactly one operation (merge it into its target), and we can process them in topological order.
