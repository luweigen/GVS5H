We compute the bottleneck distance f(x,y) between any two vertices as the maximum edge weight on the path between them in a minimum spanning tree (MST). This is done by constructing a Kruskal tree: sort edges by weight, and when merging two components with an edge of weight w, create a new node with weight w and make it the parent of the two component roots. The resulting tree (a binary tree with 2N-1 nodes) has the property that the weight of the lowest common ancestor (LCA) of two original vertices equals f(x,y). The problem then becomes matching K vertices of type A with K vertices of type B on this tree to minimize the sum of LCA weights. We solve this with a greedy DP: for each node, match as many surplus A's and B's from different child subtrees as possible, each pair contributing cost equal to the node's weight; the remaining surplus is propagated upward. The total cost is the sum over all internal nodes of (node weight) × (number of pairs matched at that node). The algorithm runs in O((N+M) log N) time and O(N) memory.
