The problem reduces to finding the maximum number of disjoint pairs (a, b) from the sorted array such that for each pair a ≤ b/2. Since the array is sorted, we can use a two-pointer greedy: keep a left pointer `i` for the smaller mochi and a right pointer `j` for the larger mochi. We try to pair the smallest available mochi with the smallest mochi on the right side that can hold it. Move `i` forward when paired; otherwise advance `j` to find a valid larger partner. The count of successful pairs is the answer.
