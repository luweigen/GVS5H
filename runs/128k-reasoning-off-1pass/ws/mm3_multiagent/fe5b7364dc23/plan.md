We need to compute \(S = \sum_{1 \le l \le r \le N} (\sum_{i=l}^r A_i)^K\) modulo \(M = 998244353\), where \(K \le 10\) and \(N \le 2 \times 10^5\). Expanding the K-th power using the multinomial theorem gives \((\sum_{i=l}^r A_i)^K = K! \sum_{j_1 + \dots + j_N = K} \prod_i \frac{A_i^{j_i}}{j_i!}\) where only indices inside \([l,r]\) appear. By swapping sums, the contribution of a fixed tuple \((j_1, \dots, j_N)\) becomes \(K! \prod_i \frac{A_i^{j_i}}{j_i!}\) multiplied by the number of intervals \([l,r]\) where all positions with \(j_i>0\) are inside the interval. For a sorted list of positions with nonzero \(j_i\), the number of intervals covering all of them is \(\text{pos}_1 \times (N - \text{pos}_t + 1)\). However, directly enumerating all \((j_1,\dots,j_N)\) with sum \(K\) is exponential. Instead, we use a DP over prefix: let \(dp[i]\) be the sum over all intervals ending at or before \(i\) of the K-th power of the sum. But a more efficient standard technique for this problem is to use generating functions and treat it as a combinatorial sum over "blocks".

Actually, a known O(N*K) solution exists: Process the array while maintaining for each \(k = 0 \dots K\) a value \(F_k\) which represents the sum of K-th powers of sums of all subarrays that end at the current position. The transition is derived from \((\text{prev} + A_i)^K = \sum_{k=0}^K \binom{K}{k} A_i^{K-k} (\text{prev})^k\), but since we want sums over all subarrays ending at \(i\), we need to accumulate contributions. A simpler approach: let \(S_i = A_1 + \dots + A_i\). Then the sum of K-th powers over all subarrays is \(\sum_{l \le r} (S_r - S_{l-1})^K\). This is exactly the sum over all pairs \((l-1, r)\) with \(0 \le l-1 < r \le N\) of \((S_r - S_{l-1})^K\). Let \(B_0 = 0, B_1 = S_1, \dots, B_N = S_N\). We need \(\sum_{0 \le i < j \le N} (B_j - B_i)^K\). This looks like a convolution-like problem. Expanding \((B_j - B_i)^K = \sum_{t=0}^K \binom{K}{t} B_j^t (-B_i)^{K-t}\). Then \(\sum_{i<j} (B_j - B_i)^K = \sum_{t=0}^K \binom{K}{t} (-1)^{K-t} \sum_{j=0}^N B_j^t \sum_{i=0}^{j-1} B_i^{K-t}\). This can be computed in O(N*K) by maintaining prefix sums of powers of \(B_i\). Specifically, for each \(t\) from 0 to K, we can sweep \(j\) from 0 to N, keeping a running sum of \(B_j^{K-t}\) up to \(j-1\). Complexity O(N*K). Since K ≤ 10, this is fast enough for N=2e5.

We precompute powers of B up to K, binomial coefficients mod M, and accumulate the answer.
