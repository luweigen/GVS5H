
## ideation
The problem is a reachability problem on a line with obstacles (bad squares) and bounded jumps. N can be up to 10^12, but A,B ≤ 20 and M ≤ 20000. The key observation is that we only need to keep track of reachable positions within a window of size B at the right end of each good interval (the "tail"), because only those positions can be used to cross the next bad interval. The size of this tail is at most B. We process good intervals left-to-right, maintaining a set of reachable positions in the current tail. For each good interval, we compute the entry positions reachable in one jump from the previous tail, then determine which positions in the new tail are reachable by checking if the distance from some entry point is representable as a sum of numbers in [A,B] (allowing 0 for the same position). We precompute a table of representable distances up to 5000 using BFS to handle large distances in O(1) time. The final step checks if N is reachable from the last good interval's entry points. If at any step the set becomes empty, we output "No". The overall complexity is O(M·B²) which is efficient for the constraints.
