We need to maximize the shortest distance from 1 to N by setting exactly K edges' weights to 1, others 0. This is a classic path‑blocking problem solvable with binary search on the answer L: can we force all paths from 1 to N to have length at least L? For a fixed L, we need to select a set S of edges (size ≤ K) such that every path from 1 to N uses at least L edges from S. Equivalently, we check whether the minimum number of edges we must select to hit all 1‑N paths is ≤ K. This is a minimum s‑t cut problem in a derived graph: duplicate each vertex v into two layers (v_in, v_out) with an edge v_in→v_out of capacity 1, and for each original edge u→v add an infinite‑capacity edge u_out→v_in. The min cut between 1_out and N_in gives the minimum number of original edges whose removal (weight 0) disconnects 1 from N. Since we can only set K edges to 1 (i.e., we may make them unusable for 0‑weight paths), we need that this min cut value ≤ K, which means we can choose those cut edges to have weight 1, and the rest weight 0, making the shortest distance at least L. We binary search L from 0 to M.

Because N ≤ 30, M ≤ 100, we can safely run max‑flow (Dinic) for each check.
