We will solve the problem by iterating over each possible middle index `i` (from 2 to n-3) and counting the number of valid left and right pairs that make the middle element the unique mode. For a fixed middle, the condition is that the non-middle elements among the four side picks must all be distinct, and the middle must appear at least twice. We precompute value frequencies and maintain prefix counts. For each middle, we use a generating function approach: for each other value `v`, its left count `L_v` and right count `R_v` contribute a factor `(1 + L_v x + R_v y)` to a polynomial whose coefficients count the number of ways to pick disjoint sets of non-middle values on the left and right. We only need coefficients up to x^2 y^2, so the polynomial is a 3x3 array updated in O(1) per value. Then we combine with binomial choices for the middle values on each side, excluding the case where no middle is picked on the sides. The overall complexity is O(n * V) where V is the number of distinct values (≤ n ≤ 1000), which is efficient.
