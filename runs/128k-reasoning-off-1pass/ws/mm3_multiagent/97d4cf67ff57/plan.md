We need to find the largest subtree (connected subgraph) of a given tree that is a tree where all internal vertices have degree 4 and leaves have degree 1, with at least one internal vertex. This is a classic "degree-constrained subtree" problem. We can root the tree at an arbitrary node (say 1) and run a DP where each node returns three values: the best size of a valid alkane fully inside its subtree that is connected and includes the node as the "closest to parent" endpoint, considering the node can be a leaf (status 0), an internal node connecting to up to 3 child branches plus possibly the parent (status 1 internal, status 2 leaf at top). We combine the best 3 child sub‑branches for the internal case. Then the answer is the maximum over all DP states across all nodes. Complexity O(N).
