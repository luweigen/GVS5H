We need to simulate inserting numbers 1..N into an array at given positions P_i, where after each insertion the array length grows. A naive O(N²) simulation is too slow for N up to 5e5. We can model the array as a linked list via a Fenwick tree (Binary Indexed Tree) that tracks which slots are still empty. For each insertion in reverse order (i = N down to 1), we find the P_i-th empty slot from the left and place number i there. This works because when we insert in reverse, each number i only needs to claim an empty position; the relative order of already placed numbers is preserved. After all numbers are placed, we output the final array.
