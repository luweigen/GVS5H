We need to select up to 4 non-overlapping intervals to maximize total weight, and return the lexicographically smallest index set achieving that max. Constraints: up to 5e4 intervals, coordinates up to 1e9. We'll use DP over sorted intervals with a segment tree / Fenwick to find for each interval the best previous solution of size 0..3 that ends before its start. Since lexicographic order of the index sets is the tie-breaker, we represent each state as a tuple `(score, indices_tuple)` and compare using (score descending, then lexicographic ascending on indices). We'll maintain for each count k a map from position to best state (by that ordering) and use a Fenwick tree to query the global best for each k among positions < l_i. The per-interval DP: for k=1..4, new state = (prev[k-1].score + w_i, sorted tuple of prev[k-1].indices + [i]). Then we update the position r_i with this new state, and for each count keep the best state at that position (by the same comparison). Complexity O(N log N) with K=4. Return the best state among all counts (0..4) by score, then lex order.
