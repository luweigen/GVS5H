Use the property that we can place values from largest to smallest. For each value `v` from `N` down to `1`, we find its current position in the "compressed" array (after larger values are placed) using a Fenwick tree, then add the cost of moving it to its target position `v`. The cost is the sum of indices of adjacent swaps required: `sum_{k=min(cur,v)}^{max(cur,v)-1} k`. Mark the original position as removed and continue. Total time O(N log N).
