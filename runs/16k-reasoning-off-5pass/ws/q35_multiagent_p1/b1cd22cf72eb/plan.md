The problem requires minimizing the total reduction in tooth lengths such that $U_i + D_i = H$ for all $i$, and $|U_i - U_{i+1}| \le X$. Since we can only reduce lengths, let the final upper teeth be $U'_i$ and lower teeth be $D'_i$. Then $U'_i + D'_i = H$, so $D'_i = H - U'_i$. The cost is $\sum (U_i - U'_i) + \sum (D_i - D'_i) = \sum (U_i + D_i) - \sum (H) = \sum (U_i + D_i) - N \cdot H$. To minimize cost, we must maximize $H$. However, $H$ is not free; it is constrained by the conditions on $U'$. Specifically, $U'_i \le U_i$, $D'_i \le D_i \implies H - U'_i \le D_i \implies U'_i \ge H - D_i$. Also $U'_i \ge 0$. So for a fixed $H$, we need to find if there exists a sequence $U'_1, \dots, U'_N$ such that:
1. $\max(0, H - D_i) \le U'_i \le U_i$ for all $i$.
2. $|U'_i - U'_{i+1}| \le X$ for all $i$.

If such a sequence exists, the cost is $\sum (U_i + D_i) - N \cdot H$. We want the maximum $H$ for which this is possible. The constraints on $U'_i$ define an interval $[L_i(H), R_i(H)]$ where $L_i(H) = \max(0, H - D_i)$ and $R_i(H) = U_i$. The condition $|U'_i - U'_{i+1}| \le X$ means we can propagate feasible intervals. We can check if a valid sequence exists for a given $H$ using a greedy interval propagation: maintain the feasible range $[cur\_min, cur\_max]$ for $U'_i$ as we iterate from $i=1$ to $N$. For each $i$, the feasible range intersected with $[L_i(H), R_i(H)]$ must be non-empty, and the next step's range is derived from expanding the current feasible range by $X$ in both directions. Since the cost decreases as $H$ increases, we can binary search on $H$. The range of $H$ is from $0$ to $2 \cdot 10^9$.
