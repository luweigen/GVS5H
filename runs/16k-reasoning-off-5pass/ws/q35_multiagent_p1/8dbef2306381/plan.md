The problem asks if we can reach square N from square 1 by jumping between A and B, avoiding "bad" squares. Since N is up to $10^{12}$, we cannot simulate all squares. However, M is small ($2 \times 10^4$) and the jump range [A, B] is very small (up to 20). The bad squares are given as disjoint intervals. We can model this as a reachability problem on a graph where nodes are squares. The key insight is that we only need to consider "critical" points: the start (1), the end (N), and the boundaries of the bad intervals. Between any two critical points, the reachability pattern repeats or can be determined by checking if the entire segment is free of bad squares. Specifically, we can use dynamic programming or BFS on the critical points. For each critical point, we determine the set of reachable previous critical points. Since the jump size is small, from a square $x$, we can reach any $y \in [x+A, x+B]$ that is not bad. We can process intervals of good squares. If a contiguous segment of good squares has length at least B, then within that segment, almost all positions are mutually reachable (specifically, if you can enter the segment, you can traverse it). We can compress the state space to the endpoints of the bad intervals and the start/end. Let's collect all interesting coordinates: 1, N, and for each bad interval $[L_i, R_i]$, the points $L_i$ and $R_i+1$. Sort these unique points. These points divide the line into segments. We can determine reachability between these segments.
