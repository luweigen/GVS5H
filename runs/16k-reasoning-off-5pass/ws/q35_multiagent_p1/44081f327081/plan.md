1. For each possible GCD value `g` (from 1 to 10^6), we want to know which indices `i` can achieve GCD `g` when `A_i` is included in a subset of size K.
2. First, for each value `v` present in A, count its occurrences. Then, for each candidate GCD `g`, collect all elements in A that are multiples of `g`. If there are at least K such elements, then any element among them can potentially be part of a subset with GCD divisible by `g`.
3. However, we need the maximum GCD for each `A_i`. We can iterate `g` from max possible down to 1. For each `g`, find all indices `i` where `A_i` is a multiple of `g` and there are at least K multiples of `g` in A. Among these, if `A_i` hasn't been assigned an answer yet, assign `g` as the answer for `A_i` (since we're iterating from large to small, the first `g` that works is the maximum).
4. To efficiently find multiples of `g`, precompute for each `g` the list of indices where `A_i` is a multiple of `g`. This can be done by iterating over each `A_i` and adding index `i` to all divisors of `A_i`.
5. For each `g`, count how many elements in A are multiples of `g`. If count >= K, then for each index `i` where `A_i` is a multiple of `g` and answer[i] is not yet set, set answer[i] = g.
