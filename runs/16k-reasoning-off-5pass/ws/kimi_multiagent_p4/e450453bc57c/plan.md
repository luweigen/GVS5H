For any fixed window of length x, the minimum cost to make all elements equal is achieved by bringing every element to the window's median, computable in O(x) or better via sorting/selection. Since subarrays must be non-overlapping, this becomes an interval-scheduling DP: choose at least k disjoint length-x windows minimizing total cost. Define dp[i][j] = min cost using the first i elements to form j subarrays, with transition dp[i][j] = min(dp[i-1][j], dp[i-x][j-1] + cost[i-x..i-1]). Because k ≤ 15, the DP is O(n·k) provided window costs are computed efficiently. Compute all window costs in O(n·x) total (or O(n log x) with two heaps), then run the DP with rolling arrays.
