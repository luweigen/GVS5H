Binary search on the answer L (minimum achievable longest run length). For a candidate L, compute the minimum flips needed so that no run of identical characters exceeds L, then check if it's ≤ numOps. Key insight: for L ≥ 2, each maximal run of length `len` independently needs `len // (L+1)` flips (placing flipped characters as dividers), and runs are independent since flipping inside a run never merges two same-char runs. For L = 1, the string must be alternating, so compute mismatches to both alternating patterns and take the minimum. Binary search range is [1, n].
