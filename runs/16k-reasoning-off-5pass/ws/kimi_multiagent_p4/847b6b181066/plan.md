Track the set of smoke positions as offsets relative to the cumulative wind displacement: after t wind steps with total displacement D_t, a smoke particle born at time k (at origin) sits at D_t - D_k. Cell (R,C) has smoke at time t+0.5 iff R+C equals D_t - D_k for some birth time k in the valid set (k=0 plus all times where origin was empty after the wind move). Maintain a hash set of the values D_k (as coordinate pairs) for all born particles, and detect when origin is empty by checking whether -D_t (i.e., the particle that would be at origin) corresponds to any existing birth offset. Each step is O(1), giving O(N) total.
