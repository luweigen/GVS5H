We need to find the minimum cost to reduce tooth lengths such that all pairs sum to a constant $H$ and adjacent upper teeth differ by at most $X$. Since we can only decrease lengths, for a fixed target sum $H$, the final upper length $u_i$ must satisfy $u_i \le U_i$ and $H - u_i \le D_i$, which implies $u_i \ge H - D_i$. Thus, for a fixed $H$, we need to find a sequence $u_i$ maximizing the sum $\sum u_i$ (to minimize cost) subject to $\max(0, H - D_i) \le u_i \le U_i$ and $|u_i - u_{i+1}| \le X$. This is a convex optimization problem solvable in $O(N)$ using isotonic regression or a "pool adjacent violators" style algorithm (specifically, the solution is the greatest sequence satisfying the constraints, which can be found via a variant of the "taut string" or "slope trick" algorithm). Since the cost function is convex in $H$, we can use ternary search over the integer range of $H$ to find the global minimum.
