- **Key insight (from plan, corrected):** For a fixed target sum $H$, final upper lengths $u_i$ must satisfy $\max(0, H-D_i) \le u_i \le \min(U_i, H)$ (the $u_i \le H$ bound comes from the lower tooth being nonnegative) plus $|u_i - u_{i+1}| \le X$.
- The feasible set for fixed $H$ is closed under componentwise max (max of two $X$-Lipschitz sequences is $X$-Lipschitz), so a greatest element exists; it maximizes every coordinate simultaneously. It is computed as $g_i = \min_j (R_j + X|i-j|)$ via one forward pass ($g_i = \min(R_i, g_{i-1}+X)$) and one backward pass ($g_i = \min(g_i, g_{i+1}+X)$). Feasibility for $H$ is exactly $g_i \ge H - D_i$ for all $i$ (any feasible sequence is componentwise $\le g$).
- **Cost telescoping:** using $u = g$, $d = H - g$, total cost $= \sum(U_i - g_i) + \sum(D_i - (H - g_i)) = \sum(U_i + D_i) - NH$, independent of $g$. So minimizing cost = maximizing feasible $H$.
- **Monotonicity:** if $H$ is feasible and $H' \le H$, then $\min(g(H), H')$ is feasible for $H'$ (it's $\le \min(U_i, H')$, Lipschitz, and $\ge \min(H - D_i, H') \ge H' - D_i$), so $g(H')$ dominates it and is feasible. Hence binary search over $H \in [0, 2\times10^9]$ works.
