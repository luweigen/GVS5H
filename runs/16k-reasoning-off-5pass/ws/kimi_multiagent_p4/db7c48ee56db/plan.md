The key constraint is C(N,K) ≤ 10^6, which means either K is small (≤ ~3-4) or N-K is small. Since XOR of K elements equals XOR of all N elements XOR'd with the XOR of the complementary N-K elements, we can choose whichever side is smaller. Enumerate all combinations of the smaller side using itertools.combinations, tracking the maximum XOR. For very small K (like 1 or 2), we can use smarter methods, but brute force over combinations works since C(N,K) ≤ 10^6. To speed up, we can use a meet-in-the-middle or Gaussian elimination approach, but simple enumeration with early termination should suffice given the constraint.
