This is a reachability problem on a line with huge N but small step range (B ≤ 20) and few bad intervals (M ≤ 2·10⁴, disjoint and sorted). The key observation: reachable positions form a set where, within any stretch of good squares, reachability eventually becomes periodic with period 1 once a full window of B consecutive reachable positions exists — after that every good square is reachable. So we process bad intervals one by one, maintaining the set of reachable positions in a sliding window of the last B positions (a bitmask). Between consecutive bad intervals, if the gap of good squares is large enough, the reachable set either dies out (answer No) or becomes "all positions reachable," which we can detect by simulating until the mask stabilizes to a full window. At the end we check whether N is reachable, also handling the case where N itself is unreachable only via the tail segment.
