For each ending position j, count how many starting positions i make the substring s[i..j] divisible by its last digit d = s[j]. If d is '0', no substring ending at j qualifies; if d is non-zero, every single-digit substring qualifies, so we need to count i ≤ j with number(i..j) mod d == 0. Since d ∈ {1..9}, we can maintain the value of the suffix modulo d incrementally: value(i..j) mod d = (value(i..j-1) * 10 + digit) mod d, but recomputing per (i, d) is O(n·9) if we track, for each d, the running remainder of the suffix starting at each i — instead, for each d, iterate i from j downward accumulating the number mod d, which is O(n) per position worst case. Better: for each d in 1..9, process the string once maintaining a counter of prefix remainders; substring (i..j) mod d = (prefix[j] - prefix[i-1] * 10^{len}) mod d, which is messy due to length dependence. The clean O(9n) approach: for each digit d, scan left to right keeping the current suffix remainder r = (r*10 + x) mod d and a frequency map of remainders of all active suffixes — actually simplest correct O(9n): for each d, iterate over positions and for each start compute remainders forward. The intended efficient solution: for each ending j with digit d, iterate i backwards from j, accumulating val = (val + digit_i * pow10) mod d, counting zeros — this is O(n) per j worst case (O(n²)). To stay efficient, note d ≤ 9 so we can afford O(n·9): for each d, do a forward pass where we keep remainders of all suffixes ending at current position by updating a list — that's O(n) per position again. Practical accepted approach: for each j, only need remainders mod d for that j's d; iterate i backwards with early accumulation — total O(n²) worst but n=1e5 needs better. Use the trick: number(i..j) mod d depends on suffix; maintain for each d an array of remainder counts updated in O(1) amortized? Standard solution: for each d 1..9, sweep and maintain cnt of remainders of suffixes: when extending by one char, every suffix remainder r becomes (r*10+x)%d, plus new suffix. Remainders mod d are few (≤9), so we keep a small array of size d and remap it in O(d) per character — total O(n · Σd) = O(45n) = O(n). For each j, answer contribution is count of suffix remainders equal 0 for d = s[j].
