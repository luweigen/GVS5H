This is the classic AtCoder ABC 077 C-like "Kagami Mochi" pairing problem. The key insight is that in an optimal solution, the K smallest mochi used as tops should be paired with the K smallest valid bottoms. A greedy two-pointer approach works: try to match the smallest available top with the smallest available bottom that is at least twice as large. If we can make K pairs this way, then K is achievable. We can either binary search on K with a greedy check, or directly compute the answer with a single greedy pass pairing the smallest half as tops against the larger half as bottoms.
