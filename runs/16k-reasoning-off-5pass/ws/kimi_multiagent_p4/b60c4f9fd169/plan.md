This is a bounded edit distance problem: determine if Levenshtein distance between S and T is at most K (K ≤ 20). Since K is tiny but strings can be 500K long, full DP is too slow; instead use the classic banded DP where we only compute cells with |i-j| ≤ K, since any path exceeding distance K is irrelevant. First handle trivial cases: if |len(S)-len(T)| > K, answer is immediately No. The banded DP runs in O(N*K) time which is about 10^7 operations — feasible in Python with optimization (arrays, minimal overhead), but we should write it carefully using lists and local variable binding. Alternatively, use the Myers bit-parallel algorithm for edit distance with threshold, but banded DP is simpler and sufficient. Edge cases: equal strings (0 operations), and early termination when possible.
