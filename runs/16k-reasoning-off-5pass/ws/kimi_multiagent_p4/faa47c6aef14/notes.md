**Reasoning / proof sketch:**

- Since P and Q are permutations, each color's movement graph is a disjoint union of directed cycles. A red ball at box s (s ≠ X) must eventually leave every non-X box it sits in (the goal requires all non-X boxes empty, and the only way a box empties is by operating it). Operating its current box pushes it along P. Hence the ball forces operations on s, P_s, P²_s, … until it first reaches X, where it may rest (X is allowed to hold balls, and we never need to operate X).
- If s's forward orbit under P never reaches X — i.e., s is not in X's P-cycle (permutation ⇒ every node is in exactly one cycle, no trees) — the ball can never stop, so the goal is impossible → print -1. Same for blue with Q.
- If s is in X's cycle at position p (with X at position 0, order following P), the forced boxes are exactly the cycle nodes at positions p, p+1, …, L−1 (a suffix of the cycle ending just before X). The union over all red sources is the suffix starting at the minimum source position. Same for blue.
- Each forced box must be operated at least once (a ball passes through it and it must end empty). Operating each forced box exactly once suffices: process boxes in order of decreasing distance-to-X along each cycle (equivalently, operate each box when the ball arrives); balls accumulate harmlessly, and operating a box moves both colors simultaneously, which is consistent because each color's forced set is computed independently and the operation serves both. Extra operations on non-forced boxes would only increase the count, so the minimum is |red_forced ∪ blue_forced|.
