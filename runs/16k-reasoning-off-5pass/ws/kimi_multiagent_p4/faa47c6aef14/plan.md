Model the problem as moving indistinguishable balls along two permutation graphs (red along P, blue along Q). Operating on box i clears it and sends its red balls to P_i and blue balls to Q_i; a box must be operated exactly when it (transitively) receives balls, and operating a box twice is never useful. The key insight: the set S of boxes that must be operated is the closure of initially non-X ball locations under inverse edges — i must be operated if it ever holds a ball that must move, which propagates: operating i forces operating P_i (if red passed through) and Q_i (if blue passed through), unless those equal X. This reduces to a reachability/fixpoint computation on the functional graph formed by edges i→P_i and i→Q_i: mark all boxes containing balls not at X, then repeatedly mark preimages... actually forward: if i is operated and i has red-path, P_i must be operated unless P_i=X. Compute minimal set via BFS from initial ball boxes along P/Q edges, skipping X; if any forced operation lands on X while X holds... handle X specially: balls already at X can stay, but if X must be operated (because it received balls that need to move — they don't), X never needs operating. Answer is size of the closure set; impossibility arises if closure requires operating X (i.e., a ball path leads into X from a box that must be cleared but X is fine — actually impossible when P_i or Q_i = X is fine since balls can rest at X). True impossibility: a box i≠X with a ball whose only escape routes cycle without reaching X — but operation always clears i regardless, so it's always possible unless operating i requires operating X. Verify with cycle analysis on the combined graph.
