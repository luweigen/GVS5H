
## ideation
- Core structure: cost per product is convex (k²·P_i), so marginal cost of the j-th unit of product i is (2j−1)·P_i, strictly increasing. Optimal purchase = take globally cheapest marginal costs.
- Equivalent formulation: for a threshold T, product i contributes k_i = max{ j : (2j−1)·P_i ≤ T } = floor((T/P_i + 1)/2) units, with cost k_i²·P_i.
- Approach: binary search on T over [0, ~2·10^27] (max marginal cost relevant: to spend M=10^18 on cheapest product P=1, k ≈ √M ≈ 10^9, so marginal ≈ 2·10^9·... actually k_max ≈ √(M/P_min) ≤ 10^9, marginal ≤ 2·10^9·P_i ≤ 4·10^18; safe upper bound: 2·10^9 · 2·10^9 = 4·10^18, use hi = 4·10^18 or compute dynamically).
- For a given T: total units C(T) = Σ k_i, total cost S(T) = Σ k_i²·P_i. Find largest T with S(T) ≤ M... but careful: answer isn't just C(T) — boundary ties matter. Standard technique: find T* = largest T such that S(T) ≤ M (with strict inequality handling). Then answer = C(T* − 1) + floor((M − S(T*−1)) / T*) where T* is the marginal cost at the boundary. Cleaner: binary search for the threshold T such that S(T) ≤ M but considering units with marginal exactly T: Let k_i(T) count units with marginal ≤ T. Find max T with S(T) ≤ M might overshoot ties. Safer method: find T = smallest value such that C(T) ≥ answer... circular. Best: binary search T where we compute for threshold T (units with marginal cost < T, i.e., ≤ T−1): count C, cost S. Then remaining budget M − S can buy floor((M−S)/T) more units at marginal price T each (those with marginal exactly T), provided S ≤ M. Choose T maximal such that S(T−1) ≤ M... Let me define f(T) = Σ over i of (units with (2j−1)P_i ≤ T) and g(T) = their cost. Binary search the largest T with g(T) ≤ M. Then answer = f(T) + min( (M − g(T)) / (T+1 adjusted)... ) — tricky because next marginal costs are ≥ next odd multiple. Simplest robust method: binary search on answer K directly is hard since cost check needs threshold anyway. Alternative clean method: binary search T (marginal threshold). Compute C = f(T), S = g(T). We want the smallest T such that g(T) > M (infeasible), call it T0. Then set T = T0 − 1: all units with marginal ≤ T are bought (cost S ≤ M), and additional units have marginal cost ≥ T0; but units with marginal exactly T0 cost T0 each, and there are enough of them? Not necessarily enough — but any unit beyond has marginal > T0 costing more, so optimal fills with T0-marginal units first; however if budget remains after exhausting T0 units, we'd need T0+... units, contradicting maximality of T0? Not exactly, because g(T0) > M means buying ALL units with marginal ≤ T0 exceeds M, so there are more T0-marginal units than we can afford — wait, g(T0) > M means cost of all units with marginal ≤ T0 exceeds M. Units with marginal in (T, T0] = exactly T0 (integers). So remaining budget M − S < (number of T0-marginal units)·T0, meaning we can buy floor((M−S)/T0) of them and can't exhaust them. Answer = f(T) + (M − g(T)) // T0. Edge: T0 could be such that no T0-marginal units exist but g jumped — g(T0) > M ≥ g(T0−1) implies at least one unit has marginal exactly T0, fine.
