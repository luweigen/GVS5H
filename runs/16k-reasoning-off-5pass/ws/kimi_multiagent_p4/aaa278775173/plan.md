Model the four diagonal directions in clockwise order so a "clockwise 90° turn" is just moving to direction index (d+1)%4. For each cell and each direction, precompute via DP (processing cells in reverse order along each direction) the length of the longest straight run starting at that cell that matches the expected alternating sequence (2,0,2,0,...), given the value expected at that cell. Then for every cell containing 1 and every starting direction, walk the straight arm; at each position along it (including the start), consider turning clockwise and add the precomputed continuation length from the next cell in the turned direction, taking the maximum. Straight segments with no turn are covered by allowing the turn contribution to be zero. Overall complexity is O(n*m) with four directional DP passes.
