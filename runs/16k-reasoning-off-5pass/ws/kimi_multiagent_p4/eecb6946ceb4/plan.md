A fine triplet is a 3-term arithmetic progression: for each middle element B, count pairs (A, C) in S with A = B - d and C = B + d for some d ≥ 1. Since values are bounded by M = 10^6, we can use a boolean presence array and, for each B, check symmetric offsets. A naive O(N·M) scan is too slow, so we use FFT convolution: the count of pairs summing to 2B is the coefficient of x^(2B) in the convolution of the indicator polynomial with itself, minus the self-pair. Each valid pair (A, C) with A + C = 2B and A ≠ C gives exactly one fine triplet centered at B, so the answer is the sum over B ∈ S of (pairs summing to 2B with both endpoints in S, excluding B itself). Convolution via FFT over size ~2·10^6 is O(M log M), easily fast enough; rounding must be handled carefully.
