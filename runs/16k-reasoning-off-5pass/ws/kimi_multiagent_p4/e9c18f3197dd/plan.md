Since target.length ≤ 4, we can enumerate all subsets of target elements (at most 15 non-empty subsets). For each subset, the cheapest way to cover it with a single nums element is to raise some nums[i] to the least common multiple (LCM) of that subset — cost = ceil(LCM/nums[i])*LCM - nums[i], minimized over all i. Then the answer is the minimum over all partitions of the target set into disjoint subsets of the sum of subset costs (subset DP over masks). LCM values must be capped (e.g., stop if LCM exceeds max(nums)+answer bound) to avoid huge numbers, but since target[i] ≤ 10^4 and subsets have ≤4 elements, LCM fits in 64-bit and we can compute safely with early overflow guards.
