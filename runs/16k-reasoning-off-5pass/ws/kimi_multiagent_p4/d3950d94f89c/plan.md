Root the tree at 0 and run a single DFS that maintains the current root-to-node path as a sliding window with all-unique values. Track, for each value, the last depth/index where it appeared on the current path so we can move the window's left boundary past any duplicate when entering a node. For each node, the best special path ending there is from the current left boundary to that node; compute its length via prefix sums of edge lengths and update the global best (max length, then min node count on ties). Use an explicit stack or recursion with sys.setrecursionlimit, and undo the "last occurrence" updates when backtracking. This is O(n) time and O(n) space.
