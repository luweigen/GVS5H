This is a weighted interval scheduling variant with at most 4 intervals, requiring lexicographically smallest index list among max-weight solutions. Sort intervals by right endpoint and compute, for each interval, the latest previous interval ending strictly before its start (binary search, since touching boundaries counts as overlapping). Run DP over sorted intervals with states (position, count used) storing both max weight and the lexicographically smallest index path achieving it. Comparison must weigh (weight, path) lexicographically: higher weight wins; ties broken by smaller index list. Reconstruct the path stored in DP directly, then map back to original indices.
