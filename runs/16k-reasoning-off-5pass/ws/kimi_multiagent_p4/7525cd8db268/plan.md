For a fixed set of pairs, a subarray [l, r] is valid iff for every pair (a, b) with a < b, it never contains both endpoints; equivalently, for each right endpoint b, the left endpoint l must be greater than max over pairs (a, b) of a. So the count of valid subarrays equals sum over b of (b - L[b]), where L[b] = max a among pairs ending at b (0 if none). Removing one pair (a, b) only affects L[b]: it can drop to the second-maximum a' among pairs ending at b. Precompute for each b the top two left endpoints and the gain from removing the max; the answer is base count plus the maximum gain.
