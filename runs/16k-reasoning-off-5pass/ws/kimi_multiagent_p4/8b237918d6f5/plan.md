We need to maximize the shortest path distance from 1 to N by choosing exactly K edges to have weight 1. Since N ≤ 30 and M ≤ 100, we can use binary search on the answer. For a candidate distance D, we check if it's possible to make the shortest path ≥ D by selecting exactly K edges. This is equivalent to finding the minimum number of edges to set to 1 such that all paths from 1 to N have at least that many 1-edges, which is a min-cut problem: the minimum edges to "block" all paths with fewer than D ones equals the min-cut in a layered graph. We build a graph with layers 0..D-1 representing the count of 1-edges used, where original edges become 0-cost transitions within the same layer and 1-cost transitions to the next layer, then compute min-cut from (1,0) to any (N,d) with d<D. If min-cut ≤ K, distance D is achievable.
