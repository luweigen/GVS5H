- **Identity used**: For any positive integer s with v2(s) = v (the exponent of 2 in s), we have the telescoping identity `s - s/2^v = sum_{t=1}^{v} s/2^t`. Hence `f(s) = s/2^v = s - sum_{t>=1, 2^t | s} s/2^t`.
- Summing over all pairs `i <= j`: `answer = S_total - sum_{t>=1} (S_t / 2^t)`, where `S_total = sum_{i<=j}(A_i+A_j) = (N+1)*sum(A)` and `S_t = sum over pairs with 2^t | (A_i+A_j) of (A_i+A_j)`. Each term `S_t / 2^t` is an integer because every summand of `S_t` is divisible by `2^t`.
- **Computing S_t**: group values by residue mod `M = 2^t` using a dict (residue -> [count, sum]). For residue classes `r` and `r' = (-r) mod M`:

  - `r == r'`: pairs `i <= j` within the class contribute `(c[r]+1)*w[r]` (derived: `sum_{i<j}(A_i+A_j) + sum_i 2A_i = (c-1)*sumA + 2*sumA`).
