Each row is a prefix of black cells, so define row threshold r[x] = number of black cells in row x; each column is a top-prefix of black cells, define column threshold c[y]. A cell (x,y) is black iff y <= r[x] iff x <= c[y]. This means the black region is a Young-diagram (Ferrers) shape: the sequence r[1..N] must be non-increasing (since x <= c[y] <=> y <= r[x] consistency forces monotonicity). So the problem reduces to: does there exist a non-increasing sequence r[1] >= r[2] >= ... >= r[N] (each in [0,N]) such that every precolored B at (x,y) has y <= r[x] and every W has y > r[x]? For each row x, B-cells give lower bound L[x] = max y over B's, W-cells give upper bound U[x] = min y - 1 over W's; we need L[x] <= r[x] <= U[x], and r non-increasing. Feasibility of monotone sequence with interval constraints: process rows top to bottom maintaining feasible range [lo, hi] for r[x] intersected with "non-increasing" (r[x] <= previous r). Actually we need r[x] <= r[x-1]; greedy: keep current feasible interval [max(L[x], ...)] — standard approach: feasible set after row x is {v in [L[x],U[x]] : exists w in prev feasible set with w >= v}. If prev feasible set is interval [a,b], new feasible = [L[x], min(U[x], b)] provided L[x] <= min(U[x],b). Rows without constraints have L=0, U=N.
