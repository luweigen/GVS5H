This is a classic partitioning problem solvable with Dynamic Programming. Let `dp[i]` be the minimum cost to partition the first `i` elements. The transition involves finding the optimal split point `j` for the last subarray. The cost calculation depends on the cumulative sum of `nums` up to the end of the subarray and the sum of `cost` within the subarray, adjusted by the partition index. We can optimize the transition by rewriting the cost function to allow using a Convex Hull Trick (CHT) or a Li Chao tree, as the relationship between the partition index and the cumulative sums can be linearized.
