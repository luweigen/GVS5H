Model the constraints as a graph on vertices 1..N with edges (X_i, Y_i) labeled Z_i, meaning A_X XOR A_Y = Z. Within each connected component, fixing one vertex's value determines all others via XOR along paths; detect inconsistency by checking cycles (including self-loops requiring Z=0 and parallel edges). Since XOR is bitwise independent, minimize the sum bit by bit: for each bit b, each component becomes a 2-coloring constraint graph; if consistent, choose the side assignment (free flip per component) that puts fewer 1s on vertices, weighted by 2^b. Combine bits to build the answer values.
