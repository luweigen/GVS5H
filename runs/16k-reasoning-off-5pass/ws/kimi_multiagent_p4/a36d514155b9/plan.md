The key insight is linearity: the total Manhattan distance over all arrangements and all pairs decomposes into independent row contributions plus column contributions. For the row part, consider any pair of rows at distance d; the number of ordered cell-pairs spanning them is n², and by symmetry each unordered pair of distinct cells appears in exactly C(mn-2, k-2) arrangements. So row contribution = C(mn-2, k-2) × n² × Σ_{i<j}(j-i), where the row-distance sum for m rows is Σ_d d·(m-d) = m²(m²-1)/6. The column part is symmetric with m and n swapped. All arithmetic is done mod 1e9+7 using modular inverse of 6, and the binomial coefficient is computed with a simple multiplicative loop since mn ≤ 1e5.
