Each operation either does nothing, sets the interval [L,R] to 1, or sets the complement of [L,R] to 1. Since setting 1s never hurts, the question is whether a chosen set of "paid" operations covers every position: position j is uncovered iff every paid interval contains j (op1 misses j) — impossible to fix with op1s alone — so we need, for each j, at least one paid operation whose chosen side covers j. Model each operation as a boolean choice (op1 covers [L,R], op2 covers complement); we need a minimum-cost set of choices covering all N positions. Key observation: with two paid operations i (op1) and k (op2), coverage is everything except (L_k..R_k) \ (L_i..R_i); full coverage requires R_i ≥ R_k and L_i ≤ L_k... i.e., intervals nested. Check feasibility with 0, 1, or 2 paid ops: 0 works only if M=0... actually 0 paid ops never works (N≥1); 1 paid op works iff some [L,R]=[1,N] with op1; 2 paid ops: either two op1s whose intervals union to [1,N] (need L=1 and R=N pair overlapping/adjacent), or op1+op2 combos, or two op2s whose complements union to [1,N] (i.e., intervals disjoint... complement union = all iff intersection empty). Since cost is 1 per paid op, answer is min over achievable counts; check 1 first, then 2 via sweep, else -1 (prove >2 never needed: if any solution exists, a ≤2 solution exists — argue via extreme intervals).
