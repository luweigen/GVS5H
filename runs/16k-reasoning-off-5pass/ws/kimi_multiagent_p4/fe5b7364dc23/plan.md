We need sum over all subarrays of (subarray sum)^K with K ≤ 10. Expand via prefix sums: subarray sum = S_{r+1} − S_l, so we need Σ_{i<j} (S_j − S_i)^K. Binomial-expand (S_j − S_i)^K = Σ_t C(K,t) S_j^t (−S_i)^{K−t}, turning the answer into a combination of power sums of prefix sums computable in one pass. For each j, maintain running totals of S_i^m for m=0..K over previous i, then accumulate Σ_t C(K,t)(−1)^{K−t} S_j^t · P_{K−t}. This is O(N·K) time, all mod 998244353.
