The graph is bipartite (no odd cycle). Adding an edge without creating an odd cycle means adding an edge between opposite color classes within each connected component. For a component with color class sizes a and b, the number of addable edges is a*b minus existing edges in that component. The game is a normal-play impartial game where each move reduces the total count of addable edges by exactly 1 (adding an edge never changes the bipartition or merges components, since edges are only added within a component). So the total number of moves available is fixed: total = sum over components of (a*b - edges_in_component). Aoki wins iff total is odd.
