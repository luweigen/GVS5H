The function f(x,y) is the classic "minimax" path value, which equals the maximum edge weight on the unique path between x and y in any Minimum Spanning Tree (Kruskal tree). So first build the MST with Kruskal (O(M log M)), then compute all pairwise f values between the K A-vertices and K B-vertices. Since K can be up to N (2e5), we cannot compute a K×K matrix in general; however, f values on a tree depend only on the maximum edge on the path, which can be computed via binary lifting LCA in O(log N) per pair — but the assignment problem (min-cost perfect matching) on a K×K matrix is O(K^3) or at best O(K^2 log K), infeasible for K=2e5. The key insight: minimax distances on a tree satisfy a strong structure — sorting both sides and matching greedily works when the cost matrix is a Monge/array structure derived from thresholding. Concretely, f(x,y) ≤ t defines an equivalence (connected components of the subgraph with edges ≤ t); the optimal assignment can be computed by processing Kruskal edges in increasing weight, unioning components, and matching A's and B's within components greedily: whenever a DSU component contains unmatched A's and B's, match them at the current edge weight. This greedy is optimal because any matching must pair A and B that become connected at some threshold, and matching as early as possible minimizes each pair's cost (an exchange argument). Total complexity O((N+M) log N + K α(N)).
