Model the problem as a shortest-path problem on an expanded state graph where each state is (vertex, parity), with parity indicating whether edges are currently reversed. Moving along an edge costs 1 and keeps parity; reversing all edges costs X and flips parity while staying at the same vertex. Since edge weights are only 1 and X, use 0-1 BFS style Dijkstra (or Dijkstra with a heap) over 2N states. The answer is the minimum distance to reach vertex N in either parity. This runs in O((N+M) log N) time, well within limits.
