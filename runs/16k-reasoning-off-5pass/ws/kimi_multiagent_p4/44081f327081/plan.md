For each index i, the answer is the maximum divisor d of A_i such that at least K elements of A are divisible by d (since we can then pick A_i plus K-1 other multiples of d). So compute cnt[d] = number of array elements divisible by d for all d up to max(A) using a frequency array and a sieve-style accumulation. Then for each A_i, the answer is the largest d dividing A_i with cnt[d] >= K; to answer quickly, precompute best[x] = largest divisor d of x satisfying cnt[d] >= K, which can be filled by iterating d over multiples of d. Overall complexity is O(M log M) where M = max(A), which fits the constraints.
