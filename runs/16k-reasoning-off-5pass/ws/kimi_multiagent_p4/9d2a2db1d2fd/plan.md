Model the state as (block, floor). Stairs change the floor within a block at cost 1 per level; walkways move to a cardinal neighbor at the same floor for cost 0, but only if that neighbor’s height is at least the current floor. For a fixed floor level x, the blocks usable at height exactly x form a binary grid (F >= x), and walkway movement at height x is just 4-neighbor connectivity in that binary grid. A journey can be viewed as: at the start block, move vertically from Y to some level x (cost |Y-x|), travel via walkways within the connected component of the level-x mask, then move vertically in the target block from x to Z (cost |Z-x|); feasibility requires both endpoints’ blocks to be in the same connected component of the mask at level x. Preprocess the grid so each query can be answered by considering candidate levels where connectivity changes, using union-find snapshots / divide-and-conquer over levels plus a data structure to evaluate min of |Y-x|+|Z-x| over feasible x.
