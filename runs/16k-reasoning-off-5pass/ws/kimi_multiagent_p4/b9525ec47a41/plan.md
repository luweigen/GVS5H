The graph is a cycle on vertices 0..N-1 plus a hub vertex N connected to a subset S of cycle vertices. Each edge orientation contributes 1 to the in-degree of its head, so we need the number of distinct in-degree sequences, equivalently the number of distinct pairs (in-degree sequence of cycle vertices from cycle edges, combined with spoke choices). Key idea: orienting cycle edges gives each cycle vertex a base in-degree in {0,1,2} from its two cycle edges; each spoke (i,N) adds either to d_i or d_N. The count factorizes via analyzing runs of consecutive 1s in s separated by 0s, since a 0-spoke vertex's cycle-edge orientations are constrained locally. We derive a DP over the circular binary string where each maximal block of 1s of length L contributes a factor f(L) (number of distinct in-degree patterns realizable within that block), computable by a small linear recurrence, and combine blocks with a cyclic convolution/DP. Everything is done modulo 998244353 in O(N).
