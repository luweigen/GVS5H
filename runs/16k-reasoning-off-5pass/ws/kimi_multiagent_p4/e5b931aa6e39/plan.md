Factor the equation: x³ − y³ = (x−y)(x² + xy + y²) = N. Let d = x−y ≥ 1; then d must divide N, and substituting x = y+d gives 3y² + 3dy + d² = N/d, a quadratic in y. Since x²+xy+y² ≥ x² > (N/3)^(1/3) roughly bounds things, but more precisely d³ < N so d ≤ N^(1/3) ≈ 10⁶, making enumeration of all d up to the cube root of N feasible (about 10⁶ iterations). For each candidate d where d divides N, solve the quadratic for y via integer square root of the discriminant and verify. Alternatively iterate over divisors, but enumerating d from 1 to cube root of N is simplest and fast enough in Python (~10⁶ loop iterations with a divisibility check and occasional square root).
