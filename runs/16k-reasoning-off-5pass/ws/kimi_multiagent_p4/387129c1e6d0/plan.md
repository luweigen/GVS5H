The path is a sequence of M axis-aligned segments; we need the final position (simple running sum) and the count of distinct houses lying on any segment. Group houses by x-coordinate (for vertical segments) and y-coordinate (for horizontal segments), keeping sorted lists of the other coordinate. For each segment, binary-search the relevant sorted list to count houses strictly between the endpoints (excluding the starting point, including the ending point) to avoid double-counting at shared vertices. Use a global visited set of house indices to deduplicate houses hit by multiple segments. Everything is O((N+M) log N) with 64-bit-safe Python integers.
