
## ideation
Core difficulty: N up to 2e5 and Q up to 3e5, so simulating all contests per query (O(NQ)) is impossible. We need a near O((N+Q) log M) method, where M ≤ 5e5 (+N possible growth).

Key structural facts:
- Each contest applies f_i(x) = x+1 if L_i ≤ x ≤ R_i else x. Each f_i is monotone non-decreasing, so the composition F is monotone non-decreasing.
- Also F(x) − x is non-increasing in x (higher starting ratings can only "lose" increments, never gain new ones relative to a lower start). This gives at most one crossing point per increment count, enabling binary search.
