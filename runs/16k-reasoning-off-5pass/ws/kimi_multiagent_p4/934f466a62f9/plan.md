The pair price is max over three coordinate sums, so the total is a max over assignments of each pair to one of three "colors" (X, Y, or Z), where a color-c pair's value is the sum of that coordinate. This is exactly a maximum-weight matching of K edges in a "3-colored" complete graph, solvable by DP over subsets of colors: sort cakes by each coordinate, and use DP[mask] = best total using pairs whose assigned colors form the set mask, taking top candidates from the sorted order of the newly added color. Since only the top 2K cakes per coordinate can ever be used, we can restrict to candidates and run a bitmask DP over 8 states with careful candidate merging. The key insight: for a fixed assignment of colors to the K pairs, the optimal is sum of top values, and the DP over color subsets with sorted lists gives an O(N log N + 3^3 * K) style solution per test.
