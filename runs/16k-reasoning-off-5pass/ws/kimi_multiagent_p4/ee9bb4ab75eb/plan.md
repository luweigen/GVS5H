Build a trie over all words, storing at each node the count of words passing through it. The answer for the full array is the deepest node (by depth = prefix length) with count >= k; for each removed index we need the same value on the trie with that word's counts decremented. Key observation: removing one word only affects nodes along that word's path, so we can compute, for each word, the deepest node with count >= k that is NOT on its path (global candidate), plus the deepest node on its path whose count remains >= k after decrement (i.e., count >= k+1). Answer per index is the max of these two depths. Edge case: if n-1 < k, answer is 0.
