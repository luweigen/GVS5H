We need the sum of (min + max) over all subarrays of length ≤ k, which equals (sum of minimums over those subarrays) + (sum of maximums over those subarrays). For each element nums[i], compute its contribution as a minimum: count of subarrays with length ≤ k where it is the minimum, using previous/next smaller element distances clamped by the k-window limit. Symmetrically compute contributions as a maximum using previous/next greater elements. Handle ties carefully (strict on one side, non-strict on the other) to avoid double counting. Total per element is O(1) after monotonic-stack preprocessing, giving O(n) time.
