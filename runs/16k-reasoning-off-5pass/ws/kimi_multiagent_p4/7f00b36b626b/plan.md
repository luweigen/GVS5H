The key insight is that lcm(a,b) = a*b/gcd(a,b) <= threshold, and since threshold <= 2*10^5, any node with value > threshold can only connect to nodes that divide it (lcm >= max(a,b)). Build a DSU over n nodes. For each value v present, enumerate multiples m = v, 2v, 3v... up to threshold; if m is also present and lcm(v,m) <= threshold (automatically true since lcm(v,m)=m when v|m... actually lcm(v,m)=m only if v divides m, which holds), union them. Also handle pairs where neither divides the other: for each value v <= threshold, iterate over multiples m of v up to threshold, and for each present value x that is a multiple of v, union via gcd enumeration. A cleaner approach: for each g from 1 to threshold, collect present multiples of g; union all pairs among them whose lcm <= threshold — but to avoid O(k^2), note that for multiples of g, lcm(a,b) = a*b/g, so union pairs where a*b <= g*threshold; sorting multiples and using two pointers makes this near-linear per g. Total complexity O(threshold log threshold + n log n).
