Since target.length ≤ 4, we can enumerate all non-empty subsets of target (at most 15). For each subset, the cheapest way to cover it with a single nums element is to raise some nums[i] to the least common multiple L of that subset: cost = min over i of (ceil(nums[i]/L)*L - nums[i]), computed efficiently by taking, for each multiple m of L up to max(nums), the gap m - largest nums[i] ≤ m. Then run subset DP: dp[mask] = min cost to cover mask by partitioning it into groups each served by one nums element, i.e., dp[mask] = min over submask of dp[mask \ sub] + cost[sub]. Answer is dp[full mask].
