The blocks form an (W+1)×(H+1) grid with a rectangular hole [L,R]×[D,U] removed; moves go only right/up. The number of paths equals the sum over all reachable (start,end) pairs of binomial path counts, which can be computed as the sum over all edges of (number of ways to reach the edge's tail) × (number of ways to go from the edge's head to any block). Compute forward DP f (paths starting at each point, i.e., number of monotone paths from each point treated as start — actually f(p) = number of paths from any start to p equals sum of binomials; simpler: total paths = Σ over edges g(tail)·h(head) + number of blocks, where g(p)=# monotone paths from the "lower-left region" to p and h(p)=# monotone paths from p to any endpoint). Use inclusion-exclusion / rectangle-sum formulas with precomputed factorials to compute these counts in O(1) per query rectangle, splitting the domain into O(1) rectangles around the hole.
