**Core difficulty:** Operating a box moves *all* balls currently inside it (both colors, including balls that arrived from earlier operations). So the decision to operate box $i$ affects not just the balls initially in $i$, but any ball routed through $i$. We need the minimum number of operations, and each box should be operated at most once (operating twice is never beneficial: balls that arrived after the first operation could have been moved during it if the operation were delayed).
