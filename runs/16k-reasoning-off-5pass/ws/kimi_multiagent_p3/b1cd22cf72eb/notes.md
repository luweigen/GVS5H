## worker: Implement the full Python solution: check(H) via f
- For a fixed common sum H, final lengths satisfy u_i ∈ [max(0, H−D_i), min(U_i, H)], and the total cost is Σ(U_i+D_i) − N·H, so we maximize feasible H.
- Feasibility for given H: forward reachable-interval propagation. The reachable set of u_i values is always an interval: start with [L_0, R_0]; at each step expand by X (curL−X, curR+X) and intersect with [L_i, R_i]. Empty ⇒ infeasible. Nonempty at i=N−1 ⇒ feasible (any endpoint can be extended backward since each step's interval was reachable). O(N).
- Monotonicity: if H is feasible with sequence u_i, then for H' = H−δ (δ≥0), u_i' = max(0, u_i−δ) is feasible for H': it stays within [0, U_i], d_i' = H'−u_i' = min(H', d_i) ∈ [0, D_i], and max(0, ·−δ) is 1-Lipschitz so adjacent differences stay ≤ X. Hence binary search over H ∈ [0, min(U_i+D_i)] is valid (H=0 always feasible).
