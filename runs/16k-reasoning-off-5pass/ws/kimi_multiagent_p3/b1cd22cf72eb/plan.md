We must choose final upper lengths u_i ≤ U_i and lower lengths d_i ≤ D_i minimizing total reduction Σ(U_i−u_i + D_i−d_i), subject to u_i + d_i = H (common) and |u_i − u_{i+1}| ≤ X. For a fixed H, the cost is Σ(U_i + D_i) − N·H, so we want the largest feasible H. Feasibility for a given H: each u_i must lie in [max(0, H−D_i), min(U_i, H)] and form a sequence with adjacent differences ≤ X; this is a classic interval-propagation (reachable-set) check doable in O(N). Since H is bounded by min(U_i + D_i) (≤ 2·10^9), we binary search the maximum feasible H in O(N log(maxH)), then compute the cost.
