We need to count substrings whose numeric value is divisible by their last digit (which must be non-zero). Since the last digit d is 1-9, divisibility by d depends on the substring value mod d. For each ending position j with digit d != 0, we need to count starting positions i such that the number formed by s[i..j] ≡ 0 (mod d). The value of s[i..j] mod d can be expressed using prefix values: num(i,j) = prefix[j+1] - prefix[i] * 10^(j-i+1), but since 10 may not be invertible mod d (d shares factors with 10), we instead process per digit d using recurrence on remainders. A cleaner approach: for each d in 1..9, scan and maintain counts of remainders of suffix values mod d as we extend the end pointer; when at position j with digit d, the number of valid substrings ending at j equals the count of remainders equal to 0 among all suffixes ending at j, which we can update incrementally: new_suffix_mod = (old_suffix_mod * 10 + digit) % d... actually each substring ending at j is (substring ending at j-1)*10 + d, so we track the multiset of remainders of all substrings ending at current position, update by (r*10 + d) % d, and count zeros. Sum over all positions with non-zero digit. This is O(9*n) = O(n).
