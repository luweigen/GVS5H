Since N ≤ 10, the LCS of any length-M string T with S is at most N, and the standard LCS DP row against S can be compressed into a state of N values (each in 0..N, nondecreasing, increments of at most 1). We model building T character by character as a finite automaton: the state is the current DP row (lcs lengths of T-prefix against each prefix of S), and each appended letter transitions to a new row via the standard LCS recurrence. We then run M steps of DP over these states, counting strings, and aggregate by the last component of the state (the LCS length with full S). The number of distinct states is small (bounded by ~C(2N,N) or less, very manageable for N ≤ 10), so we precompute transitions for all 26 letters per state and iterate M ≤ 100 steps. Answers are counts grouped by final LCS value k = 0..N, modulo 998244353.
