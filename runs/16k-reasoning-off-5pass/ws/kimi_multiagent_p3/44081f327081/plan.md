For each index i, the answer is the maximum d dividing A_i such that at least K elements of A are divisible by d (we can then pick A_i plus K-1 others divisible by d). So compute cnt[d] = number of array elements divisible by d for all d up to max(A) via a divisor-count sieve: for each d, add its frequency to multiples. Then for each i, answer = max divisor d of A_i with cnt[d] >= K. To answer fast, precompute best[x] = max divisor d of x with cnt[d] >= K; this can be filled by iterating d over all valid d and setting best[m] = d for multiples m of d (since d increases, later writes are larger, or take max). Complexity O(M log M) with M = max(A) ≤ 1e6, fine for N ≤ 1.2e6. Edge case K=1: answer is A_i itself since cnt[A_i] >= 1 always.
