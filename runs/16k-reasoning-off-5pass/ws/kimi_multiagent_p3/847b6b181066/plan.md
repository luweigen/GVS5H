Model smoke as a set of active generation times. A puff generated at time g (0 ≤ g ≤ N-1, where generation happens after wind at time g, with initial smoke as g=0) occupies position P(t)-P(g) at time t+0.5, where P(k) is the prefix displacement after k wind steps. So smoke is at (R,C) at time t iff there exists g ≤ t with P(g) = P(t) - (R,C). Maintain a set of "seen" prefix positions P(g) for all generated puffs; at each step t, check membership of target P(t)-(R,C), then add P(t) to the set if the campfire cell is empty (i.e., if P(t) itself is not in the set — since smoke at origin at time t+0.5 means some puff has P(g)=P(t)). This gives an O(N) hash-set solution.
