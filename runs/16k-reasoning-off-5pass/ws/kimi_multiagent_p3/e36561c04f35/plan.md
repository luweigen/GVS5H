We need to find the minimum number of operations to empty the array. Since swapping adjacent elements allows us to reorder the array arbitrarily (at the cost of inversions), and deleting a prefix requires all elements in that prefix to be equal, the problem reduces to: for each distinct value, we can delete all its occurrences in one operation if we first gather them together via swaps. The cost to gather all occurrences of value $v$ and delete them is the number of elements not equal to $v$ that are interspersed between the first and last occurrence of $v$ (i.e., the number of "inversions" needed to bring them together) plus 1 for the deletion. However, we can also delete elements one by one (cost = count of $v$), or use a hybrid approach. The optimal strategy for each value $v$ is independent: we choose a subset of occurrences to delete individually (cost 1 each) and gather the rest into one block (cost = number of "gaps" between consecutive kept occurrences + 1). This is equivalent to: if we keep $k$ occurrences of $v$ to delete as a block, the cost is (number of elements between first and last kept occurrence that are not $v$) + 1. We can compute this efficiently by considering the positions of each value.
