Model each row as a W-bit mask. Row flips (X) and column flips (Y) commute, so the final grid is determined by a row-flip vector r and column-flip vector c, with cell value A[i][j] XOR r[i] XOR c[j]. Since W ≤ 18, enumerate all 2^W column-flip masks c; for each, every row independently chooses r[i] to minimize its popcount, i.e. contributes min(popcount(row XOR c), W - popcount(row XOR c)). Group identical rows with a frequency map (H up to 2e5 but only ≤ 2^W distinct rows) to make the enumeration O(4^W) worst case, acceptable for W ≤ 18 (about 2.7e8 worst case — optimize by precomputing popcounts and using arrays). Alternatively, note min over r makes the per-row cost depend only on popcount of (row XOR c), so precompute popcount table of size 2^W once and iterate.
