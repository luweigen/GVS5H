We need ord_M(A) = N exactly. The simplest universal construction: pick M = N+1... but N+1 may not be prime, so instead use the lifting idea: take a prime p and set A = 1 + N, M = N... that fails coprimality. A cleaner approach: use M = N*k+1 style is hard; instead use the classic trick with A = N+1, M = N^2 won't work either. The robust known solution: choose a prime p dividing structure — actually simplest: A = 1 + N, M = N gives A ≡ 1 mod N so order 1, wrong. Instead use M = N * (something) with A having order N: take any integer g and M = g^N - 1 with A = g — then A^N ≡ 1 mod M, but the order could be a proper divisor of N. Fix: ensure order is exactly N by picking M = Φ_N(g) (cyclotomic value) — too complex. Practical approach: use A = 2 and M = 2^N - 1 only if N's order is exactly N... not guaranteed. Better: use the prime-power lifting: pick prime p with p ≡ 1 mod N? Too slow. Simplest correct: A = N+1, M = (N+1)^N - 1 divided appropriately — instead use M = A^N - 1 with A chosen so that no smaller divisor works: order of A mod (A^N-1) is exactly N, because A^k - 1 < A^N - 1 = M for k < N, so M cannot divide A^k - 1 (since 0 < A^k - 1 < M). That's the key insight! With A ≥ 2, M = A^N - 1 ≤ 10^18 requires A^N ≤ 10^18 + 1, so pick A = 2 for N ≤ 60, and for N > 60 pick A such that A^N fits — impossible for large N with A ≥ 2. So for large N use a different construction: A = 1 + N... order is 1. Alternative for large N: use M = N+1 if N+1 is prime with A primitive root — hard. Use two-case: N=1 → M=1 (any A). General: pick smallest prime p not dividing N, set A = p, M = p^N - 1 — same size problem. So the real fix: M need not equal A^N - 1; we need M | A^N - 1 but M ∤ A^k - 1 for k < N. Take M = (A^N - 1)/(A^d - 1) factors... Use cyclotomic: M = Φ_N(A) divides A^N - 1, and any prime q dividing Φ_N(A) has ord_q(A) = N unless q | N. So set M = Φ_N(A) with A chosen so Φ_N(A) has no prime factor dividing N — or simpler: M = Φ_N(A) / gcd(Φ_N(A), N) — complexity high. Simplest implementable: for N ≤ 60 use A=2, M=2^N - 1 (order exactly N since 2^k - 1 < M for k<N). For N > 60: use A = N+1? No. Use the fact: order of (1+N) modulo N^2... (1+N)^k ≡ 1 + kN mod N^2, so smallest k with N^2 | kN is k = N. So A = N+1, M = N^2 gives order exactly N! Check: (1+N)^k ≡ 1 + kN (mod N^2) by binomial theorem, so A^k ≡ 1 mod N^2 ⟺ N | k.
