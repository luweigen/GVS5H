A 400 number has the form p^{2a} q^{2b} = (p^a q^b)^2 with distinct primes p, q, so it is exactly a perfect square whose square root has exactly two distinct prime factors. For each query A, the answer is s^2 where s = floor(sqrt(A)) decreased until s has exactly two distinct prime factors. Since consecutive valid s values are dense (gaps are small), a per-query downward scan with fast factorization via a precomputed smallest-prime-factor sieve up to 10^6 suffices. Precompute the count of distinct prime factors for all integers up to 10^6 once, then answer each query in near-constant amortized time.
