We need shortest palindrome-labeled walks between all pairs. Model states as unordered endpoint pairs (u, v) representing the two ends of a partially built palindrome; start states are (i, i) with distance 0 (empty palindrome) and (i, j) with an edge i→j labeled c at distance 1 (single-char palindrome). Transitions extend both ends: from (u, v), pick edges x→u labeled c and v→y labeled c, moving to (x, y) with cost +2. Run multi-source BFS (0-1-2 weighted, but all transitions cost 2 and sources cost 0/1, so a deque-based BFS by layers works) over the O(N²) states; the first time state (i, j) is reached gives A_{i,j}. Precompute for each letter and vertex the in-neighbors and out-neighbors to make transitions efficient.
