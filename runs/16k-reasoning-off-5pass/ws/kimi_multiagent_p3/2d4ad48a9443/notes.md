## worker: Implement the full solution: two-pointer sweep wit
- Cost of a window [l, r] = sum over i of (prefixMax within window at i) - nums[i]; achieved by raising each element to the running max (optimal since increments only).
- Monotonicity: restricting an optimal non-decreasing arrangement of a superarray to a subarray gives a valid arrangement of no greater cost, so cost is monotone under shrinking from either side. Hence for l decreasing, the maximal valid r(l) is non-increasing — two pointers both moving left, O(n) total moves.
- Window state = deque of segments [level, count] with strictly increasing levels left→right (the running-max levels).
  - push-left x: position l has level x; every leading segment with level ≤ x gets raised to x (extra cost (x - v) * count each), and merges with the new element into one bottom segment. Amortized O(1) since each segment is merged away at most once.
  - pop-right: position r's level is the top segment's value v (window max); removing it costs exactly v - nums[r] and cannot affect other positions' prefix maxima. Exact, O(1).
