### Sufficiency — constructive greedy
Invariant facts used: a move exists at any `01` boundary with left 0-run ≥ X and right 1-run ≥ Y (apply A, moving the Y leftmost 1s of the right run left by X), and symmetrically at any `10` boundary with left 1-run ≥ Y and right 0-run ≥ X (apply B).

**Left-pass lemma:** suppose ones 1..k−1 already sit at their targets q_1<…<q_{k−1}, the k-th one is at p > q_k with X | (p−q_k), and all ones in positions < p are exactly the fixed ones. Then we can move the k-th one to q_k without disturbing fixed ones:
- Cells p−X..p−1 are all 0: any 1 there would be an unfixed one of index > k−1 left of the k-th one — impossible (order preservation), and fixed ones sit at ≤ q_{k−1} < q_k ≤ p−X.
- If the 1-run at p has length ≥ Y, apply A at i = p−X: the k-th one moves to p−X. Repeat (the argument re-applies: cells p−2X..p−X−1 are 0 by the same token argument) until reaching q_k.
- If the run length a < Y (ones k..k+a−1 at p..p+a−1, cell p+a is 0 or out of range): first recursively pull ones k+1..k+a−1 left so the run at p becomes length ≥ Y (their targets are ≥ q_k + something ≡ compatible mod X; each is pulled by the same lemma applied to a suffix — process the run from its right end leftward), then apply A.
