We need the sum of K-th powers of all subarray sums, with K ≤ 10 and N up to 2·10⁵. Using prefix sums S₀..S_N, each subarray sum is S_r − S_{l−1}, so the answer is Σ_{i<j} (S_j − S_i)^K. Expand via the binomial theorem: (S_j − S_i)^K = Σ_t C(K,t) S_j^t (−S_i)^{K−t}, which turns the total into a combination of power sums of prefix sums. For each j we need Σ_{i<j} S_i^m for m = 0..K, maintainable in O(K) per step, giving O(N·K) overall. All arithmetic is done mod 998244353, with the sign (−1)^{K−t} handled by modular negation.
