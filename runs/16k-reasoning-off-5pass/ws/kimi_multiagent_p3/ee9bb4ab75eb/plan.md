Build a trie over all words, storing at each node the count of words passing through it and the multiset (top-two) of word lengths ending exactly at that node. The answer for a full array is the maximum, over all nodes with subtree count ≥ k, of (depth + k-th largest ending length at that node, 0 if fewer than k end there). To handle removals, for each word compute the best value using only nodes/lengths not requiring that word: for each prefix node of the word, the count without it is cnt-1, and the ending-length multiset without it excludes its own length. Combine per-word candidate with the global best from nodes not on its path (tracked via top-two candidates per node and a global top-two over nodes). Total work is O(total characters).
