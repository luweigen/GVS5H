We need to maximize the shortest 1→N distance after flipping exactly K edges to weight 1. Key insight: the final distance d is achievable iff we can choose K edges such that every 1→N path contains at least d chosen edges. Equivalently, for a candidate d, define layers by BFS distance from 1 in the unweighted graph; only edges that go from layer i to layer i+1 ("forward" edges) can increase path length by 1 each, and any path uses exactly one such edge per layer step. The minimum number of forward-edge "hits" over all paths equals the size of a minimum cut in a layered DAG, which we can compute via max-flow with edge capacities (1 for forward edges, infinite otherwise). Binary search (or iterate) d from 0 up to dist(1,N), checking if the min-cut ≥ d is achievable with exactly K flips — actually we need: max over choices of K edges of min-path-hits = min(K, max min-cut) where the cut is computed on the graph where only forward edges count. Since N ≤ 30 and M ≤ 100, we can compute the max-flow min-cut on the BFS-layered DAG with unit capacities on forward edges; the answer is min(K, that min-cut value, dist(1,N)).
