- **Algorithm**: Answer = `min(D, K // F)` where:
  - `D` = unweighted BFS distance from 1 to N.
  - `F` = max number of edge-disjoint 1→N paths in the layered DAG of *forward* edges (edges u→v with `dist[v] = dist[u]+1`), computed via unit-capacity Dinic max flow.
- **Proof sketch**:
  - Every 1→N path must contain ≥ D forward edges (each edge raises the BFS layer by at most 1, and the layer must net-increase by D). So the weighted distance of any path ≥ number of flipped forward edges on it; flipping non-forward edges never helps the minimum.
  - *Upper bound for any strategy*: the F edge-disjoint layered paths each have length D; since they're edge-disjoint, each flipped edge lies on at most one, so `K ≥ Σ w(P_i) ≥ F·min w(P_i)`, giving distance ≤ K//F. Also distance ≤ D trivially.
  - *Achievability*: the s–t path clutter is Mengerian, so the minimum number of forward edges needed to hit every path ≥ d times is exactly `d·F` (LP duality: covering LP = d × max-flow, integral). Since `d·F ≤ K` and there are ≥ D·F ≥ d·F forward edges, we can realize d = min(D, K//F).
- **Sample verification**:
  - Sample 1: layers 0,1,1; forward edges 1→2, 1→3; F=1, D=1 → min(1, 2//1)=1 ✓

  - Sample 3: two parallel forward edges 1→2, F=2, D=1 → min(1, 1//2)=0 ✓
- Complexity: BFS O(N+M), Dinic O(E·√V)-ish here trivially fast (N≤30, M≤100, flow ≤ M).
