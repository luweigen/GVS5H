Pair the smallest mochi as tops with the smallest valid larger mochi as bottoms using a greedy two-pointer approach. Since the array is sorted ascending, we can pair the smallest half candidates (tops) with the larger half (bottoms). For each top in order, find the smallest unused bottom that is at least twice the top's size. This greedy maximizes the number of pairs because using the smallest valid bottom preserves larger bottoms for larger tops. The answer is at most N/2, and this runs in O(N).
