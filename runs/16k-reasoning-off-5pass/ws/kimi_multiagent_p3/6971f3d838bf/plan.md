The key insight is that deleting all occurrences of value x splits the array into segments separated by x, and the best subarray after deletion is the max subarray sum over those segments. For each distinct value v, we need the maximum subarray sum of the array with all v's removed. Compute prefix sums; for a segment (l..r) with no deleted values, its max subarray sum is prefix_max_sums - min prefix before it. For each value v, its occurrences split the array into gaps; the answer for deleting v is the max over gaps of (max prefix sum within gap minus min prefix sum at/before gap start). We can process each distinct value's positions, and for each gap between consecutive occurrences compute the range max/min of prefix sums using a sparse table or segment tree for O(1)/O(log n) range queries, giving O(n log n) total. Take the max over all values and also the no-deletion case (standard Kadane's).
