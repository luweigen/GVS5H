For a fixed prefix R and threshold X, the answer is the LIS length of the prefix restricted to values ≤ X. Process queries offline sorted by X, sweeping values: maintain a Fenwick tree over compressed A-values where position v holds the best LIS length ending with value v among inserted elements (those with A_i ≤ current X), updated in index order as elements become eligible. Each query then asks for the prefix maximum over compressed values ≤ X, which the Fenwick supports in O(log N). Coordinate-compress all A_i and X_i, sort elements by value and queries by X, and answer each query with a Fenwick prefix-max query. Total complexity O((N+Q) log N).
