Split p into three literal parts: prefix A (before first '*'), middle B (between the two '*'), and suffix C (after second '*'). A substring s[i..j] matches iff it starts with A, ends with C, and contains B somewhere in between (with A and C possibly overlapping B's region only in the sense that the layout is A ... B ... C in order, parts may be empty). We need the shortest window [i, j] such that A occurs at i, C ends at j, and B occurs fully inside after A. Use KMP (or Z) to find all occurrence start positions of A, B, C in s in O(n). Then for each occurrence of B, we want the latest A starting at or before B's start, and the earliest C ending at or after B's end; the window length = (C_end) - (A_start). Take the minimum over all B occurrences using prefix/suffix precomputed arrays for O(1) per query. Handle empty parts as edge cases (empty A means window can start anywhere ≤ B start; empty C means window can end anywhere ≥ B end; empty B reduces to matching A then C with overlap allowed only via ordering A before C).
