The problem asks for the longest path that: starts at a cell with value 1; moves along one of 4 diagonal directions; each subsequent step must match the alternating pattern 2,0,2,0,...; and may make at most one clockwise 90° turn (turn point counts once, sequence continues seamlessly).

Core difficulties:
1. The expected value at step k (0-indexed) is: 1 if k==0, else 2 if k odd, 0 if k even. So validity depends on parity of the step index — after a turn, the continuation must respect the parity of how many steps have already been taken.
