The key observation is that the expected value at each step depends only on the step index (1 at index 0, then alternating 2, 0, 2, 0...), so we can precompute for every cell and every diagonal direction the length of the longest valid run starting at that cell going in that direction. Using DP with memoized DFS (or reverse-order iteration), each cell/direction state is computed once in O(1) from its successor, giving O(n·m) states. For the answer, we walk from every cell containing 1 in each of the 4 directions; at each position along the walk we may turn clockwise once, and the continuation length is looked up from the precomputed table (with the correct parity offset). The maximum over all these candidates, including the no-turn case, is the answer. Total complexity is O(n·m) time and space, well within the 500×500 limits.
