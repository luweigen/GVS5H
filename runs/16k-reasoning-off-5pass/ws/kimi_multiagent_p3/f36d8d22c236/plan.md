Model the problem as a directed graph on the 26 letters: for each position i, S[i] must eventually map to T[i], so add edge S[i]→T[i]; if any letter has two different required targets, answer is -1. Each operation renames one letter globally, so we need the minimum number of renames to realize this mapping. For a letter a with edge a→b (a≠b), one operation is needed unless b's own outgoing chain lets us "rotate" — concretely, each non-trivial path component (chain ending at a fixed letter or at a letter with no outgoing edge) costs its number of edges, while each pure cycle costs cycle_length+1 (one temporary rename is needed to break the cycle). A cycle can be done in cycle_length operations only if some letter in the cycle is also reachable as a target from outside... actually the standard result: each cycle of length L costs L+1, unless there exists a letter in the cycle that has an incoming edge from a letter not in the cycle whose own target differs — the safe known result is L+1 per cycle, except when some node in the cycle has an extra incoming edge allowing a free temporary, reducing to L. Verify this reduction condition carefully, then count components in O(26).
