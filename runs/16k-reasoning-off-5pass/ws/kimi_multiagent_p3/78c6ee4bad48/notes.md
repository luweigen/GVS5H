- Operation on pieces i..i+3 reflects the middle two about the outer pair's midpoint; after re-sorting, the gap triple (d_i, d_{i+1}, d_{i+2}) becomes (d_{i+2}, d_{i+1}, d_i) — i.e., swaps gaps at distance 2. Such swaps generate the full symmetric group on each parity class of gap indices, so odd-indexed gaps and even-indexed gaps can each be arbitrarily permuted.
- x_1 and x_N never move. Sum S = N*x_1 + Σ_{j=1}^{N-1} (N-j) d_j, with weights N-j strictly decreasing in j. By the rearrangement inequality, within each parity class assign smallest gaps to smallest j (largest weights): sort class ascending, place in ascending j order.
