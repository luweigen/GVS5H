We need to count connected labeled graphs on N vertices with M edges where exactly N/2 vertices are at even distance from vertex 1 (including vertex 1 itself) and N/2 at odd distance. The key insight is that this condition depends only on the bipartition of vertices by distance parity from vertex 1. We can use exponential generating functions or direct combinatorial enumeration by iterating over which subset of vertices (containing vertex 1) forms the even-distance set. For each valid bipartition, we count graphs where edges within each part don't create shorter paths (i.e., the graph is connected and the bipartition is exactly the distance parity classes). Since N ≤ 30, we can use inclusion-exclusion or subset DP over the 2^(N-1) possible even-sets containing vertex 1, combined with counting connected graphs via standard exponential formula or Kirchhoff-based recurrences.
