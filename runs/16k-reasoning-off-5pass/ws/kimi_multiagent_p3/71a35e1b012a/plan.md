Each position j must be covered by at least one chosen operation: operation 1 on interval i covers [L_i, R_i], operation 2 covers the complement [1, L_i-1] ∪ [R_i+1, N]. We need a minimum-cost subset of operations (each used as type 1 or 2, cost 1) whose chosen "sets" cover all positions 1..N. Key insight: the answer is at most 2 — one operation covers everything only if some interval is [1,N] (op1) or... actually op2 of [1,N] covers nothing; a single op1 covers all iff (L_i,R_i)=(1,N). With two operations, we need sets A,B covering [1,N]; check pairs among types: op1+op1 (two intervals covering [1,N]), op1+op2, op2+op2 (complements covering everything means intersection of the two intervals is empty). Also answer 0 only if N=0 (impossible since N≥1 and x starts 0, so K≥1). So: check K=1 (any full interval), else check K=2 feasibility over the three type-pair cases using interval extremes, else -1. For K=2 we must also output which operation indices and types achieve it, so track witness indices during the checks.
