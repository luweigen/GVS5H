We need to decide if a tree on NK vertices can be partitioned into N vertex-disjoint simple paths of exactly K vertices (K-1 edges). Key edge cases: K=1 is always Yes (each vertex is its own path), and N=1 is Yes iff the tree itself is a path (max degree ≤ 2). For the general case, use a greedy leaf-stripping / matching-based decomposition: repeatedly peel leaves, and when K consecutive layers align, cut off a K-vertex path; equivalently, root the tree and process deepest-first, passing up "chain lengths" of unmatched vertices, pairing children chains at each node so that combined length equals K. The cleanest correct approach: root arbitrarily, DFS returns the length of the dangling partial path ending at the node; at each node, collect child chain lengths, greedily merge pairs summing to K (a completed path), and pass up the remainder plus one. Validate with a multiset-based greedy (pair smallest with largest) and verify feasibility.
