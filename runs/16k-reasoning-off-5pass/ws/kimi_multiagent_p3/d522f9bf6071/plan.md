This is a weighted interval scheduling problem with the added constraint of selecting at most 4 intervals and a tie-breaking rule for lexicographical order. A dynamic programming approach is suitable. We can sort the intervals by their end points and use binary search to find the latest non-overlapping interval for any given interval. The DP state will be `dp[i][k]`, representing the maximum score using intervals up to index `i` (in the sorted list) and choosing at most `k` intervals. To handle the lexicographical tie-breaking, the DP state must store not just the maximum score but also the corresponding lexicographically smallest list of original indices. The final answer will be derived from the state that yields the overall maximum score.
