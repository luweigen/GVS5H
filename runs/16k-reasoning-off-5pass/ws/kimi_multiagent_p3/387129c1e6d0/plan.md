The path is a sequence of M axis-aligned segments, so only houses lying on these segments matter. Group houses by x-coordinate (for vertical segments) and by y-coordinate (for horizontal segments), keeping sorted lists of the other coordinate. For each move, binary-search the relevant sorted list to count houses within the segment's coordinate range, and use a per-coordinate offset set (or a global visited set of house indices) to avoid double-counting houses hit by multiple segments. Track the running position with 64-bit-safe integers (Python ints are unbounded). Total work is O((N+M) log N).
