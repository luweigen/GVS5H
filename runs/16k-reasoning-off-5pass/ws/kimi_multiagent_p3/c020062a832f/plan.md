For a fixed k, B_i = (A_i + k) mod M, so each pair (i,j) with i<j contributes an inversion iff (A_i + k) mod M > (A_j + k) mod M. For a pair with A_i > A_j, this holds for all k except when the wrap-around interval (M - A_i, M - A_j] catches k; for a pair with A_i < A_j, it holds exactly when k is in [M - A_i, M - A_j); equal pairs never contribute. Thus each pair flips the answer at one or two k values, so we can compute the base inversion count of A and apply a difference array over k of length M. Counting inversions and per-pair difference updates can be done with a Fenwick tree over values in O(N log M), then a prefix sum over k gives all M answers in O(N log M + M).
