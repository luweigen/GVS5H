**Derivation of the cost formula.**

- Adjacent swaps generate all permutations; sorting requires each inversion pair to be swapped an odd number of times, so an optimal sequence swaps each inversion exactly once. The freedom is only in the *order*, which determines *where* each swap happens.
- Process values in increasing order $v = 1, \dots, N$. Maintain the invariant that values $< v$ have already been removed from the array (they occupy their final slots $1..v-1$). Value $v$ sits at current index $\text{cur}(v) = \text{pos}[v] - (\text{# removed before } \text{pos}[v])$ and must move left to slot $v$.
- Moving $v$ leftward, it crosses exactly the remaining elements with original position $< \text{pos}[v]$ (these are precisely values $> v$ originally left of $v$ — the inversions involving $v$ as the smaller element). If the crossed elements currently occupy indices $r_1 < r_2 < \dots < r_k$, the swaps occur at positions $r_k, r_k - 1 + \dots$ — more precisely, after $j$ swaps $v$ is at index $\text{cur}(v) - j$ and the next crossed element sits immediately to its left, so the swap positions are $r_k, r_{k-1}, \dots$ shifted... Summing carefully: total cost for $v$ $= \sum_{j=1}^{k} (\text{current index of } j\text{-th crossed element from the right})$.
