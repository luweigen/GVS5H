**Status of the derivation.** The program above implements the greedy-canonical-lift DP:

- **Characterization (verified previously):** valid `(t,h)` ⟺ `t ∈ {−1,0,1}^N` with all contiguous arc sums in `[−1,1]` ⟺ partial sums `P_j` stay in a width-1 window containing 0 (type A: `{−1,0}`, type B: `{0,1}`), total `P_N = 0`. State `(P, seen_neg, seen_pos)` with `seen_neg & seen_pos` forbidden captures this with O(1) states.
- **Distinct `d` ⟺ distinct `(u, σ)`** where `u_i = t_i + h_i − ... = d_i − 1` on S (`u ∈ {−1..2}`), `u_i = t_i` off S, `σ = Σh` (so `d_N = K − σ`).
- **Ambiguity resolution:** for `u_i ∈ {0,1}` on S there are two lifts `(t,h) = (u_i, 0)` or `(u_i−1, 1)`. The DP canonicalizes via a **greedy lift**: at each free position pick `h=0` (min-greedy) or `h=1` (max-greedy) whenever the suffix can still be completed (checked against a precomputed suffix-feasibility table `suf`, which depends only on `P`, mask, and position since any future `t ∈ {−1,0,1}` is achievable by some `u`). Min-greedy yields `lo(u)`, max-greedy yields `hi(u)`; brute force confirms the achievable `σ` set is the full interval `[lo, hi]`, so each `u` contributes `hi − lo + 1` distinct `d_N` values.
- **Answer** `= Σ_u (hi(u) − lo(u) + 1) = sum_hi − sum_lo + cnt`, computed by two O(N) DPs with O(1) state (`(P, mask)` → `(cnt, Σσ)`).

**Verification performed (during development):** against the brute-force orientation enumeration for all `N ≤ 8` with **all** `2^N` strings `s`, plus random tests up to `N = 12` (comparing against the `(t,h)`-set enumeration). Key facts confirmed: (1) greedy alive-set is identical for min/max versions and equals the existence set; (2) achievable `σ` per `u` is contiguous; (3) `cnt_min == cnt_max` always.
