Each operation replaces two numbers a,b with floor(a/4), floor(b/4). For a single number x, the number of times it must be divided by 4 to reach 0 is its "depth" d(x) = number of base-4 digits (i.e., smallest k with 4^k > x). Since each operation handles two numbers, the minimum operations for a multiset equals max(maxDepth, ceil(totalDepthSum / 2)). For a range [l, r], numbers with depth k are those in [4^(k-1), 4^k - 1]; count them in the range to compute totalDepthSum and maxDepth quickly. Answer each query in O(log r), sum over all queries.
