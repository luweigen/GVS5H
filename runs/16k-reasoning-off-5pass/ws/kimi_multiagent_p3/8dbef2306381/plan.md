Since N is huge but M and B are small, the key is to only track reachable positions near the bad intervals. A position is reachable if we can land on it, and from a reachable position x we can jump to any non-bad position in [x+A, x+B]. Between consecutive bad intervals there are long stretches of safe squares; we can compute the set of reachable positions as intervals and propagate them. Because B ≤ 20, after a long enough safe stretch, the reachable set becomes a contiguous range (all residues mod gcd-like behavior, but simpler: once a contiguous block of length ≥ A is reachable, everything after is reachable up to the next bad interval). We process each bad interval, trimming reachable ranges that fall inside it, and check if any reachable position can jump past it.
