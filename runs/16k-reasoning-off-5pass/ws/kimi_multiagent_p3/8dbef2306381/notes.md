- **A == B special case:** With a fixed step `d`, square `p` is reachable iff `p = 1 + kd` and every earlier progression square is non-bad. So the answer is Yes iff `(N-1) % d == 0` and no bad interval contains a square `≡ 1 (mod d)` (checked via `1 + ceil((L-1)/d)*d <= R`).
- **A < B general case:** Safe zones (between bad intervals) are processed left to right. `expand_closure(seeds, lo, hi)` computes the least fixpoint of reachable positions inside safe zone `[lo, hi]`:
  - Seeds = reachable positions clipped to the zone plus one-jump targets `[a+A, b+B]` (sources may lie up to `B` before the zone, since jumps can clear a bad interval plus tiny zones).
  - Repeatedly add shifted copies `[a+A, b+B] ∩ [lo,hi]`. If any interval reaches length `≥ A`, it self-extends contiguously (`a+A ≤ b+1`), so everything from its left end to `hi` is reachable — the full-extension rule, which caps the work. With `B > A`, interval lengths grow by `B-A ≥ 1` per round, so within ≤ ~20 rounds either full extension triggers or the set stabilizes; 45 rounds is a safe cap.
  - Full extension keeps earlier (smaller) intervals before the triggering one, since they may still serve as jump sources into the next zone when `a + A > next_zone_start`.
- **Trailing window:** After each zone, reachable positions below `next_zone_start - B` are discarded — they can never jump into any later zone. This keeps the interval list tiny (≤ ~45 intervals), giving `O(M · 45 · K log K)` with small `K`.
