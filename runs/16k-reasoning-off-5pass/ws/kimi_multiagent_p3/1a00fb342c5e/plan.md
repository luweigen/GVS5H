Model each bit independently: for bit k, each constraint becomes a XOR equation over GF(2) on variables A_i (bit k of A_i). Build a DSU with parity (weighted union-find) per bit to detect inconsistency and to express each variable's bit as parity relative to its component root. For each connected component and each bit, the root's bit is free; choose it (0 or 1) to minimize that bit's contribution to the total sum, i.e., pick the root value so the minority side takes bit value 1, contributing min(count1, count0) * 2^k. Sum over all bits and components; consistency check across all bits determines feasibility. Finally reconstruct each A_i by combining its bit parities across all bits.
