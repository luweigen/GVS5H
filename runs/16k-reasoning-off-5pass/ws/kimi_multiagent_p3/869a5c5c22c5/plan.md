Model the problem as finding a cyclic sequence of R red and B blue vertices where consecutive (and last-to-first) pieces are adjacent: red-red or red-blue pairs need Manhattan distance 1, while blue-blue pairs need diagonal adjacency (|dr|=|dc|=1). Key parity insight: blue moves preserve (r+c) parity, red moves flip it, so the cycle must contain an even number of red pieces unless R=0; also a single blue with reds is impossible since a blue needs both neighbors diagonal-reachable. Constructively: all-blue cases form a diagonal cycle (works for B≥3, and B=2 with two diagonally adjacent pieces); all-red cases form a grid cycle (works for even R≥2 via a 2×k loop, or R=2 adjacent pair); mixed cases need R even, R≥2, B≥2, built by a red "ladder" spine with blue pairs attached diagonally. Verify impossibility cases: R+B=2 with R=B=1, odd R>0, R=1 with B>0, B=1 with R>0.
