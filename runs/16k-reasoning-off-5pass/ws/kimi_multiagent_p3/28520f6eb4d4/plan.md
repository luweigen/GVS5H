Model each building as a vertical segment at X_i from height 0 to H_i. From viewpoint (0,h), building i is visible iff the ray to some point on it is not blocked; the key observation is that building i is visible iff h > max over j<i of the line height at X_i formed by (0,h) passing through top of building j — i.e., the "upper envelope" of lines from origin through each building top. Define f(x) = max over buildings j with X_j <= x of (H_j * x / X_j) — the height at x of the steepest ray from origin to a building top. Building i is visible from height h iff h * X_i >= f(X_i) * ... actually visibility condition: i is visible iff h >= max over j<i of H_j * X_i / X_j is wrong; correct condition: i is visible iff line from (0,h) to top of i clears all j<i, i.e., h + (H_i - h) * X_j/X_i >= H_j for all j<i. The maximum h at which some building is invisible equals max over i of g_i where g_i = max over j<i of (H_j * X_i - H_i * X_j) / (X_i - X_j), clamped at >= 0; answer is max of these, or -1 if max <= 0 (all visible at h=0). This is a classic convex-hull-trick-like computation: process buildings left to right maintaining upper convex hull of points (X_j, H_j); for each i, the best j is found via the hull (lines from j to i, maximize slope intersection height at 0). Compute h_i = max over j on hull of (H_j*X_i - H_i*X_j)/(X_i - X_j) via binary search on hull slopes, then answer = max(0, max h_i), printing -1 if max h_i <= 0.
