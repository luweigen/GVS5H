This is a bounded edit distance problem: determine if Levenshtein distance between S and T is at most K (K ≤ 20). Since K is tiny but strings can be 500K long, full DP is too slow; instead use the classic banded DP where we only compute cells with |i-j| ≤ K, since any path exceeding K edits must stay within K of the diagonal. First handle trivial cases: if |len(S)-len(T)| > K, answer is immediately No. The banded DP runs in O((N+M)·K) time and O(K) space with rolling rows, which is fast enough. Alternatively, a greedy LCS-based approach works, but banded DP is simplest and safest.
