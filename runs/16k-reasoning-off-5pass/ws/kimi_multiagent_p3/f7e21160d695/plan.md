The function f(x,y) is the classic "minimax" path value, which equals the maximum edge weight on the unique path between x and y in any Minimum Spanning Tree (Kruskal tree). Build the MST with Kruskal (O(M log M)), then compute all pairwise f(A_i, B_j) values efficiently: root the MST and use binary lifting to answer max-edge-on-path queries, giving a K×K cost matrix in O(K² log N). Since we can permute B freely, the problem becomes the assignment problem on a K×K matrix; however K can be up to 2×10^5, so Hungarian is infeasible — instead exploit structure: sort and use a greedy/exchange argument, or reduce via the MST structure (costs are ultrametric-like). The key insight: in a tree, minimax distances form an ultrametric, and for ultrametric cost matrices the optimal assignment can be found by sorting both sequences by a suitable key or via a divide-and-conquer on the Kruskal reconstruction tree. Use the Kruskal reconstruction tree: f(x,y) = weight of LCA of x,y in that tree; then the optimal matching pairs A's and B's within subtrees greedily (match within the same subtree at the lowest possible level), computable by a DFS merging multisets.
