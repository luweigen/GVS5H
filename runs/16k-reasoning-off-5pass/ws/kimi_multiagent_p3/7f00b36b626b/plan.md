Key observation: lcm(a,b) <= threshold implies both a,b <= threshold, so any value > threshold is an isolated node. For values <= threshold, instead of checking O(n^2) pairs, connect each value to its multiples: for each d, all present multiples of d can be unioned through d itself (treating d as a virtual hub), since lcm(x, d) = x <= threshold whenever d divides x and x <= threshold. Use a DSU over indices (or values) and iterate d from 1..threshold, unioning all present multiples of d together. Complexity is O(threshold log threshold + n α(n)). Count distinct roots among all nodes, with values > threshold remaining singletons.
