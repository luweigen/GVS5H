For each window of size x, the cheapest way to make all elements equal is to bring them to their median, so we need cost[i] = min operations for window starting at i. Compute all window costs efficiently with a sliding median structure (two heaps or order-statistics tree) in O(n log x). Then the problem reduces to: choose at least k non-overlapping windows (each of length x, so chosen start indices must differ by ≥ x) minimizing total cost — a weighted interval scheduling DP. Since k ≤ 15, use DP over positions with dimension k: dp[i][j] = min cost using windows starting at index ≥ i with j windows chosen, taking min of skipping or taking window i and jumping to i+x. Answer is dp[0][k] (taking exactly k is optimal since costs are non-negative).
