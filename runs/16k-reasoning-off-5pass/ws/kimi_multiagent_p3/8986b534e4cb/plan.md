Model each person as an interval on the line of towns: traveling from S to T, the prefix sums of edge weights along the path must be 0 at both endpoints and strictly positive at every interior town. Since the path is a contiguous segment of roads, this is equivalent to: for the edge sequence on the interval, all proper prefix sums are positive and the total sum is 0 — i.e., the interval's edge weights form a "Dyck-like" walk (positive interior, zero endpoints). The key observation is that feasibility of a set of intervals depends only on consistency constraints between overlapping intervals: two intervals that overlap impose that certain shared sub-sums match, and the positivity constraints propagate. Known solution (AtCoder AGC/ARC style): this reduces to checking that the set of intervals contains no pair where one interval's endpoint lies strictly inside another in a conflicting way — specifically, build a graph on towns where each person forces prefix-sum(S)=prefix-sum(T) (total sum 0) and prefix sums strictly increase then... Actually the clean reduction: define potential p on towns; person (s,t) requires p(s)=p(t) and p strictly between... The standard approach: intervals must be "non-crossing laminar with equal endpoints matched" — feasibility equals the condition that after sorting, we can 2-color/assign via union-find with parity, and queries reduce to range checks using precomputed "next conflicting index" arrays, answered with sparse table RMQ in O(1) each.
