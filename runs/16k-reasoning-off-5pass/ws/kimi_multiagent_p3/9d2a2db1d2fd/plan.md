Model the problem as a graph where each block is a node and walkway moves are free (0-cost) at any common floor, while stairs cost is the floor difference within a building. The key insight: for a path of blocks, the minimum stair cost equals the minimum over all "height profiles" of sum of |consecutive floor changes|, which can be decomposed using the fact that at each block you can freely pick any floor up to F. This reduces to a shortest-path problem on the grid where edge weights depend on F values, solvable via multi-source Dijkstra-like preprocessing or 0-1 BFS structure. Since Q is large (2e5) but H,W ≤ 500 (grid ≤ 250k nodes), we need an efficient per-query or precomputed all-pairs approach.
