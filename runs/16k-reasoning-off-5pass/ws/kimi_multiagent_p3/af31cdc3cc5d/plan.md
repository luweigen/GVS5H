This is a classic interval DP problem where removing adjacent pairs is equivalent to finding a maximum weight non-crossing matching on the sequence. Since N is up to 3×10^5, an O(N^2) DP is too slow, so we need a more efficient approach. The key insight is that this can be solved using a stack-based greedy approach combined with DP, where we maintain the maximum score achievable for prefixes. When we consider pairing position i with a previous position j, all elements between them must be perfectly matched among themselves. We can use a monotonic stack technique or segment tree DP to efficiently compute transitions in O(N log N) or O(N) time.
