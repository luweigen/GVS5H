The key insight is that Manhattan distance decomposes into row and column contributions, which can be summed independently. For the row part: consider any pair of distinct rows (r1, r2); the number of arrangements where two specific pieces occupy those rows (in specific cells) contributes |r1-r2| times the number of ways to fill the remaining k-2 pieces. By symmetry, count ordered column choices: two pieces in rows r1, r2 can be placed in n² cell-pairs, and remaining pieces fill C(mn-2, k-2) ways. Sum |r1-r2| over all row pairs with a closed form: for m rows, sum_{d=1}^{m-1} (m-d)·d = m²(m²-1)/6... (verify: sum_{r1<r2}(r2-r1) = C(m+1,3)-style formula = m(m²-1)/6). Total = [rowsum(m)·n² + colsum(n)·m²] · C(mn-2, k-2), all mod 1e9+7, using modular inverse for the division by 6 (or compute combinatorially). Need precomputed factorials up to mn (≤1e5) for the binomial.
