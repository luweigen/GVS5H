We need the expected distance between u and v over a uniformly random parent sequence P (each P_i ∈ [1, i-1]), multiplied by (N-1)!. Key insight: the distance equals the sum over edges e=(i, P_i) of A_i times the indicator that edge i is on the u–v path, i.e., that exactly one of u,v is in the subtree of i. By symmetry over P_i choices, we can compute, for each i, the probability that i's subtree separates u from v, using the structure that vertex i can only be an ancestor of vertices with larger indices. This yields closed-form probabilities depending only on the relative order of i, u, v, so each query is answered as a weighted sum of A_i over three index ranges with precomputable coefficients. Precompute prefix sums of A_i times those coefficients to answer each query in O(1).
