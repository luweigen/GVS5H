The problem asks us to maximize the total number of units purchased given a budget $M$ and a cost function where buying $k$ units of product $i$ costs $k^2 P_i$. Since the marginal cost of the $k$-th unit of product $i$ is $(k^2 - (k-1)^2)P_i = (2k-1)P_i$, which increases with $k$, this suggests a greedy approach. We should always pick the next cheapest available unit across all products. However, simulating unit by unit is too slow ($M$ is large). Instead, we can observe that for a specific product $i$, if we decide to buy $x$ units, the cost is $x^2 P_i$. We can binary search on the answer (total units $K$) or use a priority queue to simulate the process efficiently by jumping between products. Given the constraints and the convex nature of the cost function, a greedy strategy using a priority queue to always pick the next cheapest unit (considering the current count of each product) is optimal. We start with 0 units for all products. The cost to buy the next unit of product $i$ (currently having $c_i$ units) is $(2c_i + 1)P_i$. We repeatedly extract the minimum cost unit, add it to our total, and update the product's count, until the budget $M$ is exhausted.
