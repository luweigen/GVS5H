The problem asks for the largest subgraph of a given tree where every vertex has degree 1 or 4 (and at least one vertex has degree 4). This structure implies that the subgraph consists of a central "core" of degree-4 vertices connected by paths of degree-2 vertices, with leaves (degree-1) attached to the degree-4 vertices. Since the original graph is a tree, any subgraph is also a tree. We can model this by rooting the tree arbitrarily and using dynamic programming. For each node, we calculate the maximum size of a valid alkane component rooted at that node, considering whether the node acts as a leaf (degree 1 in the subgraph), a connector (degree 2 in the subgraph), or a hub (degree 4 in the subgraph). The key insight is that a node can only be a hub if it connects to exactly 4 branches, each contributing a valid component. We will iterate through all nodes, treating each as a potential root of the alkane, and take the maximum valid size found.
