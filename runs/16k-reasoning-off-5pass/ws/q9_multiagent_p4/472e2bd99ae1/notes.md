**Core Difficulty**: The problem asks for the $K$-th largest value among $N^3$ combinations, where $N$ is up to $2 \times 10^5$. A brute-force generation of all $N^3$ values is impossible ($8 \times 10^{15}$). Even a binary search on the answer with an $O(N^2)$ counting check per step would be too slow ($O(N^3)$ or $O(N^2 \log(\text{range}))$).

**Key Insight**: The objective function $f(i, j, k) = A_i B_j + B_j C_k + C_k A_i$ is strictly increasing with respect to each variable $A_i, B_j, C_k$ because all input values are positive integers ($\ge 1$).
This implies that the largest values of the function are formed by the largest elements of arrays $A$, $B$, and $C$. Specifically, if we sort $A$, $B$, and $C$ in descending order, the top $K$ values of the function must be composed of elements from the top $M$ indices of each array, where $M^3 \ge K$.

**Candidate Approach**:
1. Sort arrays $A$, $B$, and $C$ in descending order.
2. Determine the cutoff size $M = \lceil K^{1/3} \rceil$. Since $K \le 5 \times 10^5$, $M$ will be at most 81 (since $80^3 = 512,000$). We can safely use $M = 100$ to avoid edge cases.
3. Extract the top $M$ elements from each array.
4. Generate all $M^3$ combinations (at most $10^6$), compute the values, and sort them.
5. The $K$-th largest value is the answer.
