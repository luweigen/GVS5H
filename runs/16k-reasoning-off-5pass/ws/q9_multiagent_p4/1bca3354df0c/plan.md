The game is played on a graph that initially contains no odd cycles, meaning it is a bipartite graph. Adding an edge between two vertices $u$ and $v$ creates an odd cycle if and only if $u$ and $v$ are in the same connected component and lie on the same side of the bipartition of that component. The game ends when the graph becomes a complete bipartite graph (no more edges can be added without creating an odd cycle). The total number of moves available is the difference between the maximum possible edges in a complete bipartite graph formed by the union of all components and the current number of edges $M$. Since each move reduces the remaining moves by exactly 1, the winner is determined solely by the parity of the total number of available moves: if the count is odd, the first player (Aoki) wins; if even, the second player (Takahashi) wins.
