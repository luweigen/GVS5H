The problem asks us to select $k$ points from a given set on the boundary of a square such that the minimum Manhattan distance between any pair of selected points is maximized. This is a classic "maximize the minimum" problem, which can be efficiently solved using binary search on the answer (the distance). We will binary search for the maximum possible distance $D$. For a fixed $D$, we need to check if it's possible to select at least $k$ points such that every pair is at least $D$ apart. Since the points lie on the boundary of a square, we can traverse the perimeter in a linear order (e.g., starting from (0,0) and going clockwise) and use a greedy approach: always pick the first available point and then skip all subsequent points that are within distance $D$ of the last picked point until we either pick $k$ points or run out of candidates. The constraints allow $O(N \log(\text{max\_coord}))$ complexity, where $N$ is the number of points.
