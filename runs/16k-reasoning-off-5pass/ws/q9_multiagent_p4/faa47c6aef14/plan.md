The problem requires determining if all balls can be moved to box $X$ and finding the minimum operations. We can model this as a reachability problem on a graph where nodes are boxes. A box $u$ sends red balls to $P_u$ and blue balls to $Q_u$. We first identify all boxes that will ever contain balls by propagating the presence of red and blue balls from the initial configuration. We use a BFS to find the set of "active" boxes (boxes that ever hold balls) and update the `has_red` and `has_blue` flags for each box as we propagate. After identifying the active set, we construct a dependency graph where an edge $u \to v$ exists if box $u$ sends balls to $v$ (and $v \neq X$). We then check for cycles in this subgraph. If a cycle exists, it's impossible to empty the boxes involved (output -1). Otherwise, the answer is the number of active boxes excluding $X$.
