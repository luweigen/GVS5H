The problem asks for the minimum cost to travel from vertex 1 to vertex N in a directed graph where we can either move along an edge (cost 1) or reverse all edges (cost X). Since reversing all edges flips the direction of every edge, the state of the system can be represented by the current vertex and a boolean flag indicating whether the edges are currently reversed. This suggests a shortest path problem on a graph with $2N$ vertices (representing $N$ vertices in the original orientation and $N$ vertices in the reversed orientation). We can use Dijkstra's algorithm to find the minimum cost from the start state $(1, \text{false})$ to any state where the vertex is $N$ (either $(N, \text{false})$ or $(N, \text{true})$).
