The problem requires calculating the sum of absolute differences between elements of two sequences for multiple range queries. A naive $O(N \cdot K)$ approach will be too slow given the constraints. Instead, we can precompute prefix sums of the sorted versions of sequences A and B. By sorting both arrays, the absolute difference $|A_i - B_j|$ can be split into cases where $A_i \le B_j$ and $A_i > B_j$. Using binary search (specifically `bisect_right`), we can efficiently determine the split point in the sorted array B for any given $A_i$ (or vice versa) to calculate the contribution of a prefix of A against a prefix of B in $O(\log N)$ time per query, leading to an overall complexity of $O(N \log N + K \log N)$.
