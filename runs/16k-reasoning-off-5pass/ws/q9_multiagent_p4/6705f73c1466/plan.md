The problem asks for the minimum number of swaps to make all '1's contiguous. This is equivalent to moving all '1's to a specific window of size $K$ (where $K$ is the total count of '1's) in the string. The cost to move a '1' from its current position to a target position is the absolute difference between their indices. To minimize the total swaps, we should choose a target window such that the sum of distances from all '1's to their positions within that window is minimized. This is a classic problem solvable by trying every possible starting position for the contiguous block of '1's and calculating the cost efficiently using prefix sums or a sliding window approach.
