The problem requires counting triplets $(A, B, C)$ from a given set $S$ such that $B-A = C-B$, which simplifies to $A+C = 2B$. Since the constraints on $N$ and $S_i$ are up to $10^6$, an $O(N^2)$ solution is too slow. We should sort the array $S$ first. Then, we can iterate through each element $B$ and count how many pairs $(A, C)$ exist in the sorted array such that $A = B-d$ and $C = B+d$ for some $d > 0$. Using a frequency array (or hash map) allows us to check the existence of $A$ and $C$ in $O(1)$ time. Alternatively, since the values are bounded by $10^6$, we can use a direct frequency array to count occurrences of each number and then iterate through possible values of $B$ and $d$.
