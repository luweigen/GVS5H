The problem involves simulating insertions into an array, which would be $O(N^2)$ if done naively. Instead, we can work backwards from the final state. Since the last inserted element $N$ is always at position $P_N$ (1-indexed) in the final array, we can determine its position. Then, considering the array just before the last insertion, the element $N-1$ was at position $P_{N-1}$, but we must account for the shift caused by inserting $N$ if $N$ was placed before $N-1$. By iterating backwards from $N$ to $1$, we can calculate the final index for each number $i$ by adjusting its target position $P_i$ based on how many subsequent numbers (from $i+1$ to $N$) were inserted at positions less than or equal to the current calculated position of $i$. A Fenwick tree or simple difference array can efficiently manage these position shifts.
