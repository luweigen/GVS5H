Since $N$ is small ($N \le 30$) and $M$ is also small ($M \le 100$), we can iterate on the possible answer $D$ (the shortest distance from 1 to N). For a fixed $D$, we check if it's possible to select $K$ edges with weight 1 such that the shortest path from 1 to N is at least $D$. This check can be modeled as a maximum flow problem: construct a network where edges in any shortest path of length $< D$ must be "blocked" (assigned weight 1). If the maximum number of edges we can force to be weight 1 without violating the constraint that a path of length $< D$ still exists is less than $K$, then $D$ is achievable. We binary search for the maximum $D$.
