
## ideation
Core Difficulty:
1. Finding the longest path with unique values in a tree requires efficient state management during DFS.
2. A naive set copy per node is O(N^2). We must use backtracking with a single mutable set/map.
3. The "longest path ending at u" logic depends on the most recent ancestor with the same value. If a duplicate exists, the path must start at the child of that ancestor. If not, it extends the path from the parent.
4. We need to efficiently calculate the length and node count of the segment starting after the duplicate ancestor. This requires storing the distance and depth of the *child* of the duplicate ancestor in our state map (`last_pos`).

Candidate Approaches:
1. **DFS with Backtracking and Map:**
   - Maintain `last_pos`: dict mapping `value` -> `(depth_of_child_of_duplicate, dist_from_root_of_child_of_duplicate)`.
   - Maintain `dp[u]`: tuple `(length, nodes)` for the longest special path ending at `u`.
   - Global `max_len` and `min_nodes`.
   - Recurrence:
     - At node `u` (depth `d`, dist `dist`):
       - If `nums[u]` in `last_pos`:
         - `start_d, start_dist = last_pos[nums[u]]`
         - `curr_len = dist - start_dist`
         - `curr_nodes = d - start_d + 1`
       - Else:
         - If `u` is not root: extend `dp[parent]` by adding edge weight and 1 node.
         - Else (root): `curr_len = 0`, `curr_nodes = 1`.
       - Update global max/min.
       - Store `dp[u]`.
       - For each child `v` with weight `w`:
         - Save `old_last_pos = last_pos.get(nums[u])`
         - If `nums[u] == nums[v]` (actually check `nums[u]`):
           - `last_pos[nums[u]] = (d + 1, dist + w)`
         - Else:
           - `last_pos[nums[u]] = old_last_pos` (restore if not present)
         - Recurse
         - Restore `last_pos[nums[u]] = old_last_pos`
   - Time: O(N), Space: O(N).

Pitfalls:
- Recursion depth limit in Python (need `sys.setrecursionlimit`).
- Correctly handling the "start after duplicate" logic (depth/node count formulas).
- Backtracking the `last_pos` map correctly (only update if the current node's value dictates a new start point for children).
- Edge cases: single node, all values same, all values unique.

The solution implements a Depth-First Search (DFS) traversal to find the longest special path (a downward path with unique node values). 
1.  **State Management**: We maintain `last_pos`, a dictionary mapping a node value to the `(depth, distance_from_root)` of the most recent node with that value encountered on the current path. This allows us to efficiently determine the start of the valid unique segment.
2.  **Path Calculation**:
    *   If `nums[u]` is in `last_pos`, the longest special path ending at `u` starts at the child of the previous occurrence of `nums[u]`. The length is `dist[u] - dist[prev_child]` and node count is `depth[u] - depth[prev_child] + 1`.
    *   If `nums[u]` is not in `last_pos`, the path extends from the parent. The length is `dp[parent].length + weight` and node count is `dp[parent].nodes + 1`.
3.  **Backtracking**: Since we need to explore multiple branches from a node, we must restore the `last_pos` dictionary to its state before visiting the current node after returning from children. This ensures that paths in different subtrees are calculated correctly based on the unique values from the root to the current branch.
4.  **Complexity**: Time complexity is O(N) as we visit each node once. Space complexity is O(N) for the recursion stack, adjacency list, and `last_pos`/`dp` arrays.

The solution implements a Depth-First Search (DFS) traversal to find the longest special path (a downward path with unique node values).
1.  **State Management**: We maintain `last_pos`, a dictionary mapping a node value to the `(depth, distance_from_root)` of the most recent node with that value encountered on the current path. This allows us to efficiently determine the start of the valid unique segment.
2.  **Path Calculation**:
    *   If `nums[u]` is in `last_pos`, the longest special path ending at `u` starts immediately after the previous occurrence. The length is `dist[u] - dist[prev_child]` and node count is `depth[u] - depth[prev_child] + 1`. Note that `last_pos` stores the position of the *child* of the duplicate ancestor to facilitate this calculation directly.
    *   If `nums[u]` is not in `last_pos`, the path extends from the parent. The length is `dp[parent].length + weight` and node count is `dp[parent].nodes + 1`.
3.  **Backtracking**: Crucial for correctness. Before recursing into children, we update `last_pos`. After returning from all children, we restore `last_pos` to its state before entering `u`. This ensures that paths in different subtrees are calculated based on the unique values from the root to the current branch, not polluted by values from sibling branches.
4.  **Complexity**: Time complexity is O(N) as we visit each node once. Space complexity is O(N) for the recursion stack, adjacency list, and `last_pos`/`dp` arrays.
5.  **Edge Cases**: Handles single node trees, all values same, all values unique, and deep trees (via recursion limit increase).
