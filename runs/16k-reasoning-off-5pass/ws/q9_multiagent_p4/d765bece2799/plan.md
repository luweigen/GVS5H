The problem requires summing the min and max of all subarrays with length at most $k$. A naive $O(N^2)$ approach checking every subarray will be too slow given $N \le 80,000$. We need an efficient approach, likely $O(N)$ or $O(N \log N)$. We can iterate through each element as the "right" endpoint of a subarray and efficiently query the minimum and maximum within the valid window $[i-k+1, i]$. A monotonic deque (sliding window minimum/maximum) is the standard technique to find min/max in a sliding window in amortized $O(1)$ time. We will maintain two deques: one for the minimums and one for the maximums in the current valid window ending at index $i$. For each $i$, we add the current element to both deques (maintaining monotonicity), remove elements that fall out of the window (indices $< i-k+1$), and then add `nums[deque_min[0]] + nums[deque_max[0]]` to the total sum.
