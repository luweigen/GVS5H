The problem asks for the minimum number of global character replacement operations to transform string S into string T. First, we must verify feasibility: for every index i, if S[i] differs from T[i], we can map S[i] to T[i]. However, a global replacement of character 'x' to 'y' affects ALL occurrences of 'x' in S. Therefore, if two different positions i and j have S[i] == S[j] but T[i] != T[j], it's impossible because replacing S[i] would also change S[j] incorrectly. If feasible, the minimum operations correspond to the number of unique characters in S that need to be changed to match their corresponding characters in T, considering that one operation can fix multiple positions if they share the same source character. We calculate the set of source characters that need changing and the set of target characters they must become, ensuring a valid mapping exists.
