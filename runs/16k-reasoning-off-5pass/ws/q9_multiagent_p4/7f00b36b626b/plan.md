The core challenge is efficiently determining connectivity between nodes where an edge exists if `lcm(a, b) <= threshold`. Since `lcm(a, b) = (a * b) / gcd(a, b)`, the condition implies that for large numbers, edges are rare unless the numbers share large common factors or are small. Given the constraint `threshold <= 2 * 10^5`, any number greater than `threshold` cannot form an edge with any other number (since `lcm(a, b) >= max(a, b)`), so such nodes are isolated components. For numbers `<= threshold`, we can use a Disjoint Set Union (DSU) structure. To avoid an O(N^2) check, we iterate through each number `x` up to `threshold` and try to connect it with its multiples `k*x` (where `k*x <= threshold`). If both `x` and `k*x` exist in the input array, we union their sets. Finally, we count the number of disjoint sets, adding 1 for each number in `nums` that is greater than `threshold`.
