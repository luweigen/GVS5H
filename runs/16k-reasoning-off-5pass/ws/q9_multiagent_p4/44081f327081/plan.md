The problem requires finding the maximum GCD of a subset of size K that includes a specific element $A_i$ for each $i$. Since $A_i \le 10^6$, we can iterate through all possible GCD values $g$ from 1 to $10^6$. For each $g$, we count how many elements in the array are multiples of $g$. If the count is at least $K$, then $g$ is a candidate answer for any $A_i$ that is itself a multiple of $g$. To optimize, we precompute the frequency of each number and then use a sieve-like method to count multiples for every $g$. Finally, for each $A_i$, we find the largest $g$ such that $A_i$ is a multiple of $g$ and the count of multiples of $g$ in the array is $\ge K$.
