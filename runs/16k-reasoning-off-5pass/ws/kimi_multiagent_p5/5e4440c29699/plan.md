The blocks form the rectangle [0,W]×[0,H] minus the interior rectangle L≤x≤R, D≤y≤U (note boundary columns/rows x<L, x>R, y<D, y>U remain). Every monotone path ends at a "maximal" block — one whose right and up neighbors are both absent — and each path is uniquely determined by its endpoint plus the sequence of moves, so the answer equals the sum over all blocks of the number of monotone paths ending there, which equals the sum over maximal blocks T of (number of starts)×(paths from start to T) summed appropriately. A cleaner formulation: total = Σ over all blocks s of (number of paths starting at s) = Σ over maximal blocks t of Σ_{s≤t} paths(s→t); using the standard trick, Σ_{s} paths(s→t) = C(tx+ty+2, tx+1) style identities let us compute, for each maximal block, the total paths from all valid starts via binomial coefficients minus the forbidden-rectangle contributions. The forbidden rectangle affects only paths that would pass through it; we handle this by inclusion-exclusion / reflection: paths from (0,0)-region to a target avoiding the hole can be computed with the classical two-corner subtraction (enter via (L-1→L) crossing or (D-1→D) crossing), giving an O(1) formula per maximal block. Maximal blocks are O(1) in number: corners like (W,H), (L-1,H) if valid, (W,D-1), (R, U) region edges, etc. — specifically points where x∈{W, R} boundary and y∈{H, U} boundary combinations that are blocks. We precompute factorials up to W+H+2 and evaluate each maximal block's contribution with the hole-avoiding path-count formula.
