A 400 number has the form p^(2a) * q^(2b) = (p^a * q^b)^2, so it is exactly a perfect square whose square root has exactly two distinct prime factors. Thus the answer to a query A is m^2 where m = floor(sqrt(A)) reduced downward until m has exactly two distinct prime factors. Since A ≤ 10^12, m ≤ 10^6, so we can sieve smallest prime factors up to 10^6 once, then answer each query by decrementing m (at most a few hundred steps in practice, but we should bound it) and counting distinct prime factors via SPF factorization. To guarantee speed, we can precompute for every m from 1 to 10^6 whether it has exactly two distinct prime factors, and then precompute prev[m] = largest index ≤ m that qualifies; each query is then just prev[isqrt(A)] squared, O(1) per query.
