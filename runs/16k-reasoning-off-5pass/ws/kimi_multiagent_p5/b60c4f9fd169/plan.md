This is a bounded edit distance problem: determine if Levenshtein distance (insert/delete/replace, each cost 1) between S and T is at most K, with K ≤ 20 but strings up to 500k characters. First, if |len(S) - len(T)| > K, answer is immediately No. Otherwise, compute edit distance with the standard banded DP: only cells with |i - j| ≤ K can have value ≤ K, so we compute a diagonal band of width 2K+1, giving O((N+M)·K) time and O(K) memory. If any cell in a row's band exceeds K we can cap values at K+1 to keep arithmetic simple. Finally answer Yes iff dp[N][M] ≤ K.
