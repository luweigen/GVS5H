Model each row as a W-bit mask. Row flips (X) and column flips (Y) commute, so the final grid is determined by a row-flip vector r and a column-flip vector c, with final cell = A_ij XOR r_i XOR c_j. Since W ≤ 18, enumerate all 2^W column-flip patterns c; for each, every row independently chooses r_i ∈ {0,1} to minimize its popcount, i.e. contributes min(popcount(m XOR c), W − popcount(m XOR c)). Sum over rows and take the minimum over all c. With H up to 2·10^5, precompute a frequency table of row masks (size 2^W ≤ 262144) so the total cost is O(4^W / … ) — more precisely O(2^W · number_of_distinct_masks) ≤ about 6.9·10^7 worst case, which is acceptable in optimized form; alternatively compute per-c sums via iterating over distinct masks only.
