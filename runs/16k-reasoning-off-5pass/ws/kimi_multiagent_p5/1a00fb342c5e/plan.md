XOR constraints decompose per bit, so solve each bit independently as a system of equations over GF(2): for each bit b, variables a_i ∈ {0,1} with a_{X_i} ⊕ a_{Y_i} = bit b of Z_i. Build a DSU with parity (union-find storing xor-to-parent) per bit to check consistency and, for each connected component, compute the two possible assignments (root = 0 or 1) and their costs. To minimize total sum, for each component and bit choose the assignment with fewer ones (free choice), unless the component is forced (self-loop constraint X_i = Y_i with Z_i bit 1 forces a_{X_i}=1, or parity contradiction → -1). Combine bits to reconstruct A. Complexity O((N + M) · B) with B ≈ 30 bits, which is acceptable in optimized Python if we share the graph structure across bits and only recompute parities.
