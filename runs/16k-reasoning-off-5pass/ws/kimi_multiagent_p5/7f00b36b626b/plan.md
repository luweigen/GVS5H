Since threshold ≤ 2·10⁵, any edge requires lcm(a,b) ≤ threshold, so both endpoints must be ≤ threshold; nodes with value > threshold are always isolated. Key trick: instead of checking pairs, group numbers by their divisors — if gcd(a,b)=1 then lcm=a·b, but more generally we can union numbers sharing a common divisor d when their "co-factors" allow it. The cleanest approach: for each value v ≤ threshold present in nums, iterate over its multiples m = v, 2v, 3v... up to threshold; if m is also present, then lcm(v, m) = m ≤ threshold, so union them. But that only handles divisibility pairs. The full solution: for each d from 1 to threshold, collect all present multiples of d; the smallest such multiple s satisfies lcm(s, m) ≤ m·s/d... Actually the standard known solution: for each d, find the smallest present multiple s of d; for every other present multiple m of d, lcm(s, m) ≤ m (no)... The correct known result: union s with m whenever s·m/d ≤ threshold, and since s is the smallest multiple of d, if any multiple of d can pair via divisor d, s works. Then count DSU components over all n nodes (values > threshold stay singletons).
