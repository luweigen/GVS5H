The path weight is the maximum edge on the path, so f(x,y) equals the minimax distance, which is exactly the maximum edge weight on the unique path between x and y in any Minimum Spanning Tree (Kruskal tree). Build the MST with Kruskal (O(M log M)), then compute all K² pairwise f values between A-vertices and B-vertices via binary lifting on the MST (O((N + K²) log N)). Since A_i ≠ B_j for all pairs, no zero-cost self-assignments complicate things; the problem reduces to a minimum-cost perfect matching (assignment problem) on a K×K cost matrix, solvable with the Hungarian algorithm in O(K³). Note K can be up to N = 2·10⁵, so we must check feasibility: if K is large (say > 500), Hungarian is too slow — but since cost values are minimax distances, they take at most N-1 distinct edge-weight values; investigate a greedy/structure-based matching for large K, or note the intended constraint likely keeps K small. Workers should verify the K bound and design accordingly.
