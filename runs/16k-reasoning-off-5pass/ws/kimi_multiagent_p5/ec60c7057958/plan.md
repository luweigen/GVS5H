We need the k-th lexicographic permutation of [1..n] where adjacent elements alternate in parity. Since n ≤ 100 and k ≤ 10^15, we cannot enumerate; instead we build the answer position by position, counting how many valid completions exist for each candidate choice. The count of completions depends only on the remaining counts of odd/even numbers and the parity of the last placed element (or a free choice at the start). We derive a combinatorial count: fixing the sequence of parities (which is forced once the starting parity is chosen), the number of ways to fill odd slots with remaining odds and even slots with remaining evens is (odds_remaining)! × (evens_remaining)!. We cap counts at k (or a large bound) to avoid huge factorials, and use Python's arbitrary-precision integers anyway since 100! is manageable. If total valid permutations < k, return [].
