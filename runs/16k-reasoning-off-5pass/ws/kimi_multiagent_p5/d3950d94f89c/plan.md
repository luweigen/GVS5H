Root the tree at 0 and do a single DFS maintaining the current root-to-node path. A special path is a contiguous suffix of this current path whose node values are all distinct, so keep a sliding window over the current path using last occurrence of each value. For each node, the best valid downward path ending at that node starts just after the most recent blocked position; update the global answer with (distance, node count), preferring larger distance then fewer nodes. Use depth-first traversal with explicit stack or recursion with increased limit, storing prefix distances and parent info. Each edge is processed once, and window updates are amortized O(1), giving O(n) time.
