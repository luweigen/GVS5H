**Model.** Adjacent swaps generate all permutations, and deleting a proper prefix of a constant run is never better than deleting the whole run (same 1 operation, removes more). Hence the answer equals `min_B [inv(A,B) + runs(B)]` over multiset permutations B. This was verified exhaustively against BFS over the actual operation graph for all binary strings up to length 6.

**DP.** Let `dp[i]` = min operations to delete prefix `A[:i]`. The last operation either:
1. deletes `A[i-1]` alone: `dp[i-1] + 1`; or
2. after removing prefix `A[:j]`, gathers **all** copies of `v = A[i-1]` in the window `A[j..i-1]` to the front and deletes them in one operation. Taking all `v`'s in the window is WLOG: a leftover `v` would need its own future deletion and only adds swaps.

The gather cost is the number of pairs `(p,q)`, `j ≤ p < q ≤ i-1`, `A[p] ≠ v`, `A[q] = v`, which decomposes as
`swaps_v(j,i) = H_v(i) - H_v(j) - nv(j)·(cv(i) - cv(j))`
where `cv(i)` = count of `v` in `A[:i]`, `nv(j) = j - cv(j)`, and `H_v(i)` = # of (non-v before v) pairs with `q ≤ i-1`.

So candidate(j) is a **line** in `x = cv(i)`: slope `-nv(j)`, intercept `dp[j] - H_v(j) + nv(j)·cv(j)`, plus constants `H_v(i) + 1`. As `i` grows, slopes are added in nonincreasing order and query `x = cv(i)` is nondecreasing, so a monotone convex hull trick with a per-value pointer gives amortized O(1) per step.
