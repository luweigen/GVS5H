This is a reachability problem on a line with huge N but small step range (B ≤ 20) and few bad intervals (M ≤ 2×10⁴, disjoint and sorted). The key insight: reachable positions form intervals; from a reachable interval [l, r], the next reachable positions are [l+A, r+B] minus bad squares. Since bad intervals are disjoint and sorted, we can sweep through them, maintaining the current reachable range as an interval (clipped to non-bad regions). Between consecutive bad intervals, the reachable set is a contiguous interval that expands by [A, B] each "generation," but we can compute directly: reachable interval after crossing a gap is intersection/expansion arithmetic. If the reachable interval ever becomes empty or cannot jump over a bad interval (gap needed exceeds B − A reach), answer is No. Process each bad interval: trim reachable range to before the interval, check if we can jump past it (need some reachable x with x + i > R_i, i.e., r + B > R_i after stepping), then continue. Finally check N is reachable.
