## worker: Implement and deliver the final Python solution: p
- Maintain the reachable set as a contiguous interval `[lo, hi]` (invariant: every integer in it is reachable, and nothing relevant outside it is). Initially `[1, 1]`.
- For each bad interval `[L, R]` (disjoint, sorted, and `1 < L ≤ R < N`):
  - Usable launch squares are reachable positions `< L`, so cap `h = min(hi, L-1)`.
  - Windows `[x+A, x+B]` for integer `x` in `[lo, h]` union to the contiguous `[lo+A, h+B]` (since `A ≤ B`, consecutive windows overlap/touch).
  - Crossing is possible iff `h + B > R` (and `h ≥ lo`); otherwise `No`.
  - After crossing, reachable squares past `R` are `[max(R+1, lo+A), h+B]`, which becomes the new `[lo, hi]`.
- After all intervals, `N` (guaranteed not bad) is reachable iff `N ∈ [lo, hi]` or one final move lands on it: `lo + A ≤ N ≤ hi + B` (with `hi` capped at `N`). This also correctly handles `M = 0` (e.g., `N < 1 + A` gives `No`).
- Complexity: `O(M)` time, `O(1)` extra space; all arithmetic, so `N ≤ 10^12` is fine.
