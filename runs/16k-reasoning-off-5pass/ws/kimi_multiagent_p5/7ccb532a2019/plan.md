Model the problem as choosing final target counts per letter, where each letter ends with either 0 occurrences or exactly k occurrences for some common k. Since deletions and insertions cost 1 and changing a character to a later letter costs the alphabet distance, we can compute the minimum cost to transform the current 26 counts into a chosen target vector. The answer is the minimum over all feasible uniform positive targets k, plus the all-delete option. Because only forward shifts are allowed, a letter can only receive extra characters from earlier letters, so a DP over letters with bounded carry/flow is natural. We need an efficient way to evaluate candidate k values without doing an expensive 26-state DP for too many k.
