Factor the equation as x³−y³ = (x−y)(x²+xy+y²) = N. Let d = x−y ≥ 1; then d must divide N, and writing x = y+d gives 3y² + 3dy + d² = N/d. This is a quadratic in y with discriminant D = 12N/d − 3d², which must be a non-negative perfect square, and y = (−3d + √D)/6 must be a positive integer. Since x²+xy+y² ≥ x² > (N)^(2/3)-ish, we get d ≤ N^(1/3) (because N = (x−y)(x²+xy+y²) > d·d²... precisely x²+xy+y² > x² ≥ d², so d³ < N). So we only need to check divisors d of N with d ≤ N^(1/3). To enumerate divisors up to the cube root of N ≤ 10^18 (cube root ≤ 10^6), we can simply iterate i from 1 to 10^6 and test i | N — that's only 10^6 iterations, fast enough in Python. For each qualifying divisor, check the perfect-square and integrality conditions.
