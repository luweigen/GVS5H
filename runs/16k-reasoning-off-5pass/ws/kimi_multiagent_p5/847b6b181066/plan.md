Model the smoke as a set of "birth times": smoke generated at time k (at (0,0)) occupies position (prefix displacement from time k+1 to t) at time t+0.5. Smoke exists at (R,C) at time t+0.5 iff there is some birth time k (0 ≤ k ≤ t, where k=0 is the initial smoke) such that the wind displacement over (k, t] equals (R,C), and crucially the campfire was empty at time k (for k ≥ 1) so smoke was actually generated. Track the set of active birth offsets incrementally: maintain a set of positions relative to current time, shift by wind each step, add birth at origin when empty, and query whether (R,C) is in the set. Use a hash set of integer-encoded coordinates for O(1) operations, giving O(N) total.
