For each window of size x, the minimum cost to make all elements equal is achieved by raising/lowering all elements to the window's median; compute this cost for every starting index i (0..n-x) efficiently using two heaps (or an order-statistics structure) with lazy deletion as the window slides. Then the problem reduces to: choose at least k non-overlapping windows (start indices differ by >= x) minimizing total cost — a classic weighted interval scheduling DP. Since k <= 15, use DP over positions with dimension k: dp[i][j] = min cost considering windows starting at index <= i having chosen j windows; transition dp[i+x][j+1] = min(dp[i][j] + cost[i]). Answer is min over i of dp[i][k]. Total complexity O(n log x + n*k).
