Model the problem as a directed graph on 26 letters: for each position i, S[i] must eventually map to T[i], so add a constraint edge S[i]→T[i]. If any letter has two different required targets (out-degree ≥2), it's impossible. The final mapping f must be consistent with these constraints, meaning every constraint path must end at its required target; if following the chain from a letter ends at a different letter than required, impossible. Each letter with f(x)≠x needs at least one operation, and each directed cycle in f (where every letter must change) needs one extra operation to break the cycle using a temporary letter—unless a spare letter (one unused in S and T, or one that maps to itself) exists to use as buffer, in which case no extra is needed. Compute the answer as (number of letters that change) + (number of cycles among changed letters) if no free buffer letter exists, else just the number of changed letters.
