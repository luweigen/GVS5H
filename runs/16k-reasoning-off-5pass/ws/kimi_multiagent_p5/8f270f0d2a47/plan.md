We need count of n in [l, r] where digit product % digit sum == 0. Since r < 1e9, numbers have at most 9 digits, so digit sum ≤ 81 and digit product ≤ 9^9 ≈ 3.9e8. Use digit DP over the decimal string of the bound with states (position, tight, started, sum, product). Key trick: if any digit is 0 (after start), product becomes 0, which is divisible by any positive sum — collapse that into a boolean flag to keep product state bounded. Answer = f(r) - f(l-1), where f(x) counts beautiful numbers in [1, x].
