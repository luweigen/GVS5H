This is a weighted interval scheduling variant with at most 4 intervals, requiring lexicographically smallest index list among max-weight solutions. Sort intervals by right endpoint (tie-break by index for determinism) and compute for each interval the previous compatible interval via binary search (r_prev < l_cur, since touching boundaries counts as overlapping). Run DP over sorted intervals with states (position, count 0..4), storing both max weight and the lexicographically smallest index list achieving it. When comparing candidate lists, note that chosen indices are naturally increasing in time order, so compare lists element-wise with the rule that a prefix-shorter list is smaller. Reconstruct the answer from the DP table at state (n, 4) — but since "at most 4" and weights are positive, also consider fewer counts; actually with positive weights the best uses as many as beneficial, so take max over counts 1..4 with lexicographic tie-break.
