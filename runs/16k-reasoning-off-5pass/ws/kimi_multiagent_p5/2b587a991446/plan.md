Model the problem as a shortest-path search on the "configuration graph" whose vertices are ordered pairs (a, b) with a != b, where a is piece A's vertex and b is piece B's vertex. A move changes exactly one coordinate to an adjacent vertex, keeping the two coordinates distinct; the goal is (T, S) from (S, T). The full state space is O(N^2), too large, so exploit structure: BFS from the target (T, S) on the product graph, but prune using the observation that the answer relates to distances d(S,T) and the existence of a vertex where the two paths can "pass" each other. Key insight: the two pieces must swap; they can only pass each other if the graph has a cycle (non-tree) or a vertex of degree >= 3 allowing a "passing" maneuver; on a tree, swapping is possible iff there's a branching point on/near the S-T path, with extra cost. Concretely: compute the S-T path; if the graph is just that path (all relevant degrees 2), answer is -1 unless a detour exists; otherwise answer = dist(S,T) + 2 * (extra detour cost). Implement BFS on the original graph for distances, then a careful case analysis, validated against a small-state BFS for tiny N.
