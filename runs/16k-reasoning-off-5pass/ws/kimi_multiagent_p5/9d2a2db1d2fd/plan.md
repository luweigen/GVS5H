Model the problem as a graph where each block is a node and floors are levels. The key insight is that walkways are free and preserve floor level, while stairs cost 1 per floor change. For a query from (A,B,Y) to (C,D,Z), we need to find the minimum stair usage. This can be solved using a multi-source Dijkstra-like approach or by transforming the problem into a shortest path problem on a grid where the cost to move between adjacent blocks depends on the floor levels. Precompute distances using a priority queue for efficiency, handling up to 500x500 grid and 2e5 queries.
