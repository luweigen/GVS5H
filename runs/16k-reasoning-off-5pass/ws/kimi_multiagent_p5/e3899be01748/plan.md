For each ending position j, count how many starting positions i make the substring s[i..j] divisible by its last digit d = s[j]. If d is '0', no substring ending at j qualifies (division by zero / non-zero last digit required). Otherwise, we need the numeric value of s[i..j] mod d to be 0. Since d is a single digit (1-9), we can maintain the remainder of the prefix ending at j modulo d incrementally, but the modulus changes per position. Key insight: for each j with digit d, value of s[i..j] mod d = (prefix_mod[j] - prefix_mod[i-1] * 10^(j-i+1)) mod d — instead, simpler: iterate i from j backwards accumulating value mod d, but that's O(n^2). Better: for each j, value mod d depends on (s[i..j-1] * 10 + d) mod d = (s[i..j-1] * 10) mod d, so substring s[i..j] divisible by d iff number formed by s[i..j-1] * 10 ≡ 0 mod d, i.e., s[i..j-1] mod (d/gcd(d,10)) condition. Since d ∈ 1..9, d/gcd(d,10) ∈ {1,2,3,5,7,9} small set — we can precompute prefix remainders modulo each m in {1,2,3,7,9} (and handle 5 via last digit checks) and count with frequency maps. Actually cleanest: for each j, required condition is prefix_value(i..j) mod d == 0; maintain running remainder r = (r*10 + digit) mod d only works for fixed d. Instead, for each j, walk backwards at most... no. Use the math: s[i..j] mod d = (P[j] - P[i-1] * 10^{len}) mod d where P is prefix mod d. For each j, we need count of i ≤ j with P[i-1] * 10^{j-i+1} ≡ P[j] (mod d). Since 10^k mod d cycles with small period (≤4 for digits 1-9, since d≤9), we can group by (k mod period, P[i-1] value). Maintain counts indexed by (position mod period, prefix remainder) for each modulus d — but d varies per j. Alternative simpler approach: for each j, only need remainders mod d where d ≤ 9; precompute prefix mods for all d in 1..9 (9 arrays), and for each j use cycle structure of 10^k mod d. Since period of 10 mod d for d≤9 divides 6 (actually lcm of periods ≤ 6), we can maintain for each d a 2D counter [k mod period][remainder] of prefix indices, update per position, and query. Total O(n * 9 * period) = O(n).
