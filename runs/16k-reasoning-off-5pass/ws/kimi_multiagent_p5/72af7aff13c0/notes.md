This is a dynamic version of the classic "sum of products over monotone paths" DP. Static answer: dp[h][w] = A[h][w]·(dp[h-1][w] + dp[h][w-1]), answer = dp[H][W]. With Q up to 2e5 point updates (given as a walk), we need fast per-query answers.

Key facts and observations:

- A point update at cell c changing value old→v changes the answer by Δ = (v−old)·L_ex[c]·R_ex[c], where L_ex[c] = sum of path-products from (1,1) to c excluding A[c], and R_ex[c] = sum from c to (H,W) excluding A[c]. So answering is O(1) *if* we know L_ex[c], R_ex[c] for the queried cell.

**Refutation of O(1)/O(min(H,W)) walk-based incremental repair:**

There is no local recurrence letting you patch L from a neighbor in O(1), because the perturbation propagates through the bilinear recurrence L[x] = A[x](L[up]+L[left]) — the delta itself satisfies ΔL[x] = A[x](ΔL[up]+ΔL[left]) with source ΔL[c]=δ·L_ex[c]. So the stale region is the full cone, size Θ(HW) worst case. The walk structure gives no amortized bound: an adversarial walk can alternate between (1,1)-ish and (H,W)-ish regions, and each step's cone is Θ(HW).
