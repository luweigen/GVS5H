The key insight is that deleting all occurrences of value x only helps if it "bridges" segments separated by x, letting a subarray skip over negative contributions. For each distinct value x, the best subarray after deleting x consists of segments between occurrences of x; we need the max subarray sum of the array with all x's removed, which equals the best way to join consecutive "gaps" (max subarray sums of segments between x's) — but only when bridging is beneficial. Compute for each x the list of segment maxima (Kadane per segment between occurrences), then the answer for x is the max over: best single segment, and best concatenation of adjacent segments (prefix/suffix sums around each occurrence). Combine with the no-deletion Kadane answer. Total work is O(n) since segments partition the array per distinct value.
