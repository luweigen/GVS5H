Binary search on the answer L (minimum achievable longest run length). For a candidate L, decide if we can flip at most numOps bits so every maximal run has length ≤ L. Key insight: for L ≥ 2, within each original run of identical characters of length m, we must flip some positions so no sub-run of the original char exceeds L; the minimum flips for that run is floor(m / (L+1)) (place flips every L+1 positions), and these subproblems are independent, so total flips = sum over runs. For L = 1 the string must alternate; compare against both alternating patterns ("0101..." and "1010...") and take the minimum flips. Binary search L in [1, n] and return the smallest feasible L.
