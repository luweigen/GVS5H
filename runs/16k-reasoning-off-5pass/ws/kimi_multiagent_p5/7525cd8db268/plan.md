For a fixed set of pairs, valid subarrays can be counted by sweeping the right endpoint r from 1..n and maintaining the smallest allowed left endpoint L: each pair (a,b) forbids left endpoints ≤ min(a,b) once r ≥ max(a,b), so L = max over active pairs of (min+1), and each r contributes r-L+1. Removing one pair only changes the constraint at positions r ≥ max(a,b), so we need, for each r, the maximum and second maximum of (min(a,b)+1) among pairs with max(a,b) ≤ r, plus how many pairs attain the max. Then the gain from deleting a pair is the sum over r where it is the unique max of (secondMax - max).
