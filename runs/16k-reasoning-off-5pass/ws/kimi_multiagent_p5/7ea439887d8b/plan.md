Model the problem as a shortest-path problem on an expanded state graph where each state is (vertex, parity), with parity indicating whether edges are currently reversed. From state (v, 0) we can traverse original edges v→u with cost 1; from (v, 1) we can traverse reversed edges (i.e., original u→v) with cost 1; and from either parity we can flip parity at the same vertex with cost X. Run Dijkstra from (1, 0) over these 2N states using both adjacency lists (out-edges and in-edges), and answer min(dist[N][0], dist[N][1]). Use 64-bit integers (Python ints are unbounded) and a heap for O((N+M) log N) performance.
