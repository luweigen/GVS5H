We need max over i<j of L(i)+M(i+1,j)+R(j+1), where L is prefix distinct count, R is suffix distinct count, and M is the distinct count of the middle segment. Compute prefix distinct counts P[i] and suffix distinct counts S[j] in O(N). The middle distinct count for segment (i+1..j) equals (number of values whose first occurrence is > i and last occurrence <= j... ) — better: distinct in [l,r] = count of values v with first occurrence >= l and last occurrence <= r, i.e., values fully contained in [l,r]. So total = P[i] + S[j+1] + (values with first >= i+1 and last <= j). For each value, define interval [first, last]; it contributes 1 to the middle iff i+1 <= first and last <= j, i.e., i <= first-1 and j >= last. So answer = max over i<j of P[i] + S[j+1] + (# intervals with first >= i+1, last <= j). Sweep j from 2..N-1, maintaining a data structure over i: for each j, intervals with last == j get "activated" by adding +1 to all i <= first-1 (range add on prefix), then query max over i in [1, j-1] of P[i] + active[i], and add S[j+1]. Use a segment tree with lazy propagation for range add and range max query, giving O(N log N) total.
