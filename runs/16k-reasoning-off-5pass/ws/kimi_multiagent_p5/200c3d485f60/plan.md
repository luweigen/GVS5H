The key insight is to think of the array as a sequence of "runs" of equal values. If exactly k adjacent pairs are equal, then there are exactly n - k runs (blocks of consecutive equal elements). The first run can have any of m values, and each subsequent run must differ from the previous one, giving (m - 1) choices each. We also need to choose which k of the n - 1 adjacent positions are "equal" positions, which is C(n - 1, k). So the answer is C(n - 1, k) * m * (m - 1)^(n - k - 1) mod (10^9 + 7). Since n, m ≤ 10^5, we can precompute factorials and inverse factorials up to n for the binomial coefficient, and use fast modular exponentiation.
