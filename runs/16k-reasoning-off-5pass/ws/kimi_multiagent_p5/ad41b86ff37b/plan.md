A Snowflake Tree has three levels: a center (red), x≥1 middle vertices (blue), and y≥1 leaves per middle vertex (green). We must delete the fewest vertices so the remaining induced graph is exactly such a 3-level tree, meaning we keep a connected subtree of height ≤2 from some center, where every kept middle vertex has the same number of kept leaf children (≥1) and the center has ≥1 middle children. Root the tree arbitrarily and use tree DP: for each node and each "role" (center, middle, leaf) compute the max kept vertices in its subtree, with the middle-role state parameterized by the uniform leaf count y (which equals a child count, so only O(deg) candidate values per node). Combine via choosing the best common y across children (intersection of candidate y values) and take the global best over choices of center. Total work is O(N) or O(N log N) since candidate sets are bounded by degrees.
