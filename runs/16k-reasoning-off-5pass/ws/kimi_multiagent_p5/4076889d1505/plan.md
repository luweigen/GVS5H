We need ord_M(A) = N exactly. A clean construction: pick a prime p such that N | p-1 (such primes exist by Dirichlet, but we need a constructive bound), then a primitive root g mod p has order p-1, so A = g^((p-1)/N) mod p has order exactly N with M = p. However finding such p quickly is hard; instead use M = N+1 when N+1 is prime with A a primitive root... simpler: use lifting — take A = N+1, M = something? Actually the cleanest known trick: A = 2, M = 2^N - 1 fails bounds. Best approach: find prime p with N | p-1 by scanning p = kN+1 for small k (k up to ~few thousand suffices in practice for N ≤ 10^9), then find primitive root g mod p by trial with factorization of p-1, and output A = pow(g, (p-1)//N, p), M = p. Factorization of p-1 is easy since p-1 = kN with small k, and we factor N (≤10^9) by trial division up to ~31623, which is fine for T=10^4 if we cache factorizations... worst case 10^4 × 31623 divisions is too slow, so factor N using precomputed primes up to 31623 (~3401 primes) — acceptable.
