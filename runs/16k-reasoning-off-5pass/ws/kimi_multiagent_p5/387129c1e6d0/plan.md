Santa's path is a sequence of M axis-aligned segments. A house is visited iff it lies on one of these segments. Group houses by x-coordinate (for vertical segments) and y-coordinate (for horizontal segments), storing sorted lists of the other coordinate. For each move, binary search the relevant list to count houses within the segment's coordinate range, and track visited houses in a set to deduplicate across segments. Since each house lies on at most one row and one column, it can be double-counted at most once per crossing, so a visited-set keeps the count correct. Total work is O((N+M) log N). Use Python integers to avoid overflow.
