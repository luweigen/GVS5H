This is the classic AtCoder "Kagami Mochi 2 / pairing" problem: pair a smaller mochi (top) with one at least twice its size (bottom). The optimal strategy is greedy: use the smallest K mochi as tops and the largest K mochi as bottoms, matching smallest top with smallest available bottom. To find the maximum K, binary search on K (or directly two-pointer with K = N/2 candidates). For a fixed K, check if A[i] * 2 <= A[N-K+i] for all i in [0, K); this check is O(K). Binary search gives O(N log N) total, fine for N up to 5×10^5. Alternatively, a single pass with K = N//2 and a two-pointer greedy matching tops from the first half against bottoms from the second half achieves O(N).
