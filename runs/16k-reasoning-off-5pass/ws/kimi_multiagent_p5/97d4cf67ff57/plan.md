An alkane is a tree whose vertices have degree 1 or 4, with at least one degree-4 vertex. A subgraph of a tree that is itself a tree must be a connected vertex-induced subtree (we may drop edges, but dropping edges only lowers degrees, so we can also "trim" branches). Key structural fact: in such a tree, if we contract each degree-1 vertex's attachment, the degree-4 vertices form a structure where each internal node uses exactly 4 connection slots. Root the tree and do tree DP: for each node compute the best alkane-subtree in its subtree where the node connects upward via one edge (acting as a "partial" node needing more children to reach degree 4), and the best completed alkane entirely inside the subtree. States: node as leaf (degree 1, take nothing below), node as internal with exactly 3 children kept (its 4th connection is the parent edge), and combining children contributions via knapsack-like selection of top gains. Answer is the max over all nodes of a completed alkane rooted there (node has degree 4 using 4 children, or combine upward and downward parts via rerooting).
