Since target has at most 4 elements, we can enumerate all subsets of target (at most 16). For each subset, the cheapest way to cover it with a single nums element is to raise some nums[i] to the least common multiple of that subset (rounded up to the next multiple of the LCM). Precompute the minimum cost per subset over all nums elements, then run a subset DP: dp[mask] = min over submasks of dp[mask \ sub] + cost[sub]. The answer is dp[full mask]. LCM values can overflow beyond 10^4, so cap them (e.g., treat LCM > max(nums)+needed as unusable, or just cap at a large sentinel since costs only matter up to achievable multiples).
