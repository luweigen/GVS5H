This is equivalent to breaking up the longest existing runs of identical characters. Since we can choose which characters to flip, the optimal strategy is to target the longest run(s) in the string and break them into smaller pieces using our available operations. We should calculate the lengths of all contiguous runs of identical characters, sort them in descending order, and then greedily reduce the largest runs first until we run out of operations or all runs are reduced to length 1.
