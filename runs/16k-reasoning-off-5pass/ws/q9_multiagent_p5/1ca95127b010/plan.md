The operations allow us to swap a block of $X$ zeros followed by $Y$ ones with a block of $Y$ ones followed by $X$ zeros, provided they are adjacent. This suggests the problem can be modeled as checking if string $S$ can be transformed into $T$ by moving "blocks" of $X$ zeros and $Y$ ones past each other. We can treat the string as a sequence of maximal contiguous segments of identical characters. The key insight is that the relative order of these segments must be preserved, but we can swap adjacent segments if their types match the specific pattern required for an operation (specifically, a segment of $X$ zeros and a segment of $Y$ ones can swap positions). We will simulate this by greedily matching segments from left to right, allowing swaps when the current segment in $S$ matches the required pattern to transform into the corresponding segment in $T$.
