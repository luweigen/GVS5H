The problem asks for the number of ways to rotate tiles such that no "dead ends" exist on a toroidal grid. A dead end occurs if a segment exists on one side of a cell boundary but not on the adjacent cell's corresponding side. This condition implies that for every horizontal boundary between columns $j$ and $j+1$, the connection status must be consistent (both connected or both disconnected), and similarly for vertical boundaries. Since the grid is a torus, these constraints form a system of equations on the rotation choices of the tiles. We can model the choices as variables and use the principle of inclusion-exclusion or dynamic programming based on the cycle structure of the constraints. However, a more direct approach is to realize that the constraints decouple into independent cycles for horizontal and vertical connections. For each row, the horizontal constraints form a cycle of length $W$, and for each column, the vertical constraints form a cycle of length $H$. The total number of valid configurations is the product of the number of valid ways to satisfy horizontal constraints for all rows and vertical constraints for all columns. For a cycle of length $L$ with specific tile types (A or B) at each position, we can use dynamic programming or matrix exponentiation to count valid assignments. Given the constraints ($HW \le 10^6$), an $O(HW)$ solution is required. We will process each row and column independently, calculating the number of valid rotations for the linear constraints within that cycle, and multiply the results.
