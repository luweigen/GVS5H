The problem asks for the sum of $B^p$ modulo $p$ over all matrices $B$ where zeros in $A$ are replaced by non-zero values. By Fermat's Little Theorem, $x^p \equiv x \pmod p$. Thus, we need to compute the sum of $B$ modulo $p$ over all valid $B$. The sum of $B$ can be computed element-wise. For an element $(i,j)$, if $A_{i,j} \neq 0$, it is fixed, and we sum it over all $(p-1)^K$ possibilities. If $A_{i,j} = 0$, it takes each value $v \in \{1, \dots, p-1\}$ exactly $(p-1)^{K-1}$ times. We calculate the contribution for each cell based on whether it was originally zero or not.
