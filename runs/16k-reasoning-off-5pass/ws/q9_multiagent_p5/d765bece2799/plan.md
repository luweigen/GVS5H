The problem requires summing the min and max of all subarrays with length at most $k$. A naive $O(N^2)$ approach checking every subarray will be too slow given $N \le 80,000$. We can optimize by iterating through each element as the potential start of a subarray and using a monotonic deque (or two deques) to efficiently track the minimum and maximum values in the current sliding window of valid lengths (from 1 to $k$). Alternatively, we can iterate through each element as the right endpoint of a subarray and maintain deques for the min/max in the range $[i-k+1, i]$, summing contributions for all valid start points. The deque approach allows us to process each element in amortized $O(1)$ time, resulting in an overall $O(N)$ solution.
