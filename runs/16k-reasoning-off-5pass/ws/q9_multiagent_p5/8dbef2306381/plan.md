The problem asks for reachability from square 1 to N with jump constraints [A, B], avoiding "bad" squares defined by M intervals. Since N is up to $10^{12}$, we cannot simulate every square. However, the number of bad intervals M is small ($2 \times 10^4$) and the jump range [A, B] is very small (up to 20). We can model this as a graph where nodes are the start of each bad interval (plus 1 and N) and check reachability using BFS or a simple reachability check on these critical points, effectively compressing the large gaps between bad intervals. The key insight is that within a large gap of good squares, if we can reach the start of the gap, we can almost certainly reach the end unless the gap is too small or the jump constraints prevent it, but given the small jump range, we just need to check if we can "hop" over the bad intervals. A more robust approach is to treat the "bad" intervals as obstacles and perform a BFS on the set of "interesting" coordinates: 1, N, and the boundaries of the bad intervals ($L_i, R_i+1$). We only need to track reachable states at these coordinates.
