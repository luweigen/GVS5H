The problem requires tracking Santa's path through a grid while counting unique houses visited. Since $N$ and $M$ are up to $2 \times 10^5$, we cannot simulate every unit step. Instead, we will simulate the movement by updating coordinates and checking for house intersections only when the path is horizontal or vertical. For each segment, we determine the range of coordinates covered and check if any house lies on that segment using a hash set for $O(1)$ average time complexity lookups. We must also handle large coordinate values using 64-bit integers (Python handles this automatically).
