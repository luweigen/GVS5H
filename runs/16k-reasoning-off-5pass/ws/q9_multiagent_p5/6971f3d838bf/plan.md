The problem requires finding the maximum subarray sum after removing all occurrences of at most one distinct integer $x$. Since the array length is up to $10^5$, we cannot simulate the removal for every unique element and run Kadane's algorithm each time ($O(N^2)$). Instead, we can precompute prefix and suffix maximum subarray sums and prefix/suffix sums to allow $O(1)$ query time for any candidate $x$. We will iterate over all unique elements in the array, calculate the potential maximum subarray sum if that element were removed by combining the best prefix (ending before the last occurrence of $x$) and best suffix (starting after the first occurrence of $x$), and track the global maximum. We must also consider the case where no operation is performed.
