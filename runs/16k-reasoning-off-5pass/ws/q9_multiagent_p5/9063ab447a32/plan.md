The problem requires maximizing the total units purchased within a budget $M$, where the cost of $k$ units of product $i$ is $k^2 P_i$. This cost function is convex, meaning the marginal cost of the $k$-th unit is $(2k-1)P_i$. We can solve this by binary searching for the maximum "marginal cost threshold" $T$. For a given $T$, we calculate the total cost to buy all units whose marginal cost is $\le T$. If this cost is within $M$, we try a higher $T$; otherwise, we try a lower $T$. The maximum number of units corresponds to the largest $T$ satisfying the budget constraint. We sort the products to optimize the cost calculation loop.
