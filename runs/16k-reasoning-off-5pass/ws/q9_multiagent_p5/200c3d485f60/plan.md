The problem requires counting arrays of length `n` with elements in `[1, m]` such that exactly `k` adjacent pairs are equal. This can be modeled by choosing `k` positions out of `n-1` possible adjacent slots to have equal values, and ensuring the remaining `n-1-k` slots have different values. Once the equality pattern is fixed, the first element can be chosen in `m` ways, and each subsequent element is constrained: if the current slot is an "equal" transition, there is only 1 choice (must match previous); if it's a "different" transition, there are `m-1` choices. Thus, the total count is `C(n-1, k) * m * (m-1)^(n-1-k)`. We will compute the binomial coefficient using modular arithmetic and precompute factorials for efficiency.
