The problem asks for the minimum cost to sort a permutation where swapping adjacent elements $P_i$ and $P_{i+1}$ costs $i$. This cost structure implies that moving an element from position $i$ to the left costs $i$, and moving it to the right costs $i$ (relative to the swap index). By analyzing the contribution of each element to the total cost, we can determine that the total minimum cost is the sum of the absolute differences between each element's initial position and its target (sorted) position. Specifically, if an element $x$ starts at index $i$ (1-based) and needs to move to index $x$, the cost contributed is $|i - x|$. Summing these values for all elements gives the answer.
