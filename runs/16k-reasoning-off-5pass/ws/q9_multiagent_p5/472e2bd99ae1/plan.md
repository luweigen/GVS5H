The problem asks for the K-th largest value among $N^3$ combinations. Since $K$ is relatively small ($5 \times 10^5$), the K-th largest value is likely formed by elements from the top portion of the sorted sequences A, B, and C. Specifically, if we sort A, B, and C in descending order, the top $K^{1/3}$ elements of each sequence are sufficient to generate the top $K$ values. We will sort the sequences, take the top $M = \lceil K^{1/3} \rceil + 2$ elements (capped at N), generate all $M^3$ combinations, sort them, and pick the K-th largest. This approach has complexity $O(N \log N + K \log K)$, which fits well within the time limits.
