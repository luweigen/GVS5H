The problem asks us to find positive integers $x$ and $y$ such that $x^3 - y^3 = N$, where $N$ can be as large as $10^{18}$. Since $x^3 - y^3 = (x-y)(x^2 + xy + y^2)$, and $x > y$, let $d = x - y$. Then $x = y + d$. Substituting this into the equation gives $d((y+d)^2 + (y+d)y + y^2) = N$, which simplifies to $d(3y^2 + 3dy + d^2) = N$. Since $y \ge 1$ and $d \ge 1$, the term $(3y^2 + 3dy + d^2)$ is strictly greater than $d^2$ and roughly $3y^2$. Thus, $d^3 < d(3y^2 + 3dy + d^2) = N$, implying $d < N^{1/3}$. Given $N \le 10^{18}$, $d$ is at most $10^6$. We can iterate over all possible values of $d$ from $1$ to $\lfloor N^{1/3} \rfloor + 1$. For each $d$, we solve the quadratic equation $3y^2 + 3dy + (d^2 - N/d) = 0$ for positive integer $y$. If a valid integer solution exists, we output $x$ and $y$; otherwise, after checking all $d$, we output -1.
