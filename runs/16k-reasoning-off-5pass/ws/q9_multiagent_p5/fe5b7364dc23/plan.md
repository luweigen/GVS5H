The problem asks for the sum of the K-th power of all subarray sums. Since K is small (≤ 10) and N is up to 2×10^5, an O(N^2) solution is too slow. We can rewrite the sum using the identity for the K-th power of a sum involving Stirling numbers of the second kind, converting (ΣA_i)^K into a sum of products of individual terms. By fixing the right endpoint of the subarray and using prefix sums, we can express the contribution of each element as a polynomial in the prefix sum. We then use a divide and conquer approach (similar to the "sum of subarray products" technique) or a polynomial multiplication strategy to efficiently compute the required sums for each power, leveraging the fact that the number of distinct prefix sums is manageable or using generating functions. Specifically, we can iterate over the number of terms in the expansion (from 1 to K) and use a technique where we maintain the sum of products of a certain number of elements for subarrays ending at the current position, updating them as we move the right pointer. Given the constraints and the nature of the expansion, a divide and conquer approach on the array indices combined with polynomial multiplication (or simply maintaining the necessary sums via recurrence) is optimal. The most straightforward efficient method for small K is to expand (S_r - S_{l-1})^K using binomial coefficients, then sum over l. This leads to a form where we need to compute sums of the type Σ S_{l-1}^j * S_r^{K-j}. We can precompute prefix sums and then for each r, we need the sum of powers of previous prefix sums. This can be done efficiently by maintaining the sum of powers of prefix sums as we iterate, but since we need combinations of different powers, we might need a slightly more complex structure. Actually, a simpler O(N*K^2) or O(N*K) approach exists: Expand (S_r - S_{l-1})^K = Σ C(K, j) * S_r^j * (-1)^{K-j} * S_{l-1}^{K-j}. The total answer is Σ_r Σ_{j=0}^K C(K, j) * (-1)^{K-j} * S_r^j * (Σ_{l=1}^r S_{l-1}^{K-j}). We can precompute the term T[p] = Σ_{i=0}^{r-1} S_i^p for each r and each power p. Since p goes up to K, we can maintain these sums incrementally as we iterate r from 1 to N. This yields an O(N*K) solution.
