The problem asks for the minimum cost to transform sequence A into sequence B using flip operations where the cost of a flip depends on the current state of A. Since the cost of flipping index $i$ is $C_i \times (\text{current } A_i)$, flipping a 0 costs 0, and flipping a 1 costs $C_i$. To minimize total cost, we should only flip indices where $A_i \neq B_i$. If $A_i=0$ and $B_i=1$, we must flip once (cost 0). If $A_i=1$ and $B_i=0$, we must flip once (cost $C_i$). Crucially, flipping an element twice is suboptimal because the first flip (if from 1 to 0) costs $C_i$, and the second flip (from 0 to 1) costs 0, totaling $C_i$, whereas doing nothing costs 0. Thus, the optimal strategy is simply to sum the costs of all necessary single flips.
