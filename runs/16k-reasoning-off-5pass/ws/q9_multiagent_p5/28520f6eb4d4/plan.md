The problem asks for the maximum height $h$ at $x=0$ such that not all buildings are visible. This condition is equivalent to finding the maximum y-intercept of any line segment connecting two buildings $j$ and $i$ (where $j < i$). If this maximum intercept is $K$, then for any $h \le K$, there exists at least one building not visible. If $K < 0$, then even at $h=0$, all buildings are visible (since $h \ge 0 > K$), so we output -1. Otherwise, the answer is $K$. The line with the maximum intercept connecting two points in a set must be an edge of the convex hull of the set. Thus, we compute the convex hull of the buildings and check the intercept of each edge.
