The problem requires calculating the sum of absolute differences between all pairs $(A_i, B_j)$ for $1 \le i \le X_k$ and $1 \le j \le Y_k$ across $K$ queries. A naive $O(N^2)$ approach per query is too slow given the constraints ($N \le 10^5, K \le 10^4$). Instead, we can sort both arrays $A$ and $B$. By sorting, the absolute difference $|A_i - B_j|$ can be computed efficiently by splitting the sum into parts where $A_i < B_j$ and $A_i \ge B_j$. We can precompute prefix sums for both sorted arrays to answer each query in $O(\log N)$ time using binary search (specifically `bisect_right`) to find the split point in $B$ for a given $X_k$.
