The problem asks for the minimum cost to travel from vertex 1 to vertex N in a directed graph where we can either traverse an edge (cost 1) or reverse all edges (cost X). Since reversing edges is a global operation that toggles the state of the graph, the state space can be modeled as a graph with $2N$ nodes: $u$ representing being at vertex $u$ with edges in their original orientation, and $u'$ representing being at vertex $u$ with edges reversed. We can build a new graph where moving along an original edge $(u, v)$ connects $u \to v$ with weight 1, and moving along a reversed edge $(v, u)$ connects $u' \to v'$ with weight 1. Transitions between states involve reversing all edges, connecting $u \to u'$ and $u' \to u$ with weight $X$. However, since reversing edges globally affects all vertices, a more efficient approach is to consider that once we decide to reverse, we pay $X$ and then traverse the reversed graph. The shortest path can be found using Dijkstra's algorithm on a graph with $2N$ nodes, where edges exist between $u$ and $v$ (weight 1) if there is an edge $u \to v$ in the original graph, and between $u'$ and $v'$ (weight 1) if there is an edge $v \to u$ in the original graph. Additionally, for every vertex $u$, we add edges $u \to u'$ and $u' \to u$ with weight $X$. The answer is the shortest path from node 1 to node N (or potentially $N'$ if we end up in the reversed state, but since the target is just "reach vertex N", we take $\min(dist[N], dist[N'])$).
