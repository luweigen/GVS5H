Given the small constraints ($N \le 30, M \le 100$), we can iterate on the possible answer $D$ (the shortest path length). For a fixed $D$, we check if it's possible to select $K$ edges with weight 1 such that every path from 1 to $N$ has length at least $D$. This is equivalent to ensuring no path of length $< D$ exists. We can model this as a maximum flow problem: construct a graph where edges with length $< D$ have capacity 1, and edges with length $\ge D$ have infinite capacity (or simply don't restrict flow). If the max flow from 1 to $N$ is less than or equal to $K$, it means we can "block" all short paths by setting at most $K$ edges to 1. We binary search for the maximum $D$.
