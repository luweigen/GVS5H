The problem asks us to select k points from a given set on the boundary of a square such that the minimum Manhattan distance between any pair of selected points is maximized. This is a classic "maximize the minimum" problem, which can be efficiently solved using binary search on the answer (the distance). We will binary search for the maximum possible distance `d`. For a fixed `d`, we need to check if it's possible to select at least `k` points such that every pair is at least `d` apart. Since the points lie on the boundary of a square, we can traverse the perimeter in a linear order (e.g., bottom edge -> right edge -> top edge -> left edge) and use a greedy approach: pick the first point, then repeatedly pick the next available point that is at least `d` Manhattan distance away from the last picked point. If we can pick `k` points, then `d` is feasible.
