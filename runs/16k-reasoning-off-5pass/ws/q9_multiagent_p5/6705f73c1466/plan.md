The goal is to move all '1's to a contiguous block with minimum swaps. This is equivalent to finding a target position range $[l, r]$ of length $K$ (where $K$ is the total count of '1's) such that the number of '1's currently outside this range is minimized. Since each swap can move a '1' one step closer to the target block or a '0' one step closer, the cost is exactly the number of '1's that need to be moved into the block. We can iterate over all possible starting positions $l$ for the block of '1's, calculate the cost for each, and find the minimum. The cost for a specific window is the count of '1's before $l$ plus the count of '1's after $r$. We can optimize this calculation using prefix sums or a sliding window approach to achieve $O(N)$ time complexity.
