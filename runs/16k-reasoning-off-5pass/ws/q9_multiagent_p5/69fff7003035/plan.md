The problem asks for the sum of numbers formed by concatenating permutations of $1$ to $N$. We can calculate the contribution of each digit $d \in \{1, \dots, N\}$ to the total sum by determining how many times it appears at each decimal position (units, tens, hundreds, etc.) across all $N!$ permutations. First, we precompute the number of digits in each integer from $1$ to $N$. Then, for each position $k$ (from right to left, $10^0, 10^1, \dots$), we count how many times a specific number $x$ contributes to that position. A number $x$ with $L$ digits will occupy positions corresponding to the last $L$ digits of the concatenated string. We sum these contributions modulo 998244353.
