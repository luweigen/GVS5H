The problem involves inserting elements into an array at specific positions, which naively takes $O(N^2)$ time. Since $N$ is up to $5 \times 10^5$, we need an $O(N \log N)$ or $O(N)$ approach. The key insight is to process the operations in reverse order: starting from the final state where the $N$-th element is at position $P_N$, we can determine the final position of each element $i$ by accounting for how many subsequent elements (those inserted after $i$) were placed before it. By maintaining a data structure (like a Fenwick tree or Segment Tree) to track occupied positions, we can calculate the final index for each number efficiently.
