For each window of size x, the minimum cost to make all elements equal is the sum of absolute deviations from the window's median, computable in O(log x) per window with two heaps (or O(1) amortized with a sliding median structure). This gives a cost array over the n-x+1 possible subarrays. Then we need the minimum total cost to pick k non-overlapping windows (starts at least x apart), which is a classic weighted interval scheduling DP: dp[j][i] = min cost using j subarrays considering the first i windows, with transition dp[j][i] = min(dp[j][i-1], dp[j-1][i-x] + cost[i]). Since k <= 15, the DP is O(n*k) and the sliding median is O(n log x), both fine for n up to 1e5.
