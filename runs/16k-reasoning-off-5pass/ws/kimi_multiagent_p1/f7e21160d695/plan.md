The key observation is that f(x,y) equals the maximum edge weight on the unique path between x and y in a Minimum Spanning Tree (Kruskal reconstruction tree makes this even cleaner). Build a Kruskal reconstruction tree: each edge of the MST becomes an internal node with weight w, and f(x,y) = weight of LCA of x and y in this tree. We need to match A's to B's minimizing the sum of LCA weights — this is a tree DP / greedy assignment problem. Process the reconstruction tree bottom-up: at each internal node with weight w, we have some number of unmatched A's and B's in its subtree; matching within the subtree costs less, so we match as many as possible at lower levels, and only forced matches at this node pay w. Compute the total cost via DP tracking surplus of A's vs B's per subtree.
