Each operation divides two numbers by 4 (floor). A number x needs ceil(log4(x+1)) "hits" to become zero — equivalently, its level is the number of times you can divide by 4 before reaching 0. Since each operation handles two numbers, the minimum operations for one query is ceil(total_levels / 2), where total_levels = sum over x in [l, r] of level(x). Levels are constant on ranges [4^k, 4^(k+1)-1], so we compute the sum per query in O(log r) by iterating power-of-4 buckets. With up to 1e5 queries and ~16 buckets, total work is fine.
