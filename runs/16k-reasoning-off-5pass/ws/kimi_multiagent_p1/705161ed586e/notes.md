**Core difficulty:** A good caption is a concatenation of monochromatic blocks, each of length ≥ 3. We must (1) minimize total alphabet-distance cost to transform the string into such a form, and (2) among all minimum-cost results, return the lexicographically smallest string. Lexicographic comparison is over the *output strings*, which always have the same length n, so it's a well-defined total order.

**Key observations:**
- Cost to make segment [l, r) all character c = Σ|caption[i] − c|, minimized by the median character of the segment (any median; for tie-breaking we may prefer the smaller median since it tends to give lexicographically smaller output, but careful: block choice interacts with DP).
- With only 26 letters, per-segment cost for *all* c can be computed in O(26) using prefix-count arrays over letters: pref[i][c] = count of letter c in caption[:i]. Then cost(l, r, c) = Σ_{d} |c − d| * (pref[r][d] − pref[l][d]).
