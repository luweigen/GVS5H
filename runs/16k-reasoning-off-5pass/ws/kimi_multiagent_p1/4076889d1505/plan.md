We need ord_M(A) = N exactly. A clean construction: pick a prime p such that N | p-1 (such primes exist by Dirichlet, but we need an explicit, fast method). Simpler: use M = N+1 when N+1 is prime with A a primitive root — too slow to find. Instead use the lifting trick: for A = N+1, M = N^2... Actually the robust known approach: take M = p a prime divisor of Φ_N evaluated cleverly, or use A = 2 and M = 2^N - 1's primitive prime divisor (Zsigmondy) — but M must be ≤ 1e18 and computable. Best practical plan: choose M = N*k+1 prime by searching small k (k up to ~few hundred suffices heuristically for N ≤ 1e9), then find A as an element of order N mod p via A = g^((p-1)/N) mod p where g is a primitive root (found by testing small candidates against factorization of p-1). Handle N=1 trivially with M=1. Factor p-1 = N*k using trial division up to cube root plus Pollard rho if needed — but k is small so factor N (≤1e9, trial division to ~31623 fine for 1e4 cases with precomputed primes) and factor k by the search loop.
