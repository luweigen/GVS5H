This is a knapsack-style DP over three dimensions: position, alternating sum, and product. Since nums[i] ≤ 12 and limit ≤ 5000, we can track achievable (alternatingSum, product) states. The alternating sum depends on the parity of the subsequence length, so we must also track whether the next picked element is at an even or odd index (i.e., current subsequence length parity). We iterate items, updating a DP set/dict of (sum, parity) → set of products, or a set of (sum, parity, product) tuples, then answer with the max product ≤ limit at sum k. Sums can be offset since values are small (max |sum| ≤ 150*12 = 1800), but k up to 1e5 just means unreachable → -1.
