The bad intervals are sorted and disjoint, so the free squares form gaps: [1, L_1-1], [R_1+1, L_2-1], ..., [R_M+1, N]. Within a gap, moves of size in [A,B] behave like a reachability problem on a line; the reachable set inside a gap quickly becomes a union of intervals, and once a gap is longer than about B^2 (or we can just cap simulation length), reachability becomes periodic/all-reachable beyond some point. Concretely, we propagate a set of reachable positions as intervals gap by gap: from reachable positions in the previous gap, jumping over a bad interval of length len requires a step i in [A,B] with landing in the next gap; we can compute the reachable set in each gap as intervals using the fact that with steps in [A,B], from a starting interval [s,t] within a long-enough free segment, all positions >= s + something become reachable (Frobenius-style since gcd of consecutive lengths A..B is 1). Simplest robust approach: simulate reachable interval set per gap, capping each gap's effective length at B*B + B (beyond which everything up to the gap end is reachable if anything is), giving O(M * B^2) time.
