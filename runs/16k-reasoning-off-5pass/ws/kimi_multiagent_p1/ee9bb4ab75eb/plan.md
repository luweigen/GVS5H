Build a trie over all words, storing at each node the count of words passing through it. The answer for the full array is the deepest node (by depth = prefix length) with count >= k; for each removed index i, we need the deepest node with count >= k after decrementing counts along word i's path. Precompute for each node its depth and maintain, per depth, a multiset (Counter) of node-counts so we can query the max depth with count >= k. For each i, temporarily subtract 1 along its path (updating the per-depth counters), query the deepest valid depth, then restore. Total work is O(total characters), feasible since sum of lengths <= 1e5.
