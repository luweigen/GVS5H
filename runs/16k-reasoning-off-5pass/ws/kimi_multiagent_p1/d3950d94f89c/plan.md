Root the tree at 0 and do a single DFS maintaining the current root-to-node path. Because a special path must be downward and have unique values, for each node we need the deepest ancestor boundary where the current value last appeared; the valid start of a special path ending at the current node is just below the maximum such boundary among values on the path. Keep a monotonic structure (or last-occurrence map plus segment/BIT over depths) to query the best (max length, then min node count) path ending at each node in O(log n). Update a global best pair with lexicographic comparison: larger length first, smaller node count on ties. Complexity O(n log n), well within limits.
