An alkane is a tree whose internal vertices all have degree exactly 4 and leaves degree 1, with at least one degree-4 vertex. A subgraph of a tree that is itself a tree can be taken as a connected vertex subset with its induced edges (we may also drop edges, but keeping all induced edges only adds degree, so the chosen subgraph is a connected subtree where selected vertices have induced-degree 1 or 4). Root T arbitrarily and run a tree DP that, for each node, tracks the best subtree where the node's degree within the chosen subgraph is fixed to a value in {0..4}, combining children by either cutting the edge or keeping it (which consumes one degree slot on both endpoints). The answer is the best connected component formed anywhere: either a single edge (two degree-1 vertices is not allowed—need a degree-4 vertex, so minimum alkane is one degree-4 vertex with 4 leaves, 5 vertices) or a node reaching degree 4, or merging child components through a node. Careful handling: components must stay connected, so at each node we merge at most one "open" child component per degree slot; leaves of the alkane are vertices with induced degree 1 in the original tree or vertices where we cut all but one edge.
