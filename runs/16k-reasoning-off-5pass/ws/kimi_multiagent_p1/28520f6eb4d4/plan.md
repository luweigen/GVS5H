Model visibility from point (0, h): building i is visible iff the ray from (0,h) to some point on building i is not blocked by any building j with X_j < X_i. Since buildings are vertical segments at increasing coordinates, building i is visible iff h exceeds the maximum "required height" imposed by all previous buildings — specifically, the line from (0,h) to the top of building i must pass above every intermediate building j, i.e., h >= H_j * X_i / X_j for all j < i... but actually we can see any point Q on building i (from height 0 to H_i), so building i is visible iff there exists q in [0, H_i] such that the line from (0,h) to (X_i, q) clears all buildings j<i: h + (q - h) * X_j/X_i > H_j for all j<i. The best q is H_i (highest target), so building i is visible iff max over j<i of (H_j - h) * X_i / X_j < H_i - h... equivalently h >= (H_j * X_i - H_i * X_j) / (X_i - X_j) for all j < i. The answer is max over all pairs (j, i), j < i, of that expression, clamped below by 0; if the max is <= 0, output -1 (well, if max < 0 output -1; if max == 0 output 0). This is a max over pairs of a linear-fractional form, computable in O(N log N) or O(N) via convex-hull-like sweep: for each i, we need max over j<i of (H_j * X_i - H_i * X_j)/(X_i - X_j). Treat each j as a line/point and use a Li Chao tree or convex hull trick with binary search on the hull.
