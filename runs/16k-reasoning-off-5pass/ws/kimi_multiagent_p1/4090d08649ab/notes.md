
## ideation
Core insight: For a fixed subarray S=A[L..R], one operation with (l,r) erases exactly the present values in [l,r]. An interval is usable iff every value in [l,r] appears in S, so usable intervals are precisely unions within maximal runs of consecutive present values. Minimizing operations means taking each maximal run once, so f(L,R) = number of runs of the distinct value set of A[L..R] on the integer line.

Total answer = sum over subarrays of (#runs) = sum over values v of (#subarrays where v starts a run) = sum_v cnt(v present AND v-1 absent). Define g(v) = #subarrays containing v but not v-1. Answer = sum_{v=1..N} g(v) (value 1 always starts a run when present; treat v-1=0 as absent).

g(v) = (subarrays containing v) − (subarrays containing both v and v-1). Subarrays containing v: standard from occurrence positions p_1<...<p_k: sum over i of (p_i − p_{i-1})·(N − p_i + 1) with p_0=0. Subarrays containing both v and w=v−1: merge occurrence lists P (of v) and Q (of w); a subarray [L,R] contains both iff L ≤ min(nextP, nextQ positions...) — precisely: for each pair, L must be ≤ some occurrence of each and R ≥ some occurrence of each. Count = sum over L of (N − max(next occurrence of v at/after L, next occurrence of w at/after L) + 1) when both exist. Can be computed by sweeping L with two pointers, or by splitting at positions: for each L, need max(nxtP[L], nxtQ[L]). Alternative: iterate over segments between consecutive events. Overall O(N) per pair summed = O(N) total since each position belongs to one value list; pair (v,v−1) work is O(|P|+|Q|), and summing over all v gives O(N) total (each list used at most twice).

Pitfalls: (1) values up to N but some values may never occur — fine, empty lists. (2) Large answer: N up to 3e5, subarrays ~4.5e10, answer up to ~N·subarrays ~1.4e16 — need 64-bit (Python int fine). (3) Don't double count: runs counted via "v present, v−1 absent" is exact partition of runs. (4) Verify with samples (16, 23, 129).

Corrected both():
```python
def both(P, Q):
    if not P or not Q:
        return 0
    i = j = 0
    lp, lq = len(P), len(Q)
    total = 0
    L = 1
    # advance pointers to L
    while L <= n:
        while i < lp and P[i] < L: i += 1
        while j < lq and Q[j] < L: j += 1
        if i == lp or j == lq: break
        m = max(P[i], Q[j])
        # next L where something changes: min(P[i], Q[j]) + 1? Change occurs when L passes P[i] or Q[j]
        nxt = min(P[i], Q[j]) + 1
        total += (nxt - L) * (n - m + 1)
        L = nxt
    return total
```
This jumps L in O(1) steps per event, total O(|P|+|Q|) iterations. Use this version in the final program.
