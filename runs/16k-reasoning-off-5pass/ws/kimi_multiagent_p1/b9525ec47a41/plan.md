We need count distinct indegree sequences over all orientations of a graph that is a cycle on vertices 0..N-1 plus a hub N connected to a subset S of cycle vertices. For any orientation, indegrees d_v satisfy 0<=d_v<=deg(v), sum d_v = |E|, and a sequence is realizable iff for every subset of vertices, sum indegrees >= number of internal edges (Hakimi/Fulkerson orientation criterion). Because the graph is a cycle with a universal-to-S vertex, we can translate this into constraints on contiguous arcs of the cycle and on the hub, then count sequences via a combinatorial/DP argument that reduces to counting binary strings with bounded partial sums. The target is an O(N) or O(N log MOD) formula-based solution using prefix sums over s and precomputed factorials.
