Model the problem as a shortest-path problem on an expanded state graph where each state is (vertex, orientation), with orientation 0 meaning edges are as given and 1 meaning all edges are reversed. From state (v, 0) there are edges to (u, 0) with cost 1 for each original edge v→u, and to (v, 1) with cost X (reverse operation); symmetrically for orientation 1 using reversed edges. Since edge weights are non-negative (1 and X), run Dijkstra from (1, 0) over these 2N states and 2M + 2N implicit edges, and answer min(dist[N][0], dist[N][1]). Use adjacency lists for both the original and reversed graphs, 64-bit integers (Python ints are unbounded), and a heap for efficiency O((N+M) log N).
