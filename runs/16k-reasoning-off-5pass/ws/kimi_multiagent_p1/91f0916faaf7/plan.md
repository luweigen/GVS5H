Each ratio S_i/S_{i+1} in lowest terms p_i/q_i must satisfy p_i*q_i = A_i, so the possible reduced ratios are factor pairs of A_i. Lifting these reduced ratios to actual integers S_i introduces per-edge scale factors, and the chain consistency forces all S_i to be determined by S_1 times cumulative ratio products; the gcd=1 condition then bounds everything, giving finitely many sequences. The key is to model S_i = t_i * r_i where r_i comes from chosen reduced fractions and t_i are integer multipliers linked across edges, turning the problem into counting weighted assignments over a tree (path) of divisor choices. Since N, A_i ≤ 1000, divisor enumeration is cheap, and we can do a DP over the path where states are the actual integer values of S_i (bounded by products of divisors, but effectively bounded because gcd condition forces small values). A cleaner formulation: S_i/S_{i+1} = p_i/q_i in lowest terms means S_i = k_i p_i, S_{i+1} = k_i q_i for some k_i; consecutive edges sharing S_{i+1} force k_i q_i = k_{i+1} p_{i+1}, so we DP over possible values of S_{i+1} (divisors of lcm-like quantities), accumulating products, then divide by the gcd normalization via summing only primitive sequences (use Möbius-style inclusion or directly enforce gcd by bounding and dividing). Practical approach: enumerate reduced ratio options per edge, DP over the value of S_i (which must divide some bounded number derived from A's), track product weights, and handle gcd=1 by noting the minimal solution per ratio-choice and scaling—sum over all ratio choices of (product of minimal S) times sum over valid scale factors, using the fact that scaling by d multiplies gcd by d, so only d=1 survives after Möbius inversion.
