We need to find the minimum operations to make all character frequencies equal. Since we can delete, insert, or increment characters (a→b→...→z), we should try all possible target frequencies k from 0 to n. For each target k, we use dynamic programming over the 26 letters to compute the minimum cost to transform the frequency array so each letter has frequency 0 or k. The DP state tracks the current letter's count plus any "carried over" increments from the previous letter, then decides whether to trim down to k, build up to k (via inserts), or pass excess forward as increments. The answer is the minimum cost across all k.
