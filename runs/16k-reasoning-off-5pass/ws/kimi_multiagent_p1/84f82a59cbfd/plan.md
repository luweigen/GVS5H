A 400 number is exactly a number of the form p^{2a} q^{2b} = (p^a q^b)^2 with distinct primes p, q and a, b ≥ 1, i.e. a perfect square whose square root has exactly two distinct prime factors. So the answer to a query A is the largest perfect square m² ≤ A such that m has exactly two distinct prime factors. We precompute all "good" roots m up to 10^6 (the max root since A ≤ 10^12) using a sieve that counts distinct prime factors, then collect and sort the good squares. Each query is answered by binary search over the sorted list of good squares.
