The key insight is that Manhattan distance decomposes into independent row and column contributions, so we can sum them separately. For the row contribution: for any pair of rows (r1, r2), the number of piece-pairs occupying those rows across all arrangements is n² · C(mn−2, k−2) (choose one cell in each row, then fill remaining k−2 pieces from remaining cells). Multiply by |r1−r2| and sum over all row pairs; the column contribution is symmetric. The sum of |r1−r2| over all ordered row pairs equals 2·Σ_{d=1}^{m−1} (m−d)·d, which has the closed form m²(m−1)(m+1)/3 (i.e., (m³−m)/3 · ... verify: Σ ordered pairs |r1−r2| = (m³−m)/3). All arithmetic is done mod 1e9+7 using modular inverse of 3, and C(mn−2, k−2) is computed with a multiplicative loop since mn ≤ 1e5.
