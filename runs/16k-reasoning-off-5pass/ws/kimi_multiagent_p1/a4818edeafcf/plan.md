We need max over i<j of distinct(A[1..i]) + distinct(A[i+1..j]) + distinct(A[j+1..N]). Prefix distinct counts P[i] are trivial; suffix distinct S[j+1] are trivial; the hard part is the middle segment's distinct count over all (i,j). Key trick: total = P[i] + S[j+1] + mid(i,j), and mid(i,j) equals the number of values whose first occurrence in (i+1..j) exists — equivalently count of positions k in (i+1..j] with prev[k] <= i. So for fixed j, answer = S[j+1] + max over i<j of (P[i] + count of k in (i+1..j] with prev[k] <= i). This can be maintained with a segment tree / BIT sweep: as j advances, add +1 to a range of i-values for the position k=j if prev[j] exists (range i in [prev[j], j-1]), then query max of base[i] = P[i] plus accumulated range adds. Overall O(N log N).
