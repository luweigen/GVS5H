We need to maximize the minimum score across all positions after at most m moves. Since we start at index -1 and must move right first, position 0 gets visited first. The key insight is that to reach position i, we need at least i+1 moves (to get there), and each visit to position i adds points[i] to its score. We can binary search on the answer: for a candidate minimum value X, check if we can achieve gameScore[i] >= X for all i within m moves. For each position i, it needs at least ceil(X / points[i]) visits.
