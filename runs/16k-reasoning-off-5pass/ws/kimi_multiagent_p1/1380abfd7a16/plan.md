We need to simulate inserting i at position P_i for i=1..N, with N up to 5×10^5, so O(N log N) is required. The classic trick is to process in reverse: in the final array, element i's position is determined by P_i and the positions of elements inserted after it. Process i from N down to 1, maintaining an order-statistics structure of "slots"; inserting i so that exactly P_i-1 already-placed (later) elements come before it. A Fenwick tree over positions 1..N supports finding the P_i-th free slot in O(log N). Alternatively a treap/sorted list with splicing works, but Fenwick with binary search is simplest and reliable.
