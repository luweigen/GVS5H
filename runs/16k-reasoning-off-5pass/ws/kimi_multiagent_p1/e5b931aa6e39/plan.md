Factor the equation as x³ − y³ = (x−y)(x² + xy + y²) = N. Let d = x−y ≥ 1; then d must divide N, and substituting x = y+d gives 3y² + 3dy + d² = N/d, a quadratic in y. Since x²+xy+y² ≥ x² > (N/3)^(1/2) roughly bounds things, but more precisely d³ < N so d ≤ N^(1/3) ≤ 10⁶, making it feasible to enumerate all d up to the cube root of N. For each d dividing N, solve the quadratic 3y² + 3dy + (d² − N/d) = 0 and check whether the discriminant is a perfect square yielding a positive integer y. Use integer arithmetic (integer cube root, integer square root) to avoid floating-point errors for N up to 10¹⁸. Print the first valid (x, y) found, else −1.
