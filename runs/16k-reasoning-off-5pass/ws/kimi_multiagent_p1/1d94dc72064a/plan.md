Model the game as a normal-play impartial game where each index i is a pile of size A_i, but the first move on any pile also flips a shared "coverage" counter; the game ends exactly when all N piles have been touched at least once. The key insight is to separate moves into "first-touch" moves (exactly N of them must occur before termination) and "repeat" moves on already-touched piles. The game reduces to analyzing parity of total moves needed: the winner is determined by who makes the N-th distinct touch, which depends on the sum of (A_i - 1) over all piles (the extra moves available after first touches) plus the N mandatory first touches. Compute total moves M = sum(A_i) but constrained by the fact that the game ends immediately upon the N-th distinct index being added to S, so effectively the game length equals (sum over i of (A_i - 1)) + N = sum(A_i) only if the last first-touch coincides with exhausting moves; careful analysis shows the game is equivalent to a Nim-like parity game on total operations where the player making the move that completes S wins. Derive the winning condition by computing the parity of (sum(A_i) - N) combined with the parity of N, then implement an O(N) solution.
