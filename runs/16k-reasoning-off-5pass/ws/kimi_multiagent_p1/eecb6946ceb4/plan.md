Count triples (A, B, C) with A + C = 2B. Since values are bounded by 1e6, use a boolean presence array of size 1e6+1. For each element B in S, iterate over possible differences d and count pairs (B-d, B+d) both present; sum over all B. The total work is bounded because for each B, d ranges only over valid indices (up to max(B-1, MAX-B) values), giving O(N * MAX) worst case — too slow for N=1e6. Better: iterate over pairs (A, C) with same parity and check midpoint — O(N^2) worst case, also too slow. The presence-array approach per B is O(sum over B of min(B-1, MAX-B)), which in the worst case (all values 1..1e6 present) is about MAX^2/4 ≈ 2.5e11 — too slow, so we need convolution (FFT): the answer is sum over B of (f * f)[2B] restricted to distinct A<C, computed as (conv[2B] - 1)/2 summed. Use numpy FFT for an O(MAX log MAX) solution.
