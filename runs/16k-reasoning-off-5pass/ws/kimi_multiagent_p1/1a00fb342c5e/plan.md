XOR constraints decompose per bit, so solve each of the ~30 bits independently as a 2-coloring problem on a graph with N vertices: edge (X_i, Y_i) requires the bits to differ iff bit k of Z_i is 1. Use union-find with parity (weighted DSU) per bit to detect inconsistency (including self-loops X_i == Y_i requiring Z_i bit = 0). For each connected component of the graph (ignoring bit values), the two global flip choices give two candidate assignments per bit; to minimize total sum, choose per component and per bit the orientation putting bit value 1 on the smaller vertex-count side, since bits are independent and sum is additive over bits. Build the answer by accumulating bit contributions, and handle M=0 (all zeros) and isolated vertices naturally.
