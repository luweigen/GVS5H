- **Algorithm**: query-block sqrt decomposition (B=400) with the walk-band insight: within a block, Takahashi's updated cells form a connected walk of ≤B steps, so their bounding box spans ≤B+1 rows and ≤B+1 columns.
- **Per block**: snapshot base grid (updates from previous blocks applied), compute full forward DP `F[h][w] = A[h][w]*(F[h-1][w]+F[h][w-1])` (with `F[0][1]=1` to seed the start cell's value) and backward DP `G[h][w] = A[h][w]*(G[h+1][w]+G[h][w+1])` (with `G[H][W+1]=1`), plus `base_ans = F[H][W]` and `base_through` (paths through the box, via boundary DP with base values).
