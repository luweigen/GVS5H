Model the array as: choose the first element (m ways), then for each of the n-1 transitions choose whether it is "equal" (1 way) or "different" (m-1 ways). We need exactly k equal transitions, so the answer is m * C(n-1, k) * (m-1)^(n-1-k) mod (1e9+7). Since n, m ≤ 1e5, precompute factorials and inverse factorials up to n-1 for O(1) binomial queries, and use fast modular exponentiation. Handle edge cases like k = n-1 (exponent 0) and m = 1 (then only k = n-1 works, formula still holds since 0^0 = 1 via pow).
