Model smoke as a set of integer offsets from the campfire. Each wind step translates every existing smoke cell by a fixed vector, and then (0,0) is added if absent. Since translation is uniform, the set after t steps equals {cumulative displacement of steps k+1..t : for birth times k ≤ t} plus the initial smoke, i.e. smoke at time t occupies positions P_t - P_k for k=0..t where P_i is prefix displacement after i winds (with the rule that a birth at time k only happens if (0,0) was empty, which needs care). Track instead the set of "birth times" whose smoke currently covers (R,C): smoke born at time k (or initial k=0) is at (R,C) at time t iff P_t - P_k = (R,C), i.e. P_k = P_t - (R,C). So maintain a set of valid P_k values; at each t check membership of P_t - (R,C), and add P_t to the set only if (0,0) is empty at time t, i.e. P_t itself is not currently in the set (since (0,0) occupied iff some birth k has P_k = P_t).
