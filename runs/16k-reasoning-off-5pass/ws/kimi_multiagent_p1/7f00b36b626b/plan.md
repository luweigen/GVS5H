The key insight is that lcm(a, b) <= threshold implies both a <= threshold and b <= threshold, so any value greater than threshold is an isolated node (its own component). For values <= threshold, instead of checking O(n²) pairs, we use a divisor/multiple-based union: for each value v present, iterate over multiples m = 2v, 3v, ... up to threshold, and if lcm(v, m) = v*m/gcd(v,m) <= threshold, union the indices of v and m. Since threshold <= 2*10^5, we can map values to indices with a lookup array of size threshold+1, and the total work is bounded by a harmonic-like sum over present values. Use DSU (union-find) with path compression and union by rank, then count distinct roots among all nodes.
