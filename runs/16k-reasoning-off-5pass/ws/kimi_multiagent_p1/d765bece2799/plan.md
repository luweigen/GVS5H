We need sum over all subarrays of length ≤ k of (min + max). Split into two independent problems: sum of maximums over all subarrays with length ≤ k, plus sum of minimums over all subarrays with length ≤ k. For each element nums[i], compute its contribution as a maximum: count of subarrays (length ≤ k) where it is the maximum, using previous/next greater element distances to define its "ownership" range, then intersect that range with the length-≤k window constraint. The count of valid subarrays where i is the max and boundaries lie in [L, R] with length ≤ k can be computed with arithmetic-series formulas in O(1). Do the symmetric pass for minimums (previous/next smaller). Total time O(n), space O(n).
