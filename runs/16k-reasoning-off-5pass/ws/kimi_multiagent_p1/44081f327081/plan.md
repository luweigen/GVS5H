For each index i, the answer is the maximum d dividing A_i such that at least K elements of A are divisible by d (we can always include A_i itself among them). So compute cnt[d] = number of array elements divisible by d for all d up to max(A) using a frequency array and a divisor-sum sieve in O(M log M). Then for each A_i, the answer is the largest divisor d of A_i with cnt[d] >= K; to answer fast, precompute best[x] = largest divisor d of x satisfying cnt[d] >= K for every x up to max(A), by iterating d over valid divisors and updating multiples. Each query is then O(1), giving overall O(M log M + N) time and O(M) memory, feasible for N up to 1.2e6 and A_i up to 1e6.
