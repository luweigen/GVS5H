This is the classic AtCoder "Kagami Mochi 2" (ABC 085 D variant / typical pairing) problem. The optimal strategy is greedy: split the sorted array into a "small" half (candidates for tops) and a "large" half (candidates for bottoms). Use two pointers: try to match the smallest available top with the smallest available bottom that is at least twice the top. Each successful match advances both pointers; otherwise advance only the bottom pointer. The number of matches is the answer, capped at N/2. This works because tops must come from the smaller elements and bottoms from larger ones in an optimal matching (exchange argument). Complexity is O(N) after the given sorted input.
