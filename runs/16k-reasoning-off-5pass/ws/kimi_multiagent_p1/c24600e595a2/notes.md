## worker: Write a brute-force solver (BFS/DP over all states
**What was built:** A cross-validation harness with three implementations:

1. **`brute`** — Dijkstra over the full 2^N hypercube (edge weight of flipping bit i = weight of post-flip state). Exact answer for small N.
2. **`solve_fast`** — the candidate O(N log N) formula solver: offs (S1 ∪ P) decreasing C, then ons (S0 ∪ P) increasing C; P = top-K of A=B=1 bits by C; min over K computed incrementally via the Δ formula with 4 Fenwick trees (count/sum BITs over O and U, coordinate-compressed C).
3. **`best_over_subsets`** — min over *all* 2^m parked subsets of A=B=1 bits (direct simulation), used to independently validate the threshold property (top-K suffices).

**Validation results (all confirmed by the harness):**
- **Δ formula correctness**: `solve_fast` matches `brute` on 4000 random small cases (N ≤ 8, C ≤ 8) plus 3000 targeted cases biased toward expensive A=B=1 bits (C ∈ {1,2,3,50,90,100}) — the regime where parking matters. Any error in the Δ formula (insertion positions, count terms, Wbase handling) would surface immediately.
- **Threshold property**: `best_over_subsets` (all 2^m subsets) equals `brute` everywhere, and `solve_fast` (only top-K prefixes) equals both — confirming that parking a non-top-K set is never strictly better, per the exchange argument (swap parked x with unparked y, C_y > C_x: new cost = old − (C_y−C_x)·(off-period length) ≤ old).
- **Structural claims** (offs-before-ons, offs decreasing / ons increasing, S0/S1 flipped exactly once, A=B=0 never flipped, A=B=1 flipped 0 or 2 times) are all implicitly validated since the fast solver hard-codes them and matches exact BFS.
- **Edge cases verified**: A=B (answer 0, including the subtle case of a single A=B=1 bit where doing nothing beats parking); single-bit flips; flip 1→0 with cost 0; Sample 1 (=16); the motivating counterexample A=(1,0,0),B=(1,1,1),C=(100,1,1) → 105 (parking essential); A=(1,1,0,0),B=(1,1,1,1),C=(100,90,1,1) → 383 (parking harmful — matches the hand-computed Δ=+82).
