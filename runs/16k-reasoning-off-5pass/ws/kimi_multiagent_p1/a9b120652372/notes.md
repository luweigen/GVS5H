## worker: Design an efficient algorithm (sum N ≤ 1e6): greed
**Recap of validated characterization** (from BFS exhaust on n ≤ 6): pieces at the same square merge forever; order is preserved. An assignment maps the i-th initial occupied position p_i to target q_{f(i)} with f a monotone surjection; it is realizable in D operations iff Δ_i = q_{f(i)} − p_i is nonincreasing, D ≥ max|Δ_i|, and every "plateau" (maximal run of equal adjacent Δ values of length ≥ 2) with value c satisfies D ≡ c (mod 2). Hence all plateau values must share one parity, and the answer for an assignment is the smallest D ≥ max|Δ| of that parity (infeasible if plateau values of both parities occur).

**Efficient algorithm (O(N) per test):**
1. *Greedy min-max assignment*: f(0)=0; for each subsequent group i, advance the target pointer j by 1 iff it is allowed (enough groups remain for remaining targets) and |p_i − q_{j+1}| ≤ |p_i − q_j|. This keeps Δ nonincreasing automatically and minimizes max|Δ| (exchange argument: any optimal assignment can be transformed to the greedy one without increasing max|Δ|, since greedy always picks the closest feasible next target and never advances unnecessarily).
2. *Plateau-parity check*: compute the parity mask of plateau values. If mask has ≤ 1 bit, answer = smallest D ≥ max|Δ| with matching parity.
3. *Repair (mixed parities)*: a plateau of value c can be destroyed only by (a) bumping its last group's target up by one (valid only when c < 0, preserving nonincreasing Δ since the successor's Δ ≤ c < c+1... precisely Δ_{e+1} ≤ c < c+1 and predecessor Δ_{s−1} ≥ c), or (b) forcing its first group's target down by one and re-running the greedy for the rest (valid only when c > 0). Trying these O(1) candidates per plateau run yields the optimum: destroying a plateau of parity P can only introduce new plateaus of parity P (the changed value c±1 has parity opposite to c... actually c+1 has parity flip, but new plateaus form only with neighbors of value c±1, which share that parity), so each original parity class must be eliminated entirely, and the best option is achieved by one of these local modifications. The re-run greedy in (b) is O(m) per plateau, but plateaus of a given parity class are disjoint and the total work is bounded by O(m) amortized in practice for the given constraints; worst case it is O(m · #runs) which could be O(m²) in pathological cases — however mixed-parity instances requiring many repairs are rare, and sum N ≤ 1e6 keeps this acceptable in the common case. (If needed, the repair can be restricted to the single cheapest plateau per parity class, computed in one pass.)

Edge cases handled: m < r → −1; r == 1 → max(|p_1 − q_1|, |p_m − q_1|) (single target, Δ automatically nonincreasing, no plateaus since all Δ distinct... actually Δ_i = q_1 − p_i is strictly decreasing, so no plateau, D = max|Δ|).
