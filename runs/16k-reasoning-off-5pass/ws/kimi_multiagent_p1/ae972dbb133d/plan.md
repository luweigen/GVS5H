Model each cell as a degree-2 vertex in a 4-regular "medial" graph on the torus: each tile picks a perfect matching of its 4 edge-midpoints (A = one of 4 "turn" matchings, B = one of 2 "straight" matchings), and the no-dead-end condition is automatically satisfied by construction, so we must count matchings whose resulting union of cycles is consistent — i.e., count configurations where every edge-midpoint pairing forms closed loops, which is always true, so the real constraint is that the chosen matching per cell must be one of the allowed types. The condition given is equivalent to requiring the selected half-edges to match across cell boundaries, meaning each cell's tile defines which of its 4 ports are used (always exactly 2), and neighbors must agree on shared edges. This becomes: choose for each grid edge (horizontal/vertical, toroidal) whether it is "active", such that at every cell the number of active incident edges is exactly 2, and the two active edges' configuration is realizable by the tile type (B: the two active edges must be opposite; A: must be adjacent). Count weighted configurations (each cell contributes 1 way if the pattern matches its type — but A tiles have exactly 1 rotation per adjacent-pair pattern, B exactly 1 per opposite-pair pattern, so the count is just the number of valid edge-subsets). This is a degree-constrained subgraph (2-factor) problem on the H×W toroidal grid with forbidden configurations per cell, solvable by transfer matrix over rows with plug DP (connectivity-free since degree-2 constraint is local): state = which vertical edges between rows are active (W bits), transition fills horizontal edges within the row and validates each cell's degree-2 + tile-type constraint. Complexity O(H * 3^W * W) or similar per test; with HW ≤ 1e6 total and min(H,W) possibly large, choose to iterate over the smaller dimension as the bitmask width (transpose if W > H). Implement with dictionary-based sparse DP since states are limited.
