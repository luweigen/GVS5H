We need to find the minimum cost to adjust teeth lengths $(U_i, D_i)$ to $(u_i, d_i)$ such that $u_i \le U_i$, $d_i \le D_i$, $u_i + d_i = H$ for some constant $H$, and $|u_i - u_{i+1}| \le X$. The cost is $\sum (U_i - u_i) + (D_i - d_i)$. Since $d_i = H - u_i$, the constraints become $H - D_i \le u_i \le U_i$ and $u_i \ge 0, H - u_i \ge 0$. For a fixed $H$, this is a problem of finding a sequence $u_i$ within intervals $[L_i, R_i]$ (where $L_i = \max(0, H - D_i)$, $R_i = \min(U_i, H)$) minimizing $\sum |u_i - U_i|$ (since $d_i$ cost is fixed by $H$) subject to Lipschitz constraint $|u_i - u_{i+1}| \le X$. This can be solved by isotonic regression style algorithms or min-cost flow, but more efficiently by observing that the optimal $u_i$ for fixed $H$ can be found via a "taut string" or convex hull trick approach, or by modeling as a min-cost flow on a line graph. The total cost as a function of $H$ is convex, so we can use ternary search or find the optimal $H$ by checking candidates.
