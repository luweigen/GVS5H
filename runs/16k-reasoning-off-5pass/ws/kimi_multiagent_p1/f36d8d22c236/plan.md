Model the problem as a directed graph on the 26 letters: for each position i, S[i] must eventually map to T[i], so add a required edge S[i]→T[i]. If any source letter has two different required targets, it's impossible. Each operation renames one current letter to another, so we need to realize the mapping with the fewest renames, being careful about cycles (a cycle of required mappings needs one extra "buffer" rename unless a spare letter outside the cycle exists). Count edges where S[i]≠T[i] as base cost, then analyze each weakly connected component of the mapping graph: a component that is a pure cycle covering all its letters' out-edges requires +1 unless there is an unused letter available as temporary storage. Also detect impossibility when a letter must map to two targets, or when a cycle exists but all 26 letters are occupied (no buffer letter available) — actually with 26 letters, if every letter is in a cycle component and no free letter exists, a cycle can still be broken only if some letter outside the cycle can serve as buffer; if the whole alphabet is one or more cycles with no free letter, it's still solvable by using a target within... — the standard result: each cycle needs +1 operation, and it's always possible since we can pick a buffer via one extra step; but if a letter maps to itself only it's fine. Key impossibility: conflicting targets, or a required cycle where every letter in the alphabet is "blocked" (all 26 letters appear as sources with fixed distinct targets forming cycles and no free letter) — in that case answer is -1 only when a cycle needs a buffer but none exists (all 26 letters used). Compute: base = number of positions with S[i]≠T[i] counted per distinct (x→y, x≠y) edge; answer = base + (number of cycles in mapping graph among edges x≠y), with the caveat that if a cycle exists and there is no letter with out-degree 0 available as buffer (i.e., all 26 letters have a required outgoing edge), then impossible → -1.
