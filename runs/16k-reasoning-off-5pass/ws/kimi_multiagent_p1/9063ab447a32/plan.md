The cost per product is convex (k²·Pᵢ), so the marginal cost of the j-th unit of product i is (2j−1)·Pᵢ, which increases with j. The optimal strategy is to buy units in increasing order of marginal cost globally. We binary search on a threshold T: count how many units have marginal cost ≤ T, i.e. for each product, kᵢ = floor((T/Pᵢ + 1)/2) (capped by the huge stock, which never binds since M ≤ 10¹⁸ limits k to ~10⁹). Find the largest T with total count computable, then sum exact costs for units below the threshold and use remaining budget for units at the threshold. Answer = full units affordable via this greedy exchange argument.
