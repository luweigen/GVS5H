A Snowflake Tree has a center (red), x middle vertices (blue), and y leaves per middle vertex (green), so every non-center vertex is at distance 1 or 2 from the center, and all vertices at distance 2 are leaves whose parent has exactly y leaf-children. We need to delete the fewest vertices so the remaining induced connected subgraph is exactly such a 3-level structure. Root the tree arbitrarily and think of choosing a center c: then we keep a connected subtree containing c where kept nodes form levels 0,1,2, every kept level-1 node has exactly y kept leaf children (same y for all), and no other nodes are kept. Since y must be uniform, for each candidate center we need the maximum number of vertices keepable, which decomposes into independent contributions per neighbor subtree depending on how many "branches" support each possible y. Use tree DP / rerooting: for each edge direction compute, for each possible leaf-count y, the best kept vertices in that branch, then combine at each center by summing the best over children for each y and taking the max. Because y can be up to N, per-node maps keyed by y (small since branch sizes differ) keep total work near O(N log N) or O(N sqrt N); answer = N - max kept.
