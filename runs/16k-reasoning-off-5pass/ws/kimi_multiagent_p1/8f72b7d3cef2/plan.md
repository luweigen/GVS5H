For a fixed starting slime K, the reachable set of absorbed slimes always forms a contiguous interval containing K, and absorption is possible exactly while the current total size is strictly greater than the next slime on either side. Thus the optimal strategy is greedy: maintain the current interval sum and repeatedly absorb the smaller available neighbor (or any absorbable neighbor), since absorbing only increases size and never hurts future options. To answer all K efficiently, precompute prefix sums and for each K binary search the farthest right reachable boundary using the condition "sum of current interval > A_{r+1}", expanding the interval outward; symmetrically handle the left side. A two-pointer / monotonic expansion from each side gives O(N log N) or O(N) overall.
