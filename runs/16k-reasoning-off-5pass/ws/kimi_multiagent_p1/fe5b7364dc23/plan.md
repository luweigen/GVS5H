We need the sum over all subarrays of (subarray sum)^K with K ≤ 10. Expand via binomial/multinomial: (S_r - S_{l-1})^K = Σ_j C(K,j) S_r^{K-j} (-S_{l-1})^j, so the total answer is Σ_j C(K,j)(-1)^j Σ_r S_r^{K-j} (Σ_{l≤r} S_{l-1}^j). For each j, the inner quantity is a prefix-sum of powers of prefix sums, maintainable in O(1) per r. Since K ≤ 10 we can keep all power sums P_j(r) = Σ_{t≤r} S_t^j for j=0..K and update them incrementally, giving O(NK) time. All arithmetic is mod 998244353, handling the sign (-1)^j carefully.
