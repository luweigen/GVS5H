A valid coloring is a "staircase" (Young diagram shape): there is a monotone boundary such that cell (x,y) is black iff y <= f(x) for a non-increasing row-boundary function f, equivalently black iff x <= g(y) for a non-increasing column-boundary g. A key equivalent characterization: the black region is a "downset" under the product order — if (x,y) is black then every (x',y') with x'<=x and y'<=y is black; equivalently, there is no pair with a black cell strictly southeast of a white cell... more precisely no pattern where (x1,y2) is white and (x2,y1) is black with x1<x2, y1<y2 (a "2x2 inversion"). So feasibility reduces to: no given black cell (x2,y1) and white cell (x1,y2) with x1<x2 and y1<y2. This is a 2D dominance check between the B-set and W-set, solvable by sorting and sweeping.
