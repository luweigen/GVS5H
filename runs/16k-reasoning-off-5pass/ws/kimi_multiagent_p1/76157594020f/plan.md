Binary search on the answer L (minimum achievable longest run). For a candidate L, compute the minimum flips needed so no run of identical characters exceeds L. Key insight: for L >= 2, each maximal run of length len must be broken by flipping floor(len/(L+1)) characters (place flips every L+1 positions within the run), and these choices are independent per run, so total flips = sum over runs. For L == 1, the string must alternate, so compare against the two alternating patterns and take the minimum flips. Feasibility is monotone in L, so binary search works in O(n log n).
