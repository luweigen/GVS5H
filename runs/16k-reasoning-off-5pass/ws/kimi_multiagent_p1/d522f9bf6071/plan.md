This is a weighted interval scheduling variant where we pick up to 4 non-overlapping intervals maximizing total weight, with lexicographic tie-breaking on the index list. Sort intervals by right endpoint and compute, for each interval, the latest previous interval that ends strictly before it starts (binary search). Run a DP over sorted intervals with states (position, count used) storing both the best weight and the lexicographically smallest index path achieving it. Since weights are positive, ties in weight are broken by comparing reconstructed index lists. Finally reconstruct the answer from the DP table, being careful that "up to 4" with positive weights means we just take the best over counts 1..4 (empty choice only matters if all weights were non-positive, which they aren't).
