The problem asks for the number of arrays of length `n` with elements in `[1, m]` such that exactly `k` adjacent pairs are equal. We can think of this as placing `k` "equal" transitions and `n - 1 - k` "different" transitions among the `n - 1` possible adjacent positions. The number of ways to choose which positions have equal values is given by the binomial coefficient C(n-1, k). Once the positions are chosen, the first element can be any of the `m` values. Each subsequent element is then determined: if the transition is "equal", it must match the previous element (1 choice); if "different", it must be different from the previous element (m-1 choices). Therefore, the total count is C(n-1, k) * m * (m-1)^(n-1-k). We need to compute this modulo 10^9 + 7 using modular exponentiation and modular inverse for the combination.
