The problem simulates smoke movement on a grid where smoke from a previous step moves in a specific direction, and new smoke is generated at (0,0) if the cell is empty. Since N is up to 200,000, a direct simulation of all smoke particles is too slow if the number of particles grows linearly or quadratically. However, we can observe that the set of occupied cells at any time $t$ forms a specific shape relative to the wind path. We can maintain the set of occupied coordinates using a hash set (or a set of relative offsets) and update them in $O(1)$ amortized time per step. For each step $t$, we first check if $(R, C)$ is in the current set, then move all existing smoke points according to the wind direction $S[t]$, and finally add $(0,0)$ if it wasn't already present. This approach ensures an $O(N)$ total time complexity.
