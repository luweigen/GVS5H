The problem requires calculating the sum of absolute differences between the first $X_k$ elements of $A$ and the first $Y_k$ elements of $B$ for $K$ queries. A naive $O(N^2)$ approach per query is too slow given $N=10^5$. Instead, we can sort arrays $A$ and $B$ and use prefix sums to efficiently calculate the contribution of each element. For any pair of sorted subarrays, the sum of absolute differences can be computed in $O(1)$ after $O(N \log N)$ preprocessing by splitting the sum into cases where $A_i \le B_j$ and $A_i > B_j$. Since the queries specify prefixes, we need to handle the specific range $[1, X_k]$ and $[1, Y_k]$. We will sort $A$ and $B$, compute their prefix sums, and for each query, determine the split point where $A$'s elements are less than or equal to $B$'s elements within the specified ranges, then combine the results using the precomputed prefix sums.
