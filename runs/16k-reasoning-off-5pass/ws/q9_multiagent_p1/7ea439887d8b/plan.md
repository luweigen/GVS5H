The problem asks for the minimum cost to reach vertex N from vertex 1 in a directed graph where we can either traverse an edge (cost 1) or reverse all edges globally (cost X). Since reversing all edges twice returns the graph to its original state, the optimal strategy involves at most one reversal. We can model this as a shortest path problem on a graph with two states per vertex: state 0 (original orientation) and state 1 (reversed orientation). From state 0, we can move to adjacent vertices in the original graph (cost 1) or switch to state 1 (cost X). From state 1, we can move to adjacent vertices in the reversed graph (cost 1) or switch back to state 0 (cost X). We run Dijkstra's algorithm starting from (1, 0) to find the minimum cost to reach (N, 0) or (N, 1).
