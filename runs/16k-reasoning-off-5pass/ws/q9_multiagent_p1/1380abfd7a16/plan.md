The problem involves inserting elements into an array at specific positions, which naively takes $O(N^2)$ time. To optimize, we can reverse the process: instead of inserting $i$ into the current array, we determine the final position of each number $i$ by simulating the removal of elements from $N$ down to $1$. We maintain a list of available positions (initially $1$ to $N$) and use a data structure like a Fenwick tree or Segment Tree to efficiently find the $k$-th available position and mark it as occupied, allowing us to reconstruct the final array in $O(N \log N)$.
