Since the array is sorted, a greedy strategy works: iterate from the right (largest elements) to the left. For each element $A_j$ (potential bottom), try to pair it with the largest available element $A_i$ (potential top) such that $A_i \le A_j / 2$ and $i < j$. If such an $A_i$ exists, pair them and remove both.
