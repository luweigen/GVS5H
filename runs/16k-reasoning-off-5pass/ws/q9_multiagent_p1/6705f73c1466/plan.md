The goal is to move all '1's to a contiguous block with minimum swaps. This is equivalent to finding a target position $k$ (where the block of ones ends) such that the total distance the ones need to travel to reach positions $[N - \text{count}, N - \text{count} + 1, \dots, k]$ is minimized. Since the relative order of identical items doesn't change the minimum swap count, we can assume the $i$-th '1' from the left moves to the $i$-th available slot in the target block. We iterate through all possible end positions for the block of ones (from the first '1' to the last '1') and calculate the cost for each, taking the minimum.
