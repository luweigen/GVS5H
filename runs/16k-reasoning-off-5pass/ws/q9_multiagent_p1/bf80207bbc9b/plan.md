The problem asks us to minimize the sum of 1s in a grid by flipping entire rows (Operation X) or entire columns (Operation Y). Since $W$ is very small ($W \le 18$), we can iterate through all possible subsets of columns to flip. For each fixed set of column flips, the decision to flip a row becomes deterministic: for each row, we check its current state (after column flips) and flip it if it contains more 1s than 0s. We calculate the total sum for each of the $2^W$ column configurations and take the minimum.
