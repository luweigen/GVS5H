The problem asks us to maximize the total number of units purchased given a budget $M$ and a cost function $k^2 P_i$ for buying $k$ units of product $i$. Since the cost function is convex ($k^2$), the marginal cost of each additional unit increases, meaning we should always prioritize buying the cheapest available "next unit" regardless of which product it belongs to. We can treat the problem as selecting individual unit increments. However, simulating unit by unit is too slow. Instead, we can use binary search on the answer (total units $X$) or a greedy approach with binary search on the "marginal cost threshold". A more efficient approach is to realize that if we decide to buy $x_i$ units of product $i$, the cost is $\sum x_i^2 P_i$. This looks like we want to distribute the budget to maximize $\sum x_i$. Since the cost grows quadratically, the optimal strategy involves picking units with the lowest marginal costs. The marginal cost of the $k$-th unit of product $i$ is $(k^2 - (k-1)^2)P_i = (2k-1)P_i$. We need to find the largest $X$ such that the sum of the $X$ smallest marginal costs is $\le M$. This can be solved by binary searching on the maximum marginal cost threshold $T$. For a fixed $T$, we can calculate how many units we can buy from each product where $(2k-1)P_i \le T$, sum them up, and check if the total cost is within $M$.
