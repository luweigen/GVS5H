To maximize the number of kagamimochi, we should greedily pair the smallest available mochi that can sit on top of the largest possible mochi. Since the input is already sorted, we can use a two-pointer approach: one pointer at the beginning (smallest mochi) and one at the end (largest mochi). We attempt to pair the smallest with the largest; if the condition $A_{small} \leq A_{large} / 2$ holds, we form a pair and move both pointers inward. If not, the smallest mochi is too large to sit on the current largest, so it cannot be part of any valid pair with any remaining mochi (since all other remaining mochi are even smaller), so we discard it and move the small pointer forward. We repeat this until pointers meet.
