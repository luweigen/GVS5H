The strategy is to determine the optimal order of deleting distinct values to minimize swaps. The optimal order is to delete values in the order of their first appearance in the array. The total operations equal the total number of pairs of distinct elements minus the number of "consistent" pairs (where a value appearing earlier in the array is also deleted earlier). We calculate the total distinct pairs and then use a Fenwick Tree to efficiently sum the counts of previously seen values that should be deleted before the current value.
