**Core Difficulty**:
The problem asks for the minimum operations to empty an array using adjacent swaps and prefix deletions of identical values. The key insight is recognizing that the order of deletion matters significantly. If we delete a value $X$ while another value $Y$ is still present, all instances of $X$ must be moved to the front (past all $Y$'s) if $X$ appears after $Y$ in the original array, or vice versa. Specifically, to minimize swaps, we should delete values in the order of their **first appearance**. If we delete a value that appears later in the array while an earlier value is still present, we incur unnecessary swaps to bring the later value to the front.
