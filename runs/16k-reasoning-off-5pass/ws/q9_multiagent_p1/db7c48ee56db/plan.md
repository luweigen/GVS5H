The constraint $\binom{N}{K} \le 10^6$ is the key, implying that the number of ways to choose $K$ elements is small enough to iterate through all combinations directly. We will generate all possible subsets of size $K$ from the input array $A$, calculate the XOR sum for each subset, and track the maximum value found. Since $N$ can be up to $2 \times 10^5$, we must use an efficient combination generation method (like `itertools.combinations`) rather than a naive recursive backtracking that might hit recursion limits or be slower, though `itertools` is implemented in C and very fast.
