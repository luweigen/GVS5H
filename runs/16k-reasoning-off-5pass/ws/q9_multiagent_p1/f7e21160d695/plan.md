The problem asks to minimize the sum of bottleneck distances $f(A_i, B_i)$ by permuting $B$. The bottleneck distance $f(u, v)$ is the minimum possible maximum edge weight on a path between $u$ and $v$, which is equivalent to the path weight in the Minimum Spanning Tree (MST). We can solve this by first constructing the MST of the graph. Then, we sort the edges of the MST by weight in ascending order. For each distinct weight $W$ in the sorted edges, we consider the connected components formed by edges with weight $\le W$. If $A_i$ and $B_i$ are in the same component, their bottleneck distance is at most $W$. To minimize the sum, we should greedily match pairs $(A_i, B_i)$ that are already connected with the smallest possible weights. We can iterate through the sorted edge weights, union sets of vertices, and whenever a pair $(A_i, B_i)$ becomes connected, we assign the current weight to one of them (prioritizing pairs that are just now connected to avoid overcounting or using larger weights unnecessarily). Since we need to match specific $A_i$ to specific $B_i$, we can maintain a list of unmatched $A_i$'s and $B_i$'s. As we process edges, if an edge connects a component containing some unmatched $A$'s and some unmatched $B$'s, we can form pairs between them with cost equal to the current edge weight. We repeat this until all pairs are matched.
