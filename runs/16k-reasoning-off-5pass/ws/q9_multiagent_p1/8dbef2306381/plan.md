The problem asks for reachability from square 1 to N with jump constraints [A, B], avoiding "bad" squares defined by M disjoint intervals. Since N is up to $10^{12}$, we cannot simulate every square. However, the "bad" intervals are few ($M \le 2 \times 10^4$) and the jump range is small ($B \le 20$). We can model this as a shortest path or reachability problem on a compressed graph where nodes are the start of each bad interval and the final destination N. We will perform a BFS starting from 1, expanding only to the boundaries of the bad intervals and N, skipping any squares inside bad intervals.
