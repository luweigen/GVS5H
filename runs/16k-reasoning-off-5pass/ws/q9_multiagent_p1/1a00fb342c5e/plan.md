This problem models the constraints as a system of XOR equations on a graph where indices $1 \dots N$ are nodes and each $(X_i, Y_i, Z_i)$ is an edge with weight $Z_i$. We can decompose the graph into connected components. For each component, we arbitrarily assign a value (0) to one node and propagate the XOR constraints to determine all other nodes in that component. If any contradiction arises during propagation (i.e., a node is assigned two different values), no solution exists. To minimize the sum, if a component is bipartite (no odd cycles), we can choose the assignment that minimizes the sum of values in that component by trying both possible root assignments (0 or 1) and picking the better one. If the component contains an odd cycle, the values are fixed, and we must check for consistency.
