The problem requires summing the max and min of all subarrays with length at most $k$. A naive $O(N^2)$ approach iterating over all valid subarrays will time out given $N \le 80000$. We need an efficient sliding window approach using monotonic deques (or a segment tree/monotonic queue with lazy removal) to track the current maximum and minimum in $O(1)$ amortized time as we extend the window. Specifically, we can iterate through each ending position $i$, maintain a window $[j, i]$ where $i - j + 1 \le k$, and efficiently query the max/min in this window. Since the constraint is "at most $k$", we must sum contributions for all valid start positions $j$ for each $i$. A common optimized technique involves calculating the contribution of each element as the max/min for specific ranges of subarrays, which can be done by finding the nearest smaller/larger elements to the left and right within the $k$-limit.
