The problem asks to maintain the sum over all monotone paths from (1,1) to (H,W) of the product of cell values, under point updates. The grid has H rows and W columns with HW ≤ 200,000, and Q ≤ 200,000 queries. The values are modulo 998244353.

Key observation: The sum S[i][j] over all paths from (1,1) to (i,j) satisfies the recurrence:
S[1][1] = A[1][1]
S[i][1] = A[i][1] * S[i-1][1] for i > 1
S[1][j] = A[1][j] * S[1][j-1] for j > 1
S[i][j] = A[i][j] * (S[i-1][j] + S[i][j-1]) for i,j > 1

The answer after each update is S[H][W].

When A[x][y] changes, only cells with i ≥ x and j ≥ y are affected (the down-right quadrant). This region has size (H-x+1)*(W-y+1), which in the worst case is O(HW) ≈ 200,000. However, with Q up to 200,000, a naive O(HW) per update would be too slow (up to 4e10 operations).

We need a data structure that supports point updates and queries in O(log^2 N) or O((H+W) log N) time.
