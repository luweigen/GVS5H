We need the shortest palindrome that starts with the given string S. The approach is to find the longest suffix of S that is already a palindrome, then append the reverse of the remaining prefix to the end. To compute this efficiently for |S| up to 5·10⁵, we use KMP on a specially constructed string: `P = reverse(S) + '#' + S`. The length of the longest prefix of reverse(S) that matches a suffix of S (i.e., the longest palindromic suffix of S) is given by the final value of the prefix function π applied to the whole string P. The answer is S + reverse(prefix_to_add).
