We need to sum (min + max) for every subarray whose length L is between 1 and k. For each subarray, its min and max are two separate contributions. A classic technique: for each position i, count how many subarrays have `nums[i]` as the minimum (and similarly as the maximum), weighted by their length, then sum. We can do this with monotonic stacks: one pass to compute, for each i, the number of subarrays where i is the minimum (`leftMin[i]`, `rightMin[i]`), and one pass for maximums. For a subarray length L, its contribution to the answer from position i is `nums[i] * count`, where `count` is the number of subarrays of length up to k that include i and where i is the extreme. To enforce the length cap k, we must clamp the contribution: each position i contributes only from subarrays that end at most k-1 positions after i (for "right" side) and begin at most i positions back (for "left" side). Efficiently, for each i, the effective right distance is `min(rightExt[i], k-1)`, and the effective number of subarrays where i is the minimum is `leftExt[i] * min(rightExt[i], k)` (or similar). We'll compute left/right distances to previous/next smaller (for min) and greater (for max) elements using monotonic stacks. Then sum contributions while respecting the k cap via the `min(..., k)` clamp. Complexity O(n).
