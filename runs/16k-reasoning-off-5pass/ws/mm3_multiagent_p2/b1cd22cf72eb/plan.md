We need to choose a target H such that after reductions, each U_i + D_i = H (we can only reduce teeth) and |U_i - U_{i+1}| ≤ X. Let S_i = U_i + D_i (initial sum). Since only reductions are allowed, we must have H ≤ S_i for all i, and the cost to make sum equal to H is (sum over i of (S_i - H)) = total_sum - N*H. The teeth must individually stay non-negative, so after grinding, U_i' = S_i - H + D_i' but we need both U_i' ≥ 0 and D_i' ≥ 0. However the operation is: we can reduce any tooth, upper or lower, by 1 yen each. To achieve U_i' + D_i' = H with U_i' ≤ U_i, D_i' ≤ D_i, we need H ≤ S_i (so feasible sum). The minimum cost to achieve exactly H is (S_i - H) regardless of distribution between U_i' and D_i' (as long as both stay ≥ 0, which is possible iff H ≤ S_i, and we can always distribute: set U_i' = min(U_i, H), D_i' = H - U_i', ensure D_i' ≤ D_i by H ≤ S_i). So cost = sum(S_i) - N*H.

The real challenge is constraint on U_i'. We need U_i' to satisfy |U_i' - U_{i+1}'| ≤ X. We have freedom in choosing U_i' as long as 0 ≤ U_i' ≤ U_i and U_i' + D_i' = H, D_i' = H - U_i' ≤ D_i, so U_i' ≥ H - D_i = H - (S_i - U_i) = U_i - (S_i - H). Let lower bound L_i = max(0, H - D_i) and upper bound R_i = min(U_i, H). Both feasible ranges depend on H.

Goal: pick H and U_i' in [L_i, R_i] such that adjacent diff ≤ X, minimizing total cost = sum(S_i - H) = sum S_i - N*H. So we want to maximize H subject to the chain constraints with feasible intervals.

Approach: Binary search on H. For a given H, we compute the feasible range of U_i' (or U_i in resulting teeth) and check if a sequence with |diff| ≤ X exists using interval DP. Standard technique: maintain allowed interval [lo_i, hi_i] = [L_i, R_i]. Then propagate: lo_1 = L_1, hi_1 = R_1, and for i>1, lo_i = max(L_i, lo_{i-1} - X), hi_i = min(R_i, hi_{i-1} + X). Feasible if at end hi_N ≥ lo_N (i.e., interval non-empty). Check this for each H. Binary search largest H where feasible. Then answer = sum S_i - N * H_max.

Complexities: O(N log MAX). MAX = up to 2e9.
