We need to choose k disjoint subarrays of length x and convert each into a constant (all equal) using minimum total absolute adjustments. The optimal value for any subarray is its median (real-valued median minimizes sum of absolute deviations), and the cost is the sum of absolute deviations to that median. Since x can be up to n, we precompute, for every window of length x, the minimum cost to make it constant. We then need to select k non-overlapping windows minimizing total cost — a DP over positions (classic weighted interval scheduling). Because k ≤ 15, we can use DP[i][c] = min cost using c subarrays among first i positions, with i indexing windows (i-th window starts at i, length x). Transitions: DP[i][c] = min(DP[i-1][c], DP[i-x][c-1] + cost[i]) with safe sentinels. The answer is DP[last][k]. Complexity O(n log n + n*k).
