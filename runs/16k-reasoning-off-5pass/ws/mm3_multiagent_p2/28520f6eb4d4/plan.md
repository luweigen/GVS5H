We need to find the maximum height `h` at coordinate `0` (x=0) such that at least one building is not visible. From point P=(0,h), a building i is visible iff the line segment from P to some point on building i does not intersect any other building's interior. For a building at X_i, the "shadow" of any other building j (to the same side of P) that lies between them can block view. The limiting factor for each building is the closest taller (or equal) building between P and it. We treat left and right sides independently. For right side, we want a height h such that for some i, the line from (0,h) to the top (X_i, H_i) goes below the top of every intervening building. Since buildings are points in 2D (negligible width), the critical obstruction for building i is the building j immediately before i in order that is the tallest so far. As h increases, the line to building i becomes steeper; we need the line to be above the top of each intervening blocking building. The maximal h at which building i is still hidden is determined by the line that just grazes the top of its tallest predecessor. We compute for each building the threshold h_i = (H_i * X_prev - H_prev * X_i) / (X_i - X_prev) where (X_prev, H_prev) is the previous building that is the maximum height so far. If this threshold is negative, we ignore it (height must be >=0). The answer is the maximum of these valid thresholds, unless that maximum is <= 0 (then answer is 0), and if all buildings are visible even at h=0 we output -1. Symmetrically for left side we process reversed arrays.
