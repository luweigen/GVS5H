We need to transform `s` into a "good" string where every distinct character appears the same number of times. Allowed ops: delete any char (cost 1), insert any char (cost 1), and increment a char to the next letter (cost 1, but `z` cannot wrap). The key insight: increment operations can change a character into another existing character, effectively merging two character groups. We can think of the final multiset of characters as having some target frequency `k` for each character that appears, and characters not in the final set must be deleted or incremented away. For each candidate `k` (1 ≤ k ≤ max frequency, plus possibly 0 meaning we delete everything), we compute the minimum cost: deletions to reduce any count above `k` to `k`, increments to raise any count below `k` to `k` (or to convert characters we don't want into ones we want), and insertions to raise counts below `k` up to `k`. We also need to decide which subset of letters will be the final set; we can greedily pick the letters with highest counts to minimize cost. Iterate over all `k`, compute cost, take minimum.
