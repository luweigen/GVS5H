We need to count, for each M from N-1 up to N(N-1)/2, the number of connected simple labeled undirected graphs on N vertices where the BFS distance parity from vertex 1 has exactly N/2 even and N/2 odd vertices (N is even). We will use exponential generating functions (EGFs) for connected graphs by parity of distance from a root, then convert to ordinary counts via Stirling numbers of the second kind, and finally extract the coefficient of x^M in the resulting polynomial modulo prime P. Since N ≤ 30, we can do exact integer arithmetic with Python's big ints and reduce mod P at the end.
