The operation divides two numbers by 4 (floor) simultaneously, so it reduces the total "weight" of the array. For a single number x, the number of times we need to halve-by-4 to reach 0 is `f(x) = number of digits in base 4 representation of x` (i.e., `floor(log4(x)) + 1`). Each operation can apply at most two such reductions (one to each of the two chosen numbers). Therefore, the minimum number of operations for a multiset is `ceil(sum(f(x)) / 2)`. We need to compute `sum_{x=l}^{r} f(x)` efficiently for each query, then sum `ceil(total/2)` over all queries.

To compute `S(r) = sum_{x=1}^{r} f(x)` quickly, we use the fact that numbers with `f(x) = k` are exactly those in `[4^{k-1}, 4^k - 1]`. So `S(r) = sum_{k=1}^{K-1} k * (4^k - 4^{k-1}) + K * (r - 4^{K-1} + 1)`, where `K = floor(log4(r)) + 1`. We precompute prefix sums of `k * 4^k` to answer each `S(r)` in O(log r). Then `sum_{x=l}^{r} f(x) = S(r) - S(l-1)`. Finally, answer for each query is `(total + 1) // 2`, accumulate.
