We need to simulate Santa's axis-aligned moves, counting distinct houses visited. Since moves are axis-aligned, a house (x,y) is visited on a horizontal segment iff its y equals the current y and its x lies between the start and end x; similarly for vertical segments. To count efficiently, we can pre-group houses by y-coordinate (for horizontal moves) and by x-coordinate (for vertical moves). For each coordinate, sort the house positions along the line. For a move, we binary-search the sorted array to find the indices of houses in the traversed range, and add the count of those not yet visited. For deduplication, we maintain a global set of visited house indices (or a boolean array), but checking membership for each found house is O(log N) per house. Since total matched houses across all moves is at most N, total work is O(N log N + M log N). Use Python integers (unbounded) for coordinates.
