
## ideation
The problem asks for the minimum number of stair moves (vertical moves) to travel from floor Y in cell (A,B) to floor Z in cell (C,D) in an H×W grid of buildings with given heights. Horizontal moves via walkways are free if both adjacent buildings have at least the current floor.

Key observations:
- Horizontal moves are free, so the cost depends only on floor changes.
- We can move vertically within a building at cost 1 per floor.
- To move horizontally at floor f, both cells must have height ≥ f.
- The problem reduces to finding a path in a graph where nodes are (component, floor) and edges have weight 1 (floor changes). Components at floor f are connected components of cells with height ≥ f.
- Moving down is always possible (any cell in the component has height ≥ f ≥ f-1), but moving up requires the component to contain a cell with height ≥ f+1.
- The component structure only changes at floor values that are heights of cells. There are at most H*W distinct heights.
- We can compress floors into intervals between distinct heights. Within an interval, the set of active cells is constant.
- The state can be compressed to (component, layer) where layer corresponds to a height interval.
- We need to answer Q queries (up to 200k) with arbitrary Y and Z.
