This is a classic result: if we have two sequences of length K, and we have a bijection f such that 2*s_j <= l_{f(j)}, then there exists a permutation g such that 2*s_j <= l_{g(j)} and g is the identity after sorting? Actually, the condition for a perfect matching in a bipartite graph where the adjacency is defined by 2*s <= l is that when both sides are sorted, the i-th small can be matched with the i-th large. This is true because the adjacency matrix has the property that if we sort both sides, the set of feasible larges for s_i is a suffix of the larges. By Hall's marriage theorem, a matching exists iff for all j, the j-th smallest small has at least j feasible larges. The feasible larges for s_j are those with index >= some threshold. The j-th smallest small requires that there are at least j larges that are >= 2*s_j. The largest j-th small is s_{j-1} (0-indexed). The condition that there are at least j larges >= 2*s_{j-1} is equivalent to the j-th largest large being >= 2*s_{j-1}. Since we can choose the K larges to be the K largest elements in the subarray, if there is any matching, then in particular, the K largest elements must contain at least K elements that are large enough.
