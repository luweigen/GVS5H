Then for each j (end index), we need to count i in [0, p] such that tp[i] == tp[j+1]. Since we process j in order, we can maintain a frequency map of tp values for indices up to current limit (which is p). As we move j forward, p is non-decreasing (or stays same). So we can maintain a pointer `limit` and a dictionary `cnt` storing counts of tp[0..limit]. Initially limit = -1, cnt empty. As we iterate j from 0 to n-1:

    - Then ans += cnt[tp[j+1]] (since we want to count i in [0,p] with same tp).
