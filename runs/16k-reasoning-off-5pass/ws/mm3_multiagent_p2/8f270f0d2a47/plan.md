We need to count numbers in [l, r] where product of digits is divisible by sum of digits. Since r < 10^9 (max 9 digits), we can do a digit DP that tracks both sum and product of digits, with a memoized state (pos, tight, leadingZero, sum, product). The product can be large; we compress by storing only non-zero digits' product and treat zero specially: if any digit is 0, product = 0, which is divisible by any positive sum (sum >= 1 when number is positive), so such numbers are automatically beautiful. In DP, we track "hasZero" flag: if any non-leading digit is 0, product is 0 and the number is beautiful regardless. For numbers with no zero digit, we keep the actual product (max product of 9 digits 9^9 ≈ 387M, fits in int). After processing all digits, if hasZero is True, return 1; else return 1 if sum != 0 and product % sum == 0 else 0. We compute f(r) - f(l-1) to get the answer.
