We need to find a connected subgraph (subtree) of the given tree where every internal vertex has degree exactly 4 in the subgraph and leaves have degree 1, with at least one degree‑4 vertex. This is equivalent to selecting a connected set of vertices such that the induced edges form a tree where each vertex’s degree in the subgraph is either 1 or 4, and not all vertices are leaves.

We can solve it with tree DP. Root the tree arbitrarily (say at 1). For each node `u` and each possible degree `d ∈ {0,1,4}` that `u` can have in the final subgraph (0 = not included, 1 = included as leaf, 4 = included as internal), compute the maximum number of vertices in a valid connected component that contains `u` and respects the degree constraints, where the component is entirely inside the subtree of `u` and `u` is the “top” of that component (its parent edge is not used). The DP transitions combine children sub‑components that attach to `u` via exactly `d` edges (i.e., we pick `d` children whose components have `u` as a leaf, i.e., child state = 1). The rest of the children must be excluded (state 0). We take the best sum of sizes of those `d` child components plus 1 for `u` itself.

The DP is O(N * K^2) where K=3 (states), but we need to pick the best `d` children among possibly many. Since `d` is at most 4, we can simply try all subsets of children of size `d` (C(deg, d)) – deg can be large, so we need a smarter way. We can precompute for each child the best size when the child is attached as a leaf (state 1) and when excluded (state 0). Then for each `u` we need the sum of the top `d` values of `gain = dp[child][1] - dp[child][0]`. We sort these gains descending and take the prefix sum. Complexity O(N log N) overall.

Finally, the answer is the maximum over all states `d ∈ {1,4}` of `dp[u][d]` for any node `u` (state 0 cannot be the whole component). If no such state yields a valid alkane (i.e., max ≤ 0 or no degree‑4 vertex), output -1.

Edge cases: a component with a single vertex has degree 0, not allowed. A component with exactly two vertices has both degrees 1, not allowed (needs at least one degree‑4). So we only consider states 1 and 4. Also we must ensure the component is connected – the DP ensures connectivity because we only attach children that include `u`.
