We need to maximize the shortest path distance from 1 to N after setting exactly K edges to weight 1 (others weight 0). Since N ≤ 30 and M ≤ 100, we can use a meet-in-the-middle / subset DP over edges. Split edges into two halves (≈50 each). For each subset of the left half, compute the resulting shortest distance from 1 to N using BFS on a graph where selected edges have weight 1 and unselected edges weight 0 (i.e., we count number of selected edges along a path). This is a 0/1 BFS (deque) per subset, giving O(2^(M/2) * (N+M)). Similarly for the right half. Then we need to combine subsets where total selected edges = K: for each left subset with `c` selected edges and distance `dL`, we need a right subset with `K-c` selected edges and distance `dR` such that `dL + dR` is maximized. For each `c`, we store the maximum `dR` achievable among right subsets with exactly `K-c` selected edges. Then answer = max over c of dL + max_dR[c]. Complexity ~ O(2^(M/2) * (N+M)) which is feasible.
