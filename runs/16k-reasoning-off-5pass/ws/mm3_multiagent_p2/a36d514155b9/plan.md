We need the sum of Manhattan distances over all unordered pairs of pieces, summed over every arrangement of choosing k distinct cells from an m×n grid. Because Manhattan distance separates into x- and y-contributions, the total sum equals (sum of x-contributions) + (sum of y-contributions). For a fixed pair of cells, the probability they both appear in a random k-subset is C(mn-2, k-2) / C(mn, k). Hence we can sum |x_i - x_j| (or |y_i - y_j|) over all unordered cell pairs and multiply by that probability. Let Sx = sum_{i<j} |x_i - x_j| for the m×n grid (with rows 0..m-1). A row i appears n times, so Sx = n^2 * sum_{i<j} |i-j| = n^2 * (m^3 - m)/6. Similarly Sy = m^2 * (n^3 - n)/6. The total sum across arrangements is (Sx + Sy) * C(mn-2, k-2) * inv(C(mn, k)) mod MOD. Since division is by C(mn, k), we can compute a single modular fraction using factorials/inverses. All needed factorials up to m*n ≤ 1e5, so O(mn) precomputation is fine.
