We need the maximum number of disjoint pairs (i, j) with i < j and A_i ≤ A_j / 2. Since the array is sorted, a classic greedy works: use two pointers, the smallest available mochi as the "top" and the largest available as the "bottom". If the top fits (A[l] ≤ A[r] / 2), pair them, move both pointers inward, increment answer. Otherwise, the top is too large for this bottom, so discard the bottom (move r left). This yields the maximum K in O(N).
