We process N intervals `[L_i, R_i]` and Q queries `X`. For each query we simulate rating increases: while current rating `x` is ≤ maxR (5e5), we add the number of intervals covering `x` (i.e., contests where current rating is in the range). Using a difference array `cnt[l] += 1, cnt[r+1] -= 1`, we build a prefix sum `cover[x] =` number of intervals covering rating `x`. Then simulate: `x += cover[x]`; repeat until `cover[x] == 0` or `x > MAX`. Since `cover[x] ≥ 1` while there are more contests to apply, rating increases monotonically and at most MAX steps per query. Overall O(N + Q*MAX) would be too slow; instead we can accelerate by binary lifting: precompute `next[x] = x + cover[x]` and `jump[k][x]` = rating after `2^k` jumps from `x`. For each query, apply jumps while `cover[current] > 0` (i.e., while there is still a contest that will increase rating). Complexity: O((MAX) log MAX + Q log MAX).
