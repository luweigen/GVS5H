The reachable set expands in "waves" of size A…B until it hits a bad interval, then continues from after it. The key observation: from any safe square, we can reach any square in the interval `[x+A, x+B]` (if safe). Thus a maximal reachable safe prefix ends just before a bad interval, then resumes after it. We can simulate this wave propagation in O(M) time: maintain the furthest reachable index `right` and the furthest reachable "landing" `next_right = right + B` constrained by `right + A`. For each bad interval, if `right < L`, we are stuck before it; otherwise if `next_right < L`, we extend `right` to `min(next_right, L-1)`; else we jump `right` to `max(right, R)` and recompute. This greedy works because step ranges are contiguous and we always take the maximum reachable.
