Model the game as: each move must add a new index to S (if not already present) or decrement an already‑present index. Once all N indices are in S, the next move that triggers the condition wins. The crucial observation: a player can only "activate" an index i on the first time it is chosen; afterwards it merely consumes one unit from A_i. Therefore the number of useful "activating" moves is exactly N, after which the remaining moves are pure decrements until some A_i becomes zero. The parity of (N + total remaining decrements after activation) determines the winner. A simpler equivalent: simulate optimal play where both players prioritize activating new indices; the player forced to make the (N+1)-th overall move loses if there is no remaining decrement, otherwise the last decrement move wins. Compute total sum S = ΣA_i, then check parity of (S - N). If (S - N) is odd → Fennec wins (gets the final decrement), else Snuke wins.
