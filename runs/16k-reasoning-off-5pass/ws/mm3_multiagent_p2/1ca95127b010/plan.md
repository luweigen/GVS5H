We will solve this by tracking the difference between S and T as we sweep left to right. The key insight is that Operations A and B allow us to "shift" a block of X zeros followed by Y ones (or vice versa) by exactly one position: Operation A moves a `0^X 1^Y` pattern one step right, and Operation B moves a `1^Y 0^X` pattern one step right. This means any run of consecutive positions where S and T differ can be repaired by repeatedly applying operations at its leftmost differing position, greedily. For each position `i` from 0 to N-1, if `S[i] != T[i]`, we check the window starting at `i` of length `X+Y`. If it matches the required pattern (`S[i..i+X-1] = 0` and `S[i+X..i+X+Y-1] = 1` for A, or the reverse for B), we apply the operation by reversing the segment `S[i..i+X+Y-1]`. This corresponds to swapping the two blocks. We continue; if at any step the pattern doesn't match, output `No`. After processing all positions, if the strings are now equal, output `Yes`.
