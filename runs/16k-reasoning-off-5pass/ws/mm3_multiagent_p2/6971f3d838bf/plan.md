Since `n ≤ 10^5`, iterating over all distinct values is feasible.

For a fixed `x`, the array is split into contiguous segments of elements not equal to `x`. The maximum subarray sum avoiding `x` is the maximum Kadane sum over these segments. So we need, for each `x`, the max Kadane sum across its segments.

We can precompute for each position `i` the Kadane prefix (`pref[i]`) and suffix (`suf[i]`) maximum subarray sum ending at `i` and starting at `i`.
