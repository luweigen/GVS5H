We need the minimum number of flips in the original length-`3^N` string so that the final majority (after N reductions) flips from its current value to the opposite. Each reduction step takes the per-triple majority; we can decide a target value for each length-3 block recursively.

We process the tree bottom‑up (DFS from the root of length 1, expanding into 3 children of size `3^{k-1}`). At each node we know its current value `cur` (0 or 1) from the input. If `cur` already equals the target we want, we can keep it with 0 extra flips below it and force each of its 3 children to have their current value as well (so their subtrees contribute 0). If `cur` differs from the target, we must flip at least one child. To minimise flips we recursively compute for each child two numbers: cost to make the child’s value = 0, and cost to make the child’s value = 1. Let `c0_i`, `c1_i` be those costs. To make the parent’s majority equal `t` we need the child values to be `(t,t,t)` (any of the 3‑tuples with majority `t`). The minimum cost is `min(c_t_1 + c_t_2 + c_t_3, c_{1-t}_i + c_t_j + c_t_k)` for the three permutations. Recursing yields the answer.

Recursion depth ≤ 13, total nodes ≈ `(3^{N+1}-1)/2` (≤ 2.2·10^6 at N=13) which is fine in Python.
