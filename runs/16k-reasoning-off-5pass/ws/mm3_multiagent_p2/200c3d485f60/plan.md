We need to count arrays of length `n` over `[1..m]` with exactly `k` equal-adjacent pairs. An array with `k` equal pairs is formed by choosing `n-k-1` positions to break the equality, splitting the array into `n-k` "blocks" of equal values. Each block's value is chosen independently from `m` values. For the first block we have `m` choices; for each subsequent block, the value must differ from the previous block, giving `m-1` choices. Additionally, we need to choose which `n-k-1` of the `n-1` adjacent gaps are "breaks". So the count is `C(n-1, k) * m * (m-1)^(n-k-1)`. We compute factorials and inverse factorials up to `n` (or up to `n-1`) using Fermat's little theorem for modular inverses, then apply the formula modulo `MOD = 10^9+7`. Edge cases: when `n-1 < k` answer is 0; when `k = n-1` the exponent is 0 so the factor is just `m`.
