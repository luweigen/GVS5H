The problem asks for the number of arrays of length `n` where elements are in `[1, m]` and exactly `k` adjacent pairs are equal. We can think of this as choosing `k` positions out of the `n-1` possible adjacent slots to be "equal" (same value), and the remaining `n-1-k` slots to be "different" (different values). For the `k` equal slots, once the value of the first element in a pair is chosen, the second is fixed. For the `n-1-k` different slots, each transition offers `m-1` choices. The first element of the array can be any of the `m` values. The total count is `m * C(n-1, k) * (m-1)^(n-1-k)`, where `C` is the binomial coefficient. We need to compute this modulo 10^9 + 7.
