Since N is small (≤ 30), we can iterate through all possible shortest path lengths L from 0 to N-1. For a fixed length L, we check if it's possible to select K edges with weight 1 such that the shortest path from 1 to N is at least L. This is equivalent to checking if there exists a set of K edges whose removal (or weighting) breaks all paths of length < L. We can model this as a maximum flow problem where we try to "block" all paths of length < L using at most K edges. If the max flow is ≤ K, then length L is achievable. We find the maximum such L.
