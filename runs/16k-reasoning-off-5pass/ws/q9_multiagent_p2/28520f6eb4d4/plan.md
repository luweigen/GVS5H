The problem asks for the maximum height $h$ at $x=0$ such that we cannot see *all* buildings. This is equivalent to finding the minimum "blocking height" required to hide at least one building from view. A building $i$ is hidden if there exists a building $j$ (with $X_j > X_i$) that blocks the line of sight from $(0, h)$ to any point on building $i$. The critical condition for building $i$ being hidden by building $j$ occurs when the line from $(0, h)$ just grazes the top of building $j$ and passes below the top of building $i$. We need to calculate the minimum $h$ required to hide *any* building $i$ using *any* subsequent building $j$ as an occluder. The answer is the minimum of these critical heights over all pairs $(i, j)$ where $j > i$. If no building can be hidden (i.e., even at $h=0$ all are visible), output -1.
