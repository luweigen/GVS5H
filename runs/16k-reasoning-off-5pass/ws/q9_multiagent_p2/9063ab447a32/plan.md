The problem asks us to maximize the total number of units purchased given a budget $M$ and a cost function where buying $k$ units of product $i$ costs $k^2 P_i$. Since the cost function is convex ($k^2$), the optimal strategy is to greedily buy units one by one, always choosing the product that offers the lowest marginal cost for the next unit. The marginal cost of buying the $k$-th unit of product $i$ is $(k^2 - (k-1)^2)P_i = (2k-1)P_i$. We can simulate this process using a min-heap to efficiently retrieve the next cheapest unit, but since $M$ is up to $10^{18}$, a direct simulation is too slow. Instead, we can use binary search on the maximum number of units $K$ we can buy.
