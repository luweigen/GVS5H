The problem requires finding the maximum subarray sum after removing all occurrences of at most one integer value. Since the array length is up to $10^5$, we cannot simulate the removal for every unique number and run Kadane's algorithm each time (which would be $O(N^2)$). Instead, we can use a prefix-suffix approach: for each unique number $x$, calculate the maximum subarray sum in the array excluding all instances of $x$. This can be efficiently done by precomputing prefix maximum subarray sums (ending before each index) and suffix maximum subarray sums (starting after each index), then combining them with the best subarray entirely within the gaps between occurrences of $x$. We also need to consider the case where no operation is performed.
