The problem asks for the sum of numbers formed by concatenating permutations of $1$ to $N$. We can calculate the contribution of each digit position (units, tens, hundreds, etc.) independently. For a specific position $k$ (representing $10^k$), we determine how many times each number $x \in \{1, \dots, N\}$ appears at that position across all $N!$ permutations. A number $x$ appears at position $k$ if it is placed at index $i$ in the permutation such that the total number of digits from indices $i+1$ to $N$ is exactly $k$. We precompute the digit lengths of all numbers $1$ to $N$, then use combinatorics to count valid placements for each length group.
