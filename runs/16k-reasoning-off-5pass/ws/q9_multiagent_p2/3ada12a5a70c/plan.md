The problem asks us to select $k$ points from a given set to maximize the minimum Manhattan distance between any pair of selected points. This is a classic "maximize the minimum" problem, which can be efficiently solved using binary search on the answer (the distance). We will binary search for the maximum possible distance $D$. For a fixed $D$, we need to check if it's possible to select $k$ points such that every pair is at least $D$ apart. Since the points lie on the boundary of a square, we can sort them based on their position along the perimeter (or simply by coordinate if we handle the four sides carefully) and then use a greedy approach: pick the first point, then iteratively pick the next available point that is at least distance $D$ away from the last picked point. If we can pick at least $k$ points, then $D$ is feasible.
