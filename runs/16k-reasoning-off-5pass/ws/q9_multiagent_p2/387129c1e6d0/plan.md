The problem requires tracking Santa's path on a 2D grid while moving in cardinal directions and counting how many distinct houses lie on the segments traversed. Since $N$ and $M$ are up to $2 \times 10^5$, we cannot check every point on every segment. Instead, we will maintain the current position and, for each move, determine the bounding box of the segment. We can efficiently check if any house lies on this segment by querying a data structure (like a hash set or sorted lists with binary search) for houses sharing the same x-coordinate (for vertical moves) or y-coordinate (for horizontal moves) within the specific range. To handle duplicates and efficiency, we store houses in four dictionaries mapping coordinates to sets of the other coordinate.
