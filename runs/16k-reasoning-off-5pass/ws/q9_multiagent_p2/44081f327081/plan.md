The problem requires finding the maximum GCD of a subset of size K containing $A_i$ for each $i$. Since $A_i$ is small ($\le 10^6$), we can iterate over all possible GCD values $g$ from $1$ to $10^6$. For each $g$, we count how many elements in the array are multiples of $g$. If this count is at least $K$, then $g$ is a candidate answer for any $A_i$ that is a multiple of $g$. To efficiently answer for each $i$, we can maintain the maximum valid $g$ for each multiple. We will precompute the counts of multiples for every $g$ using a sieve-like approach, then iterate backwards from the largest possible $g$ to update the answer for each $A_i$ only if a larger valid $g$ hasn't been found yet.
