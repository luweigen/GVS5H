This problem models the constraints as a system of XOR equations on a graph where vertices are indices $1 \dots N$ and edges $(X_i, Y_i)$ carry the value $Z_i$. We can decompose the graph into connected components. For each component, we arbitrarily assign a value (0) to one vertex and propagate the constraints using BFS/DFS to determine all other values in that component. If we encounter a contradiction during propagation (an edge requires a value different from what is already derived), no solution exists. If a component is bipartite (which XOR graphs always are structurally, but we must check for consistency), the values are determined up to an additive constant (XOR constant) for each partition. To minimize the sum, for each partition, we choose the value that minimizes the sum of its elements (either 0 or the derived offset). Finally, we output the constructed sequence or -1 if inconsistent.
