This structure implies that the graph is the complement of an interval graph. We can model this using a Disjoint Set Union (DSU) or a segment tree approach to efficiently manage connected components and find shortest paths. Since edge weights are implicit (based on vertex weights), the problem reduces to finding the minimum weight path in a graph where we can traverse between non-overlapping intervals. A key observation is that if two intervals overlap, they are not connected directly, but we can use a "gap" or "bridge" strategy.
