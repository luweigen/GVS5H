The problem involves inserting numbers $i$ at position $P_i$ in an array that grows to size $N$. A direct simulation using list insertion is $O(N^2)$, which is too slow for $N=5\times10^5$. Instead, we can work backwards from the final state. In the final array, the number $N$ is always at index $P_N-1$ (0-indexed). The number $N-1$ was inserted at $P_{N-1}$ before $N$ was added, meaning its final position is shifted by 1 if it was inserted after $N$'s insertion point. By iterating backwards from $N$ to $1$, we can determine the final index of each number $i$ by adjusting its target position $P_i$ based on how many subsequent numbers (which were inserted later) ended up to the left of it.
