We need to calculate the sum of (min + max) for all subarrays with length at most k. Instead of iterating over all subarrays (which would be O(N^2)), we can use a sliding window approach combined with monotonic deques to efficiently track the minimum and maximum values for each valid subarray ending at the current position. For each index `i` from 0 to n-1, we maintain two deques: one for the maximums and one for the minimums of the current window ending at `i`. The window size is constrained such that it includes indices from `max(0, i - k + 1)` to `i`. We add the current element to the deques, remove elements outside the valid window range, and then sum the front of the max deque and the front of the min deque to the total result. This approach runs in O(N) time complexity.
