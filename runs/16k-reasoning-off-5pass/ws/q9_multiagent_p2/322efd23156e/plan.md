The problem asks for the maximum possible value of the minimum vitamin intake (among vitamins 1, 2, and 3) given a calorie limit $X$. Since the maximum possible answer is bounded by the total calories and minimum vitamin per food, we can iterate through all possible values of the target minimum $k$. For each $k$, we check if it's possible to select a subset of foods such that the total calories $\le X$ and the sum of each vitamin is at least $k$. This check can be modeled as a variation of the knapsack problem where we need to satisfy three lower bounds simultaneously. Given the constraints ($N, X \le 5000$), an $O(N \cdot X)$ or $O(N \cdot X \cdot 3)$ approach per check is feasible, but we can optimize the check or the iteration range. A more efficient approach is to use dynamic programming where the state tracks the current sums of the three vitamins, but since the sums can be large, we cap them at the target $k$. We will iterate $k$ from the maximum possible answer down to 0 and return the first $k$ that is achievable.
