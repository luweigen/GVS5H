The problem simulates smoke movement on a grid where smoke from (0,0) moves according to wind directions, and new smoke is generated at (0,0) if the cell is empty. Since N is up to 200,000, a direct simulation of all smoke cells is too slow if the number of smoke cells grows linearly or quadratically. However, we can observe that the set of reachable cells at time $t$ is bounded and the movement is deterministic. We can simulate the process by maintaining a set of occupied coordinates. Given the constraints and the nature of the movement (smoke spreads out but also gets cleared if it moves away), the number of active smoke cells might remain manageable, or we can use a hash set to track them efficiently. The key is to check if $(R, C)$ is in the set of occupied cells at each half-step $t+0.5$. After the wind blows, we check the target, then generate new smoke at $(0,0)$ if needed.
