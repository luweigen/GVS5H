The problem asks for reachability from square 1 to N with jump constraints [A, B] while avoiding "bad" squares (intervals). Since N is up to $10^{12}$, we cannot simulate square by square. However, M is small ($2 \times 10^4$) and the jump range [A, B] is very small (max 20). The "bad" intervals are sparse. We can model this as a graph where nodes are the start of each bad interval (plus 1 and N) and potential landing spots just before bad intervals begin. Specifically, we only need to track reachable positions at the boundaries of the bad intervals. We can perform a BFS or dynamic programming where the state is the current index, but we compress the indices to only include $1$, $N$, $L_i$, and $R_i + 1$. Since jumps are small, from any reachable point, we can check if we can jump over a bad interval or land in a safe gap. The key insight is that if we can reach a point $x$, we can reach any $y$ such that $x+A \le y \le x+B$ provided $y$ is not bad. We can iterate through the sorted critical points (starts of bad intervals) and determine reachability.
