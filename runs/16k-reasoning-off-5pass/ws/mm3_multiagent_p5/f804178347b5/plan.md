Model the problem as a ternary tree of height N where leaves are the 3^N input bits. Each internal node's value is the majority of its 3 children. We want the minimum number of leaf flips to flip the root value. We use dynamic programming on each node computing, for each node, the minimum flips to make that node evaluate to 0 and to evaluate to 1. Combining three children uses 6 possible "child value combinations" that yield a given parent value; the cost is sum of child costs. The answer is min(dp(root, 0), dp(root, 1)). Complexity: O(3^N) which is fine for N ≤ 13 (3^13 ≈ 1.6M).
