We need to split the array into contiguous subarrays to minimize the sum of subarray costs. Each subarray cost depends on the prefix sum of nums up to the end of that subarray plus `k * i` (where i is the subarray index), multiplied by the sum of cost over that subarray. Because `i` depends on the number of subarrays formed so far, this is a classic DP-with-convex-hull-trick / divide-and-conquer optimization problem. Define prefix sums `A[i] = sum(nums[0..i])` and `B[i] = sum(cost[0..i])`. The cost of the segment `[l+1..r]` (1-indexed subarray) equals `(A[r] + k * i) * (B[r] - B[l])` where `i` is the number of subarrays up to `r`. The DP recurrence: `dp[r] = min_{l<r} dp[l] + (A[r] + k * (cnt[l]+1)) * (B[r]-B[l])` where `cnt[l]` is the number of subarrays used in the optimal partition of `0..l`. To avoid tracking counts, we reformulate: the `i` multiplier can be merged by expanding the term. After expansion, each transition is linear in `A[r]` and `B[r]` with coefficients depending on `l`, allowing Li Chao segment tree or divide-and-conquer convex hull trick optimization. Given `n ≤ 1000`, an O(n^2) DP is acceptable for a simple solution. We'll implement the O(n^2) DP for clarity and safety.
