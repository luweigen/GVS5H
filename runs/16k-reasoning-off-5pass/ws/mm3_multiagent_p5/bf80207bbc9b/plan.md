The operations are linear over GF(2): each cell becomes `A_{i,j} XOR r_i XOR c_j` for some row-flip vector `r` and column-flip vector `c`. For a fixed column mask `c`, each row can be either kept or flipped, contributing `min(popcount(row XOR c), W - popcount(row XOR c))` ones. Thus the total minimum is the convolution of the row-frequency array `f` with the function `g(x) = min(popcount(x), W - popcount(x))` under XOR. We compute this efficiently using the Fast Walsh-Hadamard Transform (FWHT) in `O(H + W * 2^W)` time and `O(2^W)` memory. Finally, we take the minimum value of the resulting array.
