The problem is a variant of a bounded knapsack with three "dimensions" (vitamins 1, 2, 3) where we want to maximize the minimum of the three vitamin totals subject to a calorie capacity X (≤ 5000). Since N and X are both up to 5000, a DP over calories with bitmask of which vitamins are still "unsatisfied" is feasible. We binary‑search on the answer M: can we pick a subset with total calories ≤ X such that the intake of **each** vitamin is at least M? For a fixed M we check feasibility by DP where the state is `dp[c]` = bitmask of vitamins whose required M has already been met after spending exactly c calories. We start with mask 0, and for each food we run a classic knapsack transition (0/1) updating the mask: if the food contributes to vitamin v, new_mask = old_mask | (1 << (v-1)). After processing all foods, if any `c ≤ X` has `dp[c] == 0b111` (i.e., all three vitamins covered), the target M is achievable. The binary search range is `[0, 600000]` (because A_i ≤ 2e5 and N ≤ 5000). Complexity per check: O(N·X) ≤ 25 million, well within limits. Overall O(N·X·log(maxA)).
