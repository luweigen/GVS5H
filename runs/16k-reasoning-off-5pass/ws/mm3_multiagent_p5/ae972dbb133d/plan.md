Now, is there a known polynomial time algorithm for this? Yes, this is the "fully packed loop" (FPL) model on a torus with given face weights. The number of FPL on a torus with face weights can be computed using the determinant of a matrix (the "Kasteleyn matrix" for the loop model). Specifically, the FPL on a planar graph is equivalent to the dimer model on the medial graph. The medial graph of the torus grid is also a torus grid. The dimer model on a torus can be solved by computing the determinant of a matrix with twisted boundary conditions.
