For a viewpoint at coordinate 0 with height h, building i is visible if and only if the line from (0, h) to the top of building i (X_i, H_i) is not blocked by any other building. This means that for every building j, the line segment from the viewpoint to (X_i, H_i) must stay strictly above (or just touch) building j at X_j.

For fixed i, the condition “building j does not block i” can be expressed as a lower bound on h:
h ≥ (H_i * X_j - H_j * X_i) / (X_j - X_i)
for every j with X_j between 0 and X_i, and similarly the symmetric inequality for j on the other side. Taking the maximum over all j gives the minimum height needed to see building i from (0, h). Let f(i) be that minimum required height. Then the set of heights from which we can see all buildings is the maximum of f(i) over all i. The problem asks for the largest h such that we *cannot* see all buildings, i.e. h < max_i f(i).
