Build the intersection graph G where i~j iff [L_i,R_i] ∩ [L_j,R_j] = ∅. Since L_i,R_i ≤ 2N, we can coordinate-compress values. Use a segment tree / interval tree to connect each interval to all disjoint intervals efficiently. For each point x in [1,2N], maintain the list of intervals covering x. Iterate x from 1 to 2N, and for adjacent x, union the sets of intervals covering x and x+1 via DSU (this builds the complement of the intersection graph). After DSU processing, two vertices are in the same component iff there is a path between them in G. To answer queries, use DSU with minimum-weight tracking per component: for each component, store the sum of weights of all vertices in it. Then for a query (s,t), if they are in different components output -1, else output the stored sum of that component.
