You can expand to the left or right if the next slime is smaller than your current size. The current size is the sum of all slimes you have absorbed. So the condition to expand to a new slime at distance d (where distance is the number of slimes between it and the current boundary) is that the new slime is smaller than the sum of all slimes currently in your block. Since the block is a contiguous interval, the current size is the sum of the block. When you add a new slime, the new size becomes old size + new slime. The condition is new slime < old size. So if we consider the interval [L, R] that we will eventually occupy, the process is a sequence of expansions. The order of expansions defines a sequence of intervals [K, K], [L1, R1], [L2, R2], ..., [L, R]. At each step, the new slime added must be smaller than the sum of the current interval. This is exactly the condition that the sequence of sums is strictly increasing.
