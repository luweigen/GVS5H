For each index i, count how many subarrays ending at i have nums[i] as the minimum, and similarly how many have nums[i] as the maximum, but only for subarrays of length ≤ k. We can do this using monotonic stacks: traverse left-to-right for minimums and right-to-left for maximums (or vice versa), and for each element find the distance to the previous smaller (or larger) element. Clamp the contribution to k by limiting the count to min(distance, k). Sum these contributions efficiently in O(n).
