We need the maximum number of disjoint pairs (i, j) with i < j such that A[i] * 2 <= A[j]. Since the array is sorted ascending, a classic greedy works: use two pointers, one scanning potential "top" (small) mochi and one for "bottom" (large) mochi. For each bottom pointer j, advance the top pointer i while A[i] * 2 <= A[j]; once the condition fails, we cannot pair any further tops with this bottom, so we pair the current top with this bottom (if valid), increment answer, and move both pointers. If no valid top exists for current bottom, just move bottom pointer. This greedy is optimal because pairing the smallest possible top with each bottom leaves larger tops for larger bottoms. Complexity O(N).
