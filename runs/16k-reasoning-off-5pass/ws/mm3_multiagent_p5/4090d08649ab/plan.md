The value of f(L,R) equals the number of connected components in the graph where vertices are distinct values in the subarray and edges connect consecutive integers that both appear. This simplifies to f(L,R) = D(L,R) - G(L,R), where D is the number of distinct values and G is the number of pairs of consecutive integers both present. Summing over all subarrays, we compute Sum D and Sum G separately. Sum D is the sum over values of subarrays containing that value. Sum G is the sum over adjacent integer pairs of subarrays containing both. Both can be computed using gaps between occurrences via inclusion-exclusion in O(N) total time.
