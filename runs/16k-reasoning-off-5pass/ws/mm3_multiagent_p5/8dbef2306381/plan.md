Model reachable squares as a BFS/queue over "segments" (continuous blocks of non-bad squares). Since A,B ≤ 20, each move jumps at most 20 squares. We process intervals of non-bad squares sorted by start. From a position x, we need any x+i in [A,B] landing in a non-bad interval [L,R] (i.e., L ≤ x+i ≤ R). This is equivalent to: for each reachable interval, find which later intervals are within distance [A,B] from any point of it. We use a BFS over intervals: when we pop interval [l,r], we repeatedly take the first not-yet-visited interval whose L ≤ r + A, mark it visited, and union/merge it into the current reachable region (expand r to max(r, its R)). This standard "jump game with intervals" runs in O(M) since M ≤ 2×10⁴. Start with interval [1,1] (square 1 is not bad because L_i>1). If interval's R ≥ N, output Yes, else No.
