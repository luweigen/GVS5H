
## ideation
We need the largest N ≤ A of the form N = p^{2a} * q^{2b} with distinct primes p, q and a, b ≥ 1. A ≤ 1e12, Q up to 2e5.

Approach:
- Generate all 400 numbers ≤ 1e12 once: for each unordered pair of distinct primes p < q (primes up to 1e6, since 2^2 = 4, 1e6^2 = 1e12, but we only need primes whose squares (or higher even powers) ≤ 1e12), enumerate possible even exponents 2a for p and 2b for q such that p^{2a} * q^{2b} ≤ 1e12.
- To bound exponents: For a prime p, max even exponent e_max(p) = largest even e such that p^e ≤ 1e12, so e = 2, 4, 6, ... ≤ floor(log_{p}(1e12)) rounded down to even. Equivalently a_max = floor(log_{p}(1e12)) // 2.
- For each prime p (from list of primes up to 1e6, generated by sieve), and each a from 1 to a_max(p), compute p_pow = p^{2a}. Then for each larger prime q > p, compute q_max_even_exp = 2 * floor(log_q(1e12 / p_pow)). Enumerate b from 1 to that max, compute q^{2b}, multiply, and add to a set. This avoids duplicates and ensures O(N) work.
- Number of such numbers: p, q up to 1e6; but combined products grow fast. Typical count is around 3e5–1e6, easily manageable.
- Store all 400 numbers in a sorted list.
- For each query, binary search (bisect_right) the largest ≤ A.

Pitfalls:
- Must use integer arithmetic, avoid float.
- Sieve up to 1e6 is enough because smallest prime squared 2^2=4; but actually p, q can be up to 1e12^(1/2)=1e6 if exponents are 2. If exponent >2, p < 1e6. So sieve up to 1e6 is correct.
- Careful with overflow: use Python big ints, fine.
- Must ensure we don't generate duplicate numbers (e.g., p,q swapped). Since we only iterate p<q, each unordered pair is generated once.
- Edge case: a and b must be at least 1, i.e., at least squared, not just to the first power.

Complexity:
- Generation: O(#primes * something). Feasible under a few seconds.
- Queries: O(Q log M).

Implementation details:
- Sieve of Eratosthenes up to 1e6 to get primes.
- For each p, compute p_pows = [p^{2}, p^{4}, ...] up to ≤ 1e12.
- For each p_pow, iterate q > p up to sqrt(1e12 // p_pow) at most.
- For each such q, compute q_pows = [q^{2}, q^{4}, ...] up to ≤ 1e12 // p_pow.
- Add p_pow * q_pow to list.
- Convert to set then sorted list.

Alternative: precompute max exponent for each prime via while loop.

## worker: Implement the solution in Python: generate all 400
- The problem asks for the largest integer ≤ A that is a product of two distinct primes each raised to an even positive power: N = p^{2a} * q^{2b}.
- Precomputation enumerates unordered prime pairs (p<q) and even exponents (≥2) to generate all such N ≤ 10^12 once.
- Sieve up to 10^6 is sufficient because the smallest possible prime factor is at most √(10^12) = 10^6 when its exponent is 2.
- For each p, we list its even powers ≤ 10^12. For each such power pp, we iterate over larger primes q and list their even powers ≤ 10^12 / pp, adding the product to a set to avoid duplicates.
- The set is converted to a sorted list, enabling O(log N) binary search per query using `bisect_right`.
- The total number of generated 400 numbers is well under a million, keeping memory and time within limits for Q up to 2×10^5.
- Edge cases: The problem guarantees a 400 number ≤ A exists for all A ≥ 36, and our precomputation includes such numbers (e.g., 36 = 2^2 * 3^2).
