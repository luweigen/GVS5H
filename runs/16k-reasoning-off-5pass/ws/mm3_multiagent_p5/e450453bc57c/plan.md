We need to make at least k non-overlapping windows of length x where all elements in a window are equal. The cost to make a window equal to a target value v is `sum(|nums[i] - v|)`. For each window, the optimal v is the median, giving minimal cost. We precompute for every start index s, the cost to make window [s, s+x-1] all equal: `cost[s]`. Next we must select k non-overlapping windows, each of length x, covering distinct positions (they must not overlap). This is a classic DP: `dp[i][j]` = minimum cost to cover j non-overlapping windows among the first i positions (where i indexes through the array with positions representing possible end points of windows). We will process positions in order, either not starting a window at i, or if we can start at i-x (meaning window covers positions i-x+1..i), we transition from dp[i-x][j-1] + cost[i-x+1]. This runs in O(n*k). Since n up to 1e5 and k <= 15, this is fine. We need to precompute costs efficiently. We can use prefix sums after sorting values per window, but since windows slide by one position, we can use two heaps or a median maintenance structure. However, k is small, so O(n * x log x) is too big (1e5 * up to 1e5). Instead we use the median trick: maintain two multisets (heaps) with rebalancing and lazy deletions using a hashmap. That gives O(n log x). Alternative simpler: we can compute all window costs using a median maintained with heaps. We'll need to support sliding window of fixed size x. We'll precompute cost array in O(n log x). Then DP in O(n*k) gives overall O(n log x + n*k). Implement `minOperations` returning dp[n][k] (0-indexed). Edge cases: must be exactly k non-overlapping windows; they cannot overlap; they can be anywhere, order preserved.
