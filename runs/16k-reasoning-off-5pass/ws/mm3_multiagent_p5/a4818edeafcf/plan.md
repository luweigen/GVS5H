We need to split the array into three contiguous non-empty parts and maximize the sum of distinct counts. The standard approach for the two-subarray version uses a left sweep and right sweep. For three subarrays we can use a divide-and-conquer technique: at each recursion level, the optimal split `(i, j)` either lies completely in the left half, right half, or crosses the middle. For the crossing case we can use a meet-in-the-middle where we fix `i` near the middle and sweep `j` outward on the right while maintaining a set of distinct values for the rightmost subarray. We'll also need to efficiently query the maximum distinct count of a middle subarray starting at any position `j` and ending at any `r ≥ j` — we can precompute this using a right-to-left sweep (storing for each start index the maximum distinct count achievable for the subarray starting there, up to a point). The recursion depth is O(log N), and each level does O(N) work, giving O(N log N) overall.
