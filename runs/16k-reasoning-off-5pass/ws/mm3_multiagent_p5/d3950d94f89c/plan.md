We need to find the longest downward path (ancestor→descendant) in a rooted tree where all node values are unique, minimizing the node count among ties. We'll DFS from root, maintaining a stack of recent ancestors keyed by value to detect duplicates. For each node we find the nearest previous ancestor with the same value; any path must start after that ancestor. We'll update the best path using prefix sum distances and prefix node counts, and keep the minimal node count when lengths tie. A dictionary maps value → stack index of the most recent occurrence to bound the starting point in O(1) per node, giving O(n) overall.
