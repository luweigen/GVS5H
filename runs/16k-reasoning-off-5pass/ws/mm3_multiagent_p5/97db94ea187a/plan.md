We need to count, for each M from N−1 up to N(N−1)/2, the number of connected labeled undirected simple graphs on N vertices such that exactly half the vertices have even shortest distance from vertex 1 and the other half have odd distance. Since the graph is connected and every vertex has a finite distance, the distances form a bipartition of the vertex set induced by a BFS layer tree from vertex 1, so the condition forces the BFS to be balanced.

The classic approach is to use exponential generating functions over set partitions / labeled structures. We treat the BFS tree as a rooted structure: assign each non-root vertex a parent, and attach a (possibly empty) graph of "cross edges" within and between layers. The EGF for rooted trees with ordered levels is known; including cross edges and tracking layer sizes (even/odd) can be done using labeled set constructions. For each layer we track number of vertices in that layer; cross edges between vertices of the same parity layer (even–even or odd–odd) must have both endpoints in the same connected BFS block, while cross edges between layers are possible only between adjacent BFS layers (odd–even). We sum over all layer-size vectors (k_0,...,k_L) with sum N, k_0 = 1 (vertex 1 in layer 0, even), and the odd layers form odd distance, even layers even distance, with equal totals.

I'll implement the FPT generating-function DP over the polynomial ring Z/pZ[x] where x counts vertices. For each layer we maintain a polynomial where the coefficient of x^k is a value for that layer. Transitions multiply these polynomials. For a fixed BFS depth L, we compute the total number of connected labeled graphs that realize that exact BFS layering, with given counts of vertices in each layer, weighted so that the total vertex count is the x-power. We then extract coefficients where the even-odd balance holds.

The main loop: for L=1..N-1, compute contributions for that depth, accumulate. Finally for each M, sum the contributions of all valid (L, layer-size) configurations that give exactly M edges, and also ensure the graph is connected (which is automatic since we count only BFS tree connected).
