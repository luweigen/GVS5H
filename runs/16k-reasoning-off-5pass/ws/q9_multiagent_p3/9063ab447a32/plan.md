This problem requires maximizing the total units purchased given a quadratic cost function $k^2 P_i$ for buying $k$ units of product $i$ with budget $M$. Since the cost function is convex, we should prioritize buying units from products with the smallest $P_i$ values first. We can sort the products by their cost coefficient $P_i$. Then, we iterate through the sorted products, calculating how many units we can afford with the remaining budget. For each product, we solve the quadratic inequality $x^2 P_i \le \text{remaining\_budget}$ to find the maximum integer $x$, update the total units and remaining budget, and stop when the budget is exhausted.
