The problem asks for the minimum cost to travel from vertex 1 to vertex N in a directed graph where we can either traverse an edge (cost 1) or reverse all edges globally (cost X). Since reversing edges globally is expensive, we should only do it if it significantly reduces the number of steps needed. The state space can be modeled as a graph with two layers: Layer 0 represents the original edge directions, and Layer 1 represents the reversed edge directions. Transitions within a layer correspond to moving along edges (cost 1), while transitions between layers correspond to reversing all edges (cost X). We can use Dijkstra's algorithm on this expanded graph (2N nodes) to find the shortest path from node 1 in Layer 0 to node N in either Layer 0 or Layer 1.
