The problem requires selecting up to 4 non-overlapping intervals to maximize total weight, with ties broken by lexicographically smallest indices. Since the number of intervals to pick is very small (up to 4), we can use dynamic programming where the state tracks the number of intervals picked so far and the ending position of the last picked interval. To handle the lexicographical requirement efficiently, we will store not just the maximum weight but also the actual list of indices chosen to reconstruct the solution or compare candidates. Given the large coordinate range (up to 10^9), we cannot use coordinates directly in the DP state; instead, we will compress coordinates or simply use the index of the last interval as part of the state, iterating through intervals sorted by their end times to ensure optimal substructure. We will precompute the best single interval ending at or before a certain point for each of the 4 slots.
