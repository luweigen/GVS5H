The problem asks for reachability from square 1 to N with jump constraints [A, B], avoiding "bad" intervals. Since N is very large ($10^{12}$) but the number of bad intervals M is small ($2 \times 10^4$) and the jump range [A, B] is tiny ($\le 20$), we cannot simulate every square. Instead, we can model the state as the current position relative to the bad intervals. We only need to track if we can reach the start of each bad interval and then jump over it. Specifically, we can use a set of reachable positions. Since the jump range is small, if we can reach a position $x$, we can reach $x+A, \dots, x+B$. The critical observation is that once we pass a bad interval, the "badness" constraint is satisfied for that interval. We can process the bad intervals in order. For each interval $[L_i, R_i]$, we determine the set of reachable positions just before $L_i$. Then we check if any of these positions can jump over $R_i$ (i.e., $pos + k > R_i$ for some $k \in [A, B]$). If so, the positions $R_i+1$ to $R_i+B$ become reachable (clamped by the next interval's start). We maintain a set of reachable positions modulo the jump range or simply a boolean array of size B relative to the current boundary, updating it as we sweep through the intervals. Finally, we check if N is reachable.
