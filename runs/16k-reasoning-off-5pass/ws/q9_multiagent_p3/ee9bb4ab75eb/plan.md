The problem requires finding the longest common prefix (LCP) of any $k$ strings after removing each element one by one. A naive simulation for each removal would be $O(N \cdot N \cdot L)$, which is too slow given $N=10^5$. Instead, we can use a Trie to store all strings and count the frequency of each node (representing a prefix) across the entire array. For each index $i$, the answer is the depth of the deepest node in the Trie that has a frequency $\ge k$ after decrementing the count of the prefix contributed by `words[i]`. We can precompute the frequency of every prefix in the full array, then for each removal, temporarily decrement the counts along the path of the removed string, query the maximum depth with sufficient frequency, and then restore the counts.
