Since the constraints on `nums.length` are small (up to 150) but the values are very small (0 to 12), we can use dynamic programming. The state will track the maximum product achievable for a given alternating sum and a boolean flag indicating whether the next element in the subsequence should be added (positive contribution) or subtracted (negative contribution). We iterate through each number in `nums`, updating the DP table for both states (starting a new subsequence or continuing one). Finally, we check all possible alternating sums equal to `k` and return the maximum product that does not exceed `limit`.
