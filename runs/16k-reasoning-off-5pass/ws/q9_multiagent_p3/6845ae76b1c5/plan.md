The problem requires calculating the sum of absolute differences between the first $X_k$ elements of $A$ and the first $Y_k$ elements of $B$ for $K$ queries. A naive $O(N^2)$ approach per query is too slow given the constraints ($N=10^5, K=10^4$). The optimal strategy involves sorting arrays $A$ and $B$ and using prefix sums to calculate the contribution of each element based on its rank relative to the other array, allowing each query to be answered in $O(\log N)$ or $O(1)$ time after $O(N \log N)$ preprocessing.
