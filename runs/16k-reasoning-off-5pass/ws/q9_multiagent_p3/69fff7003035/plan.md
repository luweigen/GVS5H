The problem asks for the sum of numbers formed by concatenating permutations of $1$ to $N$. We can calculate the contribution of each digit $d \in \{1, \dots, N\}$ to the total sum by determining how many times it appears at each decimal position (units, tens, hundreds, etc.). Since the number of digits in each integer varies, we must group integers by their digit length. For a specific digit length $L$, there are $N! / L!$ permutations where a specific number of length $L$ occupies a specific relative position among the $L$-length numbers, but a more direct approach is to fix a position $k$ (from right, 0-indexed) in the final concatenated string and count how many times each digit $d$ lands there. The total count for digit $d$ at position $k$ depends on the number of permutations where $d$ is placed such that its last digit aligns with the $k$-th position of the final string. We will precompute factorials and their modular inverses, iterate through all possible digit lengths, and for each length, calculate the contribution of each number to the total sum based on its placement probability and the number of trailing digits it shifts subsequent numbers.
