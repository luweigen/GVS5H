The problem asks for the minimum number of vertex deletions to leave a "Snowflake Tree," which consists of a central root connected to $x$ children, where each child is connected to exactly $y$ leaves. This structure implies the remaining graph must have a specific degree pattern: one root (degree $x$), $x$ intermediate nodes (degree $y+1$), and $xy$ leaf nodes (degree 1). To solve this, we can iterate through every node in the original tree as a potential candidate for the root of the Snowflake Tree. For each candidate root, we calculate the maximum number of nodes we can keep by greedily matching its neighbors to the $x$ required intermediate nodes and then matching their subtrees to the $y$ required leaves. The answer will be $N$ minus the maximum number of kept nodes found across all candidates.
