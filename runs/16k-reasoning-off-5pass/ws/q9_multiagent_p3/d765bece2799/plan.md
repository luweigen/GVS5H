The problem requires summing the max and min of all subarrays with length at most $k$. A brute-force $O(N^2)$ approach is too slow given $N \le 80000$. We can use a monotonic deque (sliding window) technique to efficiently track the maximum and minimum for every valid window ending at index $i$. Specifically, for each ending position $i$, we consider all starting positions $j$ such that $i - j + 1 \le k$. The contribution of the current element as a new max/min can be calculated by determining how many subarrays ending at $i$ have the current element as their max/min, using the indices from the deques to find the range of validity. We will maintain two deques: one for maximums and one for minimums, and iterate through the array once, accumulating the result.
