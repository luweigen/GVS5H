The problem asks if a tree with $NK$ vertices can be partitioned into $N$ disjoint paths, each containing exactly $K$ vertices. A necessary condition is that the total number of vertices $NK$ matches the sum of path lengths, which is trivially true by definition. The core constraint is structural: we need to select $N-1$ edges to act as "breaks" between paths such that every resulting connected component has size exactly $K$. This is equivalent to checking if we can remove a set of edges where each removed edge splits a component of size $mK$ into two components of sizes $aK$ and $(m-1)K$ (or similar recursive splits) until all components are size $K$. A standard approach is to perform a DFS/post-order traversal. For each subtree, we calculate the size of the connected component formed by the subtree edges that haven't been "cut" yet. If a subtree's component size is a multiple of $K$ (say $mK$) and we are at a node where cutting the edge to its parent would result in a valid component of size $mK$, we *must* cut it if $m > 1$ to avoid merging with the parent and potentially creating an invalid large component later, unless the parent can absorb it perfectly. Actually, the greedy strategy is: traverse bottom-up. Maintain the size of the current path segment ending at the current node. If the size reaches $K$, we "cut" the path here (increment path count, reset size to 0). If the size exceeds $K$, it's impossible. After processing all nodes, if the total number of cut paths equals $N$ and the final root component is empty (or size 0), the answer is Yes.
