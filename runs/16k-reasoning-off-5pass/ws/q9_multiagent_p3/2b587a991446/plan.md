The problem asks for the minimum moves to swap two pieces on a graph without them occupying the same vertex. Since the graph is connected and undirected, if the shortest path between S and T has length 1 (direct edge), the pieces block each other immediately, making the swap impossible (output -1). If the shortest path length is greater than 1, we can move one piece out of the way to a neighbor of its starting position, traverse the path, and then move the other piece. The optimal strategy involves moving one piece to an adjacent vertex (1 move), moving the second piece along the shortest path (dist(S,T) moves), and finally moving the first piece along the shortest path (dist(S,T) moves). The total moves will be $1 + 2 \times \text{dist}(S, T)$. We need to compute the shortest path distance using BFS.
