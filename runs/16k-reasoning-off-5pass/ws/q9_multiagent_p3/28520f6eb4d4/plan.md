The problem asks for the maximum height $h$ at $x=0$ such that not all buildings are visible. A building $i$ is invisible if the line of sight from $(0,h)$ to $(X_i, H_i)$ is blocked by some building $j < i$. This blocking condition is equivalent to $h$ being less than the y-intercept of the line connecting $(X_j, H_j)$ and $(X_i, H_i)$. To ensure all buildings are visible, $h$ must be at least the maximum of these intercepts over all pairs $(j, i)$ with $j < i$. The answer is this maximum intercept value. If the maximum intercept is $\le 0$, then even at height 0 all buildings are visible, so we output -1. We can compute this efficiently by maintaining the upper convex hull of the buildings processed so far and using ternary search to find the building on the hull that maximizes the intercept with the current building.
