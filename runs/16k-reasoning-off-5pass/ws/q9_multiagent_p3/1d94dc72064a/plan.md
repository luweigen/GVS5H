The game ends when all indices $1$ to $N$ are added to set $S$. Each index $i$ requires exactly one move where $A_i > 0$ and $i \notin S$ to be added to $S$. Once $i \in S$, subsequent moves on index $i$ only decrease $A_i$ without adding to $S$. The total number of moves required to add all indices to $S$ is $N$ (one for each index) plus the sum of $(A_i - 1)$ for all $i$ where $A_i > 1$, effectively making the total moves equal to $\sum A_i - (\text{count of } i \text{ where } A_i \ge 1)$. Since all $A_i \ge 1$, the count is $N$. Thus, total moves = $\sum A_i - N$. If this total is odd, Fennec (1st player) wins; if even, Snuke (2nd player) wins.
