The problem asks us to select $k$ points from a given set on the boundary of a square such that the minimum Manhattan distance between any pair of selected points is maximized. This is a classic "maximize the minimum" problem, which can be efficiently solved using binary search on the answer (the minimum distance). We will binary search for the maximum possible distance $D$. For each candidate distance $D$, we need to check if it's possible to select $k$ points such that every pair is at least $D$ apart. The check function can be implemented by sorting the points based on their position along the perimeter of the square and then using a greedy approach to select points. Since the points are on the boundary, we can map them to a 1D coordinate system representing the perimeter length, sort them, and then greedily pick points ensuring the distance constraint is met.
