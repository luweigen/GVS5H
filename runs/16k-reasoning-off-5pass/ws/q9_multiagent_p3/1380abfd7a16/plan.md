The problem involves inserting numbers $1$ to $N$ into an array at specific positions, which naively takes $O(N^2)$ time. However, by observing the process in reverse, we can determine the final position of each number $i$ relative to the numbers $i+1, \dots, N$. Specifically, when inserting $i$ at position $P_i$, it shifts all subsequent elements to the right, but in reverse order, $i$ will simply occupy the $P_i$-th available slot from the end of the current sequence of larger numbers. We can simulate this reverse process using a data structure like a Fenwick tree (Binary Indexed Tree) or a Segment Tree to efficiently find the $k$-th empty position and fill the result array.
