The problem asks for the minimum number of swaps to make all '1's contiguous. This is equivalent to moving all '1's to a specific target window of length $K$ (where $K$ is the total count of '1's) with minimal cost. The cost to move a '1' from index $i$ to a target position $j$ is $|i - j|$. Since we can swap adjacent elements, the total number of swaps required to move a set of items to specific target positions is the sum of the distances between their initial positions and their final positions, assuming we match the $k$-th '1' to the $k$-th position in the target window to minimize total distance. We can iterate over all possible starting positions $l$ for the contiguous block of '1's (from $0$ to $N-K$), calculate the cost for each, and take the minimum. The cost for a fixed window $[l, l+K-1]$ is $\sum_{j=0}^{K-1} | \text{pos}[j] - (l+j) |$, where $\text{pos}[j]$ is the original index of the $(j+1)$-th '1'. This can be computed efficiently in $O(N)$ time.
