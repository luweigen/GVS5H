The problem asks to minimize the sum of 1s in a grid after flipping arbitrary rows and columns. Since $W$ is small ($W \le 18$), we can iterate through all $2^W$ possible column flip configurations. For a fixed set of column flips, the decision to flip each row becomes independent: we simply choose to flip a row if it reduces the number of 1s in that row. We calculate the total cost for each column configuration and take the minimum.
