The problem requires simulating Santa's movement along a grid while counting distinct houses visited. Since $N$ and $M$ are up to $2 \times 10^5$, we cannot check every point on every segment. Instead, we maintain the current position and for each move, we check if the start or end point of the segment matches any house. For horizontal moves, we check if any house lies on the segment by verifying if its x-coordinate is within the range and its y-coordinate matches the current y. Similarly for vertical moves. To efficiently count distinct houses, we store the indices of visited houses in a set. Finally, we output the final coordinates and the size of the set.
