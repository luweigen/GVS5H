Given the small constraints ($N \le 30, M \le 100$), we can iterate on the possible answer $D$ (the shortest path distance). For a fixed $D$, we check if it's possible to select $K$ edges with weight 1 such that the shortest path from 1 to $N$ is at least $D$. This is equivalent to checking if there exists a subset of $K$ edges whose removal (or weighting) breaks all paths of length $< D$. We can model this as a maximum flow problem: construct a flow network where edges on paths of length $< D$ have capacity 1 (representing the ability to block them by assigning weight 1), and calculate the max flow. If the max flow is $\ge K$, then we can block all short paths, making the shortest distance $\ge D$. We binary search for the maximum $D$.
