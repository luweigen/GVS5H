The key constraint is that $\binom{N}{K} \le 10^6$, which means we can iterate through all possible combinations of $K$ elements from $A$ without exceeding time limits. We will use `itertools.combinations` to generate all $\binom{N}{K}$ subsets of size $K$. For each subset, we compute the XOR sum of its elements. We track the maximum XOR sum encountered. Since $N$ is up to $2 \times 10^5$ but the number of combinations is small, this brute-force approach is efficient enough. The XOR operation is associative and commutative, so the order within a combination doesn't matter. We initialize the maximum to 0 (since all $A_i$ are non-negative) and update it as we find larger XOR sums.
