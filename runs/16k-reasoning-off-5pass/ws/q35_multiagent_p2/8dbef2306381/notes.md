
## ideation
The core difficulty is that $N$ is up to $10^{12}$, so we cannot simulate square by square. However, $M$ is small ($2 \times 10^4$) and the jump range $[A, B]$ is very small ($B \le 20$). The bad squares are given as disjoint intervals.

Key observations:
1. **State Compression**: Since the maximum jump is $B$, whether we can reach a square $x$ depends only on the reachability of squares in $[x-B, x-1]$. We can maintain a "window" of reachable states.
2. **Good Intervals**: Between bad intervals (or start/end), we have long stretches of "good" (non-bad) squares. In a long stretch of good squares, the set of reachable positions tends to become a contiguous interval or follows a simple pattern. Specifically, if we have a contiguous range of reachable positions of length at least $A$, then all subsequent positions in the good stretch will be reachable (up to the next obstacle), because from any position $y$ in that range, we can jump to $[y+A, y+B]$. If the range of reachable positions grows to cover an interval of length $B$, the next step will cover an interval of length $B$ shifted by at least $A$. Actually, a stronger property holds: if we can reach a contiguous block of size $B$, we can reach all subsequent positions in the good stretch. More precisely, if the reachable set contains an interval of length $B$, then the next reachable set will contain an interval of length $B$ (shifted). In fact, if we have a contiguous reachable interval of length $\ge B$, then all squares in the subsequent good region are reachable.
3. **Algorithm**:

   - Process the bad intervals in order. Let the current position be `curr` (initially 1).

     - Since the jump range is small, we can simulate the propagation of reachable positions through this good interval. However, if the interval is very long, we can optimize.
     - Optimization: If at any point during the propagation through a good interval, the set of reachable positions contains a contiguous block of length $B$, then all subsequent positions in this good interval (and potentially beyond) are reachable.      - Let's refine: We maintain a set of reachable positions. Since we process bad intervals in order, we only care about positions up to the next bad interval. We can use a `set` or a boolean array for the "frontier".
     - Let `reachable` be a sorted list of reachable positions. Initially `[1]`.
     - For each bad interval $[L, R]$:
       - Consider the good interval $(prev\_end, L)$. Let this be $[S, E]$ where $S = prev\_end + 1, E = L - 1$.
       - We want to find all positions in $[S, E]$ that are reachable from the current `reachable` set.

Specifically, if we have a reachable position $x < L$, and $x + A \le R$ and $x + B \ge L$, then we might land in the bad interval. But we can't land in bad intervals. - Ensuring the "contiguous interval" optimization is correct. If we have a contiguous reachable interval $[u, v]$ with $v - u + 1 \ge B$, then for any $k \ge 0$, $u + k$ is reachable? Specifically, if we have a contiguous block of size $B$, the next step produces a contiguous block of size $B$ (shifted). If the good stretch is long, the reachable set remains contiguous.
- The condition for stabilization: If we have a contiguous reachable interval of length $B$, then the next reachable interval is also contiguous of length $B$ (if the good stretch allows). If the good stretch is longer than $B$, the reachable set will be a contiguous interval. We can then just compute the final reachable interval at the end of the good stretch.

Let's implement a simulation that processes each good interval. For short good intervals, we simulate step-by-step. For long good intervals, we detect if the reachable set becomes a contiguous interval of length $\ge B$, and if so, we can fast-forward.

## worker: Implement the solution in Python.
The solution processes the squares in segments defined by the bad intervals. It maintains a set of reachable positions as a list of disjoint intervals. For each good interval between bad intervals, it computes the new reachable positions by considering all possible jumps from the current reachable intervals. If a contiguous block of reachable positions of length at least $B$ is found, all subsequent positions in the good interval are marked as reachable, which allows for efficient handling of long good intervals. After processing all bad intervals, the final stretch to $N$ is processed similarly to check if $N$ is reachable. The complexity is dominated by the number of bad intervals $M$ and the merging of intervals, which is efficient given the small jump range $B$.
