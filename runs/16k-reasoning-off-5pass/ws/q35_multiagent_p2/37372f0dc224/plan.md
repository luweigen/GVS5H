To find the shortest palindrome with prefix S, we need to append the minimum number of characters to S such that the result is a palindrome. This is equivalent to finding the longest palindromic suffix of S. If the longest palindromic suffix of S starts at index i, then the prefix S[0:i] needs to be reversed and appended to S. We can efficiently find the longest palindromic suffix using KMP algorithm on a constructed string: S + '#' + reverse(S). The failure function (pi array) at the last position of this combined string gives the length of the longest prefix of reverse(S) that matches a suffix of S, which corresponds to the longest palindromic suffix of S.
