1. **Binary Search on Answer**: The maximum total units `X` is monotonic with respect to cost. If we can buy `X` units, we can buy `X-1`. So we binary search for the maximum `X` such that the minimum cost to buy `X` units is ≤ M.
2. **Minimum Cost for Fixed X**: To minimize cost for a fixed total units `X`, we should distribute `X` among the `N` products optimally. Since the cost function for product `i` is `k^2 * P_i`, which is convex, we can use a greedy approach with a priority queue or a mathematical insight. However, with `N` up to 2e5 and `X` potentially large, we need an efficient way to compute the min cost.
3. **Efficient Min Cost Calculation**: For a fixed `X`, the optimal distribution can be found by noting that the marginal cost of buying the `(k+1)`-th unit of product `i` is `(k+1)^2 * P_i - k^2 * P_i = (2k+1) * P_i`. We can use a priority queue to always pick the unit with the smallest marginal cost. But `X` can be up to `10^18`, so we cannot simulate unit by unit.
4. **Alternative Approach - Binary Search with Convex Hull Trick / Lagrange Multipliers**: The problem is to minimize `sum(k_i^2 * P_i)` subject to `sum(k_i) = X`. Using Lagrange multipliers, the optimal `k_i` satisfies `2 * k_i * P_i ≈ λ`, so `k_i ≈ λ / (2 * P_i)`. We can binary search on `λ` to find the right distribution. Specifically, for a given `λ`, set `k_i = floor(λ / (2 * P_i))` or similar, adjust to meet the sum `X`, and compute the cost.
5. **Refined Approach**: Binary search on the total units `X`. For a fixed `X`, we need to compute the minimum cost. The optimal `k_i` values are approximately proportional to `1/P_i`. We can use a binary search on a threshold `T` such that `k_i = min(X_i, floor(T / P_i))` or more precisely, since the derivative is `2*k*P_i`, we set `2*k_i*P_i ≈ λ`, so `k_i ≈ λ/(2*P_i)`. Let `λ` be a parameter. For a given `λ`, set `k_i = floor(λ / (2 * P_i))`. Adjust `λ` so that `sum(k_i) = X`. Then compute the cost. This inner binary search on `λ` is efficient.
