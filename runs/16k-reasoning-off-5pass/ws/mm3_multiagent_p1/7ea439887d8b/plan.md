We model the problem as a shortest path on a graph whose nodes are pairs `(v, parity)` where `v` is the current vertex and `parity ∈ {0,1}` indicates whether the edges are in original orientation (0) or reversed (1). From state `(v, p)` we can move to `(u, p)` for each outgoing edge in orientation `p` with cost 1, and we can flip parity with cost X. Run Dijkstra from `(1,0)` to `(N,0)` and `(N,1)`, taking the minimum. Complexity O((N+M) log N).
