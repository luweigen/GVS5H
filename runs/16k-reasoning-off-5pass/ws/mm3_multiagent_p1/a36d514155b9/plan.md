We need the sum over all unordered pairs of cells of the Manhattan distance, counted over all `C(m*n, k)` placements, then multiplied by the number of ways to place the remaining `k-2` pieces in the other cells. By symmetry, we can compute the contribution of a fixed unordered pair `(i, j)` to the total sum: it appears in exactly `C(m*n - 2, k - 2)` arrangements, so the total sum equals `C(m*n - 2, k - 2) * S`, where `S` is the sum of Manhattan distances over all unordered pairs of distinct cells.

Computing `S` directly is O((mn)^2), too large. We split the Manhattan distance into x and y components: `S = Sx + Sy`. For the x-direction, cells are indexed `0..m-1`, each with `n` copies (one per column). The contribution of a row at index `x` to a pair with a row at index `x' > x` is `n * n * (x' - x)`. So `Sx = n^2 * sum_{0 <= x < x' < m} (x' - x)`. The inner sum is a well-known closed form: `sum_{x=0}^{m-1} x * (m-1-x) = C(m, 3) * 2`? Let's derive: `sum_{x<x'} (x'-x) = sum_{d=1}^{m-1} d * (m - d)`. Using `sum d(m-d) = m * m(m-1)/2 - m(m-1)(2m-1)/6 = m(m-1)(m+1)/6`. So `Sx = n^2 * m(m-1)(m+1)/6`. Similarly, `Sy = m^2 * n(n-1)(n+1)/6`.

Thus total = `C(m*n - 2, k - 2) * (n^2 * m(m-1)(m+1)/6 + m^2 * n(n-1)(n+1)/6) mod MOD`, where `MOD = 10^9+7`. Compute factorials up to `m*n` (≤ 10^5) to get `C` fast.
