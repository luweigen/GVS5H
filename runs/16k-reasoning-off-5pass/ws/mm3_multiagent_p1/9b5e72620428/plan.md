The key observation is that after rearrangement and filling, we need a constant S such that A_i + B_i = S for all i. Fully-known positions force this sum, and for half-known positions the unknown value becomes S minus the known one (requiring S to be large enough). The multiset condition on A is automatically satisfiable because we can freely permute A and fill its unknowns. So the problem reduces to: (1) all fully-known pairs must have the same sum, and (2) that sum must be at least every known value in A and B.
