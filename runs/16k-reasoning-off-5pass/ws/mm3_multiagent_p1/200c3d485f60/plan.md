We need to count arrays of length n over alphabet {1..m} with exactly k equal-adjacent pairs. The standard approach splits the array into runs of equal elements. If there are k equal-adjacent indices, then the array consists of r = n - k runs of (possibly) different values. Choose the first value in m ways. For each of the remaining r-1 runs, pick a value different from the previous run: m-1 ways each. So the count is m * (m-1)^{r-1} * C(n-1, k) (choose the positions of the k equal transitions among the n-1 gaps). Compute powers with fast exponentiation and nCr via factorials + modular inverses modulo 1e9+7.
