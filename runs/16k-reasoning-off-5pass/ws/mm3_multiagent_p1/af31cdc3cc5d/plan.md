We need to repeatedly remove adjacent pairs, accumulating |a-b| per removal, until ≤1 element remains. This is equivalent to selecting a perfect matching on the "line graph" positions where every position is used exactly once if N even, or all but one if N odd. Since removal order only changes adjacency, we can think of it as partitioning the sequence into pairs (with possibly one unpaired element). The total score is sum of |A_i - A_j| over the chosen pairs. So we need maximum weight perfect matching on a path (if N even) or near-perfect matching (one vertex unmatched) on a path. This can be solved with DP: let `dp[i][k]` be max score considering first i elements where k ∈ {0,1,2} indicates how many "unmatched" carries to the right (0: i fully matched; 1: i is unmatched and we can pair it with i+1; 2: i+1 is unmatched and we need to pair it later). Transitions handle pairing or leaving unmatched. Complexity O(N). We'll implement O(N) with rolling arrays.
