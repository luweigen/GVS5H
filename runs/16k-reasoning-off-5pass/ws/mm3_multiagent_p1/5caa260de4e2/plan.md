This is a classic DP with convex hull trick (CHT) optimization. Define prefix sums `S[i] = sum(nums[0..i-1])` and `C[i] = sum(cost[0..i-1])`. The cost of a subarray `nums[l..r]` as the i-th group is `(S[r+1] + k*i) * (C[r+1] - C[l])`. We compute `dp[r+1] = min over l<=r of dp[l] + (S[r+1] + k * groups) * (C[r+1] - C[l])` where `groups = (number of subarrays up to l) + 1`. The expression is linear in `C[l]` times constants, so we can use CHT (Li Chao or deque if slopes monotonic) per group count. Since n ≤ 1000, a simpler O(n²) DP may pass, but we implement O(n²) with optimization using prefix and rolling minima for clarity, or full O(n log n) CHT. Given constraints, O(n²) is acceptable. We'll provide an O(n²) solution with a small optimization using the prefix sums to compute group cost in O(1) and maintain a running minimum.
