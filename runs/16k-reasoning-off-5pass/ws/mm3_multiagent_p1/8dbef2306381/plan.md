We have N up to 1e12, but only M ≤ 2e4 bad intervals. Movement is in steps i ∈ [A,B] (A,B ≤ 20) but only to non-bad squares. We can think of this as a BFS/DFS on reachable squares, but N is huge. However, since the bad intervals are disjoint and bounded in number, the "good" (non-bad) segments are also at most M+1. Inside a long good segment, we can move freely as long as we can land somewhere; essentially we can compress consecutive good squares where any movement pattern works.

Key observation: we can represent reachability using a BFS over intervals (segments of consecutive good squares) instead of individual squares. From a good segment, we try steps i in [A,B]; the target is a square in some good segment, and once we can reach any square in that segment, we can reach the whole segment (if it's long enough to allow arbitrary steps within it — since B ≤ 20, a good segment of length ≥ B is "fully connected" internally). So we only need to track which segments are reachable, and process them by trying all step sizes A..B, finding the resulting segment, and BFS-ing. Number of segments ≤ M+1 ≤ 20001, and transitions ≤ (M+1)*(B-A+1) ≤ 2e4 * 20 = 4e5, which is fine.
