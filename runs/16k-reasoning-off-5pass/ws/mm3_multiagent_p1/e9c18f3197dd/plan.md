We need, for each `t` in `target`, at least one `n` in `nums` that is a multiple of `t`. We can only increase elements of `nums`. For each `n` we can compute the set of `t` it already covers (where `n % t == 0`). Then the problem becomes a set cover / assignment: assign each `t` to some `n` that can reach it, where the cost for `n` to cover a chosen `t` is the number of increments needed (i.e., the smallest `k >= 0` such that `(n + k) % t == 0`, which is `(-n) mod t`). Since `target.length <= 4`, we can afford a DP over subsets of target. For each `n`, we precompute a cost vector over all subsets of target that `n` can cover: if `n` already covers subset `S` (those `t` with `n % t == 0`), then for that `S` the cost is `0`; for each single missing `t`, the cost to cover exactly `{t}` added to whatever `S` it already covers is `((-n) % t)` increments (after which `n` becomes a multiple of `t`, hence also of all `t' in S`). We then run DP over `n` to find the minimum total cost to cover all `|target|` elements. Complexity is `O(nums.length * 2^|target| * |target|)`, which is fine for `nums <= 5e4` and `|target| <= 4`.
