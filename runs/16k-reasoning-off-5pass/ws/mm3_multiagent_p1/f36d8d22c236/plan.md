We need to check if a sequence of "replace all occurrences of letter x with letter y" operations can transform S into T. This operation defines a functional mapping: after a sequence of operations, each original letter in S ends up mapped to a single target letter (the result of a chain of replacements). Therefore a necessary and sufficient condition for possibility is that for every position i, the target letter T[i] is the same for all indices sharing the same source letter S[i]. If any source letter maps to two different targets, the answer is -1.

If possible, we must compute the minimum number of operations. An operation can replace any letter x with any y in one step, but operations that would be redundant (e.g., replacing a letter with itself, or replacing a letter that never appears, or replacing a letter that already equals the target) should be avoided. The optimal strategy groups letters into cycles in the mapping graph from S-letters to T-letters. 

We model the 26 letters. For each source letter c that actually appears in S, we know its final target f[c] (the unique letter that all its positions must become). If f[c] == c, no operation is needed. If a letter c maps to itself indirectly via a cycle (e.g., a->b, b->a), we need one extra operation to break the cycle. We compute the number of connected components in the directed functional graph restricted to letters that appear in S and have f[c] != c, where each component requires size operations plus an extra operation if it contains a cycle (i.e., a letter that must map to itself indirectly, which we detect by checking if any letter in the component has f[c] == c – actually a cycle exists iff for some letter c, f[c] == c is NOT in the component but the component size > 1, or more cleanly: if we topologically remove "fixed" letters f[c]==c, the remaining graph consists of cycles; each cycle needs its own one operation to break). 

Simplify: Build undirected graph of involved letters. Count components. A component of size k that contains any self-loop (letter with f[c]==c) needs exactly k operations (we can directly map each other letter to its final target). A component of size k with no self-loop (pure cycle) needs k+1 operations (one extra to temporarily introduce a self-loop).
