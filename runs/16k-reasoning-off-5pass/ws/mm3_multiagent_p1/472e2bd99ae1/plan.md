The expression `f(i,j,k) = A_i*B_j + B_j*C_k + C_k*A_i` is symmetric in the three variables after swapping roles. A classic technique for such problems is to fix one of the indices (say `j`) and sort the other sequences appropriately so that we can binary‑search the threshold value `X` counting how many triples have `f >= X`. Counting efficiently per `j` requires sorting one of the sequences (e.g. `A`) in descending order, then for each `j` we consider pairs `(A_i, C_k)` and count how many satisfy `B_j*(A_i + C_k) + A_i*C_k >= X`. This can be done with a two‑pointer sweep over a sorted array of `A_i + C_k` because for a fixed sum `S = A_i + C_k`, the term `A_i*C_k` is maximized (or minimized) when the two numbers are balanced. After we can compute `cnt(X)` we binary‑search the largest `X` with `cnt(X) >= K`. Complexity is `O(N log N log MaxValue)`, well within the limits.
