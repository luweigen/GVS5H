We need to count subarrays that avoid all conflicting pairs after removing exactly one pair. For each position `i` in `nums`, define `left[i]` = the largest index `j < i` such that there exists a conflicting pair `(a,b)` with `min(a,b)=j` and `max(a,b)=i`. Then any subarray ending at `i` must start after `left[i]` to avoid all conflicts. The total number of valid subarrays is `sum_{i=1..n} (i - left[i])`.

When we remove a pair `(a,b)` with `a<b`, it only affects positions `i=b` (and possibly later positions if `left[i]` was exactly `a`). So we can compute, for each `a`, the total gain in subarray count if we remove the pair that currently sets `left[b]=a` for the maximum `a` at each `b`. We track for each `b` the top two largest `a` values among pairs ending at `b`; removing the top one gives a gain equal to the number of positions where it was the dominant constraint, times the difference between the top two `a` values. Summing these gains over all `b` and adding the base count yields the answer.
