We need the minimum number of adjacent swaps to make all 1s contiguous. The optimal final arrangement places all 1s in some window of length equal to the number of 1s. For each possible window, sum the distances each 1 must travel left to its target position; this equals the total inversions between the sequence of 1-positions and the consecutive target positions. Use a sliding window over the 1-positions: as the window shifts by one (drop the leftmost 1's old contribution, add the new rightmost 1's contribution), update the cost in O(1) per shift. Overall O(N) after extracting positions of 1s.
