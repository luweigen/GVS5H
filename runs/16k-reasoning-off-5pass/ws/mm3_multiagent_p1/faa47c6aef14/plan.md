We model each box as a node with two outgoing edges: red edge to `P_i` and blue edge to `Q_i`. Performing an operation on box `i` moves all balls currently in `i` along these edges to their destinations. Since each ball moves independently, the reachable set of boxes from any starting box is the union of nodes reachable by following red/blue edges. We need to check whether every ball (red or blue) can eventually reach `X`. This reduces to: for each color, the directed graph formed by that color's permutation must have `X` reachable from every node that initially contains a ball of that color. If both conditions hold, we can gather all balls into `X`. The minimum number of operations equals the number of boxes we need to "activate" along the way. For each color, we compute the set of boxes that lie on some path to `X` in the reverse graph (i.e., boxes from which `X` is reachable). The answer is the size of the union of these two sets (boxes that must be operated on at least once), because operating on a box moves all balls currently there forward, and we can process boxes in topological order from farthest to `X`. If any ball's color cannot reach `X`, output `-1`.
