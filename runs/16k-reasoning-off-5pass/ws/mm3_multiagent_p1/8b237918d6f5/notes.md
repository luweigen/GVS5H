The problem asks to choose exactly K edges out of M to set weight 1 (others 0) to maximize the shortest distance from 1 to N. N ≤ 30, M ≤ 100, K ≤ M.

Core difficulty: The choice of which edges become weight 1 affects the shortest path globally. Brute-force over subsets of size K is infeasible (C(100,50) huge). We need a smarter approach.

Key observation: The condition that the shortest path cost is at least d is equivalent to: every 1→N path contains at least d edges from the selected set X. This is a covering problem: we need to select K edges such that every path has at least d hits.

We can binary search on d (0 ≤ d ≤ K). For a fixed d, we need to check if there exists a set X of size K such that every 1→N path has at least d edges from X. Because the condition is monotone in X (if X works, any superset works), it suffices to check if the minimum size of such an X is ≤ K. So we need to compute f(d) = minimum |X| such that every 1→N path contains at least d edges from X.
