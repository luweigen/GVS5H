Algorithm: sort P ascending. remaining = M. ans = 0. For each p in P: k = floor(sqrt(remaining / p)). ans += k. remaining -= k*k*p. Output ans.

We must use 128-bit integers (Python int handles arbitrary precision). Complexity O(N log N).

Edge cases: p may be up to 2e9, remaining up to 1e18, k up to 1e9 (since (1e9)²·1 = 1e18). Python's `int` and `math.isqrt` handle this.
