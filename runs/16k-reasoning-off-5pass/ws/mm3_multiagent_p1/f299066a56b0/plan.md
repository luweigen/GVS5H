We need to pair mochi such that each pair (a,b) satisfies a ≤ b/2, and maximize the number of pairs. Since sizes are sorted, a greedy two-pointer approach works: use the smallest mochi as the "top" candidate and try to match it with the smallest possible "bottom" mochi that is at least twice its size. Maintain two pointers: i starting at 0 (smallest), j starting at N/2 (or N-1) for the bottom. If A[i] * 2 ≤ A[j], we can form a pair, increment answer, move both pointers; otherwise move j forward to find a larger bottom. This runs in O(N).
