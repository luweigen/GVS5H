We need to sum (min + max) over all subarrays whose length is between 1 and k inclusive. Brute force is O(n·k) which is too slow for n=80000. The standard approach is to count, for each subarray length L, the contribution of each element as a maximum (or minimum) over exactly L-length subarrays, sum over L=1..k, then combine max+min. For a fixed L, an element nums[i] is the max of those L-length windows where it is the rightmost (or leftmost) occurrence of the max; we can count those windows using next-greater-element distances. Multiply nums[i] by the count of windows where it is the max (using rightmost-max convention) and similarly for min using next-smaller distances. Sum over i, then over L. Complexity O(n) per pass.
