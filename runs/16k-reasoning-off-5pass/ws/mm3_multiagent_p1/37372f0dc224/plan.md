We need the shortest palindrome that starts with S. This is equivalent to finding the longest suffix of S that is a palindrome, because we can keep that suffix as the center and only mirror the non-palindromic prefix. Concretely, if S = "TREE", the longest palindromic suffix is "E" (of length 1), so we prepend the reverse of the remaining prefix "TR" (=> "RT") to get "TREERT". To find the longest palindromic suffix in O(n) time, we use the string hash trick: compute forward rolling hash and reverse rolling hash for S, and binary‑search the largest length L (1..n) such that the prefix hash of length n-L matches the reverse hash of the same substring. Then the answer is S + reverse(S[0 : n-L]).
