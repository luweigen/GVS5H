We model each constraint `A_x XOR A_y = Z` as an equation over GF(2) per bit. For each bit independently, the variables are bits of A_i. The constraints form a linear system over GF(2). We can solve each bit using DSU with parity (union-find with xor-to-parent). For each connected component, we either fix the root's bit to 0 or 1; the choice determines all other bits in that component. To minimize the total sum of A_i, we should choose, for each bit, the assignment that yields the smaller contribution (i.e., fewer 1s in that component). However, components for different bits are independent, so we can simply pick the assignment that minimizes the number of 1-bits in that component for each bit independently. After processing all bits (0..30, since Z_i ≤ 1e9 < 2^30), we combine the per-bit values to form A_i. If any bit's system is inconsistent, output -1.
