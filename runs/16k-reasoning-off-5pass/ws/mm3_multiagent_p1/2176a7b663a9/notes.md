The problem asks for minimum-weight paths in a graph where vertices are intervals and edges exist iff intervals are disjoint. This is the complement of an interval graph, specifically the comparability graph of an interval order. The graph has special structure: sorted by L, each vertex i is connected to all j > i with L_j > R_i (right neighbors) and all j < i with R_j < L_i (left neighbors). However, the graph can have large diameter (e.g., paths of length 4 or more exist), and weights are positive vertex weights. We need to answer Q queries (s, t) for minimum path weight sum or -1 if disconnected.

Key observations:
- Edge weight model: cost of entering vertex v is W_v, so path cost = W_s + sum of W for intermediate vertices + W_t.
- The graph is defined by two threshold conditions: right edges (L_j > R_i) and left edges (R_j < L_i).
- Connectivity: s and t are connected if there exists a chain of disjoint intervals linking them. This is equivalent to: there is a sequence of intervals where each step jumps over the current interval's span.
- The graph is a comparability graph of an interval order, which is a DAG if oriented left-to-right. The undirected graph is its transitive closure.
- Shortest path with positive weights: Dijkstra on full graph is O(N^2) edges, too slow.
