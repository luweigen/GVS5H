The key observation is that since W is small (up to 18), we can iterate over all possible subsets of columns to flip using Operation Y. There are $2^W$ such subsets. For a fixed set of flipped columns, each row's pattern is transformed. Then, for each row, we can independently choose whether to flip it (Operation X) or not, choosing the option that results in fewer 1s in that row. Specifically, for each row, we compute the number of 1s in its current state and the number of 0s (which equals W minus the number of 1s). We take the minimum of these two values for each row and sum them up. We repeat this for all $2^W$ column flip combinations and take the global minimum. The time complexity is $O(2^W \cdot H \cdot W)$, which is feasible given $W \le 18$ and $H \le 2 \times 10^5$.
