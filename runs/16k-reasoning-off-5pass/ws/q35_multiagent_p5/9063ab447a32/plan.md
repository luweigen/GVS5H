1. **Binary Search on Answer**: The maximum total units `X` we can buy is monotonic with respect to cost. If we can buy `X` units, we can definitely buy `X-1`. So we binary search on `X` in the range `[0, M + N]` (since even buying 1 unit of the cheapest product costs at least 1, so max units <= M).
2. **Greedy Cost Minimization for Fixed X**: For a fixed total number of units `X`, we want to minimize the total cost. Since the cost function `k^2 * P_i` is convex, we should distribute the `X` units among the `N` products such that the marginal cost of adding one more unit to any product is balanced. Specifically, if we have already bought `k_i` units of product `i`, the cost to buy the `(k_i+1)`-th unit is `((k_i+1)^2 - k_i^2) * P_i = (2*k_i + 1) * P_i`.
3. **Efficient Check using Priority Queue or Mathematical Insight**: For a fixed `X`, we can think of it as assigning `X` "slots" to products. The cost of the `j`-th unit (1-indexed) of product `i` is `(2*(j-1) + 1) * P_i = (2j-1)*P_i`. We want to pick the `X` smallest marginal costs from all possible marginal costs across all products. However, `X` can be up to `10^{18}`, so we cannot simulate. Instead, we can binary search on the "threshold marginal cost" `C`. For a given threshold `C`, we can compute how many units of each product `i` have marginal cost <= `C`. The marginal cost for the `j`-th unit of product `i` is `(2j-1)*P_i <= C` => `j <= (C/P_i + 1)/2`. So the number of units of product `i` we can "afford" at threshold `C` is `max(0, floor((C/P_i + 1)/2))`. Let this be `count_i(C)`. We sum `count_i(C)` over all `i`. If the sum >= `X`, then threshold `C` is feasible. We then compute the exact minimum cost for `X` units by summing the costs of all units with marginal cost < `C`, and then adding the remaining units at marginal cost `C` (if needed).
4. **Binary Search on Threshold C**: We binary search on `C` in range `[0, 2*M]` (since max marginal cost for the last unit won't exceed `2*M`). For each `C`, we compute total units `S(C) = sum_i max(0, floor((C/P_i + 1)/2))`. We find the smallest `C` such that `S(C) >= X`. Then we compute the exact cost: sum of `(2j-1)*P_i` for all `j <= count_i(C)` where `(2j-1)*P_i < C`, plus some units at exactly `C` if `S(C) > X`.
