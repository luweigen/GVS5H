The problem asks if we can reach square N from square 1 using jumps of size in [A, B], avoiding "bad" squares. Since N is up to $10^{12}$, we cannot simulate all squares. However, M is small ($2 \times 10^4$) and B is small ($\le 20$). The bad squares form M disjoint intervals. We can model this as a reachability problem on the "good" squares. We can use a BFS/DFS approach but only visit "critical" points: the start (1), the end (N), and the boundaries of the bad intervals. Specifically, we can process intervals of good squares. Within a contiguous segment of good squares, if the segment is long enough, we can reach any position within it from any other position provided the jump constraints allow it. More precisely, we can define "events" at the start and end of each bad interval. We can compute the set of reachable positions in the current good segment. Since B is small, the "reachability window" is small. We can maintain a set of reachable positions at the current boundary. When we cross a bad interval, we check if the reachable positions can jump over the bad interval to land in the next good segment. We can use a BFS-like approach on the "segments" of good squares. For each good segment, we determine the range of reachable positions within it. If the intersection of reachable positions and the segment is non-empty, we propagate the reachability to the next segment. The key is that within a good segment of length L, if we can enter at some position, we can reach a contiguous range of positions in that segment, bounded by the segment limits and the jump constraints. We can compute the min and max reachable positions in each good segment.
