4. For each connected component, the relative values of all nodes are fixed once the root's value is chosen. Let the relative value of node $i$ be $R_i$ (where $R_{root}=0$). Then any valid assignment is $A_i = R_i \oplus C$, where $C$ is the component's constant offset.
5. To minimize the sum $\sum A_i$, we need to choose $C$ such that $\sum (R_i \oplus C)$ is minimized. Since bits are independent in XOR but not in sum, we determine $C$ bit by bit from most significant to least significant? No, actually, for each bit position $k$, the contribution to the sum depends on how many $R_i$ have the $k$-th bit set. If we choose the $k$-th bit of $C$ to be 0, the $k$-th bit of $A_i$ is $R_i$'s $k$-th bit. If we choose 1, it's flipped. We can independently choose the $k$-th bit of $C$ to minimize the total sum contribution from that bit position. Specifically, for bit $k$, let $cnt$ be the count of nodes in the component with $k$-th bit set in $R_i$. If we set $C$'s $k$-th bit to 0, the cost is $cnt \cdot 2^k$. If we set it to 1, the cost is $(Size - cnt) \cdot 2^k$. We pick the minimum.
