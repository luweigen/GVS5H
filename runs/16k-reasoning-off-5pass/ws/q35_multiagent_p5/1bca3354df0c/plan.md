The key observation is that a graph contains no odd cycles if and only if it is bipartite. The game ends when the graph becomes a maximal bipartite graph (i.e., adding any edge would create an odd cycle). In a bipartite graph with connected components having partition sizes $(a_k, b_k)$, the maximum number of edges in a maximal bipartite supergraph is $\sum_k a_k b_k$. The initial number of edges is $M$. The total number of moves possible in the game is exactly $(\sum_k a_k b_k) - M$. Since players alternate turns and the last player to move wins (normal play convention), the first player (Aoki) wins if the total number of moves is odd, and the second player (Takahashi) wins if it is even. We need to compute the connected components, determine the size of the two partitions for each component (using BFS/DFS bipartite coloring), calculate the sum of products of partition sizes, subtract $M$, and check the parity.
