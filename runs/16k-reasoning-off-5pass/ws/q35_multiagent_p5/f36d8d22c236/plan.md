Additionally, if two different characters in S map to the same character in T, that's allowed in the final state but we need to check if the graph of transformations allows it without cycles that prevent completion. Actually, the primary impossibility condition is: if `S[i] != S[j]` but `T[i] == T[j]`, this is allowed only if we can "merge" them. However, the stricter constraint is: if `S[i] == S[j]` and `T[i] != T[j]`, it's impossible. So, first check: for all `i, j`, if `S[i] == S[j]` then `T[i] == T[j]`. If not, return -1.
