The problem asks for the number of substrings divisible by their non-zero last digit. A brute-force approach checking all substrings would be O(n^2), which is too slow for n=10^5. We need a more efficient approach. Notice that the last digit determines the divisor. For each position `j` (end of substring), we consider substrings ending at `j` with last digit `d = s[j]`. If `d == '0'`, these substrings are invalid (divisor is 0). If `d != '0'`, we need to count how many start indices `i` (0 <= i <= j) form a substring `s[i..j]` such that the integer value of `s[i..j]` is divisible by `d`. The value of substring `s[i..j]` can be computed using prefix sums of powers of 10. Specifically, `num(i, j) = prefix[j+1] - prefix[i] * 10^(j-i)`. We need `(prefix[j+1] - prefix[i] * 10^(j-i)) % d == 0`. This can be rewritten as `prefix[i] * 10^(j-i) ≡ prefix[j+1] (mod d)`. For a fixed `j` and fixed `d`, we can iterate over possible lengths or use modular arithmetic properties. However, since `d` is small (1-9), we can group indices `i` by `i % d` and maintain counts of `prefix[i] * 10^(-i) mod d` or similar. A simpler observation: for each ending position `j`, the last digit `d` is fixed. We can iterate `i` from `j` down to `0`, building the number modulo `d`. Since `d` is at most 9, and we only care about divisibility, we can compute the remainder incrementally. But iterating all `i` for each `j` is still O(n^2). Instead, we can use the fact that for a fixed `d`, the condition depends on `i`. We can precompute prefix values and use modular inverse if gcd(10, d)=1, but d can be 2,4,5,6,8 where gcd(10,d) != 1. A better approach: for each digit `d` from 1 to 9, collect all positions `j` where `s[j] == d`. For each such `j`, we want to count `i <= j` such that `int(s[i..j]) % d == 0`. We can compute this by iterating `j` and maintaining a frequency array of remainders for each `d`. For each `d`, as we extend the substring to the left, the remainder changes. But doing this for each `d` separately and for each `j` is complex. Given constraints, an O(n * 9) solution is acceptable. For each `j`, if `s[j] != '0'`, let `d = int(s[j])`. We iterate `i` from `j` down to `0`, computing the number `num` modulo `d`. If `num % d == 0`, increment count. This is O(n * max_digit) = O(9n) which is O(n). This is efficient enough.
