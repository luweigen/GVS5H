1.  **Graph Construction Insight**: Directly constructing the graph is infeasible because the number of edges can be $O(N^2)$. Instead, we observe that two intervals are disjoint if one is completely to the left of the other. This suggests that connectivity is largely determined by the "extremes" of the intervals.
2.  **Component Analysis**: The graph's connectivity can be understood by looking at the sorted order of intervals. If we sort intervals by their left endpoints, intervals that are "close" in the sorted order might overlap, while those far apart might be disjoint. However, a more robust approach is to realize that if the union of all intervals forms a single contiguous block, the graph might be connected or have specific components.
3.  **Key Observation**: Two intervals $[L_i, R_i]$ and $[L_j, R_j]$ are disjoint if $R_i < L_j$ or $R_j < L_i$. This implies that if we sort the intervals by their left endpoints, an interval $i$ can connect to any interval $j$ with $L_j > R_i$.
4.  **Minimum Weight Path**: The weight of a path is the sum of vertex weights. To minimize the path weight between $s$ and $t$, we should look for a path that goes through vertices with small weights. In many cases, the shortest path (in terms of weight) between two connected components or nodes will involve going through a "hub" node with minimal weight if the graph is dense.
5.  **Algorithm**:
    *   First, determine the connected components of the graph. Since $N$ is up to $2 \times 10^5$, we need an efficient way to find components. We can use a sweep-line or sorting-based approach to identify connectivity.
    *   Specifically, we can sort the intervals by $L_i$. We can maintain the maximum $R$ seen so far. If the current interval's $L_i$ is greater than the maximum $R$ of all previous intervals, it might form a new component or connect to some previous ones. Actually, a better way is to note that if the intervals cover a range such that there are no "gaps" in the union of intervals, the graph is likely connected.
    *   However, a simpler characterization: The graph is connected if and only if the intervals cannot be partitioned into two sets $A$ and $B$ such that all intervals in $A$ are to the left of all intervals in $B$ (i.e., $\max_{i \in A} R_i < \min_{j \in B} L_j$).
    *   We can find the connected components by sorting intervals by $L_i$ and tracking the maximum $R$. If at any point the current $L_i$ is greater than the max $R$ of all previous intervals, a new component starts.
    *   Within a component, the minimum weight path between $s$ and $t$ is often just $W_s + W_t$ if they are directly connected, or $W_s + W_{min} + W_t$ if they are not directly connected but share a common neighbor with minimal weight $W_{min}$ in the component.
    *   So, for each component, we find the vertex with the minimum weight. Let this be $W_{min}$.
    *   For a query $(s, t)$:
        *   If $s$ and $t$ are in different components, output -1.
        *   If $s$ and $t$ are in the same component:
            *   Check if they are directly connected (intervals disjoint). If yes, candidate weight is $W_s + W_t$.
            *   Otherwise, the path must go through at least one intermediate node. The best intermediate node is the one with the minimum weight in the component. Candidate weight is $W_s + W_{min} + W_t$.
            *   The answer is the minimum of these candidates. Note: If $s$ and $t$ are directly connected, $W_s + W_t$ is better than $W_s + W_{min} + W_t$ (since $W_{min} \ge 1$). So we just take $\min(W_s + W_t, W_s + W_{min} + W_t)$ if we don't know if they are directly connected? No, if they are directly connected, the direct edge exists. If not, we must use an intermediate.
            *   Actually, if they are directly connected, the path $s \to t$ has weight $W_s + W_t$. If not, any path must have length $\ge 2$ edges, so at least 3 vertices. The minimum weight path would be $s \to k \to t$ where $k$ is the node with min weight in the component.
            *   So, we need to efficiently check if $s$ and $t$ are directly connected. This is equivalent to checking if $[L_s, R_s]$ and $[L_t, R_t]$ are disjoint.
