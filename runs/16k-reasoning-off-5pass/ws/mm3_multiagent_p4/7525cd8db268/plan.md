We need to count subarrays that avoid having both endpoints of any remaining conflicting pair. For each index i, define `right[i]` = number of valid subarrays ending at i. A subarray ending at i is valid iff its start position is > all "blockers": for each conflicting pair (a,b) with a<b, any subarray containing both a and b is invalid; equivalently, the rightmost index a (or b) that appears before i forbids start ≤ a. So if we maintain, for each position i, the closest blocker index `max_block[i]`, then `right[i] = i - max_block[i]`, and the total valid subarrays = sum of `right[i]`. We need to remove exactly one conflicting pair to maximize this total.

Key insight: each conflicting pair (a,b) with a<b only blocks subarrays that span across a..b; i.e., its effect is only on positions i ≥ b, where the max_block can be at least a. By scanning i from 1..n while maintaining the top two smallest a's among active conflicting pairs that end at i, we can compute base `right[i]` (with all pairs) and the "gain" from removing a pair: when the largest blocker `mx1` for position i comes from a particular pair, removing that pair would lower the blocker to `mx2` (second largest), increasing `right[i]` by `mx1 - mx2`. We accumulate for each pair the total extra subarrays gained if it were removed (by adding `mx1 - mx2` at each i where it's the dominant blocker). Answer = base_total + max_gain over pairs.

Implementation details:
- Normalize pairs: for each [a,b], set `lo = min(a,b)`, `hi = max(a,b)`, keep `(lo, hi)`. We may have duplicate pairs; treat them as separate items (removing one occurrence is what matters).
- Build `ends[hi].append(lo)`.
- Sweep i=1..n: add all lo's from `ends[i]` to a multiset; track top two max values (`mx1`, `mx2`). `base += i - mx1`.
- For gain: if `mx1` originated from a particular lo, and that lo is still in the set after this position's removals (i.e., the "best" pair for this i is identifiable), add `mx1 - mx2` to the gain bucket of that lo (or to a list of candidate gains for that lo).
- We need to map "which conflicting pair contributed mx1" to a unique identifier. Since we only care about removing one pair, we can track for each lo the accumulated gain when that specific lo is the top blocker.
- To identify which pair (lo) is the current top: when we add a value equal to current mx1, we need to know if it's from a new addition. A clean way: maintain counts of how many times each lo appears among currently active pairs (so duplicates of same lo allowed). The top mx1 is the maximum lo among active pairs. If multiple pairs share the same max lo, removing one of them doesn't change mx1 (gain = 0). So gain only accrues to the *value* lo that is uniquely the maximum. We can track `top_value = mx1`. If count[mx1] == 1, then removing that unique pair gives gain `mx1 - mx2`; we add this gain to an accumulator `gain[lo_value]`. We use a dict/list indexed by lo value. Since lo ∈ [1,n-1], we can use a dict.
- Actually, if there are multiple pairs with the same lo value, they're effectively identical for blocking; removing one of them doesn't help because the other still blocks with the same lo. So gain should only be attributed to the lo value itself, not to each pair individually. So one accumulator per lo value suffices.
- After sweep, `max_gain = max(gain.values(), default=0)`. Answer = `base + max_gain`.

Complexities: O(n + m) time, O(n + m) memory.
