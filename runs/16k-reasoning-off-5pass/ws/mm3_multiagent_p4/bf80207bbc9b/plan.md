Since W ≤ 18, we can treat each column flip (Operation Y) as a bitmask decision (0..2^W-1). For a fixed column mask, we can decide per row whether to flip it (Operation X) optimally: flip a row if flipping reduces the number of 1s in that row (after column flips). This is the classic "row/column flip minimization" problem solvable in O(H·2^W) time. For each column mask, compute the resulting total and keep the minimum.
