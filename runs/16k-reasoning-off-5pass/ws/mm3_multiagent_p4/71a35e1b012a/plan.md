We need to choose for each operation i one of {0,1,2} (cost 0/1/1) so that after processing all M operations, every position j ∈ [1,N] has been set to 1 at least once. Operation 1 sets positions in [L_i,R_i] to 1; operation 2 sets positions outside [L_i,R_i] to 1. Operation 0 does nothing.

This is a classic set cover / interval covering problem. Each operation i covers either the interval [L_i,R_i] (type 1) or its complement (type 2). We must cover the whole universe [1,N] using a subset of these "covers" (each operation can be used at most once, and we pay 1 per used operation). We want minimum number of used operations.

Key observation: If we ever use operation 2 on interval [L,R], it covers everything except [L,R]. So it is efficient to cover large contiguous blocks. The optimal solution can be found greedily: sort operations by L ascending, and among those with same L, by R descending. Then iterate, maintaining the current rightmost covered position `cur`. For each operation in sorted order, if its L ≤ cur+1, it can extend coverage (if we choose type 1). We pick the one with maximum R among those with L ≤ cur+1, set cur = maxR, record that we used this operation (type 1). If no such operation exists but cur < N, we try to use an operation 2: we need an operation whose complement covers the remaining uncovered part. The uncovered part is [cur+1, N]. We need an operation i such that [L_i,R_i] does NOT intersect [cur+1,N], i.e., R_i < cur+1 or L_i > N (impossible). So we need R_i < cur+1. Among all operations with R_i < cur+1, we want the one with minimum L_i (to maximize the complement coverage). Actually complement of [L,R] is [1,L-1] ∪ [R+1,N]. To cover [cur+1,N], we need R+1 ≤ cur+1, i.e., R ≤ cur. Wait: complement covers [R+1,N] if we choose type 2. So to cover [cur+1,N], we need R_i+1 ≤ cur+1, i.e., R_i ≤ cur. Among those, we want the smallest L_i to also cover [1, L_i-1] (which may already be covered). So we pick the operation with minimum L_i among those with R_i ≤ cur. If such exists, we use it as type 2, and cur becomes N (since complement covers up to N). If neither type 1 extension nor type 2 finishing is possible, output -1.

We also need to output the chosen operation type for each of the M operations in original order. We can store an array `ans[i]` initialized to 0, and when we select operation i as type 1 or type 2, set `ans[i]` accordingly.
