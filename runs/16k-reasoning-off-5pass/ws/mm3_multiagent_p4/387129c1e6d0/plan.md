1. **Model the movement**: Santa moves in axis-aligned straight segments, so each segment is a line parallel to one of the axes. The final position is simply the cumulative sum of signed C_i steps added to the start coordinates — handled with 64-bit integers to avoid overflow.
2. **Count houses along the path**: For each movement segment, collect only the houses that lie on that exact axis-aligned line segment (matching x for vertical moves, matching y for horizontal moves) and whose coordinate along the move lies strictly between the start and end (inclusive of the end if a house is exactly there). Insert all collected coordinates into a Python `set` for O(1) duplicate elimination.
3. **Sweep efficiently**: For a horizontal move, store houses keyed by their y-coordinate in a dictionary mapping y → sorted list of x-values, built once at the start. For each horizontal segment, binary search the relevant list to count the houses inside the interval. Do the analogous thing for vertical moves with x → sorted y-values. The total work is O((N+M) log N) using `bisect`.
4. **Aggregate**: The total distinct count `C` is `len(set)`. Output final x, final y, and C.
