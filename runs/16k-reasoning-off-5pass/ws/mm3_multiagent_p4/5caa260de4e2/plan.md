We need to partition the array into contiguous subarrays minimizing the sum of per-subarray costs, where the i-th subarray's cost depends on the prefix sum of nums up to its end plus k*i, multiplied by the sum of cost in that subarray. The standard DP approach is `dp[i] = min_{j < i} dp[j] + (prefixN[i] + k * (groups+1)) * (prefixC[i] - prefixC[j])`, where `groups` is the number of subarrays used up to index j. This can be optimized using convex hull trick / Li Chao segment tree because the cost is quadratic in `prefixC[i]` after algebraic expansion. With n ≤ 1000, a simple O(n²) DP is already efficient enough and avoids complex implementations. We'll precompute prefix sums, run O(n²) DP, and return `dp[n]`.
