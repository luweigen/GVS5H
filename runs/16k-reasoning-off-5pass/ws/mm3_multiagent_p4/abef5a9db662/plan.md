For each contest we have an interval [L_i, R_i] in which a rating increment occurs. The rating only ever increases, so the rating after all contests is X plus the number of contests i such that, at the moment of contest i, the current rating lies in [L_i, R_i]. Because rating can only increase, once a rating leaves an interval it never returns; similarly, once it becomes large enough to be inside all later intervals, it will always be counted. We can precompute for every starting rating X the final rating (or equivalently, the number of increments). Since the rating range is bounded (max 5e5 + N, but we can cap it), we can simulate forward and build a function f: start_rating -> final_rating in O(max_rating). For each query we just output f[X].
