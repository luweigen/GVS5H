We treat the string as a sequence of bits and we want to decide if we can transform S into T using two reversible local operations that swap a block of X zeros followed by Y ones (Operation A) into Y ones followed by X zeros, and the symmetric reverse (Operation B). Because both operations preserve the multiset of bits, the total number of 1's in S must equal that in T; otherwise answer is No. When they are equal, we can think of "excess" 1's to the left of each position. Let prefix sums pref[i] = (number of 1's in S[0..i)) - (number of 1's in T[0..i)). Whenever pref[i] > 0, the i‑th character of S is effectively "1 too early" and we need to move it to the right. The two operations allow us to shift a block of X "excess" 1's rightward by X+Y positions (or shift Y "excess" 0's leftward). This is exactly a problem of moving units using a fixed step size d = X+Y. Therefore a solution exists iff for every i, pref[i] is non‑negative (excess cannot move left) and all excess can be shifted right by multiples of d. This is equivalent to checking that for each residue class modulo d, the prefix excess values are non‑negative and the final value in that class is zero. We can verify this in O(N) time using a sliding‑window sum.
