The sum over all monotone paths of the product of cell values can be written as a weighted sum of entries using a known combinatorial identity. For each cell (i,j), define `c[i][j] = C(i+j-2, i-1) * C(H+W-i-j, H-i) mod p`. Then the desired sum is `Σ c[i][j] * A[i][j] mod p`. We'll precompute factorials and inverse factorials up to H+W, compute all `c[i][j]` once, then maintain `cur = Σ c * A`. Each update replaces a single `A` with a new value `a_i`; the new answer is `cur + c[new] * (a_i - old) mod p`. Each query is O(1) after O(1) updates. Total O((H+W) + HW + Q) which fits since HW ≤ 2e5 and Q ≤ 2e5.
