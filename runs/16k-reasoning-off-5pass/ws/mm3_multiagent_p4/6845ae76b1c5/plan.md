Sort arrays A and B, then precompute prefix sums of A and B for O(1) sum queries. For a query (X, Y), split the answer into four parts using binary search to find how many A[i] are less than each B[j] (or vice versa), compute sum differences using the prefix sums, and add the cross term (Y * sum of first X A) + (X * sum of first Y B) with appropriate signs. Each query becomes O(log N), total O(N log N + K log N).
