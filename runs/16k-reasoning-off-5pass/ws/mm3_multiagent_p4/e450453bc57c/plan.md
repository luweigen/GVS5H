We need to find the minimum number of +/-1 operations to create k non-overlapping subarrays of length x where each subarray is constant. This is a classic DP on intervals problem: precompute the cost of making any subarray of length x constant (the minimal operations = sum of |nums[i] - median|), then use DP[i][j] = minimum cost to make j disjoint subarrays within the first i elements. Since k ≤ 15 and n up to 1e5, we need O(n·k) DP after computing costs. We compute costs for all length-x windows using median trick (sliding window median with two heaps) in O(n log x). Then DP: dp[j] = min over valid start positions s of dp[s] + cost[s..s+x-1], with non-overlap enforced by only considering windows starting at positions s where s ≥ j*x (natural constraint). Since k is tiny, we can just do O(n·k) DP.
