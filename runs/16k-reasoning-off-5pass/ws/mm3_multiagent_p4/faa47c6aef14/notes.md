The solution works by analyzing the reverse process. The necessary condition for gathering all balls at X is that every initial red ball lies in the same P-cycle as X, and every initial blue ball lies in the same Q-cycle as X. If not, output -1. Otherwise, the minimum number of operations equals the number of distinct boxes (other than X) that lie on some path from an initial ball to X. For each color, these boxes form a contiguous segment of the cycle ending at X, whose length (excluding X) is the maximum distance from an initial ball of that color to X. The answer is the size of the union of these two segments. The algorithm computes distances from X in both cycles, determines the segments, and takes their union. The time complexity is O(N) and space O(N).
