We simulate the process by maintaining the set of prefix sums of refill times. At each step t, we compute the cumulative displacement pref[t]. To check if smoke exists at (R,C) after the wind at time t, we see if pref[t] - (R,C) equals the prefix sum of some previous refill time. This is equivalent to checking if the point (pref[t].r - R, pref[t].c - C) is in the set P of prefix sums of refill times up to t-1. We initialize P with (0,0) from the initial smoke. For each t, we first query P, then update P by adding pref[t] if it is not already present (which corresponds to a new refill). This yields an O(N) algorithm using a hash set.
