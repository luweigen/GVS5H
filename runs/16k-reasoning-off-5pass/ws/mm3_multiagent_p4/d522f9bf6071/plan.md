We need to choose up to 4 non-overlapping intervals maximizing total weight, and among optimal solutions return the lexicographically smallest index list (shorter preferred on ties). This is a classic “weighted interval scheduling with at most k intervals” problem. We sort intervals by end coordinate while keeping original indices. Let `n = len(intervals)`, and `K = 4`. Precompute for each interval i the index `p[i]` of the last interval (by sorted order) that ends strictly before `intervals[i][0]` (no boundary touching allowed). Then DP `dp[k][i]` = best (max weight, lexicographically smallest index list) using up to k intervals among first i intervals (1-indexed). We maintain DP as tuples `(weight, indices_list)` and use tuple comparison that naturally handles lexicographic order on indices and length. We backtrack from `(K, n)` to recover the chosen indices and return them sorted by original index.

To make DP efficient, `p[i]` can be built by scanning with a pointer over sorted-by-end intervals. Since tuple comparison with lists is linear, we optimize by storing index lists as Python lists and compare via custom function (weight first, then lexicographic by list). Complexity: O(K·n) with small K=4, well within limits for n up to 5e4.
