We need to construct the lexicographically smallest length-(n+m-1) string `word` such that for each `i` where `str1[i]=='T'`, the substring `word[i..i+m-1]` equals `str2`; where `str1[i]=='F'`, the substring must differ from `str2`. Positions that are not covered by any 'T' constraint can be any character (lexicographically we prefer `'a'`).

Approach: Determine the set of indices that are forced to specific characters by the 'T' constraints. For each 'T' at position `i`, for each offset `j` in `[0, m-1]`, set `word[i+j] = str2[j]`. If any forced character conflicts (two 'T's require different letters at the same index), return `""`. After processing all 'T's, attempt to fill all remaining unforced positions with `'a'`, but for each 'F' position `i` we must verify that the resulting window `word[i..i+m-1]` is not equal to `str2`. If it equals `str2`, we need to modify it minimally (lexicographically) to break equality while keeping all forced characters and any already-set `'a'` from other constraints. This is done greedily from left to right: scan the window for the first position where the current character is not forced and not equal to the required `str2[j]`, try to place the smallest character `'a'..'z'` that is ≤ current and still ≠ `str2[j]`; if none works, we cannot fix this 'F' and return `""`. If we succeed, we lock that character and restart the verification for all 'F's (at most O(n) restarts, total O(n·m) work, which is fine for n ≤ 10⁴, m ≤ 500).
