We need to minimize the sum of minimum possible maximum edge weights over a pairing between sets A and B. The function f(x,y) is the minimax path weight, which equals the minimum threshold T such that x and y become connected in the subgraph of edges with weight ≤ T. This is the classic minimax distance computable via a Minimum Spanning Tree (MST). Build the MST; on an MST, f(x,y) is exactly the maximum edge weight on the unique tree path. Then we have K up to 2e5 pairs to match. Sort A and B in non‑decreasing order of their f‑values to a common root, then pair them greedily by order. This greedy is optimal because all f-values are non‑negative and we are minimizing sum of pair sums with one‑to‑one matching; a simple exchange argument shows the optimal matching pairs sorted lists.
