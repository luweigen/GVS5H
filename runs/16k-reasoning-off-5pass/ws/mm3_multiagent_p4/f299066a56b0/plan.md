We need the maximum number of disjoint pairs (i, j) with i < j such that A[i] * 2 <= A[j]. Since the array is sorted ascending, a greedy two-pointer works: maintain a pointer `i` for the smaller mochi and `j` for the larger one. For each `j` from 0 to N-1, advance `i` while `i < j` and `A[i] * 2 <= A[j]` is not yet satisfied; once satisfied, we can pair `i` with `j`, increment the answer, and move `i` to the next index. If `i` reaches `j`, no pair can be formed for this `j`. This yields the maximum K in O(N) time and O(1) extra memory.
