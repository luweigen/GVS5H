
## ideation
The problem asks for the number of ways to rotate tiles (Type A: adjacent edges, Type B: opposite edges) on an H×W torus grid such that line segments form cycles with no dead ends (i.e., every cell has exactly two incident edges, and edges match across cell boundaries). This is equivalent to counting 2-factors in a graph where each cell offers a set of possible edges based on its type.

Key observations:
- The grid is a torus (periodic boundaries).
- The condition is local: each cell must have degree 2, and the two edges must be either adjacent (Type A) or opposite (Type B).
- The sum of HW over all test cases is ≤ 10^6, so an O(HW) or O(HW log something) algorithm is acceptable, but exponential in W is not.
- This is a constrained 2-factor counting problem on a planar graph (grid on torus). It can be solved using the Pfaffian method, but that is complex to implement.
- A transfer matrix approach is natural: state = vertical connections between rows (bitmask of size W). However, state size 2^W is too large for W up to 1000.
- Since the grid is bipartite and the constraints are local, there might be a way to reduce the problem to a determinant of a matrix of size H or W.
- I recall that counting 2-factors in a toroidal grid can be done by computing the permanent of a matrix, but that's #P-hard in general. However, for grids with specific local constraints, there might be a polynomial-time algorithm using the "transfer matrix" and the "determinant of a matrix" via the BEST theorem or the Matrix-Tree theorem.
