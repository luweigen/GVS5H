We need to find positive integers x>y with x³−y³=N. Since N ≤ 1e18, x is at most about N^(1/3)+1 ≈ 1e6+1. For each y from 1 upward, compute the corresponding x by taking the cubic root of y³+N (using integer rounding) and verify if x³−y³ exactly equals N. As soon as a valid (x,y) is found, output it. If no pair exists, print -1. The loop is cheap because the maximum y is around the same bound; the worst case is when N is a perfect cube minus 1 or similar, but still under ~1e6 iterations.
