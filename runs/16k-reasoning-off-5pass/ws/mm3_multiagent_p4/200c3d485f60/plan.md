We need to count arrays of length n with values in [1, m] such that exactly k adjacent equal pairs exist. Equivalently, we need to partition the n positions into `k+1` "blocks" of consecutive equal values, where adjacent blocks have different values. We first choose the positions where the value changes: there are `C(n-1, k)` ways to select which k of the n-1 gaps are "breaks" (non-equal). For the first block, we can pick any of m values. For each subsequent block (there are k of them), we must pick a value different from the previous block, giving (m-1) choices each. Multiplying yields `m * (m-1)^k * C(n-1, k)`. We compute `C(n-1, k)` modulo MOD = 1e9+7 using precomputed factorials and modular inverses. Overall complexity O(n) for factorials and O(1) for the final computation.
