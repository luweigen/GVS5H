
## ideation
The problem is a 1D reachability problem with small jump sizes (A..B ≤ 20) but huge N (≤1e12) and up to 2e4 bad intervals. The key insight is that within a contiguous safe zone, reachability is determined by the semigroup generated by [A,B]. Because the semigroup has a finite Frobenius number F (at most 341 for A,B≤20), all sufficiently large differences are representable. Thus, from an entry point p in a safe zone of length L, we can reach all positions in [p+F+1, R] provided R-p > F, and we only need to brute-force the first F positions. This allows efficient traversal of huge safe zones by skipping over the automatically reachable tail.

The algorithm:
1. Precompute representable differences using BFS up to a safe limit (e.g., 5000 > max possible F). Let `g = gcd(A,B)`. For d > limit, d is representable iff d % g == 0 (if g>1) or always (if g=1).
2. Define safe zones: before first bad, between bads, after last bad.
3. Maintain current safe zone and entry point. For each safe zone, compute the set of reachable positions. Since the zone can be huge, check reachability in the critical region near the right end (needed to jump to next zone) by using the fact that all positions beyond p+F are reachable.
4. To jump to next safe zone, need a reachable x such that L_next - B ≤ x ≤ R_next - A and x is in the current zone. If such x exists, choose a landing y in next zone and set new entry point to y. Otherwise, return No.
5. After processing all zones, check if N is reachable in the final safe zone.

Pitfalls: 
- Must handle 1 being bad (but constraints say L_i > 1, so 1 is always safe).
- Need to ensure the BFS limit is large enough to cover the actual Frobenius number; 5000 is safe.
- For g>1, positions not ≡ 1 (mod g) are unreachable from 1.
- Edge cases when safe zones are empty (bad intervals adjacent to 1 or N).
