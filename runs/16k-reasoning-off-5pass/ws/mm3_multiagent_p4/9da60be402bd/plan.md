We need, for every ordered pair (i, j), the length of the shortest walk whose edge-label string is a palindrome.  
Treat each vertex as a pair (v, k) where k indicates “direction” of the palindrome construction: 0 = building the left half forward, 1 = building the right half forward while matching the left half in reverse.  
A walk length L with palindrome string exists iff we can start at (i,0), end at (j,0) or (j,1) after L steps with equal character counts on both sides. This is equivalent to reachability in a product graph of size 2N where an edge from (u,0) to (v,1) is allowed only when the labels of the traversed forward edge and the reverse edge coincide, and we can always add paired “dummy” edges to align lengths.  
After building that 2N×2N adjacency, the answer for (i, j) is the smallest L such that (i,0) reaches (j,0) or (j,1) with the same “balance”. The balance is exactly the difference between how many forward‑side steps and reverse‑side steps we have taken. We can incorporate the balance into a BFS state (vertex in product graph + balance), but N ≤ 100 and alphabet size ≤ 26, so the state space is at most 2·N·(2N+1) ≈ 4·10⁴, still small.  
A simpler view: we only care about the difference d = #forward − #reverse edges used. When d = 0 the constructed string is a palindrome, and the final vertex must be (j,0) or (j,1). The forward half can be extended by any original edge, increasing |balance|; the reverse half can be added by traversing an original edge backward, decreasing |balance|. To keep |balance| bounded we cap the balance range to [−N, N] (excess larger than N can never be reduced in optimal paths because each step can change balance by at most 1).  
We run BFS over state (v, side, bal) where v∈[1..N], side∈{0,1}, bal∈[−N..N]. Transitions:  
• from (v,0): for each outgoing edge v→u with label c, we may start a new pair: move to (u,1) with bal unchanged (cost 2), or not pair it (move to (u,0) with bal+1, cost 1).  
• from (v,1): for each incoming edge u→v with label c, we may close a pair: move to (u,0) with bal unchanged (cost 2), or not close (move to (u,1) with bal−1, cost 1).  
When bal becomes 0 we are at a palindrome prefix; if the current vertex is the target j (with side 0 or 1) we record the answer. The BFS guarantees the first time we see (j,·,0) is the minimal length.  
Complexities: O(N²·alphabet + N·balance_range·E) ≤ O(N³) ≈ 10⁶, fine for N=100.
