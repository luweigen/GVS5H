
## ideation
The problem asks for the sum of the scores of all good sequences modulo 998244353. A good sequence \(S = (S_1, \dots, S_N)\) satisfies \(f(S_i/S_{i+1}) = A_i\) for all \(i\), and \(\gcd(S_1, \dots, S_N) = 1\), where \(f(P/Q) = P \times Q\) for coprime \(P, Q\).

Key observations:
1. The condition \(f(S_i/S_{i+1}) = A_i\) means that for each \(i\), we can write \(S_i/S_{i+1} = a_i/b_i\) where \(a_i b_i = A_i\) and \(\gcd(a_i, b_i) = 1\). Thus, \(S_{i+1} = S_i \cdot b_i/a_i\).
2. The sequence is determined by choosing a divisor \(a_i\) of \(A_i\) such that \(\gcd(a_i, A_i/a_i) = 1\), and then setting \(S_1\) to be the minimal positive integer making all \(S_i\) integers (the lcm of the denominators of the partial products). This minimal \(S_1\) always yields a sequence with \(\gcd = 1\).
3. The problem can be decomposed by prime factors. For each prime \(p\), let \(e_i = v_p(A_i)\). For each \(i\), we either put the full \(e_i\) into \(a_i\) (so \(S_{i+1} = S_i / p^{e_i}\)) or into \(b_i\) (so \(S_{i+1} = S_i \cdot p^{e_i}\)). This is equivalent to choosing a sign \(s_i \in \{+1, -1\}\) and setting \(S_{i+1} = S_i \cdot p^{s_i e_i}\).
4. Starting from some exponent \(v\) in \(S_1\), the exponent of \(p\) in \(S_i\) is \(v + d_{i-1}\), where \(d_0 = 0\) and \(d_k = \sum_{j=1}^k s_j e_j\). To ensure all exponents are non-negative and the minimum is 0, we must set \(v = -\min_{0 \le i \le N-1} d_i\). This is always possible, and every sign pattern yields a valid good sequence.
5. The total exponent of \(p\) in the score of the sequence is \(\sum_{i=1}^N (v + d_{i-1}) = Nv + \sum_{i=0}^{N-1} d_i\). Since choices for different primes are independent, the total sum of scores is the product over primes of the sum of \(p^{\text{exponent sum}}\) over all \(2^{N-1}\) sign patterns for that prime.
6. However, \(N\) can be up to 1000, so we cannot iterate over all \(2^{N-1}\) patterns. Instead, we can use dynamic programming. For each prime \(p\), we process the steps in order. The state can be the current value of \(d_i\) and the current minimum \(m_i = \min_{j \le i} d_j\). But the range of \(d_i\) can be large (up to the sum of all \(e_i\), which is at most \(N \log_p 1000\)). Since the total number of prime factors across all \(A_i\) is small (at most \(10000\)), we can afford a DP where the state is the current "height" above the minimum, i.e., \(h = d_i - m_i\). This \(h\) is always non-negative and bounded by the total sum of \(e_i\).
7. At each step \(i\) with size \(e = e_i\), we have two choices:
   - Take an upward step: \(d_{i+1} = d_i + e\). The new height \(h' = d_{i+1} - m_i = h + e\) (since \(m_i\) unchanged). The contribution to the exponent sum is \(N \cdot (-m_i) + \sum d_j\), but we can track the total sum of \(d_i\) separately.
   - Take a downward step: allowed only if \(h \ge e\). Then \(d_{i+1} = d_i - e\). If \(d_{i+1} \ge m_i\), then new minimum \(m_{i+1} = m_i\), and new height \(h' = h - e\). If \(d_{i+1} < m_i\), then new minimum \(m_{i+1} = d_{i+1}\), and new height \(h' = 0\). The total sum of \(d_i\) updates by adding \(d_{i+1}\).
