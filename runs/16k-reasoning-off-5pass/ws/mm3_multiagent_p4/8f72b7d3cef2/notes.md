We can compute the basin by a "flood fill" with a dynamic threshold. This can be done by a "priority queue" simulation for each K, but that's O(N^2 log N). To speed up, we can use a "divide and conquer" where we recursively solve for left and right halves, and then for the crossing, we simulate the expansion from the middle outward. Specifically, for a given interval [l,r] and a middle point m, we can compute the maximal expansion to the right for any starting point in [l,m] that expands into [m+1,r]. This can be done by a two-pointer expansion from the middle. But the expansion to the right depends on the sum from the left. However, if we know the "left sum" for each position in [l,m], we can compute the "right sum" by expanding. This is similar to the "two pointers" technique in some problems. Actually, the crossing expansion can be computed by a greedy that expands left and right from the middle. The time to compute the crossing for a given divide step is O(length of crossing). If we do a standard divide and conquer, the total time is O(N log N). This is acceptable for N=5e5.

Let's design the divide-and-conquer algorithm:
- We have an array A[1..N].
- We want to compute ans[1..N].
- The process: for a starting K, we expand left and right. The expansion is symmetric. We can think of the process as: we have a current sum S. We can absorb the smaller of the two available neighbors. This is a deterministic process that can be simulated with two pointers and a min-heap. But for the divide and conquer, we can compute the answer for all K by a recursive function that returns the answers for a segment, and also the "influence" of the segment on its neighbors? Not exactly.

Alternatively, we can compute for each K the "left limit" L[K] and "right limit" R[K] such that the final interval is [L[K], R[K]]. How to compute L[K]? L[K] is the smallest L such that starting from K, we can absorb everything in [L,K] and the sum of [L,K] is > A[L-1] (or L=1). But this condition is not sufficient because of internal blocks. However, if we consider the process of expanding left from K, we can absorb left if A[i] < current sum. This is like: we have a sequence to the left. We can take them in some order. The maximal left expansion is achieved by always taking the smallest available element. This is exactly the process of "taking the smaller side" when both sides are available. So the left expansion alone is not enough; we can interleave.
