The problem asks for the maximum height `h ≥ 0` at coordinate 0 from which at least one building is hidden. A building `i` is hidden if there exists a closer building `j` (X_j < X_i) such that the line of sight from (0, h) to (X_i, H_i) is blocked by (X_j, H_j). The blocking condition is `h < (H_j * X_i - X_j * H_i) / (X_i - X_j)`. Define `T(i, j) = (H_j * X_i - X_j * H_i) / (X_i - X_j)`. Building `i` is visible from height `h` iff `h > max_{j < i} T(i, j)`. The maximum height from which not all buildings are visible is the supremum of `h` such that there exists `i` with `h ≤ max_{j < i} T(i, j)`. This supremum is simply the maximum value of `T(i, j)` over all pairs `i > j`. If this maximum is negative, then for all `h ≥ 0`, all buildings are visible, so output `-1`. Otherwise, output that maximum.

To compute `max_{i > j} T(i, j)` efficiently, rewrite `T(i, j) = (H_i/X_i - H_j/X_j) / (-1/X_i + 1/X_j)`. Let `S_k = H_k / X_k` and `U_k = -1 / X_k`. Then `T(i, j) = (S_i - S_j) / (U_i - U_j)` with `U_i > U_j` (since X_i > X_j). This is the slope of the line connecting points `(U_k, S_k)` in the plane. The maximum such slope over all pairs is the maximum slope of the upper convex hull of these points (since the upper hull edges have decreasing slopes, and the maximum chord slope is an edge slope). We can compute the upper convex hull in O(N) time because the points are already sorted by increasing `U` (i.e., increasing X). While building the hull, we can also compute the maximum slope between consecutive hull vertices. If the maximum slope is negative, output `-1`; else output that maximum slope.
