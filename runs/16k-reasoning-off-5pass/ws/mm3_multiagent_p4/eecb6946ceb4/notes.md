
## ideation
The problem asks for the number of 3-term arithmetic progressions (fine triplets) within a set of distinct positive integers, where N and S_i can be up to 10^6. A naive O(N^2) check is too slow. The key insight is that the number of such triplets can be computed efficiently using convolution (FFT). By representing the set as a characteristic array, the convolution f * f gives the number of ordered pairs summing to each value. For each even sum s = 2B where B is the middle element, if B is in the set, the number of valid (A, C) pairs is (h[s] - 1) / 2 (subtracting the pair (B,B) and dividing by 2 for unordered pairs). The total answer is the sum over all such even s. Using numpy's FFT, this runs in O(M log M) time with M up to 2^20, which is efficient.

## worker: Implement the FFT-based solution in Python using n
The solution uses convolution (via FFT) to count 3-term arithmetic progressions efficiently. The characteristic array `f` is convolved with itself to get `h[s] = sum_{a} f[a] f[s-a]`, which counts ordered pairs summing to `s`. For each middle element `B` (where `s = 2B`), if `B` is in the set, the number of valid `(A, C)` pairs is `(h[s] - 1) // 2` (subtracting the `(B,B)` pair and dividing by 2 for unordered pairs). The FFT size is the next power of two ≥ `2*max_val`, which is at most `2^21` since `max_val ≤ 10^6`. NumPy's real FFT handles the convolution in O(M log M) time. The vectorized summation avoids Python loops. This approach handles the worst case (dense sets) in well under a second.
