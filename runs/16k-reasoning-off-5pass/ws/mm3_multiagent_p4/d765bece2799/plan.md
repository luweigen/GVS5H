We need to compute, for every subarray of length at most k, the sum of its minimum and maximum elements, then total these sums over all such subarrays. Directly enumerating all subarrays is O(n·k) and too slow for n up to 80,000. A standard technique is to use monotonic deques while sliding a window of size k. For each right endpoint r, we maintain deques that give the minimum and maximum of the current window [r-k+1, r]. As we slide the window, we can incrementally add the contribution of nums[r] as the new right endpoint: the number of subarrays ending at r with length ≤ k is min(r+1, k). For each such subarray, we need the current min and max, which we can read from the deques. Summing these values for every r yields the total sum. This runs in O(n) time and O(k) extra space, which is well within limits. Edge cases (k=1, negative numbers, large values) are handled naturally by the algorithm.
