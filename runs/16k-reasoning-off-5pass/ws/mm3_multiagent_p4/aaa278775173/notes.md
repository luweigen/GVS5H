The problem asks for the longest V-shaped diagonal segment in a 2D grid with values {0,1,2}. A V-shaped segment:
- Starts at a cell with value 1.
- Follows the alternating pattern 2,0,2,0,... in a fixed diagonal direction.
- Can optionally make exactly one clockwise 90° turn to another diagonal direction, continuing the same alternating pattern.
- The turn can happen at any point along the path (after at least one step), and the path must stay inside the grid.

This is essentially a longest path problem in a directed graph where nodes are cells and edges go along diagonals following the alternating pattern. Because we can turn at most once, we can split the path into two straight diagonal segments (the second may be empty if no turn). A natural approach:
