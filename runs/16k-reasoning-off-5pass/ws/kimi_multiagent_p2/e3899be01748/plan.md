For each ending position j, count how many starting positions i make the substring s[i..j] divisible by its last digit d = s[j]. If d == '0', no substring ending at j qualifies. Otherwise, we need the number formed by s[i..j] mod d == 0. Since d ∈ {1..9}, we can maintain the remainder of the suffix ending at j for each possible divisor d as we extend leftwards — but doing this per position is O(9n) total if we iterate over all 9 divisors at each step. Actually, a cleaner approach: iterate j from left to right, and for each j, extend i backwards while tracking the value mod d incrementally — that's O(n²) worst case. Instead, note that for a fixed j with last digit d, the substring value mod d can be computed as we move i leftward: rem = (digit_i * pow10 + rem) % d. The key insight is that pow10 mod d cycles, but we still need to check all i for each j. The efficient approach: for each j, we only need remainders mod d where d = s[j]; process each j independently by scanning i from j down to 0, accumulating rem = (int(s[i]) * p + rem) % d where p = (p * 10) % d... this is still O(n²) in the worst case (e.g., all '1's gives n + (n-1) + ... = O(n²)). However, since d ≤ 9, we can instead fix the divisor d (9 values) and for each d, scan the string maintaining a running prefix mod d; then substrings ending at j with last digit d are counted by how many prefix positions i ≤ j have prefix_mod[i] == prefix_mod[j+1] (since substring value = prefix[j+1] - prefix[i]*10^{...} — careful with the power).
