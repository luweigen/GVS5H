This is a weighted interval scheduling variant with at most 4 intervals, requiring both maximum total weight and lexicographically smallest index list among ties. Sort intervals by right endpoint (tie-break by index for determinism) and compute, for each interval, the latest previous interval ending strictly before its start via binary search. Run a DP over sorted intervals with states k=0..4, where each state stores the best (max weight, then lexicographically smallest index list) achievable using intervals up to position i. Transitions are: skip current interval, or take it (append its original index to the best list from state k-1 at the binary-search position). Since k ≤ 4, storing actual index lists in DP states is cheap (lists of length ≤ 4), and lexicographic comparison of lists directly implements the tie-break rule. The answer is the best among states k=1..4 at the final position (note: fewer intervals may win ties only if weights are equal, so compare all k).
