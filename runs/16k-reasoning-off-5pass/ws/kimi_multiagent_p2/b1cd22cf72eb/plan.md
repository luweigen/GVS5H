We need to find the minimum cost to adjust teeth lengths $(U_i, D_i)$ to $(u_i, d_i)$ such that $u_i \le U_i$, $d_i \le D_i$, $u_i + d_i = H$ for some constant $H$, and $|u_i - u_{i+1}| \le X$. The cost is $\sum (U_i - u_i) + (D_i - d_i) = \sum (U_i + D_i) - N \cdot H$. To minimize cost, we must maximize $H$. For a fixed $H$, the constraints on $u_i$ are $\max(0, H - D_i) \le u_i \le \min(U_i, H)$ and $|u_i - u_{i+1}| \le X$. We can check the feasibility of these constraints in $O(N)$ time using a standard interval propagation technique (forward and backward passes). Since the feasibility is monotonic with respect to $H$ (if $H$ is feasible, any $H' < H$ is also feasible), we can binary search for the maximum feasible $H$.
