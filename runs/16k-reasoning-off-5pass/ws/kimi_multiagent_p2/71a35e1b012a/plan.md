Model each operation as a Boolean variable: choosing op1 sets interval [L,R] to 1, op2 sets its complement to 1, op0 does nothing. A position j ends as 1 iff at least one chosen operation covers j, where op i covers j iff (choice==1 and L_i≤j≤R_i) or (choice==2 and j outside). This is a covering problem: select a minimum-cost set of "sets" (each operation offers two possible sets: interval or complement) to cover all N positions. Key insight: complements cover everything except an interval, so using op2 on i and op1 on j covers all positions iff [L_i,R_i] ∩ outside... analyze structure: coverage by complements leaves only intersection of excluded intervals uncovered. Reduce to checking small cases: 0 ops (only if N=0, impossible), 1 op (need full range), 2 ops (interval+complement overlapping appropriately, or two complements whose excluded intervals' intersection is empty, or two intervals covering [1,N]). Minimum cost is at most 2 if achievable with ≥2 ops... actually answer is min over: single full-cover op, or a pair whose union covers everything; also possibly more ops needed (e.g., sample 3 uses two op1s).
