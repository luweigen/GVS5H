Model the problem as a directed graph on the 26 letters: for each position i, S[i] must eventually map to T[i], so add edge S[i]→T[i]; if any letter has two different required targets, answer is -1. Each operation renames one letter globally, so a letter with a self-loop only (S[i]==T[i] everywhere) needs no operation, while a letter whose required image differs needs at least one operation unless its target is "donated" through a chain. Chains a→b→c→... that end at a letter with no outgoing edge can be resolved in (length) operations by processing from the end, contributing edges count. A pure cycle needs edges+1 operations (one temporary rename), but if any cycle letter is also reachable as a target from outside the cycle (in-degree from a non-cycle node), the cycle can be broken using that external letter as buffer, costing just edges. Compute total as sum over weakly connected components of the functional graph: edges + (1 if component is a pure cycle with no external incoming edge else 0), skipping trivial self-loop-only components.
