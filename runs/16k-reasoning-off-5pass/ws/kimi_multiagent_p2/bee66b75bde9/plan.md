Model the grid as a Ferrers/Young-diagram shape: black cells form a top-left justified monotone region, equivalently a boundary path from (0,N) to (N,0) using only down/right steps, with black cells above-left of the path. Each fixed cell imposes an inequality on the path: a black cell (x,y) forces the path to pass weakly above-right of it, and a white cell forces it weakly below-left. These constraints translate into lower/upper bounds on the boundary height over column intervals, and feasibility reduces to checking consistency of a monotone integer function. We can process only the M given points by sorting and maintaining feasible ranges for the boundary.
