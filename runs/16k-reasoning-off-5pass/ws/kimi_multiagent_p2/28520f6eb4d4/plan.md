Model the observer at (0, h). Building i is visible iff some point on its segment [0, H_i] at x=X_i is not blocked by any building j with X_j < X_i; since buildings are vertical segments, the sight line from (0,h) to (X_i, y) passes over building j iff y/X_i ≥ H_j/X_j (line at X_j has height h + (y−h)·X_j/X_i ≥ H_j). The key insight: define for each building the "critical slope" — building i is visible from height h iff the ray from (0,h) tangent over all previous buildings can reach some point of building i, i.e., iff max over j<i of the line from (0,h) clearing (X_j,H_j) hits X_i at height ≤ H_i. The clearing height at X_i is h + (H_j − h)·X_i/X_j, which is linear in h; building i is blocked iff for all j<i, h + (H_j−h)X_i/X_j > H_i, i.e., the max over j of that linear function exceeds H_i. So define f_i(h) = max_{j<i} [H_j·X_i/X_j + h·(1 − X_i/X_j)]; building i invisible iff f_i(h) > H_i. Each term is linear in h with slope (1 − X_i/X_j) which is negative for X_j < X_i, so f_i is a decreasing convex (max of lines) function of h; the threshold where building i becomes visible is where f_i(h) = H_i. The answer is the maximum h such that some building is invisible = max over i of the h where f_i(h) = H_i (clamped at ≥0), because visibility is monotone: once visible at h, visible at all higher h (f_i decreasing). Compute for each i the upper envelope of lines from previous buildings evaluated as function of h, find crossing with H_i. Since slopes 1−X_i/X_j increase as X_j increases, the relevant max at the crossing comes from maintaining a convex hull trick over j: each j gives line L_j(h) = H_j·X_i/X_j + h(1−X_i/X_j) — but coefficients depend on X_i, so instead process buildings left to right maintaining a hull of "blocker" lines parameterized differently: for fixed i, value = X_i·max_j(H_j/X_j − h/X_j) + h. So define g_i(h) = max_{j<i} (H_j − h)/X_j; building i blocked iff X_i·g_i(h) + h > H_i. Maintain upper hull of lines in variable h: each j contributes line (H_j − h)/X_j = H_j/X_j − h/X_j, all with negative slopes −1/X_j, slopes increasing (less negative) as X_j grows. Query max at h, find h where X_i·g(h)+h = H_i via binary search on the hull or by walking. Then answer = max over i of threshold h_i (if threshold ≤ 0, building visible at h=0; if all visible at 0, answer −1; if max threshold is exactly 0, answer 0).
