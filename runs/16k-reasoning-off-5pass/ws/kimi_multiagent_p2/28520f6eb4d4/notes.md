**Core model.** Observer at (0, h). Building i (at X_i, height H_i) is blocked iff every ray from (0,h) to a point (X_i, y), 0 ≤ y ≤ H_i, passes through some earlier building j (X_j < X_i). The ray to (X_i, y) has height at X_j equal to h + (y−h)·X_j/X_i; it clears building j iff this is > H_j. The hardest ray to block is the one to the top y = H_i, so building i is **visible iff** max over j<i of [h + (H_i − h)·X_j/X_i] > H_j... equivalently, define for each earlier building j the line in h:

L_j(h) = (H_j − h)/X_j = H_j/X_j − h/X_j.

Building i is blocked iff X_i · max_{j<i} L_j(h) + h > H_i, i.e. iff h·(1 − X_i·(1/X_j)) ... — the clean form: blocked iff max_{j<i} [H_j·X_i/X_j + h·(1 − X_i/X_j)] > H_i.

**Monotonicity.** Each term has slope (1 − X_i/X_j) < 0 in h, so the max is decreasing in h.
