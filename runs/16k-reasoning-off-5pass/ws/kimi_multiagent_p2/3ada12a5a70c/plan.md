The key insight is that all points lie on the boundary of the square, so we can parameterize each point by its 1D position along the perimeter (0 to 4*side). The Manhattan distance between two boundary points equals the minimum of their perimeter distance and 4*side minus that perimeter distance (since going "around the corner" via the perimeter gives the Manhattan distance). This transforms the problem into: given points on a circle of circumference 4*side, select k points to maximize the minimum circular distance between any two selected points. This is a classic binary search on the answer combined with a greedy check: for a candidate minimum distance d, we check if we can place k points on the circle such that consecutive points (in circular order) are at least d apart. The greedy check tries each point as a starting point and greedily picks the next point at distance >= d along the circle, verifying we can get k points within one full loop.
