Model the state as (cell, floor). Stairs cost 1 per floor within a cell; walkways cost 0 and connect equal floors between adjacent cells. The key observation: walkways at floor x are only usable between adjacent cells whose F ≥ x, so at "level x" the usable cells form a connected region of the grid thresholded by F ≥ x. Within a connected region, you can move freely at any floor ≤ min F along the region, so the optimal strategy is: from start, climb/descend to some floor x, travel through the region where F ≥ x, then adjust to the target floor. The answer for a query is min over x of |Y−x| + |Z−x| where x must allow start and target cells to be in the same connected component of {cells with F ≥ x}. This reduces to: maximize the bottleneck (minimum F) on the path between the two cells — the classic widest-path (maximin) problem. If the maximin value between cells s and t is B(s,t), then feasible x ranges over [max(Y,Z)... ] — actually x must satisfy x ≤ B(s,t) and we minimize |Y−x|+|Z−x|, giving answer = max(0, needed) = distance from the interval: if x can be chosen between Y and Z the cost is |Y−Z|; otherwise cost = |Y−Z| + 2·(gap). Compute widest paths via a maximum spanning tree (Kruskal on grid edges, weight = min(F_u, F_v)); then each query is answered by finding the minimum edge on the path in the max-spanning tree using binary lifting with LCA in O(log N).
