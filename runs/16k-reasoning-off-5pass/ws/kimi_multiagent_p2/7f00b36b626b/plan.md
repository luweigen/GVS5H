The key observation is that lcm(a,b) <= threshold implies both a,b <= threshold, so any value greater than threshold is an isolated node. For values <= threshold, instead of checking O(n^2) pairs, we connect numbers through shared divisors: for each divisor d, all multiples of d present in the array can be unioned via lcm checks, but more efficiently we can union each value with its smallest present multiple relationships. A cleaner approach: build a DSU over values 1..threshold; for each d from 1..threshold, iterate over multiples m = d, 2d, 3d... <= threshold, and if both d (or a representative multiple) and m exist in nums, union them when lcm(d, m) = m <= threshold — actually union every present multiple m of d with the first present multiple of d, since lcm of two multiples of d could exceed threshold, so we must verify lcm directly. The safe efficient method: for each value v present (v <= threshold), iterate over its multiples m = v, 2v, ... <= threshold that are present, and union(v, m) since lcm(v, m) = m <= threshold. This connects all pairs where one divides the other; but edges exist between non-divisible pairs too (e.g., 4 and 6, lcm 12). To capture those, for each d, collect present multiples of d and union pairs whose lcm <= threshold — union each present multiple m with the smallest present multiple s of d only if lcm(s, m) <= threshold; this is sufficient because connectivity through d only needs a spanning structure, and lcm(s,m) <= lcm of any pair... not always.
