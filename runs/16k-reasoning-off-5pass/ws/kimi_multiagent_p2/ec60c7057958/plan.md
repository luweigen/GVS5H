An alternating permutation requires adjacent elements to differ in parity, so the parity pattern is fully determined by the first element's parity. Since n ≤ 100, the counts of odds (⌈n/2⌉) and evens (⌊n/2⌋) must differ by at most 1 for any valid permutation to exist; if they differ by 2 or more (impossible here since they differ by at most 1 always), but when n is even both starting parities are possible, and when n is odd only starting with odd works. We build the k-th permutation greedily position by position: at each step, try the smallest available candidate of the required parity, count how many valid completions exist using combinatorics (multiplying factorials of remaining odd/even counts, times 2 if both parities remain possible for the next free choice), and skip blocks until k falls within a candidate's block. Factorials must be capped above 10^15 to avoid overflow since k ≤ 10^15. If the total count is less than k, return [].
