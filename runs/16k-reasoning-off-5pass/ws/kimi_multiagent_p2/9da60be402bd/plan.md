We need shortest palindrome-labeled walks between all pairs. Model states as pairs (u, v) representing the two ends of a partially built palindrome; from (u, v) we can extend by edges u->u' labeled c and v'->v labeled c, moving to (u', v') with cost +2. Answers for even-length palindromes are distances from diagonal states (x, x); odd-length answers come from states (u, v) with an edge u->v (cost +1). Run a multi-source 0-1-2 style BFS (Dijkstra with weights 1/2) over the N^2 states, starting with distance 0 at all (x, x) and distance 1 at all (u, v) where an edge u->v exists. Then A[i][j] = dist[(i, j)], with -1 if unreached. Complexity is manageable: N^2 states (≤10^4), each with up to 26·N transitions, fine for N ≤ 100 if we precompute edges grouped by label.
