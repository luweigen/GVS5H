Core difficulty: The game has two intertwined resources — each index must be "discovered" exactly once (N discovery moves total, game ends on the Nth), and each index i also provides A_i - 1 "pass" moves (decrements after discovery) that players can use to burn turns and flip parity. Both players play optimally, so we need to determine who controls the parity of the move on which the last discovery happens.

Key structural observations:
- The game always ends exactly when the Nth distinct index is chosen. Total moves = N + (number of pass moves used before that moment). Passes are optional but constrained: you can only pass on already-discovered indices, and index i gives at most A_i - 1 passes.
- This is a partisan-free parity game: think of it as players alternately either (a) discover a new index, or (b) pass on a discovered one. The player who makes the Nth discovery wins.
- Equivalent reformulation: there are N "discovery tokens" (one per index) and E = sum(A_i - 1) "pass tokens", but pass tokens for index i only unlock after index i is discovered. The game ends immediately when the last discovery token is taken.
