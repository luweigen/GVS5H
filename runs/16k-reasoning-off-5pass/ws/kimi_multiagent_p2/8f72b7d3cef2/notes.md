
## ideation
The problem: for each starting index K, Takahashi repeatedly absorbs an adjacent slime strictly smaller than his current size; absorbed slimes vanish and gaps close. Find max final size.

Key observations:
- Absorbing only increases his size, so absorbing whenever possible is never harmful. The reachable set is uniquely determined: it's the maximal contiguous segment containing K such that, starting from sum S = A_K over [L,R]=[K,K], we can repeatedly extend to include A[L-1] if A[L-1] < S (then S += A[L-1], L decreases), or A[R+1] if A[R+1] < S. The final segment is a fixed point of this expansion. Greedy order doesn't matter because absorbing never blocks future absorptions (size only grows, and the segment stays contiguous).
- Naive per-K simulation is O(N) each → O(N²), too slow for N=5e5.

Core difficulty: computing this "expansion closure" for all N starting points in near-linear time.

Candidate approaches:
