We need to determine if the edit distance (Levenshtein distance) between S and T is at most K, where K ≤ 20. Since K is small, we can use a banded dynamic programming approach that only computes edit distances up to K, giving O(K * max(N,M)) time complexity. If the length difference exceeds K, we can immediately answer No. Otherwise, we compute the edit distance using DP with early termination when all values in a row exceed K.
