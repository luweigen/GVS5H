For each permutation, f(P) is the concatenation of the decimal strings of the numbers in order. The contribution of a value v placed at position i equals v times 10^{total length of all elements after position i}. Group numbers by digit length d; within a group all elements have identical length, so the suffix-length weight depends only on how many elements of each length follow. Sum over all permutations by fixing v's position and counting arrangements of the remaining elements by length groups, using factorials and prefix sums of powers of 10. Everything is done modulo 998244353 in O(N log MOD) or O(N) time.
