Model the state as (vertex, parity) where parity is 0 if edges are in original orientation and 1 if reversed. From (v, p), moving along an edge costs 1: use original adjacency when p=0 and reversed adjacency when p=1. Reversing all edges costs X and takes (v, p) to (v, 1-p). Run Dijkstra (0-1 weights won't work since X can be large, so use a heap) over these 2N states from (1, 0) and report the distance to min over both parities at vertex N. Complexity is O((N + M) log N).
