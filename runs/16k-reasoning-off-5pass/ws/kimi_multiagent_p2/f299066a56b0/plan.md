We need the maximum number of pairs (top, bottom) with top ≤ bottom/2, each mochi used at most once. Since the array is sorted ascending, an optimal strategy is to use the smallest mochi as tops and the largest as bottoms. A greedy two-pointer approach works: try to match the smallest available top with the smallest available bottom that is at least twice the top. However, we must ensure enough mochi remain for bottoms, so a cleaner formulation is: for a candidate K, check if A[i] * 2 ≤ A[N-K+i] for all i in [0, K) — pairing the K smallest with the K largest. This check is monotone in K, so binary search K in [0, N/2] with an O(K) check, giving O(N log N) total. Alternatively a single greedy pass splitting the array into two halves achieves O(N); binary search is simpler and fast enough for N ≤ 5×5.
