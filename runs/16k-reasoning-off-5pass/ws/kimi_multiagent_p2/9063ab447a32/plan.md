Binary search the answer X (total units). For a fixed X, the minimum cost to buy X units is achieved by greedily taking the cheapest "next unit" across all products: buying the k-th unit of product i costs (2k-1)*P_i. Equivalently, for each product compute how many units k_i it contributes when we buy the X cheapest marginal units — this can be done by finding a threshold T on marginal cost: each product contributes k_i = number of k with (2k-1)*P_i <= T, i.e., k_i = min over formula floor((T/P_i + 1)/2). Binary search on T to make sum k_i >= X, then compute exact minimal cost = sum k_i^2 P_i minus refund for units above threshold, and compare with M. All arithmetic uses integers with early capping to avoid huge numbers (Python big ints are fine anyway).
