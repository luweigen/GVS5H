Model the array as a sequence of runs: choose which k of the n-1 adjacent positions are "equal" boundaries, which forces the remaining n-1-k boundaries to be "different". Once boundaries are fixed, the first element has m choices and each "different" boundary multiplies by (m-1), giving the closed form C(n-1, k) * m * (m-1)^(n-1-k) mod (1e9+7). Since n, m ≤ 1e5, precompute factorials and inverse factorials up to n-1 for O(1) binomial queries, and use fast modular exponentiation. Handle edge cases: k=0 with m=1 yields 0 automatically since (m-1)^(n-1) = 0 when n>1; also n=1 gives m arrays (k must be 0).
