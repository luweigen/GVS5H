We can replace -1s with arbitrary non-negative integers and permute A freely, so the question reduces to: can we choose a common sum S and assign each fixed A-value to a position such that every position's requirement is met. For positions where B_j is fixed, A assigned there must equal S - B_j ≥ 0; positions with B_j = -1 can accept any A (set B_j = S - A). Since A can be permuted, we need a matching between fixed A-values and fixed-B slots with A ≤ S - B, with leftover A's (including filled -1s, which can be any value) going to free slots. The key insight: filled A values are flexible, so feasibility for a given S is: sort fixed A's ascending, sort required values (S - B_j for fixed B_j) ascending, and check each fixed A can cover a requirement (a_i ≤ r_i in sorted order), with the count of fixed A's not exceeding fixed B's... actually extra fixed A's need free B slots. Candidate S values are A_i + B_j over fixed pairs; binary search or sweep over candidates and verify greedily.
