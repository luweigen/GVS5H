Model each row as a W-bit mask. Row flips (X) and column flips (Y) commute, so the final grid is determined by a row-flip vector r and a column-flip vector c, with final cell = A[i][j] XOR r[i] XOR c[j]. Since W ≤ 18, enumerate all 2^W column-flip patterns c; for each, every row independently chooses r[i] ∈ {0,1} to minimize its popcount, i.e. contributes min(popcount(m XOR c), W − popcount(m XOR c)). Many rows repeat, so count frequencies of the 2^W masks first (H up to 2e5), then for each c sum over distinct masks using precomputed popcounts. Total cost is O(4^W) naively, which is too big (2^36), so use a fast Walsh-Hadamard / subset-sum style optimization: define f[m] = freq[m], and we need sum over m of freq[m] * min(popcount(m XOR c), W - ...). Instead, note min(p, W-p) can be handled by iterating c over all patterns and using precomputed g[c] = sum_m freq[m] * popcount(m XOR c) via FWT in O(W * 2^W), then answer per c is derived by choosing per-row min — but min is per row, not global, so we must compute h[c] = sum_m freq[m] * min(popcount(m XOR c), W - popcount(m XOR c)). Compute this directly: distinct masks ≤ 2^18 = 262144, times 2^18 patterns = 2^36 — too slow. Better: for each c, min(p, W-p) where p = popcount(m XOR c); group by convolution over popcount using FWT per bit-count is complex; simplest correct approach: iterate over distinct masks m, and for each m add freq[m] * min(popcount(t), W - popcount(t)) to h[m XOR t]... still 4^W. Acceptable alternative: since W ≤ 18, 2^W = 262144, and distinct masks D ≤ 262144, D * 2^W worst case 6.8e10 — infeasible. Use meet-in-the-middle: split W into W1+W2, precompute for each half, then h[c] = sum over m freq[m] * min over... min of sum isn't separable. Reconsider: actually we can just enumerate c (2^W) and for each c iterate distinct masks with early vectorization via numpy: represent distinct masks as array, for each c compute popcount via lookup table on (masks XOR c) using byte-level popcount — 2^18 * D operations in numpy is 262144 * 262144 too big even vectorized. Key insight: number of distinct masks D ≤ min(H, 2^W); if D is small it's fine, worst case D = 2^18. Use FWT to compute, for each c, the distribution of popcounts: define FWT of freq; popcount(m XOR c) = sum over bits; we need sum of min(p, W-p) weighted — compute arrays cnt_c[k] = sum of freq[m] with popcount(m XOR c) = k via Walsh-Hadamard per bit combined with generating functions: polynomial P_c(y) where coefficient of y^k is count; this equals product structure computable via FWT with polynomials of degree W — O(W^2 * 2^W) ≈ 18*18*262144 ≈ 8.5e7, feasible in numpy. Then h[c] = sum_k cnt_c[k] * min(k, W-k), answer = min over c.
