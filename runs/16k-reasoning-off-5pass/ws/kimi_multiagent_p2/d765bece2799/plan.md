We need the sum of (min + max) over all subarrays of length ≤ k, which splits into sum of maximums plus sum of minimums over those subarrays. Use the classic monotonic-stack "sum of subarray minimums/maximums" contribution technique, but cap each element's contribution window at distance k on both sides. For each element as the minimum (or maximum), its contribution is nums[i] × (number of valid left starts) × (number of valid right ends), where left/right spans are clamped so subarray length ≤ k. Handle ties with strict/non-strict comparisons to avoid double counting. Total complexity O(n).
