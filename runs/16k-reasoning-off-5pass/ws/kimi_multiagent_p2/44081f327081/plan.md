For each index i, the answer is the maximum divisor d of A_i such that at least K elements of A are multiples of d (choosing A_i plus K-1 other multiples of d). So we compute cnt[d] = number of array elements divisible by d for all d up to max(A) via a sieve-style accumulation over value frequencies. Then for each A_i we need the largest d dividing A_i with cnt[d] >= K; computing this per element by enumerating divisors is too slow for N=1.2e6, so instead we precompute best[v] = max divisor d of v with cnt[d] >= K for every value v up to max(A), by iterating d descending and marking multiples. The answer for index i is best[A_i]. Total complexity is O(M log M) where M = max(A) ≤ 1e6, which is fast enough.
