Build a trie over all words, storing at each node the count of words passing through it; the answer for a full array would be the deepest node with count >= k. For each index i, removing words[i] decrements counts along its root-to-node path, so answer[i] is the maximum depth d such that some trie node at depth d has count >= k, excluding contributions that depend on word i. Precompute for each depth the top two counts among trie nodes (and which node achieved the max), then for each word walk its path: for each depth, if the best node at that depth lies on this word's path its effective count drops by 1 (use second-best or best-1 accordingly), and track the deepest depth still having effective count >= k. Total work is O(sum of word lengths) since the total characters are bounded by 1e5.
