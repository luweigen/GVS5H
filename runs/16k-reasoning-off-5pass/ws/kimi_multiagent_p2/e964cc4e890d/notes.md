- Correct model: the original edges give all forward reachability `i -> i+1 -> ... -> j` for `i<j`. Therefore an added edge `w -> b` with `w < b` is redundant: the path already goes from `w` to `b`. Only added edges with `b < w` can create new reachability from right to left.
- Cut-cover criterion: for every gap `k` (`1 <= k < 2N`, between vertices `k` and `k+1`), there must be at least one matched pair black `b <= k` to white `w > k`. Proof:
  - Necessity: if no pair has `b <= k < w`, then every edge crossing the cut `{1..k} | {k+1..2N}` goes left-to-right (original path edges, plus redundant added edges with white left and black right). No vertex on the right can reach any vertex on the left, so the graph is not strongly connected.
  - Sufficiency: suppose every gap has such a backward pair. To go from any `j` to any `i < j`, set `cur = j`. While `cur > i`, consider gap `cur-1`. By assumption there is a matched pair `b <= cur-1 < w`. Since `w >= cur`, vertex `cur` can reach `w` by forward path edges, then take `w -> b` with `b <= cur-1`, strictly decreasing the current vertex. Repeat until `cur <= i`, then go forward to `i`. Thus every `j` reaches every smaller `i`; forward edges give reachability to larger vertices, so the graph is strongly connected.
