Santa's path is a sequence of axis-aligned segments. A house is visited iff it lies on any segment: for a horizontal segment at height y spanning x∈[a,b], all houses with that y and x in range; similarly for vertical segments. Group houses by x-coordinate and by y-coordinate into hash maps of sorted lists, then for each move binary-search the appropriate group to count houses within the covered interval, accumulating into a visited set to deduplicate. Total work is O((N+M) log N). Track the running position with Python integers (no overflow concern), and output final position plus the size of the visited set.
