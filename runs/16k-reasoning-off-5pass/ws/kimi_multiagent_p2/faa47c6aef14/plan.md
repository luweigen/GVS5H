Model each ball as a token that must be routed to box X. Operating on box i sends all red balls currently in i along the red permutation P (one step) and all blue balls along Q. Since P and Q are permutations, each color forms cycles; a ball starting at box v can reach X iff X is in v's cycle for that color, and the set of boxes that must be operated on is exactly the path from v to X along the cycle (excluding X). The answer is the size of the union of these required operation boxes over all balls; if any ball cannot reach X (X not in its color-cycle), answer is -1. Compute, per color, each node's distance to X within its cycle (or mark unreachable), then sum over boxes the max requirement (a box must be operated if any ball's path includes it) — equivalently count distinct boxes that lie on some ball's path to X.
