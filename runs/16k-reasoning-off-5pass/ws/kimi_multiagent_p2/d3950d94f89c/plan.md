Root the tree at 0 and run a DFS that maintains the current root-to-node path: for each value, track the deepest (largest depth index) node on the current path having that value. When entering a node, the nearest ancestor with the same value bounds the start of a valid downward path, so the current special path extends from just below that deepest duplicate to the current node; compute its length via prefix sums of edge weights and update the best (max length, then min node count). Use a sliding-window style stack per value (or a dict mapping value to last depth index) so updates are O(1) amortized, and undo changes on backtrack. Track answer as a pair (maxLength, minNodes) with lexicographic comparison on (length, -nodes). Overall complexity is O(n).
