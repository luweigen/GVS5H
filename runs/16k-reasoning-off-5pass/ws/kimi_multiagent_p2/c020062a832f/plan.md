For a fixed k, B_i = (A_i + k) mod M, which is a cyclic rotation of the value axis: values v ≥ M-k become v+k-M (small), values v < M-k become v+k (large). So relative to k=0, exactly the pairs where one element crosses the wrap boundary and the other doesn't flip their comparison. Define f(k) = inversion count for shift k; compute f(0) with a BIT over values, then derive the delta f(k+1)-f(k) by counting, for each pair, whether exactly one of A_i, A_j equals the wrapping threshold value M-1-k. The delta decomposes into a term depending only on the count of elements equal to x = M-1-k (which flips all pairs involving value x) plus a global constant from pairs where both equal x. This gives an O(1) transition per k after O(N log M) preprocessing, total O(N log M + M).
