Binary search the answer L (minimum achievable longest run length). For a candidate L, compute the minimum flips needed so no run exceeds L. Key insight: for L >= 2, each maximal run of length len needs floor(len/(L+1)) flips (place flips to break the run into pieces of size <= L), and these choices never conflict across runs, so summing over runs gives the optimal flip count. For L = 1, the string must alternate; compare against the two alternating patterns and take the minimum mismatches. Feasibility check is O(n), binary search over [1, n] gives O(n log n), well within n <= 1000.
