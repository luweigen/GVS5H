We need sum over all subarrays of (subarray sum)^K with K ≤ 10. Expand (S_r - S_{l-1})^K via binomial theorem: the total answer becomes a double sum over prefix indices j < i of (S_i - S_j)^K = Σ_t C(K,t) S_i^{K-t} (-S_j)^t. For each t, we need Σ_{j<i} S_i^{K-t} (-S_j)^t, which is maintainable online: keep running aggregates G_t = Σ_{j<i} (-S_j)^t for t = 0..K, then answer accumulates Σ_t C(K,t) S_i^{K-t} G_t. All work is mod 998244353, O(N·K) time and O(K) memory. Powers of each prefix sum up to K are computed per step (O(K) each, fine since K ≤ 10).
