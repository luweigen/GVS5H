For a fixed subarray, the minimum increments to make it non-decreasing is sum over i of max(0, running_max_so_far - nums[i]), i.e., we only raise elements to match the prefix maximum. We need to count subarrays whose cost ≤ k. Since extending a subarray only increases cost, for each left endpoint the valid right endpoints form a prefix — suggesting sliding window / two pointers. The challenge is maintaining the cost dynamically as the window changes; this can be done with a monotonic stack storing "levels" so that adding/removing elements updates cost in amortized O(1). Overall target: O(n) or O(n log n).
