We model the joint state as a pair (a, b) where a is A's vertex and b is B's vertex, with a != b. From state (a,b) we can move A to any neighbor a' != b, or move B to any neighbor b' != a. The goal is to reach (T, S). We perform BFS over the state space (size O(N^2)) but prune by only generating valid states (a != b). Since N ≤ 2e5, a full N^2 BFS is too large, but we can use a BFS on a graph of size N(N-1) using a hash set for visited and a queue; with M up to 2e5, total transitions are O(N * degree) which is manageable. We stop when we reach (T,S) and output distance, else -1.
