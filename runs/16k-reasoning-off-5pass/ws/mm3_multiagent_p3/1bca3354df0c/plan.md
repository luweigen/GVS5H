The initial graph is bipartite (no odd cycle). Adding an edge without creating an odd cycle is exactly adding an edge between vertices of the same color in the unique bipartition — such edges are between vertices in the same part. Each connected component is a tree or has chords only inside parts. After all allowable moves, each component becomes a complete graph on each part (two cliques). For a component with parts of sizes `a` and `b`, available moves = `a*(a-1)/2 + b*(b-1)/2` (edges already present subtract out). This is a normal-play impartial game; each component is independent, so we XOR the Grundy values (just the move counts, since each move is a singleton option). The first player (Aoki) wins iff the XOR of these counts over components is non-zero.
