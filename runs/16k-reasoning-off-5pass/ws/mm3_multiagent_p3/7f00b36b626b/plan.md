We need to count connected components where nodes connect if LCM ≤ threshold. Since threshold ≤ 2*10^5, we can bucket small numbers directly. Key insight: two numbers connect if LCM ≤ threshold, which requires both numbers ≤ threshold. Numbers > threshold can only connect to numbers ≤ threshold if LCM ≤ threshold, which means the small number must divide the large number and quotient ≤ threshold/small. We'll use Union-Find over small numbers (≤ threshold) and handle large numbers individually. For each large number `x`, we iterate multiples of small numbers that divide x up to threshold, unioning them.
