We need to find positive integers x>y such that x³ - y³ = N. Since x³ - y³ = (x-y)(x² + xy + y²), we can enumerate d = x-y > 0 and solve for x, y. Setting x = y + d, we get (y+d)³ - y³ = 3dy² + 3d²y + d³ = N. For each d from 1 up to cube root of N, we can solve the quadratic 3d·y² + 3d²·y + (d³ - N) = 0 for positive integer y. The discriminant must be a perfect square. We only need to try d up to about 10⁶ (since N ≤ 10¹⁸), which is fast. If any valid y is found, output x = y+d, y.
