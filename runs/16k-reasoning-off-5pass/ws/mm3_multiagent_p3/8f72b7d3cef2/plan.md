We need for each starting slime K the maximum size achievable by absorbing adjacent strictly smaller slimes any number of times, possibly from both sides. The key observation: once a slime is absorbed, the set of remaining slimes is a contiguous subarray containing K (since you only remove adjacent slimes). The final size equals A_K plus the sum of all absorbed slimes. Since we may stop at any moment, we want to absorb a prefix to the left and a suffix to the right of K that together form a **strictly increasing sequence of sizes** when traversed outward from K (i.e., each newly absorbed slime must be larger than the previous one on that side, otherwise we cannot jump over it). So the problem reduces to: for each K, find the longest strictly increasing contiguous segment around K, i.e., the maximal subarray [L,R] containing K such that A_L < A_{L+1} < ... < A_K < ... < A_R (strictly increasing). Then answer B_K = sum of that subarray.

We can compute this efficiently using a **Longest Strictly Increasing Subarray (LSIS)** of the whole array. Let inc[i] = length of the longest strictly increasing subarray ending at i. Compute in one pass: inc[i] = inc[i-1] + 1 if A[i-1] < A[i] else 1. Similarly, dec[i] (or right[i]) = length of longest strictly increasing subarray starting at i: right[i] = right[i+1] + 1 if A[i] < A[i+1] else 1.

For each K, the maximal subarray containing K is the unique maximal strictly increasing subarray that covers it. Its left endpoint L = K - inc[K] + 1, right endpoint R = K + right[K] - 1. Then B_K = prefix_sum[R] - prefix_sum[L-1].

Complexities: O(N) time, O(N) memory, works for N up to 5·10^5.
