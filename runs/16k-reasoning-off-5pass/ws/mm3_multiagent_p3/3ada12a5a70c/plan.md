We need to select k points on the square's boundary to maximize the minimum Manhattan distance between any two selected points. Since the number of points can be up to 15,000 and k ≤ 25, a standard greedy farthest-first selection works well: repeatedly pick the point that is farthest (in minimum distance) from the already selected set, exactly k times. The minimum distance in the resulting set is the answer. This O(k * n) approach (≤ 25 * 15,000 = 375,000 operations) is fast. Manhattan distance is computed directly.
