We need for each i, the maximum length of a common prefix achievable by any k strings from the array with index i removed. Directly simulating each removal is O(n²). The key insight: the answer depends only on the multiset of word frequencies after removal. For each distinct word, the only count that changes when we remove index i is the count of `words[i]`. For any other word, its count remains the same. So the answer for each i is determined by: if the highest count among all words except `words[i]` is ≥ k, the answer is the length of that word; otherwise we must consider `words[i]`'s count (which is reduced by 1). If that reduced count ≥ k, the answer is the length of `words[i]`; otherwise answer is 0. Thus we need, for each i, the maximum word length among words with original count ≥ k, but excluding the word at i (we look at all words except i). Concretely: precompute the length of the longest word whose frequency (in the original array) is at least k; call it `best`. Also precompute, for each distinct word, its frequency `cnt`. For index i with word w, if `cnt[w] >= k+1` (i.e., even after removal, frequency ≥ k), then answer is `len(w)`. Else if `cnt[w] >= k` and `best` is the max length among all other words (or among words with count ≥ k excluding w), answer is `best`. Otherwise answer is 0. To handle "best excluding w", we can precompute the top two word lengths (with count ≥ k). Let `top1_len, top1_word` be the longest word with count ≥ k, and `top2_len` be the second longest (or 0 if none). Then for index i with word w: if `cnt[w] >= k+1` → answer = `len(w)`. Else if `cnt[w] >= k` and `w != top1_word` → answer = `top1_len`. Else (w is top1 or its count < k) → answer = `top2_len` (which is 0 if no second word with count ≥ k). This gives O(n) solution.
