We need to minimize the length of the longest run of identical bits after at most `numOps` flips. For any candidate length `L`, we can check feasibility: can we ensure every maximal block of equal characters has length ≤ L? Equivalently, within every sliding window of length L, we can flip ≤ `numOps` positions to break long runs. Because flipping a bit changes its value, breaking a long run of the same character requires placing the opposite character inside it. A standard greedy works: process the string from left to right, counting the current run length `cnt`. When `cnt > L` and we have flips left, flip the earliest bit in the run (position `i - cnt`) to break the run into two parts; decrement `numOps`. If after a flip the run length still exceeds L, we must flip again. Continue scanning. If we never exceed `numOps` and finish, `L` is feasible. Binary search the minimum feasible `L` in `[1, n]`.
