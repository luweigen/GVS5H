We need shortest path length (number of edges) from i to j such that the concatenated edge labels form a palindrome. Empty path (length 0) is allowed when i=j. Since N ≤ 100, we can use BFS on an expanded state space: state = (u, v) meaning we are building a palindrome from both ends. We start from (i, j) with distance 0. From state (u, v), we can extend by one character on each side simultaneously: pick an outgoing edge u→x with label c, and an incoming edge y→v with label c (i.e., edge from y to v labeled c). Then we move to state (x, y) with distance+1. This ensures the string remains a palindrome. BFS over N² ≤ 10000 states is trivial. For each start (i,j), BFS until we reach (j,j) (which corresponds to a palindrome path from i to j). Output distance, or -1 if unreachable.
