Sort arrays A and B. Precompute prefix sums of A and B. For each query (X, Y), let `a = A[X-1]`, prefix sum of A up to X, and similarly `b = B[Y-1]`, prefix sum of B up to Y. The sum is `|a*Y - sumB(Y)| + |b*X - sumA(X)|` because the cross-absolute terms split cleanly when one side is a single element. This reduces each query to O(log N) with binary search and O(1) with a Fenwick tree; since X,Y are indices into the sorted arrays, binary search over the sorted arrays gives the subarrays, and prefix sums give the needed sums in O(1) per query.
