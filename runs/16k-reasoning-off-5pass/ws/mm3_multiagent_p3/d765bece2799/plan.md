We need to compute the sum of (min + max) for every contiguous subarray whose length is between 1 and k inclusive. The naive O(n·k) approach is too slow for n up to 80k. The classic way to sum minimums (or maximums) of all subarrays in O(n) is using a monotonic stack that counts how many subarrays each element is the minimum (or maximum). We'll use that technique but stop counting at window size k, so each element is only the min/max for subarrays that start within the last k positions. The idea: process elements left‑to‑right while maintaining a non‑decreasing stack for mins and a non‑increasing stack for maxes. For each new element, pop from the stack and adjust a running "contribution" value that represents the total (min+max) sum of all subarrays ending at the current index. When the window length exceeds k, subtract the contribution of the element that is now out of range. Summing the per‑position contributions yields the final answer.
