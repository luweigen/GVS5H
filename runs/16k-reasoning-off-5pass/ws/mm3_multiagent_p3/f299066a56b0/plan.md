We need to pair mochi such that each pair (top, bottom) satisfies top ≤ bottom/2. Since sizes are sorted, the optimal greedy strategy is: iterate from smallest to largest, maintaining a pointer to the smallest unused mochi that can serve as a "top". For each mochi as a potential bottom, if the current smallest top satisfies top ≤ bottom/2, we pair them and advance both pointers; otherwise we skip this bottom (it can't be a bottom for any larger top either, since tops only get larger). This yields the maximum number of pairs.
