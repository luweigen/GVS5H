We need to choose k non-overlapping windows of length x and make each window constant (all elements equal) with minimum total absolute adjustments. Since k ≤ 15 and n ≤ 1e5, dynamic programming over windows is viable. For each window, we can compute the minimum cost to make it constant by choosing any value (optimal = median) and summing |a_i - median| in O(x log x) per window. Precompute all window costs in O(n·x log x) total — but n·x can be 1e5·(n/2) worst case; however x can be up to n, so we need a faster method. We'll compute window costs using a sliding window with a balanced BST / two heaps to maintain the median, updating the sum of absolute deviations incrementally in O(log x) per slide, giving O(n log x). Then DP: dp[t][i] = min cost to have t windows among the first i positions, with a window ending at i being counted or not. Use transitions: dp[t][i] = dp[t][i-1], and if i >= x, dp[t][i] = min(dp[t][i], dp[t-1][i-x] + cost[i]) where cost[i] is the cost of the window ending at i. Answer is dp[k][n]. Since k ≤ 15, complexity is O(k·n).
