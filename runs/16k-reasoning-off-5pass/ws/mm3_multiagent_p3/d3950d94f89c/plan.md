We need to find downward paths (ancestor-to-descendant) where node values are unique, and maximize the sum of edge lengths along the path, with ties broken by fewer nodes. A standard approach: DFS from root, maintaining a path stack of nodes and their cumulative distances, plus a hash map of the last occurrence (position in stack) of each value along the current root-to-current path. When we encounter a value seen earlier on the current path, we must cut the path back to just after that earlier occurrence. While exploring, after adjusting the start index, we compute the current special path length (top distance − start distance) and update the answer. The result is the maximum length, and among all max-length paths we keep the minimum node count.
