We need to decide if there exists a binary matrix where each row is a prefix of B's then W's, and each column is a prefix of B's then W's, consistent with given cells. This is equivalent to: there exist row thresholds `r_i` (0..N) and column thresholds `c_j` (0..N) such that cell (i,j) is B iff `i <= r_i` AND `j <= c_j`, else W. For each precolored cell we get a constraint on `r_i` and `c_j`. For a B cell: `r_i >= i` and `c_j >= j`. For a W cell: either `r_i < i` or `c_j < j` (i.e., not both thresholds large enough). We need to check feasibility.

Approach: For each row i, define `Rmin[i]` = max over B cells in that row of i (always i), but actually we need lower bound on `r_i`: from B cells we need `r_i >= i`. So `Rmin[i] = i` if any B in row i, else 0. For each column j, `Cmin[j] = j` if any B in column j, else 0. For W cells: we need `r_i < i` OR `c_j < j`. This means we cannot have both `r_i >= i` and `c_j >= j`. So if a row i has `Rmin[i] = i` (forced B up to at least i) and a column j has `Cmin[j] = j`, then cell (i,j) cannot be W. So check: for every W cell (i,j), we must have `Rmin[i] < i` OR `Cmin[j] < j`. If both are >= their indices, impossible.

But this is necessary but not sufficient? Actually if we set `r_i = Rmin[i]` and `c_j = Cmin[j]`, then for B cells: row i has B up to `r_i >= i`, column j has B up to `c_j >= j`, so cell is B. For W cells: if `Rmin[i] < i` then row i's prefix ends before i, so cell is W regardless of column. If `Cmin[j] < j`, similarly. If both are >=, then cell would be B, contradiction. So the condition is exactly: for every W cell, not (Rmin[i]=i and Cmin[j]=j). This is both necessary and sufficient because we can always choose thresholds exactly as these minima (they are valid 0..N). So algorithm: compute for each row whether it contains a B cell; compute for each column whether it contains a B cell. Then for each W cell, check if its row has a B and its column has a B; if so, output No. Else Yes.

We need O(M) time and O(N) space, but N up to 1e9 so use hash sets/dicts for rows and columns that have B cells.
