We need to find the k-th lexicographic alternating permutation of [1..n] efficiently for n up to 100 and k up to 1e15. An alternating permutation requires adjacent parity alternation, so the permutation must start with either odd or even, and the parity pattern is fixed by the first element. We'll build the answer position by position, at each step trying the remaining numbers in increasing order. For a candidate value at position i, we must know how many valid completions exist given the remaining numbers and the required next parity. We precompute DP for counts of alternating sequences from a set of remaining odd/even counts with a required next parity. The DP state is (odd_remaining, even_remaining, next_parity) where next_parity ∈ {0=even, 1=odd}. Transitions: place any number of that parity, then move to the opposite parity. This is a combinatorial counting problem solvable by DP over remaining counts (n ≤ 50 of each parity in worst case). The DP values can be huge, so cap at >1e15. Then we iterate through candidates: for each viable number, check if k exceeds count(num) for placing it; if so, subtract and skip; else place it and continue. At the end, if we never ran out of candidates but k was too large, return [].
