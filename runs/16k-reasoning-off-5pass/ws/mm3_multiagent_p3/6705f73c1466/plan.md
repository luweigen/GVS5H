We need the minimum number of adjacent swaps to bring all 1s together. Let total number of 1s be `k`. If we move all 1s to positions `[l, l+k-1]`, the cost equals the number of inversions between the 1s and the zeros that lie inside that window, which is `window_ones - i`, summed over each 1 in the window. Equivalently, the total cost for a window of length `k` is the number of zeros inside the window. So we can precompute prefix counts of 1s, and for each possible window of `k` consecutive positions, compute the number of zeros inside it (which equals `k` minus the number of 1s in the window). The answer is the minimum of that value over all windows.
