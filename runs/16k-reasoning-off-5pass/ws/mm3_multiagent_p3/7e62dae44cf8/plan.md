Model the problem as a graph where cells are nodes, edges exist between 4-adjacent cells. Starting from (P, Q) with strength `cur`, we can repeatedly absorb a neighbor whose strength `s` satisfies `s < cur / X` (i.e., `s * X < cur`). After absorption, `cur += s` and that node is removed, but the underlying adjacency remains (since the gap closes and neighbors become adjacent to the player). This is equivalent to a standard BFS/DFS on cells with a dynamically increasing threshold: we maintain a min-heap of adjacent slimes; we can absorb any slime whose `s * X < cur`. When we absorb, we push its neighbors onto the heap. We use long arithmetic (Python int). Complexity O(N log N).
