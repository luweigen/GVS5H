We need to partition a tree of size N·K into N disjoint simple paths of length K (K vertices each, so K-1 edges). The edges of a path of length K form a connected subpath of the tree; the union of N such disjoint length-K paths must cover all edges exactly once (since there are N(K-1) edges total, matching the tree's edge count). Equivalently, we need to partition the tree's edges into N simple paths of K-1 edges each, with all vertices used exactly once.

Approach: leaf-stripping DP. Repeatedly remove leaves and try to "pair" adjacent pending path ends. We run a BFS/DFS from leaves, tracking for each node the "remainder" r (how many vertices of a partial path are still needed extending through this node), which is computed modulo K. When two K-sized partial paths meet, they fuse; when a K-sized path closes, it becomes a finished path. At the end, if exactly one finished path remains and no leftover remainder, answer is Yes.

This is the standard "tree into N paths of length K" check, implemented with a multiset/greedy matching of partial-path requirements per edge, O(NK log NK) using sets. For efficiency with up to 2·10^5 we use adjacency lists and a stack of leaf nodes.
