The problem asks for the minimum cost to go from vertex 1 to N where each step we either traverse a directed edge (cost 1) or reverse all edges (cost X). Reversing flips the graph, so after one reversal we are in the "reversed" world, and after two reversals we are back to the original orientation. This creates a state machine with two modes: mode 0 (original) and mode 1 (reversed). The answer is the shortest path from (1,0) to (N,0) or (N,1) in a graph with 2N nodes and at most 2M+2N edges. Use Dijkstra with a 64-bit distance array because X can be up to 1e9 and distances can exceed 2^31. Complexity is O((N+M) log N).
