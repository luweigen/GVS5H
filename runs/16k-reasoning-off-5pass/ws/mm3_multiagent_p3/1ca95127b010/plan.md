Model operations as swaps of adjacent blocks of lengths X and Y where one block is all 0s and the other all 1s. The total number of 0s and 1s in S must equal those in T (necessary condition). The operations can be simulated greedily from left to right: scan both strings, and whenever the current character in S differs from T, we must apply the operation that swaps the block ending at the current position (if possible). This greedy works because the leftmost mismatch must be fixed by an operation that starts at or before that position, and any such operation also necessarily starts at that position (otherwise it would change a previously fixed character). The simulation can be done in O(N) using a deque to track pending indices of the opposite bit.
