We need to maximize the minimum vitamin intake across the three types, given a calorie limit X. Since we want to maximize the bottleneck, we can binary search the answer `mid` and check if it's possible to achieve at least `mid` units of each vitamin within X calories. For each vitamin, we can pre-sort the foods by calories and compute the minimum calories needed to collect total vitamin ≥ mid (a knapsack-like DP over total vitamin, but we only need the minimum calories for each achievable total). Then a triple-nested check: for each calorie spent on vitamin1 `c1`, vitamin2 `c2`, we can compute the minimum calories needed for vitamin3 to reach `mid` via the precomputed array, and verify `c1 + c2 + c3 ≤ X`. Use early termination and fast inner loops (use `break` when possible). Complexity: O(N * mid_sum) ≈ O(N * 3*mid) which is fine since `mid` ≤ 2e5 and N,X ≤ 5000 (practically fast).
