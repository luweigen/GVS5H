Treat each cell as a vertex with two edge-stubs (right/left, top/bottom) in a torus grid. Type-A tiles contribute one stub (choose 1 of 4 sides); Type-B tiles contribute two opposite stubs (choose 1 of 2 axes). The condition requires perfect matching across every edge on the torus (no dead ends). Because each cell only connects to its own two stubs, every valid configuration forces a perfect pairing across all grid edges. Enumerate row types: pairings across vertical edges within a row partition the W columns into blocks; each block is either an A-tile (paired top/bottom) or a chain of B-tiles ended by A-tiles, with total length equal to block size. For each row string, precompute for every block-length k the number of ways `f[len][i][j]` to tile the block ending at columns with column-types i,j. Then dynamic program rows with transfer on H (counts of A-tiles per row) via convolution. Complexity O(HW + maxA²·H) with total size ≤1e6, fast under limits.
