We need to pick up to 4 non-overlapping intervals maximizing total weight; if multiple index sets achieve the same max weight, return the lexicographically smallest list of indices (sorted by index order). We can do DP over sorted intervals, tracking the best (weight, lexicographically smallest index list) for picking k intervals (k = 0..4) ending at/before a given interval. The recurrence: for interval i (sorted by right endpoint, keep original indices), let p[i] be the greatest index j < i with r_j < l_i (strictly less to avoid boundary overlap). Then dp[i][k] = best between (not taking i) dp[i-1][k] and (taking i) combine best list of size k-1 from dp[p[i]][k-1] with index i. To compare two candidates with same k, we prefer higher total weight; if weights tie, prefer lexicographically smaller index list. We represent each state as a tuple (weight, indices) to enable direct comparison. The final answer is the best among dp[N][k] for k=0..4. Complexity O(N * K log N) for binary searching p[i], with N up to 5e4 and K=4 — fast enough.
