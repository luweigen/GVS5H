We model the constraints as a graph where each variable is a node and each equation \(A_x \oplus A_y = Z\) is an edge labeled with Z. The problem reduces to assigning values to nodes consistent with edge XORs and minimizing total sum. This is a classic system over GF(2) per bit: each connected component can be assigned a free variable (the value of one node), and all others are determined up to XOR with that variable per bit. For each component, we consider the set of feasible assignments and pick the one minimizing the sum of node values. This is a 2-SAT style minimization: for each node, given the free variable, its value is either V or V⊕(some mask) depending on the parity of its distance to the root. Among the two choices of the free variable (0 or some flip), we compute the resulting total sum and pick the smaller. We must also detect contradictions: when an edge connects two already-assigned nodes relative to the root, the implied XOR must match the edge label. Use DSU/Union-Find with parity to process each connected component, tracking the XOR distance from a chosen root.
