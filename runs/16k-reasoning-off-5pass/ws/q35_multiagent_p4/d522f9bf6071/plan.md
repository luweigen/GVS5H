1. Sort intervals by their end points to facilitate dynamic programming. We need to track the best score achievable with k non-overlapping intervals ending at or before a certain point.
2. Use dynamic programming where dp[k][i] represents the maximum weight sum using exactly k intervals from the first i intervals (sorted by end time). To handle lexicographical order, we also need to store which intervals were chosen.
3. Since n is up to 5*10^4 and k is at most 4, we can use a DP approach with state dp[k][i] = max weight using k intervals from first i. For each interval i, we can either skip it or include it (if it doesn't overlap with the previous chosen interval).
4. To efficiently find the previous non-overlapping interval, we can use binary search (bisect) on the end points of the sorted intervals.
5. After filling the DP table, the answer for maximum weight is max(dp[1][n-1], dp[2][n-1], dp[3][n-1], dp[4][n-1]). Let max_k be the largest k that achieves the global maximum weight.
6. To get the lexicographically smallest index array, we need to reconstruct the solution. However, because lexicographical order depends on the indices (original indices) and not the order of selection, we must be careful.
