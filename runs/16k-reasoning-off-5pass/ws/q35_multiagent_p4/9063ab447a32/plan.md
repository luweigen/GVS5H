1. **Binary Search on Answer**: The maximum total units $K$ is monotonic with respect to cost. We can binary search for the maximum $K$ such that there exists a way to buy $K$ units with total cost $\le M$.
2. **Minimize Cost for Fixed $K$**: For a fixed total number of units $K$, we need to distribute them among the $N$ products to minimize the total cost $\sum k_i^2 P_i$ subject to $\sum k_i = K$ and $k_i \ge 0$. This is a convex optimization problem.
3. **Optimal Distribution**: The cost function is separable and convex. The optimal distribution satisfies that the marginal cost of adding one more unit to any product is roughly equal. Specifically, if we have bought $k_i$ units of product $i$, the marginal cost of the next unit is $(k_i+1)^2 P_i - k_i^2 P_i = (2k_i+1)P_i$. We can use a greedy approach with a priority queue or binary search on the "marginal cost threshold" to find the optimal $k_i$ for each product.
4. **Efficient Check**: For a given $K$, we can determine the minimum cost by finding a threshold $\lambda$ such that for each product $i$, we buy $k_i$ units where the marginal cost of the last unit is $\le \lambda$ and the next would be $> \lambda$. 5. **Check Function**: For a fixed $K$, we can use a priority queue to greedily assign units to the product with the smallest marginal cost. However, $K$ can be large. Instead, we binary search on the "Lagrange multiplier" or marginal cost threshold. For a threshold $\lambda$, for each product $i$, the maximum $k_i$ such that the marginal cost of the $k_i$-th unit is $\le \lambda$ is determined by $(2k_i-1)P_i \le \lambda \Rightarrow k_i \le (\lambda/P_i + 1)/2$. We can compute total units and total cost for a given $\lambda$, then adjust. This allows an $O(N)$ check.
