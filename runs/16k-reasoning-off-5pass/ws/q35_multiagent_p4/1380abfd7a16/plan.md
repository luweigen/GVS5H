The naive simulation of inserting elements into an array takes O(N^2) time due to shifting elements, which is too slow for N up to 5×10^5. Instead, we can work backwards. Notice that the last element inserted (N) is placed at position P_N. The element inserted before it (N-1) is placed at position P_{N-1} in the array of size N-1. We can determine the final position of each number by maintaining a data structure that supports finding the k-th available slot. A Fenwick tree (Binary Indexed Tree) or Segment Tree can track which positions are still empty. We process from i = N down to 1: find the P_i-th empty position, place i there, and mark that position as occupied. This allows us to determine the final array in O(N log N) time.
