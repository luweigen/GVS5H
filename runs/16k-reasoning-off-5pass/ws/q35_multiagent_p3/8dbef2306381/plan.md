The problem asks if we can reach square N from square 1 by jumping between A and B, avoiding "bad" squares. Since N is up to $10^{12}$, we cannot simulate all squares. However, the number of bad intervals M is small ($2 \times 10^4$), and the jump range [A, B] is very small ($B \le 20$). We can model this as a reachability problem on a graph where nodes are "safe" squares. The key observation is that we only need to consider squares that are either start (1), end (N), or boundaries of bad intervals (since these are the only places where the set of available next moves changes significantly). We can collect all "critical" points: 1, N, and for each interval $[L_i, R_i]$, the points $L_i-1$ and $R_i+1$ (if they are safe and within bounds). We sort these critical points and build a graph where edges exist between critical points if one can jump from one to the other using a step in $[A, B]$ and the destination is safe. We then run BFS/DFS from 1 to see if N is reachable. To check if a square is bad efficiently, we can use the sorted intervals.
