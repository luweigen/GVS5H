1.  **Graph Construction Insight**: The graph $G$ has an edge between $i$ and $j$ if $[L_i, R_i] \cap [L_j, R_j] = \emptyset$. This is equivalent to $R_i < L_j$ or $R_j < L_i$.
2.  **Connectivity Analysis**: Instead of building the graph explicitly (which could have $O(N^2)$ edges), we analyze the connected components. Two intervals are connected if they are disjoint. We can use a sweep-line or sorting approach to determine connectivity. However, a more efficient way is to observe that if the union of all intervals is "dense" enough, the graph might be connected or have few components.
3.  **Shortest Path**: Since edge weights are not defined but vertex weights are, the path weight is the sum of vertex weights. This is equivalent to finding a path in $G$ with minimum vertex sum. This can be modeled as a shortest path problem on $G$ with vertex weights. Since $N$ and $Q$ are up to $2 \times 10^5$, we cannot run Dijkstra for each query.
4.  **Component-wise Precomputation**: We first identify connected components of $G$. Within a component, the shortest path between any two nodes $s$ and $t$ will likely involve a "hub" node with small weight. Specifically, the minimum path weight between $s$ and $t$ in a component is $\min_{k \in \text{Component}} (W_s + W_k + W_t)$ if $s \neq t \neq k$, or just $W_s + W_t$ if they are directly connected. More generally, it is $W_s + W_t + \min(\min_{k \neq s,t} W_k, 0)$ if we consider direct edges. Actually, the shortest path between $s$ and $t$ is either the direct edge (if it exists) with weight $W_s + W_t$, or a path through some intermediate node $k$ with weight $W_s + W_k + W_t$. Thus, for any pair $s, t$ in the same component, the answer is $W_s + W_t + \min(0, \min_{k \in \text{Component}, k \neq s, k \neq t} W_k)$. If the component has only 2 nodes, it's just $W_s + W_t$ if connected, else -1.
5.  **Algorithm**:
    -   Sort intervals to efficiently determine connectivity.
    -   Use a Disjoint Set Union (DSU) or BFS/DFS on a reduced graph to find connected components. To avoid $O(N^2)$ edges, we can connect intervals that are "adjacent" in a sorted order or use the property that if interval $i$ is disjoint from $j$, they are connected.
    -   A better approach: The complement graph $\bar{G}$ has edges where intervals intersect. $\bar{G}$ is an interval graph. Connected components in $G$ can be found by analyzing the structure of $\bar{G}$.
    -   Actually, it's easier to build $G$ implicitly. We can find connected components by iterating through sorted intervals.
    -   For each component, precompute the minimum vertex weight $min\_W$ in that component.
    -   For a query $(s, t)$, if they are in different components, output -1.
    -   If they are in the same component:
        -   Check if there is a direct edge between $s$ and $t$. If yes, candidate weight is $W_s + W_t$.
        -   Otherwise, the shortest path is $W_s + W_t + min\_W$ (using the node with minimum weight as a hub), provided the component has at least 3 nodes or the hub is distinct. If the component has only 2 nodes and no direct edge, it's -1 (but if they are in the same component of size 2, they must be connected? No, component definition ensures connectivity).
        -   Wait, if $s$ and $t$ are in the same component, there is a path. The shortest path is either direct ($W_s+W_t$) or via one intermediate node ($W_s+W_k+W_t$). It cannot be shorter via more nodes because weights are positive. So the answer is $W_s + W_t + \min(0, \min_{k \in C, k \neq s, k \neq t} W_k)$. If $|C|=2$, then no such $k$ exists, so only direct edge matters. If direct edge doesn't exist, then they wouldn't be in the same component? No, they could be connected via a path of length > 1. But if $|C|=2$ and no direct edge, they are not connected. So if they are in the same component, either direct edge exists or there is a path of length >= 2.
        -   Correction: If $s$ and $t$ are in the same component, the shortest path is $\min(W_s + W_t, W_s + W_t + \min_{k \in C \setminus \{s,t\}} W_k)$. If $C \setminus \{s,t\}$ is empty, the second term is infinity.
