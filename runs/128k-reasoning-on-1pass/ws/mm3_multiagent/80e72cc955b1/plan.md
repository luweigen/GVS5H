The operation applies `floor(x/4)` to two numbers per step. For each number `x`, the number of steps needed to reach 0 is the number of times we must divide by 4, which equals the number of digits in base 4, i.e., `f(x) = floor(log₄(x)) + 1` for `x > 0`. Since each operation reduces the total remaining steps by at most 2, the minimal number of operations for a query `[l, r]` is `ceil( (sum_{x=l}^r f(x)) / 2 )`. The function `f(x)` takes only 15 possible values for `x ≤ 10⁹` (since `4¹⁵ > 10⁹`). We can precompute powers of 4 and for each query sum `f(x)` over the interval by iterating over the at most 15 ranges `[4^{k-1}, 4^k - 1]`, counting how many numbers fall into each range and multiplying by `k`. The final answer is the sum of `ceil(sum/2)` over all queries.
