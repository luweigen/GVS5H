The edge condition `lcm(a,b) ≤ threshold` is equivalent to the existence of an integer `L ≤ threshold` that is a common multiple of `a` and `b`. Hence two numbers belong to the same connected component iff they share at least one common multiple not larger than the threshold.  
We can capture this by enumerating, for every number `a` not larger than the threshold, all its multiples `L = a, 2a, 3a, … ≤ threshold`. For each such `L` we remember the first number that visited it; every subsequent number that also divides `L` is united with that first number using a Disjoint Set Union (DSU). After processing all numbers, any two numbers that ever shared a common multiple lie in the same DSU set, while numbers larger than the threshold can never be connected to anyone and stay isolated.  
The total work is `Σ (threshold / a)` over all `a ≤ threshold`, which is `O(threshold log threshold)` (≈ 2.4 million operations for the maximal `threshold = 2·10⁵`). DSU operations are almost O(1) with path compression, so the overall solution easily fits the limits.
