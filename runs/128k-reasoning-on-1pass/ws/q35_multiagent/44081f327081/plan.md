We reduce the problem to finding, for each $A_i$, the largest divisor $g$ of $A_i$ such that there are at least $K$ multiples of $g$ in the entire sequence $A$. We first compute a frequency array of $A$, then efficiently calculate the count of multiples for every possible $g \in [1, \max(A)]$ using harmonic series summation via array slicing. Next, we initialize an answer array and iterate $g$ from $1$ to $\max(A)$. Whenever `count(g) >= K`, we mark all multiples of $g$ in the answer array with $g$. Processing $g$ in increasing order ensures that larger valid divisors overwrite smaller ones, leaving each index with the maximum possible GCD. Finally, we map the precomputed answers back to the original sequence and print them.
