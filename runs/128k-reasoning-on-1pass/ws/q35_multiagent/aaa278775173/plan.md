We will use dynamic programming to compute the longest valid diagonal sequences ending at each cell (`back` DP) and the longest valid continuations starting at each cell (`fwd` DP). The `back` DP tracks the length of sequences matching `1, 2, 0, 2, 0...` ending at `(r, c)` from each of the 4 diagonal directions. The `fwd` DP tracks the length of sequences continuing the `2, 0, 2, 0...` pattern starting at `(r, c)`, storing separate values for when the next expected value is `0` or `2`. We then iterate over all cells and direction pairs that form a clockwise 90-degree turn, combining the `back` length with the appropriate `fwd` length based on parity. The maximum combined length (or straight length) is our answer. This approach runs in $O(nm)$ time and space.
