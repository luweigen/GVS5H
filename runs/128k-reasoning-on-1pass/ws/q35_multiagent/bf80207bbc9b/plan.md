The problem requires minimizing the total number of 1s in an $H \times W$ grid by flipping rows and columns. Flipping operations are commutative and equivalent to XORing with 1. For a fixed set of column flips (represented by a mask $C$), the optimal row flips are determined independently to minimize 1s in each row. The cost for a column mask $C$ is the sum over all rows of $\min(\text{popcount}(R_i \oplus C), W - \text{popcount}(R_i \oplus C))$. This sum can be computed efficiently for all $2^W$ masks using Fast Walsh-Hadamard Transform (FWHT) as an XOR convolution of the row frequency array and a cost function array. Given $W \le 18$, $O(W \cdot 2^W)$ complexity is feasible.
