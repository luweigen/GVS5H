The problem can be modeled combinatorially by observing that exactly $k$ equal adjacent pairs divide the array of size $n$ into $n-k$ contiguous blocks of identical values. We first choose which $k$ of the $n-1$ adjacent gaps will be equal, which can be done in $\binom{n-1}{k}$ ways. For each valid partition, the first block can take any of $m$ values, and each subsequent block must differ from its predecessor, giving $m-1$ choices per block. This yields $m \times (m-1)^{n-k-1}$ value assignments. Multiplying these two components and taking the result modulo $10^9+7$ gives the final answer. We will implement modular exponentiation and modular combination efficiently to handle the constraints.
