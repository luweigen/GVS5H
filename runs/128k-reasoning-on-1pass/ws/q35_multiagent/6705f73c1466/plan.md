First, identify the indices of all '1's in the string. Let these positions be $p_0, p_1, \dots, p_{k-1}$. We want to move these 1s to a contiguous block of length $k$ starting at some position $x$, so the target positions are $x, x+1, \dots, x+k-1$. The cost to move the $j$-th 1 to its target is $|p_j - (x+j)|$, which can be rewritten as $|(p_j - j) - x|$. Let $q_j = p_j - j$. The problem reduces to finding an integer $x$ that minimizes $\sum |q_j - x|$, which is achieved when $x$ is the median of the values $q_j$. Since the original indices are sorted, $q_j$ is also sorted, so the median is simply $q_{k//2}$. Finally, compute the sum of absolute differences between each $q_j$ and the median to get the minimum number of swaps.
