The constraint $\binom{N}{K} \le 10^6$ guarantees that the number of valid subsets is small enough to enumerate directly. We can use depth-first search (DFS) to generate all combinations of size $K$ and compute their XOR sums incrementally, avoiding $O(K)$ recomputation per subset. If $K > N/2$, we exploit the identity $\binom{N}{K} = \binom{N}{N-K}$ by instead enumerating subsets of size $N-K$ to exclude. The XOR sum of the chosen $K$ elements then equals `Total_XOR ^ Excluded_XOR`, allowing us to reuse the same enumeration logic while keeping the search space minimal. We track the maximum XOR value encountered and print it.
