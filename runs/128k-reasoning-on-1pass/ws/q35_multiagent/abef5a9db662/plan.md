The problem requires simulating rating changes for multiple queries. A naive simulation per query is too slow ($O(NQ)$). Instead, we observe that the rating function is monotonic and we can process all contests to determine the final rating for any initial rating $X$. We use a Segment Tree to maintain the current rating for each possible initial rating $X \in [1, 500000]$. The Segment Tree supports range updates (adding 1 to a range of ratings) and finding the range of ratings that fall within $[L_i, R_i]$ for each contest. Since the array of ratings is always sorted, we can efficiently find the range $[l, r]$ of initial ratings whose current rating is in $[L_i, R_i]$ using binary search on the Segment Tree (specifically, finding the first index with value $\ge L_i$ and the first index with value $\ge R_i + 1$). After processing all contests, we push all lazy tags down to the leaves to retrieve the final ratings for each query in $O(1)$.
