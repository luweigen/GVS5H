
## ideation
The problem requires simulating rating changes for $N$ contests with $Q$ queries. A naive simulation per query is too slow ($O(NQ)$). We observe that the rating function $g(X)$ (final rating given initial $X$) is non-decreasing. We can maintain $g(X)$ using a segment tree with lazy propagation. The segment tree supports range updates (adding 1 to a range of initial ratings) and finding the range of initial ratings whose current rating falls within $[L_i, R_i]$ for each contest. Since $g(X)$ is non-decreasing, we can find the boundaries of this range using binary search on the segment tree in $O(\log M)$ time, where $M$ is the maximum possible rating. After processing all contests, we retrieve the final ratings for each query in $O(1)$ time. The total time complexity is $O(N \log M + Q)$, which fits within the constraints.
