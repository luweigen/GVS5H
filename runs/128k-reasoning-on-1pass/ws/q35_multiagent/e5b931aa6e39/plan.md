We rewrite the equation $x^3 - y^3 = N$ as $(x-y)(x^2+xy+y^2) = N$. Let $d = x-y$, so $x = y+d$. Substituting this into the equation yields a quadratic in $y$: $3y^2 + 3dy + d^2 = N/d$. For a valid solution, $d$ must be a divisor of $N$. We iterate $d$ from $1$ up to $\lfloor \sqrt[3]{4N} \rfloor$, since the discriminant of the quadratic must be non-negative. For each divisor $d$, we compute the discriminant $D = 12(N/d) - 3d^2$, check if it's a perfect square, and verify if the resulting $y$ is a positive integer. If found, we output $x=y+d$ and $y$; otherwise, we continue. If no solution is found after checking all valid $d$, we output `-1`. This approach runs in $O(N^{1/3})$ time, which is well within limits for $N \le 10^{18}$.
