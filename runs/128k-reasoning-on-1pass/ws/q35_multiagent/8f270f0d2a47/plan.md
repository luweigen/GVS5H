We will solve the problem using Digit DP. The core idea is to count beautiful numbers up to `r` and subtract beautiful numbers up to `l-1`. A number is beautiful if the product of its digits is divisible by the sum of its digits. Since the maximum number of digits is 9, the digit sum is at most 81. We can track the exact product of digits in the DP state because the number of distinct products formed by digits 0-9 (7-smooth numbers) is very small (~1800 values up to $9^9$), keeping the state space manageable. Numbers containing a `0` digit automatically have a product of `0`, which is divisible by any positive sum, so they are naturally handled. The DP state will track the current position, running digit sum, running digit product, tight constraint, and whether we have started placing non-zero digits.
