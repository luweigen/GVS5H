The operation reduces two numbers by dividing them by 4, which corresponds to decrementing their "height" (number of base-4 digits) by 1. Each number `x` has a height `h(x) = floor(log4(x)) + 1`. The problem reduces to finding the minimum steps to reduce all heights to zero by pairing them, which is a classic result: `max(max_height, ceil(sum_heights / 2))`. Since `h(x)` is constant over intervals `[4^k, 4^(k+1)-1]`, we can precompute prefix sums of heights to calculate the sum of heights for any range `[l, r]` in O(1) time. We then apply the formula for each query and sum the results.
