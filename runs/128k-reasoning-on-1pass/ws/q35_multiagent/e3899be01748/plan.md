We need to count substrings divisible by their non-zero last digit. Since the last digit can only be `1` through `9`, we can iterate over each possible divisor `d` independently. For a fixed `d`, we want to count pairs `(i, j)` where `s[j] == d` and the substring value `V[i..j] ≡ 0 (mod d)`. Using prefix values `P[k]`, the condition becomes `P[j+1] ≡ P[i] * 10^(j-i+1) (mod d)`. Because `10^k mod d` is periodic with period at most `6`, we can maintain a frequency array `cnt[rem][offset]` tracking prefix remainders grouped by their index modulo `6`. For each valid ending position `j`, we query this array to count matching starting positions in `O(1)` amortized time. This yields an overall `O(N)` solution with a small constant factor.
