We will use dynamic programming combined with the Convex Hull Trick (CHT) to optimize the transition. Let $DP[j]$ represent the minimum cost to partition the prefix $nums[0 \dots j-1]$. The cost of adding a subarray $nums[l \dots j-1]$ as the $i$-th subarray is $(P[j] + k \cdot i)(C[j] - C[l])$, where $P$ and $C$ are prefix sums of `nums` and `cost`. This transition can be rewritten as a linear function of $C[l]$, allowing us to use CHT to find the minimum in $O(1)$ amortized time per state. We iterate over the number of subarrays $i$ from 1 to $N$, updating the DP array and tracking the global minimum cost.
