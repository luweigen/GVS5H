The problem asks us to determine if smoke exists at a specific coordinate $(R, C)$ at various times $t+0.5$. Smoke starts at $(0,0)$ at $t=0$. At each step $t$, wind blows all smoke, and if no smoke is at $(0,0)$, new smoke is generated there. This implies that at each time $t+0.5$, there is always smoke at $(0,0)$. We can track the position of the "initial" smoke (the smoke present at $t=0$) as it moves with the wind. Let $P_t$ be the position of this smoke at time $t+0.5$. Any smoke particle present at $(0,0)$ at time $k+0.5$ will be at position $P_t - P_k$ at time $t+0.5$. Smoke exists at $(R,C)$ at time $t+0.5$ if and only if there exists some $k < t$ such that $P_t - P_k = (R,C)$, which is equivalent to $P_k = P_t - (R,C)$. We can maintain a set of all visited positions $\{P_0, P_1, \dots, P_{t-1}\}$ and check if $P_t - (R,C)$ is in this set for each $t$. This approach runs in $O(N)$ time and space.
