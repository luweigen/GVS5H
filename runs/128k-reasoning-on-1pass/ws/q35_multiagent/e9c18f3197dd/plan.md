We will solve this using bitmask dynamic programming since the number of targets is very small (at most 4). First, we compute the LCM for every possible subset of targets. Then, for each subset, we find the minimum operations required to make some element in `nums` a multiple of that LCM. Finally, we use DP over bitmasks to partition the targets into disjoint subsets and assign each subset to a distinct `nums` element, minimizing the total operations. The answer is the DP value for the full target mask.
