We split the problem into two independent subproblems: computing the sum of maximums and the sum of minimums for all valid subarrays, then adding the results. For each element, we determine how many subarrays of length $\le k$ have it as their maximum (or minimum) using a monotonic stack to find the nearest greater/smaller boundaries. Given boundaries $L$ and $R$, the number of valid subarrays where `nums[i]` is the extremum is equivalent to counting pairs $(x, y)$ with $1 \le x \le L$, $1 \le y \le R$, and $x + y - 1 \le k$. This count can be computed in $O(1)$ using arithmetic series formulas. The overall time complexity is $O(n)$ and space complexity is $O(n)$.
