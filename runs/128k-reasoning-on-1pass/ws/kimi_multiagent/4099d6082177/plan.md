Root the tree arbitrarily and compute every subtree size. For each parent–child edge, the child-side size modulo K forces the edge: if it is 0, the edge must be cut; otherwise it must be kept inside one K-vertex path. After keeping exactly the forced edges, each connected kept component must have precisely K vertices and maximum degree at most 2, making it a path. If all kept components satisfy this, print Yes; otherwise print No. This is linear in NK and also handles K=1 and N=1 naturally.
