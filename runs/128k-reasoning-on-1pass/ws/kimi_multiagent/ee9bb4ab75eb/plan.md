Build a trie of all words and store at each node its depth and how many words pass through it. For a removed word, only nodes on that word’s root-to-terminal path lose one count, so a node remains usable if `cnt >= k` off the path or `cnt >= k+1` on the path. During one DFS, maintain the best qualifying ancestor depth for the current path and the best qualifying depth not on the current path using depth buckets plus a max structure. At each terminal node, the answer for that word index is the max of those two values, with the global `n-1 < k` case forced to 0. Total work is near-linear in the sum of word lengths, with logarithmic depth-structure updates if needed.
