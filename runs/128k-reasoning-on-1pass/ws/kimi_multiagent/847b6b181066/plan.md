Model the whole smoke set as copies of the origin translated by the cumulative wind displacement. Let `P[t]` be the prefix displacement after `t` wind steps; smoke created at time `k` is at `P[t]-P[k]` at time `t`. New smoke is created at `(0,0)` exactly when the current prefix position `P[t]` has never occurred before, so creation times are first occurrences of prefix-sum positions. For target `X=(R,C)`, smoke is present at time `t` iff `P[t]-X` equals some prefix position whose first occurrence time is `<= t`. Precompute prefix positions and first occurrences, then answer all `t` in O(N).
