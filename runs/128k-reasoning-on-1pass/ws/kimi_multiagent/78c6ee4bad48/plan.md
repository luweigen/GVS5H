Transform coordinates into gaps `g[k]=X[k+1]-X[k]`; one operation reverses a length-3 gap block `(g[i],g[i+1],g[i+2])`, which only swaps `g[i]` and `g[i+2]`, so gap-index parity is invariant. Thus odd-indexed gaps can be permuted arbitrarily among odd positions, and even-indexed gaps among even positions. The total sum is `N*X[0] + Σ (N-k)*g[k]`, with weights decreasing as `k` increases. By rearrangement inequality, minimize each parity class independently by placing smaller gaps on larger weights and larger gaps on smaller weights. Use 64-bit integers and sort only the two parity classes.
