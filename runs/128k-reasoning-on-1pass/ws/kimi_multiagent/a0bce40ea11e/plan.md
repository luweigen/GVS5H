Work over F_p and view each entry of B^p as a sum of length-p walks; summing over all replacements makes each zero-edge variable contribute -1 iff its exponent is a positive multiple of p-1, otherwise 0. For p>3 this forces any contributing walk to use no zero edges, so the answer is (-1)^K(A with zeros set to 0)^p mod p. Handle p=2 directly since every zero must become 1. Handle p=3 separately: a contributing walk may use one zero edge exactly twice plus one fixed edge once, giving base (zeros-as-0)^3 plus small row/column/reverse-edge corrections, all multiplied by (-1)^K. Use fast modular matrix exponentiation for the fixed-edge matrix.
