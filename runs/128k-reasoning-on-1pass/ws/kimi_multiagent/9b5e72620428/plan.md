Because A can be freely permuted, only the multiset of fixed A values matters; B positions are fixed except for `-1` wildcards. For a chosen common sum S, every fixed B value y demands an A value exactly S-y, while every fixed A value x must either match a fixed B with y=S-x or be absorbed by a B wildcard. Let aF,bF be fixed counts and p,q be A/B wildcard counts; if M(S) is the maximum number of fixed-fixed pairs with x+y=S, the conditions are S at least all fixed values, bF-M(S)<=p, and aF-M(S)<=q. Equivalently M(S)>=L=max(0,bF-p,aF-q), so we only need to know whether some feasible sum S attains enough fixed-fixed matches. Compute match counts for candidate sums from fixed value frequencies and accept if any candidate satisfies the bounds.
