Build the disjointness graph implicitly: an edge exists iff one interval ends strictly before the other starts. Use/prove the key structural fact that complements of interval graphs are P5-free; with positive vertex weights, any chord in a shortest path can be skipped, so a minimum path uses at most 3 edges. Preprocess prefix minima of weights by right endpoint and suffix minima by left endpoint so we can query the cheapest interval strictly left/right of any coordinate in O(1). For each query, if the intervals are disjoint answer W_s+W_t; otherwise take the best common-neighbor 2-edge path and the best opposite-side 3-edge path using those range minima. If no such candidate exists, output -1. Total complexity is O(N + coordinate + Q), with coordinate ≤ 2N.
