Let `P[x]` be the prefix sum of road strengths up to town `x`; a traveler’s stamina is a difference of these potentials. Normalize each person to an interval `[l,r]` with `l<r` and type `U` if `S<T` (endpoints are strict minima) or `D` if `S>T` (endpoints are strict maxima). A set is feasible iff same-type intervals are laminar: for `l1<l2`, they conflict exactly when `l2<r1<=r2`, including shared-endpoint containment; opposite types only conflict when they have the same unordered endpoints. Thus feasibility becomes absence of pairwise conflicts, so compute for each person `i` the maximum previous index `bad[i]` conflicting with it. Query `[L,R]` is `Yes` iff `max(bad[L..R]) < L`, answered with RMQ after an `O(M log N)` sweep.
