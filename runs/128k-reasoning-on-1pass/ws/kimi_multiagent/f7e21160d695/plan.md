Use the minimax property: for any undirected graph, f(x,y) equals the maximum edge weight on the unique x-y path in any MST, equivalently the Kruskal threshold when x and y first become connected. Build an MST with Kruskal, then process its edges in increasing weight while maintaining DSU components. In each component keep only the unmatched surplus of A-vertices and B-vertices, with the invariant that a component never has both after internal matching. When merging two components at weight w, match opposite-type surpluses across the edge and add w times the number matched; this greedy earliest-possible matching is optimal for an ultrametric cost. The total over all MST edges is the minimum assignment sum, with duplicates handled by vertex multiplicities.
