Only grinding down is allowed, so for a chosen common sum \(H\), position \(i\) must end with upper length \(u_i\) in \([\max(0,H-D_i),\min(U_i,H)]\); the cost there is always \((U_i+D_i)-H\) regardless of split. Thus total cost for feasible \(H\) is \(\sum(U_i+D_i)-N\cdot H\), so we want the maximum feasible integer \(H\le \min_i(U_i+D_i)\). Feasibility is monotone: if a sequence works for \(H\), truncating uppers with \(\min(u_i,h)\) works for any lower \(h\). Check one \(H\) by propagating the reachable upper interval through adjacent constraint \(|u_{i+1}-u_i|\le X\). Binary search the best \(H\) and print the 64-bit cost.
