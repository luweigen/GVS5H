Binary search the answer D, noting D ≤ min(K, N−1) because any simple 1→N path has at most N−1 edges. For a fixed D, ask whether we can choose ≤K edges so every 1→N path uses at least D chosen edges. Model this with threshold variables x[v][i] meaning “vertex v has distance/level at least i”; monotonicity, source/sink fixing, and edge Lipschitz constraints become infinite-capacity implications. Each original edge that must cross exactly one level boundary contributes unit cost, so feasibility reduces to a minimum s-t cut in an O(ND)-node layered network. If mincut ≤ K then D is attainable; take the largest such D.
