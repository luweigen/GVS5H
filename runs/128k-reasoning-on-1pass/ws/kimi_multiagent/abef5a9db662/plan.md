Process contests online while maintaining, for every possible initial rating `x`, how many earlier contests would have incremented it (`add[x]`). Before contest `i`, the current rating for initial `x` is `g(x)=x+add[x]`, and `g` is nondecreasing because each contest map is nondecreasing. Therefore the initial ratings affected by contest `i` are exactly a contiguous interval `[l,r]`: the preimage of `[L_i,R_i]` under `g`. Find `l` as the first `x` with `g(x)>=L_i` and `r` as the last `x` with `g(x)<=R_i` using Fenwick binary lifting, then range-add `+1` to `add[l..r]`. After all contests, each query answer is `X+add[X]`, for total `O((N+Q) log M)` with `M=5e5`.
