A 400 number is exactly a square whose square root has precisely two distinct prime factors: if \(N=p^{2a}q^{2b}\), then \(\sqrt N=p^a q^b\). Since \(A\le 10^{12}\), all candidate roots are at most \(10^6\), so we can precompute every integer up to \(10^6\) with exactly two distinct prime factors. Squaring those roots gives all possible 400 numbers up to \(10^{12}\). After sorting the squares, each query is just a binary search for the largest value \(\le A\). This is \(O(10^6\log\log 10^6 + Q\log M)\), easily fast enough.
