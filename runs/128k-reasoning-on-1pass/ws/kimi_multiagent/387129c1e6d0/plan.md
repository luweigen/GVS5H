Track Santa’s position move by move; each move is an axis-aligned segment, so only houses sharing the current row (for L/R) or column (for U/D) can be encountered. Preprocess houses into two indexes: by x-coordinate storing sorted y-values, and by y-coordinate storing sorted x-values. For every segment, binary-search the relevant sorted list for the covered inclusive interval and enumerate only houses inside it. To guarantee each house is counted once and never rescanned, maintain a DSU “next unvisited index” successor structure per sorted line and delete/union houses as they are found. Accumulate the final coordinate with 64-bit-safe arithmetic (Python integers are unbounded) and output it with the distinct count.
