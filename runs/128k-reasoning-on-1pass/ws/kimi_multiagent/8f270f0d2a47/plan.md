Use digit DP to count beautiful numbers `<= x`, then answer `f(r) - f(l-1)`. Since `r < 1e9`, there are at most 9 digits, so digit sum is only `1..81`. For each candidate sum `s`, run a DP over position/tight/started/current sum/product modulo `s`; a number is valid for that `s` if it has started, final sum equals `s`, and product mod `s == 0`. Summing over all `s` gives `f(x)` without storing huge digit products.
