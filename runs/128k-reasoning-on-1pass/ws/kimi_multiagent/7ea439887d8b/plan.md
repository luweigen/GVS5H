Model the process as a shortest-path problem on a doubled state graph: each state is `(vertex, orientation)` where orientation is `0` for original edges and `1` for reversed edges. From `(v,p)` there are move edges of cost `1` along the currently active direction, plus a flip edge to `(v,1-p)` of cost `X`. Build adjacency implicitly from the original edge list so both orientations are available without duplicating too much data. Run Dijkstra from `(1,0)` using 64-bit distances and answer `min(dist[N][0], dist[N][1])`. This is `O((N+M) log N)` and fits the constraints.
