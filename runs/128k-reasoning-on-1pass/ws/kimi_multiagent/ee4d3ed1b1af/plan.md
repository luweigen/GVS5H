Split `p` at the two `*` into three literal parts `a`, `b`, `c`; any match is an occurrence of `a`, then `b` after `a` ends, then `c` after `b` ends. Find all occurrence starts of each literal in `s` using KMP/Z in linear time, treating an empty literal as matching at every boundary `0..n`. Build `nextB[t]` and `nextC[t]`, the earliest start of `b`/`c` at or after position `t`, via reverse scans. For each possible start `i` of `a` (or every boundary if `a` is empty), compute `j=nextB[i+len(a)]`, `k=nextC[j+len(b)]`, and minimize `k+len(c)-i`. Return the minimum or `-1`; total time is `O(|s|+|p|)` and memory `O(|s|)`.
