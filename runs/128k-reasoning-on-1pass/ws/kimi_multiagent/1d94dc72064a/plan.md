Model each index as a chain: the first decrement “opens” it, and later decrements are only passes. The decisive moment is who is forced to open the (N−1)-th index, since the opponent can then open the last index and win. This suggests a parity/invariant solution rather than simulation: handle N=1 separately, otherwise use N parity and the parity of the A_i values. Because the rule is very short, first validate it against a brute-force minimax on small random cases before submitting. Final implementation should be O(N) after input.
