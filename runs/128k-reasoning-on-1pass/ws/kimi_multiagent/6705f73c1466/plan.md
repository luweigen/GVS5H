Collect the 0-based positions `p` of all `1`s; adjacent swaps preserve their relative order, so the final contiguous block is determined by choosing its start `r`. If there are `k` ones at ranks `i=0..k-1`, the cost for start `r` is `sum |p_i - (r+i)| = sum |(p_i-i) - r|`. This is minimized by taking `r` as the median of the transformed values `a_i = p_i - i`. Compute that median and sum absolute deviations in one pass or after sorting the already ordered positions. The algorithm is `O(N)` time and `O(k)` memory, suitable for `N <= 5e5`.
