Build frequency of each value, then compute `cnt[d]` = how many array elements are divisible by `d` using a sieve-style multiple loop. A candidate gcd `d` is feasible iff `cnt[d] >= K`, because any included element divisible by `d` can be extended with `K-1` other multiples of `d`. For every possible value `x`, precompute `best[x]` = the largest feasible divisor of `x`; then each answer is simply `best[A_i]`. Use fast input/output and arrays sized to `max(A)` to stay within limits.
