Split foods by vitamin and run three independent 0/1 knapsack DPs over calories 0..X, storing the maximum vitamin amount achievable for each calorie budget. Convert each DP to “at most c calories” via prefix maxima so each array is nondecreasing. Binary search the answer T; for a candidate T, use binary search on each vitamin’s prefix array to find the minimum calories needed to reach at least T. Feasible iff the three required calorie amounts sum to at most X. Complexity is O(NX + log(total) log X) time and O(X) memory.
