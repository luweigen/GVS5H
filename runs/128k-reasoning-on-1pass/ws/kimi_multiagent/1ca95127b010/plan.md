View each operation as swapping adjacent blocks `0^X` and `1^Y`, equivalently flipping an `X by Y` rectangle in the lattice-path representation of the binary string. Operation A moves a block of `Y` ones left across a block of `X` zeros and strictly decreases the one-position sum/area, so orienting rewrites only by A gives a terminating normalization process. First cheap necessary filters are equal zero/one counts and the induced modular invariants such as residue counts mod `gcd(X,Y)` / area mod `XY`. The core equivalence test should reduce both strings to a canonical run/token normal form where no `0^X1^Y` redex remains, then compare those forms. If local confluence fails in the proof step, fall back to a token-rewriting equivalence search guided by the same invariants rather than naive string simulation.
