Sort intervals by right endpoint while preserving original indices, then compute for each interval the previous compatible interval via binary search with strict non-overlap (`prev_r < cur_l`). Run DP over sorted intervals and `k=0..4`, where each state stores the best `(weight, sorted_tuple_of_original_indices)`; primary key is maximum weight, tie-break is lexicographically smallest index tuple. Because weights are positive, storing only the best tuple per `(i,k)` is sufficient, and tuples have length at most 4 so comparisons/insertions are O(1). Transition each state by skipping the current interval or taking it after the best compatible previous state. The answer is the best among states with up to 4 intervals, returned as a list.
