Sort A, B, C in descending order so the value F(i,j,k)=A_iB_j+B_jC_k+C_kA_i is monotone nonincreasing as any index increases. The triples form a 3D monotone grid rooted at (0,0,0), and moving from a triple to (i+1,j,k), (i,j+1,k), or (i,j,k+1) never increases the value. Use best-first search with a max-heap from the root, marking visited index-triples to avoid duplicates. Pop exactly K times; the K-th popped value is the K-th largest. This works because any not-yet-generated triple has a generated predecessor with value at least as large, so the heap frontier always contains the largest remaining candidate. Complexity is O(N log N + K log K), memory O(K), with K≤5×10^5.
