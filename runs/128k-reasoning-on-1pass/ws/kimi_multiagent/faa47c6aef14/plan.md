Treat red and blue balls as tokens that must travel along the permutation cycles of P and Q respectively. A color is feasible only if every initial ball of that color lies in the cycle containing X; otherwise print -1. For each color, only the farthest ball from X matters, because operating that whole path automatically carries nearer same-color balls. The problem then becomes finding the shortest common supersequence of two ordered vertex-paths: the red path to X under P and the blue path to X under Q. Since each path has distinct vertices, their LCS can be computed by mapping one path to positions in the other and running LIS.
