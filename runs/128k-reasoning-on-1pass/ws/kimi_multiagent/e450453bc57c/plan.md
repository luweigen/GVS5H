For any fixed length-`x` window, the cheapest way to make it constant is to move every value to the window median, costing the sum of absolute deviations; compute this cost for every possible start index with a sliding median structure. Because all costs are nonnegative, “at least k” is equivalent to choosing exactly `k` non-overlapping windows. Then run a small DP over window starts: selecting a window starting at `s` forbids the previous selected window from starting after `s-x`. Since `k <= 15`, an `O(n log x + nk)` solution is fast enough for `n <= 1e5`. Use 64-bit integers and INF sentinels for unreachable states.
