
## ideation
Core difficulty: the palindrome condition couples the two ends of the path, and paths may repeat vertices, so a normal single-source shortest-path DP is insufficient. The natural state is an ordered pair `(l, r)` representing the shortest palindrome-labeled walk from `l` to `r`. Base cases are length `0` for `(v, v)` and length `1` for every direct edge. The key recurrence is: if `a -> l` and `r -> b` have the same label, then `dist[a][b] <= dist[l][r] + 2`. This is essentially shortest paths/CFL-reachability over an `N^2`-state product graph with nonnegative increments.

Main pitfalls: forgetting the empty string for `i == j`; treating paths as simple; mishandling self-loops; assuming BFS by path length works directly when transitions add `2` from base states of cost `0/1`; and performance. A naive four-loop relaxation can be `O(N^4)` or worse in Python if implemented carelessly, though `N = 100` is small enough with label-bucketed edges and a worklist/Dijkstra. Need a clear termination argument: once a pair-state has its minimal distance, repeating that state cannot improve the answer.

## worker: Write the complete Python solution: parse input, b
- **Model**: `dist[l][r]` = shortest walk from `l` to `r` whose label string is a palindrome. Base cases: `dist[v][v] = 0` (empty string) and `dist[u][v] = 1` for each direct edge (single letter). Recurrence: a palindrome of length ≥ 2 is `c + palindrome + c`, so for edges `a->l` and `r->b` with the same label, `dist[a][b] <= dist[l][r] + 2`.
- **Algorithm**: Dijkstra over the `N²` pair-states, implemented with Dial buckets since every transition adds exactly 2 and base distances are 0/1. States are processed in nondecreasing distance, so the first time a pair `(a, b)` is reached is its final shortest distance (all transition costs are positive; any relaxation into a state comes from a layer exactly 2 smaller, processed earlier).
- **Performance**: edges are bucketed by label; per state `(l, r)` we only iterate labels in `in_mask[l] & out_mask[r]` and predecessors `a` of `l`. Bitsets (Python ints, N=100) let us compute all newly-reached `b` for a given `a` in one `AND`/`NOT`. Total work is `O(Σ_{l,r} indeg(l)) = O(N·M) ≤ O(N³)` big-int operations (~10⁶ for N=100) plus `O(N²)` bit extractions — easily fast enough, avoiding the naive `O(N⁴)`.
- **Correctness sketch**: induction on distance. Base layers 0/1 are exactly the length-0/1 palindromes. When state `(l, r)` is popped at distance `d`, `d` is its true shortest palindrome length; extending by matching labels on both ends yields exactly all palindromes of length `d+2` whose inner palindrome is `(l, r)`, and every longer palindrome decomposes this way. Unreached pairs have no palindrome walk → `-1`.
