Because `target.length <= 4`, compress targets into bitmasks and enumerate every nonempty subset; each subset has an LCM that a single `nums` element could be incremented to cover. For each number and each subset, compute the cheapest increments to reach the next multiple of that subset’s LCM: `(L - x % L) % L`. Then run a bitmask DP over the 16 target states, processing each `nums` element at most once and relaxing `dp[mask | sub]` with that element’s subset cost. The answer is `dp[full_mask]`. This avoids invalid reuse of one array element for multiple target groups and is easily fast enough: about `5e4 * 16 * 16` transitions.
