Because the array is already sorted and sizes are positive, any valid top must be strictly smaller than its bottom, so we can treat smaller-index mochi as candidate tops and larger-index mochi as candidate bottoms. A key feasibility fact is that K pairs are possible iff the K smallest mochi can be matched to the K largest mochi with `2*A[i] <= A[N-K+i]` for all `i < K`. This allows either binary search on K with an O(N) check, or a direct O(N) two-pointer greedy using the first half as tops and scanning the second half for the earliest valid bottom. The greedy advances the bottom pointer when the current smallest unused top cannot fit, and consumes both when it can. The answer is the number of consumed tops, bounded by `N//2`.
