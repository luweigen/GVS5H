Process insertions in reverse while maintaining the set of still-unassigned final positions. Key invariant: after deleting all values greater than i from the final array, value i is exactly the P_i-th remaining element, so i must occupy the P_i-th currently empty final slot. Use a Fenwick tree initialized with all N positions empty to support “find kth empty” and “mark occupied” in O(log N). Fill ans[pos] = i for i = N down to 1, then print ans[1..N]. This avoids O(N^2) list insertion and fits N ≤ 5×10^5.
