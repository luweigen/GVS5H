Only values `<= threshold` can have edges, because `lcm(a,b) >= max(a,b)`; every value `> threshold` is its own component. For any `L <= threshold`, all present numbers that divide `L` are pairwise connected, since their lcm divides `L`. Conversely, any edge with `lcm(x,y)=L<=threshold` is captured when processing that `L`. So build DSU over present values `<=T`, and for each multiple `L` union all present divisors of `L` together using a `first[L]` representative. Finally count DSU roots among small values plus the number of large values.
