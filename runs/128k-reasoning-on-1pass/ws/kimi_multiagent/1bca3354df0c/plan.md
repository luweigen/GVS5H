Treat “no odd cycle” as “graph stays bipartite,” so each connected component has a fixed two-coloring up to flip. A move inside a component only fills a missing opposite-color edge, while a move between components merges them and fixes their relative flip; the game ends at one complete bipartite component K_{A,B}. The total number of moves for a terminal coloring is AB-M, so for odd N the parity is fixed by M, and for even N it reduces to who controls the parity of the final color-class size A. Use a parity DSU to extract component side sizes, then classify components by size/side parity and solve the small parity game over odd-sized components.
