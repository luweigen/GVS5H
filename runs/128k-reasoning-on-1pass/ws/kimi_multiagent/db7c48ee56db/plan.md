Exploit the constraint \(\binom NK\le 10^6\) by enumerating combinations on the smaller side: let \(r=\min(K,N-K)\). If \(r=K\), directly maximize the XOR of each chosen \(K\)-subset; otherwise enumerate complements of size \(r\) and convert via \(\text{chosen}=\text{total\_xor}\oplus\text{complement\_xor}\). Generate combinations lexicographically with an index array and compute each subset XOR by summing its \(r\) elements; under \(\binom Nr\le10^6\) this is easily fast enough. Use Python integers for 60-bit values and handle \(r=0\) separately.
