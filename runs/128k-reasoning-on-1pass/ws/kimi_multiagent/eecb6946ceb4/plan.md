Build a 0/1 indicator array over the value domain `1..max(S)`, then count 3-term arithmetic progressions by their middle element `B`. For each present `B`, we need unordered pairs `(A,C)` with `A+C=2B`, `A<C`, both present. This is exactly a self-convolution problem: if `P` is the indicator polynomial, `conv[2B]` counts ordered pairs summing to `2B`, including `(B,B)`, so each present `B` contributes `(conv[2B]-1)//2`. Use FFT/NTT convolution over length about `2*max(S)+1` for `O(M log M)` time, with careful rounding and 64-bit accumulation. The final answer is the sum of contributions over all `B in S`.
