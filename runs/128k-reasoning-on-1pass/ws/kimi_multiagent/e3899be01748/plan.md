Scan left to right and count, for each end index `j` with nonzero digit `d`, how many starts `i` make `s[i..j] ≡ 0 mod d`. Split digits by structure: `1,3,7,9` are coprime to 10, so use normalized prefix remainders `P[t] * inv(10)^t mod d` and count equal values; `6` reduces to the mod-3 prefix test since evenness is automatic; `2,5` are always valid; `4,8` depend only on the last 2 or 3 digits for long substrings, with short lengths brute-forced. Maintain small frequency maps per modulus as the scan advances, add contributions before inserting the current prefix, and sum everything in O(n).
