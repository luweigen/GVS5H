Normalize every conflict to `(l, r)` with `l < r` and group by `r`, keeping the largest left endpoint, second largest, and multiplicity of the largest to handle duplicates. For any fixed set of pairs, valid subarrays equal `sum_{end=1..n} end - prefMaxLeft[end]`, where `prefMaxLeft[end]` is the maximum `l` among pairs with `r <= end`. Removing a pair only helps if it is the unique maximum for its right endpoint and that value is a new prefix record; otherwise its gain is zero. For each such record, find the next right endpoint whose maximum left is at least as large, then compute how much the prefix cap drops over that suffix interval using a monotonic stack / Cartesian-tree prefix-max sum. The answer is the baseline valid count plus the maximum nonnegative gain, since exactly one pair must be removed.
