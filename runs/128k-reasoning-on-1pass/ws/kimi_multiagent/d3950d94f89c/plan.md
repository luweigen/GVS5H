Root the tree at 0 and run a DFS that maintains the current root-to-node stack, prefix edge-length sums, and the leftmost valid start index for a unique-value downward window. For each node at depth `d`, update the last occurrence of `nums[node]`; if it appeared before in the current stack, move the window left boundary past that previous occurrence. The best special path ending at this node is `pref[d] - min(pref[a])` over start depths `a` in the valid window `[left, d]`, breaking ties by larger `a` to minimize node count. Use a segment tree/Fenwick over depths with push/pop updates during DFS to query that minimum in `O(log n)`. Track the global best by `(length, -nodes)` and restore all state on backtracking. Total complexity is `O(n log n)` time and `O(n)` space.
