Build the required final mapping from each character in `S` to the corresponding character in `T`; if one source character must become two different targets, answer `-1`. Ignore self-mappings and form a directed graph of necessary renames `a -> b`. Each weak component is either acyclic, costing its number of edges, or contains exactly one directed cycle, which needs one extra temporary rename to break the cycle. A cycle is breakable only if some lowercase letter never appears in `S` to act as an empty buffer; if all 26 letters occur and a cycle exists, it is impossible. Sum component costs for the minimum operations in `O(N + 26)`.
