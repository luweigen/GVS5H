For two distinct blocks, the optimal route is governed by the widest path value `M`: the maximum, over all grid paths between the blocks, of the minimum building height on that path. If `M >= min(Y,Z)`, Takahashi can travel at the lower endpoint floor and pay only `|Y-Z|`; otherwise he must descend to floor `M`, cross there, and pay `Y+Z-2*M`, so the answer is `max(|Y-Z|, Y+Z-2*M)`. The all-pairs widest-path values are preserved by any maximum spanning tree of the grid with edge weight `min(F_u,F_v)`. Thus build one MaxST, preprocess minimum edge on tree paths with binary lifting, and answer each query in logarithmic time. Same-block queries are just `|Y-Z|`.
