Model the array by its adjacent equality pattern: choose exactly k of the n-1 adjacent gaps to be equal, which is C(n-1, k). Those equal gaps merge positions into n-k runs, and each run boundary must change value. The first run has m choices, while every later run has m-1 choices, giving m * (m-1)^(n-k-1).
