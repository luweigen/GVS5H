Model the kept Snowflake Tree as an induced connected subtree determined by its red center `r`, a set of `x` blue neighbors of `r`, and for each blue vertex `b`, exactly `y` kept leaf neighbors excluding `r`. For a fixed center `r`, each neighbor `b` can serve as a blue vertex only if `deg(b)-1 >= y`, since it needs `y` leaves other than `r`. For fixed `r`, take values `a_b = deg(b)-1` for neighbors `b`; sorting them descending gives candidates `1 + x * (a_x + 1)` when choosing the `x` best blue vertices and setting `y = a_x`. Maximize this kept size over all centers and feasible `x`, then answer `N - max_kept`. The total work is bounded by sorting adjacency-derived values, `O(sum deg log deg)`, which fits `N <= 3e5`.
