For a chosen value `x`, deleting all occurrences turns the array into the concatenation of the maximal “gaps” of non-`x` elements between occurrences of `x`. So the answer for `x` is just the maximum subarray sum of those gap ranges concatenated in order. Build one segment tree where each node stores `(sum, best_prefix, best_suffix, best_subarray)` for a range, allowing O(log n) gap queries and O(1) concatenation of gap aggregates. Across all distinct values, the total number of gaps is `sum(freq[x] + 1) = n + distinct <= 2n`, so evaluating every possible deletion plus the no-deletion case is O(n log n).
