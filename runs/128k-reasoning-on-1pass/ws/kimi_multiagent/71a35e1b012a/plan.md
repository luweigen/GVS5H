Model each chosen nonzero operation as contributing either the interval [L_i,R_i] (op1) or its complement (op2); since writes only set 1s, order is irrelevant and the goal is pure union coverage. Key fact for intervals on a line: if coverage is possible, it is possible with at most 2 operations. Cost 1 is exactly an interval [1,N]. Cost 2 happens iff there is a pair of distinct intervals that either (a) as op1s touch/overlap from 1 to N, (b) are disjoint and used as op2s, or (c) are nested/equal with the outer as op1 and inner as op2. Detect these three pair cases in O(M log M), reconstruct choices, otherwise print -1.
