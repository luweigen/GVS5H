The operation set is exactly Levenshtein edit distance, so the task is to decide whether `dist(S,T) <= K`. First reject immediately if `abs(len(S)-len(T)) > K`, then trim equal prefixes/suffixes to shrink the effective strings. Because `K <= 20`, run a banded edit-distance DP only over diagonals `|i-j| <= K` with rolling rows and early abandonment when every cell in a row exceeds `K`. If the final banded distance is at most `K`, print `Yes`, otherwise `No`. In Python, keep the inner loop tight using lists/`array` or use a bit-parallel Myers-style implementation if the simple banded DP is too slow.
