The game is played on a bipartite graph, and players take turns adding edges that preserve the bipartite property. The game ends when no more edges can be added, which occurs when the graph becomes a complete bipartite graph. The maximum number of edges in a complete bipartite graph with $N$ vertices is $\lfloor N^2 / 4 \rfloor$. Since the initial graph is bipartite with $M$ edges, the total number of moves in the game is fixed at $\lfloor N^2 / 4 \rfloor - M$. The winner is determined by the parity of this number: if it is odd, the first player (Aoki) wins; if it is even, the second player (Takahashi) wins.
