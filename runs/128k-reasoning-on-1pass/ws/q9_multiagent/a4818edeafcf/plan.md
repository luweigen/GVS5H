The problem asks us to split the array $A$ into three non-empty subarrays to maximize the sum of distinct element counts in each subarray. We can precompute the number of distinct elements in prefixes ($S_i$) and suffixes ($T_j$). The middle subarray's distinct count $D(i+1, j)$ can be expressed as the number of elements $k \in [i+1, j]$ such that the previous occurrence of $A_k$ is before $i+1$. This allows us to iterate over the first split point $i$ and maintain the values for the second split point $j$ using a Segment Tree that supports range updates and range maximum queries. Specifically, as we iterate $i$, we activate indices $k$ where $prev[k] = i$, and update the Segment Tree to reflect their contribution to the distinct count for valid $j$'s.
