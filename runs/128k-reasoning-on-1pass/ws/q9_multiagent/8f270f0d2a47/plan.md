Since the range $[l, r]$ can be up to $10^9$, a linear scan is infeasible, so we will use a Digit DP approach to count valid numbers up to $n$. We will define a helper function `count_upto(n)` that iterates through all possible digit sums $s$ from 1 to 81, as the maximum sum for a number less than $10^9$ is 81. For each sum $s$, we run a recursive Digit DP to count numbers $\le n$ with digit sum $s$ where the product of digits is divisible by $s$. We optimize performance by memoizing states where the tight constraint is false, which are reusable across different digit positions for a given $n$. The final answer is derived by computing `count_upto(r) - count_upto(l - 1)`, handling the edge case where $l=1$.
