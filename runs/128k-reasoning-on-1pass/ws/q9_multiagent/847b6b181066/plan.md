The problem requires simulating the movement of smoke on a grid with a campfire at (0,0) that regenerates smoke if the cell is empty. We need to determine if smoke exists at a target cell $(R, C)$ at specific time points. By analyzing the movement, we can observe that a smoke particle born at time $b$ at $(0,0)$ will be at position $D(t) - D(b)$ at time $t$, where $D(t)$ is the displacement of the original smoke particle after $t$ steps. Smoke exists at $(R, C)$ at time $t$ if and only if there exists a birth time $b < t$ such that $D(t) - D(b) = (R, C)$, which simplifies to checking if $D(t) - (R, C)$ has been visited by the original smoke particle at any time $0 \le b < t$. We can solve this efficiently by simulating the path of the original smoke particle, storing visited positions in a hash set, and checking the condition for each time step.
