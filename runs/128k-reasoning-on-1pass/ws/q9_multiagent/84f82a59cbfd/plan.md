A 400 number $N$ must be a perfect square of an integer $Y$ that has exactly 2 distinct prime factors. Since $A \le 10^{12}$, we only need to consider $Y \le 10^6$. We precompute the number of distinct prime factors for all integers up to $10^6$ using a sieve. We construct a lookup table that stores the largest valid $Y$ for any limit $K \le 10^6$. For each query, we compute $K = \lfloor\sqrt{A}\rfloor$, retrieve the precomputed $Y$, and output $Y^2$.
