Fix the second cut `j` and let `pre[i]=distinct(A_1..A_i)`, `suf[k]=distinct(A_k..A_N)`; the answer is `max_{2≤j≤N-1} ( suf[j+1] + max_{1≤i<j} f_j(i) )` where `f_j(i)=pre[i]+distinct(A_{i+1..j})`. Going from `j-1` to `j`, the array `f` changes by: activating a new position `i=j-1` with value `pre[j-1]`, then **adding 1 to the whole suffix** `[p, j-1]`, where `p=max(1, last occurrence of A_j before j)`; so we only need the global maximum `L` of `f` under "append at right" + "suffix +1" operations. Maintain the *strict suffix maxima* (records) of `f` as a stack: values strictly decrease left→right, `L` = value of the leftmost record `head`, and each record stores `d = value − value(next record)` (all `d ≥ 1`). A suffix +1 from `p` does: if `head ≥ p` then `L += 1`, else find `q` = last alive record with position `< p`, do `d[q] -= 1`, and if it hits 0 delete `q` (linked list + DSU "previous alive" with path compression); appending `j-1` costs at most one pop because `pre[j-1] ≤ pre[j-2]+1` = current tail value. This gives an O(N·α) pure-Python solution; a lazy segment-tree (range add / global max) version is the fallback/reference.
