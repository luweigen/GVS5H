Reduce the game to a counting/parity problem: the terminal position is always a complete bipartite graph $K_{a,b}$ ($a+b=N$) containing $G$, so the total number of moves is exactly $a\cdot b-M$, and Aoki (first) wins iff that is odd. If $N$ is odd, $a\cdot b$ is always even, so the winner depends only on $M \bmod 2$. If $N$ is even, $a\cdot b\equiv a \pmod 2$, and the parity of $a$ is only influenced by the orientations chosen when two **odd-size** components (groups) get merged; a merge of two odd groups is "free" (either relative orientation, i.e. either parity, is achievable) unless both groups are single isolated vertices. Analyzing the resulting game on states $(m=K/2$ pairs of odd components, $I$ = number of isolated vertices, $\Phi=\sum x_iy_i-M$ = number of currently addable internal edges, $M\bmod2)$ yields: with $I=2m$ → mover wins iff $\Phi+m$ odd; with $I\in\{2m-2,2m-1\}$ → mover always wins; otherwise ($I\le 2m-3$) → mover wins iff $M$ odd (this also covers $K=0$, where $m=I=0$). Workers must brute-force verify this classification before shipping the $O(N+M)$ implementation.
