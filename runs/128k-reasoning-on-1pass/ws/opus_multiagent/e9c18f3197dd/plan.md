Since `len(target) ≤ 4`, there are at most 16 subsets of targets; a single element of `nums` can be raised to cover any *subset* S simultaneously at cost `(L - num % L) % L` where `L = lcm(S)`. Precompute `lcm` for all 16 subsets once (values fit easily in Python ints, ≤ 10^16). Then run a subset‑cover DP over the array: `dp[mask]` = minimum operations to have covered the targets in `mask`, processing elements one at a time so each element contributes to at most one subset. Transition per element: `ndp[mask | S] = min(ndp[mask|S], dp[mask] + cost(num, S))` over all masks and all subsets S, giving O(n · 16 · 16) ≈ 1.3·10^7 operations — fast enough. Answer is `dp[(1<<m)-1]`.
