Since K ≤ 20 but |S|,|T| ≤ 5·10⁵, an O(|S|·K) band DP in pure Python (~2·10⁷ steps) is risky, so the main line of attack is Ukkonen/Myers' diagonal "furthest‑reaching point" algorithm: for each edit budget d = 0…K and each diagonal k = j−i ∈ [−K, K], keep fr[d][k] = the largest i reachable with exactly d edits, extended greedily by the longest common extension (LCE) of S[i:] and T[i+k:]. Transitions are fr[d][k] = max(fr[d−1][k]+1 (substitute), fr[d−1][k+1]+1 (delete), fr[d−1][k−1] (insert)), followed by an LCE jump; answer "Yes" iff for some d ≤ K we get fr[d][m−n] ≥ n (i.e. we reach (n, m)). This needs only ≈(2K+1)·K ≈ 900 LCE queries, each answered in O(log n) by binary search on precomputed polynomial prefix hashes (mod 2⁶¹−1, random base) of S and T. Cheap pre-filters first: if | |S|−|T| | > K print "No"; if S == T print "Yes"; optionally strip the common prefix/suffix to shrink input. Keep a simple banded DP implementation as a cross-check/fallback for correctness testing on small inputs.
