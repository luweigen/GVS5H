Key theory: two orientations yield the same in‑degree sequence iff they differ by reversing directed cycles, and by Stanley's theorem the number of achievable score (in‑degree) vectors equals T_G(2,1) = the number of spanning **forests** (acyclic edge subsets) of G. So we must count acyclic edge subsets of "cycle C_N + hub N joined to the marked vertices (s_i=1)". Any cycle of G is either the whole C_N or hub + two spokes + the cycle path between them; hence if we pick a nonempty set T of spokes, the marked vertices in T cut the cycle into arcs, and the forest condition is exactly "each arc misses ≥1 of its L edges" → weight ∏(2^{L}-1); if T=∅ the count is 2^N−1. Therefore answer = (2^N−1) + Σ_{T≠∅} ∏_j (2^{L_j}−1), a cyclic-composition sum over the k gaps between consecutive marked positions, computable in O(N) by prefix-sum DP because f(L)=2^L−1 splits as 2^{P_b}·2^{−P_a} − 1 (keep running sums of D[i]·2^{−P_i} and D[i]). Handle the circularity by splitting into "gap-index 0 selected" (plain linear composition DP D[·]) and "not selected" (aggregate DPs X[b]=Σ_{a≤b}E_a[b]2^{P_a}, Y[b]=Σ_{a≤b}E_a[b], each with the same O(1)-per-step recurrence), giving answer = (2^N−1) + D[k] + 2^N·W − V with W=Σ X[b]2^{−P_b}, V=Σ Y[b]. Special case k=0 → 2^N−1; k=1 → 2(2^N−1). Verify everything by brute force on small inputs, then optimize for N=10^6 in Python.
