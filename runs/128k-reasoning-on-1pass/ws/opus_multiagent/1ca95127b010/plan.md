Both operations are inverses of each other (A turns `0^X 1^Y` into `1^Y 0^X`, B does the reverse), so reachability is an *equivalence relation* generated by swapping an adjacent block of X zeros with a block of Y ones. Encode the string by, for each `1`, the number of zeros before it (`z_j`), and for each `0`, the number of ones before it (`o_i`); a swap changes exactly Y of the `z_j` by ∓X and exactly X of the `o_i` by ±Y, never reordering them. Hence the sequences `(z_j mod X)_{j=1..K}` and `(o_i mod Y)_{i=1..Z}` (plus the counts of ones/zeros) are invariants, and the conjecture (to be validated by brute force) is that they are **complete**: S ~ T iff same number of ones and identical residue sequences. Note the degenerate cases are automatically covered: if `X+Y > N` then `X > Z` or `Y > K`, so one residue sequence is injective and forces exact equality of the strings. Deliverable: an O(N) solution using prefix sums (numpy for speed at N = 5·10^5), backed by an exhaustive small-case BFS validation.
