Reduce visibility to a geometry condition: building *i* is visible from (0,h) iff the segment from (0,h) to the **top** (X_i,H_i) stays strictly above every building j with X_j < X_i (lower target points are strictly worse, so the top is optimal). Solving `h·(1−X_j/X_i) + H_i·X_j/X_i > H_j` gives the requirement `h > (H_j·X_i − H_i·X_j)/(X_i − X_j)`, which is exactly the y‑intercept at x=0 of the line through points (X_j,H_j) and (X_i,H_i). Hence the answer A = max over all pairs j<i of that intercept; print A if A ≥ 0, else −1 (N=1 ⇒ −1). Writing the intercept as `H_j − X_j·slope(j,i)`, for each left point j we only need the **minimum slope** to points on its right, which is obtained by sweeping right‑to‑left maintaining the lower convex hull and popping from the front (amortized O(N) total). All comparisons are done with exact integer arithmetic (cross‑multiplication) so the sign of A and the choice of the maximizing pair are exact; only the final division is floating point.
