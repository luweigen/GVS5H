Model the coloring by the per‑row prefix length `a_r` (number of black cells in row r). The row condition is automatic; the column condition (every column is a black prefix from the top) holds exactly when `a_1 ≥ a_2 ≥ … ≥ a_N`, i.e. the black region is a Young diagram. A given black cell (x,y,B) forces `a_x ≥ y` (lower bound L_x), a white cell (x,y,W) forces `a_x ≤ y−1` (upper bound U_x); unmentioned rows have L=0, U=N. A non‑increasing sequence within [L_x,U_x] exists iff, setting `a_x` = suffix maximum of L over rows ≥ x, we have that value ≤ U_x for every row — equivalently L_x ≤ U_x for all x and L_{x2} ≤ U_{x1} for all x1 < x2. So: aggregate constraints per row (only the ≤2·10^5 mentioned rows matter), sort rows, scan from the bottom row upward maintaining the running max of L, and compare with U.
