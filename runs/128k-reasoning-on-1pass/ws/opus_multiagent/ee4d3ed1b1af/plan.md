Split `p` on `'*'` into three literal parts `a`, `b`, `c` (any may be empty); a substring matches iff it contains `a` as a prefix, then `b` somewhere after it, then `c` as a suffix, in non‑overlapping left‑to‑right order. Use KMP (or Z‑algorithm) to compute, in O(n+m), the sorted list of start positions of each non‑empty part in `s`; if a part is empty its "occurrence" list is every position `0..n` (handled implicitly rather than materialized). Then iterate over each occurrence `j` of the middle part `b`: binary‑search the largest occurrence `i` of `a` with `i + |a| <= j`, and the smallest occurrence `k` of `c` with `k >= j + |b|`, and take `min(k + |c| - i)`. Empty parts collapse to trivial bounds (`i = j` for empty `a`, `k = j+|b|` for empty `c`), and if all three parts are empty the answer is 0. Overall complexity O(n log n) time, O(n) memory; return -1 if no valid triple exists.
