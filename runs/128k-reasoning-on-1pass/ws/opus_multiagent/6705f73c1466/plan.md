This is the classic "gather all 1s together with adjacent swaps" problem. Collect the 0-indexed positions `p_0 < p_1 < ... < p_{k-1}` of all 1s; moving them into a contiguous block means mapping `p_j -> t + j` for some target start `t`, and the minimum number of adjacent swaps equals the total displacement `Σ |(p_j - j) - t|` (relative order of 1s never needs to change, and 0s move implicitly). Setting `b_j = p_j - j`, the cost is minimized by choosing `t` as the median of the `b_j` array, so the answer is `Σ |b_j - median(b)|`. The `b` array is already non-decreasing, so the median is just the middle element—no sorting needed. Implement with fast stdin reading and an O(N) loop (or numpy) to stay within limits for N = 5·10⁵; the answer can exceed 32-bit so rely on Python big ints.
