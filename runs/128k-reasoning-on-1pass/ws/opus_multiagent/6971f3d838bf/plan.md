Key reduction: removing a value `x >= 0` can never increase the maximum subarray sum (it only deletes non‑negative contributions), so the answer is `max(Kadane(nums), max over distinct negative x of Kadane(nums without x))`. Recomputing Kadane per distinct negative value is O(n·d) and too slow, so instead build a segment tree over the original array where each node stores `(total, bestPrefix, bestSuffix, bestSubarray)`. For a fixed value `x` with occurrence positions `p1<…<pk`, the array after removal is the concatenation of the gap ranges `[0,p1-1], [p1+1,p2-1], …, [pk+1,n-1]`; merging those `k+1` segment-tree queries with the standard merge gives that array's best subarray in O(k log n). Since the total number of occurrences over all distinct values is `n`, total cost is O(n log n). Handle the "array must remain non-empty" rule by skipping any `x` whose removal empties the array (i.e. all merged segments empty), and guard empty ranges with a neutral element (`sum=0`, prefix/suffix/best = -inf).
