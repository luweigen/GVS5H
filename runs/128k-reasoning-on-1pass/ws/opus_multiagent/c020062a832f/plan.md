Compute the answer for k=0 with a standard BIT/Fenwick inversion count over values in [0,M), then derive each subsequent answer incrementally. Going from k to k+1, every element increases by 1 except those currently equal to M−1, which wrap to 0; relative order of all non-wrapping elements is unchanged, so only the wrapping elements' pairs change. For a wrapping element at position p (1-indexed) that is the r-th (1-indexed) among the c wrapping elements sorted by position: it loses (n−p)−(c−r) inversions (it was the max, now the min, so all pairs to its right vanish) and gains (p−1)−(r−1) inversions (all elements to its left are now strictly positive except the other wrapped ones). Summing over the group gives the closed form delta = 2·sumPos[v] − cnt[v] − cnt[v]·N where v = (M−1−k) mod M is the value group that wraps at step k. So precompute cnt[v] and sumPos[v] for every value, then produce all M answers in O(N log N + M) total.
