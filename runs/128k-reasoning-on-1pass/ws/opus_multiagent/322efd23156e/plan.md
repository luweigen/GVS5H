Split the foods by vitamin type and run three independent 0/1 knapsacks over calorie budget 0..X, where `f_v[c]` = maximum units of vitamin `v` obtainable with total calories ≤ c (each `f_v` is non-decreasing, with `f_v ≡ 0` if no food of that type exists). Since `min` is associative, first merge vitamins 1 and 2 into `h[c] = max_{c1+c2 ≤ c} min(f1[c1], f2[c2])`, then answer = `max_{c ≤ X} min(h[c], f3[X-c])`. The merge is O(X²) = 25·10⁶ pairs, which must be vectorized with NumPy (loop over `c1`, update `h[c1:] = maximum(h[c1:], minimum(f1[c1], f2[:X-c1+1]))`) or done with a two-pointer/binary-search using monotonicity, to stay fast in Python. The knapsack itself is also vectorized: for each item `(a,c)`, `dp[c:] = maximum(dp[c:], dp[:-c] + a)`, giving O(N·X) element operations in NumPy. Use int64 to avoid overflow (max total ≈ 5000·2·10⁵ = 10⁹, still fine). Edge cases: any vitamin missing ⇒ answer 0; X smaller than every item's calories ⇒ answer 0.
