Model the problem as a BFS over the N² states (i, j) meaning "shortest palindromic-labelled path from i to j". Base states: dist(i,i)=0 and dist(i,j)=1 whenever C[i][j] is a letter. The only expansion rule is peeling one character off both ends: from state (k,l) with distance d we reach (i,j) with distance d+2 whenever C[i][k] = C[l][j] (same letter). Since every transition adds exactly 2 and initial distances are 0 or 1, a single FIFO queue seeded with all distance-0 states followed by all distance-1 states yields correct BFS order. To keep it fast in Python, keep an "unvisited columns" bitmask Unvis[i] per row and precompute, for each vertex k, the in-neighbour lists grouped by letter (in_by_char[k][c]) and, for each vertex l, out-neighbour bitmasks per letter (out_mask[l][c]); processing a state costs only O(indeg(k)) bigint ops, so total work is ≈10⁶ operations.
