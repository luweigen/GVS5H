Model the set as a 0/1 indicator array `f` of length `M = 1_000_001` where `f[v] = 1` iff `v ∈ S`. A fine triplet is a pair `A < C` with `A + C = 2B` and `B ∈ S`, so the self-convolution `g = f * f` (ordered pairs summing to each value) gives, for each `B ∈ S`, `g[2B]` ordered pairs including the degenerate `A = C = B`; thus the count for that `B` is `(g[2B] - 1) / 2`. Compute `g` with a real FFT (numpy `rfft`/`irfft`) at length `2^21 ≥ 2M - 1`, round to integers, and sum over all `B ∈ S`. Precision is safe: convolution values are ≤ 10^6 and float64 FFT error at this size is ~10^-3, well under 0.5, but round with `np.rint` before casting to int64. I/O must be fast (`sys.stdin.buffer.read` + `np.frombuffer`/`np.fromstring` parsing) since N can be 10^6, and the final answer can reach ~10^11 so use Python int / int64 accumulation.
