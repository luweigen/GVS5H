Model reachability with a rolling bitmask over the last `B` squares: bit `i` of `mask` means square `x-i` is reachable. One step to `x+1` sets the new low bit to `1` iff `((mask >> (A-1)) & ((1<<(B-A+1))-1)) != 0` and `x+1` is not bad, then `mask = ((mask<<1) | newbit) & ((1<<B)-1)`. Bad intervals of length `len` are handled in O(1) since every new bit is 0: `mask = (mask << len) & full` (and if that is 0 the answer is immediately `No`). Free stretches can be astronomically long (up to 1e12), but the map `mask -> step(mask)` is deterministic, so we iterate with dictionary-based cycle detection and reduce the remaining length modulo the detected period (the transient/period is tiny in practice: with `A<B` the mask saturates to all-ones within ~O(B·A/(B-A)) steps, with `A==B` it becomes periodic with period `A ≤ 20`). Start at `x=1` with `mask=1`, walk through the given (already sorted, disjoint) intervals alternating free-advance / bad-skip, finish with the free stretch up to `N`, and print `Yes` iff bit 0 is set (i.e. `N` is reachable).
