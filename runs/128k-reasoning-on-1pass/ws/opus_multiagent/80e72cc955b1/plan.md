Reduce the problem to a counting formula: for a value x ≥ 1, the number of divide-by-4 steps needed to reach 0 is d(x) = floor(log4(x)) + 1. Each operation reduces the total step-count by at most 2 (it applies one step to two elements), and since l < r there are at least two elements and no single element dominates, the answer per query is ceil(S/2) where S = Σ_{x=l}^{r} d(x). Compute S via a prefix helper f(n) = Σ_{x=1}^{n} d(x), evaluated by grouping numbers into blocks [4^(k-1), 4^k − 1] (only ~16 blocks for n ≤ 1e9), giving O(1)-ish per query and O(q·16) overall. Finally sum ceil(S/2) = (S+1)//2 over all queries.
