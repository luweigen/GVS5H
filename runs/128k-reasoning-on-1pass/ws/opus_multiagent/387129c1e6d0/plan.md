Simulate the walk exactly (Python ints handle the up to ~2·10¹⁴ coordinates), while answering, for each move, a "which houses lie on this axis-parallel segment" query. Bucket the houses twice: by x-coordinate (each bucket holds its y's sorted) and by y-coordinate (each bucket holds its x's sorted); a vertical move only touches the bucket for the current x, a horizontal move only the bucket for the current y. Inside the relevant bucket, binary-search the index range covered by the segment and enumerate the still-unvisited houses there; every enumerated house is marked visited globally and logically deleted from *both* buckets, so total enumeration work is O(N α) amortized. Implement deletion with a "next alive index" DSU (path-compressed pointer array) over each of the two globally sorted house arrays, with group boundaries preventing leakage between buckets; deleted-in-the-other-structure houses are skipped lazily by checking a `visited` flag and unioning past them. Endpoints of each segment are included (the start point can be re-included harmlessly because of the visited flag). Finally print the running position and the visited counter.
