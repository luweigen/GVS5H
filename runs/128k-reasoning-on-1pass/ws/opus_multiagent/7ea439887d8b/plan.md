Model the process as a shortest-path problem on a doubled state graph: state `(v, p)` where `v` is the current vertex and `p ∈ {0,1}` is the current parity of reversals. From `(v,0)` we may traverse any original edge `v→u` to `(u,0)` with cost 1; from `(v,1)` we may traverse any original edge `u→v` backwards to `(u,1)` with cost 1; and from `(v,p)` we may go to `(v,1-p)` with cost X (flipping all edges). The answer is `min(dist[(N,0)], dist[(N,1)])` from source `(1,0)`. Sizes are up to 4·10^5 states and ~10^6 arcs, so we need a fast CSR-based Dijkstra with `heapq` (or Dial-free binary heap) and fast input reading; costs can exceed 32 bits so use Python ints (no overflow issue).
