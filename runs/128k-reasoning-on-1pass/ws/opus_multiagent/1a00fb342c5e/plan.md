Model each constraint as an undirected edge (X_i, Y_i) with weight Z_i; A must satisfy A_u XOR A_v = w. Run an iterative BFS/DFS over each connected component, assigning d_v = XOR of edge weights along the tree path from the component root (d_root = 0), and verify every edge satisfies d_u XOR d_v = w (self-loops require Z_i = 0); any violation ⇒ print -1. Inside a component the only freedom is a single XOR offset r applied to all vertices, so bits are independent: for bit b, if the number of vertices with that bit set in d exceeds half the component size, set that bit of r to 1 (flipping to reduce the count). Finally output A_v = d_v XOR r[comp(v)]. Bits only go up to 29 since Z_i ≤ 10^9 < 2^30; implement with flat arrays / CSR adjacency (and optionally numpy bincount per bit) to keep it O((N+M)·30) and fast in Python.
