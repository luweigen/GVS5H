Use prefix sums S_0=0, S_r=A_1+…+A_r, so the target is Σ_{1≤l≤r≤N} (S_r − S_{l−1})^K. Expand by the binomial theorem: (S_r − S_{l−1})^K = Σ_{j=0}^{K} C(K,j)(−1)^{K−j} S_r^{j} S_{l−1}^{K−j}. Sweeping r from 1 to N, maintain running sums T_m = Σ_{p=0}^{r−1} S_p^m (mod 998244353) for m=0..K, and add Σ_j C(K,j)(−1)^{K−j} S_r^j T_{K−j} to the answer. This is O(N·K) ≈ 2×10⁶ modular operations, which fits comfortably in the limits if the inner loops are written tightly (cache the power list of the current prefix sum and reuse it on the next iteration when updating T). Handle edge cases: K=1, N=1, A_i possibly 0 or up to mod−1 (reduce mod at every step).
