Model the process as a greedy region-growing: Takahashi's absorbed set is always a connected region containing (P,Q), and its total strength only grows. Maintain a min-heap of the frontier cells (cells adjacent to the current region, not yet absorbed), keyed by strength. Repeatedly peek the minimum-strength frontier cell; if `S * X < cur` (strict `S < cur/X`, using integer multiplication to avoid floats), absorb it, add its strength to `cur`, mark it visited, and push its unvisited neighbors; otherwise stop, since no larger frontier cell can be absorbed and no new frontier cells can appear. Output `cur`. Complexity is O(HW log(HW)) with H,W ≤ 500 (≤250k cells), well within limits; Python big ints handle values up to ~2.5×10^17 fine.
