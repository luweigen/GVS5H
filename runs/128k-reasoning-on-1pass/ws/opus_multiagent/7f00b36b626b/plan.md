Split the array into "big" values (`num > threshold`) and "small" values (`num <= threshold`). Any big value can never share an edge (since `lcm(a,b) >= max(a,b) > threshold`), so each contributes exactly one isolated component. For the small values, build a DSU over indices and use a harmonic (divisor-sieve) loop: for every `d` from 1 to `threshold`, find the smallest present multiple `s` of `d`, then union `s` with every other present multiple `x` of `d` while `s*x//d <= threshold` (break as soon as it exceeds, since `x` grows). This is correct because `lcm(s,x) <= s*x/d <= threshold` (sufficiency) and for any true edge `(a,b)` with `g = gcd(a,b)` the smallest multiple `s` of `g` satisfies `s*a/g <= a*b/g <= threshold` and likewise for `b`, so `a` and `b` end up connected through `s` (completeness). Total work is `O(threshold log threshold + n α(n))`, which easily fits the limits. Final answer = number of DSU roots among small values + count of big values.
