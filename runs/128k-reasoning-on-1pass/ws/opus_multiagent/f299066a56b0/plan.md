Since the array is sorted, the optimal strategy for a fixed K is to use the K smallest mochi as tops and the K largest as bottoms, matching them in order (i-th smallest with i-th of the last K). Feasibility of K is monotone (if K works, K−1 works), so binary search K in [0, N//2] and check `2*A[i] <= A[N-K+i]` for all i in [0,K). Each check is O(N) with slice/zip comparison, giving O(N log N) total, fast enough for N = 5·10⁵ in Python. Read input with `sys.stdin.buffer` for speed and print the maximal feasible K.
