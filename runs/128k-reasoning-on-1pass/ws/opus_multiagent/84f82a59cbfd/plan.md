Observe that all prime exponents being even means N is a perfect square, N = m², and the distinct prime factors of N are exactly those of m. So N is a "400 number" iff N = m² where m has exactly 2 distinct prime factors (ω(m) = 2). Since A ≤ 10¹², we only need m ≤ 10⁶: compute x = isqrt(A), then find the largest m ≤ x with ω(m) = 2 and print m². Precompute ω for all m ≤ 10⁶ with a linear/sieve-of-Eratosthenes style count (for each prime p, increment counter for all multiples), then build a prefix array best[x] = largest valid m ≤ x (best[6] = 6 guarantees answers exist since A ≥ 36). Queries are then O(1) each with fast I/O (sys.stdin.buffer read, join output).
