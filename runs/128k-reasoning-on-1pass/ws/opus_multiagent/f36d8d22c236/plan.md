Model the problem as a letter mapping: for every index i, letter `S[i]` must map to `T[i]`; if any letter of S is required to map to two different letters, output `-1`. Otherwise we have a partial function `f` on the 26 letters (defined on the set `U` of letters occurring in S). Each operation "replace x by y" realizes one required re-labeling, so the minimum number of operations is `(#letters x in U with f(x) != x)` plus one extra operation per directed cycle of length ≥ 2 in the functional graph (a cycle must be broken through a temporary spare letter, which can be reused across cycles). The only impossible-with-cycles case is when every one of the 26 letters occurs in S **and** `f` is a bijection onto all 26 letters (then no spare letter can ever be freed, since the number of distinct letters never increases) — otherwise some letter is either unused or is a "source" not in the image and can be freed first. Implement with O(N + 26) time: consistency check, then iterative cycle counting over the 26-node functional graph using color marking (0=unvisited, 1=on current path, 2=finished).
