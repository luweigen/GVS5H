Build an adjacency list and run a single DFS from node 0, maintaining the current root-to-node chain as a stack of prefix distances (`dist[0..k]`) plus a "left boundary" pointer `start` marking the shallowest index at which the chain still has all-distinct values. For each node we look up the last recorded chain index of `nums[node]` (kept in a dict `lastIdx` mapping value → index, saved/restored on backtrack) and set `start = max(start, lastIdx[val] + 1)`; since `start` is passed down as a per-call parameter, sibling branches are unaffected automatically. At each node the candidate answer is `length = prefix[k+1] - prefix[start]` with `nodeCount = k + 1 - start + 1`, and we keep the maximum length, breaking ties by the minimum node count. Because n can be 5·10⁴ and the tree may be a path, the DFS must be iterative (explicit stack with enter/exit events) or use an increased recursion limit / threading trick; iterative is preferred. Initialize the answer to `[0, 1]` so the degenerate single-node path is always covered.
