Work over F_p with the walk expansion: entry (i,j) of B^p is the sum over walks i=v_0→…→v_p of ∏ B_{v_t,v_{t+1}}. Summing over all B, each zero-position variable x with multiplicity m contributes Σ_{x=1}^{p-1} x^m = −1 if (p−1)|m (including m=0) and 0 otherwise, so the total equals (−1)^K times the sum over "valid" walks, i.e. walks in which every zero-cell is used a multiple of (p−1) times. Since a walk has exactly p steps, for p≥3 the only options are: (a) no zero cell used at all → contributes A^p (zeros kept as 0), (b) exactly one zero cell used p−1 times plus one step on a nonzero cell — which is only geometrically possible for a zero self-loop (a,a) (extra step A_{a,c} at the end or A_{c,a} at the start), or, when p=3, for a zero cell (a,b), a≠b, with the walk a→b→a→b contributing A_{b,a} to entry (a,b). The case p=2 is degenerate (only B with all zeros replaced by 1) and is handled directly as M² mod 2. Implement fast matrix power mod p with numpy using a hi/lo 15-bit split to avoid int64 overflow, then add the correction terms and multiply by (−1)^K.
