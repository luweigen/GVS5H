Model the decomposition as a forced bottom‑up DP on the rooted tree. Root the tree at vertex 1 and process vertices in reverse BFS (post‑order) order; each vertex `v` returns the number of vertices of the still‑incomplete path that contains `v` and must extend to its parent (or 0 if the path containing `v` is already closed with exactly `K` vertices). Since any incomplete chain coming from a child can only be extended through `v`, every child returning a nonzero value must be merged at `v`, so the DP is fully deterministic: let `s = 1 + sum(nonzero child values)` and `c = count(nonzero children)`; answer is "No" if `c > 2` or `s > K`, otherwise return `0` if `s == K` else `s`. The answer is "Yes" iff no failure occurs and the root returns 0 (K=1 is trivially "Yes"). Implementation must be iterative (no recursion) and use fast I/O with CSR adjacency to handle NK up to 2·10⁵.
