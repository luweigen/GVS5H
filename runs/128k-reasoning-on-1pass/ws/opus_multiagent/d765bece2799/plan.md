Treat the problem as two symmetric subproblems: sum of maxima over all subarrays of length ≤ k, and sum of minima (which equals −(sum of maxima of the negated array)). For the max part, use a monotonic stack to find, for each index i, the nearest previous strictly-greater element (L) and nearest next greater-or-equal element (R); this tie-break makes every subarray attributed to exactly one index. Then count how many subarrays with start in [L+1, i], end in [i, R−1] have length ≤ k using a closed-form inclusion–exclusion count of lattice points x+y ≤ k−1 with x ≤ a−1, y ≤ b−1, where a = i−L, b = R−i. Multiply each count by nums[i] and sum; run the same routine on [−v for v in nums] and subtract to get the min contribution. Total complexity O(n) time, O(n) space, well within n = 80000.
