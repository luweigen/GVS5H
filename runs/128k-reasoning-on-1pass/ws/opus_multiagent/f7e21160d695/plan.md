The value f(x,y) equals the maximum edge weight on the path between x and y in the minimum spanning tree (bottleneck shortest path), so all pairwise distances form an ultrametric induced by Kruskal's merging order. Process edges in nondecreasing weight with a DSU; each component stores its counts of still-unmatched A-vertices and B-vertices, and because matching is done greedily at the earliest (cheapest) possible moment, a component always has surplus of only one kind (store a single signed surplus: positive = extra A's, negative = extra B's). When an edge unites two different components at weight w, the number of newly formed pairs is min(surplusA of one, surplusB of the other) = the amount of cancellation between the two signed surpluses; add that count times w to the answer and set the merged surplus to the sum. Since A_i ≠ B_j guarantees no zero-cost self-pairs, all K pairs get matched by the time the graph is fully connected, and greedy earliest-matching is optimal for an ultrametric cost matrix.
