Key insight: for a fixed K the greedy absorption is confluent, so the answer is the sum of the unique maximal ("closure") interval reachable from K, and these closure intervals form a laminar family. Build the "max-split tree": for every distinct value V, the maximal runs of positions with all values ≤ V that contain at least one value == V are the tree nodes; a slime K escapes a node C only if its closure equals all of C and sum(C) > V of the parent's barrier (then it eats a barrier and, being larger than the parent's max, swallows the whole parent node). This lets us process distinct values in **increasing** order with a linked-interval union (leftEnd/rightEnd arrays) plus a group-DSU: each component keeps a pointer to the group of indices whose closure is exactly that component; at each level either that group is finalized (sum ≤ V ⇒ answer = sum of component) or promoted into the newly formed node's group; a new barrier p joins the node's group iff it has a strictly smaller neighbour inside the node, otherwise its answer is A[p]. At the very end the single remaining component's group gets the total sum. Total cost O(N log N) (sort) + O(N α(N)), which must be written as tight, inlined Python to fit N = 5·10⁵.
