Model all prefixes with a trie where each node stores its depth and `cnt` = number of words passing through it; a prefix of length d is achievable by k strings iff some node at depth d has `cnt >= k`. Removing word i only decrements counts along word i's own root path, and those path nodes form a contiguous chain of depths 1..D_i (counts are non‑increasing down a path), so a node survives removal iff (it is off word i's path and `cnt >= k`) or (it is on the path and `cnt >= k+1`). Precompute, for each depth d, `cntd[d]` = number of nodes at depth d with `cnt >= k`; let M1 = max depth with `cntd >= 1` and M2 = max depth with `cntd >= 2`. Then for each word, walk its path to get D_i (deepest path node with `cnt >= k`) and A_i (deepest path node with `cnt >= k+1`), and answer[i] = max(A_i, M2, M1 if M1 > D_i else 0), since at depths ≤ D_i only one node (the path node) is excluded, while any depth > D_i is safe. Handle the trivial case n-1 < k → all zeros. Total work is O(sum of word lengths), which fits the 1e5 bound.
