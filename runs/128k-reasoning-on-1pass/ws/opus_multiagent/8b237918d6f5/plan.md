Key reduction: the final shortest distance is ≥ d iff there exists a potential p: V→{0,…,d} with p(1)=0, p(N)=d, p(v)−p(u) ≤ 1 for every edge (u,v), and the number of "tight" edges (those with p(v)=p(u)+1) is ≤ K (tight edges must get weight 1; leftover 1-weights can be placed anywhere since extra 1s never decrease distances). So for each candidate d from 0 to min(K, N−1) we must compute the minimum number of tight edges over all such labelings, and answer with the largest feasible d. That minimization is a multi-label MRF whose pairwise cost g(x)=cost of x=p(v)−p(u) (0 if x≤0, 1 if x=1, huge if x≥2) is convex, hence exactly solvable by min-cut via the Ishikawa/ramp decomposition: g(x)=1·max(0,x)+BIG·max(0,x−1), and max(0,p_v−p_u−s)=Σ_k [y_{v,k}=1 ∧ y_{u,k−s}=0] where y_{i,k}=[p_i≥k]. Build the s–t graph with nodes (i,k), i∈V, k=1..d (y=1 ⇔ source side), and take the min cut with early stop once flow exceeds K. Note the LP/max-flow shortcut (d·maxflow) is WRONG (counterexample: 1→2 plus two parallel 2→3 edges, d=2 needs 3), so the layered min-cut must be used.
