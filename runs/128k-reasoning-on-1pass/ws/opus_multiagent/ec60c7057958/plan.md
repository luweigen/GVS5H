Treat the permutation as determined by its first element's parity: once the first element is chosen, parities of all later positions alternate deterministically. If `o = ceil(n/2)` odds and `e = n//2` evens remain to fill positions of fixed parity, the number of completions is simply `o! * e!` (valid only when the multiset of remaining parities matches the pattern of remaining slots). So we build the answer greedily position by position: try available numbers in increasing order, compute the count of completions if that number is placed, and either subtract it from `k` or descend into it. Total count = `o!*e!` for odd `n` (must start odd) and `2*o!*e!` for even `n`; return `[]` if `k` exceeds it. Python big integers handle `100!` fine, so no overflow concerns, though counts can be capped for speed. Complexity is O(n²) with precomputed factorials.
