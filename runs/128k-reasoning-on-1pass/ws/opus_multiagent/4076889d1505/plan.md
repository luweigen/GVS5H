Use the binomial/lifting identity: for A = N+1 and M = N², we have (N+1)^n ≡ 1 + nN (mod N²), so (N+1)^n − 1 ≡ nN (mod N²) is 0 exactly when N | n; hence the multiplicative order is precisely N. Bounds hold: A = N+1 ≤ 10⁹+1 and M = N² ≤ 10¹⁸. The case N = 1 is also covered (A = 2, M = 1, order 1). Therefore each test case is answered in O(1) with no factorization, primality search, or big-number work. The only remaining concern is I/O speed for T up to 10⁴ (trivial, but use buffered read/write).
