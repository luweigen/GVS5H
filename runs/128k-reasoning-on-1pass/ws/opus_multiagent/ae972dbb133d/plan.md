Model each shared torus edge as a 0/1 variable: `h[i][j]` = right edge of cell (i,j), `v[i][j]` = bottom edge. A Type‑A cell forces exactly one of {left,right} and one of {top,bottom} to be occupied, i.e. `h[i][j]=h[i][j-1]^1`, `v[i][j]=v[i-1][j]^1`; a Type‑B cell forces `h[i][j]=h[i][j-1]`, `v[i][j]=v[i-1][j]` and `h[i][j]!=v[i][j]`. Hence with `a[i][j]=1` iff cell is 'A', wrapping around gives the necessary conditions "every row has an even number of A" and "every column has an even number of A"; then `h[i][j]=r_i^P[i][j]`, `v[i][j]=c_j^Q[i][j]` where `P` is the row prefix‑XOR of `a` (inclusive) and `Q` the column prefix‑XOR, leaving free bits `r_i` (per row) and `c_j` (per column). Every B cell contributes the XOR constraint `r_i ^ c_j = 1 ^ P[i][j] ^ Q[i][j]`, so the answer is `0` if any parity/XOR constraint fails, otherwise `2^C mod 998244353` where `C` is the number of connected components of the bipartite graph on the `H+W` row/column nodes with one edge per B cell (isolated nodes count). (Verified: sample 1 → 2^1=2, sample 2 → row 0 has an odd A count → 0, sample 3 → 2^1=2.) Because T can be 1e5 while ΣHW ≤ 1e6, all preprocessing must be done **globally with NumPy over all test cases concatenated** (no per‑test-case NumPy calls), followed by a single pure‑Python weighted‑DSU pass over all B cells (≤1e6 unions) using globally offset node ids. Component counts per test case are then obtained vectorized by counting DSU roots inside each node block.
