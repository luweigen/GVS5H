Compute the distinct-count prefix array and suffix array, then optimize the middle segment efficiently over all split positions. For each right boundary \(j\), maintain the best value of `prefix[i] + distinct(i+1..j)` for all valid \(i<j\) using a range-add segment tree: when extending the middle segment with \(A_j\), add 1 to exactly those \(i\) where \(A_j\) has not appeared in \(A_{i+1..j-1}\). Query the maximum maintained value and combine it with the suffix distinct count after \(j\). This yields an \(O(N\log N)\) algorithm.
