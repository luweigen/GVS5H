Model each state as `(vertex, parity)`, where parity indicates whether the graph has been reversed an even or odd number of times. From `(v, 0)`, traverse original outgoing edges; from `(v, 1)`, traverse original incoming edges, while a reversal changes parity at cost `X`. Run Dijkstra’s algorithm on these `2N` states, starting from `(1, 0)`, and output the minimum distance to either parity of vertex `N`. Store both outgoing and incoming adjacency lists and use 64-bit-safe integer arithmetic.
