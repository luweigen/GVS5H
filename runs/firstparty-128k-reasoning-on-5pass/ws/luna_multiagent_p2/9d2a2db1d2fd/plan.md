Model each building as a node whose capacity is its floor count, with adjacent buildings connected by an edge weighted by the minimum capacity of its endpoints. For two different buildings, the greatest floor level that can be maintained while traveling between them is the maximum bottleneck value over all grid paths, obtainable from a maximum spanning tree or Kruskal reconstruction tree. If this value is \(M\), the optimal stair count is \(Y+Z-2\min(Y,Z,M)\); the same-building case directly costs \(|Y-Z|\). Preprocess the reconstruction tree for LCA queries, allowing each query to be answered in \(O(\log(HW))\).
