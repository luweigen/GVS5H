Model each paid operation as a set of positions it turns to 1: operation 1 contributes the interval \([L_i,R_i]\), while operation 2 contributes its complement. Since values only change from 0 to 1, operation order is irrelevant, and the goal becomes finding a minimum-cardinality collection of these sets whose union is \([1,N]\). Develop an efficient interval-coverage characterization/DP that handles up to \(N=10^6\) and \(M=2\cdot10^5\), reconstruct the chosen operations, and assign operation 0 to all unused indices. Prove both feasibility and optimality, then implement with memory-conscious arrays and fast input/output.
