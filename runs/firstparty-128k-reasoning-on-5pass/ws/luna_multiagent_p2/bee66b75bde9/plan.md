The valid final coloring must form a coordinatewise downward-closed set of black cells: if \((x,y)\) is black, then every cell \((x'\le x,y'\le y)\) must also be black. Therefore, a contradiction occurs exactly when a precolored white cell is coordinatewise above-left of some precolored black cell, i.e. when there exist \(B=(x_b,y_b)\) and \(W=(x_w,y_w)\) with \(x_b\ge x_w\) and \(y_b\ge y_w\). Detect this efficiently by sorting the given cells by row in descending order and maintaining the maximum column among black cells seen so far. If any white cell has a column no greater than this maximum, print `No`; otherwise, print `Yes`.
