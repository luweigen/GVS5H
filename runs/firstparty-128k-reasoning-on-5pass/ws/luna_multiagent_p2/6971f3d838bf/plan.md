Model each possible deleted value \(x\) with a Kadane-style state representing the best subarray sum ending at the current position after removing all \(x\)'s. Processing a value \(a\) updates every state except the state for \(x=a\), which skips \(a\); the challenge is performing these bulk updates efficiently rather than once per distinct value. Use a lazy segment tree supporting range addition, range chmax, point exclusion/update, and global maximum queries, with values compressed by distinct array elements. Also separately account for the original array and ensure deleting a value never produces an empty array.
