Use the bottleneck-distance characterization: two vertices have \(f(x,y)\le w\) exactly when they are connected using only edges of weight at most \(w\). Process edges in nondecreasing weight with a DSU, maintaining for every component the number of currently unmatched \(A\)-occurrences and \(B\)-occurrences. When two components merge at weight \(w\), greedily match as many unmatched \(A\) and \(B\) occurrences across them as possible, adding \(w\) times that count to the answer; the remaining imbalance is stored in the merged component. This greedy process is optimal because every pair formed at a DSU merge has the smallest possible bottleneck threshold, and all values and the answer must use 64-bit integers.
