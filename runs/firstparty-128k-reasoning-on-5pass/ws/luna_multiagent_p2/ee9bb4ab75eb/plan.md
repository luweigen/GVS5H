Build a trie of all words and store the number of words passing through each node. A trie node at depth `d` can support a common prefix of length `d` exactly when its count is at least `k`; maintain how many such valid nodes exist at every depth. Removing a word only changes counts on its trie path, and a depth becomes invalid only when the path node’s original count is exactly `k`. For each word, temporarily remove its affected depths, query the greatest depth still having any valid node using a segment tree, then restore the changes.
