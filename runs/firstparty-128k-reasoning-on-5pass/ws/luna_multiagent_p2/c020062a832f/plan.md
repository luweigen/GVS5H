Compute the inversion count for \(k=0\) using a Fenwick tree over values \(0,\ldots,M-1\). As \(k\) increases by one, each element whose value is \(M-1\) wraps to \(0\), while all other values increase without changing their relative ordering. For an element of value \(x\), moving it from \(M-1\) to \(0\) changes the inversion count by \((N-1)-2x\), where \(x\) is its original value; aggregate these effects by value and update the answer for every shift. Output the resulting count for all \(M\) shifts.
