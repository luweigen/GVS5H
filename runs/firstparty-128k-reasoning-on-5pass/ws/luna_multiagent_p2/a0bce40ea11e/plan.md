Use the expansion of each entry of \(B^p\) as a sum over length-\(p\) walks, then sum each walk’s monomial independently over all replacements of zero entries. For a zero variable \(x\), its power sum over \(\{1,\ldots,p-1\}\) is \(-1\) when the exponent is divisible by \(p-1\), and \(0\) otherwise modulo \(p\). For \(p>2\), this restricts surviving walks to those using either no zero entries or exactly \(p-1\) copies of one zero matrix position; derive an efficient aggregate formula using powers of the original matrix and rank-one single-entry matrices. Handle \(p=2\) separately, where every replacement is necessarily \(1\), then implement all computations in \(O(N^3\log p)\) or better with modular arithmetic.
