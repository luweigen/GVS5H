Group foods by vitamin and compute, for each vitamin and every calorie amount up to \(X\), the maximum vitamin intake achievable with exactly that calorie cost using 0/1 knapsack. For a candidate target \(T\), find the minimum calorie cost needed to obtain at least \(T\) units of each vitamin; \(T\) is feasible iff the sum of these three costs is at most \(X\). Since feasibility is monotonic in \(T\), binary search for the largest feasible target. The preprocessing takes \(O(NX)\) time and \(O(X)\) memory per vitamin, while the binary search adds \(O(X\log M)\), where \(M\) is the answer range.
