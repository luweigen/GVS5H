- **Matching structure:** Repeatedly deleting adjacent pairs produces a noncrossing matching. If \(N\) is even, every element is matched; if \(N\) is odd, exactly one element remains unmatched.
- **Absolute differences as signs:** For every matched pair, \(|x-y|\) can be written as \(+x-y\) or \(+y-x\). Thus each pair contributes one \(+1\) coefficient and one \(-1\) coefficient.
- **Even length:** Any balanced assignment of \(N/2\) plus signs and \(N/2\) minus signs can be matched noncrossingly by repeatedly removing adjacent elements with opposite signs. Therefore the optimum is obtained by assigning plus signs to the largest half of all values and minus signs to the smallest half. The answer is `sum(largest half) - sum(smallest half)`.
- **Odd length:** The unmatched element cannot be crossed by any pair, so its position must be odd (using 1-based indexing). For a fixed unmatched position, the left and right portions are independent even-length sequences. Each portion contributes its largest-half sum minus its smallest-half sum.
- **Efficient computation:** Maintain the smaller half and larger half of every prefix using two heaps, with their sums tracked. This computes the required value for every even-length prefix in \(O(N\log N)\); applying the same procedure to the reversed sequence gives all even-length suffix values.
- **Complexity:** \(O(N\log N)\) time and \(O(N)\) memory. Python integers safely handle all possible score sums.
