- **Cycle parametrization:** Let \(a_i\in\{0,1\}\) indicate whether the cycle edge \(\{i-1,i\}\) is directed into \(i\). The cycle contribution to vertex \(i\) is \(c_i=1+a_i-a_{i+1}\), where indices are cyclic.
- **Spoke contribution:** If \(s_i=1\), let \(b_i\in\{0,1\}\) indicate whether the spoke is directed from the apex \(N\) into \(i\). Then \(d_i=c_i+b_i\). If \(s_i=0\), \(d_i=c_i\).
- **Apex degree is redundant:** Since \(\sum_{i=0}^{N-1}c_i=N\), we have \(\sum_{i<N}d_i=N+\sum b_i\), while \(d_N=\#\{i:s_i=1\}-\sum b_i\). Thus \(d_N\) is uniquely determined by the first \(N\) degrees, so it suffices to count realizable words \(d_0,\ldots,d_{N-1}\).
- **Finite-state relation DP:** For a fixed output digit at position \(i\), define a binary relation from \(a_i\) to \(a_{i+1}\). A prefix induces a relation from \(a_0\) to the current state. There are only \(2^4=16\) possible relations on two states.
- **Transition relations:** For \(s_i=0\), the four pairs \((a_i,a_{i+1})=(0,0),(0,1),(1,0),(1,1)\) produce outputs \(1,0,2,1\), respectively. For \(s_i=1\), each pair may additionally receive spoke contribution \(1\), so its output increases by one optionally.
- **Cyclic closure:** After all \(N\) positions, an output word is valid iff the accumulated relation contains \((0,0)\) or \((1,1)\), meaning at least one initial state returns to itself.
- **Correctness of merging:** Prefixes producing the same relation have exactly the same possible continuations, so they can be merged safely. DP counts distinct output words because each step branches by the actual degree digit, not by orientations.
- **Complexity:** There are 16 relation states and at most 4 output digits per position. Time is \(O(N)\), memory is \(O(1)\). Exhaustive enumeration of all edge orientations for small \(N\) confirms the relation characterization and resulting counts, including the sample \(N=3,\ s=010\).
