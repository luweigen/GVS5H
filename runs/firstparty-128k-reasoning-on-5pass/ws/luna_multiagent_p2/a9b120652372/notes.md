- **Token order:** Pieces never cross. If initial pieces at positions \(x_1 < x_2 < \cdots\) are assigned to final occupied positions \(y_1 \le y_2 \le \cdots\), the assignment must be nondecreasing; several pieces may be assigned to the same final square.
- **Contraction condition:** For every pair of pieces, their distance never increases. Therefore a valid assignment satisfies \(x_j-y_j \ge x_i-y_i\) whenever \(i<j\). Equivalently, the displacement values \(x-y\) are nondecreasing along the pieces.
- **Bottleneck lower bound:** In \(D\) operations, each piece moves by at most \(D\), so every assigned pair must satisfy \(|x-y|\le D\). The minimum answer is the smallest \(D\) for which a valid assignment exists.
- **Greedy feasibility test:** Process initial pieces from left to right and target occupied squares from left to right. For each source piece, first try assigning it to the next uncovered target. This is optimal because advancing the target makes \(x-y\) as small as possible, which can only relax the required nondecreasing-displacement condition for later pieces. If advancing is invalid, assign the piece to the previously covered target, representing a merge.
- **Feasibility result:** The greedy assignment is valid exactly when every source piece can be assigned, all target squares are covered, displacement bounds hold, and displacements remain nondecreasing.
- **Binary search:** Feasibility is monotone in \(D\), so binary search over \(0\ldots N-1\) gives the minimum number of operations.
- **Complexity:** Each feasibility check is \(O(N)\), and binary search uses \(O(\log N)\) checks. Total complexity is \(O((\sum N)\log N)\), with \(O(N)\) temporary storage per test case.
