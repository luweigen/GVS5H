For any chosen divisor \(d\), an element \(A_i\) can belong to a valid \(K\)-element set with GCD divisible by \(d\) exactly when \(d\mid A_i\) and at least \(K\) array elements are divisible by \(d\). Compute, for every \(d\le \max A\), how many input elements are divisible by \(d\) using a multiples sieve. Process eligible divisors in descending order and assign each multiple \(x\) the first such divisor encountered, which is its maximum possible answer. Store answers by value, then output the answer corresponding to each original array position.
