Model each operation as flipping one bit, with the operation cost equal to the weighted number of currently active bits after the flip. Only indices where \(A_i \ne B_i\) must be flipped, but their order affects the accumulated costs. Derive the optimal ordering by comparing adjacent swaps of flips, then sort mismatched indices according to the resulting priority and simulate the flips efficiently using the total active weight. Implement the simulation in \(O(N \log N)\) time with 64-bit integer arithmetic.
