- **Contribution decomposition:** For a fixed element \(x\), if the set of elements after it has total digit length \(L\), then \(x\) contributes \(x10^L\). If exactly \(k\) elements are after \(x\), each chosen suffix set corresponds to \(k!(N-1-k)!\) permutations.
- **Generating polynomial:** For the remaining \(M=N-1\) elements, the suffix subset generating polynomial is \(\prod_d(1+10^d z)^{c_d}\), where \(c_d\) is the count of numbers of digit length \(d\). Its coefficient of \(z^k\) gives the total \(10^L\)-weight of \(k\)-element suffix subsets.
- **Removed element:** For an element of digit length \(d\), the remaining polynomial is the full polynomial divided by \(1+10^d z\). Synthetic division computes this quotient in \(O(N)\). All elements in the same digit-length class have identical positional weights, so their contributions are multiplied by the sum of their values.
- **Polynomial construction:** Each factor \((1+10^d z)^{c_d}\) is generated using binomial coefficients, and the at most six factors are multiplied using NTT convolution. Total complexity is \(O(N\log N)\), plus \(O(DN)\) for the six divisions and weighted sums, with \(D\le6\).
- **Checks:** For \(N=1\), the quotient is \([1]\), giving answer \(1\). For \(N=3\), the quotient for each one-digit element is \((1+10z)^2=[1,20,100]\), and \(2+20+200=222\); multiplying by \(1+2+3=6\) gives \(1332\).
