Process the string left to right while maintaining, for each modulus 1 through 9, the counts of previous prefixes grouped by their remainder modulo that modulus. For a substring ending at position `i` with non-zero digit `d`, its value is divisible by `d` exactly when the prefix before it has the same remainder as the current prefix modulo `d`; additionally, the substring may start at `i`, so handle the single-digit prefix explicitly. Digits ending in `0` contribute nothing because division by zero is excluded. Update all nine remainder-frequency tables after counting each position, giving an `O(9n)` time and `O(9^2)` space solution.
