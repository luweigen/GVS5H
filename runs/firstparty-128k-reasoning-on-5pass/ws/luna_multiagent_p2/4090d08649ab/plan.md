Characterize \(f(L,R)\) as the minimum number of contiguous value intervals whose union covers all distinct values appearing in \(A_L,\ldots,A_R\), where each interval must contain every integer between its endpoints among the present values. Derive an incremental formula for how \(f(L,R)\) changes when extending \(R\), likely in terms of adjacent-value connections among the distinct values. Design a data structure that maintains this quantity for every left endpoint while sweeping \(R\), and supports range updates plus global summation in \(O(\log N)\) time per element. Prove the characterization, update rule, and complexity, then implement the full algorithm with 64-bit integer arithmetic.
