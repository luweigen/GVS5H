Use a bottom-up dynamic programming tree, where each node represents a block of the string and stores the minimum changes needed to make that block’s resulting majority value equal to 0 or 1. For a leaf, the costs are 0 for keeping its original bit and 1 for changing it. For each group of three child nodes, compute the cost for each possible parent value by selecting child outcomes whose majority matches that value. The root’s cost for the opposite of the original final value is the required answer.
