For every length-`x` subarray, compute the minimum cost to make all its elements equal; this is achieved by changing values to a median. Use prefix sums and a sliding median structure to calculate all window costs in `O(n log n)`. Then apply dynamic programming where `dp[j]` is the minimum cost to select `j` non-overlapping valid windows among the processed indices. Optimize transitions using the fact that selecting a window ending at `i` requires the previous selection to end before its start, yielding `O(nk)` after window costs are available.
