Use the sorted order of the mochi sizes and model each kagamimochi as one smaller “top” mochi paired with one larger “bottom” mochi. For a fixed number \(K\), greedily match the \(K\) smallest available mochi as tops with the earliest sufficiently large mochi among the remaining mochi as bottoms; this feasibility check is optimal because smaller tops are easiest to satisfy. Binary search the maximum feasible \(K\), or equivalently use two pointers to maximize the number of matches in \(O(N)\). Implement the linear two-pointer method with the second pointer starting at \(\lceil N/2\rceil\), since no more than \(\lfloor N/2\rfloor\) pairs are possible.
