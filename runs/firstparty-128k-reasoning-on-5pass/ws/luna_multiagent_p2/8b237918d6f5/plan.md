For a target distance \(D\), compute the minimum number of edges that must receive weight 1 so that every path from 1 to \(N\) has weight at least \(D\). Represent each vertex by threshold labels \(z_{v,i}\), indicating whether its potential is at least \(i\), and encode label monotonicity and edge constraints as infinite-capacity implications in a min-cut network. A finite-capacity cut charges one unit exactly when an original edge moves upward between consecutive labels, corresponding to selecting that edge. Since feasibility is monotone in \(D\), binary search the largest \(D\) whose minimum required number of selected edges is at most \(K\); any remaining edges can be selected arbitrarily.
