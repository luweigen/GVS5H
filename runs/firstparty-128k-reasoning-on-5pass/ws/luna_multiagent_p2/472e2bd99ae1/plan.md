Sort each sequence in nonincreasing order; for a fixed pair \((a,b)\), the expression is increasing in \(c\), so the number of valid \(c\)'s can be found by binary search. For a candidate threshold \(X\), define \(G(a,b)=ab+C_{\max}(a+b)\), which is the maximum achievable value for the pair; count pairs with \(G(a,b)\ge X\) in linear time using two pointers. If at least \(K\) such pairs exist, the answer count is already at least \(K\); otherwise, enumerate all these fewer-than-\(K\) pairs in descending \(G\) order with a heap and count their valid \(c\)'s. Binary-search the largest threshold whose count is at least \(K\), using 64-bit integers throughout.
