Represent each row as a bitmask and count the frequency of every mask. For a chosen set of column flips `m`, a row mask `r` becomes `r xor m`; optionally flipping the entire row lets us pay `min(popcount(r xor m), W - popcount(r xor m))`. Thus the total cost for every `m` is an XOR convolution between the row-frequency array and a kernel depending only on popcount. Compute this convolution using a Fast Walsh–Hadamard Transform in `O(W·2^W)`, then output its minimum.
