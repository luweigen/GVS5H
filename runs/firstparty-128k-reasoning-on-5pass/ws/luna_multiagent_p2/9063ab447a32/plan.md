For a fixed total number of units \(K\), minimize the purchase cost by distributing units among products so that marginal costs are selected in increasing order. For product \(i\), buying its \(k\)-th unit adds \(P_i(2k-1)\), so feasibility can be tested by counting how many marginal costs are at most a threshold and summing them. Use binary search on the marginal-cost threshold to identify the largest fully affordable prefix, then buy any remaining units using the next cheapest marginal cost. Implement all arithmetic with Python integers and binary search the answer or threshold efficiently over the \(N \le 2\cdot10^5\) products.
