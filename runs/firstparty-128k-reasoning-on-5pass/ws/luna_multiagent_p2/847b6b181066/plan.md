Track the cumulative displacement of the wind from the origin after each time step. A smoke particle generated at time \(k\) is at the cumulative displacement at time \(t\) minus the displacement at time \(k\), so smoke is at \((R,C)\) exactly when an earlier prefix displacement equals the current prefix displacement minus \((R,C)\). Maintain a set of all prefix positions where smoke could have been generated, initially containing \((0,0)\), and after each wind step check whether the required prior position is present. Then add the current prefix position to the set and output the results as one binary string.
