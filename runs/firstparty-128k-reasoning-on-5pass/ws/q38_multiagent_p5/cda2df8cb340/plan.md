We need the sum of the odd part of every pair sum \(A_i+A_j\) with \(i \le j\). For each possible 2-adic valuation \(v\), isolate pairs whose sum is congruent to \(2^v\) modulo \(2^{v+1}\); for those pairs the contribution is \((A_i+A_j)/2^v\). For a fixed \(v\), group the array elements by residue modulo \(2^{v+1}\), storing the count and the sum of original values in each residue class. Pairs satisfying the congruence are either between complementary residues or within a self-complementary residue, and their total \(A_i+A_j\) can be computed from the stored counts and sums without enumerating pairs. Iterate \(v\) while \(2^v \le 2\max(A)\), accumulate \(S_v/2^v\), giving \(O(N \log \max A)\) time and \(O(N)\) memory.
