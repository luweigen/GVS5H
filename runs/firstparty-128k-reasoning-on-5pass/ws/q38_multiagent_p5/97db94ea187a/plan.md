For fixed layer sizes, the edge generating function factorizes, and the required balance is that the total size of even-indexed layers is N/2. Perform a DP over layers with state (total vertices, current layer size, current layer parity, number of even-distance vertices so far), keeping only counts not exceeding N/2. Represent edge generating polynomials in the basis y=1+x, so the transition for adding b vertices to a layer of size a is the sparse factor y^{C(b,2)}(y^a-1)^b, and label choices contribute C(N-t,b). At the end, sum the balanced states, convert the y-basis polynomial to x^M coefficients by a binomial transform, and output M=N-1..N(N-1)/2.
