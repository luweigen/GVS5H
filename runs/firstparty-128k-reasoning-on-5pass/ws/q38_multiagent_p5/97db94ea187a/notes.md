- **BFS layer decomposition:** In a connected graph, BFS distance layers from vertex 1 are unique. If layer sizes are `a0=1, a1, ..., aL`, edges can only be inside a layer or between adjacent layers, and every vertex in layer `i>0` needs at least one edge to layer `i-1`. This gives a bijection with layer-size sequences, label partitions, and independent edge choices.
- **Generating function:** For fixed layer sizes, the edge polynomial factorizes. Adding a layer of size `b` after a layer of size `a` contributes `C(N-t,b) * (1+x)^{C(b,2)} * (((1+x)^a - 1)^b / x^b)`. The division by `x^b` removes the mandatory one-edge-per-new-vertex minimum, so the final shifted polynomial is `G(x)=F(x)/x^{N-1}`.
- **Degree bound:** Every even vertex except vertex 1 is nonadjacent to vertex 1, so at least `N/2 - 1` edges are missing. Thus maximum balanced edge count is `C(N,2) - N/2 + 1`, and `G` has degree `D = C(N,2) - 3N/2 + 2`. Output zeros for larger `M`.
- **Evaluation/interpolation:** Evaluate `G(x)` at `x=1..D+1` modulo `P` (valid because `P > D+1`). Use Newton forward differences to get coefficients in basis `C(x-1,k)`, then iteratively multiply by `(x-(k+1))/(k+1)` to convert to the power basis.
- **DP state:** State is `(t, a, parity)`: vertices used, current layer size, current layer parity. It stores a polynomial in even-count `z` of degree at most `E=N/2`. Start is `z^1` at `(1,1,0)`. Transition to next layer size `b` shifts the even-count polynomial by `b` iff the new layer is even.
- **Packed even-count polynomial:** Store coefficients in base `2^45`. Coefficients are kept lazily: each transition multiplies each limb by the scalar weight modulo `P`, producing limbs `<P`; additions are ordinary integer additions. A DP state receives at most `N` incoming transitions, and the final answer sums at most `2N` such states, so no limb reaches `2^45`. This avoids per-limb modular reduction after additions while keeping carries impossible.
- **Pruning:** Drop coefficients with `even < t-E` because odd count already exceeds `E`. For even->odd transitions, limit `b` by `max_e - t + E`. For odd->even transitions, limit `b` by `E - min_e` and keep only coefficients with `e <= E-b`. Shifting by `min_e` and processing only the active limb range reduces work.
- **Edge cases:** `N=2` gives `D=0` and answer `1`. The output length is `C(N,2)-N+2`; after the `D+1` interpolated coefficients, append `N/2-1` zeros.
