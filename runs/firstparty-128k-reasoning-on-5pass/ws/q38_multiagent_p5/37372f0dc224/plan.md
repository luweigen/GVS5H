We need to append the minimum number of characters to the end of S so that the result is a palindrome. If the longest palindromic suffix of S has length l, then only the first n - l characters need to be mirrored and appended, giving S + reverse(S[:n - l]). A suffix of S of length l is palindromic exactly when it equals the first l characters of reverse(S). Therefore, l is the longest prefix of reverse(S) that is also a suffix of S. We can compute this longest border in O(n) using the KMP prefix function on reverse(S) + separator + S. Finally, construct and print the answer.
