Treat reachability as a finite-state DP over the last B squares, since B≤20. A state is a B-bit mask of reachable positions in the current window; a safe step shifts the mask and sets the new bit if any of the first B−A+1 old bits is set, while a bad step shifts in zero. Sweep the sorted bad intervals, applying safe-gap transitions and bad-interval zero shifts, with square 1 initialized as reachable. Because N is huge, precompute powers of the safe-step transition as boolean matrices (basis masks) so a safe gap of length G is applied in O(B log G). Bad intervals are handled by right-shifting the mask by min(length, B), clearing it when the interval length is at least B. Finally, square N is reachable iff the newest bit of the mask is set after processing up to N.
