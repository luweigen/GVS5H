Use a digit DP to count beautiful numbers from 1 to N, then return count(r) - count(l - 1). The DP state tracks the current position, digit sum, digit product, whether a non-leading digit has started, and whether the prefix is tight to N. Leading zeros are ignored, and once a zero is placed after starting, the product becomes zero, making every remaining suffix beautiful. For non-tight states with product zero, immediately return the number of possible suffixes; otherwise continue with the exact product, which is bounded by 9^9 for this constraint. Memoize non-tight states so the search over at most nine digits is small.
