Precompute prefix distinct counts L[i] for A[1..i] and suffix distinct counts R[k] for A[k..N] in linear time. For each possible right split j, maintain F_i = L[i] + distinct(A[i+1..j]) for all valid left splits i<j in a segment tree. When moving from j-1 to j, A[j] increases the middle distinct count exactly for those i whose middle segment did not already contain A[j], which is the suffix of i from the previous occurrence of A[j] (or 1 if none) to j-1, so apply a range add of +1. Insert the new left split i=j-1 with base value L[j-1] before or after the range add in a way that its middle segment A[j] contributes one distinct value. For each j=2..N-1, update the answer with R[j+1] plus the maximum F_i in the tree. This gives an O(N log N) time and O(N) memory solution.
