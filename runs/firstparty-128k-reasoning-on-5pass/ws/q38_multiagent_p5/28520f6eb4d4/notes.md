- **Visibility reduction:** For target building i, choosing the top point (X_i, H_i) is optimal because the line height at every earlier building k is increasing in the chosen Q height. Building i is visible iff the segment to its top is strictly above every earlier top; touching a top blocks visibility, as confirmed by sample 3.
- **Pairwise critical height:** For k < i, the line through the tops of buildings k and i has y-intercept I_{k,i} = (H_k X_i - H_i X_k) / (X_i - X_k). From observer height h, building i is blocked by building k exactly when h <= I_{k,i}. All buildings are visible iff h is strictly greater than every such intercept.
- **Answer threshold:** Let M be the maximum intercept over all pairs k < i. If M < 0, height 0 already sees all buildings, so output -1. If M = 0, height 0 is still blocked, so output 0. If M > 0, all heights in [0, M] fail and all heights > M succeed, so output M.
- **Adjacent-pair reduction:** Map building i to (u_i, v_i) = (1/X_i, H_i/X_i). Then I_{k,i} is the slope between mapped points k and i. For any non-adjacent k < i, that slope is a positive weighted average of the slopes of consecutive mapped points between them, with positive weights 1/X_j - 1/X_{j+1}. Therefore the global maximum is attained by some adjacent pair in input order.
- **Exact arithmetic:** Denominators X_{i+1} - X_i are positive. Keep the best fraction (max_num, max_den) and compare candidates by num * max_den > max_num * den. Python integers avoid floating-point precision issues during the maximum search.
- **Output formatting:** The exact integer maximum fraction is retained for comparison. For max_num > 0, print f"{max_num / max_den:.18f}", using binary float formatting with exactly 18 digits after the decimal point. For max_num == 0, print "0.000000000000000000". For max_num < 0, print -1.
- **Sample check:** Sample 1 gives max fraction 3/2 and prints 1.500000000000000000. Sample 2 gives a negative maximum and prints -1. Sample 3 gives maximum 0 and prints 0.000000000000000000. Sample 4 gives max fraction 120/7 and prints 17.142857142857142350.
- **Complexity:** One pass over the N buildings, O(N) time and O(1) extra state beyond input tokens.
