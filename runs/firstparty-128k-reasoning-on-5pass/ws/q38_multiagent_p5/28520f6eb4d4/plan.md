Model visibility from (0,h) by the line to the top of each building, since lowering the target point only lowers the line over all intermediate buildings. For a pair k<i, building i is hidden exactly when h <= (H_k X_i - H_i X_k)/(X_i-X_k), the y-intercept of the line through their tops. Hence the desired threshold is the maximum of these intercepts over all pairs, with -1 if the maximum is negative and 0 if it is zero. Map each building to (1/X_i, H_i/X_i); then each intercept is the slope between two mapped points. For any non-adjacent pair, that slope is a positive weighted average of the slopes of consecutive mapped points, so the maximum is attained by adjacent buildings in the given order. Therefore an O(N) scan of adjacent pairs with exact rational comparison solves the problem.
