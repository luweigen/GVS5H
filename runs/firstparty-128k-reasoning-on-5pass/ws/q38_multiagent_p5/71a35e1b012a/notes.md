- **Coverage model:** operations are monotone OR updates. A position is still 0 at the end exactly when it is not inside any chosen type-1 interval and is inside every chosen type-2 interval. This makes small pattern checks sufficient.
- **Cost 1:** only a type-1 operation on [1, N] can finish in cost 1. Keep the first full interval while reading and return immediately.
- **Cost 2 order:** after the cost-1 check, sort intervals by (L, R, index), then check type-1-contains-type-2, then disjoint type-2 pairs, then two type-1 cover. All three are valid cost-2 patterns; this order is the required tie-breaking.
- **Containment scan:** maintain `max_r_prev` and its index among intervals with strictly smaller L. For each equal-L group, first test `max_r_prev >= intervals[i][1]`. If true, output op 1 on `max_r_prev_idx` and op 2 on `intervals[i][2]`. This catches a previous interval containing the smallest-R interval of the current group. If false and the group has size > 1, the max-R interval in that group contains another interval in the same group; output op 1 on that max-R index and op 2 on a different index. For groups that do not trigger, update `max_r_prev` with the group's R.
- **Disjoint type-2:** after sorting, keep the minimum R seen so far. If current L > min_r, the previous min-R interval and current interval have empty intersection, so two type-2 operations cover all positions.
- **Two type-1 cover:** precompute the best L=1 interval (maximum R) and the best R=N interval (minimum L). They cover [1, N] iff `min_l_end <= max_r_start + 1` and the indices differ. A full interval would already have been handled as cost 1.
- **Cost 3 fallback:** if no cost 1 or 2 exists and M >= 3, no containment pair exists, so the first three sorted intervals have strictly increasing L and R. Use type 2 on the first and third intervals and type 1 on the middle interval. Positions left of the middle interval's L are outside the third interval, positions inside the middle interval are covered by type 1, and positions right of the middle interval's R are outside the first interval.
- **Achievability:** if M < 3 and no cost 1 or 2 exists, print -1. If M >= 3, the cost-3 fallback always works when no cost 2 exists.
- **Complexity:** O(M log M) time from sorting, O(M) memory, and no N-sized arrays.
