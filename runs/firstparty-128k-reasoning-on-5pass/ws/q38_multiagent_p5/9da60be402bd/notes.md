- **Core idea:** Every palindromic walk has a center: a vertex for even length, or an edge for odd length. Removing matching first and last edges leaves a shorter palindromic walk between the new endpoints. Thus a state `(u, v)` can represent the current endpoints of a palindrome, with distance equal to the shortest palindromic walk length from `u` to `v`.
- **Sources:** `(i, i)` has distance 0 because the empty string is a palindrome. Every non-diagonal edge `(u, v)` has distance 1. Self-loop edges are not used as distance-1 sources because `(u, u)` already has distance 0 and dominates any self-loop center.
- **Transition:** From a state `(x, y)` with distance `d`, if there are edges `u -> x` and `y -> v` with the same label `c`, then `(u, v)` gets candidate distance `d + 2`. This adds two matching outer edges around the existing palindrome.
- **BFS order:** Enqueue all distance-0 states first, then all distance-1 states. Since every transition adds exactly 2, a FIFO queue pops states in nondecreasing distance. The first time a pair is assigned is therefore its shortest distance, so each state is enqueued at most once.
- **Why one distance per pair is enough:** If a longer palindrome between the same endpoints exists, replacing it by the shortest palindrome between those endpoints only shortens any outer extension. The inner label string does not matter for extension, only the endpoints and palindrome property.
- **Bitset implementation:** `in_edges[x]` stores `(u, c)` for edges entering `x`. `out_bits[c][y]` is a bitmask of vertices `v` with edge `y -> v` labeled `c`. `row_unvis[u]` is a bitmask of columns `v` not yet assigned in row `u`. For popped `(x, y)`, for each `(u, c)` in `in_edges[x]`, compute `M = out_bits[c][y] & row_unvis[u]`; all bits in `M` receive distance `d + 2`, are cleared from `row_unvis[u]`, and are enqueued.
- **Complexity:** There are at most `N^2` states. Each popped state scans at most `N` incoming edges to `x`, giving about `N^3` small integer bit operations. For `N = 100`, this is around one million iterations, easily fast in Python. Each of the `N^2` states is assigned and enqueued once.
- **Pitfalls:** Stop when the queue is empty or all states are assigned; do not pop from an empty queue. Direction matters: the left outer edge must enter `x`, and the right outer edge must leave `y`. Diagonal distance-0 states must be initialized before edge sources. Use an INF sentinel and print `-1` for unassigned pairs.
- **Input parsing:** Joining all tokens after `N` and slicing into rows of length `N` handles the standard row format and also tolerates accidental spaces between characters.
