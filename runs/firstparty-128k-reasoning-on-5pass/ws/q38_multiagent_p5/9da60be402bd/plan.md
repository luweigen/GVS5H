Represent every ordered pair (u, v) as a state meaning the current outer endpoints of a palindrome path from u to v. A state has base cost 0 if u = v (empty middle) and base cost 1 if an edge u -> v exists (one-character middle); otherwise it is not a source. In the reversed state graph, a state (x, y) generates predecessors (u, v) for each label c with edges u -> x and y -> v, adding 2 to the distance. Run a multi-source BFS from all base states; because every transition adds exactly 2 and sources are enqueued in order 0 then 1, a simple FIFO queue processes states in nondecreasing distance. Use 100-bit bitsets for unassigned rows and columns, and for each popped state iterate over the smaller of incoming edges to x and outgoing edges from y, clearing all newly reached cells with bit operations. This computes all answers in about O(N^3) bit operations, leaving unreachable pairs as -1.
