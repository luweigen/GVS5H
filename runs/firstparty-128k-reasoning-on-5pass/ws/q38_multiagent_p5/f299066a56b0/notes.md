- **Problem:** Given sorted mochi sizes, find the maximum number of disjoint pairs where a top size `a` can be placed on a bottom size `b` iff `2 * a <= b`.
- **Role partition:** In every valid pair, the top is smaller than the bottom. For any feasible number of pairs, the tops can be chosen from the smallest available mochi and the bottoms from the largest available mochi. Thus it is enough to match the first `N // 2` elements against the largest `N // 2` elements.
- **Odd N handling:** When `N` is odd, only `N // 2` bottoms are needed. The largest `N // 2` elements start at index `(N + 1) // 2`, so the middle element can be ignored as a bottom without losing optimality.
- **Greedy scan:** Use `i` for candidate tops in increasing order and `j` for candidate bottoms in increasing order. If `2 * A[i] <= A[j]`, pair them and advance both. Otherwise, `A[j]` is too small for `A[i]`, and since later tops are at least as large, `A[j]` can never be used; advance only `j`.
- **Correctness sketch:** The smallest remaining top is the easiest to place. If the smallest available bottom cannot support it, that bottom is useless for all remaining tops. If it can support it, an exchange argument shows some optimal solution pairs this top with this bottom: if the bottom was used by a larger top, swap bottoms; if the top was used by a larger bottom, use the smaller bottom instead. This preserves the number of pairs and reduces the problem.
- **Indexing:** Zero-based indexing is used. `half = N // 2`, `i` starts at `0`, and `j` starts at `(N + 1) // 2`. The loop runs while `i < half` and `j < N`.
- **Complexity:** The scan visits each relevant bottom at most once and each top at most once, giving `O(N)` time. Storing the array uses `O(N)` memory, which is fine for `N <= 5 * 10^5`.
- **Edge cases:** `N = 2` checks the only possible pair. If no pair is possible, the answer remains `0`. Duplicates are allowed because the condition is non-strict. Python integers avoid overflow when doubling values up to `10^9`.
- **Implementation:** Read all integers from standard input. The first integer is `N`, followed by the already sorted array. No sorting is needed. Print the final count.
