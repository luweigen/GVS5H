Use the sorted order and the condition that a top mochi of size `a` can be placed on a bottom mochi of size `b` exactly when `2*a <= b`. For a candidate number `K` of kagamimochi, it is sufficient and necessary to try pairing the `K` smallest mochi with the `K` largest mochi in order. If every pair satisfies `2*A[i] <= A[N-K+i]`, then `K` is feasible; otherwise it is not. Therefore the answer can be found by binary searching `K` in `[0, N//2]` with this check, or by a direct two-pointer greedy scan. This gives an efficient solution well within the constraints.
