Count triplets by their middle element B: for each B in S, the number of valid (A, C) is half of the number of ordered pairs (A, C) in S with A + C = 2B, excluding the pair (B, B). This ordered-pair count is the autocorrelation of the indicator set at position 2B. Compute the autocorrelation efficiently with convolution/NTT rather than O(N^2). Split the indicator into even and odd endpoint values to halve array sizes, convolve each squared indicator, and combine h_even[B] + h_odd[B - 1] for each B. Since all coefficients are at most 1e6, a single NTT prime such as 998244353 gives exact values. Sum (combined - 1) // 2 over all B and print the 64-bit answer.
