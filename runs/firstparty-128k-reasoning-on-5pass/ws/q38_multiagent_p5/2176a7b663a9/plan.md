The graph is the comparability graph of intervals ordered by complete left/right separation, and positive vertex weights let us shortcut any path between overlapping vertices to at most three edges using the first and last intermediate vertices. If the queried intervals are disjoint, the direct edge is optimal. If they overlap, a two-edge path requires a vertex disjoint from both, which is exactly an interval left of the smaller L or right of the larger R. A three-edge path can be non-dominated only when the two intervals cross (neither contains the other); then the two middle vertices must have L in (R_left, R_right] and R in [L_left, L_right), respectively, so their minimum total weight is two range-minimum queries. Preprocess coordinate minima with prefix/suffix arrays and segment trees, then answer each query in O(log N).
