Use sqrt decomposition on both sequences with a block size of about N/100, so each query has only O(sqrt N) leftover elements. Precompute, for every A_i and every full prefix of B blocks, the sum of |A_i-B_j| over that B prefix, and symmetrically for every B_j and full prefix of A blocks, using incremental block additions and two-pointer scans over value-sorted arrays. Also precompute the full-block answer G[x][y] = sum over the first x blocks of A and first y blocks of B from the same PA table. For a query (X,Y), split into full blocks and remainders: add G, add PA/PB contributions for the small remainders against the opposite full prefix, and compute the small remainder-remainder part by sorting the two short slices and merging. All values fit in signed 64-bit, and the total complexity is about O(N sqrt N + K sqrt N) time with O(N sqrt N) memory.
