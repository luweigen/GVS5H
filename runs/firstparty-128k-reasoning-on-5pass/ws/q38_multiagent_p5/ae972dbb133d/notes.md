- **Edge model:** Replace each tile orientation by bits on the four incident grid edges. No dead ends on the torus means the bit on a shared edge is the same from both sides. An A cell forces left xor right = 1 and top xor bottom = 1; a B cell forces left xor right = 0, top xor bottom = 0, and left xor top = 1.
- **Row reduction:** In a fixed row, the xor of left/right differences around the torus must be 0, so the row's A count must be even. Then all horizontal edge bits in that row are determined by one bit x_i (the left edge of column 0): h_{i,j}=x_i xor parity of A's in row i up to column j.
- **Column reduction:** Similarly each column's A count must be even, and vertical bits are determined by y_j (top edge of row 0): v_{i,j}=y_j xor parity of A's in column j up to row i.
- **B coupling:** For a B cell (i,j), left xor top = 1 gives x_i xor y_j = 1 xor row_prefix_before_j xor col_prefix_before_i. A cells add no row-column equation because any one horizontal and one vertical edge are adjacent.
- **Counting:** The B cells form a bipartite XOR graph on H row variables and W column variables. If any row/column parity is odd or a cycle has odd total label, answer 0. Otherwise each connected component, including isolated variables, has one free bit, so answer is 2^{components} mod 998244353.
- **Implementation:** Read all tokens with sys.stdin.buffer.read().split(). For each case, advance idx past the H row strings and process them by index. First pass uses bytes.count for row parity, tracks has_A/has_B, and builds column A parity in a list col. If any row is odd or col contains 1, output 0. If no A, output 2 (complete bipartite B graph). If no B, output 2^{H+W}. Otherwise reuse col (all zeros) as the column prefix for the second pass and add B constraints to a parity DSU.
- **Parity DSU:** parent, rank, parity-to-parent, and component count. union inlines two finds with path compression and enforces val[a] xor val[b]=w; when merging roots it sets the new root parity to pa xor pb xor w.
- **Validation:** Sample outputs are 2, 0, 2. Small brute-force checks match: 2x2 all A -> 16, all B -> 2, every other 2x2 pattern -> 0; 2x3 ABA/ABA -> 8; all-A grids with even row/column parity -> 2^{H+W}; all-B grids -> 2.
- **Pitfalls:** Use prefix before the current cell (same as after for B), include isolated variables in the component count, do not add constraints for A cells, handle torus wrap via row/column parity, and advance idx before the passes so invalid cases still consume input.
