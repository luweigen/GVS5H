- **Target feasibility:** For a fixed D, we need at most K edges S such that every 1-N walk has at least D edges of S. Exactly K is equivalent to at most K because extra 1-edges only increase path costs.
- **Potential equivalence:** The minimum size of such S equals the minimum, over integer labels p(v) in [0,D] with p(1)=0, p(N)=D, and p(v)<=p(u)+1 for every edge u->v, of the number of edges with p(v)=p(u)+1. From a working S, take p(v) as the capped minimum number of S-edges on a 1-v path; from a label, take S as the +1 edges. Any 1-N walk has net label increase D and each edge can increase the label by at most 1, so it uses at least D +1 edges.
- **Cut encoding:** Let y_{v,i}=1 mean p(v)>=i+1, for i=0..D-1. Source side of the cut is y=1. Add large-capacity edges source->(N,i) and (1,i)->sink to force p(N)=D and p(1)=0. Add large-capacity (v,i)->(v,i-1) for i>0 for prefix monotonicity. Add large-capacity (v,i)->(u,i-1) for each original u->v and i>0 to enforce p(v)>=i+1 => p(u)>=i. Add unit edges (v,i)->(u,i) for each original u->v and all i; under the large-capacity constraints, these are cut exactly for the unique i where p(v)=p(u)+1.
- **Feasibility test:** Build the network for D>0, run Dinic with large capacity K+1 and stop once flow reaches K+1. D is feasible iff flow<=K. D=0 is always feasible.
- **Search bounds:** The answer is at most K (a shortest path cannot contain more paid edges than chosen) and at most N-1 (a shortest path can be chosen simple). Binary search the largest feasible D in [0, min(K, N-1)].
- **Implementation details:** Use 0-indexed vertices. Node id for (v,i) is v*D+i, with D layers. Rebuild the flow graph for each D. Dinic has at most about N*D+2 <= 872 nodes and a few thousand edges, so the ~5 binary-search checks are easily fast.
- **Pitfalls:** A naive time-expanded graph where layers are paid edges used so far can cut the same original edge independently in different layers and undercount. The threshold/potential gadget charges each original edge once, at the level where the label crosses it. Off-by-one: layers are 0..D-1, unit edges for all i, cross large-capacity edges only for i>=1, monotonic edges from i to i-1.
