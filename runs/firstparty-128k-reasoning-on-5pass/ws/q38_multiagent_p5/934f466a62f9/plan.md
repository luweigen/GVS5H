Reduce the original pairing problem to choosing 2K cakes and assigning each cake to one of the three attributes, with the number of cakes assigned to each attribute even; pairing same-attribute cakes shows the two formulations have the same optimum. Let f(k) be the optimum for k pairs; f is concave because it is the maximum weight matching cardinality function in a complete graph. Use the Aliens trick: binary search an integer per-pair penalty λ, and for a fixed λ maximize total scaled value 2*price - 2λ per pair by DP. For fixed λ, run an O(N) DP over 8 parity masks where each cake is unused or assigned to X/Y/Z with gain 2*value - λ, maximizing adjusted value and, on ties, the number of selected cakes. Binary search the largest λ whose optimal pair count is at least K, then recover the answer as (dp_value + 2λK)//2. Implement the DP with encoded (value,count) integers and unrolled transitions to keep the 31 passes over total N=1e5 fast in Python.
