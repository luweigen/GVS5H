A 400 number has the form \(p^{2a}q^{2b}\) with distinct primes \(p<q\) and \(a,b\ge 1\), equivalently the square of \(M=p^aq^b\). Since \(A\le 10^{12}\), we only need \(M\le 10^6\), so all valid numbers can be precomputed once. Generate primes up to \(10^6\), enumerate all products \(p^aq^b\le 10^6\) with exactly two distinct prime factors, square them, and sort the results. For each query, answer by binary searching the largest precomputed 400 number not exceeding \(A\). This gives fast per-query lookup and small memory usage.
