Treat each unordered pair of grid cells independently: every arrangement containing that pair contributes its Manhattan distance, and there are C(mn - 2, k - 2) such arrangements. Thus the answer is C(mn - 2, k - 2) times the sum of Manhattan distances over all unordered cell pairs. Manhattan distance separates into row and column components; for rows, each row pair contributes n column choices and distance d, giving n * m(m^2 - 1)/6, and similarly m * n(n^2 - 1)/6 for columns. Compute this closed form modulo 10^9 + 7 using the modular inverse of 6, and multiply by the binomial coefficient computed with factorials/inv-factorials up to mn. This yields an efficient solution well within the constraints.
