Normalize each person to an interval [l, r] and a sign (+ if T > S, - otherwise). A set of people is feasible iff it contains no bad pair: two intervals sharing a left or right endpoint, or two same-sign intervals that cross in either order. This pairwise obstruction is sufficient because, when absent, the induced strict min/max constraints on prefix values are acyclic and can be satisfied by a topological assignment. For range queries, infeasibility is hereditary, so for each right end R we only need the largest L such that some bad pair lies inside [L, R]. Compute for every index j the maximum earlier index i that forms a bad pair with j, then take prefix maxima to answer all queries. Same-endpoint pairs are found by last occurrences; same-sign crossing pairs are found by an offline CDQ + segment-tree range-max, run once normally and once on mirrored coordinates.
