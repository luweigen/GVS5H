- **Normalization:** Each person becomes an interval [l, r] with l = min(S, T), r = max(S, T), and a sign: 0 for right-moving (T > S), 1 for left-moving (T < S). Right-moving requires P_l = P_r and P_x > P_l for l < x < r; left-moving requires P_l = P_r and P_x < P_l.
- **Feasibility criterion:** A set of people is feasible iff it contains no bad pair. Bad pairs are: two intervals with the same left endpoint, two intervals with the same right endpoint, or two same-sign intervals that properly cross. Touching intervals (one right endpoint equals the other left endpoint) are not bad.
- **Range queries:** For each person j, let p[j] be the largest earlier index i < j forming a bad pair with j. A query [L, R] is feasible iff max_{j <= R} p[j] < L. Thus prefix maxima of p answer all queries in O(1).
- **Same-endpoint predecessors:** Use last occurrence arrays for left and right endpoints while scanning person indices increasing. This gives the largest previous index with the same endpoint.
- **Crossing computation:** For each sign separately, compute crossing predecessors. Split proper crossings into two orientations:
  - Original: L_a < L_b < R_a < R_b.
  - Mirrored: transform (L, R) to (N+1-R, N+1-L); the other crossing order becomes the same original form.
- **Backward report-delete sweep:** Process person indices in decreasing order. Active future intervals of the same sign are stored. For current earlier interval a, report all active future intervals b satisfying L_b in (L_a, R_a) and R_b > R_a. The first time b is reported in this sweep is exactly the largest earlier interval of that crossing type, so p[b] is updated and b is deleted from this sweep.
- **Data structure:** Compress all L values for the sweep. Build a segment tree over compressed L. Each interval is inserted once at leaf x = L with heap key y = R. Each leaf heap is a max-heap by y, encoded as (y << SHIFT) | index and stored negated for Python min-heap. Internal nodes store the maximum y in their subtree.
- **Query operation:** For current a, query x-range (L_a, R_a) using bisect_right(L_a) and bisect_left(R_a)-1. Decompose the range into O(log M) segment-tree nodes. Use a stack to traverse only nodes whose max y > R_a. At leaves, pop heap entries while y > R_a, updating p[index]. After leaf changes, update ancestor max values upward, breaking early if unchanged.
- **Complexity:** Each interval is inserted once and reported at most once per sweep. There are four sweeps (two signs, original/mirrored), each O(M log M). Same-endpoint and queries are O(M + Q). Total O((M + Q) log M), memory O(M).
- **Strictness:** Use strict inequalities everywhere: x-range excludes L_a and R_a via bisect_right/left, and y condition is y > R_a. This correctly excludes touching and same-endpoint cases from crossing sweeps.
- **Edge cases:** Single person is always feasible. Prefix maximum p[R] is always < R, so [L, L] answers Yes. Intervals have length at least 2 by constraints, but the algorithm also works if interiors are empty because compressed query ranges may simply be empty.
