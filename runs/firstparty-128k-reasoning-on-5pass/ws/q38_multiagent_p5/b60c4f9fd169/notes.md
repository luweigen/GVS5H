- **Algorithm:** Use Landau-Vishkin furthest reaching for edit distance at most K. After swapping, S is the shorter string (length n), T length m. Diagonal is d = x - y, where x,y are consumed lengths. V[d] stores the furthest x reachable with at most the current edit count, after extending through matching characters.
- **Early exits:** If |n-m| > K, No. Swap so n <= m. If K >= m, Yes, because at most n substitutions plus m-n insertions (total <= m) suffice.
- **Initialization:** V[0] = LCE(0,0). If n == m and V[0] == n, Yes.
- **Transitions:** For e = 1..K and d = -e..e, read old = V[d]. Candidate x values: old (carry), V[d-1]+1 (delete from S), V[d+1] (insert into S, i.e. consume T), old+1 (substitute). Keep only candidates with 0 <= x <= n and 0 <= x-d <= m. Use the previous V for all candidates and write results to a new list.
- **Extension:** If the best candidate is larger than old, extend it by LCE(best, best-d). If the extended state has x == n and x-d == m, print Yes.
- **LCE:** Deterministic chunked longest common extension. BLOCK = 4096. A first-character guard avoids slicing when the next characters differ. Otherwise compare bytes slices of length min(BLOCK, remaining S, remaining T); if equal, jump by that length. Otherwise scan at most that block character by character to the first mismatch and stop. No hashing, so no collision risk.
- **Complexity:** O(K^2) DP states. Each LCE uses block jumps; worst-case byte work is about O(K^2 * (max(n,m)/4096 + 4096)), and memory is O(K). With K <= 20 and lengths 500000 this is small.
- **Correctness:** The invariant follows from the type of the last edit. On a fixed diagonal, a larger reachable x dominates a smaller one: any matching run from the smaller position cannot pass the larger position without the larger position's LCE reaching at least as far.
- **Edge cases:** K=0, prefix/suffix insertions, all equal, all different, length difference exactly K, x reaching n before y reaches m, and y reaching m before x reaches n are all handled by the bounds and LCE stop conditions.
- **Verification:** Samples 1-3 are covered. Small edge cases such as a->aa, a->ba, ab->ba, abc->awtf were checked by hand. A brute-force Levenshtein cross-check on small random strings matches the same transition logic.
