Sort A, B, and C in nonincreasing order; since all entries are positive, the expression is monotone nonincreasing when any index increases. Run a best-first search over the 3D index grid from (0,0,0) using a max-heap of encoded states. To avoid a visited set, use a fixed lexicographic spanning tree where the parent of (i,j,k) is (i,j,k-1) if k>0, else (i,j-1,0) if j>0, else (i-1,0,0), and push only the tree children of a popped state. Because every ancestor of a cell has a value at least as large, the heap always contains a candidate no smaller than any unpopped cell, so the K-th popped value is the K-th largest. This gives O(N log N + K log K) time and O(K) memory.
