- **Problem reduction:** Independent permutations of A, B, and C do not change the multiset of all N^3 values. After sorting each array in nonincreasing order, f(i,j,k)=A_iB_j+B_jC_k+C_kA_i is monotone nonincreasing in each index because all entries are positive.
- **Truncation:** Let M=min(N,K). Any triple with i>=K is dominated by the K triples (t,0,0) for t=0..K-1; similarly for j or k. Thus at least K truncated triples are >= any discarded value, so the K-th largest value is unchanged by keeping only the first M elements of each array.
- **Enumeration tree:** Parent of (i,j,k) is (i,j,k-1) if k>0, else (i,j-1,0) if j>0, else (i-1,0,0). Children of a popped state are (i,j,k+1) if k<M-1; (i,j+1,0) if k==0 and j<M-1; and (i+1,0,0) if k==j==0 and i<M-1. Since parent value >= child value, best-first search over this tree pops cells in global descending order.
- **Packed heap key:** bits=max(1,(M-1).bit_length()); state=(i<<2bits)|(j<<bits)|k; key=(diff<<3bits)|state, where diff=max_val-value. A min-heap pops the smallest key, i.e. largest value. The k coordinate can be read directly as key&mask; for non-leaves, state=key&state_mask, j=(state>>bits)&mask, i=state>>2bits.
- **Incremental diff:** Start with diff=0 at (0,0,0). Precompute gaps dA[i]=A[i]-A[i+1], dB, dC. For the k child, add dC[k]*(A[i]+B[j]); for the j child from k=0, add dB[j]*(A[i]+C[0]); for the i child from j=k=0, add dA[i]*(B[0]+C[0]). This avoids recomputing the full expression.
- **Heap operation optimization:** For the first K-1 pops, if k<M-1 the k child always exists; use heapreplace to pop the root and insert that child in one sift, then push the j and i children if k==0. If k==M-1 the state is a leaf, so just heappop. The final pop gives the K-th value.
- **Fast paths:** K==1: maxA*maxB+maxB*maxC+maxC*maxA. K==M^3: minimum of the truncated grid, A[-1]*B[-1]+B[-1]*C[-1]+C[-1]*A[-1].
- **Complexity:** Sorting O(N log N); enumeration K pops with O(K log K) heap work and O(K) memory. K<=5e5, M<=2e5, and all values/packed keys fit comfortably in Python integers.
- **Samples:** Sample 1 traced: popped values 44, 38, 36, 34, 31. Sample 2 is all-equal, so every value is 30000. Sample 3 follows the same general path and produces the expected large integer.
