- **State model:** The only global information needed is the parity of the number of edge reversals. Parity 0 means original directions, parity 1 means all edges reversed. A state is `(vertex, parity)`, giving `2N` states.
- **Transitions:** From parity 0 at `v`, follow original outgoing edges `v -> u` with cost 1 to `(u, 0)`. From parity 1 at `v`, follow reversed edges, which correspond to original incoming edges `u -> v`, so move to each in-neighbor `u` with cost 1 to `(u, 1)`. At every vertex, toggle parity with cost `X`.
- **Start and goal:** Start at `(1, 0)` with distance 0. The goal is vertex `N` in either parity, so the answer is `min(dist[N][0], dist[N][1])`. Stopping when the first popped state has vertex `N` is safe because Dijkstra pops states in nondecreasing final distance.
- **Implementation encoding:** Use 0-based vertices and encode a state as `s = (v << 1) | p`. Toggling parity is `s ^ 1`. Layer 0 move target is `to << 1`; layer 1 move target is `(to << 1) | 1`. Keep two adjacency lists: `out` for original outgoing edges and `inn` for original incoming edges.
- **Complexity:** The state graph has `2N` vertices, `2M` move edges, and `2N` toggle edges. Dijkstra runs in `O((N + M) log(N + M))` time and `O(N + M)` memory, which fits the constraints.
- **Numerical safety:** Distances can exceed 32-bit range because `X` can be up to `10^9` and many operations may be needed. Python integers are arbitrary precision; use a large `INF` such as `10**30`.
- **Edge cases:** Self-loops and parallel edges are harmless because they only create extra transitions that cannot incorrectly improve distances. If `N` were 1, the start state is already the target and the answer is 0; constraints have `N >= 2`, but the code handles it. The graph is guaranteed reachable, but a fallback prints the minimum stored target distance if the heap empties.
- **Pitfalls avoided:** In reversed parity, do not use outgoing adjacency; use incoming adjacency. Do not require returning to original orientation at the end. Do not assume at most one reversal; toggle edges allow any number of reversals.
