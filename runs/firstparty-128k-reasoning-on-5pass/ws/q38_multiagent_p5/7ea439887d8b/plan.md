Model the process as a shortest path problem on a two-layer graph, where layer 0 represents the original edge directions and layer 1 represents the reversed edge directions. For each original edge u -> v, add a cost-1 move from u in layer 0 to v in layer 0, and a cost-1 move from v in layer 1 to u in layer 1. Also add a cost-X toggle edge between the two layers at every vertex. Run Dijkstra from state (1, 0) over the 2N states, and the answer is the minimum distance to either (N, 0) or (N, 1). This gives an O((N + M) log N) solution with O(N + M) memory and 64-bit-safe distances.
