- **Core invariant:** For every 1 in left-to-right order, its absolute position modulo X is preserved; for every 0 in left-to-right order, its absolute position modulo Y is preserved. Operation A shifts the chosen Y ones left by X and the chosen X zeros right by Y, so each selected symbol keeps its relevant residue, and the relative order of all 1s and all 0s is unchanged.
- **Sufficiency:** Orient Operation A as the rewrite 0^X 1^Y -> 1^Y 0^X. The rewrite is terminating because the sum of 1-positions decreases by XY. The left-hand side has no proper self-overlap, so the rewrite system is confluent; each equivalence class has a unique A-normal form with no occurrence of 0^X 1^Y. The residue sequences determine that normal form. For X=1 or Y=1, the problem reduces to moving a single symbol across blocks of length Y or X, and the corresponding prefix-residue invariants are complete.
- **Stress test result:** The included optional stress mode BFSes all 2^N strings for N <= 10 and all X, Y. It checks that connected components and invariant sequences define the same partition. No counterexample was found, supporting that the ordered-residue invariant is complete.
- **Algorithm:** If X + Y > N, no operation can be applied, so answer Yes iff S == T. Otherwise, compare the ordered 1-position residues modulo X and the ordered 0-position residues modulo Y. If both sequences are equal, print Yes; otherwise No.
- **Edge cases:** X=1 makes the 1-residue sequence trivial, so only the count of 1s matters for that part. Y=1 makes the 0-residue sequence trivial, so only the count of 0s matters. N=1, X=Y=1 is handled correctly: 0 and 1 are not equivalent.
- **Complexity:** O(N) time. Worst-case memory is O(N) for the two residue lists being compared; mod-1 cases use O(1) extra memory. This is easily within limits for N up to 5e5.
- **Implementation details:** The solver reads bytes and compares integer byte values 48 and 49. The optional stress test uses bitmask states and precomputed masks for each possible operation start; it is not run in normal judge mode.
- **Samples:** Sample 1 gives Yes because the 1-residue sequences match and zero counts match. Sample 2 gives No because X+Y>N and the strings differ.
