- **Model:** Each removal sequence is a noncrossing matching on original indices; any noncrossing matching can be removed inside-out. For odd N the unmatched index must have even 0-based parity because removing adjacent elements shifts right-side indices by 2.
- **Even segment optimum:** For an even-length multiset, total score is at most the sum of the largest half minus the sum of the smallest half. This bound is attainable: label the largest half plus and the smallest half minus; every plus is at least every minus. Repeatedly remove adjacent opposite labels; this yields a valid noncrossing matching and the total equals the half-sum difference.
- **Odd N reduction:** If the survivor is p (even 0-based), no pair can cross it, so the score is opt(A[0:p]) + opt(A[p+1:N]). Both sides have even length. We need the maximum over p = 0, 2, ..., N-1.
- **Heap maintainer:** low is a max-heap using negated values for the smaller half, high is a min-heap for the larger half. Maintain len(low) = (total + 1) // 2 and all low values <= all high values. After each insertion, at most one element moves between heaps. When total is even, the segment score is sum_high - sum_low.
- **Implementation:** Even N: sort and print upper-half sum minus lower-half sum. Odd N: scan A[0:N-1] to fill pref[k] for prefix length 2k. Initialize ans = pref[m], which handles survivor at the last index with empty suffix. Then scan indices N-1 down to 1; when the current suffix length N-i is even, start i is odd and p = i-1 is a valid survivor, so update ans with pref[(i-1)//2] + current suffix score.
- **Complexity:** O(N log N) time and O(N) memory. Python integers safely handle totals up to about 1.5e14.
- **Pitfalls:** The survivor is not simply a global median; prefix and suffix use their own half-sums, not global half-sums of all non-survivors. Empty segment score is 0. Ties at the median are harmless. The survivor's own value is ignored.
- **Validation:** Samples give 5, 14, and 0. A brute-force DP f(l,r) = max_i |A_i - A_{i+1}| + f(l,i) + f(i+2,r) on small random arrays matches this formula.
