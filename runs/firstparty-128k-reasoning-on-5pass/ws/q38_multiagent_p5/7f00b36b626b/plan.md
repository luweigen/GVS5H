Numbers greater than the threshold are always isolated because their LCM with any other number is at least as large as themselves. For numbers at most the threshold, use a DSU over values and exploit the fact that if two present numbers both divide some common multiple `m <= threshold`, then their LCM also divides `m` and is therefore valid. For each present value `d`, scan all multiples `m` of `d` up to the threshold and keep a representative present divisor for each `m`. Union `d` with that representative so all present divisors of the same multiple become connected. This gives an efficient `O(threshold log threshold)` solution with `O(threshold)` memory, which is easily feasible for `threshold <= 2 * 10^5`.
