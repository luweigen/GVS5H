Model the operations as choosing row-flip parities and a column-flip mask, since repeated flips only matter modulo 2. For a fixed column mask, each row pattern contributes independently by either flipping or not flipping that row, giving a cost of the minimum Hamming distance to the column mask or its complement. Therefore the answer is the minimum over all column masks of a weighted sum over row patterns. This sum is an XOR convolution between the row-pattern frequency array and a kernel depending only on Hamming distance. Compute this convolution for all masks using a fast Walsh-Hadamard transform in O(H + W·2^W).
