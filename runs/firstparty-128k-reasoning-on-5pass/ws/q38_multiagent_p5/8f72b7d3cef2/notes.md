- **Core model:** For a fixed starting slime K, Takahashi’s current state is a contiguous interval [l, r] containing K, and his size is sum(l, r). He can expand left/right exactly when his current sum is strictly larger than the adjacent outside slime. A terminal interval is therefore stable: sum(l, r) <= A[l-1] if l > 1, and sum(l, r) <= A[r+1] if r < N, with missing boundaries treated as infinity.
- **Answer characterization:** Any stable interval containing K is a trap: while the current interval is inside it, its sum is at most the stable interval’s sum, so it cannot absorb the stable interval’s boundary. The maximal reachable interval is stable, hence it is the minimal stable interval containing K. Since all sizes are positive, nested stable intervals have strictly increasing sums, so the answer for K is the minimum sum among stable intervals covering K.
- **Laminar bound:** Two overlapping stable intervals cannot cross. If [l, r] and [l', r'] cross with l < l' <= r < r', stability gives sum(l, r) <= A[r+1] <= sum(l', r') <= A[l'-1] <= sum(l, r), forcing impossible equalities with positive sizes. Thus stable intervals are laminar, there are O(N) of them, and the minimal stable interval containing each K is unique.
- **Prefix inequalities:** Let P be prefix sums. For left boundary l, the left inequality is P[r] <= 2P[l-1] - P[l-2] (for l=1, always true). Rmax[l] is the farthest r satisfying it, found by bisect_right. For right boundary r, the right inequality is P[l-1] >= 2P[r] - P[r+1] (for r=N, always true). Lmin[r] is the smallest l satisfying it, found by bisect_left; if none, Lmin[r] = r+1.
- **Active sweep:** Sweep r from 1 to N. Active left endpoints are those with l <= r <= Rmax[l]. Add l=r when Rmax[r] >= r. Remove l at r = Rmax[l]+1 using expiration buckets exp_head/exp_next. Active endpoints are kept in a doubly linked list ordered by l.
- **Successor query:** For each r, stable intervals ending at r are exactly active l >= Lmin[r]. If Lmin[r] <= head, first is head. Otherwise, find the first active position >= Lmin[r]. The implementation uses a two-level bitset: 1024-bit masks per block of active positions, plus a bitset of nonempty blocks. Same-block search shifts the block mask; otherwise it shifts the nonempty-block bitset. This replaces a per-position Fenwick prefix+kth step with O(1) big-int operations.
- **Interval enumeration:** Once the first active l >= Lmin[r] is found, follow the active linked list to tail and append every [l, r]. Each appended interval is stable, and the total number of appended intervals is O(N) by laminarity.
- **Packing and assignment:** Pack each interval as (sum << 40) | (l << 20) | r. N <= 5e5 fits in 20 bits, and lower 40 bits cannot affect sum ordering. Sort packed intervals by sum. Use a DSU next-unassigned array to paint each position with the first interval covering it; this is the minimum-sum stable interval covering that position. The whole array [1, N] is always stable and guarantees coverage.
- **Complexity:** O(N log N) time from the N bisect calls and sorting O(N) intervals; sweep, enumeration, and painting are O(N) amortized. Memory is O(N).
- **Pitfalls handled:** Equality is allowed in stability because absorption requires strictly smaller; missing boundaries are infinity; remove expired endpoints before querying; add l=r before querying; bisect off-by-one for Lmin uses hi=r; 20-bit packing is safe for constraints; positive sizes are essential for laminarity and sum monotonicity.
