Binary search the answer X and check feasibility in O(n). For a candidate X>0, req[i]=ceil(X/points[i]); since every index must receive a positive score, any feasible walk must reach the last index N=n-1. For a chosen ending position p, take the shortest base walk 0->N->p, whose base visits are 2 at index 0 iff p=0, 2 at interior i iff i>=p, and 1 at the last index; extra traversals come in pairs across edges and add one visit to each adjacent index. For fixed p, the minimum number of extra pairs is the maximum weight matching on a path with weights equal to the deficits (req minus base visits, floored at 0) for the endpoint and adjacent constraints. Sweep p=0..N in O(n) by representing the matching DP as 2x2 max-plus matrices, precomputing suffix products for the p=0 deficits, and moving one deficit from the suffix to the prefix (updated for p>0) as p advances. X is feasible iff min_p (1 + 2N - p + 2*matching_weight(p)) <= m.
