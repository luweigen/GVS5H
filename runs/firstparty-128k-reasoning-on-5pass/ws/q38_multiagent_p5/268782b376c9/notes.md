- **Core model:** Binary search the target minimum score x. x = 0 is trivial. For x > 0, index i needs req[i] = ceil(x / points[i]) visits. If m < n or any req[i] > m, x is infeasible.
- **Walk structure:** A positive target forces visiting every index, so the walk must reach n - 1. If it ends at p, the minimal edge traversals are 1 on edges i < p and 2 on edges i >= p, plus the initial step from -1 to 0. Base moves are 2n - 1 - p.
- **Base visits:** Index 0 has base visit 2 only when p = 0, otherwise 1. Interior index i has base visit 2 when i >= p, otherwise 1. The last index always has base visit 1.
- **Extra pairs:** Additional moves come in pairs on an edge. e_i extra pairs on edge i cost 2 moves and add one visit to both endpoints. Visits become base_visits + e_{i-1} + e_i. Deficits are d[i] = max(0, req[i] - base_visits[i]).
- **Path covering dual:** Minimize sum e_i subject to e_{i-1} + e_i >= d[i]. The dual is max sum d[i] * y[i] with y[i-1] + y[i] <= 1, so the optimum equals the maximum weight independent set on the path with vertex weights d[i].
- **Weights by p:** For p = 0, non-last vertices use a[i] = max(0, req[i] - 2), and the last uses a[last] = max(0, req[last] - 1). For p > 0, vertices before p use b[i] = max(0, req[i] - 1), while vertices from p onward use a[i].
- **Suffix DP:** g0[i] is the maximum weight independent set on suffix i..n-1 using a weights. Recurrence: g0[i] = max(g0[i+1], a[i] + g0[i+2]), with g0[n] = g0[n+1] = 0. The suffix value with vertex i excluded is g0[i+1].
- **Prefix sweep:** p0 and p1 store the best prefix 0..p-1 with the previous vertex not taken or taken. Start p0 = 0, p1 = -inf. At p, the whole independent-set value is max(p0 + g0[p], p1 + g0[p+1]). x is feasible if 2n - 1 - p + 2 * value <= m. Then update p0, p1 = max(p0, p1), p0 + b[p].
- **Bounds:** hi = floor(m * max(points) / n) + 1 because total score after m moves is at most m * max(points). If m < n, return 0. At most m moves means no parity padding is needed.
- **Edge cases:** The first move is forced to index 0. n = 2 works with the same formulas. The last index base visit is 1, not 2. Index 0 base visit is 2 only for p = 0. The prefix tuple update must use the old p0. NEG is far below any possible DP value.
- **Sample tests:** The harness checks the two examples, exhaustive n = 2 small cases against brute force and a closed-form n = 2 checker, m < n cases, large n = 50000 with m = n where the answer is min(points), large n = 2 with m up to 1e9 against the closed form, large n = 50000 with m = 1e9 bounds, and 200 random brute-force cases with n <= 4 and m <= 8.
- **Verdict:** The sample harness is expected to print the pass verdict; all listed checks validate feasible(x) and the final answer.
