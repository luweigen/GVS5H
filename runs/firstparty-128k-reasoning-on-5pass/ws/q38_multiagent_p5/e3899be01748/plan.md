Count valid substrings by their rightmost digit, skipping rightmost digit '0'. For rightmost digits '1', '2', and '5', every substring ending at that position is valid, so add i+1. For rightmost digits '3', '6', and '9', use prefix digit sums modulo 3 or 9 to count previous prefix positions with the same residue. For rightmost digits '4' and '8', use the last-two/last-three digit divisibility rules, adding all longer substrings when the relevant suffix is divisible and separately handling the one- and two-digit cases for '8'. A single left-to-right pass with O(1) counters gives O(n) time.
