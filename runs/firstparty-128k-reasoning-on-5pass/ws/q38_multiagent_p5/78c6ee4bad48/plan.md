Model the configuration by the N-1 consecutive gaps between sorted pieces. The operation on four consecutive pieces reverses the three gaps between them, which is exactly swapping the first and third gap while leaving the middle gap unchanged. Therefore operations allow arbitrary adjacent swaps of gaps whose indices have the same parity, so the odd-indexed gaps and even-indexed gaps can be permuted independently while X_1 and the multiset of gaps in each parity are invariant. The total coordinate sum is N X_1 plus a weighted sum of gaps with weights N-1, N-2, ..., 1. To minimize, within each parity assign the sorted gaps in ascending order to the decreasing weights (largest gaps to smallest weights). Compute this weighted sum and print it.
