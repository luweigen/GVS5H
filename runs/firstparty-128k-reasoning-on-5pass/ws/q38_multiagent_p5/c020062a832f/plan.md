Compute the inversion count for k=0 with a Fenwick tree over values, iterating A left to right and counting previous elements greater than A_i. When k increases by 1, only elements whose current value is M-1 (original A_i = M-1-k) wrap from maximum to minimum, so all other relative orders stay the same. For each wrapping index p, the inversion count changes by the number of non-wrapping indices before p minus the number of non-wrapping indices after p, while pairs among wrapping indices contribute no change. Store the positions of each original value, then for v from M-1 down to 0 compute the total delta for all positions with A_i=v in linear time over the bucket. Print the current answer for each k and update it by the delta for the next k, giving O(N log M + N + M) time and O(N+M) memory.
