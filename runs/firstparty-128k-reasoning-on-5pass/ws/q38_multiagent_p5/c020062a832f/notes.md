- **Final algorithm:** Compute the inversion count for k = 0 once using a Fenwick tree over values. While reading A, also store cnt[v] = number of indices with A_i = v and sumpos[v] = sum of their 1-based positions. Then iterate k = 0..M-1, print the current answer, and update it for the next k using the wrapping group v = M-1-k: ans += 2 * sumpos[v] - (N + 1) * cnt[v].
- **Transition logic:** Going from k to k+1 adds 1 modulo M to every element. Pairs where neither element wraps keep their relative order. Pairs where both elements wrap remain equal before and after, so they contribute no change. Only cross pairs between wrapping and non-wrapping elements change.
- **Per-position effect:** For a wrapping position p, every non-wrapping position before p becomes a new inversion, and every non-wrapping position after p stops being an inversion. Thus the local delta is nonwrap_before(p) - nonwrap_after(p).
- **Batch formula:** Let W be the set of wrapping positions, c = |W|, S = sum of positions in W. The number of non-wrapping positions before wrapping positions is X = S - c - c(c-1)/2 = S - c(c+1)/2. The number of wrapping-before-non-wrapping pairs is Y = c(N-c) - X. The total delta is X - Y = 2S - c(N+1), which is exactly 2 * sumpos[v] - (N + 1) * cnt[v].
- **Fenwick details:** Values 0..M-1 are mapped to Fenwick indices 1..M. For each x, prefix_sum(x+1) gives the number of previous elements <= x, so previous greater elements = seen - prefix_sum(x+1). This correctly ignores equal values.
- **Edge cases:** M = 1 works because there is only one output and no update is performed. N = 1 gives zero inversions and all deltas are zero. Duplicates are handled naturally: equal values never form inversions, and wrap-wrap pairs do not change the inversion count.
- **Integer size:** Maximum inversion count is about N(N-1)/2, around 2e10 for N = 2e5. Python integers handle this safely.
- **Complexity:** Initial inversion count is O(N log M). Building cnt and sumpos is O(N). The M updates are O(M). Total time is O(N log M + M), memory is O(N + M).
- **Verification:** The formula matches the provided samples. Small manual checks include [1, 0] with M=2 giving 1 then 0, [0, 1] giving 0 then 1, and [1, 1, 0] with M=2 giving 2 then 0. Early wrapping positions produce negative deltas, late wrapping positions produce positive deltas, consistent with the formula.
- **Rejected alternatives:** Simulating each wrapping element with a position Fenwick tree is possible but less clean. Interval coverage over all pairs and FFT-style aggregation are overkill. Sqrt decomposition is unnecessary once the batched wrap formula is available.
