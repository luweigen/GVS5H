Treat each index k as the potential middle of a 5-subsequence, requiring two chosen indices before k and two after k. For v=nums[k], the middle value can be a unique mode only if its total frequency in the 5 elements is 2, 3, 4, or 5. Sweep k while maintaining frequency maps for the left and right sides, and compute the number of valid left/right pair choices for each frequency case. The frequency-2 case is the only one needing extra care: the three non-v elements must be pairwise distinct, which can be counted using distinct-pair counts and cross-value sums. Sum the per-k contributions modulo 10^9+7, yielding an O(n^2) algorithm for n<=1000.
