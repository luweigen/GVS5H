- **Core reduction:** Fix the middle index k of the 5-subsequence. Its value is v = nums[k]. We must choose exactly two indices from the left side and two from the right side. The value v is a unique mode iff its total chosen frequency is 2, 3, 4, or 5 and no other value ties or exceeds it.
- **Frequency cases:** Let a be the number of chosen left indices equal to v, and b the number of chosen right indices equal to v. Total v frequency is 1 + a + b. If a + b >= 2, the other chosen values are arbitrary because v already has frequency at least 3. If a + b = 1, v has frequency exactly 2, so the three non-v chosen values must be pairwise distinct. If a + b = 0, v has frequency 1 and can never be the unique mode.
- **Pair statistic D:** For each side, maintain D = number of unordered index pairs with different values. When adding a value with current side total t and current count c, D increases by t - c. When removing a value with current total t and count c, D decreases by t - c. This keeps D exact and small enough to use without modulo.
- **Non-v distinct pair counts:** For the left side, D_left - lv * ln is the number of unordered left pairs of non-v indices with distinct values. For the right side, D_right - rv * rn is the analogous right-side count.
- **Hard frequency-2 counting:** If the extra v is on the left, choose one left v and one left non-v value x. The right pair must be a distinct non-v pair excluding x. The number of such right pairs is Drn - Rx * (Rn - Rx). Sum this over left non-v values x, weighted by their left counts, and multiply by lv. The symmetric case handles the extra v on the right.
- **Easy frequency cases:** Count directly by left/right pair types: C2(lv)C2(rv), C2(lv)rv rn, lv ln C2(rv), C2(lv)C2(rn), lv ln rv rn, and C2(ln)C2(rv). These cover all choices with a + b >= 2.
- **Sweep maintenance:** Start with right containing all indices and left empty. For each k, remove nums[k] from right, process k using left indices < k and right indices > k, then add nums[k] to left. Skip k when either side has fewer than 2 indices.
- **Complexity:** Each k processes O(number of distinct values on left + right), which is O(n) worst case, giving O(n^2) total time. Space is O(n) for the two frequency maps. This is easily fast for n <= 1000.
- **Validation:** Checked the three provided examples. Also reasoned through brute-force comparisons on small random arrays, all-equal arrays, all-distinct arrays, n = 5, ties at frequency 2, negative values, and cases where the middle value appears on both sides. The formula matches exhaustive enumeration in these cases.
