Model each parent sequence as a random recursive tree, so the required sum is (N-1)! times the expected distance between u and v. For an edge labeled by child x with weight A_x, the edge is on the u-v path exactly when x is an ancestor of exactly one of u and v. In this random recursive tree, for x<y the probability that x is an ancestor of y is 1/x, and for x<u<v the probability that x is an ancestor of both u and v is 2/(x(x+1)). These facts give closed-form contribution probabilities depending only on whether x is below u, equal to u, between u and v, or equal to v. Precompute prefix sums of A_x times the corresponding rational weights and answer each query in O(1), then multiply by (N-1)! modulo 998244353.
