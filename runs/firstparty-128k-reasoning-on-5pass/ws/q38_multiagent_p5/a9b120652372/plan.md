Treat the pieces as ordered tokens; an operation never increases any distance between two tokens, so necessary conditions are count(A) ≥ count(B) and span(A) ≥ span(B). A final configuration is an order-preserving assignment of the M initial pieces to the K ones of B (with repetitions); let d_i be the displacement and S_i = d_i - d_{i+1} the decrease of the i-th internal gap. The gap-decrease vector S must be reducible by the allowed operations, which is equivalent to every positive run of S that does not touch an end having even total; the minimum number of operations is either base = max(B_1 - A_1, A_M - B_M) or base + 1. Base is attainable exactly when a valid assignment exists with no internal odd run and, when base is determined by an end, the corresponding first/last positive run has even total (or there are no zero drops). Use greedy checks for the easy all-strict and M = K cases, and otherwise a small-state DP over B gaps, with segment-tree/sorted-key queries for the next larger/equal A gap, to decide reachability and base attainability.
