Use the identity x^3 - y^3 = (x-y)(x^2+xy+y^2) and let d = x-y > 0. Substitute x = y + d to obtain 3d y^2 + 3d^2 y + d^3 = N, a quadratic in y. For each d, the discriminant is 3d(4N - d^3), so a solution requires d^3 <= 4N and the discriminant to be a perfect square. Iterate d from 1 up to the integer cube root of 4N, which is at most about 1.6e6 for N <= 10^18, and test the integer root for divisibility and positivity. Return the first valid (y+d, y), or -1 if none exists.
