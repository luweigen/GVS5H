Use dynamic programming over prefix length and number of subarrays. Let `P` and `C` be prefix sums of `nums` and `cost`, and define `dp[t][i]` as the minimum cost to partition the first `i` elements into exactly `t` subarrays. If the last subarray starts after `p`, its cost is `(P[i] + k*t)*(C[i] - C[p])`, giving `dp[t][i] = min_{p<i} dp[t-1][p] + (P[i] + k*t)*(C[i] - C[p])`. Rewrite this as `(P[i] + k*t)*C[i] + min_p (dp[t-1][p] - (P[i] + k*t)*C[p])`, a line-query problem with line slope `-C[p]` and intercept `dp[t-1][p]` evaluated at `x = P[i] + k*t`. Because `C[p]` and `P[i]` are nondecreasing, each `t` can be processed in `O(n)` with a monotone convex hull trick, for `O(n^2)` total time and `O(n)` memory with rolling arrays. Return the minimum `dp[t][n]` over all possible `t`.
