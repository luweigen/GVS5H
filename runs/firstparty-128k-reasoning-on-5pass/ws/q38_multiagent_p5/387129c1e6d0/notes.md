- **Problem reduction:** Santa’s path is the union of axis-aligned closed line segments. A house is visited iff it lies on a vertical segment with the same x-coordinate and y-coordinate inside that segment’s y-interval, or on a horizontal segment with the same y-coordinate and x-coordinate inside that segment’s x-interval.
- **Simulation:** Start from the given point and process all moves. For each vertical move, append a closed y-interval to a dictionary keyed by the fixed x-coordinate. For each horizontal move, append a closed x-interval to a dictionary keyed by the fixed y-coordinate. Also update the current coordinates to obtain the final position.
- **Interval storage:** Intervals are stored as `(low, high)` with `low <= high`. Endpoints are included because arriving at or passing through a house at a segment endpoint must count.
- **Merging:** For each fixed coordinate, sort its intervals by start point and merge overlapping or touching intervals using `l <= current_right`. The result is a set of disjoint closed intervals, stored as two parallel lists: starts and ends.
- **House query:** For a house `(hx, hy)`, first check vertical coverage at `hx`. Use `bisect_right(starts, hy) - 1` to find the last interval whose start is at most `hy`, then verify `hy <= ends[i]`. If not covered vertically, perform the analogous check for horizontal coverage at `hy` using `hx`.
- **Counting once:** A house may lie on both a vertical and a horizontal segment. The code checks vertical first and only checks horizontal if vertical coverage fails, so each house is counted at most once.
- **Complexity:** Sorting all intervals across all keys takes `O(M log M)` in the worst case. Each house query uses two dictionary lookups and at most two binary searches, giving `O(N log M)` total. Memory is `O(N + M)`.
- **Overflow safety:** Python integers have arbitrary precision, so final coordinates and interval endpoints can safely exceed 32-bit ranges.
- **Edge cases:** No house exists at the initial point, but returning there is harmless. Overlapping, touching, and repeated segments are handled by merging. Negative coordinates are handled naturally by sorting and binary search.
