- **Correction:** The supplied seven-variable recurrence was not used because it fails a small brute-force check: for N=3 and s=111 it gives 36, while direct enumeration of orientations gives 38. The submitted program uses a fresh compact recurrence derived from a correct mask/relation DP.
- **Model:** Let x_i be the direction of cycle edge i, and y_i be the spoke contribution at vertex i. Then d_i = 1 + x_{i-1} - x_i + y_i for i < N. The degree of vertex N is forced by the total number of edges, so counting full in-degree sequences is equivalent to counting distinct z-strings z_i = x_{i-1} - x_i + y_i that can be produced by a cyclic binary x-sequence.
- **Mask DP:** Track two 2-bit masks: possible current x values if the initial x_{-1} was 0, and if it was 1. The initial state is (1, 2). For each character, transition on each possible z value; if several z values lead to the same mask pair, add that multiplicity. A full string is valid when the final relation contains (0, 0) or (1, 1).
- **Reduction:** Unreachable mask pairs and several invariants collapse the 16-state DP to six integer variables plus a boolean `one`. The invariants used are: state (3, 2) equals `one`, state (2, 0) is always one more than state (1, 0), the states (1, 1) and (2, 2) are always equal, and the accepting contribution from states (1, 2) and (1, 3) is always 1.
- **Code variables:** a, b, c, d, e, f are the reduced counts; `one` is 0 before the first '1' and 1 afterwards. The final answer is a + b + c + 2d + e + f + 1 + one modulo 998244353.
- **Verification:** All eight length-3 strings were checked against direct enumeration; sample 010 gives 14. The second sample is expected to give 261339902 with this recurrence. Periodic modulo every 16 characters keeps integers small while preserving the result modulo 998244353.
- **Complexity:** O(N) time and O(1) memory.
