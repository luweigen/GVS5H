Count the 26 character frequencies, and observe that any reassignment that is not keeping a character or moving it to the next letter can be simulated by delete+insert at cost 2. Thus, for a fixed uniform frequency k, a target is specified by choosing which letters have count k, and the cost is n + total target length minus savings from same-letter matches (2 each) and next-letter matches (1 each). For fixed k, the optimal savings are local: take min(c_i, k) same matches for each used letter, then match excess of letter i to deficit of letter i+1, which depends only on adjacent choices. This yields a 26-step DP with state only whether the previous letter is used, run in O(26) for each k. Enumerate k from 1 to n (larger k is dominated) and return the minimum total cost.
