- **Cost model:** For a fixed final count vector where each used letter has frequency k, start from deleting all original characters and inserting all target characters, costing n + target_length. Keeping an original letter i as target i saves 2 operations. Changing original i to target i+1 saves 1 operation. All other reassignments save 0 and can be replaced by delete + insert.
- **Local optimality:** For a used letter i, there is always an optimal solution that keeps min(c_i, k) copies of i. Replacing one same-letter match by one previous next-letter match plus one next next-letter match changes savings by at most -2 + 1 + 1 = 0, so it never improves the result. Therefore excess from letter i is max(0, c_i - k) if i is used, and c_i if i is unused. Deficit of a used letter i is max(0, k - c_i).
- **DP state:** For each k, dp0 and dp1 store the minimum partial cost, excluding the global n, for the processed prefix where the previous letter is unused or used. Transition to current unused is ndp0 = min(dp0, dp1). Transition to current used adds k - 2*min(c_i, k), and if i > 0 subtracts min(max(0, c_{i-1} - k*prev_used), max(0, k - c_i)), which is the one-operation saving from changing letter i-1 to i.
- **No wraparound:** The sweep stops at letter z. No transition from z to a is added, matching the rule that z cannot be changed to a.
- **Frequency bound:** It is enough to try k from 1 to n. The initial upper bound is n - max(c), obtained by keeping the most frequent letter and deleting everything else. If k > n and at least two letters are used, cost is at least target_length - n > n, which is worse. If only one letter j is used, at least k - c_j operations are needed to raise its count, and k - c_j > n - max(c).
- **Complexity:** Counting is O(n). The DP is O(26 * n) time and O(1) extra space, about 520,000 inner iterations for n = 20,000.
- **Validation:** The provided examples give 1 for "acab", 0 for "wddw", and 2 for "aaabc". A Dijkstra brute force over count vectors with delete, insert, and change-to-next operations on small alphabets and short random strings agrees with this DP. Edge cases checked include all same, already good multi-letter strings, gaps, zero-count bridge letters, and the z boundary.
