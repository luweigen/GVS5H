- **Split pattern:** `p.split('*')` gives literal blocks `A`, `B`, `C`. A valid match is an occurrence of `A`, then `B`, then `C` in that order, with no overlap. Stars may match zero characters, so adjacency is allowed: `a + lenA <= b` and `b + lenB <= c`.
- **Empty match:** Only `p == "**"` can match the empty substring, so return `0` immediately when all three blocks are empty. Any non-empty literal block requires at least one character.
- **KMP occurrences:** For each non-empty block, find all start positions in `s` using KMP. Each list is sorted because KMP scans left to right. Total occurrence-finding time is linear in `|s| + |p|`. The reset `j = pi[j - 1]` after a full match allows overlapping occurrences.
- **B non-empty:** Iterate over every `B` start `b`. If `A` is non-empty, use `bisect_right(A_occ, b - lenA) - 1` to get the latest valid `A` start; if none, skip. If `A` is empty, the substring starts at `b`. If `C` is non-empty, use `bisect_left(C_occ, b + lenB)` to get the earliest valid `C` start; if none, break because later `B` starts require even later `C` starts. If `C` is empty, the substring ends at `b + lenB - 1`. Update the minimum length.
- **B empty:** If `A` is empty, the answer is `lenC` when `C` occurs. If `C` is empty, the answer is `lenA` when `A` occurs. If both are non-empty, iterate over `A` starts and pair each with the earliest `C` start at or after `a + lenA`; break when no such `C` remains.
- **Complexity:** Time is `O(|s| + |p| + k log n)` where `k` is the number of scanned `B` or `A` occurrences; with `n <= 10^5` this is easily fast enough. Memory is `O(n)` for occurrence lists.
