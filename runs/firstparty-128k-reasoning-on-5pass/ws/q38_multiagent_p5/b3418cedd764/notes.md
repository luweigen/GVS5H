- **Graph structure:** View i -> A_i as an edge to a parent. Each weak component is a directed cycle with in-trees. The inequalities around a cycle force all cycle vertices to have the same value. Removing cycle edges leaves rooted trees where labels must be nondecreasing from leaves to root.
- **Dynamic programming:** For a non-cycle node u, let F_u(k) count valid labelings of u's subtree when its parent has value k. If children are v, then F_u(k) = sum_{a=1}^k prod_v F_v(a). The array prod[u][a] stores the product over already processed children of F_v(a). Processing u takes the prefix sum of prod[u] to obtain F_u, then multiplies F_u into prod[A[u]].
- **Peeling order:** Indegree peeling starts from leaves. When u is popped, all its children have already contributed to prod[u]. After updating its parent, decrement the parent's indegree; when it reaches zero, the parent is ready. Cycle nodes keep indegree at least one from the cycle predecessor, so they are not popped.
- **Dirty flag:** dirty[u] is False while prod[u] is still the all-ones vector. This is an optimization: a leaf has F_u(k)=k, and multiplying an all-ones parent by a vector is just assignment. It also lets pure cycles be handled in O(1) per cycle.
- **Cycle handling:** Remaining indeg>0 nodes are exactly cycle nodes. Follow A from each unvisited remaining node to collect a cycle. For a cycle, each node's prod array is the factor from its attached trees for a common value k. The cycle contribution is sum_k product over cycle nodes of prod[node][k]. All-ones factors are skipped; if none are nontrivial, the contribution is M. Multiply all cycle contributions modulo.
- **Complexity:** Each node causes at most one length-M vector update, so time is O(NM). Memory is O(NM) in the worst case for the stored vectors, which is fine for N,M <= 2025. Processed vectors are set to None to release memory.
- **Edge cases:** M=1 has exactly one sequence and is returned early. Self-loops are length-one cycles. Pure cycles with no trees contribute M. Multiple components multiply independently. Prefix sums use one subtraction because both addends are below the modulus, and k values are below the modulus since M <= 2025.
