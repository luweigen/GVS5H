Compress each test case into maximal runs of equal values, storing their values and lengths; let M be the number of runs. A potential argument shows that, starting from M runs, only adjacent swaps that reduce the run count by 2 can lower the final operation count, and such a swap must exchange two adjacent singleton runs inside a 4-run pattern a,b,a,b. Each such beneficial swap removes the two middle runs and lengthens the two outer runs, so two chosen swaps cannot have their middle-pair start indices within 2 of each other. Thus the problem reduces to selecting the maximum number of valid 4-run patterns whose start indices differ by at least 3. A 1D DP over run indices computes this maximum, and the answer is M minus that maximum.
