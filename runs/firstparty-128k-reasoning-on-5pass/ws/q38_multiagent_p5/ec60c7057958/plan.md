Treat the problem as lexicographic unranking over parity-constrained permutations. At any prefix, the only state needed is how many odd and even numbers remain and the parity required next. For a fixed required parity and remaining length, valid completions exist only if the remaining odd/even counts match the alternating pattern; their number is `fact[rem_odd] * fact[rem_even]`, capped above `10^15`. Build the answer greedily by scanning unused numbers in increasing order, subtracting the block size for each candidate until `k` falls inside one block. If `k` is larger than all blocks, return an empty list.
