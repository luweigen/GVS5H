Use the fact that for any N, the element 1+N has exact multiplicative order N modulo N^2. Set M=N^2 and A=N+1 for every test case. By the binomial theorem, (1+N)^d ≡ 1 + dN (mod N^2), so it is congruent to 1 modulo M exactly when N divides d. Therefore the smallest positive d is N, and the construction is valid for N=1 as well because M=1 makes the condition trivial. All bounds hold since N≤10^9 implies M≤10^18 and A≤10^9+1, so the algorithm is O(T).
