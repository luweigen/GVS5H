- **Core reduction:** T windows are hard equalities; fill a length n+m-1 array from every T window and return empty on any conflicting assignment. F windows become a ban on the pattern automaton reaching a full match at the window's end position.
- **Automaton:** Use KMP states 0..m-1, where state is the longest prefix of str2 that is a suffix of the built prefix. Build the prefix function and raw transitions for 26 letters. A raw transition to m means the current length-m window equals str2; when allowed, collapse it to pi[m-1].
- **Position modes:** Each position has a fixed character or is free, and has a forbid flag if it is an F-window end. For each of the 27*2 modes and each state, precompute a bitset of next states reachable by allowed characters without an immediate forbidden full match.
- **Backward DP:** feasible[p] is a bitset of states before position p from which a valid suffix exists. feasible[L] is all states. For p backward, state k is feasible iff its precomputed next-state bitset intersects feasible[p+1]. If a feasible set becomes empty, return empty.
- **Greedy reconstruction:** Start in state 0. At each position, try letters in increasing order (or the fixed letter), skip forbidden full matches, and take the first letter whose next state is in feasible[p+1]. This gives the lexicographically smallest valid string.
- **Complexity:** T filling O(n*m) <= 5e6, automaton O(m*26), backward DP O(L*m) <= about 5.25e6 bitset checks, memory O(L) Python ints plus small tables. The mode_all shortcut avoids the inner loop when the next feasible set is all states.
- **Edge cases checked:** m=1, all T, all F, overlapping T conflicts, T-forced indirect F violations, and the three examples. F-only instances are always satisfiable, and the DP still handles them.
