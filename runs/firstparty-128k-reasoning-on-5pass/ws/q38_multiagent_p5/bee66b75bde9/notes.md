- **Model:** A valid coloring is determined by row black lengths a_1, ..., a_N. The row condition makes each row a black prefix of length a_i. The column condition is equivalent to a_1 >= a_2 >= ... >= a_N; any nonincreasing sequence of row lengths gives a valid grid.
- **Fixed cells:** A black cell (x, y) forces a_x >= y. A white cell (x, y) forces a_x <= y - 1. Unconstrained rows have default bounds 0 <= a_i <= N.
- **Existence criterion:** For lower bounds L_i and upper bounds U_i, a nonincreasing sequence exists iff for every row i, max_{j >= i} L_j <= U_i. Choosing a_i = max_{j >= i} L_j is the maximal feasible candidate; if it violates an upper bound, no sequence can work.
- **Dominance form:** The criterion becomes: no fixed white cell (x, y) may have a fixed black cell (x', y') with x' >= x and y' >= y. Such a black cell would force (x, y) to be black, contradicting the fixed white.
- **Sweep:** Process fixed cells from bottom to top, i.e. x descending. Maintain max_black_col as the maximum y among black cells already seen, meaning black cells in rows below the current row plus same-row black cells if processed first. For a white cell, if max_black_col >= y, there is a contradiction. For a black cell, update max_black_col = max(max_black_col, y).
- **Same-row order:** Black cells in the same row must be processed before white cells in that row; otherwise a same-row conflict where a black cell is at or to the right of a white cell could be missed. Sorting by (-x, 0 for B, 1 for W) implements this.
- **Complexity:** O(M log M) time for sorting and O(M) memory. N is only a coordinate bound and is never iterated over, so N up to 10^9 is fine.
- **Edge cases:** A white cell at column 1 conflicts with any black cell at or below it. A black cell above a white cell below is not a conflict. A black cell below with a smaller column is not a conflict. Multiple constraints in the same row are handled by the maximum black column and checking every white cell. If M were 0, the answer is Yes. Large coordinates are safe in Python.
- **Implementation:** Use sys.stdin.buffer, store (-x, order, y) with order 0 for B and 1 for W, sort ascending, then sweep. Output Yes if no conflict is found, otherwise No.
- **Verification:** Sample 1 gives Yes because the bottom black at column 1 does not force the white at column 2. Sample 2 gives No because the bottom black at column 2 forces the top white at column 2 to be black. Sample 3 gives Yes because a single white cell with no black cells is satisfiable. The listed edge cases match the row-length criterion.
