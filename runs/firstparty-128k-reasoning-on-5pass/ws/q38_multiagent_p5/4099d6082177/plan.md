If K=1, the answer is always Yes. For K>1, root the tree and process subtrees bottom-up, classifying each subtree as closed (fully partitioned into K-vertex paths), open (partitioned except one unfinished path containing the subtree root), or dead. In an open subtree the unfinished path length is forced to be the subtree size modulo K, so only one length value is needed per node. At a node, all children must be closed or open; let the open children have lengths l_i. The node is open if there are 0 open children (length 1) or exactly 1 open child with l_i<K-1 (length l_i+1), and closed if there is exactly 1 open child with l_i=K-1 or exactly 2 open children whose lengths sum to K-1. Print Yes iff the root is closed.
