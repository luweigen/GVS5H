- **Core idea:** For a fixed endpoint, all valid special paths ending there start at some ancestor on the root-to-endpoint path. Valid starts form a suffix of that path. Because all edge lengths are positive, the longest valid path ending at that endpoint starts at the highest valid ancestor. Therefore one candidate per endpoint is enough.
- **Boundary invariant:** While traversing a root-to-node path, maintain `boundary`, the maximum depth of the previous occurrence of any value that appears again below it. Equivalently, for each value, take the second-deepest occurrence depth on the current path, and take the maximum over all values. A start depth is valid exactly when it is strictly greater than `boundary`.
- **Candidate computation:** If the current node is at depth `depth` and root distance `dist`, the highest valid start is at depth `boundary + 1`. Its distance is `path_dist[boundary + 1]`. Candidate length is `dist - path_dist[boundary + 1]`, and candidate node count is `depth - boundary`.
- **Online update:** When entering a node with value `x`, let `p = last[x]` be the deepest previous occurrence of `x` on the parent path. The only value whose second-deepest occurrence can change is `x`, so the new boundary is `max(old_boundary, p)`. Then set `last[x] = depth`. On exit, restore both `last[x]` and `boundary`.
- **Iterative DFS:** Use an explicit stack with enter and exit states to avoid recursion-depth issues on chains of length up to 50,000. Push the exit marker before children so it is processed after the whole subtree. Use the parent pointer to root the undirected tree at node 0.
- **Tie-breaking:** Keep `best_len` and `best_nodes`. Update when the current candidate length is larger, or equal with fewer nodes. Positive edge lengths guarantee that for a fixed endpoint, different valid starts have strictly different lengths, so no non-highest valid start can tie the endpoint's maximum length.
- **Complexity:** Time is `O(n + max(nums))` because each node is entered and exited once and the `last` array is linear in the value range. Memory is `O(n + max(nums))` for adjacency, stack, path distances, and last-occurrence array.
- **Verification:** Example 1 returns `[6, 2]` from paths `2 -> 5` and `0 -> 1 -> 4`. Example 2 returns `[0, 1]` because both single-node paths are the only valid paths of maximum length.
- **Edge cases:** All equal values produce only single-node candidates, returning `[0, 1]`. All unique values keep `boundary = -1`, so the best path is the maximum root-to-node distance, with minimum node count among ties. Deep chains are handled iteratively. Duplicate at the parent makes `boundary = depth - 1`, yielding a single-node candidate of length 0.
