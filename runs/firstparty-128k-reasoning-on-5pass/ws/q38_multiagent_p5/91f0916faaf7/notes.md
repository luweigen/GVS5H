- **Prime-wise reduction:** For each prime p, let e_i = v_p(S_i) and a_i = v_p(A_i). The condition f(S_i/S_{i+1}) = A_i is equivalent to |e_i - e_{i+1}| = a_i for every i. The gcd condition is min_i e_i = 0 for every prime. The score factorizes over primes, so the answer is the product of independent per-prime sums.
- **Bounded-walk shift formula:** For a fixed p, let T = sum a_i. Any valid exponent walk with minimum 0 has maximum at most T. Define G_H as the total weight p^{sum e_i} over all walks of length N with 0 <= e_i <= H and the same adjacent differences. Then the desired per-prime factor is F_p = G_T - p^N G_{T-1}, because walks in [0,T] not visiting 0 are exactly walks in [0,T-1] shifted up by 1, and shifting all N heights multiplies the weight by p^N.
- **DP for G_H:** Initialize dp[h] = p^h for h = 0..H. For a positive step a, the new value at height j is p^j * (dp[j-a] + dp[j+a]) with boundary checks. A run of L zero steps simply multiplies dp[h] by p^{Lh}. This is compressed instead of processing each zero edge separately.
- **Simultaneous computation:** For each prime, compute G_T and G_{T-1} together. Maintain two DP arrays and two active bounding boxes. The bounding box update uses the previous box and the step size a, considering both +a and -a transitions clipped to [0,H]. This keeps loops restricted to plausible target heights.
- **Implementation details:** Factor all A_i up to 1000. Store only nonzero exponent events per prime, and process gaps as zero runs. The transition loop processes the union of the two active target intervals in segments, so each height is handled with the correct active DP(s). In the large middle region where both +a and -a contributions are valid, a faster loop without boundary checks is used. All entries are reduced modulo 998244353 after each transition.
- **Complexity:** The sum of T over all primes is at most 9(N-1), because A_i <= 1000 has at most 9 prime factors with multiplicity. The total height-edge work is O(N * sum_p T_p), around 9e6 in the worst case, with memory O(max T) <= about 9000.
- **Edge cases:** Primes absent from all A_i contribute 1. If T = 1, G_0 is computed with height 0 only and dies on a step of size 1. If a step size exceeds H, that G_H DP becomes dead. A_i = 1 introduces no prime events and only zero runs.
