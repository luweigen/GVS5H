Because target.length is at most 4, represent which targets are already satisfied by a bitmask. For a nums value x and a subset of targets, the cheapest way to make x cover that subset is to increment x to the next multiple of the lcm of that subset. Process nums with a DP where dp[mask] is the minimum operations needed to satisfy mask using the elements seen so far. For each x, try assigning it to every subset of targets, updating the DP with the cost for that subset, and also allow leaving x unused. The answer is dp[full_mask] after all nums are processed.
