A kept Snowflake is determined by its center c and a set B of x neighbors of c that become the blue vertices. A blue vertex b can have y leaves only if y <= deg(b)-1, because all other incident branches can simply be deleted. For a fixed c, assign each neighbor b the weight deg(b)-1; any feasible set with minimum weight m can be enlarged to include all neighbors with weight at least m, so the best choice for c is a prefix of the positive weights sorted descending. If the kth largest weight is w, the largest Snowflake centered at c using k blue vertices has size 1 + k + k*w. Maximize this value over all c and k, then the answer is N minus the maximum kept size.
