- **Core reduction:** Expand each entry of B^p as a sum over directed walks of length p. Every originally zero entry is an independent variable taking values in F_p^*. Summing a monomial over F_p^* vanishes unless every zero-variable exponent is 0 or a positive multiple of p-1. Each surviving zero-variable contributes a factor -1, so every surviving walk gets the global factor (-1)^K, where K is the total number of zeros.
- **Surviving walk shapes for p > 2:** The total walk length is p. Since p-1 >= 2, the only possible nonzero-exponent pattern is one zero edge used exactly p-1 times and one originally nonzero edge used once, or no zero edges at all. The no-zero-edge part is exactly A^p.
- **Zero diagonal corrections:** If a zero is a loop at u, the single nonzero edge can only be placed at the beginning or the end; placing it in the middle would require a nonzero loop at u, impossible because A[u][u] = 0. Thus a zero diagonal (u,u) adds column u and row u of A to A^p.
- **p = 3 off-diagonal corrections:** If a zero is a non-loop edge u -> v, it can be repeated twice only in the pattern z, e, z. The middle edge must be the reverse nonzero edge v -> u. Therefore, for p = 3 and zero off-diagonal (u,v), add A[v][u] to position (u,v). For p > 3, non-loop zero edges cannot be repeated p-1 times, so there are no off-diagonal corrections.
- **Small primes:** p = 1 is handled by printing all zeros. p = 2 has only one possible B, namely the all-ones matrix, and B^2 = N * J, so every output cell is N mod 2.
- **Implementation:** Read all input at once. For p > 2, build A, count K, and early-exit if A is all zero. Compute A^p as A * (A^2)^((p-1)//2) using binary exponentiation, skipping the final unnecessary square. Matrix multiplication uses i-k-j accumulation: skip zero row entries, special-case a = 1 and a = p-1 to avoid multiplication, and reduce each row modulo p after finishing its k-loop. Zero-row and zero-matrix checks provide small early exits.
- **Finalization:** Add the local corrections directly to A^p, then multiply every entry by (-1)^K modulo p and reduce modulo p before printing.
- **Complexity:** O(N^3 log p) time and O(N^2) memory. With N <= 100 and log p <= 30, this is practical. Corrections cost O(N^2).
