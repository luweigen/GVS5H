- **Core invariant:** For any sorted set of tracked initial ratings, the vector of current ratings F is nondecreasing after every contest, because each contest map x -> x or x+1 is nondecreasing. Therefore the indices whose current rating lies in [L,R] form one contiguous block [l, r1-1], where l is first F>=L and r1 is first F>=R+1.
- **Difference representation:** Instead of range-adding F, store F1=F[0] and D[j]=F[j+1]-F[j] for j=0..n-2. D is nonnegative and F[j]=F1+prefix_D(j). When a block [l, r1-1] is incremented, only F1 and two differences change: if l==0 then F1+=1; if l>0 then D[l-1]+=1; if r1<n then D[r1-1]-=1. This is the key simplification that replaces the assigned lazy segment tree range add with point updates.
- **Fenwick lower_bound:** Since D is nonnegative, prefix sums are nondecreasing. A Fenwick tree over D supports point add and lower_bound(target): smallest count j with prefix_D(j)>=target. To find first F>=v, use target=v-F1; target<=0 gives 0, target>total gives n, otherwise Fenwick lower_bound. total=sum D is maintained explicitly.
- **Hybrid tracked array:** Read all input first. Let M=max(queries), Q=len(queries). Use query-subset mode when next_power_of_two(Q) < next_power_of_two(M), otherwise full-domain 1..M, as in the assigned plan. In subset mode initial F is the sorted query list and D is its adjacent differences; in full mode F1=1 and D is all ones. This keeps n small when Q is much smaller than M.
- **Contest loop:** For each [L,R], compute l with target L-F1 and r1 with target R+1-F1. If r1==l, no tracked rating is in the interval. Otherwise apply the point updates above. The decrement D[r1-1] is safe because F[r1-1]<=R and F[r1]>=R+1, so that difference is at least 1.
- **Final extraction:** Reconstruct final F by walking D once. Full-domain: fill final_val[x] for x=1..M. Subset: fill final_val[x] while walking sorted_queries; duplicates have zero difference and receive the same value. Then answer original queries by direct lookup in final_val.
- **Complexity:** O((N+Q) log n + n + Q) time and O(n+M+Q) memory, where n is Q in subset mode and M in full mode. This is faster and simpler than the lazy segment tree plan; no lazy propagation or range add is needed.
- **Edge cases:** n=1 has empty D and total=0; the target checks handle all contests. Duplicate queries in subset mode are fine. Final ratings can reach 500000+200000, well within Python int. No padding or -INF is needed.
- **Samples:** Sample 1 was traced manually: sorted subset [2,3,5] evolves to [6,6,8], matching outputs. Sample 2 and 3 follow from the same invariant; the code uses the same boundary and update logic.
- **Superseded plan:** The iterative lazy segment tree with range add and first_ge is no longer used. It is correct but heavier; the difference/Fenwick method achieves the same monotone-array idea with point updates.
