- **Core reduction:** Label the 1s in their original left-to-right order. Adjacent swaps never need to change this relative order, so in any final contiguous block of length k, the i-th original 1 must occupy the i-th slot of the block.
- **Cost for a fixed block:** If the block starts at L using 0-indexing, the target position of the i-th 1 is L + i. Each adjacent swap moves exactly one 1 by one position, so the minimum swaps for that L is sum_i |p_i - (L + i)|, where p_i is the original 0-indexed position.
- **Median transform:** Rewrite the cost as sum_i |(p_i - i) - L|. Define a_i = p_i - i, equivalently the number of zeros before the i-th 1. The sequence a_i is nondecreasing because p_{i+1} >= p_i + 1.
- **Optimal L:** The sum of absolute deviations is minimized by any median of the a_i. Use a[k // 2], the upper median for even k. Since p_i >= i and p_i <= N - k + i, every a_i lies in [0, N - k], so the median is a feasible block start; clamping is optional and harmless.
- **Implementation:** Scan S once, maintain the count of seen ones, and append i - count for each '1'. Take the median and sum absolute differences. Python int handles the answer, which can be quadratic in N.
- **Complexity:** O(N) time and O(k) memory, where k is the number of 1s. With N <= 5e5, this is easily within limits.
- **Edge cases:** k = 1 gives an adjusted list of length 1 and answer 0. All ones gives all adjusted values 0 and answer 0. Alternating strings are handled by the same median formula.
- **Self-test:** The program includes a guarded --selftest mode. It compares the O(N) formula against a small-state BFS brute force for the three samples, single-1 strings, all-1 strings, alternating strings, and random small strings. It does not hardcode sample outputs. Normal execution with no special argument reads stdin and prints only the answer.
- **Pitfalls:** Use 0-indexed positions consistently. Do not divide the sum by 2. Do not use the median of raw positions; subtracting i is essential. Use arbitrary precision or 64-bit arithmetic.
