We can fix the final common sum S. For a fixed S, a known A value a and a known B value b can occupy the same position only if a+b=S; any known value larger than S is impossible, while unmatched known A/B can be paired with filled -1 entries as long as S is at least all known values. If k and m are the numbers of known A and B, pigeonhole forces at least L=max(0,k+m-N) known-known pairs, and this many pairs is also sufficient. For a fixed S, the maximum number of known-known pairs is sum over distinct a of min(cntA[a], cntB[S-a]). Therefore we only need to know whether some S>=max_known has this value at least L. Since N<=2000, enumerating all distinct (a,b) value pairs and accumulating min(cntA[a],cntB[b]) into the sum a+b is O(N^2) and decides the problem.
