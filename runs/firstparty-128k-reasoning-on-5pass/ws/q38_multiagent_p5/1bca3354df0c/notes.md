- **Correction to plan:** The proposed even-N rule with b = parity of components with size % 4 == 2 is not sufficient. Star K1,3 and P4 both have N=4, M=3, one component of size 4, but star is terminal (P) while P4 has one legal move (N). The correct b is the parity of components whose two bipartition sides are both odd (type E1). This requires BFS colors, despite the earlier note.
- **State reduction:** A connected bipartite component is described by side parities and q = missing cross edges mod 2. Types: E0=(0,0), E1=(1,1), O_iso=isolated (only the odd side is usable), O_full=odd size >=3 (both sides usable). Internal moves only flip q parity of one component; merge moves combine two components and the new type/q parity follow from side parities.
- **Merge type rules:** E0+E0->E0, E1+E1->E0, E0+E1->E1, E0/O_full or E1/O_full -> O_full, O_iso+O_iso->E1 forced, O_iso+O_full or O_full+O_full can produce E0 or E1. O_iso+E0/E1 -> O_full. Isolated vertices are the only O components with a restricted choice.
- **Parity invariant:** Let m=M mod2 and b=parity of E1 components. Since a*b is odd exactly for E1, total missing-edge parity is m xor b. If this is 1, an internal move is available; if 0, internal moves may still exist but are even-delay moves.
- **N odd:** Every final complete bipartite graph has an even number of edges, so every maximal play has length parity M mod2. First wins iff M is odd.
- **N even criterion:** Let u=#odd-size components, i=#isolated vertices, f=u-i, b=parity of E1 components, m=M mod2. If f=0 (i==u): first loses iff m == b xor ((u//2)&1). If f=1 or 2 (i>=u-2 and i!=u): first always wins. If f>=3: first loses iff m==0.
- **Proof sketch:** The type transitions preserve the above predicate as a kernel. From P states every legal move flips m or changes f/u/b into an N state. From N states a winning move exists: for f=0 use an internal move if m xor b=1, otherwise merge two isolated vertices; for f=1 merge an isolated with a full odd component and choose E0/E1; for f=2 merge the two full odd components and choose E0/E1; for f>=3,m=1 use an internal move if b=0, or merge an E1 with a full odd component (or two full components when f>=5) to reach f>=3,m=0.
- **Implementation details:** Iterative BFS/DFS with a color array counts c0,c1 for each component. For even size, b toggles when both c0 and c1 are odd. For odd size, increment u and i if size==1. No recursion, O(N+M) time and memory.
