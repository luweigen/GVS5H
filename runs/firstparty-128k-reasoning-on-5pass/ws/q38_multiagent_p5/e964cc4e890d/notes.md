- **Strong connectivity:** The original path edges only go forward. A graph is strongly connected iff every proper prefix cut has at least one added edge from the suffix to the prefix, i.e. a white vertex after the cut matched to a black vertex before the cut.
- **Early exits:** If the first vertex is white, the first prefix has no black vertex to receive a backward edge. If the last vertex is black, the last proper prefix has no white vertex in the suffix. Both give answer 0.
- **Prefix constraints:** Order white vertices and black vertices increasingly. Let q_j be the white index matched to the j-th black. For black count a, the strongest prefix cut is just before the next black; let D_a be the number of whites there. The condition is max(q_1,...,q_a) > D_a. For a=N, D_N=N-1 and the condition is automatic.
- **First occurrences:** D_a is nondecreasing. For a block with the same D=x, the prefix maximum is nondecreasing, so only the first index L of that block matters. If L > x, the constraint is automatic. Keep pairs (L_i, x_i) for first occurrences with L_i <= x_i.
- **Inclusion-exclusion recurrence:** For a selected set of constraints, the number of permutations making the corresponding rectangles empty factors into factorial ratios. Summing over subsets gives A_i = -(fact[x_i] + sum_{j<i} A_j fact[x_i-L_j]) / fact[x_i-L_i]. The answer is fact[N] + sum_i A_i fact[N-L_i].
- **CDQ divide-and-conquer:** Compute A online. For a node, after solving the left half, add its contributions to the right half: contrib[i] += sum_{j in left} A[j] * fact[x_i-L_j]. Then solve the right half.
- **Python convolution trick:** Instead of NTT, use exact big-integer convolution in base 2^80. Pack A_j at digit L_j-a and the factorial prefix fact[0..maxy] into 10-byte little-endian digits. Since N*MOD^2 < 2^78, all needed low coefficients are below base 2^80, so no carry corrupts them. Extract 10-byte chunks for the right-side x_i values.
- **Direct fallbacks:** Use direct loops for small left*right products. In big crosses, if at most 32 left A-values are nonzero, direct loops are faster than packing/multiplying.
- **Precomputation:** Factorials and inverse factorials modulo 998244353. Also precompute a packed bytes object for factorial digits to build the right convolution factor quickly.
- **Brute force:** For N <= 8, enumerate all N! bijections and check max-prefix constraints; the main program uses this for small N.
- **Edge cases:** m=0 gives fact[N]. D_N is ignored because it is automatic. D values 0 are skipped because L>=1. All modular divisions use invfact.
