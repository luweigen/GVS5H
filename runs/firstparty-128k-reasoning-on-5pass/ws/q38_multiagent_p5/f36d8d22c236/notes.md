- **Reduction:** Only the 26 letters matter. For every letter c appearing in S, all positions with S[i]=c must have the same T[i]; otherwise print -1. This gives a function f(c) for appearing letters A.
- **Mandatory moves:** If f(c) != c, the token originally in bin c must at some point leave bin c, so an operation with x=c is unavoidable. These are distinct for different c, giving lower bound m = count of c in A with f(c) != c.
- **Graph model:** Edge c -> f(c) for c in A. If f(c) is not in A, the edge goes to an initially empty bin and cannot be part of a directed cycle. Indegree is counted only over A, including self-loops for fixed points.
- **Non-pure cycles:** If a nontrivial cycle has an incoming edge from outside, say u -> v and p is the cycle predecessor with p -> v, then p and u have the same final target v. Moving p -> u is safe, then the rest of the cycle can be rotated, then u -> v. This uses exactly one operation for each nonfixed letter involved, so no extra cost. Trees feeding into u are processed after u is emptied.
- **Pure cycles:** A nontrivial cycle with every node indegree 1 has no incoming present edge. Its first token must be moved to an outside bin, and that bin must later be moved into the cycle. The second move cannot be one of the m mandatory moves, so each pure cycle adds exactly 1. Different pure cycles cannot share the extra move because their tokens have different final targets.
- **Buffer availability:** If len(A) < 26, a letter absent from S is an empty buffer. If len(A) == 26 but not all indegrees are 1, some letter has indegree 0; it is nonfixed and its final bin is empty, so its mandatory moves can create a reusable buffer. If len(A) == 26 and all indegrees are 1, the mapping is a permutation. With a nontrivial cycle, no safe first move exists (equivalently S and T both contain all 26 letters, so distinct count cannot be preserved), hence -1.
- **Formula:** answer = m + pure_cycles, except -1 for inconsistent mapping or for pure_cycles > 0, len(A) == 26, and all indeg[c] == 1 for c in A.
- **Implementation:** Use 26-element arrays. target[c] = -1 means c not in S. present[d] tells whether an edge stays inside A. Cycle detection with state 0/1/2 over A; count cycles of length at least 2 where every node has indegree 1.
- **Pitfalls:** Do not count differing positions; count letters. Fixed points are not nontrivial cycles. A cycle with any incoming edge is not pure and needs no extra. One buffer can be reused for many pure cycles, but each pure cycle still contributes one extra operation.
