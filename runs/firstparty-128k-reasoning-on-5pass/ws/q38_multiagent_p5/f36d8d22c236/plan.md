First check that each character of S has a single required target in T; if not, output -1. Build the functional graph on the letters that appear in S, with edge c -> f(c), and count m, the number of appearing letters whose target differs from itself. A directed cycle of length at least 2 needs one extra operation only if it is pure, meaning no appearing letter outside the cycle points into it (equivalently every cycle node has indegree 1). If all 26 letters appear in S and the mapping is a permutation (all indegrees are 1) while there is a nontrivial cycle, no temporary empty letter can ever be created, so the answer is -1. Otherwise, the minimum number of operations is m plus the number of pure nontrivial cycles.
