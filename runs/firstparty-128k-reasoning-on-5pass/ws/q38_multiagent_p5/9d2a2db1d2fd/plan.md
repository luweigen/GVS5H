Zero-cost walkways at floor x connect exactly the cells whose building height is at least x, so the only cost is vertical movement between floors. For a fixed grid path, if M is the minimum building height on the path, the optimal stair count from floor y to floor z is |min(y,M)-min(z,M)| + max(0,y-M)+max(0,z-M), and this value is nonincreasing as M increases. Hence each query only needs B, the maximum bottleneck height between the start and end cells, i.e. the largest threshold for which they are connected in the subgraph of buildings with height at least that threshold. This bottleneck can be obtained by Kruskal on grid edges weighted by min(F_u,F_v) in descending order. Process all queries offline during this Kruskal run by keeping pending query IDs in each DSU component and resolving a query at the merge weight when its two endpoint components first meet. Same-building queries are handled directly with B equal to that building's height, and the final answer is obtained by applying the formula to B.
