Process the insertions in reverse order. After all operations, if we remove elements greater than i, the remaining elements 1..i form exactly the array after step i, so element i must be the P_i-th element among the positions reserved for elements 1..i. Maintain a Fenwick tree over the N final positions, initially all empty. For i from N down to 1, find the P_i-th empty position, place i there, and mark that position occupied. This reconstructs the final array in O(N log N), which is efficient for N up to 5×10^5.
