- **Core identity:** For a fixed subarray, only the set of distinct values matters. One operation can erase exactly one consecutive block of present values, so the minimum number of operations equals the number of connected components of the present values on the integer line.
- **Component-start form:** A component starts at a present value x whose predecessor x-1 is absent. Therefore f(L,R) is the number of x such that x appears in A[L..R] and x-1 does not appear in A[L..R]. For x=1, x-1=0 is always absent.
- **Summation swap:** The required sum is sum over x of the number of subarrays containing x and containing no x-1. This avoids enumerating subarrays directly.
- **Gap counting for fixed x:** Let P be positions of x and B be positions of x-1. Add sentinels 0 and N+1 to B. A valid subarray must lie completely inside one gap between consecutive blockers: [prev+1, blocker-1]. In a gap of length m, there are m(m+1)/2 subarrays.
- **Subtract no-x subarrays:** Inside a gap, if the x positions are p1...pk, subarrays with no x are exactly those contained in the x-free segments [left,p1-1], [p1+1,p2-1], ..., [pk+1,right]. For a segment of length s, add s(s+1)/2.
- **Monotonic pointer:** Process gaps in increasing order while keeping an index into P. Skip P positions before the gap, process all P positions inside the gap, and leave the index at the first P position after the gap. Each occurrence of x is processed once for its x.
- **Complexity:** The outer loop is O(N). Total blocker iterations over all x are O(N) because each position of value y is scanned only when processing x=y+1, and only if x is present. Total x-position iterations are O(N). Memory is O(N) for the position lists.
- **Implementation details:** Use pos[0..N], with pos[0] empty. If a gap contains no occurrence of x, its contribution is zero and can be skipped. Python integers handle the final answer safely.
- **Sample checks:** The implemented counting gives 16 for sample 1, 23 for sample 2, and 129 for sample 3.
