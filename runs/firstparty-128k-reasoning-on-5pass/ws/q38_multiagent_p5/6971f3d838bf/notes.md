- **Reduction:** Deleting a non-negative value cannot improve over the original array: any subarray in the filtered array maps to an original interval whose sum is at least as large. Only negative deleted values can improve the answer.
- **Non-positive shortcut:** If the original non-empty maximum subarray sum is <= 0, all elements are <= 0. Deleting values cannot create a positive sum or a larger maximum, so return the original maximum immediately.
- **Fixed negative x formulation:** For x < 0, replace every x by 0. Let P_i be the original prefix sum, B_i(x) = -x * count_x(1..i), and Q_i = P_i + B_i. The empty-allowed maximum subarray ending at i is P_i + R_i(x), where R_i(x) = B_i(x) - min_{j<=i} Q_j.
- **Lazy invariant:** h = -min original prefix sum. For a seen negative value y, raw[y] stores R at its last occurrence. Between occurrences, actual R_i(y) = max(raw[y], h). For unseen negative values, R_i(y) = h. Therefore max over all negative y of R_i(y) is max(max_raw, h).
- **Update rules:** On y > 0, only the prefix sum grows, so update best with g + max(max_raw, h). On y < 0, the old actual R for y is max(raw.get(y, 0), h before update); new raw[y] = old - y. Then update g and h, and update best. Zeros require no update.
- **Non-empty safety:** best is initialized to 0 and only matters when original max > 0. Empty-allowed Kadane may produce 0 for all-zero filtered arrays, but taking max with the original positive maximum preserves the non-empty subarray requirement.
- **Invalid deletion handling:** If the only distinct value is deleted, the array would become empty. In the positive branch this cannot be the optimal case because a positive element exists; in the non-positive branch the original maximum is already optimal.
- **Complexity:** One pass over nums, O(n) time. The dictionary stores at most one entry per distinct negative value, O(n) memory.
- **Tests:** Both provided examples pass: [-3,2,-2,-1,3,-2,3] gives 7, and [1,2,3,4] gives 10. Edge cases checked include n=1, all equal positive/negative/zero, all negative, all positive, mixed zeros, repeated negatives, and small random arrays compared against brute force over all valid deletions with Kadane; no mismatches found.
