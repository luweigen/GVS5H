Binary search the minimum possible maximum run length `L`. For a fixed `L`, check feasibility with a dynamic program that computes the minimum number of flips needed to make every run length at most `L`. The DP state tracks the last character and the current run length, and transitions try placing either `0` or `1` at the next position. A candidate `L` is feasible if the minimum flips is at most `numOps`. Since feasibility is monotonic in `L`, binary search over `1..n` finds the answer.
