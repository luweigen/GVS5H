Construct the Kruskal reconstruction tree by processing graph edges in nondecreasing weight and creating a parent node whenever two DSU components merge; the parent’s value is the edge weight. In this tree, the bottleneck distance \(f(x,y)\) equals the value of the lowest common ancestor of vertices \(x\) and \(y\). Perform a bottom-up DP: within each subtree, optimally match as many unmatched \(A\)-occurrences and \(B\)-occurrences as possible, paying the subtree’s merge weight for pairs first matched there, and propagate the remaining surplus of one side upward. The final DP value at the root is the minimum total matching cost.
