Model each building pair \((j,i)\) with \(X_j<X_i\): building \(i\) is blocked from height \(h\) whenever the line of sight to its top cannot pass above building \(j\). The critical height for this pair is the \(y\)-intercept of the line through \((X_j,H_j)\) and \((X_i,H_i)\), namely \((X_iH_j-X_jH_i)/(X_i-X_j)\). The answer is the maximum nonnegative critical height over all pairs; if every critical height is negative, height \(0\) already sees all buildings and the answer is \(-1\). Compute the maximum efficiently using a monotone feasibility test and binary search, where a candidate \(m\) is feasible to obstruct some building iff some earlier \((H_j-m)/X_j\) is at least \((H_i-m)/X_i\).
