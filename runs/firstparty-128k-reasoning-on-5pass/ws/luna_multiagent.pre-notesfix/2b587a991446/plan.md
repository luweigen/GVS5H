Model the configuration as an ordered pair \((a,b)\) of distinct vertices, where one operation changes exactly one coordinate along an edge while preserving \(a\ne b\). Since the full state graph has \(N(N-1)\) states, derive a graph-specific shortest-path method that avoids explicitly constructing it and prove its correctness. Pay special attention to parity, bipartite components, and the impossibility case illustrated by the two-vertex graph. Then implement the resulting algorithm in \(O(N+M)\) or near-linear time with memory suitable for \(2\times10^5\) vertices and edges.
