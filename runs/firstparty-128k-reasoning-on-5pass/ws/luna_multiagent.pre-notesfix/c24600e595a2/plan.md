Model each operation as moving between binary states with the cost of the destination state. Prove that an optimal route never flips a bit initially and finally equal to 0, while a bit initially and finally equal to 1 may optionally be flipped off and later restored. For any chosen set of temporary deactivations, all 1-to-0 flips should be performed in descending order of \(C_i\), followed by all 0-to-1 flips in ascending order of \(C_i\). Optimize which equal-to-1 bits are temporarily deactivated using sorted costs, prefix sums, and a linear or near-linear dynamic-programming/marginal analysis.
