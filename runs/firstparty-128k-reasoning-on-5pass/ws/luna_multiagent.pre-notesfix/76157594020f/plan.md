Binary-search the smallest possible maximum run length \(L\). For each candidate \(L\), use dynamic programming over the string, tracking the final character and the length of its current identical run; transitions either keep or flip the next character, subject to the run-length limit. The feasibility check returns whether the minimum required flips is at most `numOps`, and the binary search finds the minimum feasible \(L\). This runs in \(O(n^2 \log n)\) time in the worst case and uses \(O(nL)\) space, which is sufficient for \(n \le 1000\).
