Use four diagonal direction vectors in clockwise order: NE, SE, SW, NW, where a clockwise turn maps each direction to the next one. For every cell containing `1`, try each initial direction and use memoized DFS states `(row, col, direction, turned, parity)`, where parity determines whether the next value must be `2` or `0`. Each state can continue straight, and if no turn has been used, it may also continue after one clockwise turn; take the maximum resulting length. The total state space is `O(nm)` up to a constant factor, with `O(nm)` memory and time.
