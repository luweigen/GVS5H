Build a mapping from each character in `S` to the corresponding character in `T`; if one source character maps to multiple targets, the transformation is impossible. Every non-identity mapping requires one operation, while each directed cycle of non-identity mappings requires one additional temporary operation to break the cycle. A temporary character is available if some lowercase letter does not appear in `T`; otherwise, any cycle makes the transformation impossible. Count the mappings and cycles, then output the minimum total.
