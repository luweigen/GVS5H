Compute the inversion count for \(k=0\) using a Fenwick tree over values \(0\ldots M-1\). As \(k\) increases by one, each element’s residue changes from \(x\) to \(x+1\) modulo \(M\), so only elements currently equal to \(M-1\) wrap to \(0\). Derive the inversion-count delta for the wrapping elements using their counts before and after each position, allowing all \(M\) answers to be generated in \(O(N+M)\) after preprocessing.
