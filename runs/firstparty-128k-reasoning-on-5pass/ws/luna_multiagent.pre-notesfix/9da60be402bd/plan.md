Model each state as an ordered vertex pair \((u,v)\), representing a palindrome-compatible path whose unmatched middle currently lies between \(u\) and \(v\). From \((u,v)\), add transitions to \((x,y)\) whenever edges \(u\to x\) and \(y\to v\) exist with the same label, increasing the eventual path length by 2. Initialize answers with \(0\) for \(u=v\) and \(1\) for every direct edge, then compute the minimum distances to all states using a multi-source shortest-path search over the \(N^2\) pair states. For each pair, the answer is the minimum of its even-length state distance and one plus the distance of any state connected by a direct edge between its two vertices.
