Process each query \((X,Y)\) by considering only the prefixes \(A_1\ldots A_X\) and \(B_1\ldots B_Y\). Sort the values in each prefix incrementally and maintain prefix sums, allowing the sum of absolute differences between a newly added value and the opposite prefix to be computed via binary search in \(O(\log N)\). Since queries may request arbitrary prefix sizes, sort queries offline by \(X\) and incrementally extend the \(A\)-prefix; for each query, similarly use a persistent or precomputed structure for the \(B\)-prefix. A practical solution can build a persistent segment tree over compressed values for every prefix of \(B\), supporting count and sum queries on values less than a given value, then answer each pair in \(O(\log N)\).
