For a chosen final common height \(H\), each pair must satisfy \(u_i+d_i=H\), so the final upper-tooth length \(u_i\) lies in \([\max(0,H-D_i),\min(U_i,H)]\). Check feasibility of \(H\) by propagating the interval of possible upper-tooth lengths from left to right, expanding the previous interval by \(X\) and intersecting it with the current tooth’s allowed interval. Feasibility is monotone in \(H\), so binary search for the maximum feasible \(H\), which minimizes the total grinding cost \(\sum_i(U_i+D_i)-NH\). Use 64-bit integers for the answer and intermediate sums.
