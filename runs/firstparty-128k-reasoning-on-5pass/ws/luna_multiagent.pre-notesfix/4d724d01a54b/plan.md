The minimum cost can be determined independently for every boundary between positions \(i\) and \(i+1\). Let \(k_i\) be the number of elements initially among the first \(i\) positions whose values exceed \(i\); exactly \(k_i\) elements must cross that boundary to reach their correct sides. Since each crossing costs \(i\), the answer is \(\sum_{i=1}^{N-1} i k_i\). Compute \(k_i\) efficiently with a Fenwick tree while scanning the permutation, and use 64-bit integer arithmetic.
