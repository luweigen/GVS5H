Observe that \(f(L,R)\) equals the number of maximal consecutive-value components among the distinct values appearing in \(A_L,\ldots,A_R\). For a fixed right endpoint \(R\), let \(\mathrm{last}[v]\) be the latest position \(\le R\) containing value \(v\), with \(\mathrm{last}[0]=0\); the number of subarrays ending at \(R\) whose value set has a component starting at \(v\) is \(\max(0,\mathrm{last}[v]-\mathrm{last}[v-1])\). Thus the total contribution of all subarrays ending at \(R\) is \(S_R=\sum_v\max(0,\mathrm{last}[v]-\mathrm{last}[v-1])\). Updating \(A_R=x\) changes only the terms for \(v=x\) and \(v=x+1\), so maintain the sum in \(O(1)\) per element and accumulate all \(S_R\).
