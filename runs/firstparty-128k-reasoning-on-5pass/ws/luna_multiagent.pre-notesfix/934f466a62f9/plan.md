Model each selected pair as being “charged” to one coordinate that attains the pair’s maximum; then the pair contributes the sum of that coordinate over its two endpoints. Since arbitrary vertices can be paired within each charged coordinate class, the problem reduces to selecting exactly \(2K\) cakes, assigning each to beauty, tastiness, or popularity, and requiring every assignment class to have even size. Develop an efficient optimization for this three-class parity-constrained selection, exploiting that only three parity bits and the fixed cardinality matter, then reconstruct the maximum value without explicitly building pairs. Validate the resulting algorithm against edge cases such as duplicate cakes, zero values, and \(K=N/2\).
