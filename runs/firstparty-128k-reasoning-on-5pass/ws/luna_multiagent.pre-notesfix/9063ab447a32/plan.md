For a fixed total of \(K\) units, minimize the purchase cost by distributing units among products so that marginal costs are globally smallest. The marginal cost of adding the \(j\)-th unit of product \(i\) is \((2j-1)P_i\), so the problem becomes selecting the \(K\) smallest values among these sequences. Use binary search on \(K\), and compute the minimum cost for that total efficiently by finding a threshold marginal cost and counting how many terms from each sequence are below it. Handle ties by adding the required number of equal-cost marginal units, then binary search the maximum feasible \(K\).
