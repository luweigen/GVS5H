Process each possible non-zero ending digit \(d \in [1,9]\) independently. For each position, maintain counts of remainders modulo \(d\) for all substrings ending at the previous position; appending the current digit transforms every remainder \(r\) into \((10r+x)\bmod d\), while also creating the one-digit substring. If the current digit equals \(d\), add the number of newly formed substrings whose remainder is zero, since exactly those substrings are divisible by their last digit. This requires \(O(9n)\) time and \(O(9^2)\) auxiliary space.
