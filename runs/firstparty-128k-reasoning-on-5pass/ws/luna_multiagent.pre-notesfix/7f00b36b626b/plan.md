Use a DSU to maintain connected components among values not exceeding `threshold`; any value greater than the threshold is isolated because every LCM containing it is also greater than the threshold. For each present value `x <= threshold`, iterate through its multiples `m = x, 2x, ...` up to `threshold`, since two values are adjacent exactly when their LCM is some common multiple within this range. At each multiple, union the current value with one previously encountered value dividing that multiple; this captures every edge because any adjacent pair meets at `m = lcm(a, b)`. Initialize the component count to the number of input values and decrement it on every successful union, yielding an `O(threshold log threshold)` solution.
