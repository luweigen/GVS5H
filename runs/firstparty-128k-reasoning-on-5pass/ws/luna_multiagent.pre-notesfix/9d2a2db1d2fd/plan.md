Model each block as a vertex and each adjacent pair as an edge whose capacity is the minimum floor count of its two buildings. For any fixed route, only the minimum edge capacity along that route matters: the traveler can preserve a floor level up to that bottleneck, and any excess endpoint height must be handled by stairs. Thus the optimal route is one maximizing the bottleneck capacity between the two blocks, obtainable from a maximum spanning tree. Preprocess binary-lifting/LCA minimum-edge queries on that tree, then answer each query in \(O(\log(HW))\) using the endpoint floors and the bottleneck.
