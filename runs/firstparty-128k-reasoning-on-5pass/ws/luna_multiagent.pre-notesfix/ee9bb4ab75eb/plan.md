Build a trie containing all words, storing each node’s total number of words passing through it. A prefix of depth `d` can be shared by at least `k` remaining strings exactly when its trie node has count at least `k`; maintain, for every depth, whether any such node exists. For each removed word, temporarily invalidate trie nodes on its path whose count is exactly `k`, query the deepest still-valid depth using a segment tree, then restore those nodes. If fewer than `k` strings remain, return `0`; total per-word processing is proportional to the total input length.
