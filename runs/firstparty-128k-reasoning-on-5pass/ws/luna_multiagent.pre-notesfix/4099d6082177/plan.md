Root the tree and process vertices bottom-up, maintaining for each subtree whether it is fully decomposed or has exactly one unfinished path whose endpoint is the subtree root. At each vertex, collect unfinished-path lengths from its children and pair them so that two paths together with the current vertex form a path of exactly \(K\) vertices. Because the current vertex can belong to at most one resulting path, all child lengths must be complementary with respect to \(K-1\), except possibly one leftover path that is extended upward. The root is valid precisely when its subtree has no unfinished path; handle \(K=1\) directly.
