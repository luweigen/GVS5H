Let prefix sums be \(P_0=0\) and \(P_i=\sum_{j=1}^i A_j\); every subarray sum is \(P_r-P_{l-1}\). For each right endpoint \(r\), expand \((P_r-P_j)^K\) using the binomial theorem and maintain, over all previous prefixes \(P_j\), the sums of powers \(P_j^t\) for \(0\le t\le K\). Each endpoint is processed in \(O(K)\), yielding total \(O(NK)\) time and \(O(K)\) memory modulo 998244353.
