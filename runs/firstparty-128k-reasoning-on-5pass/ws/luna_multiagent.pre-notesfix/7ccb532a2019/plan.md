Enumerate the common positive frequency \(k\) of the resulting good string, considering every \(k\) from 1 through \(|s|\), plus deleting all characters as a fallback if the empty string is considered good. For a fixed \(k\), each letter’s final count is either 0 or \(k\), so use a two-state DP over the 26 letters indicating whether the current letter is retained at frequency \(k\). Start with the independent cost \(|f_i-x_i|\), where \(f_i\) is the original frequency and \(x_i\in\{0,k\}\); an adjacent forward change can improve this cost by one for each unit transferred from a surplus at letter \(i\) to a deficit at letter \(i+1\). Since moving two or more positions costs at least as much as deleting and reinserting, an optimal solution only needs adjacent transfers, making each \(k\) evaluation constant-time over the alphabet and yielding \(O(26|s|)\) time.
