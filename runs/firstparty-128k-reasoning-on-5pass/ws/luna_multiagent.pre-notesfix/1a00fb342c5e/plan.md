Model each constraint as an XOR relation on a graph: assign each vertex a potential relative to an arbitrary root, and detect contradictions while traversing every connected component. If a contradiction occurs, output `-1`. Otherwise, each component has one free XOR offset `t`, so each vertex value is `potential[v] XOR t`; optimize the component’s contribution independently by choosing `t` bit-by-bit, setting each bit to the minority choice among the vertices’ potentials. Isolated vertices are handled as components with zero potentials, yielding value zero.
