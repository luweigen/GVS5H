Compute the number of distinct values in every prefix and suffix. Sweep the second cut position \(j\) from left to right, maintaining for every possible first cut \(i<j\) the value \(\mathrm{distinct}(A_{1..i})+\mathrm{distinct}(A_{i+1..j})\). When processing \(A_j\), use its previous occurrence to apply a range increment to exactly those \(i\) for which this occurrence is new in the middle segment. A lazy-propagation segment tree supports these range additions and maximum queries in \(O(\log N)\), yielding an overall \(O(N\log N)\) solution.
