Use sqrt decomposition on the index prefixes with a block size around 250–350. Precompute the answer for all full-block prefixes by computing the absolute-sum cost of every A block against every B block in O(block size) using sorted blocks, then taking a 2D prefix sum. For the partial blocks in a query, answer each single element against the opposite prefix using a wavelet tree/matrix (or persistent segment tree) that returns count and sum of values ≤ x in a prefix in O(log N). Combine the O(1) full-block answer with the O(block size log N) remainder contributions, taking care not to double-count the remainder-remainder part. This yields O(N²/B + K·B·log N) time and O(N log N) auxiliary memory, which fits the constraints with 64-bit integers.
