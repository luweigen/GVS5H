Process the insertions in reverse order to determine final positions. When considering element i from N down to 1, all larger elements already have their final positions fixed, and element i must occupy the P_i-th still-empty position in the final array. Maintain a Fenwick tree over the N positions, where 1 means empty and 0 means filled. For each i, find the P_i-th empty position using a Fenwick lower-bound query, place i there, and mark that position filled. This gives an O(N log N) solution with O(N) memory, which is sufficient for N up to 5×10^5. Finally, output the array in increasing position order.
