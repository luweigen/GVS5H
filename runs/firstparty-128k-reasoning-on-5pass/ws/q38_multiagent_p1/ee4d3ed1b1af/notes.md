- **Pattern model:** Split `p` into `A`, `B`, `C` by the two stars. A valid match is an occurrence of `A`, then `B`, then `C` in `s`, with `A_end <= B_start` and `B_end <= C_start`. Empty parts are skipped. The shortest substring starts at the first required literal and ends at the last required literal; leading/trailing stars can be zero length.
- **Search:** Use KMP prefix-function search for each nonempty literal to collect all start positions in `s`. KMP allows overlapping matches and runs in `O(|s| + |literal|)` per literal, so total time is linear in the input sizes. Do not call KMP on empty strings. If a required nonempty literal has no occurrence, return `-1`.
- **B nonempty:** Iterate `B` starts in increasing order. Maintain a pointer over `A` starts and remember the latest `A` whose end is `<=` current `B` start; this minimizes the left boundary for that `B`. Maintain a pointer over `C` starts and take the earliest `C` whose start is `>=` current `B` end; this minimizes the right boundary. If `A` is empty, use `B` start as the left boundary. If `C` is empty, use `B` end as the right boundary. Take the minimum `end - start`.
- **B empty:** The two stars collapse into one gap. If both `A` and `C` are nonempty, iterate `C` starts and use the latest `A` with `A_end <= C_start`. If only `A` or only `C` is nonempty, return its length when it occurs. If all are empty, return `0`.
- **Off-by-one:** Use exclusive end positions. Adjacent literals are allowed, so use `<=` for `A` before `B`/`C` and `>=` for `C` after `B`. Overlapping literal occurrences are invalid.
- **Edge cases:** `p == "**"` returns `0`. Patterns like `"a**"`, `"*a*"`, and `"**a"` reduce to one required literal. Adjacent stars make `B` empty. No valid ordered combination returns `-1`. The four provided examples and small edge cases such as single-character strings, adjacent literals, and overlapping same-character literals are consistent with this logic.
