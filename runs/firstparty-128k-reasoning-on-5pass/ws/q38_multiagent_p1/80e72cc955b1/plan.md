For each integer x, the number of times it must be divided by 4 to become 0 is its base-4 digit count t(x), which is constant on intervals [4^{k-1}, 4^k - 1]. One operation can apply one division to two elements, so the minimum operations for a fixed array are the minimum makespan of unit tasks with processing times t(x): max(max t(x), ceil(sum t(x) / 2)). Since t(x) is nondecreasing, max t(x) over [l, r] is simply t(r), and the sum can be answered by a prefix function F(n) = sum_{x=1}^n t(x) computed from base-4 blocks. For each query, compute total = F(r) - F(l - 1) and add max(t(r), (total + 1) // 2). This gives an efficient O(log r) or O(1) per query solution, easily within the constraints.
