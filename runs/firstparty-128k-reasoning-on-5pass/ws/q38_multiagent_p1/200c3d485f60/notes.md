- **Core formula:** There are `n - 1` adjacent gaps. Choose exactly `k` of them to be equal, giving `C(n - 1, k)` gap patterns. For any fixed pattern, start with `m` choices for the first element. An equal gap has exactly `1` continuation, while a different gap has `m - 1` continuations. Therefore the answer is `C(n - 1, k) * m * (m - 1)^(n - 1 - k)` modulo `1_000_000_007`.
- **Runs interpretation:** The `k` equal gaps merge positions into `n - k` runs. Adjacent runs must have different values, so a fixed run partition can be colored in `m * (m - 1)^(n - k - 1)` ways. Since `n - k - 1 = n - 1 - k`, this matches the gap-pattern formula.
- **Why no overcount:** Each array has a unique set of equal adjacent gaps. For a chosen set, forcing unchosen gaps to be different is exactly equivalent to coloring adjacent runs with different values. The number of valid colorings depends only on the number of runs, not on run lengths.
- **Edge cases:** `n = 1` has `gaps = 0`, so only `k = 0` is valid and the answer is `m`. `m = 1` is handled directly: only the all-ones array exists, so the answer is `1` when `k = n - 1` and `0` otherwise. `k = 0` and `k = n - 1` are naturally covered by the binomial coefficient and zero exponent.
- **Modular arithmetic:** The modulus is prime and `n - 1 <= 100000`, far below the modulus, so factorial inverses exist. Use `C(N, K) = fact[N] * invfact[K] * invfact[N - K] mod MOD`.
- **Implementation choices:** A class-level lazy factorial cache extends only to the largest `n - 1` seen, so repeated calls avoid rebuilding factorials. Each call performs one modular exponentiation for `(m - 1)^(n - 1 - k)`. The direct `m == 1` shortcut avoids relying on `0^0` behavior, although Python’s `pow(0, 0, MOD) == 1` would also make the formula work.
- **Verified cases:** Provided examples pass: `(3, 2, 1) -> 4`, `(4, 2, 2) -> 6`, `(5, 2, 0) -> 2`. Boundary checks pass: `(1, 1, 0) -> 1`, `(1, 5, 0) -> 5`, `(2, 1, 0) -> 0`, `(2, 1, 1) -> 1`, `(3, 1, 2) -> 1`, `(3, 1, 1) -> 0`, `(2, 3, 0) -> 6`, `(2, 3, 1) -> 3`, `(3, 3, 1) -> 12`, and large `n = 100000` cases for `m = 1` and `k = n - 1`.
