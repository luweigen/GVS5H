Treat each adjacent equality as merging neighboring positions into a run, so exactly k equal adjacencies imply n-k runs. The k equal gaps can be chosen in C(n-1, k) ways, equivalently the run lengths are positive compositions of n into n-k parts. For a fixed run partition, assign values to runs so adjacent runs differ, giving m * (m-1)^(n-k-1) colorings. Handle m=1 carefully, where the formula naturally yields 1 only when k=n-1 and 0 otherwise.
