Root the tree arbitrarily and process vertices in postorder. For a subtree, all completed paths have K vertices, so if the subtree is not fully partitionable, the single unfinished path containing the subtree root must have size exactly equal to the subtree size modulo K. Therefore each child is either closed (remainder 0) or forces the parent to use that child's open path, and a vertex can use at most two such open children. With zero open children the vertex remains an open path of size 1; with one open child it is always extendable; with two open children they are valid only if their remainders plus the vertex sum to K. This gives a linear-time bottom-up decision, with K=1 trivially Yes.
