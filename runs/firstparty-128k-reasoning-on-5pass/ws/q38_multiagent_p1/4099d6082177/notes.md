- **Core lemma:** For any edge e, let S be one side after removing e. If |S| is divisible by K, no path can use e; if |S| is not divisible by K, e must be used. A path using e contributes between 1 and K-1 vertices to S, while every other path lying in S contributes K vertices. Since the whole tree has NK vertices, the condition is independent of which side is chosen.
- **Consequence:** The set of edges that must be inside paths is uniquely forced. Root the tree at 1; for a child c of v, keep edge v-c exactly when the subtree size of c modulo K is nonzero. All other edges are cut.
- **Decision:** After forcing these edges, a valid decomposition exists iff every connected component of the kept-edge forest is a path with exactly K vertices. In a tree, maximum degree at most 2 plus size K is equivalent to being a K-vertex path.
- **Implementation:** Read all input. If K=1, answer Yes immediately. Build adjacency. Root iteratively with a parent array and an order list to avoid recursion. Compute subtree sizes modulo K in reverse order: start s=1, add each child's modulo, subtract K once when needed. Then traverse the kept forest with a stack, using the parent array to test whether an edge is kept. For each component count vertices and kept degree; fail if count exceeds K, degree exceeds 2, or final count differs from K.
- **Complexity:** O(NK) time and memory, linear in the number of vertices. Three linear scans of the adjacency lists.
- **Edge cases:** K=1 is trivial. N=1 reduces to checking whether the whole tree is a path. Stars fail by degree. A path of NK vertices passes. Zero-modulo child edges are cut, not open.
- **Pitfalls:** Do not use recursion on 2e5 vertices. Do not treat a zero-modulo child as an open path. The component size must be exactly K, not merely a multiple of K. The root side modulo is safe because total size is divisible by K.
