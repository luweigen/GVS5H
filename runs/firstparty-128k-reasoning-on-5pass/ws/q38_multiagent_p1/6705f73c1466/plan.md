Model the ones as ordered tokens and note that adjacent swaps preserve their relative order, so the cost to move them into a block starting at \(l\) is \(\sum_i |pos_i - (l+i)|\). For fixed \(l\), this is a sum of absolute deviations from \(l\) after subtracting \(i\) from each position, so the optimal \(l\) is a median of the values \(pos_i - i\). Clamp that median to the valid start range \([1, N-k+1]\), then sum the absolute moves. This gives an \(O(N)\) algorithm using 64-bit integers.
