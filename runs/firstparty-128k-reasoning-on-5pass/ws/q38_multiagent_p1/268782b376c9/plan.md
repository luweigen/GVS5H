Binary search the maximum X. For a candidate X, let req[i]=ceil(X/points[i]) be the required visits to index i. If the walk ends at t, the shortest walk that reaches all indices has length 2n-1-t and gives base visits 1 to every index, plus one extra base visit to each i with t<=i<n-1; remaining demands are covered by extra back-and-forth edge pairs, where a pair on edge i adds one visit to i and i+1. The minimum number of such pairs for a demand vector is the maximum weight independent set on the path with those demands as weights. Sweep t from 0 to n-1, maintaining a prefix DP for vertices left of t (demand req[i]-1) and a precomputed suffix DP for vertices right of t (demand req[i]-2, except last req[n-1]-1), to obtain all MWIS values in O(n). Feasibility is min_t (2n-1-t + 2*MWIS_t) <= m.
