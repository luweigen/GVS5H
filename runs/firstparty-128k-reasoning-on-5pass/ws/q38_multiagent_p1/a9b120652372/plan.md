Let S and T be the positions of 1s in A and B; if |S|<|T| the answer is -1. A reachable final support is equivalent to splitting S into |T| contiguous blocks, block j ending at T_j, with the A-gap at each chosen boundary at least the B-gap T_{j+1}-T_j. For any such partition the maximum displacement is fixed as R=max(T_1-S_1, S_K-T_M), and the only extra obstruction is that all tight boundaries (A-gap = B-gap) must have the same displacement parity (T_j-S_r mod 2); if they do, the minimum is R, or R+1 when that parity differs from R mod 2 (with no tight boundaries, R). For a fixed required tight parity p (or no tight boundaries), existence of a partition is checked greedily by scanning A-gaps in order and, for each B-gap, taking the earliest gap that is either larger than the B-gap or equal with the required parity. Run this greedy check for strict, p=0, and p=1, then combine the results to output R, R+1, or -1.
