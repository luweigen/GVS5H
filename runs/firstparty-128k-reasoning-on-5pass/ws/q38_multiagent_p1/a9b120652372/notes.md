- **Reduction:** Let S and T be 0-based positions of 1s in A and B. If |S| < |T|, impossible. Otherwise a reachable support T corresponds to splitting S into |T| nonempty contiguous blocks, block j ending at T_j. For each boundary, the initial gap G_i must be at least the final gap H_j = T_{j+1}-T_j.
- **Endpoint bound:** R = max(0, T[0]-S[0], S[-1]-T[-1]) is the unavoidable endpoint lower bound. If |T| == 1, answer is R.
- **Parity:** For a chosen partition, let D_i be the required reduction of initial gap i (0 for internal gaps, G_i-H_j for boundary gaps). Gap reductions are realizable iff all tight boundaries (D_i=0) have the same displacement parity (T_j-S_i) mod 2. Strict boundaries (D_i>0) can absorb parity changes.
- **Answer rule:** If a partition exists whose tight parities are p, the minimum is R when p == R&1, otherwise R+1. A partition with no tight boundaries works for both parities and gives R.
- **Greedy check:** ok(p) scans initial gaps once. For each final gap H_j it takes the earliest G_i > H_j, or G_i == H_j with ((T[j]-S[i]) & 1) == p. Choosing the earliest feasible boundary is safe because it leaves a superset of later gaps.
- **Implementation:** Read all tokens with sys.stdin.buffer.read().split(). Skip N. If A == B, output 0. Build S and Tpos by enumerating bytes and testing c == 49. Compute R, then call ok(R&1), and if needed ok((R&1)^1). Output R, R+1, or -1.
- **Complexity:** Each test case does at most two linear scans over gaps plus position extraction, so O(sum N) time. Memory is O(max N) for the position lists of one case.
- **Edge cases:** Negative endpoint shifts are handled by max with 0; Python negative & 1 gives correct parity. Board boundaries do not add extra constraints because a valid sequence can be kept inside the convex hull of initial and final positions. Sample gives 3, -1, 5.
