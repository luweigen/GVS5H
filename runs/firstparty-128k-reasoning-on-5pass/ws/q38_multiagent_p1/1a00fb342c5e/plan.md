Model the variables as vertices and each constraint as an undirected edge with XOR weight Z_i. Run an iterative BFS/DFS from each unvisited vertex, assigning a potential equal to the XOR from the component root, and reject if any edge gives a different required potential. For a consistent component, every valid assignment is obtained by XORing all potentials with one component-wide mask. Because the sum of integers is additive over bits, choose each mask bit independently to make the minority of the component's potentials have that bit set. Equivalently, set a mask bit to 1 when more than half of the potentials in the component have that bit 1, then output potential[v] xor mask for each vertex.
