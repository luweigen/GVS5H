Model row and column flips as binary masks: each row flip is a bit and each column flip is a mask. For a fixed column-flip mask, every row independently chooses whether to flip, so a row with mask p contributes min(popcount(p xor c), W - popcount(p xor c)). Count how many rows have each of the 2^W possible masks. The total cost for every column mask c is the XOR convolution of the row-frequency array with the kernel d(x)=min(popcount(x), W-popcount(x)). Compute this convolution for all c using Fast Walsh-Hadamard Transform in O(W 2^W), then take the minimum value.
