Process values in descending order: when x is the largest remaining value, it must cross every smaller value currently to its right, and moving it directly right minimizes the positions of those crossings. After all larger values are fixed, x's current position among the remaining values is 1 plus the number of smaller values that originally appeared before x. Thus x contributes the sum of swap positions from that current position to x-1, equal to T(x-1)-T(L_x), where T(k)=k(k+1)/2 and L_x is that smaller-before count. Compute all L_x in O(N log N) by scanning the permutation left to right and using a Fenwick tree over values to count smaller values seen so far. Sum the contributions with 64-bit/arbitrary-precision integers and print the result.
