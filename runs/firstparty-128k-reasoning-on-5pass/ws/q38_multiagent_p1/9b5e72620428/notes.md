- **Core model:** Fixed A and B entries are multisets of sizes p and q; blanks are N-p and N-q. Since A can be permuted, only multisets matter. For a common sum S, fixed-fixed pairs can only use values a,b with a+b=S, and the maximum number is m(S)=sum_v min(cntA[v],cntB[S-v]).
- **Feasibility:** Let L=p+q-N. If L<=0, Yes. If L>0, a solution exists iff there is an integer S>=M (M=max fixed value) with m(S)>=L. Choosing L fixed-fixed pairs leaves p-L=N-q fixed A entries for B blanks and q-L=N-p fixed B entries for A blanks; S>=M makes all filled blanks non-negative, and leftover blanks can be (0,S).
- **Candidate theorem:** If m(S)>=L, then S must be in topA+B, where topA is the set of distinct values among the largest K_A=p-L+1 fixed A values. If no topA value contributed to m(S), only the p-K_A=L-1 smaller A values could contribute, so m(S)<=L-1. Symmetrically S is in topB+A. Thus it is enough to test sums from the smaller of topA x B and topB x A.
- **top_values fix:** The old version returned only the boundary value. The fixed version appends every value while the cumulative count is still below k, then appends the boundary value and stops, so it returns all distinct values appearing in the top k elements with multiplicity.
- **Algorithm:** Count fixed values. If L<=1, Yes. Optional high-count shortcut: if some A value and some B value each occur at least L times and their sum is >=M, Yes. Build a dict of candidate sums x+y>=M from the smaller candidate product. Enumerate all distinct value pairs with a+b>=M using sorted lists and bisect starts; if the sum is a candidate, add min(counts) to its total and stop when a total reaches L. Otherwise No.
- **Complexity:** Candidate product is at most (N-q+1)q or (N-p+1)p, <= about 1.01e6 for N=2000. Pair enumeration is at most 4e6. Memory is one dict of candidate sums (<=1e6 entries) plus small lists. The previous multi-branch fallback is unnecessary and removed.
- **Regression and samples:** The requested regression N=4, A=10 10 9 1, B=0 0 -1 -1 returns Yes. A non-shortcut top_values case N=4, A=10 9 9 1, B=0 9 -1 -1 also returns Yes. Samples 1-3 return Yes, No, No.
- **Edge cases:** All blanks or one side all blanks gives L<=0 and Yes. All fixed values zero works with S=0. If the candidate set is empty, No. Duplicates are handled by counts; top_values includes a boundary value once even if many copies are in the top k.
