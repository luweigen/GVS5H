Model -1 entries as blanks and ignore B's order because A may be permuted. For a candidate common sum S, a fixed A value a can be paired with a fixed B value only when b=S-a, so the maximum number of fixed-fixed pairs is m(S)=Σ_v min(cntA[v], cntB[S-v]). If p and q are the numbers of fixed A and B entries, at least L=max(0,p+q-N) fixed-fixed pairs are necessary, and this is also sufficient when S is at least every fixed value, because the remaining fixed entries can be matched to blanks. Therefore the answer is Yes iff L=0 or there exists an integer S≥max_fixed with m(S)≥L. Compute this by enumerating all distinct fixed A/B value pairs (at most 4×10^6) and accumulating min(counts) for each sum, stopping early when a sum reaches L.
