- **model:** The answer has length N = n + m - 1. A window starting at i ends at p = i + m - 1. It equals str2 exactly when the KMP state after reading position p is m. Thus each str1[i] is a position-dependent check on the next automaton state.
- **automaton:** States 0..m, state q = longest prefix of str2 that is a suffix of the processed word. Build prefix function pi. For q < m, transition on c is q + 1 if c == str2[q], otherwise trans[pi[q-1]][c] (state 0 stays 0 on mismatch). For q = m, use full-match fallback trans[m][c] = trans[pi[m-1]][c], so state m remains a real state and consecutive matches are handled.
- **masks:** For each state q and requirement r in {none, T, F}, mask_r[q] is a Python int bitset of next states reachable by at least one lowercase letter satisfying r. T keeps only next state m; F excludes m; none includes all reachable next states.
- **backward dp:** dp[p] is the bitset of states before position p from which suffix p..N-1 can be completed. dp[N] is all states. For p from N-1 down to 0, with r = req[p] (req[i+m-1] from str1[i]), q is feasible iff mask_r[q] & dp[p+1] != 0. If any dp[p] becomes 0, return "".
- **greedy:** If state 0 is not in dp[0], return "". Otherwise scan left to right, maintaining the actual KMP state. At each position choose the smallest c such that the requirement at p is satisfied by trans[state][c] and trans[state][c] is in dp[p+1]. This gives the lexicographically smallest valid word by the standard prefix-extension argument.
- **complexity:** Transition table O(m*26). Backward DP O(N*m) bitset tests, at most about 5.3 million for the limits. Greedy O(N*26). Memory is O(N) big integers (each up to m+1 bits) plus O(m*26) tables.
- **edge cases:** m = 1 works directly. Consecutive T windows are possible only when str2 has period 1; the automaton catches this via transitions out of state m. F constraints are locally satisfiable over 26 letters but can be globally impossible due to future T/F constraints. Positions p < m-1 have no constraint.
- **implementation notes:** Use a req array of 0/1/2 to avoid repeated pos-m+1 arithmetic. Use bits = [1 << i] and all_states = (1 << (m+1)) - 1. Early return when cur == 0, then check dp[0] & 1. Preallocate the answer list.
