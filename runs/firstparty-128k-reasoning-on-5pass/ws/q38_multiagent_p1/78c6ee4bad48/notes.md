- **Gap representation:** Replace coordinates by the N-1 positive gaps between consecutive pieces in sorted order. For four consecutive pieces with gaps u, v, w, the operation reflects the two inner pieces across the midpoint of the outer two. The new sorted gap triple is w, v, u, so the operation swaps the two outer gaps.
- **Operation effect:** In terms of gap indices, choosing i swaps gap i and gap i+2 while leaving gap i+1 unchanged. Therefore each gap value can only move among gap positions with the same 1-indexed parity.
- **Reachability:** Swapping gap i and i+2 is an adjacent swap inside the subsequence of gaps of one parity. Adjacent swaps generate all permutations, so every permutation of odd-parity gaps among odd-parity slots and every permutation of even-parity gaps among even-parity slots is reachable.
- **Invariant leftmost coordinate:** The leftmost piece is never moved: if i=1 it is an outer piece and stays fixed; if i>1 it is not involved. Thus the minimum coordinate remains X_1.
- **Sum formula:** If sorted positions are p_1 < ... < p_N and gaps are g_1, ..., g_{N-1}, then p_k = X_1 + sum_{t=1}^{k-1} g_t. Hence total sum = N*X_1 + sum_{t=1}^{N-1} (N-t) g_t.
- **Weights:** The weight of gap position t is N-t. These weights strictly decrease as t increases. For 1-indexed odd positions the weights are N-1, N-3, N-5, ...; for even positions they are N-2, N-4, N-6, ...
- **Optimization:** Since parity classes are independent, minimize each weighted sum separately. By the rearrangement inequality, pair the smallest gaps with the largest weights. Thus sort each parity class ascending and pair it with its naturally decreasing weight sequence.
- **Implementation details:** Use 0-indexed Python slices: gaps[0::2] are 1-indexed odd positions, gaps[1::2] are 1-indexed even positions. Use integer arithmetic only; no midpoint floating point is needed.
- **Complexity:** Computing gaps is O(N). Sorting the two parity lists is O(N log N). Memory is O(N). Python integers handle the large answer safely.
- **Sample verification:** Sample 1 gives gaps [4,2,3], odd sorted [3,4], even sorted [2], answer 4*1 + 3*3 + 1*4 + 2*2 = 21. Sample 2 gives gaps [1,5,4,4,2], odd sorted [1,2,4], even sorted [4,5], answer 0 + 5*1 + 3*2 + 1*4 + 4*4 + 2*5 = 41.
