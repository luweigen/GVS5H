- **Problem split:** The required total is the sum of subarray minima plus the sum of subarray maxima over all subarrays whose length is at most k. The two parts are independent and can be computed with the same online structure.
- **Online invariant:** While sweeping right endpoint r, each deque stores groups `(value, count)` in increasing start-index order. For minima, group values are nondecreasing from left to right; for maxima, nonincreasing. The running total is `sum(value * count)` over all currently valid starts.
- **Extension step:** When `x = nums[r]` arrives, every previous valid start extends by x and the new start r is added. For minima, any old minimum `>= x` becomes x; because values are nondecreasing, those groups form a suffix, so pop from the right, accumulate their counts, and append one merged group `(x, count)`. For maxima, any old maximum `<= x` becomes x; pop the suffix while value `<= x` and append `(x, count)`.
- **Length cap:** Before processing r, the deque contains starts for r-1 with length at most k. After extension it temporarily contains one extra oldest start when `r >= k`. Remove exactly one start from the leftmost group, subtract its value from the running total, and decrement its count or popleft. Then the deque represents starts `max(0, r-k+1)` through r, and the total is added to the answer.
- **Duplicates:** Using `>=` for minima and `<=` for maxima merges equal values into the newest group. This keeps groups unique and makes count-based removal safe; if all starts share one value, removing the oldest start only decrements the count.
- **Complexity:** Each group is appended once and popped at most once in each pass, and each right endpoint causes at most one left removal. Time is O(n), memory is O(n) in the worst case. Python integers handle the 64-bit-sized result.
- **Pitfalls checked:** The removal must happen after extension and before adding the total to the answer; the condition is `r >= k` with 0-based indexing. The maximum pass uses the opposite comparison direction. Popped group contributions must be subtracted before adding the merged group contribution.
- **Verification:** A brute-force O(n^2) checker enumerates all subarrays of length at most k. The included main runs examples, fixed arrays, k=1, k=n, duplicate-heavy arrays, negative values, and 400 small random cases with a fixed seed.
