Maintain F(x), the current rating after processed contests, for every initial rating x. Each contest operation is monotone, so F remains nondecreasing and the set of x with L_i <= F(x) <= R_i is a contiguous interval. Use a lazy segment tree over the initial-rating domain (1..500000, or the maximum queried X) storing maximum values to support range add and threshold searches. For each contest, find a = first index with F(a) >= L_i and b = first index with F(b) > R_i minus one, then add 1 to F on [a,b] if nonempty. After all contests, answer each query by point-querying F(X) and printing the result.
