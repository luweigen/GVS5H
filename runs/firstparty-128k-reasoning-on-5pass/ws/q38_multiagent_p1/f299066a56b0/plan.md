Read N and the already sorted array A from standard input. Use a two-pointer greedy: let i scan candidate top mochi from the beginning and j scan candidate bottom mochi starting at index (N+1)//2. While both pointers are valid, if 2*A[i] <= A[j], form one kagamimochi, increment both pointers, and increase the answer; otherwise increment j to try a larger bottom. This is optimal because the smallest unused top should be matched with the smallest feasible bottom, and starting j after the first half guarantees that tops and bottoms are distinct. Finally print the number of formed pairs.
