Build the forced mapping from each S character to its T character; if one S character maps to two different T characters, output -1. Model the 26 letters as a directed graph with an edge a -> f(a) for every letter a that appears in S. The minimum has a base of M, the number of present letters with f(a) != a, because each such letter must be the source of at least one replacement. A cycle of length at least 2 requires one extra operation only when its component contains no nodes outside the cycle (equivalently, every cycle node has indegree 1); otherwise a node feeding into the cycle can absorb the extra move. If all 26 letters are present and no present letter has indegree 0, then a non-identity permutation is impossible; otherwise the answer is M plus the number of such pure cycles.
