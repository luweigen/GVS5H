For each test case, choose \(A = N + 1\) and \(M = N^2\). By the binomial theorem, \((1+N)^N = 1 + N^2 + \sum_{j=2}^{N} \binom{N}{j}N^j\), so \((N+1)^N \equiv 1 \pmod{N^2}\). For any \(0 < d < N\), \((1+N)^d - 1 \equiv dN \pmod{N^2}\), which is not divisible by \(N^2\). Therefore the smallest positive exponent giving a multiple of \(M\) is exactly \(N\). The bounds are safe because \(N \le 10^9\) implies \(A \le 10^9+1\) and \(M \le 10^{18}\). The solution is therefore a direct per-test-case output with no heavy computation.
