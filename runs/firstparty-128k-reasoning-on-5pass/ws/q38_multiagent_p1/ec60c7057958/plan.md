Model each valid permutation by its parity pattern; after a prefix, the remaining parity slots are forced, so the number of completions depends only on how many odd/even numbers remain. For a feasible remainder, completions equal fact(remaining_odds) * fact(remaining_evens), capped at 10^15. Unrank lexicographically by scanning unused numbers in ascending order at each position, skipping parity conflicts, and subtracting whole blocks until k falls inside one. If no candidate can accommodate k, return an empty list.
