Split the foods by vitamin type, because a food contributes to only one vitamin and the only coupling between types is the shared calorie budget. For a candidate minimum T, each vitamin type must independently reach at least T units, so the problem becomes finding the minimum calories needed for each type to reach T. Precompute for each vitamin a 0/1 knapsack DP over calories up to X, where dp[c] is the maximum units of that vitamin obtainable with at most c calories. After taking prefix maxima, dp[c] is nondecreasing, so the minimum calories to reach T is the first c with dp[c] >= T. Feasibility of T is true exactly when the sum of these three minimum calories is at most X. Binary search T from 0 to the minimum total available amount among the three vitamins to obtain the maximum feasible value.
