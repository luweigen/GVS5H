Rewrite the expression as (A_i+B_j)(C_k+B_j)-B_j^2, so for each fixed B_j=b the problem becomes enumerating top products of the positive arrays A+b and C+b. Sort A and C in descending order; then for a fixed b the product matrix is sorted in both rows and columns and can be generated lazily in descending order by a heap starting at (0,0), pushing (p+1,0) only when q=0 and pushing (p,q+1) whenever possible. Treat each b as one sorted sequence and merge all N sequences with a global max-heap initialized with the (0,0) value for every b. Pop K times from this global heap, pushing the next element(s) of the corresponding b-sequence, and the K-th popped value is the answer. This gives O(N log N + (N+K) log(N+K)) time and O(N+K) memory, which fits the constraints.
