- **Core reduction:** With positive vertex weights, a shortest path can be assumed simple. If the query intervals are disjoint, the direct edge is optimal. If they overlap, take any path and inspect the first and last internal vertices; they always yield a length-2 or length-3 shortcut no heavier than the original path.
- **Containment:** If one interval contains the other, every vertex disjoint from the containing interval is also disjoint from the contained interval. Any path must contain a vertex adjacent to the containing interval, hence a common neighbor. The extra weight is min(P[L_large], S[R_large]).
- **Crossing:** Let early have smaller L and smaller R, late have larger L and larger R, so L_early < L_late <= R_early < R_late. Common neighbors are exactly R < L_early or L > R_late. The only non-common length-3 shape is early - X - Y - late with L_X > R_early and R_Y < L_late; any such X and Y are automatically disjoint. Extra is min(min(P[L_early], S[R_late]), P[L_late] + S[R_early]).
- **Arrays:** P[x] = min W_i with R_i < x, S[x] = min W_i with L_i > x. Coordinates are 1..2N, so no compression is needed. P is a prefix minimum over right endpoints, S a suffix minimum over left endpoints. Strict inequalities are essential because intervals are closed.
- **Safety of minima:** The relevant thresholds never allow s or t to be selected as a middle vertex. In the crossing two-vertex case, one vertex cannot satisfy both R < L_late and L > R_early because L_late <= R_early and L <= R, so the two minima are automatically distinct.
- **Superseded idea:** The earlier 2D offline/Fenwick plan is unnecessary; the crossing two-middle case separates into independent one-dimensional minima because the middle intervals are forced to opposite sides.
- **Implementation:** Use a flat int list from stdin, keep intervals in it, and answer queries by case analysis. INF = 10**18 is far above any finite answer; output -1 when the best extra is at least INF//2.
- **Complexity:** O(N + Q + 2N) time and O(N + 2N) memory.
- **Validation:** A brute-force checker that builds the explicit graph for small N and runs Dijkstra per query matches the formula on random tests, including touching endpoints, identical intervals, containment, and crossing cases.
