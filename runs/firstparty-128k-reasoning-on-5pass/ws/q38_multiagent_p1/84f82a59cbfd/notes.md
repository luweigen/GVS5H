- **Core reduction:** A 400 number has all prime exponents even, so it is a perfect square. If N = product p_i^(2e_i), then N = m^2 where m = product p_i^e_i. The distinct prime factors of N are exactly the distinct prime factors of m. Therefore N is a 400 number iff m has exactly two distinct prime factors.
- **Search bound:** Since A <= 10^12, any valid square root m satisfies m <= isqrt(A) <= 10^6. It is enough to precompute valid m up to the maximum query square root.
- **Sieve method:** Use a bytearray cnt of length max_root + 1. Iterate i from 2 to max_root. If cnt[i] == 0, then i is prime, because no smaller prime has divided it. For every multiple j of i, increment cnt[j]. After the sieve, cnt[x] is the number of distinct prime divisors of x.
- **Why prime detection works:** Composite numbers have a prime factor smaller than themselves, so they have already been incremented by that prime. Primes are untouched before their own iteration, so cnt[i] == 0 exactly for primes.
- **Valid bases:** Collect all i with cnt[i] == 2. This list is naturally sorted. The smallest valid base is 6, giving 36, which matches the minimum query value.
- **Query handling:** For each A, compute r = isqrt(A). Use bisect_right(valid, r) - 1 to find the largest valid base not exceeding r. The answer is base^2. Using math.isqrt avoids floating-point precision issues.
- **Complexity:** The sieve performs sum over primes p <= M of floor(M/p) increments, about M log log M, which is under 3 million increments for M = 10^6. The outer scan and valid-base collection are O(M). Each query is O(log |valid|) using bisect. Memory is O(M + Q + |valid|), easily within limits.
- **Implementation details:** Read all input with sys.stdin.buffer.read().split(). Parse Q and the queries. Compute max_root before building the sieve. Use local bindings for isqrt and bisect_right for speed. Accumulate output strings and join them with newlines.
- **Edge cases:** If A is exactly a valid square, isqrt returns its base and bisect_right includes it, so the answer is A. If A is not a square, the floor square root is used. A = 36 returns 36. A = 10^12 returns 10^12 because 10^6 = 2^6 * 5^6 has exactly two distinct prime factors.
- **Sample verification:** 404 has r = 20, largest valid base <= 20 is 20, answer 400. 36 has r = 6, answer 36. 60 has r = 7, largest valid base is 6, answer 36. 10^12 has r = 1000000, answer 10^12. 123456789 has r = 11111, and 11111 = 41 * 271, so answer 11111^2 = 123454321.
