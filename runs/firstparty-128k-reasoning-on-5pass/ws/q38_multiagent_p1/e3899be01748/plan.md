Process the string left to right and count valid substrings by the digit at the right end. For endings 1, 2, or 5, every substring ending there is valid, so add i+1. For endings 3, 6, or 9, use divisibility by 3 or 9: maintain frequencies of prefix digit-sum residues and add the count of previous prefixes with the same residue. For endings 4 and 8, use the standard last-two/last-three-digit rule, adding the one-digit substring plus all longer starts when the required short suffix is divisible. For ending 7, maintain prefix values modulo 7 multiplied by inverse powers of 10, so a substring is valid exactly when its normalized prefix key equals the current normalized prefix key. Ignore zero endings, use a 64-bit integer, and keep O(1) auxiliary space for O(n) time.
