Use the substitution d = x - y, where d is a positive integer. Since y >= 1, we have N = d(3y^2 + 3dy + d^2) >= d^3 + 3d^2 + 3d, so d^3 < N and d is at most 10^6 for N <= 10^18. Enumerate all possible d from 1 to the integer cube root of N. For each d that divides N, set q = N / d and solve 3y^2 + 3dy + d^2 = q. The discriminant is D = 12q - 3d^2; a valid solution exists iff D is a nonnegative perfect square and (-3d + sqrt(D)) is positive and divisible by 6. Return x = y + d for the first valid d, or print -1 if none exists.
