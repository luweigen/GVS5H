- **Modeling:** Use the unique breadth-first search layering from vertex 1. Layer 0 is {1}; all later layers are nonempty. Edges can only be inside one layer or between consecutive layers, and every vertex in layer i > 0 must have at least one edge to layer i-1. The parity condition is that total sizes of even-indexed layers and odd-indexed layers are both H = N/2.
- **Layer transition:** For previous layer size a and new layer size b, the exponential generating factor is invfact[b] * (1+x)^{C(b,2)} * ((1+x)^a - 1)^b. Expanding by inclusion-exclusion gives sum_j (-1)^j C(b,j) (1+x)^{C(b,2)+a(b-j)}. The code stores terms as (j, coeff, exp) for all a,b in 1..H and applies invfact[b] separately.
- **DP state:** State is (used_even, used_odd, current_layer_size, current_layer_parity). Start is (1,0,1,0). The next layer parity is forced to 1-p, and its size b is bounded by the remaining vertices of that parity. Valid completions are states with used_even = used_odd = H. The final answer is multiplied by (N-1)! because vertex 1 is fixed as the root.
- **Requested precomputations:** The program precomputes H, D, factorials/invfacts up to max(N,D), inverses up to D+1, binomials up to H, and transition terms (j, (-1)^j C(b,j), exponent C(b,2)+a(b-j)) for all a,b in 1..H.
- **Degree bound:** Let R = D - H + 1. Any non-root even-distance vertex cannot be adjacent to vertex 1, so at least H-1 edges from vertex 1 are missing. Hence the answer polynomial has degree at most R. This reduces interpolation points from D+1 to R+1.
- **Evaluation:** For each x = 1..R, run a scalar DP over states. Transitions increase used_even+used_odd, so processing states in increasing total order is valid in-place. Modulo reduction is deferred until a state is processed to reduce modulo operations; final states are summed and reduced once.
- **Interpolation:** Values at x = 0..R are interpolated using Newton forward differences. The code converts the binomial basis C(x,k) to ordinary coefficients using the recurrence C(x,k+1) = C(x,k)*(x-k)/(k+1).
- **Complexity:** H <= 15 and R <= 421. The number of possible transitions per evaluation point is at most about 28800, so total scalar updates are around 12 million. Weight precomputation is O(R*D), interpolation is O(R^2), both small.
- **Edge cases:** N=2 works and outputs 1. Since P >= 1e8 and D <= 435, all needed inverses exist. Coefficients for M > R are exactly zero and are output as 0.
