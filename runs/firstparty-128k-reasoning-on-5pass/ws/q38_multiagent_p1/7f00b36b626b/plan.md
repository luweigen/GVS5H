Values greater than threshold can never have an edge because lcm(a, b) >= max(a, b), so count them as isolated components. For values at most threshold, two numbers are connected exactly when they share some common multiple L <= threshold, since their lcm is the smallest common multiple. Process each present value x by scanning its multiples up to threshold and unioning x with the first present divisor already seen for that multiple. This creates one DSU component for all numbers that share any common multiple, matching the graph connectivity. Finally count distinct roots among present values <= threshold and add the isolated large values.
