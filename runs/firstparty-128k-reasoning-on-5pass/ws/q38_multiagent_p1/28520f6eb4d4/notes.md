- **Visibility reduction:** For a target building i, aiming at its top gives the highest possible line height over every earlier building. If the line to the top is blocked by some earlier building, any lower point on building i gives an even lower line and is also blocked.
- **Pair threshold:** For j < i, the critical observer height where the line from (0, h) to the top of i just touches the top of j is c_{j,i} = (H_j * X_i - H_i * X_j) / (X_i - X_j). Building i is visible iff h is strictly greater than every such c_{j,i} for j < i.
- **Answer rule:** Let M be the maximum pair threshold. If M < 0, height 0 already sees all buildings, so print literal -1. If M = 0, height 0 is the maximum bad height, so print 0.000000000000000000. If M > 0, print M.
- **Adjacent-only maximum:** For three x-sorted points A, B, C, the y-intercept of line AC lies between the y-intercepts of AB and BC. Therefore any non-adjacent pair threshold is no larger than some adjacent pair threshold, so scanning consecutive buildings is sufficient.
- **Exact comparison:** Denominators are positive because X is strictly increasing. Compare fractions a/b and c/d by a*d > c*b using Python integers. Values are small enough: numerators are about 1e18, denominators about 1e9, cross products about 1e27, so O(N) exact arithmetic is fast for N = 2e5.
- **Output formatting:** The exact integer scan still determines the sign and the maximum rational value. For best_num < 0, print -1. For best_num == 0, print 0.000000000000000000. For best_num > 0, print f"{best_num / best_den:.18f}", using IEEE-754 double formatting.
- **Double formatting safety:** The required tolerance is 1e-9 absolute or relative. Double conversion error is far below that for small answers, and for large answers the relative error remains far below 1e-9.
- **Sample check:** Sample 1 prints 1.500000000000000000. Sample 2 prints -1. Sample 3 prints 0.000000000000000000. Sample 4 has best value 120/7 and now prints 17.142857142857142350.
- **Edge cases:** N = 1 has no blocking pair and prints -1. A zero maximum prints 0.000000000000000000, not -1. Large positive answers are handled by float formatting with acceptable relative error.
