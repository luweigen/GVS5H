- **Reduction to e-sequences:** Let x_i be the direction bit of cycle edge i, and t_i the spoke contribution at vertex i. Then d_i = 1 + x_{i-1} - x_i + t_i. Define e_i = d_i - 1. The hub degree is d_N = (#ones) - sum t_i, and because the cycle differences telescope, sum e_i = sum t_i. Hence d_N is determined by the first N values, so it suffices to count valid e-sequences.
- **NFA formulation:** For a fixed s_i, a transition from a to b emits e = a - b + t, where t ∈ {0, s_i}. A valid e-word is one for which there is a closed walk on states {0,1}: the initial state x_{N-1} must equal the final state. Since the initial state may be 0 or 1, track two reachable sets: A from start 0 and B from start 1.
- **DFA state encoding:** Encode a determinized state as (A << 2) | B, where A and B are 2-bit subsets of {0,1}. Initial state is A={0}, B={1}, i.e. 6. Accepting states satisfy (A & 1) or (B & 2).
- **Transition tables:** For each s ∈ {0,1}, compute subset transitions sub[S][e] for e ∈ {-1,0,1,2}. Feasible e are -1,0,1 when s=0 and -1,0,1,2 when s=1. For DFA state p=(A,B), each feasible e gives next state (sub[A][e] << 2) | sub[B][e]. Store one entry per feasible e; duplicates are intentional because different e values are different output symbols.
- **DP counting distinct words:** dp[p] counts distinct prefixes leading to DFA state p. For each character, add dp[p] to ndp[next] for every stored next state. This counts each distinct output word once, not each orientation.
- **Dead state:** State 0 means both A and B are empty. It can never become accepting, so it is safely dropped from the active DP.
- **Unrolled implementation:** The code builds the tables as required, then uses an explicit unrolling of the 12 reachable non-dead states: 1,2,3,4,5,6,7,8,10,12,14,15. This avoids per-transition list overhead while preserving the same DP semantics.
- **Modulo strategy:** Values are reduced modulo 998244353 every 16 characters. This keeps integers small (roughly under 2^65 between reductions) while avoiding a modulo operation on every character.
- **Complexity:** O(N) time and O(1) memory. The per-character work is a fixed number of integer additions and assignments, suitable for N up to 10^6.
- **Pitfalls:** Do not count orientations; duplicate transitions must be counted separately. The hub degree is not an independent variable. The closed-walk condition is start=final, not merely nonempty final reachability. e=-1 corresponds to d=0 and e=2 to d=3.
