Model the town as the full lattice rectangle \(0\le x\le W,\ 0\le y\le H\) with the closed forbidden rectangle \([L,R]\times[D,U]\) removed, and count monotone right/up paths of any length. First count all such paths in the full rectangle with arbitrary start and end using a hockey-stick closed form, then subtract the paths that are not allowed. The forbidden paths split into starts inside the removed rectangle, and starts outside whose first forbidden point is entered from the left edge or the bottom edge. The start-inside correction is a two-dimensional prefix sum of binomial continuation counts and can be done in \(O(1)\), while the left and bottom first-entry corrections are one-dimensional sums over at most \(10^6\) points each. Precompute factorials and inverse factorials up to \(W+H+4\) modulo \(998244353\) so every binomial coefficient is \(O(1)\), giving an overall \(O(W+H)\) solution.
