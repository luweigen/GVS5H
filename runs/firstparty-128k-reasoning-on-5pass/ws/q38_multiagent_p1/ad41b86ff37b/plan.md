A Snowflake Tree is determined by a center c, a set of x neighbors of c, and a common number y of leaves kept at each of those neighbors. For fixed c and y, a neighbor v of c can be used as one of the x vertices iff deg(v)-1 >= y, since its other incident vertices can be kept as leaves after deleting everything else. Therefore the best size for that c and y is 1 + (y+1) times the number of such eligible neighbors. For each c, sort the values deg(v)-1 over its neighbors in decreasing order; if the k-th largest value is a, choosing y=a and k eligible neighbors gives a valid candidate of size 1 + k(a+1), and scanning all k covers all optimal y. Take the maximum candidate over all centers and output N minus that maximum.
