- **Snowflake embedding:** In any kept snowflake, if c is the center and v is one of the blue neighbors, v must have y kept neighbors other than c, so y <= deg(v) - 1. Conversely, if we choose center c, a set B of neighbors of c, and y such that deg(v) - 1 >= y for every v in B, we can keep c, all v in B, and y other neighbors of each v. In a tree these leaf sets are disjoint, so the remaining induced graph is a valid snowflake.
- **Fixed center optimization:** For a fixed center c, list the degrees of its eligible neighbors (degree at least 2) in nonincreasing order: d_1 >= d_2 >= ... . If we keep k blue neighbors, the best common y is min_{i<=k}(d_i - 1) = d_k - 1. The resulting size is 1 + k * d_k. Therefore, for each center, only the kth largest neighbor degree matters.
- **Global descending-degree sweep:** Process all vertices v with deg(v) >= 2 in nonincreasing degree. For each center c, cnt[c] counts how many neighbors of c have already been processed. When v is processed, for each neighbor c, after incrementing cnt[c] to k, the value 1 + k * deg(v) is exactly the candidate size for center c with k blue neighbors in that nonincreasing order. Ties are harmless: equal degrees give the same d_k, and the sweep updates every k inside the tie block, including the largest one.
- **Complexity:** Building adjacency and degrees is O(N). Sorting eligible vertices is O(N log N). The sweep visits each directed edge once, so O(N). Memory is O(N) for adjacency, degree, cnt, and the sorted order. This is comfortably within the constraints for N = 3e5.
- **Edge cases:** x and y are positive, so degree-1 vertices can never be blue vertices. The center may be a leaf in the original tree; for example, a path of 3 vertices is a snowflake with x=1, y=1. Stars are handled by choosing one leaf as the center and the original center as the single blue vertex. best is initialized to 0, and the answer is N - best.
- **Implementation details:** Use 0-based indices. Read all input tokens, build adjacency and degree arrays, then delete the token list before sorting to reduce memory. Sort eligible vertices using deg.__getitem__ as the key. In the sweep, store k = cnt[c] + 1 before writing it back to avoid reading cnt[c] twice.
