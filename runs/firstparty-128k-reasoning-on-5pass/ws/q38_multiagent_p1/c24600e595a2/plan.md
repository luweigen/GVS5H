Model each bit's optimal trajectory: 0->0 never changes, 0->1 changes once in the second phase, 1->0 changes once in the first phase, and 1->1 either stays 1 or is turned off once in the first phase and on once in the second phase. For any fixed set of flips, all first-phase 1->0 flips must precede all second-phase 0->1 flips, with first-phase flips in decreasing C and second-phase flips in increasing C. Hence the only decision is which 1->1 bits to temporarily turn off; for a fixed number x of such bits, an exchange argument shows the optimal ones are the x largest C among 1->1 positions. Compute the cost for every x by maintaining the order-statistic sums for the negative and positive phases as the next largest 1->1 weight is inserted. Take the minimum over x; sorting gives O(N log N) time.
