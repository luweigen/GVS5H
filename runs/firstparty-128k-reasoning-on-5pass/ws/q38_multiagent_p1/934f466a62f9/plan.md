Pairing cakes and taking the maximum coordinate is equivalent to choosing, for each pair, one of the three coordinates; thus the problem is a maximum-weight matching of size K in a multigraph where an edge of color d between i and j has weight X_i+X_j (or Y/Z). Equivalently, select 2K cakes and color them so that each color is used an even number of times, gaining the chosen coordinate. The optimal value as a function of K is concave, so we can use the WQS/Aliens trick with a penalty per pair. To keep all numbers integral, double every coordinate and penalize each selected cake by μ; a feasible selection of 2K cakes has adjusted score 2·(original score) − 2Kμ. For a fixed μ, an 8-state DP over the parities of the three color counts gives the best adjusted score and, among ties, the maximum number of selected cakes. Binary search the largest μ for which this maximum count is at least 2K; the answer is (best_score + 2Kμ)/2.
