Compute the cost of making every length-x window internally equal by maintaining a sliding median and the sums of elements on each side, giving O(n log x) window costs. Then use dynamic programming over the prefix of the array and the number of chosen subarrays, where a state either skips the current position or takes the window ending there if it does not overlap previous choices. The transition is dp[j][i] = min(dp[j][i-1], dp[j-1][i-x] + cost[i-x]) with dp[0][i]=0. This yields O(nk) time after the cost precomputation and handles arbitrary target values because the median minimizes absolute deviations. Return dp[k][n].
