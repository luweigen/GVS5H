Read the input and mark each given value in a boolean indicator array over the value range, while keeping the list of present middle candidates. Compute the convolution of the indicator array with itself using an NTT to obtain, for every sum s, the number of ordered pairs (x, y) in S with x + y = s. Because the NTT modulus is larger than the maximum possible pair count, one transform is enough for exact coefficients. For each B in S, the desired triples centered at B are the unordered distinct pairs summing to 2B, so add (conv[2B] - 1) // 2, where the -1 removes the self-pair (B, B). Print the accumulated answer.
