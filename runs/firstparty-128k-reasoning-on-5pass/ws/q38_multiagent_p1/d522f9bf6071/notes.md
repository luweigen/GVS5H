- **Approach:** Use the finish-time prefix DP. Sort intervals by right endpoint, then left and original index. Let `ends` be the sorted right endpoints. For each interval, `p = bisect_left(ends, l)` is the count of intervals ending strictly before `l`, which enforces the no-shared-boundary rule.
- **DP state:** `dp_w[t][i]` and `dp_idx[t][i]` store, for exactly `t` intervals among the first `i` end-sorted intervals, the maximum total weight and the lexicographically smallest sorted 0-based original-index tuple achieving that weight. `t=0` has weight `0` and empty tuple; infeasible states use `-1` and `None`.
- **Transition:** For each interval and `t=1..4`, skip carries the previous prefix state. Take uses `dp[t-1][p]` plus the current interval. The current original index is inserted into the small sorted tuple using manual insertion for lengths up to 4. Candidates are compared by weight first, then by tuple lexicographic order.
- **Tie-breaking correctness:** For sorted tuples of equal length, inserting the same new index preserves lexicographic order. Therefore the lexicographically smallest maximum-weight prefix remains the best prefix after adding any future interval, so one tuple per state is sufficient. Final comparison scans `t=0..4` at `i=n`; Python tuple comparison matches the required rule that a shorter prefix is lexicographically smaller.
- **Complexity:** Sorting is `O(n log n)`. The DP does `4n` transitions, with one bisect per interval, so total time is `O(n log n)`. Memory is `O(4n)` for weights and index tuples, which is fine for `n <= 5 * 10^4`.
- **Edge cases checked:** Shared endpoints are excluded by strict `<` via `bisect_left`. Same right endpoint groups are never split by a compatibility prefix. Equal weights tie by smallest sorted original indices. Ties between different cardinalities are handled by tuple comparison. `n=1` returns `[0]`. Empty input would return `[]`.
- **Sample verdict:** Example 1 returns `[2, 3]`. Example 2 returns `[1, 3, 5, 6]`. Edge cases for shared endpoints, equal weights, shorter-prefix ties, and `n=1` behave as expected. Verdict: pass.
