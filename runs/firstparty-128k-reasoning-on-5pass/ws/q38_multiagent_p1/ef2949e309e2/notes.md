- **Validity split:** For a fixed middle index m with value x, choose two indices before m and two after m. Let a and b be the numbers of chosen x's on the left and right. Total x count is 1 + a + b. If a + b >= 2, x appears at least 3 times and is automatically the unique mode because only two non-x slots remain. If a + b = 1, x appears exactly twice and the three non-x values must be pairwise distinct. If a + b = 0, x appears once and can never be the unique mode.
- **Case A:** Count left/right pairs by how many x's they contain: L0 = C(ln, 2), L1 = lx * ln, L2 = C(lx, 2), and R0, R1, R2 similarly. Add the six combinations with a + b >= 2: L0*R2 + L1*R1 + L1*R2 + L2*R0 + L2*R1 + L2*R2.
- **Case B:** Exactly one extra x. If the extra x is on the left, choose the left x index in lx ways and a left non-x value y in lc[y] ways. The right pair must be a distinct non-x pair avoiding y. Let D_right be the number of distinct non-x index pairs on the right. The number avoiding y is D_right - rc[y] * (rn - rc[y]). Sum over y and multiply by lx. The symmetric term handles the extra x on the right.
- **Distinct pair count:** For a side with non-x total t and frequency-square sum S, D = (t*t - S) // 2. This equals all unordered non-x index pairs minus same-value pairs.
- **Implementation:** For each eligible middle index, build left and right Counters from slices, pop x to separate x-frequencies from non-x frequencies, then compute the formulas. This is O(n^2) total for n <= 1000 and uses O(n) memory per middle index.
- **Verification:** The three examples produce 6, 4, and 0. A brute-force checker enumerating all 5-index subsequences for small random arrays, including all-same, all-distinct, duplicates, negative values, and n = 5, matches this formula.
- **Pitfalls:** Do not require distinctness when x appears at least 3 times; there are only two non-x elements. In Case B, D_right already excludes same-value pairs, so subtract only distinct pairs containing y. Unordered index pairs are counted once, with no extra factor of 2. The middle element is the third chosen index, so exactly two indices must be chosen before and after it.
