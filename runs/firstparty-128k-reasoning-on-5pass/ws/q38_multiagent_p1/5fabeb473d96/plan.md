Treat the \((N-1)!\) parent sequences as a uniform random recursive tree, so each query answer is \((N-1)!\) times the expected distance. An edge \(i\) contributes \(A_i\) exactly when its rooted subtree contains exactly one of \(u,v\). For fixed \(i\) and endpoints \(u<v\), derive the contribution probability by cases: \(i<u\), \(i=u\), \(u<i<v\), and \(i=v\), using the Pólya-urn fact that for \(i<x\), \(P(i \text{ is an ancestor of } x)=1/i\) and \(P(i \text{ is an ancestor of both } x,y)=2/(i(i+1))\). This yields coefficients \(2(i-1)/(i(i+1))\) for \(i<u\), \(1-1/u\) for \(i=u\), \(1/i\) for \(u<i<v\), and \(1\) for \(i=v\). Precompute modular inverses, \((N-1)!\), and prefix sums of \(A_i\) times the first and middle coefficients, then answer each query in \(O(1)\) and multiply by the factorial modulo \(998244353\).
