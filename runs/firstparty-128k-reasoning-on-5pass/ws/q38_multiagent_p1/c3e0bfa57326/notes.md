- **Tree model:** Parse each matched pair as a node; its children are the maximal valid substrings directly inside it. Top-level components are children of a virtual root. A balanced string is uniquely represented by this ordered forest.
- **Operation meaning:** A valid substring is exactly a consecutive block of siblings at some depth. The special reversal is mirror-reverse M: reverse the block order and apply M to each sibling subtree. For a node, M reverses its child order and mirrors each child recursively.
- **Invariant:** M preserves the unordered rooted tree type of every subtree, and reversing a sibling block only changes sibling order. Therefore the unordered rooted forest, including the virtual root, is invariant.
- **Reachability:** A single sibling can be mirrored by choosing it alone. Two adjacent siblings X and Y can be swapped exactly by: mirror block XY to get M(Y)M(X), mirror the first to get YM(X), mirror the second to get YX. Thus adjacent swaps generate arbitrary sibling permutations at every depth. By induction, each subtree can be transformed to any plane embedding of its unordered type, so all plane embeddings of the initial unordered forest are reachable.
- **Counting:** For an unordered tree type, let c_t be the multiplicity of child type t and d = sum c_t. The number of ordered child-type sequences is d! / prod c_t!. For each occurrence of type t, choose one of val[t] embeddings. Hence val = fact[d] * prod invfact[c_t] * prod val[t]^{c_t} modulo MOD. The final answer is the same formula applied to the top-level multiset of node types.
- **Canonicalization:** Process nodes in reverse creation order so all children are already typed. For each node, sort its children’s type ids into a tuple and use a dictionary from tuple to type id. The leaf type is the empty tuple. Tuple keys are exact, avoiding hash-collision concerns.
- **Implementation details:** Use a stack to parse: on '(' create a node and push it; on ')' pop and append to the parent or to the top-level list. Precompute factorials and inverse factorials up to max(N, len(S), 1) using Fermat inversion. Scan sorted tuples to count equal type runs. Complexity is O(N log N) because of sorting child-type lists, and total child occurrences are O(N), easily within N <= 5000.
- **Samples:** For (())(), the top-level types are a leaf and a one-child node, giving 2! = 2. For (), there is one leaf, giving 1.
- **Pitfalls:** Do not forget the virtual root/top-level permutations. Do not canonicalize by node ids or original order. Do not use a set for children; multiplicities matter. Do not process a node before its children. Do not overcount identical child types: divide by factorials of multiplicities, but still multiply by val[t]^{c_t} for independent embeddings.
