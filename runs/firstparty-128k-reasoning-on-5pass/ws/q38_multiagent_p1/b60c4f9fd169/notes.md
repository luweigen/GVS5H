- **Approach:** Exact banded Ukkonen Levenshtein DP, not Landau-Vishkin. Any edit script of cost at most K keeps prefix length difference |i-j| <= K, so only a band of width 2K+1 is needed. Complexity is O(nK), where n is the shorter length after trimming.
- **Preprocessing:** Read input as bytes. Yes if S == T. No if abs(len difference) > K, or K == 0 with S != T. Swap so len(S) <= len(T); edit distance is symmetric. Yes if K >= len(T) because replacing the shorter string and inserting the rest costs len(T). Trim common prefix and suffix, then repeat n == 0 and K >= m checks.
- **DP indexing:** Use sentinel T = b'\0' + T so T[j] is the j-th target character and T[0] is safe. Row 0: prev[j+K] = j for j = 0..K, and DP only runs when K < m. For row i, valid j_low is 0 if i <= K else i-K; idx_low is K-i if i <= K else 0; idx_high is 2K if i+K <= m else m-i+K. Array index is j - (i-K). Previous row same j is idx+1, diagonal is idx; left is current row j-1, initialized INF.
- **Values and early exit:** INF = K+1; cap every cell > K to INF. This preserves all values <= K. Track row_min over the valid band; if row_min > K, no path of cost <= K can cross this row, so answer No.
- **Arrays:** Two lists of width 2K+2. Only the current band is written; the next row reads at most one index outside the previous band, which is either never written or set to INF. For safety, set curr[idx_low-1] and curr[idx_high+1] to INF after each row.
- **Final answer:** After n rows, the full-string cell is prev[m-n+K]; Yes iff it is <= K.
- **Performance:** Worst case is about 500000 * 41 inner iterations. The loop is tight: bytes indexing, small cached ints, no per-row list allocation. Trimming and K >= m early exits handle many easy cases.
- **Samples:** 3/abc/awtf gives Yes after trimming to bc/wtf and K >= 3; 2/abc/awtf gives No because DP final value is 3 > 2; 17/twothousandtwentyfour/happynewyear gives Yes after swapping and trimming, leaving a small DP.
- **Pitfalls:** Off-by-one in idx mapping, stale DP values, capping before row_min, sentinel for j = 0, and checking K >= len(T) only after swapping to the shorter string.
