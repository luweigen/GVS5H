- **Core reduction:** Only negative values need to be tried. For x >= 0, any subarray after deleting x maps to an original interval whose sum is larger by the removed non-negative elements, so the original maximum subarray sum dominates.
- **Zero-placeholder model:** For a negative x, replace every x by 0. The best valid subarray after deleting x is the best interval in this modified array that contains at least one non-x element. The segment tree root gives the best interval overall.
- **Segment tree:** Power-of-two iterative tree with four arrays `sums`, `pref`, `suff`, `best` for non-empty intervals. Empty leaves use sum 0 and negative infinity for pref/suff/best. Combine uses standard prefix/suffix/subarray formulas. Point updates set a leaf to 0 or back to x and recalculate ancestors.
- **Zero-only invalid intervals:** Because x positions become 0, the root best is at least 0. If it is positive, the interval must contain a non-x element and is valid. If it is 0, the only possible invalid case is when all non-x elements are negative; then the true candidate is the largest non-x element. Replacing 0 by the maximum element excluding x is safe: if a non-x zero exists, that maximum is 0; if all non-x are negative, it is the correct negative answer.
- **Max excluding x:** Precompute the top two distinct values. If the global maximum is not x, it is the max excluding x; otherwise use the second distinct maximum. Values with frequency n are skipped because deletion would empty the array.
- **Procedure:** Group indices by negative value. For each negative x with frequency < n, update all its positions to 0, read root, apply the zero correction, update answer, then revert all positions to x. Baseline is the original root best.
- **Complexity:** Each negative index is updated twice, O(log n) per update, so O(n log n) time and O(n) memory. Python ints handle sums up to about 1e11; -10**30 is a safe negative infinity.
- **Edge cases covered:** n=1, all elements equal, all negative, zeros mixed with negatives, positive-only arrays, bridging positive elements across deleted negatives, and large sums. The included main block has deterministic asserts and a fixed-seed brute-force cross-check on small arrays.
