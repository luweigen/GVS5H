- **Problem reformulation:** For a candidate maximum run length L, ask whether some binary string t with every run length at most L is within Hamming distance numOps of s. The answer is the smallest feasible L.
- **Monotonicity:** If L is feasible, any larger L is feasible because the same final string still satisfies the weaker bound. This justifies binary search.
- **Search bounds:** Lower bound is 1. Upper bound is the original maximum run length, since zero operations already achieve that bound. The n=0 guard returns 0, though constraints have n>=1.
- **DP state:** After processing a prefix, dp0[r] is the minimum flips when the chosen prefix ends with a zero run of length r, and dp1[r] is the same for a one run. r is 1..L; index 0 is unused and kept INF.
- **Transitions:** For original bit b, choosing 0 costs b and choosing 1 costs 1-b. A new run of length 1 comes from the opposite previous bit, using the minimum of that opposite array plus the cost. A run of length r>=2 comes from the same previous bit with run length r-1 plus the cost. Runs longer than L are not generated.
- **Correctness:** The DP is a shortest path over the finite automaton accepting exactly strings with no run longer than L. The last chosen bit and current run length are sufficient to determine all future valid continuations and costs, so induction over positions proves optimality.
- **Cost capping:** INF = numOps + 1. Any prefix cost above numOps can never become feasible because future costs are nonnegative, so capping at INF is safe and keeps values small.
- **Complexity:** One feasibility check is O(nL) time and O(L) memory. Binary search over at most log n values gives O(n^2 log n) worst case, easily within n<=1000.
- **Edge cases:** n=1 returns 1. numOps=0 returns the original maximum run length. Sufficient flips make L=1 feasible via an alternating string. All-same and alternating inputs are covered.
- **Validation verdict:** PASS. The included script harness checks the three examples, edge cases including n=1, numOps=0, numOps=n, all same, alternating, and mixed runs, plus 100 seeded random cases with n<=10 against a brute force that enumerates all 2^n target strings. No mismatches were found.
