Model each operation as swapping an adjacent block of X zeros with an adjacent block of Y ones, which preserves the relative order of all 1s and all 0s. For the j-th 1, the number of 0s before it changes only by multiples of X, so its residue modulo X is invariant; for the k-th 0, the number of 1s before it changes only by multiples of Y, so its residue modulo Y is invariant. These ordered residue sequences are complete: the one-directional rewrite 0^X1^Y -> 1^Y0^X is terminating and confluent, and its normal form is determined by these residues, so two strings are reachable iff the sequences match. Therefore compute and compare the residue sequence of all 1s (zeros-before mod X) and the residue sequence of all 0s (ones-before mod Y) in O(N). If the number of 1s differs or any sequence differs, output No; otherwise Yes.
