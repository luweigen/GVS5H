- **Model:** Operation A/B is exactly the reversible adjacent block swap `0^X 1^Y <-> 1^Y 0^X`. It never changes the relative order of the 1s among themselves or the 0s among themselves; it only changes how the two ordered token sequences are interleaved.
- **Invariant:** For the j-th 1, the number of zeros before it changes only by multiples of X, so `zeros_before % X` is invariant. For the k-th 0, the number of ones before it changes only by multiples of Y, so `ones_before % Y` is invariant. Both sequences must be compared in token order, not as multisets.
- **Completeness:** Orient the rule as `0^X 1^Y -> 1^Y 0^X`. It terminates because the number of 0-before-1 inversions decreases by `X*Y`. It is locally confluent: the left side has no proper self-overlap, and the adjacent critical pair `0^X 1^Y 0^X 1^Y` joins to `1^{2Y} 0^{2X}`. Hence each equivalence class has a unique normal form with no `0^X 1^Y`. The ordered residue sequences determine that normal form, so they are necessary and sufficient.
- **Algorithm:** Scan S left to right, maintaining `zeros_seen` and `ones_seen`. On `'1'`, append `zeros_seen % X` to the 1-residue list and increment `ones_seen`. On `'0'`, append `ones_seen % Y` to the 0-residue list and increment `zeros_seen`. Then scan T with fresh counters and compare its 1-residues to the first list in order and its 0-residues to the second list in order.
- **Length check:** If T has too many or too few 1s/0s, the scan either hits an out-of-range index or fails the final equality `i1 == len1` and `i0 == len0`. This also handles count mismatches.
- **Complexity:** O(N) time and O(N) memory. The two residue lists together contain exactly N integers, which is safe for N up to 5e5 in Python.
- **Edge cases:** X=1 or Y=1 makes the corresponding residues all 0; modulo by 1 is safe. All-zero/all-one strings work because one residue list is empty. If X+Y > N, at least one token count is below the corresponding block size, so the relevant residue sequence is exact and distinguishes strings; the same check handles it.
- **Implementation details:** Use `sys.stdin.buffer.read().split()` for fast input. S and T are bytes, so compare `c == 49` for `'1'`. Use short-circuit checks before indexing the residue lists.
- **Pitfalls:** Do not compare only aggregate invariants such as total counts or total inversion count. Do not compare residues as unordered multisets. Record the residue before incrementing the corresponding counter.
