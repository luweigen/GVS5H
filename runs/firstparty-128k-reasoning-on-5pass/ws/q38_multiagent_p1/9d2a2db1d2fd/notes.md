- **Core reduction:** For a fixed block path, let B be the minimum building height on that path. Any traversal must at some point be on a floor x with 1 <= x <= B in the shortest building on the path. Total stair moves are at least min over such x of |Y-x| + |Z-x|, which equals max(|Y-Z|, Y+Z-2B). This bound is achievable by stairing to such an x, using walkways at floor x along the whole path, then stairing to Z.
- **Bottleneck formulation:** For distinct blocks, the answer depends only on the largest B such that the two blocks are connected using only buildings of height at least B. This is a maximum bottleneck path problem.
- **Edge weights:** Give each adjacent pair edge weight min(F[u], F[v]). For any path with at least one edge, the minimum edge weight on the path equals the minimum building height on the path. A maximum spanning tree preserves bottleneck values: the minimum edge on the tree path between two nodes equals the maximum possible bottleneck in the original grid.
- **MST construction:** Process cells in descending F. When activating cell u, every active neighbor has height at least F[u], so the edge weight to that neighbor is F[u]. Union active neighbor components; on each successful union, add the tree edge (u, v, F[u]). This is Kruskal on grid edges in descending weight without explicitly storing all grid edges. The grid is connected, so the result has N-1 edges for N > 1.
- **LCA preprocessing:** Root the maximum spanning tree at 0. An iterative DFS computes depth, parent0, and mn0, where mn0[v] is the edge weight from v to its parent and INF for the root. Binary lifting tables up[k][v] and mn[k][v] store the 2^k ancestor and the minimum edge on that jump. LOG = N.bit_length().
- **Query handling:** Same-block queries are answered directly as abs(Y-Z), because the net floor change is a lower bound and direct stairs achieve it. For distinct blocks, lift the deeper node to the other node's depth while accumulating the minimum edge, then lift both nodes from high to low while their ancestors differ, and finally add the two edges to the LCA. The accumulated minimum is B. The answer is max(abs(Y-Z), Y+Z-2B).
- **Implementation details:** Flatten block (i,j) as i*W+j. Use a bytearray for active cells. DSU uses path halving and union by size; the current root ru of the activating cell is maintained across its at most four neighbor checks to avoid repeated find(u). Adjacency is stored compactly with forward-star arrays head/to/nxt/wt using array('i').
- **Memory management:** Delete order, DSU arrays, active, and F after building the MST. Delete adjacency arrays after DFS and before building lifting tables. Lifting tables are Python lists of lists; higher-level entries copy references to existing integer objects rather than creating new integers, keeping memory moderate.
- **Edge cases:** N=1 has no tree edges and only same-block queries; LOG=1. Boundary checks handle W=1 and H=1 using u >= W, u < N-W, col != 0, and col != W-1. INF=10**9 is larger than any building height.
- **Complexity:** Sorting O(N log N), DSU activation O(N alpha N), DFS O(N), lifting O(N log N), queries O(Q log N). With N <= 250000 and Q <= 200000, log N <= 18.
