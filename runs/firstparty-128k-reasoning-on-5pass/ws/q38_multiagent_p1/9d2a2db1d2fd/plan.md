For any fixed grid path, the minimum stair usage depends only on the path's minimum building height B and equals max(|Y-Z|, Y+Z-2B). Thus each query reduces to finding the maximum possible B over all paths between the two blocks, i.e. the maximum bottleneck (widest path) value. Build a Kruskal reconstruction tree by processing cells in descending F: activate cells, union active adjacent components, and create an internal node of weight h whenever two components merge at height h. In this tree, the maximum bottleneck between two blocks is the weight of their LCA, with leaf weights equal to the block's F for the same-block case. Preprocess the tree for binary lifting LCA and answer each query by taking B as the LCA weight and applying the formula.
