Model each wind step as a unit vector and maintain the prefix displacement P_t of the initial smoke after t steps. A smoke particle created at time k is at P_t - P_k after step t, so target T=(R,C) is occupied iff P_t - T equals some earlier prefix P_k. Therefore for each t we only need to test whether the point P_t - T has appeared among prefixes P_0..P_{t-1}. Use a hash set of seen prefix coordinates, update the current prefix, query the shifted point, then insert the current prefix. This yields O(N) time and O(N) memory, easily within constraints.
