- **Approach:** Root the undirected tree at node 0. For every node treated as the lower endpoint of a downward path, the best special path ending there starts at the shallowest ancestor such that all values on the segment are unique. Because all edge lengths are positive, this shallowest valid start always gives the maximum length for that endpoint.
- **Bound invariant:** On the current root-to-node path, a start depth is valid exactly when it is deeper than the second-most-recent occurrence of every value. Maintain `bound` as the shallowest valid start depth. When entering a node at depth `depth` with value `v`, let `prev` be the previous occurrence depth of `v` on the current path. The new bound is `max(parent_bound, prev + 1)`, where `prev = -1` contributes `0`.
- **State restoration:** Maintain `last[value]` as the deepest occurrence of that value on the active root-to-node path. On enter, save the previous `last[v]` and the parent bound, then update both. On exit, restore them. Since descendants exit before their ancestor, this correctly returns the state to the parent path.
- **Iterative DFS:** Use an explicit stack to avoid recursion depth issues. Enter events are `(0, node, parent, depth, dist)` and exit events are `(1, node, old_last, old_bound)`. Push the exit event before pushing children so children are processed before the exit. A single `bound` variable is safe because each child subtree restores the parent bound before the next sibling is popped.
- **Distance and node count:** Keep `path_dist[depth] = dist` for the active path. For the current node, candidate length is `dist - path_dist[bound]`, and candidate node count is `depth - bound + 1`. Set `path_dist[depth]` before evaluating the candidate so that `bound == depth` correctly represents the single-node path.
- **Answer update:** Initialize the answer to length `0` and node count `1`. Update when a candidate has greater length, or equal length with fewer nodes. This handles the all-duplicate case where only single-node paths are longest.
- **Complexity:** Building the adjacency list and traversing the tree takes O(n) time. The `last` array size is O(max(nums)), bounded by 50000 under the constraints. Memory is O(n + max(nums)) for adjacency, path distances, last occurrences, and the DFS stack.
- **Pitfalls:** Root the tree using a parent check rather than a visited set; restore both `last` and `bound` on exit; do not use recursion for 50000 nodes; and rely on positive edge lengths to justify considering only the shallowest valid start for each endpoint.
