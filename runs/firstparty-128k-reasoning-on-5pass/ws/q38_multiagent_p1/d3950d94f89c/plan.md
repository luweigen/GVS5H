Root the tree at 0 and traverse it with a DFS that maintains the current root-to-node path. Keep the last occurrence depth of each value and a lower_bound depth that is the maximum over all values of (second-last occurrence depth + 1), which is the shallowest depth from which the path to the current node has unique values. For each node, the best special path ending there starts at the ancestor at depth lower_bound, giving length dist[node] - dist[ancestor] and node count depth[node] - lower_bound + 1. Update the global answer with the maximum length and, for equal lengths, the minimum node count. Use enter/exit events or backtracking to restore last occurrences and lower_bound when leaving a node, yielding O(n) time after building the adjacency list.
