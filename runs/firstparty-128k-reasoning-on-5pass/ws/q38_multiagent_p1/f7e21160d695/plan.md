The value f(x, y) is the smallest threshold T for which x and y lie in the same connected component of the subgraph with edges of weight at most T. Process edge weights in increasing order with a DSU, and for each component keep how many A-items and B-items are still unmatched. After all edges of a given weight are added, any opposite-color unmatched items inside the same component can be paired with cost exactly that weight, so match as many as possible and add matched_count * weight to the answer. This greedy is optimal because the minimax distance is an ultrametric/hierarchical: it is always best to maximize the number of pairs completed at the earliest possible threshold, and an exchange argument shows delaying a possible match cannot improve later costs. The algorithm runs in O(M log M + (N+K) alpha(N)) time and uses 64-bit arithmetic for the sum.
