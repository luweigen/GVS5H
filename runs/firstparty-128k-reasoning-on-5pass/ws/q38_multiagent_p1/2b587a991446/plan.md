Decompose the graph into biconnected components (blocks) and build the block-cut incidence tree; the tokens must traverse the unique tree path between S and T, giving a base cost of 2*dist(S,T). A swap is possible iff some cyclic block can be used as a passing cycle, and the optimal solution uses exactly one such block. The answer is this base cost plus the minimum extra detour over cyclic blocks on that tree path or incident to a vertex on it. For a cyclic block on the path with entry/exit p,q, the extra is the shortest cycle in that block containing p,q minus 2*dist_block(p,q); for an off-path cyclic block at vertex v, the extra is the shortest cycle through v, plus 2 if v is S or T. All needed local shortest-cycle values can be computed by BFS/Suurballe routines on the relevant blocks in total linear/near-linear time.
