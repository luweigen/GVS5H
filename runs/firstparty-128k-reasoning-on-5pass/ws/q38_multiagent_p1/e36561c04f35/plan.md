Compress consecutive equal elements, since they can always be deleted together without swaps. Prove that in an optimal solution the batches can be ordered so that the maximum original index of each batch is strictly increasing; then each batch is a prefix of the remaining occurrences of its value. This gives a milestone formulation: choose an increasing set S of milestone positions (including the last occurrence of every value), assign each element to the first milestone of its value at or after it, and minimize |S| plus the number of inversions in the resulting label array. The milestone optimization is a shortest-path/DP problem over positions: adding a milestone p has a marginal cost that depends only on the previous milestone of A_p and the already chosen milestones, and can be maintained with a Fenwick tree or segment tree. Process all test cases in O(N log N) total.
