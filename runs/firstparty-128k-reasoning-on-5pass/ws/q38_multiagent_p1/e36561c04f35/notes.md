- **Run model:** Compress consecutive equal elements into runs; baseline cost is the number of runs M. A swap of two adjacent singleton runs in pattern X Y X Y (Y and the second X singleton) reduces runs by 2 and costs 1, giving net saving 1 (P). A swap in pattern X Y X with Y and one outer X singleton reduces runs by 1 and costs 1, net saving 0 (Z). Other swaps, crossing heavy runs, and partial deletions have nonpositive net effect and can be omitted or replaced without increasing the optimum.
- **DP states:** For prefix length i, best[i] is max P-savings with no open run. z[i] is max savings for an open chain whose open value is vals[i-2] (last move Z). p[i] is max savings for an open chain whose open value is vals[i-3] (last move P). A start state with open value vals[i-1] is derived from best[i-1]. The invariant is that the last run of the transformed prefix is different from the next original run, so no uncounted merges occur.
- **Transitions:** At prefix i, if runs i and i+1 are singleton and the open value equals vals[i+1], then if i+2 < M and vals[i+2] == vals[i] apply P to i+3 with +1; otherwise apply Z to i+2 with +0. Open states may stop into best[i]. This is a DAG scan, O(M).
- **Reverse:** The forward DP covers the Z orientation where the right outer run is singleton. Running the same DP on the reversed run sequence covers the opposite Z orientation. The answer is M - max(reward_forward, reward_reverse). Forward alone is likely sufficient, but reverse is safe and cheap.
- **Self-test:** ExactSmall computes exact distances by Dijkstra on the swap graph for all small sequences, using already-solved shorter lengths as deletion costs. The built-in test exhaustively checks binary N<=11, ternary/quaternary N<=7, random small cases, and the regression cases; all match, no mismatches.
- **Complexity:** O(M) per test case, O(sum N) total. The self-test is only run with `python program.py test` and is not used by the judge.
- **Status:** No known mismatches; the program is ready.
