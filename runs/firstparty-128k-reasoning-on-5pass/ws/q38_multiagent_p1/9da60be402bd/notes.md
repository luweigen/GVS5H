- **State model:** A palindromic walk is built from a center. Even center is the empty walk at a vertex, odd center is one existing edge. A state `(x, y)` means a palindromic middle walk from `x` to `y`; stored distance is its length.
- **Expansion rule:** From `(x, y)` at distance `d`, for each label `c`, every `u` with edge `u -> x` labeled `c` and every `v` with edge `y -> v` labeled `c` gives state `(u, v)` at distance `d + 2`. This is exact by peeling matching first and last edges from a palindrome.
- **Parity separation:** Even BFS starts from all `(i, i)` at distance `0`. Odd BFS starts from all edges `(i, j)` at distance `1`. They must be separate because the same pair can have both parities, and only the same parity can be extended by adding two matching edges.
- **Bitsets:** `out_mask[y][c]` is a bitset of successors `v` of `y` by label `c`. `in_mask[x][c]` is a bitset of predecessors `u` of `x` by label `c`. For a state `(x, y)`, iterate labels with nonempty `in_mask[x][c]`, take `S = out_mask[y][c]`, and for each `u` bit in `P` compute `new = S & unvisited[u]`.
- **Unvisited rows:** In each BFS, `unvisited[u]` holds columns not yet enqueued in row `u`. Sources are removed initially. When `new` is nonzero, clear those bits from `unvisited[u]`, set their distances, and enqueue each bit. This ensures each of the `N^2` states is enqueued at most once per BFS.
- **Queue order:** All transitions add `2` and all sources in one BFS have the same initial distance, so FIFO order gives nondecreasing distances; first enqueue is shortest. A `remaining` counter stops the BFS once all states are enqueued.
- **Complexity:** `N <= 100`, so `N^2 <= 10000` states. For each processed state `(x, y)`, iterating predecessor bits over all labels costs `O(in-degree(x))`; summed over all `y` this is `O(N * E) <= 1e6` row checks per BFS. Bit operations are on 100-bit integers, and total enqueues are `O(N^2)`.
- **Edge cases:** Diagonal answer is always `0` from the empty walk. Self-loops are valid odd centers but do not override the `0`. If there are no edges, odd BFS is empty. Unreachable pairs remain `-1`.
- **Final answer:** For each `(i, j)`, output `min(even[i][j], odd[i][j])`, treating `-1` as absent.
