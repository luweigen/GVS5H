Treat a palindrome by peeling matching first and last edges, so a walk from i to j can be built outward from an inner state (x, y). Use two BFS runs over the N^2 states: even-length walks start from (i, i) at distance 0, odd-length walks start from every existing edge (i, j) at distance 1. From a state (x, y) with distance d, any edge u -> x labeled c and edge y -> v labeled c creates state (u, v) at distance d + 2. Because N <= 100, represent outgoing neighbors by 100-bit integers and update all new v in a row at once, making the BFS fast. The answer for each pair is the minimum of the even and odd distances, with unreachable as -1.
