- **Model:** Put one bit on every toroidal grid edge: horizontal edge `h_{i,j}` is the right edge of `(i,j)` / left edge of `(i,j+1)`, vertical edge `v_{i,j}` is the bottom edge of `(i,j)` / top edge of `(i+1,j)`. The no-dead-end condition is exactly using shared edge bits.
- **Tile constraints:** For cell `(i,j)`, let `a=1` for A, `0` for B. Type A requires `h_left xor h_right = 1` and `v_top xor v_bottom = 1`. Type B requires `h_left = h_right`, `v_top = v_bottom`, and `h xor v = 1`.
- **Row elimination:** Choose row constant `R_i` as the left edge of column 0, i.e. `h_{i,W-1}`. If the row has odd number of A's, impossible. Otherwise every horizontal edge in the row is determined by `R_i` and the prefix parity of A's before that column. For a B at `(i,j)`, its horizontal used bit is `R_i xor row_parity_before_j`.
- **Column elimination:** Choose column constant `C_j` as the top edge of row 0, i.e. `v_{H-1,j}`. If the column has odd number of A's, impossible. Otherwise every vertical edge is determined by `C_j` and the prefix parity of A's above that row. For a B at `(i,j)`, its vertical used bit is `C_j xor col_parity_before_i`.
- **B equation:** Since a B tile uses horizontal iff it does not use vertical, `horizontal_bit xor vertical_bit = 1`. Thus for every B cell: `R_i xor C_j = 1 xor row_parity_before_j xor col_parity_before_i`.
- **Counting:** Only rows/columns containing B participate in the bipartite parity system. Use a parity DSU over active row vertices and active column vertices. If consistent, each connected component contributes one free bit. All-A rows and all-A columns also contribute one free bit each, provided their parity checks passed. Answer is `2^(components + allA_rows + allA_cols)`, or `0` on any parity/DSU contradiction.
- **Implementation:** Read all tokens with `sys.stdin.buffer.read().split()`. Scan each row left-to-right, maintaining `row_parity` and `col_parity`. Update `col_parity` immediately on A; for B use the current value, which is the parity above the current row.
- **DSU details:** Lazy-allocate parent/size/diff on the first B. Parity DSU stores `diff[x] = value[x] xor value[parent[x]]`. Iterative find returns root and parity to root, then compresses the path by walking back with the accumulated parity. Union by size keeps depth small.
- **Invalid early exit:** Once a case is invalid, remaining row tokens are still consumed but not processed. This avoids unnecessary work.
- **Pitfalls:** The prefix parity must be relative to `R_i = h_{W-1}` and `C_j = v_{H-1}`, not to `h_0` or `v_0`. H=2/W=2 wrap edges are distinct and are handled naturally by the cycle equations. A cells do not couple `R_i` and `C_j`; only B cells do. All-A rows/columns are free only when their cyclic A-count parity is even.
- **Validation:** Sample cases match. A tiny brute-force edge-bit enumerator for H,W<=3 was used as a development cross-check and agrees with the row/column elimination formula.
