- **Model:** Operations only turn 0 into 1, so order is irrelevant. Each chosen operation covers either its interval (op 1) or its complement (op 2); we need the union to be [1,N] with minimum chosen operations.
- **Cost 1:** Achievable iff some interval is exactly [1,N] and we use op 1 on it. Op 2 on [1,N] covers nothing, so it cannot give cost 1.
- **Cost 2 patterns:** For two intervals, the only useful combinations are: both op 1, one op 1 and one op 2, or both op 2. Both op 1 cover the line iff one starts at 1, one ends at N, and they overlap/touch. One op 1 plus one op 2 covers the line iff the op 2 interval is contained in the op 1 interval. Both op 2 cover the line iff the two intervals are disjoint.
- **Cost 2 detection:** Sort by (L,R). While scanning, keep max_R and min_R among previous intervals. max_R >= current R means a previous interval contains current; use op 1 on that previous interval and op 2 on current. min_R < current L means a previous interval is disjoint from current; use op 2 on both. Same-L groups are checked afterwards because equal L containment is not caught by the strict L ordering; use op 1 on the group's max-R interval and op 2 on a distinct min-R interval. Finally check the span pattern using max R among L=1 intervals and min L among R=N intervals.
- **No cost 2 structure:** If no cost-2 pattern exists, all L values and R values are distinct, and after sorting by L the R values strictly increase while each interval overlaps/touches the next. Thus the intervals form a chain.
- **Cost 3 fallback:** For such a chain with M>=3, op 2 on the first interval (minimum L) and op 2 on the last interval (maximum R) cover everything except possibly [L_last, R_first]. Any other interval lies between them in both endpoints, so op 1 on any third interval covers that gap. If the min-L and max-R indices coincide, use that interval as op 1 and two other intervals as op 2.
- **Impossibility:** If no cost 1 or cost 2 is found and M<3, the goal is impossible; print -1.
- **Samples:** Sample 1 is caught by containment ([1,4] contains [2,4]); sample 2 by full interval; sample 3 by span ([1,3] and [2,5]); sample 4 has M=2 and no pattern.
- **Implementation:** Keep original indices in tuples. Emit immediately when a valid pattern is found. K is the number of nonzero operations, and the op array is printed space-separated.
