Compute prefix distinct counts L[i] and suffix distinct counts S[k] in O(N). Sweep the right split j from 2 to N-1, maintaining for every possible left split i<j the value L[i]+distinct(A[i+1..j]) in a lazy segment tree. When A_j is added, only i values whose middle segment did not already contain A_j increase by 1; if p is the previous occurrence of A_j, this is the range i in [p, j-2] (or [1,j-2] if none), so apply a range add. Insert the new candidate i=j-1 with value L[j-1]+1, query the maximum over i<j, and update the answer with that maximum plus S[j+1]. This yields O(N log N) time and O(N) memory, sufficient for N=3e5.
