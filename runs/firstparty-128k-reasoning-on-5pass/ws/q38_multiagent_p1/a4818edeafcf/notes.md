- **Identity:** For each appearing value x, let c_i, c_j, T be its counts up to i, up to j, and total. Its contribution to the three distinct counts equals 1 + I(0 < c_j < T) + I(0 < c_i < T and c_j > c_i). Summing over x gives answer = K + W[j] + max_{i<j} H(i,j), where K is total distinct, W[j] is the number of values with 0 < c_x(j) < T, and H(i,j) is the number of values with 0 < c_x(i) < T and c_x(j) > c_x(i).
- **Relation to planned sweep:** The planned pref/suf sweep is equivalent. This implementation uses the contribution form above, which is the same difference point-update segment tree but with base 0, avoiding pref/suf and reducing constants.
- **H sweep:** For fixed i, H(i,j) increases by 1 exactly when j is the first occurrence after i of a value that already appeared up to i. If current position j has previous occurrence p > 0, this adds +1 to all i in [p, j-1]. If p = 0, no H increase occurs.
- **Difference array:** Maintain D so that H(i,j) is the prefix sum of D up to i. When p > 0, apply D[p] += 1 and D[j] -= 1. The -1 at j is only needed when p > 0 in this H form; unlike the original middle-distinct form, p = 0 does not create a range add.
- **New left cut:** When right cut is j, the new i = j-1 has H = 1 if p > 0 else 0. This is exactly prefixD[i] after the current D[p] += 1 and before D[j] -= 1 affects it.
- **Segment tree:** Tree over i = 1..N-2. Each node stores sum of D in its interval and best = max over active leaves in the interval of the prefix sum from the node left boundary to that leaf. Pull: sum = sum_left + sum_right; best = max(best_left, sum_left + best_right). Active leaf stores D[i] relative to its own leaf; inactive leaves have best = NEG.
- **Operations per j:** Update W[j] online from counts. Let p = last[A[j]]. Activate i = j-1 by setting leaf best = leaf sum. If p > 0 and p < i, point add +1 at p. If p == i, combine activation and +1. If p > 0 and j <= N-2, apply D[j] -= 1 to the leaf only, without pulling ancestors.
- **Deferred -1 safety:** The leaf j is inactive and lies to the right of all active indices, so its stale ancestors cannot be used as left sums for active leaves. When i = j is activated next, its path is pulled and all affected sums are restored.
- **Complexity:** O(N log N) time and O(N) memory. At most two segment-tree pulls per j: one when p = 0 or p == i, two when 0 < p < i.
- **Pitfalls:** M = N-2; right cut j runs 2..N-1; W[j] must be computed after including A[j]; last[x] must be read before updating it; do not apply D[j] -= 1 when p = 0 in this formulation.
