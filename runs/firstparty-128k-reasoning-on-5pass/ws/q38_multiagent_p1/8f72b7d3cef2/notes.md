- **Reduction:** For a fixed starting position K, Takahashi’s absorbed slimes always form a contiguous interval [L,R] containing K, and his size is its sum. He can expand left/right exactly when the current sum is strictly larger than the outside neighbor. The maximum final interval is the inclusion-minimal stable interval containing K, where stable means no outside neighbor is strictly smaller than the interval sum.
- **Stability equations:** Let x=L-1, y=R, and P be prefix sums. For x>0, stability on the left is P[y] <= E[x] := P[x]+A[x] = 2P[x]-P[x-1]. For y<N, stability on the right is D[y] := 2P[y]-P[y+1] <= P[x]. Boundaries x=0 and y=N are vacuous on the missing side.
- **Extreme arrays:** Define Rmax[x] = largest y such that [x+1,y] is stable, and Lmin[y] = smallest x such that [x+1,y] is stable. For K, the optimal boundaries are X=max{x<K | Rmax[x]>=K} and Y=min{y>=K | Lmin[y]<K}. The interval [X+1,Y] is stable and is contained in every stable interval containing K, so the answer is P[Y]-P[X].
- **Computing Rmax:** Sort y=1..N-1 by D[y] ascending. Sweep x=1..N-1 ascending, activating y with D[y]<=P[x] in a Fenwick prefix-max tree. For each x, U=bisect_right(P,E[x])-1. If U>=N, Rmax[x]=N; otherwise query max active y<=U and keep it only if >x, else -1. Rmax[0]=N.
- **Computing Lmin:** Sort x=1..N-1 by E[x] descending. Sweep y=N-1..1 descending, activating x with E[x]>=P[y] in a reversed Fenwick prefix-min tree using rev=N-x+1. If D[y]<=0, Lmin[y]=0. Otherwise L=bisect_left(P,D[y]); query minimum active x>=L and keep it only if <y, else INF. Lmin[N]=0.
- **Combining without DSU:** The plan’s DSU range painting can be replaced by monotone stacks. For X, process K ascending, push x=K-1, pop while Rmax[top]<K; top is X. For Y, process K descending, push y=K, pop while Lmin[top]>=K; top is Y. Popped elements are inactive forever because K moves in the direction that only makes their condition harder.
- **Non-strict inequalities:** Equality blocks absorption, so all stability conditions are non-strict: D[y]<=P[x], E[x]>=P[y], Rmax[x]>=K, Lmin[y]<K.
- **Implementation details:** Use Python ints (64-bit safe). Fenwick updates can break early when a node already has a better value: max update breaks if bit[i]>=y, min update breaks if bit[i]<=x. Queries can break early if the best possible bound is reached. D is deleted after Rmax and recomputed from P during Lmin to save memory.
- **Complexity:** Two sorts and two offline Fenwick sweeps give O(N log N) time. Stacks and arrays give O(N) memory.
