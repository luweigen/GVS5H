Reframe the process: an interval is stable if its sum is not strictly smaller than either adjacent outside slime, and the maximum reachable interval for starting position K is exactly the minimal stable interval containing K. This follows because every final interval is stable, stable intervals containing K have a unique minimal intersection, and a stable interval cannot be crossed before it is fully reached. Represent a stable interval by x=L-1 and y=R with prefix sums P; stability is P[y] <= P[x]+A[x] for x>0 and 2P[y]-P[y+1] <= P[x] for y<N. For each x compute the largest stable y (Rmax[x]) using a segment tree over D[y]=2P[y]-P[y+1], and for each y compute the smallest stable x (Lmin[y]) using a segment tree over E[x]=P[x]+A[x]. Then sweep to get L_K-1 = max{x<K | Rmax[x]>=K} and R_K = min{y>=K | Lmin[y]<K}, and output P[R_K]-P[L_K-1].
