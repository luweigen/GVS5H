- **Core reduction:** For a query `[l, r]` in 0-indexed form, if `K` pairs are possible, the `K` smallest items in the interval can be used as tops and the `K` largest as bottoms. This follows from order statistics and the threshold matching property: sorted tops and bottoms must satisfy `top <= bottom / 2`.
- **Feasibility condition:** Let `p = l + K - 1`. Then `K` is feasible iff `p <= P = (l + r - 1) // 2` and for every `i in [l, p]`, the first sufficient bottom index `f[i]` satisfies `f[i] <= i + (r - p)`.
- **Precomputation:** `f[i]` is the first index with `A[f[i]] >= 2 * A[i]`, found by a two-pointer scan because `2 * A[i]` is nondecreasing. If no such index exists, `f[i] = N`. Define `g[i] = f[i] - i`. The condition becomes `max_{i=l..p} g[i] <= r - p`.
- **Direct formula:** Since `f` is nondecreasing, precompute `F[r] = last i with f[i] <= r + 1` by another two-pointer scan. For each query, set `T = min(P, F[r])`. If `T < l`, answer is `0`. Otherwise let `mx = max_{i=l..T} g[i]` and `p0 = min(T, r - mx)`. The answer is `max(0, p0 - l + 1)`.
- **Why `r + 1`:** Any feasible `p` has `f[p] <= r`, so `p <= F[r]`. For any feasible `p` and any `i in (p, T]`, `f[i] <= r + 1`, hence `g[i] <= r + 1 - i <= r - p`. Thus taking the maximum over the slightly larger range `[l, T]` never makes a feasible `p` look infeasible. Excluding indices with `f[i] > r + 1` prevents their large `g` values from incorrectly lowering `r - mx`.
- **Segment tree:** An iterative max segment tree over `g` answers each range maximum in `O(log N)`. Total complexity is `O(N + Q log N)`, with `O(N)` auxiliary memory.
- **Edge cases:** `f[i] = N` is handled naturally; for `r = N - 1`, it equals `r + 1` and is safe. Length-2 queries, duplicates, and `p0 < l` all produce `0` correctly. `P` enforces the capacity bound `K <= floor((r - l + 1) / 2)`.
- **Verification:** The two provided samples produce the expected outputs. A brute-force checker that tests all possible `K` on small random sorted arrays agrees with this formula; no sample data is hardcoded in the final program.
