The cost for a chosen common height H is total initial length minus N*H, so the problem reduces to finding the maximum feasible H. For fixed H, each upper tooth length u_i must lie in the interval [max(0, H-D_i), min(U_i, H)]. The adjacent constraint |u_i-u_{i+1}|<=X can be checked in O(N) by propagating the reachable interval of u_i and intersecting it with [prev_low-X, prev_high+X]. Feasibility is monotone: if H is feasible, any smaller H is feasible by capping all chosen u_i at the smaller height. Thus binary search H in [0, min_i(U_i+D_i)] and output total_sum - N*H_max.
