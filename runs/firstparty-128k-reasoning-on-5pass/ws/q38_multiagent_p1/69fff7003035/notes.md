- **Reduction:** By linearity, each value x contributes x times the sum over permutations of 10^{total digits to its right}. If the set S of elements to the right has size k, there are k!(N-1-k)! permutations with exactly that set to the right, and the multiplier is the product of 10^{digits(y)} over y in S.
- **Digit grouping:** Only digit length matters for the multiplier. Let c_l be the count of l-digit numbers and S_l their sum. For a fixed length d, the relevant polynomial is Q_d(z)=P(z)/(1+10^d z), where P(z)=∏_l(1+10^l z)^{c_l}. If q_k is the coefficient of z^k in Q_d, then F_d=∑_{k=0}^{N-1} q_k k!(N-1-k)!, and the answer is ∑_l S_l F_l.
- **Logarithmic derivative:** Let D(z)=∏_{active l}(1+10^l z) and B(z)=∑_l c_l 10^l D(z)/(1+10^l z). Then P'(z)D(z)=P(z)B(z). If D=∑d_r z^r and B=∑b_r z^r, coefficient comparison gives (k+1)p_{k+1}=∑_{r=0}^{min(M-1,k)} b_r p_{k-r} - ∑_{r=1}^{min(M,k)} d_r(k-r+1)p_{k-r+1}.
- **Implementation details:** Build D by in-place polynomial multiplication. Build B by dividing D by each (1+10^l z): t_0=1, t_j=d_j-10^l t_{j-1}, then add c_l 10^l t_j to b_j. Precompute inverses up to N. Precompute a_k from a_0=(N-1)! using a_{k+1}=a_k(k+1)/(N-1-k). For each active length d, compute q_0=1 and q_k=p_k-10^d q_{k-1}, accumulating F_d=∑a_k q_k.
- **Edge cases:** N=1 works directly: F=1 and answer=1. N<10 has M=1. Since N<mod, all needed inverses exist. p_N is computed but only p_0..p_{N-1} are needed for q.
- **Complexity:** At most six active digit lengths, so time is O(6N) and memory is O(N). No NTT is used.
