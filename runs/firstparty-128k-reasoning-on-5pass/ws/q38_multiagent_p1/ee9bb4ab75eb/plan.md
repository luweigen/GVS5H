Model all prefixes as trie nodes; a prefix of length d is feasible after removing i iff at least k remaining words pass through that node. For each word i, the answer is the maximum depth of a node with count >= k+1 on i's path, or a node with count >= k not on i's path. Build the trie once and count words per node. Then compute two values per word-end node: the deepest path node with count >= k+1, and the deepest good node outside the word's prefix path using subtree maxima and top-two sibling maxima. Combine them, defaulting to 0, and handle k == n as all zeros.
