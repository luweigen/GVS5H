Define prefix sums P[i] and C[i] for nums and cost. Use DP where dp[t][i] is the minimum cost to partition the first i elements into exactly t subarrays. The transition is dp[t][i] = min_{j<i} dp[t-1][j] + (P[i] + k*t)*(C[i] - C[j]). Rewrite it as P[i]*C[i] + k*t*C[i] + min_j((-C[j])*P[i] + dp[t-1][j] - k*t*C[j]), which is a line query in x=P[i]. Because C[j] and P[i] are increasing, the slopes and queries are monotone, so each layer can be computed with a convex hull trick in O(n), giving O(n^2) total. Return the minimum dp[t][n] over all valid t.
