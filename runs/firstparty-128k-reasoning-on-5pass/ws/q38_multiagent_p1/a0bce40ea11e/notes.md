- **Special primes:** p=1 means every value is 0 modulo 1. For p=2, every A entry is 0 or 1, and replacing zeros by 1 makes B the all-ones matrix, so B^2 has every entry N; output N mod 2.
- **Field and moments:** Work in F_p. For odd p, sum_{x in F_p^*} x^m is -1 when m=0 or m=p-1, and 0 otherwise for 0<=m<=p; in particular m=p gives sum x = 0.
- **Walk expansion:** Each entry of B^p is a sum over directed walks of length p. A zero edge variable survives only if its exponent is 0 or p-1. Since total length is p, surviving walks use either no zero edges, or exactly one zero edge p-1 times plus one originally nonzero edge once.
- **Common factor:** Every surviving walk contributes factor (-1)^K, where K is the number of zero entries. This is true both for no-zero walks and one-zero walks.
- **No-zero part:** Let C be A with zeros replaced by 0. The no-zero contribution is exactly C^p.
- **Zero diagonal loops:** If A_rr=0, the repeated zero edge is the loop at r. The single nonzero edge must start at r and be the last step, or end at r and be the first step. Add C_{r,b} to (r,b) and C_{a,r} to (a,r) for a,b != r. Diagonal corrections are zero because C_rr=0 for a zero diagonal.
- **Zero off-diagonal edges:** For z=(u,v) with u!=v, z cannot be followed by z. With only one other edge, a valid walk exists only when p=3, as z,e,z, forcing e=(v,u) to be nonzero. Then add C_{v,u} to (u,v). For p>3 this is impossible because p-1>2 zero traversals cannot be separated by one edge.
- **Algorithm:** Count K, build C, track zero diagonal positions and zero off-diagonal positions. Compute C^p by binary exponentiation; if C is diagonal, use pow on diagonal entries. Add O(N^2) corrections, then multiply the whole matrix by -1 if K is odd.
- **Matrix multiplication:** Use transposed B and dot products with `sum(map(operator.mul, row, col)) % p`, applying one modulo per entry. N=100 and at most about 60 matrix multiplications are feasible.
- **Pitfalls:** Do not use the odd-prime moment argument for p=2. Do not forget the p=3 reverse zero-edge correction. Do not treat a zero entry as the single fixed nonzero edge. Do not add diagonal corrections for zero diagonal loops. The common factor is (-1)^K, not (-1)^{K+1}.
