Work in F_p and separate the trivial p=2 case, where zeros have only one possible replacement, so the answer is simply B^2 with zeros set to 1. For p>2, expand each entry of B^p as a sum over length-p walks and sum over the independent choices in F_p^*. A zero entry's contribution vanishes unless its exponent is 0 or p-1, so only walks using no zero entries (C^p, with C=A and zeros set to 0) or walks using one zero entry exactly p-1 times survive, all with a common factor (-1)^K. For p>3 such a repeated zero entry must be a zero diagonal, producing only row/column corrections; for p=3 zero off-diagonal 2-cycles with a fixed opposite edge also contribute. Compute C^p by fast matrix exponentiation modulo p, add the O(N^2) corrections, multiply by (-1)^K, and output.
