Binary search the answer D, the target shortest distance from 1 to N. For fixed D, feasibility is equivalent to assigning integer labels 0..D to vertices with label(1)=0, label(N)=D, no edge increasing the label by more than 1, and at most K edges increasing the label by exactly 1. This is because choosing the +1 edges (and any extra edges if fewer than K) makes every 1-to-N path use at least D chosen edges, and any feasible choice yields such a labeling via shortest-path potentials. The labeling problem is a convex multi-label energy, so it can be minimized by an s-t cut on a layered graph with nodes (v,i) for i=1..D. In that graph, infinite edges enforce label monotonicity and forbid jumps larger than 1, while unit edges from (v,i) to (u,i) for each original edge u->v charge one for each +1 edge. D is feasible iff the minimum cut capacity is at most K, so the answer is the largest feasible D.
