- **Reduction to labels:** For a target distance D, feasibility is equivalent to assigning integer labels l_v in [0, D] with l_1 = 0, l_N = D, l_v <= l_u + 1 for every edge u -> v, and at most K edges satisfying l_v = l_u + 1. From a chosen edge set, use shortest distances from 1 capped at D; every tight increasing edge must be chosen. Conversely, choosing all tight increasing edges makes every 1-to-N path have net label increase D, and since each edge can increase the label by at most 1, every path contains at least D chosen edges.
- **Exactly K:** The condition can be relaxed from exactly K to at most K because changing additional edges from 0 to 1 cannot decrease any shortest distance.
- **Layered cut construction:** Node (v, i), i = 1..D, represents the threshold l_v >= i. Source side means true. Chain edges (v, i+1) -> (v, i) with INF enforce monotone thresholds. source -> (N, i) INF forces l_N = D, and (1, i) -> sink INF forces l_1 = 0.
- **Original edge gadget:** For each original edge u -> v, add unit edges (v, i) -> (u, i) for i = 1..D and infinite edges (v, i) -> (u, i-1) for i = 2..D. For a valid labeling, unit edges cut exactly once iff l_v = l_u + 1, and infinite edges cut iff l_v >= l_u + 2. Thus min cut capacity equals the minimum number of tight increasing edges.
- **INF and early stop:** Use INF = K + 1 and stop max flow once it reaches K + 1. Any cut violating a constraint or boundary has capacity at least K + 1, so flow <= K iff D is feasible.
- **Bounds and binary search:** D = 0 is trivially feasible. The answer is at most min(K, N - 1, unweighted shortest path length from 1 to N). Feasibility is monotone in D, so binary search the maximum feasible D.
- **Implementation details:** Dinic is sufficient because N <= 30 and D <= 29, giving under about 900 auxiliary nodes and a few thousand edges. Parallel edges are added separately, so parallel tight edges all count. Directed edges are kept directed and never symmetrized.
- **Edge cases:** D = 0 returns true immediately. Multi-edges are handled naturally by separate unit edges. Vertices not on any 1-to-N path do not break the equivalence; the min cut can label them to avoid unnecessary cost, and the shortest-distance labeling from a feasible solution also avoids false tight edges.
- **Samples:** The general construction yields the sample answers 1, 2, and 0 without any hardcoded sample logic.
