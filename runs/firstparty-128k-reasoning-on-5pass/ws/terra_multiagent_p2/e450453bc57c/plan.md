Compute the minimum cost for every length-`x` window to make all its elements equal; the optimal target is the window median, and the cost is the sum of absolute deviations from that median. Maintain this cost efficiently while sliding the window using two balanced multisets/heaps partitioned around the median, along with sums of each half. Then use dynamic programming to select at least `k` non-overlapping windows: at each ending position, either skip it or take the current window and add its cost to the best solution ending before its start. Since all costs are nonnegative, selecting exactly `k` windows yields the same minimum as selecting at least `k`.
