Model every removal sequence as a noncrossing matching of all elements when N is even, or all but one element when N is odd. For each matched pair, orient the larger value as `+` and the smaller as `-`, so the total score is the sum of selected positive values minus selected negative values. Any assignment with equally many `+` and `-` signs can be realized by repeatedly removing adjacent opposite signs, so only the multiset of chosen values matters. Therefore, sort the array: subtract the smallest `floor(N/2)` values from the largest `floor(N/2)` values, leaving the median unused when N is odd.
