Interpret the constraints as a directed functional graph with edges \(i \to A_i\); every directed cycle forces all its vertices to have equal values. Contract each cycle into one node, obtaining a rooted forest where every non-root node has the constraint \(x_v \le x_{\mathrm{parent}(v)}\). Use dynamic programming over possible assigned values: for each tree node, compute the number of valid assignments in its subtree when its value is fixed. Combine child contributions via suffix sums, then multiply across independent roots. The resulting complexity should be \(O(NM)\), suitable for \(N,M\le 2025\).
