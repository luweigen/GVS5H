Model each state as `(vertex, orientation)`, where orientation indicates whether the graph is currently original or reversed. From each state, moving along an available edge costs `1`, while toggling orientation at the same vertex costs `X`. This produces a graph with `2N` states and `2M + 2N` weighted transitions, so Dijkstra’s algorithm finds the shortest cost from `(1, original)` to either orientation of vertex `N`. Use 64-bit integer distances because costs can exceed 32-bit range.
