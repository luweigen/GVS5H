- **State representation:** After generating a string prefix `T`, retain the LCS DP row `dp[j] = LCS(T, S[:j])` for `j=0..N`. Since adjacent row values differ by either 0 or 1, encode the row by an `N`-bit mask whose bit `j-1` is 1 exactly when `dp[j] > dp[j-1]`. There are at most `2^N <= 1024` states.
- **Transition:** For every state mask, reconstruct its DP row by prefix sums. When appending character `c`, compute the next row left-to-right. At position `j`, if `S[j-1] == c`, the new value is `old[j-1] + 1`; otherwise it is `max(old[j], new[j-1])`. Convert the new row back to an increment mask.
- **Alphabet aggregation:** Multiple letters may produce the same next mask. For each source mask, aggregate equal destinations with their number of letters, so the length DP uses only distinct transitions and multiplicities.
- **Counting:** Start with one way in mask 0. Repeat transitions `M` times modulo `998244353`. The final LCS length of a state equals the popcount of its mask, so sum DP values by popcount for answers `0..N`.
- **Complexity:** Building transitions costs `O(2^N * 26 * N)`. The counting DP costs `O(M * 2^N * D)`, where `D <= 26` is the number of distinct outgoing destinations. This easily fits the limits.
