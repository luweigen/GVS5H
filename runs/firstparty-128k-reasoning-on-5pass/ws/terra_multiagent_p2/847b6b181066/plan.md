Track the cumulative wind displacement after each time step. Smoke generated at the origin at some earlier time remains at positions equal to the current cumulative displacement minus the displacement at its generation time. Thus, at time \(t\), smoke is at \((R,C)\) exactly when the prefix-displacement \((x_t-R, y_t-C)\) has appeared among valid earlier prefix displacements. Maintain these prior displacements in a hash set while processing the string in \(O(N)\).
