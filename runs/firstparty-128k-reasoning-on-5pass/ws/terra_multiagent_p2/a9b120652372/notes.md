- **Structural characterization:** After any sequence of operations, every original piece follows the same nondecreasing 1-Lipschitz position map \(f\): for source positions \(x<x'\), \(0\le f(x')-f(x)\le x'-x\). Each operation changes any individual position by at most one, hence \(|f(x)-x|\le k\) after \(k\) operations.
- **Support reachability formulation:** Let occupied source positions be \(a_0<\dots<a_{m-1}\), and desired occupied positions be \(b_0<\dots<b_{q-1}\). A target support is reachable in at most \(k\) operations iff there is a nondecreasing assignment of every source position to a target position such that: every target is used at least once; assigned target differences across adjacent sources are no larger than source gaps; and each assigned source-target displacement is at most \(k\).
- **Why this is sufficient:** The global pivot operations can realize every such ordered contraction assignment within the maximum assigned displacement. Thus minimum operations equal the minimum possible maximum source-target displacement subject to the assignment constraints.
- **Groups:** Since assignments are nondecreasing and every target must be used, sources are partitioned into \(q\) nonempty consecutive groups. All sources in group \(t\) map to \(b_t\). For a fixed \(k\), sources eligible for \(b_t\) are a contiguous index interval \([L_t,R_t]\), where \(b_t-k\le a_i\le b_t+k\).
- **Boundary constraint:** If group \(t-1\) ends at source index \(s-1\) and group \(t\) starts at \(s\), then the 1-Lipschitz condition is exactly \(a_s-a_{s-1}\ge b_t-b_{t-1}\). Thus each group boundary must lie at a sufficiently large source gap.
- **Feasibility greedy:** Process targets left to right. For each next target, select the earliest source boundary that is after the previous boundary, at least \(L_t\), and has a large enough source gap. Check that this boundary does not exceed \(R_{t-1}+1\) and starts no later than \(R_t\). Earliest boundaries dominate later ones, so this greedy is exact.
- **Complexity:** A feasibility check uses two pointers to compute all \([L_t,R_t]\) and one monotone boundary scan, hence \(O(N)\). Binary search over \(k\in[0,N]\) gives \(O(N\log N)\) per aggregate input length, acceptable for total \(N\le10^6\).
- **Impossible cases:** If target occupied count exceeds source occupied count, impossible immediately. Even with large \(k\), feasibility can fail because target gaps cannot exceed the source gap where a group boundary is placed; this captures examples such as source support `111` to target support `101`.
