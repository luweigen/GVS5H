- **DP invariant:** Root the tree at an arbitrary vertex. For every processed subtree, all vertices can be partitioned into valid K-vertex paths except possibly for one unfinished simple path segment whose endpoint is the subtree root. The state is `0` if no segment is exposed, and otherwise is the number of vertices in the unique exposed segment.
- **Why one exposed segment suffices:** Any path crossing the edge from a subtree to its parent must contain the subtree root, so at most one such path can leave that subtree. All other paths are entirely internal and must already have exactly K vertices.
- **Child combination:** A child with state `0` needs no connection through the current vertex. Each nonzero child state requires connecting its dangling endpoint to the current vertex. More than two such children is impossible because the current vertex would have degree greater than two in its assigned path.
- **Transitions:** With no dangling children, the current vertex starts a segment of size 1. With one child segment of size `x`, it becomes size `x+1`; if this equals K it is completed and state becomes `0`. With two child segments of sizes `a,b`, they must join through the current vertex, requiring `a+b+1=K`, after which the state is `0`.
- **Root handling:** The root has no parent, so it cannot expose an unfinished segment. The decomposition exists exactly when its final state is `0`.
- **K=1:** Every vertex alone is a valid path, so the answer is always `Yes`.
- **Correctness:** Each transition is forced by the invariant and the degree-at-most-two condition for paths. Conversely, every accepted transition explicitly constructs valid internal paths and, when applicable, the sole exposed segment. Induction over bottom-up order proves the invariant; root state `0` proves a full decomposition.
- **Complexity:** Iterative DFS and bottom-up processing both take O(NK) time and O(NK) memory, avoiding recursion-depth issues.
