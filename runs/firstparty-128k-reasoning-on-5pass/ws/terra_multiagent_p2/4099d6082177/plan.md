Root the tree arbitrarily and process it bottom-up, maintaining for each subtree whether all fully formed paths are valid and whether there is one unfinished path segment extending upward. Each vertex combines unfinished segments from its children: it may join two segments through itself, extend one segment, or start/end a path, but no vertex can belong to more than one path. Track segment lengths modulo the required path size K and reject any combination that cannot produce paths of exactly K vertices. Handle K=1 as an immediate `Yes`, since every vertex is its own path.
