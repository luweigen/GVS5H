Exploit that each food contributes to exactly one vitamin, so the selections for the three vitamins are independent except for sharing the calorie budget. For each vitamin type, compute a 0/1 knapsack DP where `dp[c]` is the maximum amount obtainable using at most/exactly `c` calories. Then, for every target vitamin amount, determine the minimum calories needed to achieve it for each vitamin and check whether the three minimum costs sum to at most `X`. Binary search the largest feasible target amount.
