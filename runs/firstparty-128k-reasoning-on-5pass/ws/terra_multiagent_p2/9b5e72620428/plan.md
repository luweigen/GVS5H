Model the final common sum as an integer \(S\). Each fixed value in \(A\) must be matched, after permutation, with a position in \(B\) whose fixed value is at most \(S\), while each fixed value in \(B\) must receive an \(A\) value at most \(S\); unknown entries can fill any remaining requirements. Derive a monotone feasibility predicate for a chosen \(S\), accounting for fixed \(A\) values, fixed \(B\) values, and the counts of \(-1\) entries. Identify a finite range or a set of critical candidate sums sufficient to test, then implement efficiently for \(N\le 2000\).
