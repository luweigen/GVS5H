- **Approach:** Use rerooting DP with one directed message for each oriented tree edge. A message from vertex `u` toward neighbor `v` represents the maximum number of vertices in a valid connected branch lying on `u`'s side when edge `(u,v)` is selected.
- **Directed-message recurrence:** Since the edge toward `v` is already selected, `u` can either be a leaf, yielding size `1`, or have selected degree `4`, requiring exactly three selected branches through its other neighbors. Thus the message is `max(1, 1 + sum of the best three incoming messages from neighbors other than v)` when at least three such neighbors exist.
- **Final answer:** Choose any selected degree-4 vertex as the center of the alkane. It must use exactly four incident branches, so its value is `1 +` the four largest incoming directed messages. The maximum over all vertices is the answer. If no vertex has four incident directions, print `-1`.
- **Implementation:** Root arbitrarily at vertex 0. Compute child-to-parent messages (`down`) bottom-up. Then process root-to-leaf, using each vertex's parent-side message (`up`) plus child-side messages to compute both center candidates and parent-to-child messages.
- **Correctness detail:** A connected subgraph of an original tree is automatically a tree. Therefore it is sufficient to ensure every selected vertex has degree 1 or 4. Unselected original edges impose no restrictions.
- **Complexity:** Sorting incoming branch values per vertex costs `O(sum(deg(v) log deg(v)))`, bounded by `O(N log N)`. Memory usage is `O(N)`.
- **Sample verdict:** The implementation produces `8`, `-1`, and `11` for samples 1, 2, and 3 respectively.
