Use bitmask dynamic programming over subsets of `target`, since `target.length <= 4`. For every nonempty subset, compute its LCM: a single incremented `nums` element can satisfy every target in that subset by becoming the smallest multiple of that LCM that is at least its original value. Process each number and update a DP where `dp[mask]` is the minimum cost to cover the target elements represented by `mask`; each number may either be unused or assigned to cover one subset. The answer is the DP value for the full target mask.
