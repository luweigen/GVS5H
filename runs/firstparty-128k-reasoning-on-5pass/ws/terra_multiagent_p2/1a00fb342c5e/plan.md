Model the constraints as a graph where each edge enforces `A[u] XOR A[v] = z`. Traverse every connected component, assigning each vertex a provisional XOR-distance value from an arbitrary root; any contradictory revisit means no solution exists. In a component, every valid assignment has the form `A[v] = dist[v] XOR root_value`, so choose `root_value` bit by bit to minimize the total sum. For each bit, set the root bit to `1` exactly when more than half of the component’s provisional values have that bit set; either choice is valid on ties. Isolated vertices should be assigned zero.
