- **Graph modeling:** Treat each constraint `A[x] XOR A[y] = z` as an undirected edge labeled `z`. In a connected component, choose an arbitrary root and assign each vertex a provisional XOR potential `dist[v]`, representing the XOR of edge labels along a path from the root to `v`.
- **Feasibility check:** During iterative DFS/BFS, traversing edge `(v, to, z)` requires `dist[to] = dist[v] XOR z`. If `to` is unvisited, assign this value. If already visited with a different value, constraints are inconsistent, so output `-1`. This handles cycles, parallel edges, and self-loops correctly.
- **Form of all solutions:** Once a component is consistent, every valid assignment has form `A[v] = dist[v] XOR T`, where `T` is one shared non-negative integer offset for that component. Different connected components can choose offsets independently.
- **Optimization:** For each bit independently, let `ones` be the count of component potentials whose bit is one and let component size be `s`. If the offset bit is zero, that bit contributes `ones * 2^bit` to the total; if one, it contributes `(s - ones) * 2^bit`. Set the offset bit to one iff `ones > s - ones`, equivalently `2 * ones > s`. Either choice is optimal on ties.
- **Bit bound:** Since all `Z_i <= 10^9 < 2^30`, every provisional potential has bits only in positions `0..29`. Setting any higher offset bit would set that bit in every component vertex and strictly increase the sum, so it is never optimal.
- **Complexity:** Graph traversal is `O(N + M)`. Per-component bit counting totals `O(30N)`, so total time is `O(N + M + 30N)` and memory is `O(N + M)`.
- **Implementation:** Uses iterative stack traversal to avoid recursion depth issues for `N <= 2 * 10^5`. Isolated vertices form one-vertex components with potential and optimal value zero.
