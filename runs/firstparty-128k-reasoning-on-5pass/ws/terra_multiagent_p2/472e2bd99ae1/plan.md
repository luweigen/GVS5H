Sort all three sequences in descending order. Since every value is positive, the expression is non-increasing when any one of the sorted indices is increased, creating a monotone 3D grid of candidate values. Start from indices `(0,0,0)` in a max-heap, repeatedly extract the current largest value, and push its valid neighboring states obtained by incrementing one index. Use a visited set to avoid inserting the same triple multiple times; after exactly K extractions, the last extracted value is the answer.
