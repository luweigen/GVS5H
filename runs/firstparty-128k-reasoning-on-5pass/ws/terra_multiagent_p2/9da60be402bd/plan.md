Model each state as an ordered pair of vertices `(u, v)`, representing that we still need to construct matching palindrome layers around a path from `u` to `v`. Run multi-source BFS backwards from all valid palindrome centers: `(i, i)` with distance `0`, and every direct edge `(i, j)` with distance `1`. From a state `(u, v)`, expand to `(predecessor of u by character c, successor of v by character c)` with distance increased by `2`. The resulting distances are exactly the shortest palindrome-path lengths for every ordered pair.
