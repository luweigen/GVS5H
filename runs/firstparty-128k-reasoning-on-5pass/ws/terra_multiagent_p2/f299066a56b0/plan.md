Use the sorted order and observe that for any target number of pairs \(K\), it is optimal to use the smallest \(K\) mochi as the upper mochi and select \(K\) suitable larger mochi as bottoms. Check feasibility greedily by matching each small mochi, in ascending order, with the earliest unused mochi from the latter portion whose size is at least twice the upper mochi. Binary search the maximum feasible \(K\) between 0 and \(\lfloor N/2 \rfloor\). This yields \(O(N \log N)\) time, which is sufficient for the constraints.
