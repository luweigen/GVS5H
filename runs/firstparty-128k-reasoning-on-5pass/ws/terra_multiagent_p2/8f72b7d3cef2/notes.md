- **Cartesian representation:** Build a max Cartesian tree while popping only values strictly smaller than the incoming value. Therefore every child has value at most its parent, and equal-value nodes remain distinct, with earlier equal values becoming ancestors of later equal values.
- **Initial absorbable component:** For a source at Cartesian node `v`, every child subtree whose root value is strictly smaller than `A[v]` can be entirely absorbed immediately: all values in that subtree are at most its root and hence strictly below `A[v]`. A direct equal-valued child cannot be crossed initially.
- **Equal-value handling:** The initial component has sum `A[v] + sum(strict-child subtrees)`. If no strict child exists, this is exactly `A[v]`; all adjacent Cartesian barriers have value at least `A[v]`, so the source is stuck. If at least one strict child exists, the sum is strictly larger than `A[v]`, allowing the source to cross every equal-valued direct child as well and complete the full subtree of `v`.
- **After completing a subtree:** Once the entire subtree of node `v` is absorbed, it can cross to its Cartesian parent exactly when `subtree_sum[v] > A[parent[v]]`. After absorbing that parent, its size is strictly larger than the parent value, so it can absorb all remaining elements of the parent subtree. Thus its state again becomes a completed Cartesian subtree.
- **Ancestor recurrence:** Let `top[v]` be the highest completed subtree reachable from an already-completed subtree `v`. For an edge `child -> parent`, if `sub[child] > A[parent]`, then `top[child] = top[parent]`; otherwise `top[child] = child`. Processing the tree in root-to-leaf order computes all `top` values in linear time.
- **Answer formula:** If node `v` has no strict child, answer is `A[v]`. Otherwise its initial strict-child absorption yields positive surplus, it completes subtree `v`, then reaches `top[v]`; answer is `sub[top[v]]`.
- **Complexity:** Cartesian tree construction, traversals, subtree sums, ancestor recurrence, and answer generation are all `O(N)` time and `O(N)` memory.
- **Strict inequality:** Every transition uses `>` exactly. Equal children are not initially consumable, but become consumable after gaining any positive mass from a strictly smaller neighboring subtree.
