Model the required flips as two groups: positions changing from 0 to 1 and positions changing from 1 to 0. Any unnecessary pair of extra flips can be removed without increasing cost, so an optimal solution flips each differing position exactly once. Derive the total cost from the order of these flips: each active `1` contributes its weight to every operation performed while it remains `1`. Show that, within each relevant group, sorting by `C_i` in the appropriate order minimizes the pairwise contribution, then compute the result with prefix/suffix sums in `O(N log N)` time. Use 64-bit integer arithmetic because total costs can be large.
