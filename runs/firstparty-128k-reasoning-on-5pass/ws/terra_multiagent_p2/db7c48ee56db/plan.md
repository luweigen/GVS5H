Exploit the guarantee that \(\binom{N}{K}\le 10^6\), so every valid selection can be enumerated directly. Generate all combinations of exactly \(K\) indices/elements, compute the XOR incrementally for each combination, and keep the maximum value found. In Python, `itertools.combinations(A, K)` provides efficient combination enumeration, while `functools.reduce` or a small loop computes each XOR. The total number of combinations is bounded, so this fits comfortably within time limits.
