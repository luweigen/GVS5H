Use prefix sums \(S_0=0,\ S_r=\sum_{i=1}^r A_i\), so every subarray sum is \(S_r-S_{l-1}\). For each right endpoint prefix sum \(x=S_r\), expand \((x-S_j)^K\) by the binomial theorem and aggregate powers of all earlier prefix sums \(S_j^t\). Maintain \(\sum_{j<r} S_j^t\) for every \(t=0,\dots,K\), allowing each endpoint’s contribution to be computed in \(O(K)\). Since \(K\le 10\), the total complexity is \(O(NK)\) modulo 998244353.
