Compute the inversion count for \(k=0\) using a Fenwick tree over values. When increasing \(k\) by one, exactly the elements whose current value is \(M-1\) wrap to \(0\); equivalently, these are original elements with value \(M-1-k\). Each such element changes its inversion contribution based on how many other elements occur before and after it. Precompute, for every value, the summed update caused by wrapping all positions containing that value, then iteratively output and apply updates for all \(M\) shifts. This yields \(O(N \log M + N + M)\) time and \(O(N+M)\) memory.
