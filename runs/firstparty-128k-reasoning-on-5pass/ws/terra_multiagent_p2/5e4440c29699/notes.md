- **Full-grid endpoint count:** In a complete grid, the number of paths ending at `(x,y)` over every possible start is `F(x,y)=C(x+y+2,x+1)-1`. Symmetrically, paths starting at `(x,y)` over every possible end are `G(x,y)=C(W-x+H-y+2,W-x+1)-1`.
- **Full-grid total:** Summing `F` over all grid points gives `C(W+H+4,W+2)-W-H-4-(W+1)(H+1)`.
- **Unique invalid-path decomposition:** Every full-grid path that is invalid visits the removed rectangle. If its first visited removed point is its start, it is uniquely counted by that starting point. Otherwise its first entry must be through the left side `(L,y)` from `(L-1,y)`, or through the bottom side `(x,D)` from `(x,D-1)`. No other first entry is possible for positive-coordinate monotone paths.
- **Why prefix factors are unrestricted:** A path ending at `(L-1,y)` cannot previously visit the hole since all of its vertices have x-coordinate at most `L-1`. Similarly, a path ending at `(x,D-1)` cannot visit the hole. Therefore the corresponding prefix counts are ordinary full-grid counts `F`.
- **Invalid count:** `sum_{p in hole} G(p)` counts paths starting inside the hole. Add `sum_{y=D..U} F(L-1,y)G(L,y)` if `L>0`, and `sum_{x=L..R} F(x,D-1)G(x,D)` if `D>0`.
- **Rectangle binomial aggregation:** For `P(a,b)=sum_{0<=i<=a,0<=j<=b} C(i+j,i)`, `P(a,b)=C(a+b+2,a+1)-1`. Inclusion-exclusion evaluates the binomial part of `sum_{p in hole}G(p)` in O(1). Subtract the hole area because every `G` contains `-1`.
- **Complexity:** Factorial preprocessing is O(W+H), left/bottom sums are O((R-L+1)+(U-D+1)), and memory is O(W+H). All limits fit because `W+H+4 <= 2,000,004`.
