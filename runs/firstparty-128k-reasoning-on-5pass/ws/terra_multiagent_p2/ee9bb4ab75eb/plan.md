Build a trie containing all words, where each node stores how many words pass through it. A prefix of length `d` is achievable by some `k` strings exactly when a trie node at depth `d` has count at least `k`. Removing one word only changes counts along that word’s trie path, so only prefix lengths whose count is exactly `k` can become invalid. Maintain the globally best and second-best valid depths, then for each word inspect its path to determine whether it uniquely destroys the global best depth.
