Root the tree at node 0 and perform a DFS while maintaining the current root-to-node path. For every value, track the deepest path index where it last appeared; this lets us maintain a sliding valid start boundary so the current ancestor-to-node segment has unique values. Prefix sums of edge lengths give the length of the valid segment in O(1), while its node count is derived from path indices. Update the global answer by maximizing length and, on ties, minimizing node count; use an iterative DFS to avoid Python recursion-depth issues.
