- **Finite-field summation:** For a replacement variable \(x\in\mathbb F_p^\*\), \(\sum_{x=1}^{p-1}x^e\) is \(-1\) modulo \(p\) when \(e=0\) or \(e>0\) is divisible by \(p-1\), and is \(0\) otherwise.
- **Global sign:** Every surviving walk has total factor \((-1)^K\), where \(K\) is the total number of zero entries in the input. An unused zero variable contributes \(-1\); a used surviving variable with exponent \(p-1\) also contributes \(-1\).
- **Main term:** Let \(C_{ij}=A_{ij}\) for nonzero entries and \(0\) for zero entries. Walks using no replaced zero entries contribute \(C^p\).
- **Primes \(p>3\):** A surviving walk using zeros must use exactly one zero entry exactly \(p-1\) times and one fixed nonzero entry once. Since there is only one separator, repeated copies force the zero edge to be a diagonal loop. The fixed edge can only be before all loop copies or after all loop copies; an interior fixed edge would have to be the same diagonal entry, which is zero and therefore cannot be fixed. If \(D\) is the diagonal mask of zero diagonal entries, exceptional contribution is \(CD+DC\).
- **Prime \(p=3\):** A zero edge may occur twice with the sole fixed edge between them, without requiring the zero edge to be diagonal. This adds the matrix \(E\) with \(E_{ij}=1_{A_{ij}=0}C_{ji}\). The full exceptional term is \(CD+DC+E\).
- **Prime \(p=2\):** Every zero has exactly one replacement, 1, so there is no averaging. Construct the unique completed matrix and output its square modulo 2.
- **Complexity:** Binary matrix exponentiation computes \(C^p\) in \(O(N^3\log p)\) time and \(O(N^2)\) memory.
