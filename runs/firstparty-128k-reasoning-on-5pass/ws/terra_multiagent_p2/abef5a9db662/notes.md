- **Offline compression:** Only queried initial ratings need to be represented. Sort and deduplicate all query values; their current ratings remain nondecreasing throughout all contests.
- **Contest update:** For an interval `[L, R]`, all compressed positions whose current values are in `[L, R]` form one contiguous index range due to monotonicity. Increment that whole range by one.
- **Segment tree operations:** Maintain maximum current value per node and lazy range-add tags. Find the left boundary using the first position with value at least `L`; find the exclusive right boundary using the first position with value greater than `R`.
- **Boundary search correctness:** Even after equal values arise, the sequence remains nondecreasing. Searching recursively by node maxima returns the first qualifying position, since every earlier segment whose maximum is below the threshold cannot contain a qualifying value.
- **Complexity:** Sorting/deduplication costs `O(Q log Q)`. Each of `N` contests uses two threshold searches and one range increment, each `O(log Q)`. Final point extraction costs `O(Q log Q)`. Total is `O((N + Q) log Q)` with `O(Q)` memory.
- **Edge cases:** If no represented current value belongs to a contest interval, the computed boundaries satisfy `left == right` and no update is applied. Duplicate queries are restored through a dictionary from initial value to its final rating.
