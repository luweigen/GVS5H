- **State reduction:** After some indices have entered `S`, only the total number `t` of remaining tokens on already-touched indices matters. Any move on such an index is simply a delay move changing `t` to `t-1`; its individual pile identity is irrelevant.
- **Reduced recurrence:** For untouched multiset `U` and delay total `t`, a player may delay if `t>0`, or touch an index of value `a`, changing the state to `(U \\ {a}, t+a-1)`. If `|U|=1`, touching the remaining index wins immediately.
- **Parity suffices:** Exact retrograde analysis shows every nonterminal reduced state has one of three outcome forms as a function of `t`: always winning, winning exactly for even `t`, or winning exactly for odd `t`. Thus each newly touched pile only matters through `(a-1) mod 2`, equivalently whether `a` is even.
- **Small sizes:** `N=1` is always Fennec; `N=2` is always Snuke. For `N=3`, Fennec loses only when all three values are even.
- **General rule:** For `N>=4`, the state is losing for the first player iff `(N + E)` is even, where `E` is the count of even `A_i`. Therefore Fennec wins iff `(N+E)%2==1`.
- **Inductive classification:** Let `c` be the count of even values. For all `N>=4`, except that `N=4` is the base case, the losing-delay parity is `(N+c) mod 2`; at initial delay total zero, Fennec wins exactly when that losing parity is one. The recurrence preserves this because removing an odd/even-valued untouched pile produces the same unique winning opening parity.
- **Complexity:** `O(N)` time and `O(1)` extra space besides input storage. Sorting is unnecessary; candidate rules involving sorted thresholds or value gaps are disproven by the pooled-delay state reduction.
