Model the game by observing that an index only needs to be selected once to enter \(S\); all further decrements on already-selected indices are delay moves. Sort the values and derive the winner from the parity of the distinct increasing thresholds, accounting for duplicate minimum available values that constrain optimal play. The final algorithm should run in \(O(N \log N)\) due to sorting and use 64-bit integers for values up to \(10^9\).
