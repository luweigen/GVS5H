- **Reachability characterization:** Label zeroes from left to right as \(0_0,0_1,\dots\). For a zero \(0_i\), let \(h_i\) be the number of ones before it. One operation moves exactly \(X\) consecutive labelled zeroes across exactly \(Y\) consecutive labelled ones, so it changes the corresponding \(h_i\) values by \(+Y\) or \(-Y\).
- **Per-zero invariant:** Therefore \(h_i \bmod Y\) is invariant for every individual zero label \(i\). This is stronger than merely comparing distributions of residues within classes modulo \(X\).
- **Class-sum invariant:** Write \(h_i=Yq_i+r_i\), where \(r_i=h_i\bmod Y\). Every operation changes \(q_i\) by \(+1\) or \(-1\) for one consecutive group of \(X\) zero labels. Such a group contains exactly one index from every residue class modulo \(X\). Hence the differences between \(\sum_{i\equiv c\pmod X}q_i\) for distinct classes are invariant; equivalently, between two strings all these class sums must change by one common integer.
- **Sufficient conditions:** Assuming both strings have the same number of zeroes and ones and there are at least \(X\) zeroes and \(Y\) ones, reachability is characterized by: (1) equal \(h_i\bmod Y\) for every labelled zero; and (2) the difference of the quotient sums \(\sum_{i\equiv c\pmod X}\lfloor h_i/Y\rfloor\) is independent of \(c\). This is the standard rectangular-flip/lattice-path characterization for swaps \(0^X1^Y\leftrightarrow1^Y0^X\).
- **No-operation case:** If the total number of zeroes is less than \(X\), or the total number of ones is less than \(Y\), no substring can match either operation. Then only identical strings are reachable.
- **Implementation:** Scan each string once. Maintain `ones`, and on every zero at index `zi`, record `ones % Y` and add `ones // Y` to the accumulator for `zi % X`. Comparing residue arrays takes \(O(N)\); comparing accumulator arrays takes \(O(X)\). Total memory is \(O(N+X)\), total time \(O(N+X)\).
- **Edge cases:** The direct equality branch covers \(N<X+Y\), but is also needed in general whenever either symbol count is insufficient. If counts differ, reachability is immediately impossible because operations preserve both counts.
