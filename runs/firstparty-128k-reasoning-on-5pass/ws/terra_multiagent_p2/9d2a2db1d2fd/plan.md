Model each floor level as inducing connected components among blocks whose buildings reach that level; moving by walkways is free within such a component. As the level decreases, components only merge, so construct a merge tree (Kruskal reconstruction tree) by processing grid edges in decreasing order of `min(F[u], F[v])`. For a query, the highest floor at which the two endpoint blocks are walkway-connected is the floor value of their LCA in this merge tree. The minimum stair usage is then `(Y - T) + (Z - T)` when their common reachable level is `T`, except that if both endpoints are already connected at `min(Y,Z)`, the direct vertical difference `abs(Y-Z)` is optimal.
