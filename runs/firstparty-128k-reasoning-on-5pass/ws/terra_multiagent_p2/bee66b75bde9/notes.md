- **Monotonicity model:** Valid black cells form a downward-closed set under coordinates: if \((x,y)\) is black, every \((x',y')\) with \(x' \le x\) and \(y' \le y\) must be black. This follows from row black prefixes and column black prefixes.
- **Conflict criterion:** A prescribed black cell \((x_b,y_b)\) and prescribed white cell \((x_w,y_w)\) are inconsistent exactly when \(x_b \ge x_w\) and \(y_b \ge y_w\). The black cell would force the white cell to be black.
- **Sufficiency:** If no such black-white dominance pair exists, color precisely the downward closure of all prescribed black cells black and all other cells white. This is a valid monotone coloring and contains no prescribed white cell.
- **Sweep algorithm:** Sort all constraints by column descending. Maintain the maximum row among black points seen at columns greater than or equal to the current column. For each same-column group, first incorporate all black points, then test every white point. A white point at row `x` conflicts iff `x <= max_black_row`.
- **Equal-column handling:** Black cells in the current column must be included before checking whites in that column because equality of columns also satisfies the dominance condition.
- **Complexity:** Sorting costs \(O(M\log M)\); sweeping costs \(O(M)\). Memory use is \(O(M)\). This is valid for \(M \le 2\times10^5\), independent of huge \(N\).
