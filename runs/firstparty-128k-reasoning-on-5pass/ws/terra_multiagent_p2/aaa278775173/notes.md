- **Verification:** The implementation was checked against all four supplied examples; it returns `5`, `4`, `5`, and `1`, respectively.
- **Clockwise mapping:** With matrix coordinates where rows increase downward, the required clockwise V-turn mapping is `SE (1,1) -> SW (1,-1) -> NW (-1,-1) -> NE (-1,1) -> SE`. This agrees with example 1 (`SE` then `SW`) and example 2 (`SW` then `NW`).
- **Suffix DP scan order:** For an alternating suffix moving by `(dr, dc)`, its dependency is at row `r + dr`. Processing rows bottom-to-top when `dr = 1`, and top-to-bottom when `dr = -1`, guarantees the dependent suffix is already computed. Column order is irrelevant because every dependency is on another row.
- **Prefix DP scan order:** A first-arm prefix moving by `(dr, dc)` depends on its predecessor at row `r - dr`. Thus rows are processed top-to-bottom for `dr = 1` and bottom-to-top for `dr = -1`. Again, column order is irrelevant.
- **Targeted edge cases:** A `1x1` grid containing `1` returns `1`; a grid containing no `1` returns `0`; a standalone `1` surrounded by unusable cells returns `1`; straight valid diagonals are retained because the answer is updated before attempting a turn; and an immediate turn after the initial `1` is handled by checking the turned neighbor.
- **Parity:** A prefix of odd length ends on `1` or `2` at positions requiring next value `2`; a prefix of even length requires next value `0`. The same parity applies across the turn, so the continuation suffix begins at exactly the required value.
- **Complexity:** Four alternating-suffix passes and four prefix passes each process every cell once, for `O(nm)` time. Four suffix arrays plus one prefix array use `O(nm)` memory. `array('H')` is safe since a diagonal has length at most `min(n, m) <= 500`.
