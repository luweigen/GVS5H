- **Testing:** Both provided samples pass: `[-3,2,-2,-1,3,-2,3] -> 7` and `[1,2,3,4] -> 10`.
- **Exhaustive validation:** Compared the segment-tree implementation with a brute-force solver that tries no deletion and deletion of every distinct value, then runs Kadane's algorithm on each resulting non-empty array. Exhaustive arrays with values in `[-2, -1, 0, 1, 2]` for lengths `1` through `7` pass (`97,655` arrays). No counterexample found.
- **Random validation:** Random small arrays, including repeated values, all-negative inputs, zeros, large positive/negative mixtures, and deletion candidates at boundaries, match brute force. No counterexample found.
- **Reduction:** Removing a nonnegative value cannot improve the answer. Any post-deletion subarray can instead retain occurrences of that value in the original array, preserving contiguity and not decreasing its sum. Only distinct negative values need be tested, in addition to no operation.
- **Model:** For a fixed deleted negative value, all its occurrences become inactive zero-contribution positions. They may bridge retained elements, but a final subarray must contain at least one retained element.
- **Segment state:** Every node stores total active sum, whether it contains a retained element, maximum prefix/suffix sums allowing empty selections, validity flags for whether tied optimal prefix/suffix choices can retain an element, and best valid non-empty retained subarray sum.
- **Correctness details:** Negative active leaves use empty prefix/suffix sum zero but mark them invalid; their valid-subarray answer remains the negative value. Inactive leaves have no retained element and no valid subarray. On equal prefix/suffix sums, validity is ORed so a retained representative is not lost.
- **Complexity:** Each negative occurrence is deactivated and restored once. Time is `O(n log n)` and memory is `O(n)`.
