- **Current result:** No complete full-constraint algorithm has been derived. The program is exact but only supports efficient logarithmic updates when the smaller grid dimension is at most three. For all other grids it recomputes the whole DP after every update, which is not worst-case feasible.
- **Single-update identity:** Let `L(v)` be the weighted path sum from `(1,1)` to `v`, excluding the weight of `v`, and `R(v)` the weighted path sum from `v` to `(H,W)`, excluding the weight of `v`. Replacing `A[v]=x` by `y` changes the answer by `(y-x)L(v)R(v)` modulo `998244353`. This is valid with zero weights, but dynamically maintaining the needed values is difficult.
- **Small-width transfer method:** With oriented height `d`, each column has lower-triangular transfer matrix `T[i,j]=product(A[j..i])` for `j<=i`. Consecutive columns compose as `T_right*T_left`. A segment tree over columns supports rebuilding one changed column and composing matrices without division, hence zero weights are handled.
- **Rank-one observation:** Changing one cell inside a column changes that column transfer matrix by a rank-one matrix: entries affected are exactly those with start row `j<=r` and end row `i>=r`, and their difference factors into a suffix term times a prefix term. Sandwiched by the products of columns on both sides, the full transfer product also changes by rank one. A full solution may exploit this, but obtaining the required current prefix and suffix actions efficiently remains unresolved.
- **Trace-only elimination obstruction:** Eliminating unchanged vertices while retaining cells visited by the update walk can create dense transfer relations. A walk along the top and then right boundary of a rectangle can induce interactions from every retained top cell to many retained right cells through the interior.
- **Adjacency limitation:** Update positions form a connected walk, but this does not bound the number of distinct positions, bounding box, separator crossings, or treewidth. Therefore adjacency alone does not justify sparse interactions among updated cells.
- **Potential direction:** A complete method likely needs a dynamic planar-DAG or low-rank transfer representation supporting point gate replacements and querying one terminal entry, while using the adjacent update cursor to avoid arbitrary dynamic matrix-product costs.
