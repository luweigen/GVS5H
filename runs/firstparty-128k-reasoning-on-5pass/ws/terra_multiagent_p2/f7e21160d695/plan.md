Build a minimum spanning tree (MST), since the minimax path value between any two vertices in the original graph equals the maximum edge weight on their unique path in an MST. Process MST edges in increasing weight order using DSU; when two components merge, optimally match as many unmatched occurrences of A and B across those components as possible, charging the current edge weight for each such pair. Maintain per-component counts of unmatched A and B, including duplicates. The total charged weight is the minimum possible sum.
