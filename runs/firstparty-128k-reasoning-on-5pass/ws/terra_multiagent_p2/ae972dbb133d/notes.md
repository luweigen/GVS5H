- **Edge-variable formulation:** Let `h[i][j]` indicate whether the right edge of cell `(i,j)` is occupied, and `v[i][j]` whether its bottom edge is occupied. Toroidal adjacency means these variables represent shared interfaces directly.
- **Local constraints:** For an A tile, exactly one horizontal and one vertical incident edge are occupied, giving `h[i][j-1] xor h[i][j] = 1` and `v[i-1][j] xor v[i][j] = 1`. For a B tile, opposite edges are paired, giving the same equations with right side `0`, plus `h[i][j] xor v[i][j] = 1`.
- **Unified difference equations:** With `a[i][j]=1` for A and `0` for B, all cells require horizontal and vertical differences equal to `a[i][j]`. Therefore every row and every column must contain an even number of A tiles; otherwise cyclic propagation is inconsistent and the answer is zero.
- **Prefix labels:** Choose row seed `R[i]=h[i][W-1]` and column seed `C[j]=v[H-1][j]`. Define `HP[i][j]=xor(a[i][0..j])` and `VP[i][j]=xor(a[0..i][j])`. Then `h[i][j]=R[i] xor HP[i][j]` and `v[i][j]=C[j] xor VP[i][j]`. At every B cell, the crossing condition becomes `R[i] xor C[j] = 1 xor HP[i][j] xor VP[i][j]`.
- **Counting:** Build a parity-constraint graph with one vertex per row seed and column seed. Every B cell adds one XOR equation. A consistent connected component has exactly one free binary choice, including isolated vertices. Thus the answer is `2^(number of DSU components)`.
- **Implementation:** A parity DSU stores the XOR value from each node to its parent. It verifies B-cell equations while merging components. Prefixes are computed streaming row by row, using `horizontal_prefix` and one `vertical_prefix` array, so time is `O(HW alpha(H+W))` and memory is `O(H+W)`.
- **Multiplicity:** No additional tile-orientation factor is needed. Once occupied cell edges are fixed, the segment pattern of each A or B tile is uniquely determined.
