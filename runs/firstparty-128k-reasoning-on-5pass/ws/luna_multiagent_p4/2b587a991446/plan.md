Model the configuration as an ordered pair of distinct vertices \((a,b)\), where A is at \(a\) and B is at \(b\); each operation changes exactly one coordinate along an edge while preserving \(a\neq b\). The state graph has \(N(N-1)\) states, so an explicit BFS is too large. Derive the shortest-path structure using distances from \(S\) and \(T\), identifying whether the two pieces can follow shortest routes without colliding and handling the exceptional parity/bipartite obstruction. Implement the resulting distance computation in \(O(N+M)\) time and output \(-1\) when the swap is impossible.
