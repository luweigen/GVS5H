Use the sorted order of mochi sizes and seek the largest number of pairs between a lower half and an upper half. For a candidate \(K\), pair the first \(K\) unused/smallest mochi with the \(K\) mochi starting at position \(N-K\), checking \(A_i \times 2 \le A_{N-K+i}\) for every \(i\). This feasibility condition is monotonic in \(K\), so binary search \(K\) from \(0\) to \(\lfloor N/2\rfloor\). The resulting algorithm runs in \(O(N\log N)\) time including binary search checks and uses \(O(1)\) extra space beyond the input.
