Compute the inversion count for \(k=0\) using a Fenwick tree over the values \(0,\ldots,M-1\). When increasing \(k\) by one, exactly the elements with \(A_i=M-1-k\) wrap from \(M-1\) to \(0\); each such element changes its inversion relation with every element of a different original value. For each value group, precompute the total change using its occurrence positions, excluding pairs of equal values because their relative order never changes. Output the current count before applying each transition.
