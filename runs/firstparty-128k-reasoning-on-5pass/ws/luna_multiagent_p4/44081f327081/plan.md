Use the key observation that a candidate GCD \(d\) is possible for \(A_i\) exactly when \(d\mid A_i\) and at least \(K\) array elements are divisible by \(d\). Compute, for every divisor \(d\), how many input values are multiples of \(d\) using a sieve-style multiples loop. Then process feasible divisors in increasing order and assign each of their multiples the divisor, so the final assigned value is the largest possible GCD. Output the precomputed result for each original element, with total complexity \(O(M\log M+N)\), where \(M=\max A_i\).
