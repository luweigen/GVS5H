- **Minimax distance:** For any two vertices, the minimum possible maximum edge weight on a path equals the maximum edge weight on their path in a minimum spanning tree. Kruskal processing therefore exposes all pairs in nondecreasing order of their values \(f(x,y)\).
- **Component matching count:** For a connected component, if it contains `a` occurrences from sequence `A` and `b` occurrences from sequence `B`, then at most `min(a, b)` pairs can currently be matched using only vertices inside that component.
- **Union contribution:** Before merging two components, their achievable matching counts sum to `old_pairs`. After merging, the count becomes `min(total_a, total_b)`. The increase consists of pairs whose minimum possible bottleneck weight is exactly the current edge weight, so it contributes `(new_pairs - old_pairs) * weight`.
- **Duplicates:** Occurrences are represented by counts, so repeated values within either sequence are handled independently. The guarantee that no `A_i` equals any `B_j` means no initial component contains both types.
- **Complexity:** Sorting edges costs `O(M log M)`. DSU operations take near-linear time, and memory usage is `O(N + M)`.
