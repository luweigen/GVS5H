- **Characterization:** For any subarray, the minimum number of operations equals the number of maximal consecutive-value components in its set of distinct values. Each component can be erased in one operation. Different components cannot be erased together because a missing integer would violate the operation condition.
- **Component assignment:** Assign each component to its smallest value \(x\). Then \(x\) contributes exactly when \(x\) appears in the subarray and \(x-1\) does not.
- **Fixed right endpoint:** Let `last[x]` be the latest position of value \(x\) among \(A_1,\ldots,A_R\), with value 0 if absent. A subarray \([L,R]\) contains \(x\) iff \(L\le last[x]\), and excludes \(x-1\) iff \(L>last[x-1]\). Therefore the number of valid left endpoints is \(\max(0,last[x]-last[x-1])\).
- **Local update:** Appending value \(v=A_R\) changes only the terms for \(x=v\) and \(x=v+1\). For \(x=v\), the term changes from \(\max(0,old\_last[v]-last[v-1])\) to \(R-last[v-1]\). For \(x=v+1\), its predecessor becomes the newly appended \(v\), so its term changes from \(\max(0,last[v+1]-old\_last[v])\) to zero. All other terms remain unchanged.
- **Complexity:** Each element is processed in \(O(1)\) time, giving \(O(N)\) time and \(O(N)\) memory. The answer fits in Python integers without special handling.
- **Validation:** The update produces totals 16, 23, and 129 for the three samples. It also handles repeated values, absent predecessors through `last[0]=0`, value \(N\) through the extra `last[N+1]` slot, and singleton subarrays.
