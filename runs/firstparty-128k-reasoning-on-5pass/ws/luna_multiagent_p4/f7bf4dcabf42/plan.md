Process every possible length-\(M\) string implicitly using dynamic programming over prefixes of the unknown string. Represent a state by the LCS DP row between \(S\) and the current prefix; for each of the 26 letters, update this row using the standard LCS recurrence and accumulate the number of ways reaching each state modulo \(998244353\). After \(M\) steps, group states by their final LCS value with the full string \(S\), producing answers for all \(k=0,\ldots,N\). Since \(N\le 10\), the number of distinct DP rows remains manageable, while \(M\le100\) allows repeated state transitions efficiently.
