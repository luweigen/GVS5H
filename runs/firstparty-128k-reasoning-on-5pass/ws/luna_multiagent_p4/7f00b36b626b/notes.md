- **Reduction:** Two positive integers `a` and `b` have `lcm(a, b) <= threshold` exactly when they divide a common multiple `m <= threshold`; their least common multiple itself is such an `m`.
- **Auxiliary-node DSU:** Create one DSU node for every original array element and one auxiliary node for every integer from `1` through `threshold`. For each input value `x <= threshold`, union its original node with every auxiliary node representing a multiple of `x`.
- **Correctness:** If two values have an edge, they both divide their LCM, so their original nodes connect through the auxiliary node for that LCM. Conversely, if two original nodes connect through an auxiliary multiple `m <= threshold`, then both values divide `m`, so their LCM is at most `m` and they are adjacent. Thus DSU connectivity matches graph connectivity.
- **Values above the threshold:** A value greater than `threshold` cannot have an LCM at most `threshold` with any positive value, so it remains an isolated component and requires no unions.
- **Complexity:** The total number of processed multiples is at most `threshold * (1 + 1/2 + ... + 1/threshold) = O(threshold log threshold)`. DSU operations are effectively inverse-Ackermann time. Memory usage is `O(n + threshold)`.
