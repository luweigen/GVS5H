Build a trie of all words, storing for each node the number of words passing through it and its depth. A prefix node contributes to the answer after removing index `i` iff its original count is at least `k`, except nodes on the removed word’s trie path, where the count decreases by one and must therefore be at least `k + 1` originally. Maintain the maximum valid trie depth globally, while temporarily disabling the affected path nodes for each removal and querying the maximum remaining depth. Use a segment tree or equivalent depth-indexed structure to support efficient updates and restores, yielding near-linear complexity in the total input size.
