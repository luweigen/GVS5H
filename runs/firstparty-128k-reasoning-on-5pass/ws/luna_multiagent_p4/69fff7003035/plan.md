Express each concatenated number as the sum of each element multiplied by a power of 10 determined by the elements appearing after it. For a fixed value \(x\), group permutations by the subset of elements placed after \(x\); the contribution depends only on the subset size and the product of weights \(10^{\text{digits}(y)}\). Build the elementary-symmetric polynomial of all element weights, then obtain the polynomial excluding each digit-length class by dividing by \(1+w t\); there are only six possible digit lengths. Combine its coefficients with \(k!(N-k-1)!\) and the sum of values in each class to obtain the answer in \(O(N \log N)\) or \(O(6N)\) time modulo 998244353.
