Represent each row as a bitmask and let a column-flip mask determine which columns are toggled. For a fixed column mask `m`, each row can optionally be flipped, so its minimum contribution is `min(popcount(row xor m), W - popcount(row xor m))`. Count the frequency of every row mask and compute the XOR convolution with the kernel `f[t] = min(popcount(t), W - popcount(t))` using a Walsh–Hadamard transform in `O(W2^W)` time. The minimum convolution value over all column masks is the answer.
