Represent each entry of \(B^p\) as a sum over length-\(p\) walks, then interchange the walk sum with the independent sums over values assigned to zero entries. Over \(\mathbb F_p\), use \(\sum_{x=1}^{p-1}x^e=0\) unless \(p-1\mid e\), in which case it equals \(-1\), and exploit that the total walk length is only \(p\). For odd \(p\), this restricts contributing walks to those using no zero entries or one zero entry exactly \(p-1\) times; analyze the resulting walk shapes separately for \(p=3\) and \(p>3\). Handle \(p=2\) directly, since every zero has the unique replacement \(1\), then implement the remaining matrix products and corrections in \(O(N^3)\).
