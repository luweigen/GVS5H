Represent each town by a potential \(P_x\), where road \(j\) has strength \(P_{j+1}-P_j\). A person imposes \(P_{S_i}=P_{T_i}\) and strict inequalities requiring every intermediate potential to lie strictly above this value when traveling right, or strictly below it when traveling left. Thus, for any consecutive subset of people, feasibility becomes checking whether the induced equality classes and strict-order constraints contain a directed cycle. Use an offline range-query algorithm with rollback data structures, while compressing each person’s interval inequalities through a segment tree so that all constraints are processed in near-linearithmic time.
