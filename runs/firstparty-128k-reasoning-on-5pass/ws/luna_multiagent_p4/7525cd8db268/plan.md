Normalize each conflicting pair as \((l,r)\) with \(l<r\), and sweep subarray right endpoints from 1 to \(n\). For every right endpoint \(r\), the active pairs ending at or before \(r\) impose a minimum forbidden left boundary, namely the maximum \(l\) among pairs with right endpoint at most \(r\); thus the number of valid subarrays ending at \(r\) is \(r-\text{boundary}\). Track the largest and second-largest active left boundaries, along with which pair uniquely contributes the largest one, so removing that pair can be credited with every boundary reduction it enables. Sum the baseline count using all pairs, add each pair’s accumulated improvement, and return the maximum result.
