Model each sequence of swaps and prefix deletions as a process that brings equal-valued elements together before deleting them, balancing swap costs against the number of deletion operations. Derive a dynamic programming or equivalent combinatorial formulation that captures the optimal order of deleting value-groups and can be computed in near-linear time. Prove the formulation, validate it on edge cases and the samples, then implement it with total complexity \(O(\sum N \log N)\) or better.
