- **Decomposition:** Split `p` as `A*B*C`. Removing empty literal segments is valid because every `*` can match an empty sequence, so adjacent wildcard regions can be merged. The remaining nonempty literals must occur in order, with each next occurrence starting at or after the previous occurrence’s end.
- **Empty pattern literals:** If all three pieces are empty, then `p == "**"` and the empty substring is valid, so the answer is `0`. With one nonempty piece, the shortest match is simply any occurrence of that piece, giving its length.
- **Occurrence search:** KMP finds all occurrences of each nonempty literal in `O(len(s) + len(piece))` time. The occurrence lists are naturally sorted by starting position.
- **Candidate construction:** For every occurrence of the first nonempty piece, binary search each later occurrence list for the first start position at least the previous piece’s end. Choosing the earliest feasible later occurrence is optimal because it minimizes the final endpoint and also leaves the most room for subsequent pieces.
- **Correctness:** A valid matching substring corresponds exactly to a chain of occurrences of the retained literals, ordered by non-overlap between consecutive literals. Conversely, every such chain is realizable by assigning each wildcard the gap between neighboring literals, including an empty gap. The computed span from the first literal’s start to the last literal’s end is therefore a valid matching substring, and all possible first occurrences are examined.
- **Complexity:** KMP takes `O(len(s) + len(p))` total because there are at most three literal pieces. The candidate scan performs at most two binary searches per first occurrence, for `O(len(s) log len(s))` time and `O(len(s) + len(p))` memory.
- **Boundary cases:** Leading, trailing, or internal empty pieces are handled by filtering them out. Adjacent stars, literals touching wildcard boundaries, repeated literals, overlaps in raw occurrences, and patterns such as `*a*`, `a**b`, or `**a` all follow the same ordered-boundary rule.
