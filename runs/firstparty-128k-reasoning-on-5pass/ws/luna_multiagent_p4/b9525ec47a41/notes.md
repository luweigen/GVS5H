- **Local encoding:** Let the cycle edge entering position \(i\) have state \(x_{i-1}\), and the edge leaving it have state \(x_i\), where state 1 means the edge points toward the larger-index endpoint. The cycle contribution to \(d_i\) is \(x_{i-1}+1-x_i\). If \(s_i=1\), an additional binary spoke contribution is possible.
- **Output relations:** For each possible degree, construct the Boolean relation from \(x_{i-1}\) to \(x_i\). With \(s_i=0\), the relations are \(E_{01}\), \(I\), and \(E_{10}\). With \(s_i=1\), they are \(E_{01}\), \(\begin{smallmatrix}1&1\\0&1\end{smallmatrix}\), \(\begin{smallmatrix}1&0\\1&1\end{smallmatrix}\), and \(E_{10}\).
- **Distinctness:** Every leaf-degree string uniquely determines one selected relation at each position, so counting relation products counts distinct degree strings rather than orientation assignments.
- **Cyclic closure:** The product relation after all \(N\) positions represents possible initial-to-final cycle states. A valid cyclic orientation exists iff the product contains a diagonal entry, corresponding to initial state equal to final state.
- **Finite-state DP:** There are only \(2^4=16\) Boolean \(2\times2\) relations. Relations are composed deterministically, and the DP stores the number of distinct output strings producing each product relation. Zero relations are harmless and naturally retained.
- **Hub degree:** The hub indegree equals the total number of graph edges minus the sum of the leaf indegrees. Therefore distinct leaf-degree vectors always give distinct full degree sequences, so no additional counting condition is needed.
- **Complexity:** The algorithm uses \(O(16N)\) time and \(O(16)\) memory.
