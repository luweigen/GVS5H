Track the cumulative displacement of the wind path, denoted by `P[t]`, after the first `t` winds. Smoke is generated exactly when the current cumulative position is visited for the first time, so each distinct prefix position corresponds to one smoke source. At time `t+0.5`, a source created at prefix position `P[k]` is at `P[t] - P[k]`; therefore smoke is at `(R,C)` iff `P[t] - (R,C)` is among the prefix positions first visited by time `t-1`. Process the string from left to right while maintaining the set of visited prefix positions and append `1` or `0` for each time.
