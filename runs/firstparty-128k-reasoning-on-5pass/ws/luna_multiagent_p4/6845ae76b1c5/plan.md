Use square-root decomposition on the prefix of `A`. For each block of `A`, precompute its contribution against every individual `B_j`, then prefix-sum over `j` so any complete `A` block and `B` prefix can be answered in O(1). For the final partial `A` block, compute each `|A_i-B_j|` prefix sum using sorted `B` values and prefix sums with binary search. Each query is answered in O(√N log N), while preprocessing costs O(N√N + N log N).
