- **Model:** Each type-1 operation contributes its interval; each type-2 operation contributes the complement of its interval. The final state is determined by the union of selected contributions, independently of operation order.
- **Reduction:** If no type-2 operation is selected, type-1 intervals must cover `[1,N]`. If one type-2 interval `[L,R]` is selected, type-1 intervals must cover `[L,R]`. If two type-2 intervals are selected, only their intersection must be covered by type-1 intervals; disjoint excluded intervals already solve the problem with cost 2. More than two type-2 operations are never useful because their intersection is already determined by two extremal boundaries.
- **Interval covering:** Minimum interval covers are computed greedily. For every starting coordinate, store the interval with maximum right endpoint among intervals beginning no later than that coordinate. Binary lifting answers each cover query in `O(log N)` and reconstruction is done only for the final answer.
- **Two type-2 operations:** For a fixed interval `a`, if another interval has `L_b <= L_a`, the best candidate minimizes `R_b` subject to `R_b >= L_a`. If `L_b > L_a`, the best candidate maximizes `L_b` subject to `L_b <= R_a` and `R_b >= L_a`. These extrema suffice because shrinking an intersection cannot increase its minimum cover size.
- **Complexity:** `O((N + M) log N + M log M)` time and `O(N log N + M)` memory.
