Model each group of three as a subtree of a ternary tree, where each internal node stores the majority value of its three children. For every node, compute the minimum number of leaf changes needed to make its resulting value 0 or 1. For a leaf, the costs are 0 for retaining its bit and 1 for changing it; for an internal node, calculate each target value by choosing child outcomes whose majority equals that target and minimizing the total cost. The answer is the minimum cost for producing the opposite of the current root value.
