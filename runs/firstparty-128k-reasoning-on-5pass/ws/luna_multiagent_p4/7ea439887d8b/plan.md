Model each state as `(vertex, parity)`, where parity indicates whether the graph has been reversed an even or odd number of times. From `(v, 0)`, traverse original outgoing edges; from `(v, 1)`, traverse reversed edges, equivalently original incoming edges. Add reversal transitions between `(v, 0)` and `(v, 1)` with cost `X`, then run Dijkstra from `(1, 0)` and take the minimum distance to vertex `N` in either parity. Use 64-bit-sized integers for distances because the answer can exceed 32-bit range.
