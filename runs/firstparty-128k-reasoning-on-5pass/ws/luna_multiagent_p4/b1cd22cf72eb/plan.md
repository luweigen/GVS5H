For a fixed target total length \(H\), each upper tooth must lie in the interval \([\,\max(0,H-D_i),\ \min(U_i,H)\,]\), while the lower tooth is \(H-U_i'\). The total grinding cost for this \(H\) is \(\sum_i(U_i+D_i)-NH\), so it suffices to find the maximum feasible \(H\). Check feasibility in \(O(N)\) by propagating the possible interval of each upper tooth while enforcing adjacent differences at most \(X\). Feasibility is monotone in \(H\), allowing binary search over \(0\) through \(\min_i(U_i+D_i)\), and use 64-bit integers for the answer.
