- **Target representation:** For a fixed positive frequency `k`, every letter's final count is either `0` or `k`. The selected/absent choices form a binary sequence over the 26 letters.
- **Why only adjacent changes matter:** Moving a character forward by distance `d` costs `d` operations. If `d >= 2`, deleting the source character and inserting the destination costs only 2, so an optimal solution never needs such a move. Same-letter matching is free, and an adjacent change costs 1 instead of the baseline delete-plus-insert cost 2, saving exactly 1.
- **Fixed target cost:** Start with `sum(abs(count[i] - target[i]))`, corresponding to deletions and insertions independently. After same-letter matching, letter `i` has `max(count[i] - target[i], 0)` surplus and letter `i+1` has `max(target[i+1] - count[i+1], 0)` deficit. Up to the minimum of these can be changed from `i` to `i+1`, reducing the cost by one each.
- **Dynamic programming:** Process letters left to right. The state records whether the current letter is absent or present in the target. The transition adds its mismatch cost and subtracts the adjacent surplus/deficit matching reward determined by the previous and current states.
- **Frequency range:** Frequencies greater than `n` cannot improve on deleting all characters, so testing `k = 1..n` is sufficient. Deleting the whole string gives the initial answer `n`; this also covers an empty target if it is considered good.
- **Complexity:** There are `n` candidate frequencies, 26 letters, and two states, giving `O(26n)` time and `O(1)` extra space.
