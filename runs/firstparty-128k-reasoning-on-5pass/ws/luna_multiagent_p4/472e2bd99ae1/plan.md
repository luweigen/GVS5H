Sort each sequence in descending order; since all values are positive, the expression is non-increasing when any index moves forward. Treat the values as a monotone 3D grid and use a max-heap to enumerate grid states in descending order, starting from \((0,0,0)\). After popping a state, insert its three forward neighbors while preventing duplicate states; the K-th popped value is the answer. Encode states compactly and use 64-bit arithmetic, with \(O(K\log K)\) time and \(O(K)\) memory.
