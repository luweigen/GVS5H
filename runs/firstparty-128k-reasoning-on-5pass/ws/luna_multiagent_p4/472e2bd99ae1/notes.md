- **Sorting and monotonicity:** Sort all three arrays in descending order. Since every element is positive, decreasing any one selected value cannot increase \(ab+bc+ca\). Thus the expression is non-increasing along every grid axis.
- **Best-first search:** Each state \((i,j,l)\) represents one index triple and is stored in a max-heap via its negated value. Starting from \((0,0,0)\), repeatedly pop the currently largest unprocessed state.
- **Neighbors:** From each popped state, generate all valid states obtained by incrementing exactly one coordinate: \((i+1,j,l)\), \((i,j+1,l)\), and \((i,j,l+1)\).
- **Duplicate handling:** A state can be reached through multiple paths, so a visited set of index triples is used. Each state is inserted into the heap at most once, while equal values from different index triples are still counted separately.
- **Correctness:** Every state’s generated parent has a value at least as large as the state because of coordinate-wise monotonicity. Therefore, when a state becomes the largest heap element, no ungenerated state can have a larger value than it. The popped sequence is consequently the complete collection of \(N^3\) values in non-increasing order, including multiplicity.
- **Complexity:** Only the first \(K\) states and their neighbors are needed. The time complexity is \(O(N\log N + K\log K)\), and the heap plus visited set use \(O(K)\) memory.
