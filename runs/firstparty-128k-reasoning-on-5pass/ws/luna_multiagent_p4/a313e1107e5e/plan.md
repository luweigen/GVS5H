Process the sequence from left to right while maintaining the standard patience-sorting `tails` array, where `tails[k]` is the minimum possible ending value of a strictly increasing subsequence of length `k+1`. Each new element replaces the first `tails` value that is at least it, so every prefix produces a new version differing at only one position. Build persistent segment-tree versions of these arrays, allowing each query `(R, X)` to inspect the version after the first `R` elements and find the largest index whose tail value is at most `X`. Since `tails` is sorted, this search takes `O(log N)`, giving total complexity `O((N+Q)\log N)`.
