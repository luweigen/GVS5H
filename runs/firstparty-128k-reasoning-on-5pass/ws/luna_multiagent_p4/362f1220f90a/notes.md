- **Forced placements:** Every `T` window directly assigns all characters of `str2` into the output. Any conflicting assignment immediately makes the instance impossible.
- **Forbidden windows:** An `F` window is already safe if a forced character differs from `str2`. Otherwise it remains an active clause requiring at least one mismatch. Its `remaining` count tracks unassigned positions in that window.
- **Greedy construction:** Unassigned output positions are processed left to right. For an active `F` window with exactly one unassigned position left, that position cannot receive its corresponding character from `str2`; those characters are collected in a forbidden set.
- **Clause updates:** If the chosen character differs from the required pattern character, the corresponding `F` window is permanently satisfied. If it matches, its number of remaining unassigned positions decreases. Choosing a character that would reduce this count to zero is prevented.
- **Correctness:** Each greedy choice is the smallest character that preserves every currently unsatisfied constraint. Constraints only become easier after a mismatch is introduced, so local feasibility preservation yields the lexicographically smallest valid string.
- **Complexity:** Forced placement, initial window analysis, and greedy updates each take `O(nm)` time. The output uses `O(n + m)` storage apart from the `O(n)` auxiliary arrays.
- **Edge cases:** Handles `m = 1`, overlapping `T` occurrences, conflicting forced overlaps, all-forced `F` windows that equal `str2`, and cases where every lowercase character is forbidden at a position.
