The graph has an edge exactly when two intervals are disjoint, and all vertex weights are positive. For any path between two overlapping intervals, the first and last intermediate vertices can shortcut the entire path to at most three edges without increasing the total weight. Hence a query only needs the direct edge, a minimum-weight vertex disjoint from both endpoints, and, when the endpoints cross, a minimum-weight pair from the two opposite pockets. Precompute prefix minima over right endpoints and suffix minima over left endpoints to answer all such minimums in O(1). Process each query in O(1) using strict endpoint inequalities and 64-bit integers.
