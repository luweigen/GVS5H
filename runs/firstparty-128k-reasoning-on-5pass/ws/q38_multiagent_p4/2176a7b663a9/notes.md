- **Graph structure:** Edge exists exactly when intervals are disjoint; all weights are positive, so a direct edge is always optimal when the query intervals are disjoint.
- **Shortcut lemma:** If query intervals s and t overlap, take any path and let a be the first vertex after s and b the last before t. Then a is disjoint from s and b is disjoint from t. If a and b are disjoint, s-a-b-t is a valid path no heavier than the original. If a and b overlap, case analysis on the relative order of s and t shows one of a,b is disjoint from both s and t, giving a two-edge path no heavier. Thus only direct, two-edge, and three-edge paths matter.
- **Two-edge candidate:** For overlapping s,t, a vertex disjoint from both must lie completely left of both (R < min(Ls,Lt)) or completely right of both (L > max(Rs,Rt)). These are the only possibilities because the two intervals have a nonempty intersection.
- **Three-edge candidate:** It is only needed when the intervals cross. If Ls < Lt and Rs < Rt (and they overlap), the non-redundant middle pair is x with Lx > Rs and y with Ry < Lt. Every such x is to the right of every such y, so x-y is an edge; the minimum sum is the sum of the two independent minima. The symmetric case is Lt < Ls and Rt < Rs, using R < Ls and L > Rt. In containment or equal intervals, any three-edge pair contains a middle vertex disjoint from both endpoints, so the two-edge candidate dominates.
- **Precomputation:** Coordinates are in [1, 2N]. Build pref[c] = min W_i with R_i <= c by placing weights at R_i and prefix-minimizing. Build suff[c] = min W_i with L_i >= c by placing weights at L_i and suffix-minimizing. Strict conditions use pref[x-1] for R < x and suff[x+1] for L > x. Allocate 2N+5 to safely access 2N+1.
- **Query formula:** If Rs < Lt or Rt < Ls, answer Ws+Wt. Otherwise base=Ws+Wt. A=min(pref[min(Ls,Lt)-1], suff[max(Rs,Rt)+1]). B is the crossing pair sum above, else INF. Answer base+min(A,B) if finite, else -1.
- **Pitfalls:** Intervals are inclusive, so disjointness and all pocket conditions are strict. Crossing requires strict inequalities in both L and R; equal L or equal R is containment, not crossing. Query endpoints are automatically excluded from all strict minima. Use a large INF (10**30) and Python integers; maximum real answer is at most 4e9.
- **Verification:** A brute-force Dijkstra tester on small random N (explicit graph, vertex-weighted Dijkstra) matches the formula; checked touching endpoints, containment, equal intervals, reversed query order, and isolated vertices.
