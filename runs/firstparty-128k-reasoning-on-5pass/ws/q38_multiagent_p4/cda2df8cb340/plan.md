Use the 2-adic valuation of each pair sum: if S=A_i+A_j and v=v_2(S), then f(S)=S/2^v. Define V_t as the sum of S/2^t over all i<=j with 2^t dividing S; the desired answer is V_0 - V_1 - V_2 - ... because the coefficients telescope to 2^{-v}. For a fixed t, group numbers by residue modulo 2^t and keep only the count and total sum in each residue class. A residue r can only pair with s=(-r) mod 2^t, so cross-residue contributions are obtained from the stored counts and sums, while self-pairing residues (r=0 and, for t>=1, r=2^{t-1}) use the unordered-with-repetition formula. Iterate t while 2^t <= 2*max(A), since larger moduli cannot divide any positive pair sum. This gives O(N log maxA) time and O(N) memory.
