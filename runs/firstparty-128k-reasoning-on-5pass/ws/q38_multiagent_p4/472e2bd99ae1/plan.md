Sort A, B, and C in non-increasing order, which makes f(i,j,k)=A_iB_j+B_jC_k+C_kA_i monotone non-increasing in each index because all elements are positive. Define a spanning tree of the N^3 grid by making the parent of (i,j,k) be (i-1,j,k) if i>0, else (i,j-1,k) if j>0, else (i,j,k-1); every parent has a value at least as large as its child. Run a max-heap best-first search from (0,0,0), pushing only the canonical children of a popped node, so the popped nodes appear in non-increasing value order over the whole grid. Pop exactly K nodes and return the value of the K-th popped node. The total complexity is O(N log N + K log K) with O(K) heap memory, and all arithmetic fits in 64-bit integers.
