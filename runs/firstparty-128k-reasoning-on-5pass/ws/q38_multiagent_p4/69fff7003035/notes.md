- **Core reduction:** By linearity, each value x contributes x times the sum over subsets S of the other N-1 values of |S|!(N-1-|S|)! 10^{digits(S)}. This depends only on the digit length l of x. With n=N-1, c_d counts and S_d sums of d-digit values, answer = n! * sum_d S_d F_d, where F_d = sum_k h_{d,k}/C(n,k) and h_{d,k} is [x^k] Q_d, Q_d = P/(1+10^d x), P = prod_d (1+10^d x)^{c_d}.
- **Coefficient recurrence:** Let D be the number of active digit lengths (<=6), a_d=10^d mod M. R=prod(1+a_d x)=sum r_j x^j, T=sum c_d a_d prod_{e!=d}(1+a_e x)=sum s_j x^j (degree D-1). From R P' = P T, (k+1)E_{k+1} = s_0 E_k + sum_{j=1}^{min(D,k)} s_j E_{k-j} - sum_{j=1}^{min(D,k)} r_j (k-j+1) E_{k-j+1}, with s_D=0. Compute E_0=1 up to E_n using modular inverses of 1..n.
- **Computing r and s:** Build r by multiplying at most six linear factors. For each d, get q=R/(1+a_d x) via q_0=1, q_j=r_j-a_d q_{j-1} for j=1..D-1, then add c_d a_d q_j to s.
- **Division and accumulation:** For each active d, h_k = E_k - a_d h_{k-1}, h_{-1}=0. Accumulate F_d = sum_{k=0}^n h_k invC(n,k). invC is precomputed by invC_0=1, invC_{k+1}=invC_k*(k+1)/(n-k). Multiply final sum by n! = (N-1)!.
- **Implementation choice:** The code stores E[0..n] and invC[0..n], then for each active length sweeps k=0..n updating h and F. This is simpler than a circular-buffer one-pass and still O(DN) with D<=6.
- **Implementation edge cases:** N=1 gives n=0, E=[1], h_0=1, answer 1. Digit ranges are start=10^{d-1}, end=min(N,10^d-1), count=end-start+1, sum=(start+end)*count//2 mod M. All N<MOD, so factorials and binomial inverses are nonzero.
- **Complexity and pitfalls:** O(DN) time and O(N) memory. Do not index s[D] as a real coefficient (set it to 0), compute E only to N-1, use n=N-1 in binomial weights, and remember h_n is generally nonzero because Q_d has degree n.
