Model the minimum operations for a subarray as the sum of its running maxima minus the sum of its original values. For a fixed left endpoint, this cost is nondecreasing as the right endpoint grows, and for a fixed right endpoint it is nonincreasing as the left endpoint moves right, so a two-pointer sweep over right endpoints can count valid subarrays. To evaluate a cost query quickly, preprocess the next strictly greater element for each index; the running-maximum records for `[l, r]` are exactly the chain `l, ng[l], ng[ng[l]], ...`. Use binary lifting on this chain to compute the sum of running maxima in `O(log n)`, then subtract the range sum of `nums`. This yields an `O(n log n)` time algorithm with `O(n log n)` memory.
