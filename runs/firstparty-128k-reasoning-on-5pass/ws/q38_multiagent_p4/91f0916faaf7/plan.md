For each prime p, the condition f(S_i/S_{i+1})=A_i is equivalent to |v_p(S_i)-v_p(S_{i+1})|=v_p(A_i). Thus the exponent sequences for different primes are independent, and gcd(S_1,...,S_N)=1 means each prime's exponent sequence has minimum 0, so the desired sum factorizes over primes. For a fixed prime p, let a_i=v_p(A_i) and S=sum a_i; any valid exponent sequence stays in [0,S]. Run a DP over current height h and a flag whether height 0 has been seen, initializing all h in [0,S] with weight p^h and processing transitions h -> h±a_i (or h if a_i=0), multiplying by p^{new h}. Finally multiply the per-prime DP sums modulo 998244353.
