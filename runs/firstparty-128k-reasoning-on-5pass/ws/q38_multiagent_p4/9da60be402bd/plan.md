Represent a palindromic walk by simultaneously consuming matching labeled edges from its start and end, using product states (left endpoint, right endpoint). One product step moves the left endpoint forward and the right endpoint backward along edges with the same label; even-length palindromes finish on a diagonal state (v,v), while odd-length palindromes finish on a state (u,v) with an existing edge u->v. Thus the desired answer for (i,j) is min(2*d_diag[i][j], 2*d_edge[i][j]+1), with 0 for i=j and -1 if both distances are undefined. Compute d_diag and d_edge by two multi-source BFS runs on the reversed product graph, starting from all diagonal states and from all edge states respectively. Use per-vertex, per-label bitsets of incoming and outgoing neighbors to generate predecessor states efficiently, giving an O(N^3)-ish solution for N<=100.
