Define prefix sums `S` for `nums` and `C` for `cost`. Let `dp[j][i]` be the minimum cost for the first `i` elements split into exactly `j` subarrays, with transition from a previous cut `p`: `dp[j][i] = min(dp[j-1][p] + (S[i] + k*j) * (C[i] - C[p]))`. Rewrite the transition as `C[i]*(S[i] + k*j) + min_p(dp[j-1][p] - (S[i] + k*j)*C[p])`, which is a minimum line query with line slope `-C[p]` and intercept `dp[j-1][p]` at `x = S[i] + k*j`. For each fixed `j`, the slopes are monotone and the query `x` values are monotone, so a convex hull trick can compute all transitions in linear time per `j`. Iterate `j` from `1` to `n`, maintain the hull incrementally, and return the minimum `dp[j][n]` over all valid numbers of subarrays.
