- **Status:** Corrected even-N rule implemented. Optional `--validate` brute-forces all bipartite graphs for N<=6 and should print no mismatches. The old two-type cold/hot formula is insufficient.
- **Component types:** Use color-class parities. O = odd-size component (one part odd, one even); I = isolated vertex; E0 = even component with both parts even; E1 = even component with both parts odd. Let o = total O including I, i = I, b = E1 count, e = E0 count. P = internal-missing parity = (b&1) ^ (M&1).
- **Move parities:** Internal moves and all merges except O+O->E1 and O+E1->O flip P. O+O->E0 is an odd-flip move and is unavailable if both O components are isolated. Other orientation choices are legal.
- **Outcome types:** For fixed component counts, the outcome as a function of P is one of: C = win iff P=1, H = always win, N = win iff P=0. Even missing count h=0 and h>0 have the same outcome, so only P matters.
- **Induction result:** e never affects the type. The type table is: H if i=o-2 or i=o-1; if i=o then N when o%4==2 else C; if i<o-2 then C when b even else N. o=0 is i=o C; o=2 gives i=0,1 H and i=2 N.
- **Even-N formula:** If i==o-2 or i==o-1, Aoki. Else if i==o, Aoki iff (P ^ ((o//2)&1)) == 1. Else (i<o-2), Aoki iff (P ^ (b&1)) == 1, equivalently M is odd.
- **Odd-N formula:** Every terminal complete bipartite graph has even edge count, so all plays have parity M; Aoki iff M is odd.
- **N=14 proof:** State o=4, i=0, b=1, P=0 falls in i<o-2 with b odd, type N, so P=0 is winning. Explicit winning move: merge one O with the E1 component (even P-preserving) to o=4, i=0, b=0, P=0, which is C and losing for the next player.
- **Brute force:** Edge-mask DP over all bipartite masks for N<=6; a mask is winning if some unset edge keeps the graph bipartite and leads to a losing mask. The new formula matches all masks. Spot checks: N=6 empty Aoki, N=4 empty Takahashi, edge+4 isolated Takahashi, P3+3 isolated Aoki, E00+2 isolated with P=1 Takahashi.
- **Pitfalls:** P=1 is not always winning; N states lose at P=1. Isolated count i matters only through i=o, i=o-1, i=o-2, or i<o-2. E0 count is irrelevant to the type, but its missing edges are included in P via M and b.
