Process candidate strings of length M character by character while maintaining the one-row LCS DP table against the fixed string S. Since N ≤ 10, this DP row is fully determined by an N-bit mask indicating where the row increases, giving at most 2^N states. Precompute the transition for every mask and every lowercase letter using the standard LCS row update. Run a length-M DP over this automaton, starting from the all-zero mask and accumulating counts modulo 998244353. Finally, bucket the ending states by their LCS length, which is the popcount of the mask, to obtain answers for k = 0..N.
