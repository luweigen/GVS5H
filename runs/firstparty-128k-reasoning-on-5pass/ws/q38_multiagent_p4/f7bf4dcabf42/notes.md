- **State:** For a processed prefix T of the candidate string, store f[i] = LCS(S[:i], T) for i = 0..N. Since f[0] = 0 and adding one character to S can increase LCS by at most 1, each difference f[i+1] - f[i] is 0 or 1. Thus the whole row is an N-bit mask, with bit i equal to that difference.
- **Final answer extraction:** The LCS length with all of S is f[N], which is exactly the popcount of the mask. Therefore final states are bucketed by popcount.
- **Correct transition:** Appending a character c to T gives a new row g. The standard LCS recurrence is g[0] = 0 and, for i = 0..N-1, g[i+1] = max(f[i+1], g[i], f[i] + (S[i] == c)). The initially planned formula max(f[i+1], g[i] + (S[i] == c)) is not correct because it can reuse the newly appended character twice; for example S = "cc", T empty, c = "c" would incorrectly give LCS 2.
- **Precomputation:** For every mask, build the old row f by prefix sums of its bits. For each of the 26 lowercase letters, run the N-step update, form the next mask from the increments g[i+1] - g[i], and aggregate letters that lead to the same next mask. This gives at most 26 transitions per state.
- **Counting DP:** dp[mask] is the number of length-t candidate prefixes ending in that state. Initialize dp[0] = 1. Repeat M times: ndp[next] += dp[mask] * ways, modulo 998244353.
- **Complexity:** There are at most 2^10 = 1024 states. Precomputation is about 1024 * 26 * 10 operations, and the DP is about 100 * 1024 * 26 operations, easily fast in Python.
- **Sample checks:** Sample 1 gives 576, 99, 1 by direct two-step counting. Sample 2 with S = "aaa" reduces to counting the number of 'a' characters capped at 3: 25^4, 4*25^3, 6*25^2, 4*25+1, matching the sample. Sample 3 is handled by the same automaton.
- **Pitfalls:** Use the old f[i] in the matching term, not g[i]; keep bit order aligned with S indices; aggregate duplicate next masks; unreachable masks are harmless because DP starts from mask 0; apply modulo during the DP.
