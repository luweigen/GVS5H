Use prefix sums S_i so each subarray sum is S_r - S_l with 0 <= l < r <= N. Since K <= 10, expand (S_r - S_l)^K by the binomial theorem and separate terms depending on l and r. While scanning r from 1 to N, maintain B_j = sum_{l<r} S_l^j for j=0..K, initialized with S_0=0. For each r, add sum_{j=0}^K binom(K,j)(-1)^j S_r^{K-j} B_j to the answer, then update B_j with S_r^j. All operations are modulo 998244353, giving O(NK) time and O(K) memory.
