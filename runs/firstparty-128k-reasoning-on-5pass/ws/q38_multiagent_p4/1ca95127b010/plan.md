Treat each operation as swapping adjacent blocks `0^X 1^Y` and `1^Y 0^X`. This preserves the number of 1s and 0s, and the relative order of all 1s and all 0s; a moved 1 shifts by `X` and a moved 0 shifts by `Y`, so the k-th 1 position modulo `X` and the l-th 0 position modulo `Y` are invariant. These invariants are also complete: the rewrite rule `0^X 1^Y -> 1^Y 0^X` is terminating and confluent, and its unique normal form is determined exactly by these ordered residue sequences. Therefore S can be transformed to T iff the two strings have the same number of 1s and the same ordered residue sequences for 1s (mod X) and 0s (mod Y). The solution is a linear scan comparing these sequences, with O(N) time and O(1) or O(N) memory.
