Use the identity x^3 - y^3 = (x-y)(3y^2 + 3(x-y)y + (x-y)^2). Let d = x-y; then d must divide N, and because y >= 1 we have N > d^3, so d is at most the cube root of N (about 10^6 for N <= 10^18). Iterate d from 1 to that bound and keep only values with N % d == 0. For each such d, solve 3y^2 + 3dy + d^2 = N/d by checking whether the discriminant 12(N/d) - 3d^2 is a nonnegative perfect square and gives a positive integer y. Return the first valid (y+d, y); if none exists, print -1.
