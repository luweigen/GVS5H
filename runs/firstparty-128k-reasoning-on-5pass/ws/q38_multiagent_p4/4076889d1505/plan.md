Use the identity that \((1+N)^N - 1\) is divisible by \(N^2\), while \((1+N)^d - 1\) is not divisible by \(N^2\) for any \(1 \le d < N\). Therefore choosing \(A = N+1\) and \(M = N^2\) gives the smallest valid exponent exactly \(N\). For \(N=1\), this naturally gives \(M=1\), where every exponent works and the smallest positive exponent is \(1\). All values fit the constraints because \(N \le 10^9\) implies \(N^2 \le 10^{18}\) and \(N+1 \le 10^{18}\). For each test case, just print these two integers. This yields \(O(T)\) time and \(O(1)\) extra memory.
