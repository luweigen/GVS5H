- **Problem model:** Only the 26 letter frequencies matter. For a fixed target vector d, the baseline cost of deleting surplus and inserting deficits is sum |cnt[i]-d[i]|. A one-step forward move replaces one deletion and one insertion, saving exactly 1; moves of distance 2 or more have no net saving. Thus exact cost is baseline minus sum_i min(surplus_i, deficit_{i+1}).
- **Fixed-k DP:** For a common frequency k, each letter is either absent (d=0) or present (d=k). Unary costs are cnt[i] if absent and |cnt[i]-k| if present. The only pairwise term is the adjacent saving, which depends only on the previous letter’s state. A two-state DP over the 26 letters is exact.
- **Bounds:** Deleting all but the most frequent letter gives a valid upper bound ans <= n-1. Any nonempty target with frequency k has length at least k, so if k-n >= ans it cannot improve. Enumerating k=1..2n is safe. k=0 would be the empty string, costing n, and is never better.
- **Brute force harness:** For small strings, brute_force enumerates all good targets. It restricts selected letters to positive-count letters and their immediate next letter. A zero-count letter whose previous letter also has zero count can be removed and strictly lowers cost, so this restriction is safe.
- **Brute force cost:** Each target is evaluated by a min-cost flow DP on the 26-letter line. With b=cnt-d and x_i flow across edge i->i+1, cost is sum x_i + |b[i] + x_{i-1} - x_i|, with x_{-1}=x_{25}=0. The DP over x_i is O(26*B), where B is bounded by total surplus and hence by n.
- **Validation:** The harness cross-checks the line-flow DP against the closed-form baseline-saving formula on 200 random b vectors to catch implementation errors.
- **Sample tests:** The program prints a verdict. Expected/observed verdict is pass: examples acab=1, wddw=0, aaabc=2; edge cases all same, all distinct, near z, gaps, and 160 random small strings of length 3-5 over mixed alphabets matched brute force. No failing cases found.
- **Complexity:** The submitted solution is O(26*2n) time and O(1) extra space. The test harness is only for small n and is not part of the submitted algorithm.
