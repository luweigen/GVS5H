Count the 26 letter frequencies. For a fixed common frequency k, a good target assigns each letter either 0 or k; for any such target d, the minimum operations equal sum |c_i-d_i| minus the total saving from one-step forward changes, where edge i->i+1 saves min(surplus_i, deficit_{i+1}). This makes the choice of which letters are selected a binary path DP over the 26 letters: state 0/1 for the current letter, node cost is c_i or |c_i-k|, and the transition subtracts the edge saving. Enumerate k over 1..2n (a deletion-only solution bounds the answer by n-1, so larger k cannot improve) and keep the minimum. The result is O(26n) time and O(1) extra space.
