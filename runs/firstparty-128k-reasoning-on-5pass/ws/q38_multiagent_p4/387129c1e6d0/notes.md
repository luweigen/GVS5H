- **Problem reduction:** Santa’s path is the union of axis-aligned closed line segments. A house can only be hit by horizontal segments with the same y-coordinate or vertical segments with the same x-coordinate, so the problem separates into one-dimensional interval coverage per fixed coordinate.
- **Simulation:** Track the current position. For each move, append an inclusive interval to a horizontal dictionary keyed by y for L/R moves, or a vertical dictionary keyed by x for U/D moves. Skip storing an interval if its fixed coordinate has no house, using house_ys and house_xs sets.
- **Merging:** For each group, sort intervals by start endpoint and merge overlapping or touching closed intervals in place. This produces disjoint interval lists representing the exact traversed coverage on each line.
- **Counting:** For each house, check whether its x-coordinate is covered by the merged horizontal intervals at its y, or its y-coordinate is covered by the merged vertical intervals at its x. Use bisect_right on a list of (start, end) tuples with (point, INF) to find the last interval starting at or before the point, then verify end >= point. Single-interval groups use direct comparison. Count a house if either orientation covers it, so repeated visits or both orientations count once.
- **Edge cases:** Endpoints are inclusive, so houses at move endpoints are counted. Python integers avoid overflow; final coordinates can reach about 2e14. The constraint says no house at the initial point, but inclusive intervals correctly handle later returns to any visited point.
- **Complexity:** Sorting all interval groups and checking all houses with binary search gives O((N + M) log M) time and O(N + M) memory.
- **Samples:** Sample 1 produces final position (2, 3) and count 2. Sample 2 produces final position (3000000000, 0) and count 0.
