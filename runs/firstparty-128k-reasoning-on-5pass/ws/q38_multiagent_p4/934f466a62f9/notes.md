- **Reduction:** A pair can be labeled by one coordinate attaining its maximum. Then the pair contributes the sum of that coordinate on its two cakes. The problem is equivalent to choosing M = 2K cakes and assigning each one of X/Y/Z so that each label count is even, maximizing the sum of assigned coordinates.
- **Aliens trick:** Let H(m) be the maximum doubled coordinate sum for exactly m chosen cakes, with m even. For penalty p per original pair, each chosen cake contributes 2*coord - p in doubled value. The penalized optimum G(p) and its maximum count c(p) are obtained by DP. The matching/labeled-selection value is concave in cardinality, so the largest p with c(p) >= M gives H(M) = G(p) + p*M.
- **DP states:** 8 parity masks, bits X=1, Y=2, Z=4. For new mask m, the previous mask when adding label bit b is m ^ b. Transition table for previous masks (X, Y, Z): 0:(1,2,4), 1:(0,3,5), 2:(3,0,6), 3:(2,1,7), 4:(5,6,0), 5:(4,7,1), 6:(7,4,2), 7:(6,5,3). Unused keeps the old state.
- **Encoding:** Encode (doubled adjusted value, count) as value << 17 + count. Count <= 1e5 < 2^17. Precompute (2*coord << 17) + 1 for each coordinate; for penalty p, delta = pre - (p << 17). This adds value 2*coord - p and count 1. Extract count with d0 & MASK and value with d0 >> SHIFT. Python arithmetic shift and bitwise and work correctly for negative encoded values too.
- **Binary search:** p is integer in [0, max_doubled]. p=0 has count at least M; p=max_doubled+1 has count 0. Search the largest p with count >= M. Keep the last true d0 to avoid one extra DP pass when possible.
- **Edge cases:** all zero answer 0; N odd max feasible count at p=0 is N-1, still >= M; final mask 0 guarantees even label counts and even total count; NEG is far below any valid encoded value.
- **Performance:** Total N is 1e5, about 31 DP passes, unrolled 8-state transitions, O(N log maxcoord). Use list of 3-tuples, local variables, manual max, and individual assignments instead of tuple assignment.
- **Validation:** Samples give 12, 209, 333. A brute force over all labeled selections/matchings for N <= 8 matches the WQS result on small random cases.
