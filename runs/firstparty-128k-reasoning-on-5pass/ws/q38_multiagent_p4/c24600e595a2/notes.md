- **Reduction:** Each index has a fixed final parity. If a coordinate has a 0->1 flip and later its next 1->0 flip, deleting that pair keeps the final state valid and lowers all intermediate totals, so it is never optimal. Thus A=1,B=0 gives one negative flip (-C), A=0,B=1 gives one positive flip (+C), A=1,B=1 may give one optional off-on pair (-C,+C), and A=0,B=0 is never used.
- **Ordering:** For a fixed optional set, adjacent exchange shows all negative deltas must precede all positive deltas; among negatives larger C comes first; among positives smaller C comes first. This respects each off-on pair because its off is in the negative block and its on is in the positive block.
- **Cost formula:** Let N be the negative magnitudes (size n), P the positive magnitudes (size p), m=n+p, S0 the initial weighted sum, and sumN=sum(N). Define Wneg=sum(N)+sum_{pairs in N} max = sum_i (n-i+1)N_i for N descending, and Wpos=sum(P)+sum_{pairs in P} min = sum_i (p-i+1)P_i for P ascending. Then total cost = m*S0 - p*sumN - Wneg + Wpos.
- **Prefix property:** If a chosen set contains x but omits y>=x, replacing x by y does not increase cost. In the negative block, sums of t largest magnitudes do not decrease. In the positive block, the starting total decreases by y-x, and sums of t smallest magnitudes can increase by at most y-x, so every positive-block total is also no larger. Hence an optimal optional set is a prefix of D sorted descending.
- **Sweep invariants:** Sort X descending, Y ascending, D descending. Maintain Wneg, Wpos, sumN, k, m, p. For a new c, N_old = X plus previous D. Use pointer nx/sumX_gt for X elements > c; previous D greater sum is sumD_gt, previous D equal count is group_count. Update Wneg += c + sumX_gt + sumD_gt + c*((lenX-nx)+group_count). For P_old, use pointer pos/sumY_lt for Y elements < c; all previous D are >= c, count k. Update Wpos += c + sumY_lt + c*((lenY-pos)+k). Then sumN+=c, k++, m+=2, p++, and evaluate the cost.
- **Ties and edges:** Strict > for X and >= for Y make equal weights fall into <= for Wneg and >= for Wpos. Equal D weights are handled by group_count and k. Empty X/Y/D work, and the initial k=0 case is evaluated. Python integers avoid overflow. Complexity is O(N log N) for sorting plus O(N) for the sweep.
