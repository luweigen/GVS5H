Model the average over all (N-1)! parent sequences as a random recursive tree, so the required sum is (N-1)! times the expected distance. An edge corresponding to vertex x is on the u-v path exactly when exactly one of u and v lies in the subtree of x. Using the Pólya-urn representation of recursive trees, for x>=2 the probability that x is an ancestor of any later vertex is 1/x, and the probability that x is an ancestor of two later vertices y<z is 2/(x(x+1)). Split the possible edge indices x into x=v, x=u, u<x<v, and x<u to obtain closed-form coefficients for each A_x. Precompute modular inverses and prefix sums of these coefficients, then answer every query in O(1) by multiplying the summed coefficient by (N-1)!.
