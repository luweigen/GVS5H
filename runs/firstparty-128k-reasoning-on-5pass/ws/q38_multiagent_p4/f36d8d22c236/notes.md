- **Reduction:** For each character c in S, all positions with c must have the same character in T; otherwise those positions can never be separated, so answer -1. This gives a function target[c] for present letters.
- **Mandatory operations:** Every present c with target[c] != c must at some point be the source x of an operation, because its tokens start at label c and cannot change unless label c is used as source. Let M be this count; if M=0 answer 0.
- **Graph model:** Build edges c -> target[c] only for present c, target[c] != c, and target[c] present. Self-loops and edges to absent letters are acyclic sinks and do not form cycles.
- **Bare cycles:** A directed cycle of length at least 2 is bare when every node v in it has indeg[v] == 1, where indeg counts all present sources mapping to v. Then no outside present letter has the same final letter as a cycle node, so the cycle cannot be broken by a safe merge; it needs one empty buffer and one extra operation. Count these cycles as B.
- **Impossibility:** Besides the mapping conflict, the only impossible case is all 26 letters present in S and indeg[i] == 1 for every i with M > 0. Then the mapping is a non-identity permutation: every label is occupied, every final letter is unique, so no operation can merge two labels with the same final letter and no empty buffer exists.
- **Why M+B is enough:** If not impossible, either some letter is absent from S (initial empty buffer) or some final letter has indeg > 1 / indeg 0, giving a safe mandatory merge that creates an empty buffer. Non-bare cycles can be resolved using their incoming same-final node with no extra. Each bare cycle then uses the reusable empty buffer with exactly one extra operation.
- **Cycle detection:** Use 26-node state 0/1/2 traversal on the out edges. When a state-1 node is hit, the cycle is path[pos[v]:]; count it if all its nodes have indeg 1. Self edges are excluded, so found cycles have length at least 2.
- **Samples:** Sample 1 has M=4 and no cycles. Sample 2 has M=0. Sample 3 has a mapping conflict for 'a'. Sample 4 is a bare 3-cycle, M=3, B=1, answer 4.
- **Implementation details:** target uses -1 sentinel; present tracks S letters; indeg includes self-loop contributions, which is correct for the permutation check; out excludes self and absent targets; the code is O(N + 26).
