Model each target as a bit in a mask of size `m <= 4`. A single `nums` element can satisfy any subset `S` of targets if we raise it to a multiple of `lcm(target[S])`; the cheapest such value is the smallest multiple `>= nums[i]`, giving cost `ceil(nums[i]/L)*L - nums[i]`. The problem becomes assigning subsets of target bits to `nums` elements so that the union of chosen subsets is the full mask with minimum total cost. Use dynamic programming over `nums` elements where `dp[mask]` is the minimum cost to have covered `mask` so far, and for each `nums` element try all submasks to update `dp`. Since `m <= 4`, there are at most 16 masks, so the DP is easily fast enough for `n <= 5 * 10^4`. Return `dp[full_mask]`.
