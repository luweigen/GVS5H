- **Target reduction:** Remove duplicate targets and any target that divides another target. If t divides u, a multiple of u is also a multiple of t, so t is redundant. Keep only maximal values under divisibility; the mask size stays at most 4.
- **State:** dp[mask] is the minimum cost after processing a prefix of nums to have credited coverage of mask. Start with dp[0] = 0.
- **Element options:** For a value x and a non-empty target subset S, the cheapest final value making x a multiple of every target in S is the smallest multiple of lcm(S) not less than x. The cost is (-x) % lcm[S].
- **Subset lcms:** Precompute exact lcms for all non-empty masks using gcd. Python integers handle large lcms easily, and costs are capped separately.
- **Safe cap:** Since reduced target count m <= nums.length, assigning distinct nums elements to each reduced target gives a feasible total strictly less than sum(reduced). Set INF = sum(reduced) + 1 and cap any single-element subset cost above sum(reduced); such a cost cannot be part of an optimal solution.
- **Transition:** For each x, take a snapshot new_dp = dp[:]. For every old mask, try every non-empty submask of rem = full ^ mask and update new_dp[mask | sub] with dp[mask] + cost[sub]. Using only uncovered submasks is safe because already covered targets need not be re-covered, and adding already covered targets to the subset cannot lower the cost. The snapshot prevents using the same nums element more than once.
- **Accidental coverage:** If the cheapest multiple for subset S also satisfies extra targets, the superset containing those extra targets has the same or lower cheapest cost, so the superset transition captures the benefit.
- **Complexity:** With m <= 4, there are at most 16 masks and 65 non-empty uncovered-submask transitions per nums element. Costs are cached per distinct nums value, which is at most 10000 under the constraints. This easily handles nums.length <= 5 * 10^4.
- **Pitfalls:** In-place DP without a snapshot can reuse one nums element multiple times. Greedy per-target costs are unsafe because lcm synergy can make one element cover several targets. Duplicate or divisibility-redundant targets should be removed to avoid unnecessary mask bits.
