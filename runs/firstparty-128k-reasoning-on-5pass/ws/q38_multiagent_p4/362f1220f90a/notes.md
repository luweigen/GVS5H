- **Model:** The final word has length L = n + m - 1. A constraint from str1[i] applies to the window ending at position p = i + m - 1. Store this as types[p] = 0 for p < m - 1, 1 for T, and 2 for F.
- **KMP state:** State s in 0..m-1 is the length of the longest prefix of str2 that is a suffix of the processed prefix, with full matches immediately falling back to pi[m-1]. A length-m window ending at p equals str2 exactly when the state before p is m-1 and the chosen char is str2[-1].
- **Transition table:** Build pi, then trans[s][c] for all s,c. If c matches str2[s], go to s+1, or pi[m-1] when s+1 == m; otherwise fall back to trans[pi[s-1]][c], or 0 for s=0. This is O(m*26).
- **Feasibility DP:** dp[p] is a bitset of states before position p from which a valid suffix exists. Base dp[L] = all_mask. For T, only state m-1 is feasible and only if the fallback bit is in dp[p+1]. For None/F, state s is feasible if its reach mask intersects dp[p+1]. reach_F is built by iterating all 26 chars and excluding only the full-match transition, not merely removing the fallback bit.
- **Bitset optimizations:** Precompute reach_all, reach_F, and preimage masks pre_all/pre_F. In the backward DP, if B=0 then dp[p]=0; if B=all_mask and type is None/F then dp[p]=all_mask because every state has at least one allowed char; if B is a single bit, use the corresponding preimage mask directly; otherwise loop over the m states.
- **Reconstruction:** Starting from state 0, scan left to right. For T, force the last char from state m-1. For F/None, try 'a'..'z' in order, skip the full-match char for F, and take the first char whose next state is in dp[p+1]. This greedy choice is safe because future feasibility depends only on position and KMP state.
- **Edge cases:** m=1 works with state 0 and F having 25 allowed letters; all-T cases are caught by the automaton when overlapping T windows are incompatible; n=1 F returns the smallest string not equal to str2; first m-1 positions are unconstrained.
- **Self-test:** The included __main__ asserts the three examples plus edge cases: T/a, F/a, TT/aa, TT/ab, F/aaa, T/abc, FFF/b, TTT/ab, TTT/aa, F/bc, F/aa, FTF/aa, TFT/aba, TFT/abc.
- **Complexity:** Worst-case O(L*m) bitset checks with L <= 10499 and m <= 500, plus O(m*26) setup; memory O(L + m*26) Python ints, well within limits.
