Collect the 1-indexed positions of all '1's in the string; let their count be K. If the final contiguous block of K ones starts at position l, then the j-th original '1' must move to position l + j - 1. The minimum number of adjacent swaps equals the sum of absolute distances from the original positions to these target positions. This cost can be rewritten as the sum of absolute deviations from values q_j = p_j - (j - 1), so the optimal l is a median of the q_j values. Compute the sum of absolute differences to the median using 64-bit arithmetic and output it.
