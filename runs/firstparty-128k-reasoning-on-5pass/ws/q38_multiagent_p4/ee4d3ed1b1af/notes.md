- **Problem reduction:** Split p at the two stars into A, B, C. A matching substring is exactly a non-overlapping ordered placement of the nonempty literals; it starts at the first nonempty literal and ends at the last nonempty literal. If A, B, C are all empty, the empty substring matches, so return 0.
- **Occurrence finding:** For each nonempty literal, run KMP prefix-function search over s to collect all start positions, including overlapping matches. If a literal is longer than s, its list is empty.
- **Pairing strategy:** Occurrence lists are sorted. For a fixed anchor, the best left literal is the latest start whose end is at most the anchor start; the best right literal is the earliest start whose start is at least the anchor end. Two pointers maintain these choices while anchors increase.
- **Case handling:** All three nonempty: iterate B, pair latest valid A before B and earliest valid C after B. A and B only: iterate B, pair latest valid A before B. A and C only: iterate C, pair latest valid A before C. B and C only: iterate B, pair earliest valid C after B. Single nonempty literal: return its length if it occurs.
- **Boundary rule:** Use end-exclusive positions. Compatibility between consecutive literals is prev_start + prev_len <= next_start. Candidate length is end_exclusive - start. Equality is allowed because stars may match zero characters.
- **Edge cases:** Empty literal blocks are handled by the case selection. Missing required literal returns -1. Overlapping literal occurrences are rejected. Adjacent stars and leading/trailing stars are covered by the same boundary rule.
- **Complexity:** At most three KMP searches over s and total literal length, plus linear sweeps over occurrence lists. Time O(|s| + |p|), memory O(|s| + |p|) for occurrence lists and prefix arrays.
- **Verification:** The four examples give 8, -1, 0, and 6. Edge cases such as a*a on "a" -> -1, a**a on "aa" -> 2, *b*a on "ba" -> 2, a*b on "ab" -> 2, and *a* on "a" -> 1 were checked.
