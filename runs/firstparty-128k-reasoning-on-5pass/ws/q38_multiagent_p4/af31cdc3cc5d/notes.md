- **Matching model:** A valid deletion sequence is equivalent to a noncrossing matching of original positions. If N is odd, one position remains unmatched, and no pair can have endpoints on both sides of it.
- **Survivor parity:** The unmatched position must have even 0-based index, because the number of elements to its left must be removed in pairs.
- **Even block value:** For 2m elements, the maximum score is the sum of the largest m values minus the sum of the smallest m values. The upper bound follows by orienting each pair from smaller to larger. It is attainable by coloring the m smallest values as lower and the m largest as upper; a balanced binary sequence always has an adjacent opposite-colored pair, and repeatedly deleting such pairs preserves balance.
- **Odd N formula:** For N = 2M + 1, the answer is max over k = 0..M of value(prefix length 2k) + value(suffix length 2(M-k)). Reversing the array converts suffixes into prefixes.
- **Two-heap maintenance:** For each prefix length t, keep a max-heap of the smallest floor(t/2) values and a min-heap of the largest ceil(t/2) values, with their sums. Insert x into lower if lower is nonempty and x <= max(lower), otherwise into upper. Then move one top element if a heap exceeds its target size. Record sum_upper - sum_lower after even t.
- **Indexing:** scores[k] corresponds to prefix length 2k. For even N = 2M, print scores[M]. For odd N = 2M + 1, compute pa for A and pb for reversed A, then answer max(pa[k] + pb[M-k]).
- **Complexity and safety:** O(N log N) time and O(N) memory. Python integers safely handle sums up to about 1.5e14. Empty prefix/suffix score is 0. Ties at the median can be split arbitrarily.
