We precompute the final rating for every possible initial rating X from 1 to 500000, since all queries are point lookups. Maintain an array A where A[x] is the current rating after the processed contests for initial rating x; initially A[x]=x and A is nondecreasing. For each contest [L,R], the indices x satisfying L <= A[x] <= R form a contiguous block, so the contest corresponds to adding 1 to that block. Use a lazy segment tree over A that stores segment maximums and supports range add plus lower_bound, i.e. finding the first index with value at least v, to locate the block in O(log M). After all N contests, answer each query in O(1) by outputting A[X]. This yields O((N+Q) log M) time and O(M) memory.
