- **Cut reduction:** Original edges 1->2->...->2N give forward reachability. Strong connectivity fails iff some proper prefix has no added edge from a suffix white to a prefix black. For each c=1..N-1, the hardest prefix with c blacks is just before the (c+1)-th black. Let T[c] be the number of whites before that black. A pairing is valid iff for every c, max(p[0..c-1]) >= T[c], where p is the permutation assigning white indices to black order.
- **Immediate zeros:** If S[0]=='W', the first prefix has no black. If S[-1]=='B', the last proper prefix has no suffix white. Both force answer 0.
- **Permutation encoding:** Order black vertices B_1..B_N and white vertices W_1..W_N. A pairing is a permutation p of 0..N-1, where p[i] is the white index matched to black i. A prefix with c blacks and t whites is bad iff max(p[0..c-1]) < t.
- **T array:** T[c] for c=1..N-1 is #W before the (c+1)-th B. It is nondecreasing. If T[c] < c, the bad event is impossible because c distinct whites cannot all lie in fewer than c indices.
- **Inclusion-exclusion recurrence:** Let B[c] be the signed inclusion-exclusion weight for the event that the first c blacks are matched inside the first T[c] whites. For active c (T[c] >= c):
  B[c] = -invfact[T[c]-c] * (fact[T[c]] + sum_{d<c, active} B[d] * fact[T[c]-d]).
  Answer = fact[N] + sum_{c active} B[c] * fact[N-c].
- **CDQ structure:** Maintain add[i] = sum of contributions from already processed d < i. In solve(l,r), solve left half, then add contributions from left half to right half, then solve right half. For a base block of size <=32, compute sequentially and sum previous B directly.
- **Convolution formula for CDQ apply:** For left indices l..mid-1 and right indices mid..r-1, let m=mid-l, t0=T[mid], t1=T[r-1], R=t1-t0. For right t=t0+j, contribution is sum_{p=0}^{m-1} B[l+p] * fact[t0+j-(l+p+1)]. Build A[p]=B[l+p] and F[k]=fact[t0-mid+k] for k=0..R+m-1, with negative factorial indices as 0. Then the needed values are (A*F)[j+m-1] for j=0..R.
- **NTT implementation:** Use mod 998244353 and primitive root 3. Forward transform is decimation-in-frequency, inverse is decimation-in-time, so no explicit bit-reversal is needed. Precompute twiddle powers for each power-of-two stage and inverse length factors. This avoids repeated pow calls and bit-reversal swaps.
- **Thresholds:** Use direct computation when m <= 32, R <= 32, or m*(R+1) <= 16384. Otherwise use NTT. Base block size is 32. This keeps small intervals cheap and limits NTT overhead.
- **Complexity:** T is nondecreasing, so the sum of R over nodes at one CDQ level is O(N), and the sum of left lengths is O(N). With NTT, total work is O(N log^2 N) in the worst case, with small constants in practice. Memory is O(N) plus NTT arrays and precomputed roots.
- **Validation:** Self-tests check NTT convolution against naive convolution, brute force for all balanced strings N<=5, O(N^2) recurrence for random N=6..10, larger random N=1000 to exercise NTT, and all provided samples.
- **Edge cases:** N=1 returns 1 for "BW" and 0 for "WB". Inactive cuts have B=0. Factorial indices are kept nonnegative; negative factorial terms are treated as zero. All modular additions use one subtraction when possible because operands are reduced modulo MOD.
