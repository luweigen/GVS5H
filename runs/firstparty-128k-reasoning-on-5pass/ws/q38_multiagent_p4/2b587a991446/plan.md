Treat the swap as a shortest path in the two-token configuration graph, but compress the problem using the block-cut tree of the original graph. Run BFS from S and T to get distances, and if the graph is only a path (no cyclic biconnected component and no vertex of degree at least 3), output -1. A valid swap can be realized either by using a degree-3 vertex as a hub or by using a cyclic biconnected component as a loop. For a hub v, the cost is 2*(dist(S,v)+dist(T,v)) plus 2 if v separates S and T on the block-cut path, otherwise 4. For a cyclic block, take the two vertices where the S-T block-cut path enters/exits it (or the single closest articulation if the block is off the path), add 2*(dist(S,p)+dist(T,q)) to the length of the shortest cycle in that block containing p and q, and take the minimum over all candidates.
