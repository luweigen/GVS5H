Compute the inversion count for k=0 directly with a Fenwick tree over values 0..M-1. Observe that moving from k to k+1 only changes inversions for pairs where exactly one element has current value M-1 and wraps to 0; all other pairs keep their relative order. For a fixed original value v, the set of indices that wrap at transition k=(M-1-v) mod M is fixed, and the total change is the sum over those indices of (2i-1-N), because internal pairs among the wrapping set cancel. Precompute this sum for every value v, then start from the k=0 answer and add the appropriate delta for each successive k, printing M answers. This yields O(N log M + M) time and O(M) memory, with 64-bit integers.
