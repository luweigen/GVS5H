Binary search the answer T, the minimum vitamin intake we want to guarantee. For a fixed T, the three vitamin types are independent: for each type we only need the minimum calories required to obtain at least T units from foods of that type. Precompute for each type a knapsack DP over calories up to X that stores the maximum vitamin amount achievable with that calorie budget. Then min calories for T is the first budget where the DP reaches T, and T is feasible iff the sum of these three minima is at most X. This gives O(NX + log(maxA) log X) time and O(X) memory per type.
