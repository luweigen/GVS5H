Sort intervals by right endpoint while keeping original indices, and precompute for each interval the count of intervals ending strictly before its left endpoint. Use a weighted interval scheduling DP for exactly c=0..4 intervals, where state (c,i) stores the maximum score and the lexicographically smallest sorted tuple of original indices achievable with c intervals among the first i end-sorted intervals. When taking interval i, combine its weight with state (c-1,p_i) and insert its original index into the previous tuple in sorted order. Break score ties by comparing these tuples lexicographically; this is safe because inserting a fixed index preserves lexicographic order of sorted index tuples. Finally, select the best tuple among c=0..4 by maximum score and lexicographic tie-break, giving O(4 n log n) time and O(4 n) memory.
