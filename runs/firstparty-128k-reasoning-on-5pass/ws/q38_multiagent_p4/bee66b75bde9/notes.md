- **Model:** A valid coloring is a Ferrers diagram: if R_x is the number of black cells in row x, the column-prefix condition is equivalent to R_1 >= R_2 >= ... >= R_N. Conversely any such nonincreasing sequence gives valid row and column prefixes.
- **Row intervals:** For each fixed cell in row x, black at column y forces R_x >= y, white at column y forces R_x <= y-1. Aggregate per row into L_x = max black y (default 0) and U_x = min white y-1 (default N).
- **Feasibility condition:** A nonincreasing sequence inside intervals [L_x, U_x] exists iff for every row x, max_{z >= x} L_z <= U_x. Necessity: R_x must dominate all lower rows' lower bounds. Sufficiency: choose R_x = max_{z >= x} L_z; it is nonincreasing and satisfies all bounds when the condition holds.
- **Sparse check:** Unconstrained rows have L=0 and U=N, so their condition is automatic because all L_z <= N. Therefore only rows appearing in the input need to be checked. Sort those row indices in descending order (bottom to top), maintain the running maximum of L, and fail if it exceeds the current row's U.
- **Off-by-one:** White at column y means the row length is at most y-1, not y; black at column y means at least y. Lengths 0 and N are allowed.
- **Edge cases:** A row with both a black and a white constraint can have L_x > U_x; the suffix check catches this because the running maximum includes L_x. If no constrained rows exist, answer is Yes. Multiple cells in the same row are combined before checking.
- **Complexity:** O(M log M) time due to sorting distinct constrained rows, O(M) memory. N up to 1e9 is handled without iterating over rows or columns.
- **Samples:** Sample 1 passes with row bounds (1: L=3), (3: U=1), (4: L=1). Sample 2 fails because row 1 has U=1 but row 2 below has L=2. Sample 3 is Yes with U=0 and L=0.
