Model a valid coloring by the number of black cells in each row, \(R_1,\dots,R_N\). The column condition is equivalent to requiring \(R_1 \ge R_2 \ge \dots \ge R_N\). Each fixed black cell \((x,y)\) imposes \(R_x \ge y\), and each fixed white cell imposes \(R_x \le y-1\), giving an interval \([L_x,U_x]\) for each constrained row. The problem reduces to checking whether a nonincreasing sequence can be chosen from these intervals, with unconstrained rows freely fillable. This is possible iff every row's upper bound is at least the maximum lower bound among that row and all rows below it. Therefore, sort constrained rows by row index, compute suffix maxima of lower bounds, and compare them with upper bounds.
