- **Visibility reduction:** For target building i, only buildings j < i can block the segment from (0, h) to a point on building i. For a point Q at height y on building i, the segment height at x_j is h + (y - h) * x_j / x_i, which increases with y. Therefore the top y = H_i is the best possible point. Building i is visible iff h is strictly greater than (X_i H_j - X_j H_i) / (X_i - X_j) for every j < i.
- **Global threshold:** All buildings are visible exactly when h exceeds T, the maximum of all such rational thresholds. Equality is blocking, as shown by sample 3. If T < 0, height 0 already sees all buildings, so the answer is -1. If T = 0, the answer is 0. If T > 0, the answer is T.
- **Adjacent-pair maximum:** Map each top (X, H) to (u = 1/X, v = H/X). The threshold for j < i is the slope of the line between the two mapped points. For three ordered mapped points, the slope of the outer pair is a positive weighted average of the two adjacent slopes, so it cannot exceed both. Hence the maximum threshold is attained by some consecutive pair in the original X order.
- **Algorithm:** Scan consecutive buildings once. For each adjacent pair, compute num = x * prev_h - prev_x * h and den = x - prev_x. Track the maximum fraction by exact cross multiplication: num * best_den > best_num * den. Python integers safely handle the products, and the algorithm is O(N) time with O(1) extra memory.
- **Output formatting:** Negative or absent thresholds print exactly -1. A zero threshold prints 0.000000000000000000. Positive thresholds are printed as a double with exactly 18 digits after the decimal point using f"{best_num / best_den:.18f}". Double precision has relative error around 1e-16, which is well within the required 1e-9 absolute or relative tolerance for all constraint ranges.
- **Sample rerun:** Sample 1 prints 1.500000000000000000. Sample 2 prints -1. Sample 3 prints 0.000000000000000000. Sample 4 prints 17.142857142857142350.
- **Edge cases:** N = 1 has no blocking pair and prints -1. All negative thresholds print -1. A zero maximum threshold prints zero. Large positive intercepts, up to about 1e18, are safe because the judge allows relative error for large answers.
