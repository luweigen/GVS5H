The shortest palindrome with S as a prefix is formed by appending the reverse of a prefix of S, and the append length is minimized when the remaining suffix of S is already a palindrome. Thus the problem reduces to finding the longest palindromic suffix of S. Compute this length L with the KMP prefix function on reverse(S) + '#' + S, where the final prefix-function value is L. If n = |S|, append reverse(S[:n-L]) to S and print the result. This runs in O(n) time and O(n) memory, which is safe for n up to 500000.
