Only substrings ending in a non-zero digit can be counted, and the divisor is exactly that last digit. Scan the string left to right while maintaining, for each modulus d=1..9, a frequency table of remainders of all substrings that end at the current position. When a new digit x is read, every previous substring ending at the previous position transforms from remainder r to (10*r + x) mod d, and the one-character substring contributes remainder x mod d. If x is non-zero, the number of valid substrings ending here is the updated frequency of remainder 0 modulo x. This yields O(9*9*n) time and O(9*9) memory, safely within constraints.
