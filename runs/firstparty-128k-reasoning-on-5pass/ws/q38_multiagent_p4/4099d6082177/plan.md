Interpret the decomposition as deleting N-1 edges so that the resulting N connected components are paths with exactly K vertices. Root the tree and process it bottom-up, tracking for each subtree whether it is CLOSED (fully decomposable), OPEN (decomposable except for one path ending at the subtree root that will attach to its parent), or BAD. In an OPEN subtree the unfinished path length is forced to be sz[v] mod K, because all other components in that subtree have size K. Hence each node only needs its state and subtree remainder: a CLOSED node must have remainder 0 and one or two non-CLOSED children that are OPEN with remainders summing to K-1, while an OPEN node must have nonzero remainder and either (no non-CLOSED children and remainder 1) or (exactly one non-CLOSED OPEN child with remainder one less). The answer is Yes exactly when the root is CLOSED, with K=1 always Yes.
