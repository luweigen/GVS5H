A 400 number is exactly the square of an integer that has exactly two distinct prime factors. Since A is at most 10^12, its square root is at most 10^6, so we only need to precompute valid roots up to 10^6. Use a sieve to count distinct prime factors for every integer up to 10^6. Build a prefix array storing the largest valid root seen so far. For each query, take the integer square root of A, look up the largest valid root not exceeding it, and square it. This gives O(1) per query after preprocessing.
