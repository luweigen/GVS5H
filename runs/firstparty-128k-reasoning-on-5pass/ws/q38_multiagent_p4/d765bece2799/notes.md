- **Decomposition:** The required answer is the sum of minima over all valid subarrays plus the sum of maxima over all valid subarrays. These two parts are independent and can be computed separately.
- **Tie-breaking:** Equal values must be assigned to exactly one representative index. For minima, use previous strictly smaller and next smaller-or-equal boundaries, which assigns a subarray to its rightmost minimum. For maxima, use previous strictly greater and next greater-or-equal boundaries, assigning a subarray to its rightmost maximum. This keeps contributions disjoint.
- **Boundary meaning:** For index i, if prev is the exclusive left boundary and next is the exclusive right boundary, then left_len = i - prev and right_len = next - i. These are the numbers of possible starts and ends for subarrays where i is the chosen representative.
- **Monotonic stack rules:** For minima, previous strictly smaller is found by popping while stack value >= current; next smaller-or-equal is found right-to-left by popping while stack value > current. For maxima, previous strictly greater pops while stack value <= current; next greater-or-equal pops while stack value < current.
- **Length-cap counting:** A subarray represented by left extension x and right extension y has length x + y - 1. Need x + y <= k + 1. The helper counts positive pairs (x, y) inside a left_len by right_len rectangle under that sum constraint in O(1).
- **Helper formula:** Let K = k + 1 and X = min(left_len, K - 1). Let t = min(X, max(0, K - right_len)). The first t x-values allow all right_len choices. The remaining x-values contribute K - x each, summed by an arithmetic-series formula.
- **Edge cases:** k = 1 counts only single-element subarrays and returns 2 * sum(nums). k = n reduces to the unconstrained sum of subarray minima plus maxima. Duplicates are handled by the rightmost representative rule. Negative values are safe because Python integers have arbitrary precision.
- **Complexity:** Four linear passes over nums plus O(n) auxiliary storage for the next-boundary array. Time is O(n), memory is O(n).
- **Verification:** Checked against the two provided examples, k = 1, k = n, all-equal duplicates, negative values, and small brute-force comparisons over random arrays. The contribution counts match the brute-force enumeration for those cases.
