Model each of the n-1 adjacent gaps as either equal or different, and require exactly k equal gaps. For any fixed set of equal gaps, the first element has m choices and every different gap has m-1 choices, while equal gaps are forced. Thus the count is C(n-1,k) * m * (m-1)^(n-1-k) modulo 1e9+7. Handle m=1 naturally by the power term, with 0^0 treated as 1 when k=n-1. Use O(n) modular factorial precomputation, or an equivalent multiplicative combination method, to evaluate the binomial coefficient.
