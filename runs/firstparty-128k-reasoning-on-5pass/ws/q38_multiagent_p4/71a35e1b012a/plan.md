Reformulate each chosen operation as covering either its interval (type 1) or its complement (type 2); the final state is all ones iff the chosen covered sets cover [1,N]. A single operation succeeds only if it is type 1 on [1,N]. For two operations, the only successful orientation patterns are: both type 1 when the two intervals' union is [1,N], both type 2 when the intervals are disjoint, or one type 1 and one type 2 when one interval contains the other. Check these cases in O(M log M) using extremes and a containment sweep. If no cost 1 or 2 exists and M>=3, no interval contains another, so after sorting by L the first three intervals have strictly increasing L and R; choosing type 2 on the first and third and type 1 on the middle covers every position, giving minimum cost 3. Otherwise, if M<3, the goal is impossible.
