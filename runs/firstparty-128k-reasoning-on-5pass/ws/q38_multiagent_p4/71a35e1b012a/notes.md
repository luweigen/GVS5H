- **Core reformulation:** Updates only turn 0 to 1, so order is irrelevant. A paid operation i covers either [L_i,R_i] (op 1) or its complement (op 2). The problem is a minimum-cardinality cover of [1,N] by these sets.
- **Cost 1:** Only op 1 on a full interval [1,N] covers everything. Check while reading and return immediately.
- **Cost 2 mixed containment:** op 1 on a container plus op 2 on a contained interval covers all iff one interval contains the other (equality allowed). Sort by L ascending, R ascending. Scan with max_r/max_r_idx over all previous intervals and last_same_l_idx reset when L changes. If max_r >= R, the previous max-R interval contains current: op 1 for max_r_idx, op 2 for current. Else if last_same_l_idx exists, current has same L and larger/equal R, so it contains last: op 1 for current, op 2 for last. Run this before both-type-1 so sample 1 outputs 2 0 1 0.
- **Cost 2 both type 1:** Two intervals' union is [1,N] iff one starts at 1, one ends at N, and maxR_start >= minL_end - 1. Track these extremes while reading. Full would already have returned, so the two indices are distinct.
- **Cost 2 both type 2:** Complements cover all iff the original intervals are disjoint. In L-ascending order keep the minimum R seen; if min_r < current L, output both op 2. Strict inequality is required; touching at one point is not disjoint.
- **Cost 3 fallback:** If no cost 1 or 2 exists and M >= 3, any three intervals suffice. Use the first three sorted intervals. Build coords {1, N+1, L_k, R_k+1}, sweep nonempty integer segments, and mark the 3-bit membership masks. There are at most 7 segments, so some mask value is absent. Pick one absent mask value m (loop m=0..7 over seen bits). For each of the three intervals, choose op 1 if m's corresponding bit is 0, op 2 if it is 1. Any real point has a different mask, so a differing bit gives a covering operation. If all 8 masks were seen (impossible), fallback to op 2, op 1, op 2 on the sorted first three, which is valid when no cost 2 exists because L and R are strictly increasing.
- **Implementation order:** read all intervals and track full/extremes; emit cost 1; sort; mixed containment; both type 1; both type 2; if M < 3 print -1; otherwise cost 3.
- **Pitfalls:** sort R ascending for mixed; max_r persists across L groups while last_same_l resets; disjointness is strict; pair indices must be distinct; cost 3 is used only after cost 1 and all cost 2 cases are ruled out; the absent mask is a value 0..7, not the 8-bit set of absent masks; use seen |= 1 << mask and then loop m=0..7; output K equals the number of nonzero ops.
- **Complexity:** O(M log M) time due to sorting, O(M) memory.
