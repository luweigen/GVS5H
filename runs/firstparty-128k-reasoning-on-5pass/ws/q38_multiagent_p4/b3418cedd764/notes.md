- **Graph structure:** Each index has exactly one outgoing edge to A_i, so every weakly connected component contains one directed cycle with reverse trees feeding into it. Indegree peeling removes all non-cycle nodes; the remaining nodes are exactly the cycle nodes.
- **Cycle equality:** On a directed cycle v1 -> v2 -> ... -> vk -> v1, the constraints give x_v1 <= x_v2 <= ... <= x_vk <= x_v1, so all cycle vertices in that component must have the same value c.
- **Tree DP:** For a non-cycle node v, let F_v[k] be the number of valid labelings of its reverse subtree when x_v <= k. A leaf has F_v[k] = k. If its children are u, then fixing x_v = t contributes product_u F_u[t], so F_v[k] is the prefix sum over t = 1..k of that product.
- **Cycle component contribution:** For a cycle component with common value c, every non-cycle child u of any cycle node contributes F_u[c]. The component count is sum_{c=1}^M product_u F_u[c], or M if there are no such children. Different components multiply independently.
- **Implementation:** Build child_count for non-cycle nodes and process leaves with a queue. Keep acc[v] as the pointwise product of finished children's F arrays. When the first child finishes, reuse its array as acc[v] instead of allocating an all-ones array. When all children are processed, prefix acc[v] in place to obtain F_v. If v's parent is non-cycle, store or multiply F_v into acc[parent]; if the parent is a cycle node, store or multiply F_v into H[component].
- **Memory and time:** Arrays are reused up chains and discarded after multiplication, so only active node/component arrays are kept. Each non-cycle node causes about one O(M) pass, giving O(NM) total time, easily within N, M <= 2025. Lists are used for speed; leaf arrays are copies of a shared base list.
- **Edge cases:** Self-loops are cycles of length one. Pure cycles have H None and contribute M. Multiple components are independent. M = 1 gives answer 1. Index 0 is unused in arrays and is set to 0 after prefixing.
