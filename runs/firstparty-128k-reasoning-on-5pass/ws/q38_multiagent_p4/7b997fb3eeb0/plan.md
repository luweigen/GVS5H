For any sorted interval, K kagamimochi can be made iff the K smallest elements can be paired with the K largest elements, i.e. A[L+t-1] <= A[R-K+t]/2 for all t=1..K. Precompute f[i], the first global index with A[f[i]] >= 2A[i], by a two-pointer scan, and set h[i]=f[i]-i (or N-i if no such index exists). For a query [L,R] with length M, the above condition is equivalent to max_{i=L}^{L+K-1} h[i] <= M-K. This predicate is monotone in K, so each query is answered by binary searching K and checking the range maximum with a sparse table (or segment tree). The overall complexity is O(N log N + Q log N) time and O(N log N) memory, or O(N + Q log^2 N) with a segment tree.
