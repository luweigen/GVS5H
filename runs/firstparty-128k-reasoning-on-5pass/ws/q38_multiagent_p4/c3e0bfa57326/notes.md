- **Model:** Represent each matched pair as a node. Top-level pairs are children of an artificial root. A valid parenthesis sequence is an ordered rooted forest, and its parse tree is unique.
- **Operation meaning:** Any valid substring of a valid parenthesis sequence is exactly a contiguous block of sibling nodes under some parent. If the block is C1...Ck, the special reversal produces M(Ck)...M(C1), where M is mirroring: reverse the string and flip parentheses. Thus the operation reverses sibling order and mirrors each subtree in the block.
- **Reachability:** Mirroring a single node is allowed because a single pair is a valid substring. To reverse a sibling interval without changing subtree orientations, first mirror every node in the interval, then apply the interval operation; the two mirrors cancel and only the order is reversed. Length-2 reversals are adjacent swaps, so arbitrary sibling permutations are reachable. By induction, every ordered forest with the same unordered rooted forest is reachable. Since operations preserve the unordered rooted forest, this is the exact reachable set.
- **Counting:** Count all plane embeddings of the unordered forest. For a node with d children, if its children have unordered isomorphism-class frequencies f_c, the number of possible child class orders is d! / prod f_c!. Multiplying this local factor over every actual node, including the artificial root, gives the total number of distinct strings. Identical subtrees still contribute their internal factors separately because each actual node is processed.
- **Canonical IDs:** Process nodes in reverse creation order. For each node, sort the canonical IDs of its children; the tuple is an exact key for unordered subtree isomorphism. Assign integer IDs with a dictionary. Leaves have key ().
- **Implementation:** Parse with a stack of node indices and store children lists. Precompute factorials and inverse factorials up to the maximum degree, at most 2500 for N=5000. In the bottom-up pass, multiply ans by fact[deg] and by invfact[run_length] for each run of equal child IDs in the sorted list.
- **Complexity:** Total child count is O(N). Sorting child ID lists over all nodes is O(N log N) in the worst case, and all other work is O(N). Memory is O(N). Modulo 998244353 is prime and larger than N, so factorial inverses are valid.
- **Edge cases:** Include the artificial root in the product. Leaves contribute factor 1. Empty or degree-zero cases are handled by fact[0]=1. Samples give 2 for (())() and 1 for ().
