- **Model:** Let P_v be prefix road strength up to town v. A person from S to T becomes interval [l,r] with sign + if S<T, - if S>T. Requirement is P_l=P_r and every interior P_x is > P_l for +, < P_l for -.
- **Conflict characterization:** A set is feasible iff no pair has: same left endpoint, same right endpoint, or same sign with strict crossing. Equality edges form vertex-disjoint paths because no two intervals share a left or right endpoint. Inequality edges never go from a - component to a + component; same-sign crossing creates a 2-cycle, same endpoint creates immediate contradiction.
- **Query reduction:** For each person j, bad[j] = largest i<j conflicting with j. Prefix maximum pref[j]=max(pref[j-1],bad[j]). Query [L,R] is Yes iff pref[R] < L.
- **Endpoint conflicts:** Computed first with last_l and last_r arrays over all signs.
- **Same-sign crossing:** Process + and - signs separately. Partition each sign’s indices into blocks of size B (~8192). Local bit position is the position inside the block, i.e. increasing original index, so the highest set bit in a mask is the largest conflicting index in that block.
- **Mask formula:** For previous block P and current interval j, conflict mask is  
  (l_i <= l_j < r_i <= r_j) OR (l_j <= l_i < r_j <= r_i).  
  With prefix masks: A=Lpref(l_j), A0=Lpref(l_j-1), B=Rpref(r_j), B0=Rpref(r_j-1), Cm=Rpref(l_j), D=Lpref(r_j-1). Then mask = (A & B & ~Cm) | (D & ~A0 & ~B0), implemented with all_mask XOR to keep positive ints.
- **Block data:** For each block store sorted l/r values, prefix bitmasks for l and r, sorted orders, all_mask, min/max l/r, and original indices. Prefix masks are Python ints.
- **Block pair processing:** For current block C, first compute intra-block conflicts using P=C and mask with (1<<p)-1. Then scan previous blocks newest to oldest. For each P, fill six arrays by four sweeps over C’s sorted l/r and P’s sorted l/r, avoiding per-query bisects in the main path. Final loop computes mask; first non-empty P gives the maximum previous conflict for that j.
- **Done/skip logic:** If bad[j] is already at least the maximum index in the current previous block, no older block can improve it, so mark done. Bounding skip: if all P intervals are left/right of C, or one block contains the other, no strict crossing exists; endpoint conflicts are already handled.
- **Hybrid mode:** If only a small fraction of current-block intervals remain unresolved, use direct bisect against P instead of full sweeps.
- **Complexity/memory:** Big-int work is roughly O(M^2 / word) independent of B; B mainly controls Python overhead and memory. Memory is dominated by prefix masks. Current block orders are freed after the block is processed to reduce peak memory.
- **Edge cases:** Touching endpoints are not conflicts; same endpoints are safely included in masks and also handled by endpoint arrays. Single-person queries are always Yes. Strictness is enforced by l_j < r_i and l_i < r_j.
