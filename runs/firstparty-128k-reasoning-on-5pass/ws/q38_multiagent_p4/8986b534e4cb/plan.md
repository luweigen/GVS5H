Model road strengths as prefix values \(A_v\); each person becomes an interval \([l,r]\) with type \(+\) if \(S<T\) and \(-\) if \(S>T\), requiring \(A_l=A_r\) and all interior towns to be strictly above (for \(+\)) or below (for \(-\)) the endpoint value. A set of people is feasible iff no two people conflict, where conflict means they have the same left endpoint, the same right endpoint, or have the same type with strictly crossing intervals. Therefore a query \([L,R]\) is satisfiable exactly when it contains no conflicting pair. For each right endpoint \(j\), compute the largest index \(i<j\) that conflicts with \(j\); the prefix maximum of these values answers all queries in \(O(1)\). Same-left/same-right conflicts are found by last occurrences, while same-type crossing conflicts are computed by two symmetric 2D range-maximum passes (original and reversed coordinates) using an index-block bitset decomposition.
