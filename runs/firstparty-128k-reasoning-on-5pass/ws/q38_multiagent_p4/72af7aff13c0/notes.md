- **Storage:** After optional transpose so that H <= W, cell (r,c) is stored at flat index `s * stride + (r + 1)` where `s = r + c` and `stride = H + 2`. Offsets 0 and H+1 in each diagonal row are zero padding. This makes anti-diagonals contiguous and gives the uniform recurrences `F[j] = A[j] * (F[j-stride-1] + F[j-stride])` and `G[j] = A[j] * (G[j+stride] + G[j+stride+1])`.
- **Transpose:** If original H0 > W0, swap coordinates and remap original L/R/U/D to new U/D/L/R. The value of `s = r + c` and each diagonal length are invariant under transpose, so the smaller dimension controls the maximum recomputed diagonal length.
- **Initialization:** `F[start] = A[start]`, `G[end] = A[end]`. Forward DP fills F for diagonals 1..max_s; backward DP fills G for diagonals max_s-1..0. Initial answer is `F[end]`.
- **Frontier invariant:** After processing a query on diagonal d, F is correct for all diagonals <= d and G is correct for all diagonals >= d. Moving to d+1: update only `G[pos]`, then recompute F[d+1]. Moving to d-1: update only `F[pos]`, then recompute G[d-1]. If the value does not change, the frontier diagonal is still recomputed to restore the invariant.
- **Query update:** For the updated cell, L is 1 at s=0, otherwise `F[pos-stride-1] + F[pos-stride]`. R is 1 at s=max_s, otherwise `G[pos+stride] + G[pos+stride+1]`. The answer changes by `(new - old) * L * R` modulo 998244353. The walker state maintains r, c, s, and base; `pos = base + r + 1`.
- **Direction handling:** Precomputed tables for base delta, dr, dc, and ds for the four direction character codes. Base changes by +/- stride and s changes by +/- 1, so at most one diagonal is recomputed per query.
- **Boundary handling:** Padding removes per-cell boundary branches inside diagonal recomputation. Only the queried cell needs explicit start/end special cases for L and R.
- **Performance:** Total recomputed cells is the sum of lengths of visited diagonals, bounded by Q * min(H, W). For H = W = 447 and Q = 200000 oscillating across the middle diagonal, this is about 89.4 million diagonal-cell updates. The loops use local bindings, precomputed diagonal index lists, one conditional subtraction for neighbor sums, and modulo only for products.
