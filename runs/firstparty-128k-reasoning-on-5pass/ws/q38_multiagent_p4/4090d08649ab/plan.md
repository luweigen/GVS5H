For any subarray, \(f(L,R)\) depends only on the set of distinct values present: it equals the number of contiguous value-runs in that set. This is because one operation can erase a value interval only if every value in that interval is present, so it cannot cross a missing value, and each initial run can be erased in one operation. Thus \(f = \text{distinct values} - \text{adjacent value pairs both present}\). The total answer is therefore the sum over all values of the number of subarrays containing that value, minus the sum over adjacent value pairs \((x,x+1)\) of the number of subarrays containing both. For a fixed set of positions, the number of subarrays avoiding it is obtained by summing triangular numbers over the gaps between consecutive positions. Using inclusion-exclusion for adjacent pairs and processing all occurrence lists gives an efficient linear/near-linear solution.
