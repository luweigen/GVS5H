- **Reduction:** For a subarray, only the set S of distinct values matters. An operation can erase an interval [l, r] only if every value in [l, r] is currently present, so it cannot cross a missing value. Each maximal contiguous value-run in S requires one operation, and one operation suffices for each run. Therefore f(L, R) is exactly the number of contiguous value-runs in the distinct-value set of A[L..R].
- **Sweep invariant:** Process the right endpoint i from 1 to N. Maintain cur = sum_{L=1}^i f(L, i). When A_i = x is appended, let prev = last[x] before updating. For L <= prev, x was already present in [L, i-1], so f(L, i) = f(L, i-1). For L in prev+1..i, x was absent, so its addition changes the run count by 1 - I(x-1 present) - I(x+1 present).
- **Neighbor counting:** Before updating last[x], last[y] is the last occurrence position of neighbor y. For L in prev+1..i, y is present in [L, i-1] iff last[y] >= L. The number of such L is max(0, last[y] - prev). Hence delta = (i - prev) - max(0, last[x-1] - prev) - max(0, last[x+1] - prev).
- **Implementation details:** Use last of length N+2 so last[0] and last[N+1] safely handle x=1 and x=N. Compute delta before setting last[x] = i. Use if ly > prev: d -= ly - prev instead of max for speed. Delta can be negative when both x-1 and x+1 are present while x was absent; this correctly represents merging two runs into one.
- **Complexity:** O(N) time and O(N) memory. The maximum answer is on the order of N^3/6, about 4.5e15 for N=3e5, which is easily handled by Python integers.
- **Verification:** Sample 1 gives cur sequence 1, 3, 5, 7 and answer 16. Sample 2 gives 23. Sample 3 gives 129 when the max(0, last[y] - prev) condition is applied; subtracting last[y] unconditionally is the main off-by-one trap. Edge cases such as N=1, all equal values, x=1, x=N, and negative delta cases are handled correctly.
