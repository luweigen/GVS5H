Binary search the integer distance D and check whether k points can be chosen with all pairwise Manhattan distances at least D. Map each boundary point to u = x + y - side and split it into two chains: A = bottom ∪ right and B = left ∪ top; on one chain distance is |Δu|, while across chains it is max(|Δu|, 2*side - |u1| - |u2|). For a fixed D, in increasing u-order it is enough to enforce that a new point is D-separated from the last chosen point on its own chain and compatible with the last chosen point on the other chain. DP over the number of chosen points (k ≤ 25) keeps, for each possible last point on one chain, only the minimum coordinate of the last point on the other chain (or -inf if none), which dominates all larger values. Each DP layer is computed in O(n log n) using sorted coordinates, prefix minima for the no-other-chain case, and segment-tree/Fenwick queries for the leftmost compatible previous point. Return the largest feasible D.
