Interpret f(x, y) as the smallest threshold T such that x and y are connected using only edges of weight at most T; this gives an ultrametric structure produced by Kruskal-style processing. Process all edges in nondecreasing weight order with a DSU, maintaining for each component the number of A-tokens and B-tokens. When two components merge at weight w, any newly possible A-B pair has cost exactly w, so match as many leftover opposite-color tokens as possible and add w times that number. This greedy choice is optimal because matching inside already-formed components at lower or equal thresholds is never worse than deferring to a higher threshold, and the component hierarchy is laminar. After all unions, the accumulated cost is the minimum possible sum.
