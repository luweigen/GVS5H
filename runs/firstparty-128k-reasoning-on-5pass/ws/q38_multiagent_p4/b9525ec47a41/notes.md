- **Reduction:** Let a_i=1 if cycle edge i is directed i -> i+1 mod N, and e_i=1 if spoke i is directed N -> i, with e_i <= s_i. For i<N, x_i = d_i = 1 + a_{i-1} - a_i + e_i. Since total edges are N+M where M is the number of ones in s, d_N = N+M - sum(x_i), so full in-degree sequences are in bijection with feasible x strings.
- **NFA:** Hidden state is a_i. For s_i=0, x_i=0,1,2 correspond to transition masks 2, 9, 4. For s_i=1, x_i=0,1,2,3 correspond to masks 2, 11, 13, 4. Mask bits are 1=(0,0), 2=(0,1), 4=(1,0), 8=(1,1).
- **DFA:** The state is the reachability relation from the initial cycle bit to the current cycle bit. Initial mask is 9. A full x string is feasible iff the final mask contains bit 1 or bit 8. The reachable masks are 0,1,2,3,4,5,8,9,10,11,12,13,15; mask 0 is dead and is omitted from the unrolled DP.
- **Transition correction:** The exact transition from mask 5 on input '1' is to 0,5,10,15. The task table entry 5->4,10,13,15 is inconsistent with the NFA and fails small brute force, e.g. N=4 s=1111. The code uses the corrected transition.
- **Unrolled update:** The code aggregates the per-x destination multiplicities into direct linear updates. For '0', each tracked source has three destinations; for '1', four. Common subexpressions y123, y48, y510, y911, y913, t4812, t51015 keep the loop small.
- **Accepting states:** Masks with bit 1 or bit 8 are 1,3,5,8,9,10,11,12,13,15. The answer is their sum modulo 998244353.
- **Modulo and size:** Counts are reduced every 64 characters. Between reductions integers stay around a few hundred bits, so additions remain fast.
- **Verification:** N=3 s=010 gives 14; N=3 s=111 gives 38; sample 2 gives 261339902. Brute force over all cycle and spoke orientations for N<=6 matches the DP. Complexity is O(N) time and O(1) memory, suitable for N=1e6.
- **Orbit remark:** The 8-orbit aggregation is actually exact under the 0/1 symmetry of the automaton, but the requested explicit 13-mask DP is implemented here, with the dead mask omitted.
