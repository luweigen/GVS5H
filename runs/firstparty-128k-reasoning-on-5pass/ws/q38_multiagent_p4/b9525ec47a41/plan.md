Represent each orientation by cycle bits \(a_i\) and spoke bits \(e_i \le s_i\); the cycle in-degree is \(x_i = 1 + a_{i-1} - a_i + e_i\), and \(d_N\) is fixed by \(\sum x_i\), so we only need to count distinct \(x\) strings. For a fixed last cycle bit \(a_{N-1}=p\), the string \(x\) is generated by a 2-state NFA whose state is the current \(a_{i-1}\), with transitions determined by \(s_i\) and \(x_i\). A string is feasible iff this NFA has a path from \(p\) to \(p\) for \(p=0\) or \(p=1\). Build the deterministic subset automaton over the 2x2 reachability matrix of the NFA (16 possible, 13 reachable) and run an O(N) DP over its states, summing accepting states modulo 998244353.
