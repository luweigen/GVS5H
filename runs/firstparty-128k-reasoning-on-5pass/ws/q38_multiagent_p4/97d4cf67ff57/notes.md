- **Reduction:** In any alkane, a vertex with original degree less than 4 cannot have degree 4 in the subgraph, so it can only be a leaf. Therefore all degree-4 vertices of an alkane must come from the set H of original vertices with degree at least 4.
- **Core structure:** Let S be the set of degree-4 vertices in an alkane. If S has more than one vertex, the path between any two vertices of S cannot contain a leaf, so it is entirely inside S. Thus S is connected in the induced forest on H, and every vertex of S has at most 4 neighbors inside S.
- **Size formula:** For a valid core S, each v in S needs 4 - d_S(v) leaf neighbors outside S. Since deg_T(v) >= 4, enough such neighbors exist, and outside neighbors of different core vertices are disjoint in a tree. Total vertices = |S| + sum(4 - d_S(v)) = 5|S| - 2(|S|-1) = 3|S| + 2. So the problem reduces to maximizing |S|.
- **Core DP:** Build the forest of H-vertices with edges between H-vertices. Root each component. `down[u]` is the maximum size of a valid core subgraph in u's rooted subtree that contains u when the edge to its parent is already used, so u may take at most 3 children: `1 + sum of top 3 child down values`. `best[u]` is the maximum valid core subgraph in u's subtree: either the top is u (up to 4 children) `1 + sum of top 4 child down values`, or it lies completely in one child subtree `max best[child]`.
- **Answer:** Let k be the maximum `best[u]` over all H-vertices. If k > 0, output `3*k + 2`; otherwise -1. k > 0 exactly when some original degree is at least 4.
- **Implementation details:** Read all integers, compute degrees, mark H, and build adjacency only for H-H edges. Use iterative DFS with a parent array (0 unvisited, -1 root) to avoid recursion. Process each component in reverse DFS order. Maintain the top four child `down` values with simple shift variables and the maximum child `best`.
- **Complexity:** O(N) time and O(N) memory. The high-induced forest has at most N-1 edges, and each edge is scanned a constant number of times.
- **Edge cases:** N=1 or no degree >=4 gives -1. An isolated H-vertex gives k=1 and answer 5. A high vertex with more than 4 high neighbors is handled by taking only the best 4 children, or 3 children when it has a parent in the core.
