Root the input tree arbitrarily and process vertices bottom-up, since any connected subgraph has a unique highest vertex and can be decomposed into child subtrees. For each vertex u store four DP values: the maximum size of a connected selected subgraph in u's subtree that includes u, with the edge to its parent absent or present, and with or without a degree-4 vertex already present. If an edge to a child is selected, the child must contribute its parent-edge-present value; if not selected, it contributes nothing. For each u, combine children with a constant-size DP tracking how many child edges are chosen (0 to 4) and whether a chosen child subtree contains a degree-4 vertex. Keep only choices where u's selected degree is 1 or 4: with no parent edge choose 1 or 4 children, with a parent edge choose 0 or 3 children, and mark the has-4 flag true when u itself has degree 4. The final answer is the maximum, over all vertices, of the no-parent-edge and has-4 value, or -1 if none exists.
