Model the constraints as an undirected graph where each edge \((X_i, Y_i)\) has XOR weight \(Z_i\). For each connected component, compute XOR potentials from an arbitrary root and check consistency; if any edge violates the potential relation, no solution exists. For a consistent component, every valid assignment has the form \(A_v = C \oplus D_v\), where \(D_v\) is the XOR distance from the root and \(C\) is a free component-wide value. Since the sum of integers is additive over bits, each bit of \(C\) can be chosen independently to minimize the number of 1-bits in the component. Choose bit \(k\) of \(C\) to be 1 if more than half of the \(D_v\) values have bit \(k\) equal to 1, otherwise choose 0. Then output \(A_v = C \oplus D_v\) for all vertices.
