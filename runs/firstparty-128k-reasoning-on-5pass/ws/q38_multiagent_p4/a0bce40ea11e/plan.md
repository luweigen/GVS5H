Handle p=2 separately: every possible B is the all-ones matrix, so each answer entry is N mod 2. For odd p, expand (B^p)_{i,j} as a sum over length-p walks and sum over all choices of zero entries; a zero entry's sum is nonzero only when its exponent is 0 or p-1, so a contributing walk uses at most one zero edge, and if it uses one, that edge is repeated p-1 times. This yields a global factor (-1)^K and leaves A^p plus local corrections. For each zero diagonal A_{u,u}=0, add row u and column u of A; for p=3 and each zero off-diagonal A_{u,v}=0, add A_{v,u} to (u,v). Compute A^p by fast exponentiation in O(N^3 log p), apply corrections, and multiply by (-1)^K.
