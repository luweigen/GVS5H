- **Approach:** Keep the current segment-tree solution. Each leaf is either active with its value or empty; internal nodes store total sum, best prefix, best suffix, and best subarray for the active sequence in that interval.
- **Empty representation:** A segment with no active element is marked by `best == NEG`. This avoids sentinel arithmetic contaminating valid summaries and correctly enforces non-empty subarrays.
- **Combine rule:** For non-empty left and right children, `total = L.total + R.total`, `pref = max(L.pref, L.total + R.pref)`, `suff = max(R.suff, R.total + L.suff)`, and `best = max(L.best, R.best, L.suff + R.pref)`. If one child is empty, copy the other child.
- **Deletion simulation:** Build the tree with all leaves active for the no-operation answer. For each negative value whose frequency is less than `n`, deactivate all its indices, read the root best, then reactivate them. Total point updates are at most `2n`, giving `O(n log n)` time and `O(n)` memory.
- **Why only negative values:** Deleting a non-negative value cannot improve the answer. Any subarray in the filtered array maps to an original interval containing the same non-deleted elements plus some deleted `x` occurrences; adding `x >= 0` cannot decrease the sum.
- **Test harness added:** The program now includes a `__main__` harness that runs the provided examples, the previous edge cases, and 3400 deterministic random small arrays against a brute-force checker.
- **Brute force checker:** For each unique value with count less than `n`, it builds the filtered array and computes the maximum subarray sum using Kadane. It also includes the original array for the no-operation case.
- **Failure reporting:** If any mismatch occurs, the harness prints the failing arrays with expected and got values, then exits with status 1. Otherwise it prints a success message.
- **Result:** No failures were found. The deterministic random checks cover `n = 1`, all negative, all positive, zeros, repeated values, large values, and cases where deleting a repeated negative connects positive parts.
- **Edge cases:** `n = 1`, all elements equal, full-frequency values skipped, padding leaves empty, all-negative arrays return the largest element, and zeros correctly return `0` when present.
