Count the triplets by converting the set into an indicator polynomial and computing its self-convolution. Encode each value s as a 1 in a 20-bit-wide coefficient at position s; this is safe because every convolution coefficient is at most N <= 10^6 < 2^20, so no carries occur. In Python, build a big integer with bit 20s set for each s, square it, and read the 20-bit chunk at position 2b from the product to obtain the number of ordered pairs (x,y) in S with x+y=2b. For each b in S, subtract the mandatory (b,b) pair and divide by 2 to count unordered (A,C) pairs, then sum these contributions. The result is printed as the answer, with the heavy convolution done by the interpreter's fast big-integer multiplication.
