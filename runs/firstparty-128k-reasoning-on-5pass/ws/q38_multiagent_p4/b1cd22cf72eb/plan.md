The total cost for a chosen common tooth-sum H is fixed as sum(U_i + D_i) - N*H, so minimizing cost is equivalent to maximizing feasible H. For a fixed H, each upper tooth i must lie in the interval [max(0, H - D_i), min(U_i, H)]. Feasibility for H can be checked in O(N) by propagating the reachable interval of upper-tooth lengths while enforcing adjacent differences at most X. Feasibility is monotone: if H is feasible, every smaller H is also feasible, so binary search over H works. The search range is [0, min_i(U_i + D_i)], and the answer is the total initial sum minus N times the maximum feasible H. Use 64-bit integer arithmetic.
