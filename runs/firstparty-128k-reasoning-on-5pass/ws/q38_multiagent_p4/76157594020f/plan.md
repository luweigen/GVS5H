Binary search the answer L, the maximum allowed run length. For a fixed L, check feasibility with a dynamic program that builds the final string left to right while tracking the last bit and current run length. The DP stores the minimum flips needed to reach each state and rejects transitions that would make a run longer than L. If the minimum flips at the end is at most numOps, L is feasible; otherwise it is not. The binary search returns the smallest feasible L, with trivial handling for n=1 and numOps=0.
