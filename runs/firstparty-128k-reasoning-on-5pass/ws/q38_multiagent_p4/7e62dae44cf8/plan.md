Model Takahashi's reachable area as a connected region starting from cell (P, Q). At any moment, only unabsorbed cells adjacent to this region can be absorbed, and a cell with strength S can be absorbed exactly when X * S < current_total. Because all strengths are positive, absorbing any eligible cell only increases current_total and expands the frontier, so a greedy process is optimal. Use a min-heap of frontier cells keyed by strength; if the smallest frontier cell cannot be absorbed, no frontier cell can be absorbed. When absorbing a cell, add its strength to current_total and push its unvisited neighboring cells into the heap. This runs in O(HW log(HW)) time and O(HW) memory, using integer arithmetic to avoid precision and overflow issues.
