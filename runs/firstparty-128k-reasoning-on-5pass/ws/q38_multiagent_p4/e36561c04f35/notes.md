- **Final algorithm:** Compress each test case into runs `(value, length)`. Let `m` be the number of runs. A useful swap is an adjacent swap of two length-1 runs at edge `i` (between runs `i` and `i+1`, 0-indexed) with `i >= 1`, `i+2 < m`, `vals[i-1] == vals[i+1]`, and `vals[i] == vals[i+2]`. It changes `x y x y` to `x x y y`, reducing the run count by 2 for cost 1, so it gives a net saving of 1.
- **Why only useful swaps:** Any other adjacent element swap either increases the run count or reduces it by at most 1, so its net saving (run reduction minus swap cost) is nonpositive. Partial prefix deletions also have nonpositive net saving and cannot create a new useful swap; whole-run deletions are exactly the final deletions after all useful swaps. A local check shows a non-useful swap cannot create a new length-1 `x y x y` pattern that would be useful.
- **Conflict rule:** A useful swap consumes its two length-1 runs and merges them with the neighboring runs. Therefore another useful swap cannot use any run within distance 2; selected useful edges must have indices differing by at least 3. Conversely, any set of useful edges with pairwise distance at least 3 can be performed independently, in any order.
- **DP recurrence:** For edges `0..m-2`, let `good[i]` be true if edge `i` is useful. Let `dp[i]` be the maximum number of useful edges chosen among `0..i`. Then `dp[i] = dp[i-1]`, and if `good[i]` then `dp[i] = max(dp[i], (dp[i-3] if i >= 3 else 0) + 1)`. The answer is `m - dp[m-2]`. If `m == 1`, answer is 1. The implementation keeps only the last three DP values.
- **Complexity:** Compression and DP are linear in the number of runs, hence O(N) per test case and O(sum N) overall (<= 2e5). Memory is O(N) for the current case's run arrays; DP state is O(1). Input is read with `sys.stdin.buffer.read().split()` and output is joined.
- **Sample verification:** Case 1 has runs `1,2,1,2` with one useful edge, answer `4-1=3`. Case 2 has four distinct runs and no useful edge, answer `4`. Case 3 has 11 alternating runs; the maximum nonconflicting useful edges are 3 (e.g. edges 1,4,7), answer `11-3=8`.
- **Edge cases:** All equal gives `m=1` and answer 1. For `m=2` or `m=3` there is no useful edge, so the answer is `m`. Only equality of values matters; no coordinate compression is needed.
- **Cleanup:** All brute-force, self-test, random, and debug code has been removed; the final program only reads stdin, solves the cases, and writes stdout.
