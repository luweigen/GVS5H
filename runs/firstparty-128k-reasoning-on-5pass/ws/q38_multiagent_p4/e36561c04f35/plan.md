Compress each test case into runs of equal values, since an optimal deletion removes a whole prefix run. A swap can give a net saving only when it exchanges two adjacent length-1 runs in a four-run pattern `x y x y`; this reduces the run count by 2 for cost 1. All other swaps, partial deletions, or zero-net rearrangements can be removed without improving the total. Such a saving swap consumes its two length-1 runs and merges the neighboring runs, so two selected saving swaps must start at least three run positions apart. Hence the answer is the number of runs minus the maximum number of non-conflicting good pairs, solvable by a simple DP or greedy selection.
