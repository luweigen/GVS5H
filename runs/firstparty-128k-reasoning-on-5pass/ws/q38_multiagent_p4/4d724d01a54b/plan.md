Use the fact that an optimal sorting sequence can be viewed as processing values from N down to 1, moving each value x right to its final position x across smaller elements. When x is processed, all larger values are already fixed to the right, so x's current position is exactly 1 plus the number of smaller values that were initially to its left. If that position is A_x, the cost contributed by x is the sum of edge costs A_x, A_x+1, ..., x-1, equal to T_{x-1}-T_{A_x-1}. Compute A_x for all x by scanning values in increasing order and using a Fenwick tree over positions to count smaller values before pos[x]. Sum the contributions with 64-bit integer arithmetic and print the result.
