- **Model:** Adjacent swap at edge i costs i. Sorting a permutation cannot be solved by plain inversion count or net edge crossings, because an element may cross the same edge multiple times in an optimal sequence. Example: 3 2 1 requires edge 1 to be used twice.
- **Largest-value induction:** For value N with initial position p, N must cross each edge p, p+1, ..., N-1 from left to right at least once. Therefore swaps involving N cost at least sum_{i=p}^{N-1} i. Moving N left only adds extra crossings and cannot help.
- **Projection argument:** If we project out N, every swap not involving N occurs at a reduced position no larger than its original position. Thus the cost of all other swaps is at least the optimal cost for the reduced permutation of values 1..N-1. Moving N monotonically right first achieves the lower bound, then the reduced problem remains.
- **Reduced position A_x:** After values greater than x are fixed/removed, values 1..x occupy positions 1..x. The position of x is its rank among values <= x in the original order: A_x = 1 + count{y < x : pos[y] < pos[x]}. Since there are x-1 smaller values, A_x is always between 1 and x.
- **Contribution of x:** In the reduced prefix of length x, x must move from A_x to final position x. The minimum cost is sum_{i=A_x}^{x-1} i = T_{x-1} - T_{A_x-1}, where T_k = k(k+1)/2. The total answer is the sum of these contributions over x=1..N.
- **Computation:** Build pos[value] = original index. Iterate x from 1 to N, maintaining a Fenwick tree over original positions of already processed smaller values. prefix(pos[x]-1) gives the number of smaller values initially left of x, so A_x = prefix + 1. Add the triangular difference, then insert pos[x]. Complexity is O(N log N), memory O(N).
- **Magnitude:** The maximum answer occurs for the reverse permutation and equals sum_{x=1}^N T_{x-1} = N(N-1)(N+1)/6. For N=2e5 this is about 1.33e15, easily fitting in Python integers and also in 64-bit signed integers.
- **Edge cases:** Sorted permutation gives A_x = x for all x, so the answer is 0. Reverse permutation gives A_x = 1 for all x. N=2 works directly.
- **Implementation:** Use sys.stdin.buffer.read().split() for fast input. Inline Fenwick prefix-sum and update loops to keep the solution fast. No simulation of swaps is needed.
