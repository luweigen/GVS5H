Model each color independently: red balls move along P and blue balls move along Q, and a ball can reach X only if its starting box is in the cycle of X for that permutation. For a color whose farthest initial ball is at distance M from X along the permutation, the necessary and sufficient operations for that color are the M boxes on the path from that farthest box to X, performed in decreasing-distance order. Thus we obtain two ordered lists, one for red and one for blue; a global operation on a box can serve both colors only when it can be placed consistently in both orders. The minimum number of operations is the length of the shortest common supersequence of these two lists, which equals len(R)+len(B)-LCS(R,B). Since each list has distinct boxes, LCS can be computed in O(N log N) by mapping positions in one list and taking the LIS of the other list's mapped positions. If any initial ball of a color is outside X's cycle, output -1; otherwise output the SCS length (0 if both lists are empty).
