Treat only values <= threshold as potentially connected, since any larger value has lcm at least itself and is isolated. For two values a and b, lcm(a,b) <= threshold iff they share some common multiple m <= threshold, so all present divisors of each m must lie in one component. Use a DSU over labels 1..threshold and, for each present x, scan its multiples m; keep the first present divisor seen for m and union x with that first divisor. This connects every pair that has a common multiple without enumerating all pairs, in O(threshold log threshold) time. Finally return the number of DSU components among the original n nodes, with >threshold values remaining isolated.
