Root the given undirected tree at node 0 and perform an iterative DFS, tracking each node's depth in nodes and weighted distance from the root. While traversing, maintain the current root-to-node path and, for every value, the depths of its last and second-last occurrences on that path. Use a lazy max-heap over second-last depths to obtain the deepest blocking duplicate, so the highest valid ancestor for the current endpoint is at depth max_second + 1. For each node as the descendant endpoint, compute the candidate path length and node count from that ancestor to the node, then update the global maximum length and minimum node count on ties. Backtrack value states when leaving nodes, keeping the algorithm within O(n log n) time and O(n) memory.
