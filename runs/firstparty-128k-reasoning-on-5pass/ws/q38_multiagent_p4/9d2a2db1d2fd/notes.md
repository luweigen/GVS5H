- **Core reduction:** For any fixed block path, let m be the minimum building height on it. The minimum stair cost is max(|y-z|, y+z-2m). The |y-z| part is unavoidable; if m is below both floors, the route must drop to at most m and rise again, giving y+z-2m, and this is attainable by moving monotonically down to m and then up while staying within available heights. Thus each query only needs M, the maximum possible minimum height over all block paths.
- **Widest path as Kruskal tree:** Process cells in descending F. Activate a cell and union it with already active cardinally adjacent cells. Each successful union creates a new internal node whose weight is the current cell height and whose children are the two component roots. Leaves are cells with weight F. The LCA weight of two leaves is exactly M; for the same leaf it is the leaf's F.
- **DSU implementation:** One parent array serves both DSU and active flag: inactive cells have -1, active cells have a nonnegative parent. Maintain cur, the current component root of the activating cell, so only the neighbor needs find. Path halving is used. A separate size array is unnecessary because every merge creates a new root; path compression is sufficient for the roughly 500k edge unions.
- **Tree size:** N leaves plus N-1 internal nodes, at most 499999. The grid is connected because all heights are at least 1, so the final root contains all leaves.
- **LCA preprocessing:** Build an iterative Euler tour of the binary reconstruction tree using a stack of encoded node/state values. The tour length is 2*nodes-1. While generating the tour, write nodes directly into the leaves of a segment tree to avoid storing a separate Euler array. Store first occurrence only for leaf nodes because queries only use leaves, and store depth for all nodes.
- **Segment tree RMQ:** The segment tree stores the node with minimum depth in each Euler interval. Unused segment-tree leaves are set to a dummy node with depth INF so they never win. LCA of two leaves is the RMQ result over [first[u], first[v]].
- **Query handling:** Convert 1-based coordinates to row-major leaf indices. If the leaves are equal, M is the leaf weight. Otherwise run the iterative segment-tree RMQ. Answer is max(abs(y-z), y+z-2M).
- **Complexities:** Sorting O(N log N), construction O(N alpha) in practice, Euler and segment tree O(N), each query O(log N). N<=250000, Q<=200000.
- **Edge cases:** N=1, one-dimensional grids, same-block queries, equal heights, and M larger than one or both floors making the second term negative are handled.
