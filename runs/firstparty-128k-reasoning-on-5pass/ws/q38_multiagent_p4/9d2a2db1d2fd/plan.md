A route's stair cost is determined by the lowest building height m on the sequence of blocks it visits: the optimum for that block path is max(|y-z|, y+z-2m). Therefore each query reduces to finding M, the maximum over all block paths of the minimum building height (a widest-path value). Build a Kruskal reconstruction tree by activating blocks in decreasing height and unioning active neighbors; each successful union creates a node weighted by the current height. In this tree, M for two blocks is the weight of their LCA (and for the same block it is the leaf's height). Use binary lifting on the reconstruction tree to answer LCA queries, then apply the formula.
