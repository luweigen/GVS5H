- **Endpoint model:** For each cell use bits for top, left, right, and bottom endpoints. Type A has top xor bottom = 1 and left xor right = 1. Type B has top = bottom, left = right, and top xor left = 1. Torus no-dead-end means right endpoint of (i,j) equals left endpoint of (i,j+1), and bottom endpoint of (i,j) equals top endpoint of (i+1,j).
- **Edge variables:** Let H_{i,j} be the shared horizontal bit at the left edge of (i,j), and V_{i,j} the shared vertical bit at the top edge of (i,j). Moving right, an A tile flips the horizontal bit and a B tile does not. Moving down, an A tile flips the vertical bit and a B tile does not.
- **Free bits:** If all row and column A-counts are even, H_{i,j} = x_i xor row_pref(i,j) and V_{i,j} = y_j xor col_pref(i,j), where x_i is the horizontal bit at column 0 of row i and y_j is the vertical bit at row 0 of column j.
- **Parity conditions:** Wrapping around a row or column requires the xor of flips around the cycle to be 0. Therefore every row and every column must contain an even number of A tiles; otherwise the answer is 0.
- **B equations:** For a B cell, top xor left = 1 gives x_i xor y_j = 1 xor row_pref_left xor col_pref_above. A cells add no equation between x and y.
- **Counting:** The equations are bipartite xor constraints on H row nodes and W column nodes. If consistent, each connected component, including isolated vertices, has one free bit, so the answer is 2^{components} modulo 998244353.
- **Indexing fix:** Column nodes must be H+j, not W+j. The total node count is H+W, so base = H makes row nodes 0..H-1 and column nodes H..H+W-1. With this fix the sample cases produce 2, 0, 2.
- **Union-find details:** parity[v] stores value[v] xor value[parent[v]]. find returns the root and the xor from v to root using a two-pass iterative compression. For equation u xor v = w, if roots differ, attach one root to the other with parity pu xor pv xor w; if roots are the same, check pu xor pv == w.
- **Implementation:** Read all tokens with sys.stdin.buffer.read().split(). For each case allocate parent, size, parity, and col_pref. Scan rows; an odd-A row marks bad. For B cells, union row i with column H+j using the computed label. After all rows, any nonzero col_pref marks bad. Output 0 if bad, otherwise pow(2, comps, mod).
