Model each tile orientation by binary variables on the four edge midpoints; no dead ends means opposite cells agree on each shared edge. For a cell, type A forces top/bottom and left/right edge variables to differ, while type B forces them to be equal and top/left to differ. The A-imposed differences around each torus column and row require every row and column to contain an even number of A tiles, otherwise the answer is 0. When this holds, vertical edge variables are determined by one free bit per column and horizontal edge variables by one free bit per row; each B cell then gives one XOR equation between its row bit and column bit. Count solutions of these bipartite XOR equations with a parity DSU: if inconsistent output 0, otherwise each connected component of the B-cell row-column graph contributes a factor 2, so the answer is 2^{components} modulo 998244353.
