Binary search the answer X (feasibility is monotone) and make feasibility O(n). For X>0, define d_i=(X-1)//points[i], the extra visits needed at i beyond the first visit. For a walk ending at f, the shortest all-visiting skeleton costs 2n-1-f moves and already gives one free extra visit to each vertex in [f,n-2]; remaining extra visits are covered by edge bounces, each costing 2 moves and covering its two endpoints. For fixed f, the minimum bounce count is the maximum-weight independent set on a path with weights p_i(f)=d_i if f>i (and p_{n-1}=d_{n-1}), otherwise max(0,d_i-1). Compute all f in one pass by precomputing suffix DP for the low weights and sweeping a prefix DP for the high weights, combining the two sides with the no-adjacent-selection constraint. Feasible iff min_f (2n-1-f + 2*bounces_f) <= m; binary search up to m*min(points).
