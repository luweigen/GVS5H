- **Potential formulation:** For target distance \(D\), minimize the number of selected edges subject to every path from 1 to \(N\) containing at least \(D\) selected edges. This is equivalent to choosing labels \(x_v\in[0,D]\), with \(x_1=0\), \(x_N=D\), and \(x_v\le x_u+1\) for every edge \(u\to v\). An edge is selected exactly when \(x_v=x_u+1\).
- **Equivalence:** Given a selected set with shortest weighted distance at least \(D\), use truncated shortest distances from vertex 1 as labels. Unselected edges cannot increase labels, selected edges can increase by at most one. Conversely, selecting all label-increasing edges ensures every 1-to-\(N\) path has at least \(D\) selected edges by telescoping label changes.
- **Threshold variables:** Use \(y_{v,i}=[x_v\ge i]\) for \(1\le i\le D\). A source-side cut node means threshold value 1. Nesting is enforced by infinite arcs \((v,i+1)\to(v,i)\).
- **Edge constraint arcs:** The label constraint \(x_v\le x_u+1\) becomes infinite arcs \((v,i)\to(u,i-1)\) for every \(i=2,\dots,D\). Any cut crossing such an arc would have \(x_v\ge i\) but \(x_u<i-1\), violating the constraint.
- **Finite cost arcs:** For each original directed edge \(u\to v\) and every threshold \(i\), add capacity-1 arc \((v,i)\to(u,i)\). Its cut contribution is \(\sum_i[y_{v,i}=1,y_{u,i}=0]=\max(x_v-x_u,0)\). Since constraint arcs guarantee \(x_v-x_u\le1\), this is exactly one iff the edge rises by one, otherwise zero. Parallel original edges must each add their own arcs.
- **Terminal constraints:** Enforce \(x_1=0\) using infinite arcs \((1,i)\to T\), and enforce \(x_N=D\) using infinite arcs \(S\to(N,i)\).
- **Exact K:** If the minimum required number is at most K, extra edges can be selected arbitrarily; increasing edge weights never lowers a shortest-path distance. Thus feasibility is min-cut value at most K.
- **Bounds and complexity:** The answer is at most \(N-1\), since a shortest path may be simple. Binary search over \(D\in[0,N-1]\). Each flow graph has \(ND+2\le902\) vertices and \(O(MD+ND)\) arcs.
