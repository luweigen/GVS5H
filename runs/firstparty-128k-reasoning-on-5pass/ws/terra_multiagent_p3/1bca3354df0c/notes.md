- **Bipartite components:** Every connected component remains bipartite. A legal internal edge joins opposite color classes. An edge between distinct components is always legal and merges them, choosing one of the two possible orientations of either component.
- **Fixed-parity positions:** If `N` is odd, every final complete bipartite graph has an even number of edges. If every initial component has even size, flipping any component preserves the parity of either global color class. Hence in both cases the parity of the final edge count is invariant.
- **Fixed winner calculation:** Build arbitrary BFS bipartitions and let `S` be the total number assigned color 0. The final edge parity is `(S mod 2) * ((N-S) mod 2)`. Aoki wins iff this differs from `M mod 2`.
- **Why the previous flexible rule was false:** For `N=4, M=0`, the old rule said Aoki. But Aoki must first create an edge; Takahashi creates a disjoint edge. The remaining legal play necessarily ends at `K_{2,2}` after four total moves, so Takahashi wins.
- **Flexible case:** This occurs exactly when `N` is even and at least one component has odd order. The number `O` of odd-order components is even. Merging two odd components is the operation that eventually fixes the parity of the global bipartition; merging any other pair only rearranges the control state.
- **Flexible winner rule:** Aoki wins exactly when `O == 2` or the total number of connected components is odd. Otherwise Takahashi wins. Equivalently, for `O >= 4`, Aoki wins iff the number of even-order components is odd.
- **Examples:** Empty `N=4` has `O=4`, component count 4, so Takahashi. A path on three vertices plus one isolate has `O=2`, so Aoki; Aoki joins the isolate to the middle vertex and immediately obtains terminal `K_{1,3}`.
- **Implementation:** BFS finds component sizes, arbitrary colors, total color-0 count, component count, and odd component count in `O(N+M)` time and `O(N+M)` memory.
