Use the sorted order to greedily match the smallest available mochi as the top with the earliest sufficiently large unused mochi as the bottom. For a candidate number of pairs \(K\), it is enough to check whether each of the first \(K\) mochi can be paired with one of the last \(K\) mochi, matching in order. This feasibility condition is monotonic in \(K\), so binary search can find the maximum feasible value efficiently. Alternatively, a two-pointer greedy scan directly computes the same maximum in linear time.
