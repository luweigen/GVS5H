- **Algorithm:** Use a linear two-pointer greedy method. Set `top = 0` and `bottom = (N + 1) // 2`. Scan candidate bottom mochi from left to right. Whenever `2 * A[top] <= A[bottom]`, pair them and increment `top` and the answer.
- **Correctness:** The first half of the sorted mochi are the only possible candidates needed as tops for a maximum matching, while starting bottoms at `(N+1)//2` guarantees no overlap between a matched top and bottom. For each current smallest unmatched top, the first bottom that can support it is the best choice: using a larger bottom instead cannot enable more pairs, while leaving larger bottoms available is never worse. If a bottom cannot support the current smallest top, it cannot support any later top because later tops are at least as large, so it is safe to discard that bottom. Thus every greedy match is safe and the final count is maximum.
- **Complexity:** The two pointers only move forward, so time complexity is `O(N)` and extra space beyond input storage is `O(1)`.
- **Edge cases:** For odd `N`, `bottom = (N+1)//2` leaves at least one unpaired middle mochi and prevents overlap. Equality is valid and handled by `<=`. Multiplication is safe because `2 * A_i <= 2 * 10^9`, well within Python integer limits. If no valid pair exists, the output remains zero.
