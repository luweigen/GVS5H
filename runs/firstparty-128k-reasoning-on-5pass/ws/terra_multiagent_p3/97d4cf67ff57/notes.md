- **Model:** Any selected alkane is a connected subtree of the input tree. Edges not selected do not contribute to degrees, so a selected vertex may be a leaf even if its original degree is large.
- **Directed branch DP:** For every directed edge `v -> u`, define a message as the maximum number of selected vertices in the component on `v`'s side when edge `(v,u)` is selected. Then `v` has one selected edge toward `u`, so it is either a leaf with value `1`, or degree `4` with exactly three selected branches among its other neighbors.
- **Transition:** A directed message is `1 + sum(best three incoming messages from neighbors other than destination)` if at least three such neighbors exist; otherwise it is `1`.
- **Final answer:** Select any vertex `v` as a degree-4 vertex. It needs exactly four selected incident branches, so its best alkane size is `1 + sum(best four incoming directed messages)`. The maximum over all vertices is the answer. If no vertex has four usable neighboring branches, output `-1`.
- **Why rerooting is needed:** A bottom-up DP alone is insufficient when the best alkane extends toward the fixed root. For example, a degree-4 star center may have one of its selected leaves as its parent in an arbitrary root. Directed messages in both directions handle all possible branch orientations.
- **Implementation:** Root at vertex `0` iteratively. Compute child-to-parent messages in reverse traversal order, then parent-to-child messages in traversal order. At each vertex, sort incoming messages; only the largest four are needed.
- **Complexity:** Sorting incident-message lists costs `O(sum(deg(v) log deg(v)))`, bounded by `O(N log N)`. Memory use is `O(N)`.
