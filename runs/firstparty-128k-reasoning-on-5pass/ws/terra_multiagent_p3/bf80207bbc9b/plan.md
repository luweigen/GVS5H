Model the chosen column flips as a bitmask of length \(W\); once this mask is fixed, each row can independently either remain unchanged or be flipped. For a row bitmask \(r\), its number of ones after column flips is \(\mathrm{popcount}(r \oplus m)\), and an optional row flip changes this to \(W-\mathrm{popcount}(r \oplus m)\). Therefore, enumerate all \(2^W\) column masks and sum the smaller of these two values for every row, taking the global minimum. This is feasible because \(W \leq 18\), with complexity \(O(H \cdot 2^W)\).
