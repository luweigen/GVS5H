Reformulate each pair by choosing which of the three coordinates attains its price: if a pair is charged to coordinate \(d\), its contribution is the sum of that coordinate over its two cakes. Thus, we need select exactly \(2K\) cakes, assign each selected cake one of three coordinate labels, and require each label to be used an even number of times; cakes with the same label can then be paired arbitrarily. Start from each cake’s best coordinate value, then handle the three parity constraints through a constant-size DP / correction over a small set of potentially changed cakes near the selection boundary. Prove that only a constant number of cakes outside the top \(2K\) baseline candidates need consideration, enabling \(O(N \log N)\) per test case.
