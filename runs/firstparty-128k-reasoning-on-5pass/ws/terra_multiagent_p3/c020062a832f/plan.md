Compute the inversion count for k=0 using a Fenwick tree over values 0 to M-1. When increasing k by 1, exactly the elements currently equal to M-1 wrap to 0, while all other relative comparisons remain unchanged. For each occurrence of the wrapping value, calculate its inversion contribution before and after wrapping based on elements before and after it, and update the total inversion count. Process values in descending order of their original value, since value v wraps when k reaches M-v.
