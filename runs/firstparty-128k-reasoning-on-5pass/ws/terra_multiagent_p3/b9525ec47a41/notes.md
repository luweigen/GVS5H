- **Orientation/forest correspondence:** The number of distinct indegree sequences obtainable by orienting an undirected graph equals its number of forests (edge subsets containing no cycle). This is the standard graphical-zonotope/Tutte-polynomial fact: the indegree vectors of orientations are the lattice points of a translate of the graphical zonotope, whose count is \(T_G(2,1)\), also the number of forests. Thus this task reduces to counting forests of the given graph.
- **Direct forest DP:** Process the rim as a path from vertex 0 through vertex \(N-1\), postponing the closing edge \((N-1,0)\). A partial forest only needs connectivity information among three retained objects: hub \(N\), vertex 0, and the current rim vertex. Their connectivity partition has only five possible states.
- **Transition:** When adding rim vertex \(i\), choose whether its allowed spoke exists in the forest and whether rim edge \((i-1,i)\) exists. Insert each selected edge only if its endpoints are currently disconnected; otherwise it creates a cycle and is rejected. Then discard the previous current vertex, retaining hub, vertex 0, and the new vertex.
- **Closure:** At the end, omitting edge \((N-1,0)\) is always valid. Including it is valid exactly when vertex 0 and vertex \(N-1\) are in different components. This automatically handles all zero-, one-, and multiple-spoke cases without special formulas.
- **Complexity:** There are five states and at most four choices per transition, so time is \(O(N)\), memory is \(O(1)\), and all counts are modulo 998244353.
