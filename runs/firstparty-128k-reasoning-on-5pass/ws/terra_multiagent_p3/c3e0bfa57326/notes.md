- **Forest representation:** Parse the sequence into an ordered rooted forest. Each matching parenthesis pair is a node, whose children are the primitive balanced blocks immediately inside it. Add a virtual root whose children are the top-level primitive blocks.
- **Effect of one operation:** Any valid contiguous substring starts and ends at boundaries between siblings under one common parent, so it is a consecutive forest segment \(T_l,\dots,T_r\). Reverse-and-swap transforms it into \(M(T_r),\dots,M(T_l)\), where \(M\) is recursive mirror: it reverses each node’s child order.
- **Pure sibling reversal:** After applying an operation to a consecutive sibling segment, apply the operation once more to every complete subtree currently in that segment. Each \(M(T_i)\) becomes \(T_i\), while their order remains reversed. Thus a pure reversal of any consecutive sibling interval is achievable without changing any descendant interiors.
- **Arbitrary permutations:** Reversals of consecutive intervals generate the full symmetric group, since an adjacent swap is a reversal of an interval of length two. Therefore children of every node can be permuted arbitrarily. These transformations can be performed independently at different nodes after arranging the relevant parent’s children.
- **No additional invariant changes:** Every operation only mirrors a consecutive forest segment, so it never changes the underlying unordered rooted forest. Together with the constructive sibling-permutation argument, reachable strings are exactly all plane embeddings of the original unordered rooted forest.
- **Counting formula:** For a node with \(k\) children, grouped by unordered subtree type with multiplicities \(m_t\), the number of reachable encodings is
  \[
  k! \cdot \prod_t (m_t!)^{-1} \cdot \prod_{\text{children }u} \mathrm{ways}(u).
  \]
  The multinomial chooses the order of child structural types. Each occurrence independently chooses one reachable plane encoding of its subtree. Distinct unordered types cannot produce the same parenthesis encoding.
- **Canonical types:** Assign each node a global deterministic type ID from the sorted multiset of its children’s type IDs. Equal unordered rooted trees then receive the same ID. Reverse node creation order is postorder because every descendant is created after its parent.
- **Virtual root:** Apply the identical formula to the virtual root; its value is the requested count for the whole top-level forest.
- **Complexity:** Parsing is \(O(N)\). Sorting child-type lists across all nodes is \(O(N \log N)\) in the worst case, with \(O(N)\) memory.
- **Small exhaustive validation:** For all five Dyck strings with three pairs, orbit sizes are: `((())): 1`, `(()()): 1`, `(())(): 2`, `()(()) : 2`, `()()(): 1`. The two strings of size 2 form the same orbit and match the unordered-forest formula; all others are fixed because every sibling set contains only identical subtree types or has size at most one.
