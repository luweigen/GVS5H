Rewrite each subarray sum as a difference of prefix sums: \((S_r-S_{l-1})^K\). Expand with the binomial theorem, so for every right endpoint \(r\), its contribution can be computed from maintained sums of powers \(S_j^t\) over all previous prefix sums \(j<r\). Since \(K\le 10\), updating these \(K+1\) aggregates and evaluating each contribution costs \(O(K^2)\) or better per position, which is easily fast enough. Perform all arithmetic modulo \(998244353\).
