- **Approach:** The implemented method is square-root decomposition by queried `X`. A query is decomposed into a fixed A-prefix ending at the start of its block, plus at most `BLOCK=400` remaining A elements.
- **Base contribution:** For each nonempty block, maintain the sorted multiset of A values in the fixed prefix. Sweep B in value order to compute `sum(abs(a-B_j))` for every needed B position, then accumulate in original B-index order for each query Y.
- **Short suffix contribution:** Build a persistent segment tree for B prefixes over compressed values. For one A value and B prefix Y, obtain count and sum of B values at most A, yielding the absolute-distance sum in `O(log N)`.
- **Persistent memory:** Four compact `array` buffers store child pointers, counts, and sums. The tree has `O(N log N)` nodes; at maximum size this is substantially less memory than Python node objects.
- **Complexity:** Base sweeps and merges are about `O(N^2 / BLOCK)` across all populated blocks. Extra terms are `O(K * BLOCK * log N)`. With `BLOCK=400`, the worst-case extra part is roughly 68 million tree-level iterations.
- **Benchmark assessment:** The main expected maximum-case runtime bottleneck is not persistent-tree construction but the nested short-suffix loop: up to `K * BLOCK` persistent range queries. A direct value divide-and-conquer does not solve this problem efficiently because every prefix rectangle query branches into both value children, causing query replication across many nodes rather than only logarithmic participation.
- **Alternative comparison:** A 2D Mo traversal would typically require about `O(N sqrt(K))` rectangle-boundary moves, each requiring value-structure work, and is expected to have a larger Python constant factor. The current block/persistent approach remains the more practical offline algorithm for these constraints.
- **Correctness:** The base and suffix A ranges are disjoint and cover exactly `A[0:X]`. Each distance query uses the identity `a*c-s + (S-s)-a*(Y-c)` where `c,s` are count and sum of B values at most `a`.
