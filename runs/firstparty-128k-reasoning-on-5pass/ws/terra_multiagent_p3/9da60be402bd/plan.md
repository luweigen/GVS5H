Model each state as an ordered pair of vertices `(u, v)`, representing the current unmatched middle portion of a palindrome path from `u` to `v`. Initialize states where the palindrome center is empty (`u == v`, length 0) or a single edge (`u -> v`, length 1). Run multi-source BFS backwards: from state `(u, v)`, add matching-labeled edges `x -> u` and `v -> y` to obtain state `(x, y)` with distance increased by 2. The first distance assigned to every pair is its shortest palindrome-path length.
