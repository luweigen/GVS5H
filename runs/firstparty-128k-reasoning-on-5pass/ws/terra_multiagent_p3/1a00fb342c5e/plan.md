Model the constraints as an undirected graph where an edge \((u,v)\) requires \(A_u \oplus A_v = z\). For each connected component, assign tentative XOR labels by DFS/BFS from an arbitrary root with label 0, checking every edge for consistency. Every valid assignment in a component is then obtained by XORing all tentative labels with one common value \(t\). Minimize the component sum independently, choosing each bit of \(t\) based on whether fewer tentative labels have that bit set or unset.
