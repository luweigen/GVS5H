Model visibility of each building from observer height \(h\) using the slope of sight lines from \((0,h)\). A building is visible iff some point on it has a slope exceeding all blocking buildings before it; because the building is vertical, its top point is sufficient to characterize this condition. Derive, for every building, the threshold observer height at which it becomes visible, then take the largest threshold among buildings. If every building is already visible at height 0, output \(-1\).
