- **Geometric threshold:** For a target building \(i\), aiming at its top is optimal. It is visible from \((0,h)\) iff its top sight-line slope is strictly greater than every earlier top sight-line slope. Against building \(j<i\), this is equivalent to \(h > (X_iH_j-X_jH_i)/(X_i-X_j)\).
- **Global objective:** The answer is the maximum threshold over all ordered pairs \(j<i\). Equality remains blocked because a line segment touching a previous building intersects it, so the maximum threshold itself is a height from which not all buildings are visible.
- **Slope formulation:** For fixed target \(i\), the pair threshold is \(H_i-X_i s_{ji}\), where \(s_{ji}=(H_i-H_j)/(X_i-X_j)\). Since \(X_i>0\), maximizing the threshold is equivalent to minimizing the slope from a previous point \(j\) to point \(i\).
- **Hull:** Only vertices of the lower convex hull of previous building-top points can minimize this slope. Points are inserted in increasing \(X\), so the lower hull is maintained with increasing edge slopes, deleting the penultimate point while the new edge slope is no larger.
- **Monotone tangent pointer:** For each new target, the minimum-slope hull vertex is found by advancing a pointer while the next hull vertex gives no larger slope. The pointer never moves left except when its current hull vertex is deleted during insertion. Every pointer advance and hull deletion is amortized \(O(1)\), yielding total \(O(N)\).
- **Exact arithmetic:** All slope and hull comparisons use integer cross multiplication. The best threshold is stored as an exact numerator/denominator pair and compared by cross multiplication. Python integers safely handle all products.
- **Zero case:** At height zero, strict visibility of all buildings holds exactly when the maximum threshold is negative. Then print integer `-1`; if it is zero, print `0`, since equality blocks visibility.
- **Complexity:** \(O(N)\) time and \(O(N)\) memory.
