- **Cut-flow counterexample:** Mandatory net crossings at each fixed boundary do not determine the cost. For permutation `321`, reduced sorting words are `s1 s2 s1` with cost `1+2+1=4` and `s2 s1 s2` with cost `2+1+2=5`. At boundary 1, the mandatory net right-to-left flow is one, but `s1 s2 s1` crosses that boundary twice. Thus even inversion-only optimal sequences need not cross every boundary only the mandatory number of times.
- **Optimal strategy:** Because edge costs increase from left to right, use ordinary left-to-right bubble sorting: repeatedly scan edges from left to right and swap adjacent inversions. Equivalently, process values `x=N,N-1,...,1`; in the current sequence of values at most `x`, move `x` right to position `x`.
- **Position formula:** Let `c_x` be the number of values smaller than `x` that occur before `x` in the original permutation. Before value `x` is moved in the descending-value interpretation, its current position is `c_x+1`. It crosses edges `c_x+1, c_x+2, ..., x-1`, costing `T(x-1)-T(c_x)`, where `T(k)=k(k+1)/2`.
- **Answer formula:** The minimum is `sum_x (T(x-1) - T(c_x))`.
- **Lower-bound potential:** Define `F(P)=sum_x (T(x-1)-T(c_x))` for any current permutation. It is zero for the sorted permutation. If an inverted adjacent pair is swapped at edge `i`, only the larger value's `c_x` increases by one, and `F` decreases by at most `i`. If an ordered pair is swapped, `F` increases, so again its decrease is at most `i`. Therefore every sorting sequence has cost at least initial `F`. Bubble sorting attains equality: when it moves a value `x` right, every element before it is smaller, so each swap at edge `i` decreases `F` exactly by `i`.
- **Implementation:** Scan the original permutation left to right with a Fenwick tree over values. For each value `x`, query the count of already seen values `<x`, yielding `c_x`, add the formula contribution, then insert `x`. Complexity is `O(N log N)` time and `O(N)` memory.
- **Numeric range:** The answer can be `Theta(N^3)`, approximately `N^3/6`, so Python integers are appropriate; in fixed-width languages use 64-bit integers.
