Model each state as `(vertex, parity)`, where parity indicates whether the graph has been reversed an even or odd number of times. From each state, moving along an available edge costs `1`, while toggling parity at the same vertex costs `X`. Build this implicit graph with `2N` states and run Dijkstra’s algorithm from `(1, 0)`. The answer is the minimum distance to either `(N, 0)` or `(N, 1)`.
