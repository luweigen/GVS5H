For each divisor \(d\), count how many elements of \(A\) are divisible by \(d\). A value \(d\) can be the answer for an element \(A_i\) exactly when at least \(K\) array elements are divisible by \(d\) and \(d\mid A_i\). Compute divisibility counts with a sieve-style loop over multiples, then process valid divisors in increasing order and assign them to all their multiples so the final stored value is the maximum valid divisor. This runs in \(O(M \log M)\)-like harmonic complexity, where \(M=\max A_i\le 10^6\), and uses linear memory.
