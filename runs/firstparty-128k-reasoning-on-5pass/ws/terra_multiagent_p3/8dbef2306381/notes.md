- **State representation:** After processing square `p`, bit `k` of `state` indicates whether square `p-k` is reachable, for `0 <= k < B`. For a safe next square, it is reachable iff some bit from `A-1` through `B-1` is set. Shift the state left and insert that result at bit 0.
- **Position indexing:** Initially square 1 is already processed and reachable, so `pos = 1`, `state = 1`. Before a bad interval `[L, R]`, process only safe squares `pos+1` through `L-1`, whose count is `L-pos-1`. After processing the bad interval, `pos = R`. The final safe suffix has length `N-pos`.
- **Bad runs:** Every bad destination is unreachable. Advancing through `d` bad positions shifts the rolling state left by `d`; it becomes zero if `d >= B`.
- **Fixed jump case:** If `A == B`, safe updates rotate the `A` state bits, so a safe run can be reduced modulo `A`.
- **Variable jump saturation:** For `A < B`, sums of exactly `k` jumps cover `[kA, kB]`. Let `K = ceil((A-1)/(B-A))`; intervals for consecutive `k >= K` overlap or touch, so every distance at least `K*A` is representable.
- **Exact long safe-run criterion:** Any reachability that can enter a safe run does so within its first `B` processed squares, because every jump has length at most `B`. Once a reachable square is inside the uninterrupted safe run, all squares at distance at least `K*A` after it are reachable. After another `B` positions, the whole rolling window is reachable. Therefore after `2B + K*A` safe updates, the state is exactly either zero or the all-ones mask. This makes the bulk transition exact rather than assuming arbitrary nonzero states are immediately saturated.
- **Complexity:** Each interval uses `O(B + K*A)` operations, bounded by a small constant since `B <= 20`; total time is `O(M * B^2)` in practice and memory is `O(1)`.
- **Sample 3:** The corrected position indexing and exact saturation criterion produce `Yes`.
