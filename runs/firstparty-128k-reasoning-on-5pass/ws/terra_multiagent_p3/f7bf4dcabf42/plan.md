Represent the effect of a partially built length-\(M\) string by its LCS DP row against every prefix of \(S\). Each row is a nondecreasing sequence starting at 0 with adjacent differences in \(\{0,1\}\), so there are at most \(2^N\) possible states. For each of the \(M\) appended characters, transition every reachable row using the standard LCS recurrence, aggregating counts modulo 998244353. After exactly \(M\) steps, group state counts by the final DP value for the full prefix of \(S\), which is the LCS length.
