- **Residual DP state:** Root the tree arbitrarily. For a vertex subtree, all vertices can be partitioned into complete paths of exactly `K` vertices except possibly one unfinished path segment that must use the edge to the parent. If such a segment exists, it necessarily contains the subtree root vertex and has that vertex as an endpoint.
- **Why only one residual exists:** A subtree has exactly one edge to its parent. A simple path can cross that cut through only this edge, so at most one path can remain unfinished toward the parent.
- **Residual size:** Store `0` if the subtree is fully partitioned, otherwise store the number of vertices in its unfinished segment, always in `[1, K-1]`. A segment reaching `K` vertices is immediately a completed path and is stored as `0`.
- **Modulo property:** Conditional on a subtree being feasible, its residual is forced by subtree size modulo `K`: residual `0` for remainder `0`, otherwise that remainder. This follows because completed paths use multiples of `K` vertices. However, modulo alone does not prove feasibility; the local path-degree and chain-merging transitions must still be checked.
- **Transition with zero nonzero child residuals:** The current vertex has no unfinished child chain to attach to. For `K > 1`, it starts a new unfinished segment, so its residual is `1`.
- **Transition with one nonzero child residual `a`:** Attach the current vertex to that child segment. If `a + 1 == K`, it completes one path and the residual becomes `0`; otherwise it becomes `a + 1` and is passed upward.
- **Transition with two nonzero child residuals `a, b`:** Both must be joined through the current vertex, because neither can be ignored and propagating their joined result upward would give the current vertex path-degree three. Thus this is valid exactly when `a + b + 1 == K`, yielding residual `0`.
- **Three or more nonzero child residuals:** Impossible, because a vertex in a path has degree at most two.
- **Root condition:** The root has no parent, so it must finish with residual `0`. The total number of vertices is divisible by `K`, but this explicit check is still required by the DP.
- **Complexity:** Iterative rooting plus reverse-order DP is `O(NK)` time and `O(NK)` memory. Iteration avoids recursion-depth failure on a path-shaped tree.
- **Special case:** For `K = 1`, every vertex alone is a valid path, so the answer is always `Yes`.
