Build a trie containing all words, where each node stores how many words pass through it. A prefix of length `d` is valid for selecting `k` strings exactly when some trie node at depth `d` has count at least `k`. Removing one word only decreases counts along that word’s trie path, so only nodes whose count is exactly `k` can stop being valid. Maintain the globally deepest valid trie depth and, for each removed word, temporarily account for affected depth-`k` nodes to determine the best remaining depth efficiently.
