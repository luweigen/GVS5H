- **Chordless-path bound:** Every chordless path in an interval-disjointness graph has at most three edges. If a chordless path had five consecutive vertices \(v_1,\dots,v_5\), then in the interval-intersection graph the induced subgraph on those vertices is the complement of \(P_5\). Vertices \(v_1,v_4,v_2,v_5\) form an induced 4-cycle there: its four cycle edges correspond to nonconsecutive pairs of the path, while diagonals \(v_1v_2\) and \(v_4v_5\) correspond to consecutive disjoint pairs. This is impossible because interval intersection graphs are chordal. The bound is tight: a four-vertex induced path can occur.
- **Shortest paths:** Since every vertex weight is positive, a minimum-weight path is chordless: if a path has an edge between nonconsecutive path vertices, shortcutting along that edge removes one or more positive-weight vertices. Therefore every answer uses 1, 2, or 3 edges.
- **Direct and two-edge paths:** If endpoint intervals are disjoint, the direct edge is optimal. Otherwise they overlap. A common disjoint intermediate interval must either satisfy \(R_x<\min(L_s,L_t)\) or \(L_x>\max(R_s,R_t)\). These minima are answered by a prefix minimum indexed by right endpoint and a suffix minimum indexed by left endpoint.
- **Three-edge characterization:** Let a chordless path be \(s-x-y-t\), where endpoints overlap. If \(x\) is left of \(y\), then \(x\) must be right of and disjoint from \(s\)'s left side while overlapping \(t\), and \(y\) must be left of and disjoint from \(t\)'s right side while overlapping \(s\). This simplifies exactly to \(L_t\le R_x<L_s\) and \(R_t<L_y\le R_s\). Thus this orientation exists only when \(L_s>L_t\) and \(R_s>R_t\), and its optimum is the sum of independent range minima over right endpoints and left endpoints. The mirror orientation exists exactly when \(L_s<L_t\) and \(R_s<R_t\), with \(L_s\le R_y<L_t\) and \(R_s<L_x\le R_t\).
- **Data structures and complexity:** Static segment trees store minimum weight for every left endpoint and every right endpoint, supporting the two range minima needed for a three-edge candidate in \(O(\log N)\). Prefix/suffix arrays answer two-edge candidates in \(O(1)\). Total complexity is \(O((N+Q)\log N)\), memory \(O(N)\).
