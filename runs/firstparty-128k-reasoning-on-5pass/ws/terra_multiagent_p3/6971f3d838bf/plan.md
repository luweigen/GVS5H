Model the deletion choice as a modified Kadane DP: for each possible value, track the best subarray sum ending at the current position if all occurrences of that value are skipped. Since only values that have appeared can be deletion candidates, maintain these states efficiently in a hash map while scanning once. Also track the ordinary Kadane result for the “no operation” option, and take the maximum over all states.
