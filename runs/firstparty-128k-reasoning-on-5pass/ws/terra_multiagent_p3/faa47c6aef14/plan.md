Model each operation as forwarding every currently present red token along permutation edge \(i \to P_i\) and every blue token along \(i \to Q_i\). A box must be operated whenever it contains balls and is not \(X\); thus the problem is to find the smallest closed set of operated boxes that can route every initially occupied box to \(X\), while respecting dependencies caused by both colors. Analyze reachability and forced operations using the reverse graphs of \(P\) and \(Q\), then derive a linear-time propagation/topological or SCC-based solution that detects impossible cycles away from \(X\). Prove that every forced box needs exactly one operation in an optimal strategy, allowing the answer to be its count.
