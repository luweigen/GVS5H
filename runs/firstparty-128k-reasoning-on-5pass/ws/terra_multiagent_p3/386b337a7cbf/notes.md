- **Overflow state:** The corrected DP uses index `limit + 1` as an overflow-product bucket. All products greater than `limit` are merged there. This is valid because multiplication by positive values keeps them above the limit, while multiplication by zero sends every such state to exact product zero.
- **DP state:** `even[p]` and `odd[p]` are bitsets of reachable alternating sums for non-empty subsequences with exact product `p` and even/odd selected length. The overflow bucket is included in both arrays.
- **Alternating transitions:** Appending positive `x` to an even-length subsequence adds `x` and produces odd length; appending to odd length subtracts `x` and produces even length. Bitset shifts implement these transitions.
- **Zero transitions:** Appending zero leaves alternating sum unchanged, flips parity, and changes any prior product to zero. The singleton `[0]` is inserted into the odd-length, zero-product state.
- **Target zero and ones:** Non-empty handling is preserved through explicit singleton insertion. Values of one correctly preserve product while flipping parity, because each iteration reads only the previous DP layer and writes into copied next layers.
- **Complexity:** There are `limit + 2` product buckets. Each positive number performs `O(limit)` bitset operations plus one overflow transition; each zero performs `O(limit)` bitset OR operations. Bitsets span at most `2*sum(nums)+1 <= 3601` positions.
