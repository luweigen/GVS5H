Use dynamic programming along the four diagonal directions to precompute how far an alternating `2,0,2,0,...` suffix can continue from every cell, with parity determined by the expected next value. Then, for every possible starting `1` and initial diagonal direction, extend along that diagonal while considering either no turn or one clockwise turn. At each possible turning point, combine the prefix length before the turn with the precomputed valid continuation length in the clockwise direction. This yields an \(O(nm)\) or \(O(4nm)\) approach suitable for a 500×500 grid.
