- **Cartesian tree:** Use a maximum Cartesian tree with ties broken toward the left: while building with a monotone stack, pop only strictly smaller values. Thus an equal value on the right becomes a right descendant, while every left child has strictly smaller value than its parent.
- **Subtree interval property:** Every Cartesian subtree is a contiguous interval of the original row. Its root is adjacent to the exterior only through the parent boundary, after the subtree has been fully consumed.
- **Initial completion characterization:** Starting at Cartesian node `v`, Takahashi can consume the full subtree of `v` except precisely when `v` has no left child and has an equal-valued right child. In that exceptional case the equal right child is adjacent but cannot be absorbed, and no positive mass is accessible elsewhere first.
- **Why ordinary nodes complete their subtree:** A left child root is strictly smaller and can be absorbed first. If an equal right child exists, consuming a nonempty left subtree makes the size strictly larger than the root value, so the equal child becomes absorbable. If no equal child exists, both child roots are strictly smaller. Once a child root is absorbed, all values in that child subtree are no greater than the original root and can be swept up.
- **Crossing an ancestor:** After fully consuming subtree `v`, its size is `subsum[v]`. It can absorb its parent exactly if `subsum[v] > A[parent[v]]`. After doing so, its size is strictly greater than the parent maximum, hence it can consume all of the parent subtree, including any equal-valued right-side region.
- **Jump characterization:** For a non-exceptional start, repeatedly climb Cartesian parent edges satisfying `subsum[child] > A[parent]`. The final answer is the subtree sum of the highest reached node. An exceptional start cannot cross its parent because parent value is at least its own size, so its answer is just `A[v]`.
- **Equal-value counterexample handled:** For `10 1 5 5`, the leftmost `5` has a left child `1`, so it first gains mass, then can absorb the equal `5`, and finally `10`. The right-child equal-value structure is explicitly represented rather than incorrectly treating equal maxima as freely absorbable.
- **Complexity:** Cartesian construction and subtree sums are `O(N)`. Binary lifting and all answers take `O(N log N)`. Memory is `O(N log N)` using compact signed integer arrays for lifting tables.
