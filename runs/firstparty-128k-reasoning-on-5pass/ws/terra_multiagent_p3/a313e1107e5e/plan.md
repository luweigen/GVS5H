Process queries offline in nondecreasing order of \(R\), incrementally maintaining information for the prefix \(A_1 \dots A_R\). For each processed element, compute its LIS DP value \(dp_i=1+\max dp_j\) over earlier values \(A_j<A_i\), using coordinate compression and a Fenwick tree for prefix maxima. Each element contributes a point \((A_i, dp_i)\); a query \((R,X)\) asks for the maximum DP among inserted elements with value at most \(X\), which can be answered by the same Fenwick tree after all prefix elements are inserted. Strictness is handled by querying only compressed coordinates strictly below \(A_i\) when computing DP.
