Sort A, B, and C in descending order; since all values are positive, the expression is non-increasing when any sorted-array index increases. View each triple of indices `(i,j,k)` as a node in a monotone 3D grid, with its value `A[i]*B[j] + B[j]*C[k] + C[k]*A[i]`. Start from `(0,0,0)` in a max-heap and repeatedly extract the currently largest value, adding its three neighbors obtained by incrementing one index. Use a visited set to avoid inserting the same triple more than once, and the K-th extracted value is the answer.
