- **Core characterization:** For any subarray, the minimum number of erase operations equals the number of connected components of its distinct values on the integer line. Each component is a maximal consecutive interval of values and can be erased in one operation; values separated by a missing integer can never be erased together.
- **Incremental state:** Process right endpoints `r = 1..N`. Let `current_sum` be the sum of `f(l, r-1)` over every start `l` before appending `A[r]`. After updating it, it becomes the sum of `f(l, r)` for `1 <= l <= r`.
- **Affected starts:** Let `x = A[r]` and `p = last[x]`, where `last[v]` is the latest occurrence of value `v` before position `r`. Exactly starts `l` in `[p+1, r]` newly gain value `x`; starts at most `p` already contained `x`, hence their component count is unchanged.
- **Per-subarray change:** On inserting absent value `x`, the component count changes by `+1` and decreases by one for every already-present adjacent value, namely `x-1` and `x+1`. Both neighbors, if present, belong to distinct components because `x` was absent.
- **Counting neighbor presence:** For a neighbor `y`, it is present in old subarray `[l, r-1]` iff `last[y] >= l`. Among affected starts `l in [p+1, r]`, this holds for `max(0, last[y] - p)` starts.
- **Final update formula:** `delta = (r-p) - max(0,last[x-1]-p) - max(0,last[x+1]-p)`. Then do `current_sum += delta`, `answer += current_sum`, and finally `last[x] = r`.
- **Boundary handling:** Arrays of size `N+2` make lookups of `last[0]` and `last[N+1]` safely zero, correctly representing nonexistent neighbors for values `1` and `N`.
- **Complexity:** Time `O(N)`, memory `O(N)`. The answer can be cubic in magnitude, but Python integers safely handle it.
- **Validation:** The formula matches the supplied samples. It can be exhaustively checked on small random arrays by directly enumerating every subarray, forming its distinct-value set, counting consecutive-value components, and comparing the summed brute-force value against this algorithm.
