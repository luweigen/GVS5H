Observe that the minimum operations for a subarray equals the number of connected components of its set of distinct values on the integer line: each maximal consecutive-value block can be erased in one operation, and missing values prevent blocks from being merged. Process right endpoints incrementally, maintaining the total component count over all subarrays ending at the current position. When appending value \(x\), only starting positions after the previous occurrence of \(x\) gain a new copy of \(x\); for each such subarray, the component count changes by \(+1\), minus one for each present neighbor \(x-1\) and \(x+1\). Count these affected starts using last-occurrence positions, yielding an \(O(N)\) solution.
