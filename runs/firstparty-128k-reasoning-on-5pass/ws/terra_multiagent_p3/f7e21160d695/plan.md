Reduce the graph to any minimum spanning tree: for every pair of vertices, their minimum possible bottleneck path value equals the maximum edge weight on their path in the MST. Process MST edges in nondecreasing weight order with DSU, maintaining for each component the net number of unmatched occurrences of A versus B. When two components merge at weight \(w\), unmatched opposite-side endpoints can be paired across the merge, contributing \(w\) per pair; the remaining net balance is stored in the merged component. This greedy cancellation is optimal because any pair first connectable between the two components must have bottleneck cost at least \(w\).
