A 400 number is exactly the square of an integer whose prime factorization contains precisely two distinct primes: if \(N=p^{2a}q^{2b}\), then \(N=(p^a q^b)^2\). Precompute the smallest-prime-factor sieve up to \(\lfloor\sqrt{10^{12}}\rfloor=10^6\), and identify every integer with exactly two distinct prime factors. Store their squares in sorted order. For each query \(A\), use binary search to return the largest stored square not exceeding \(A\).
