Root the tree at node 0 and perform a DFS while maintaining the current root-to-node path, prefix distances, and the latest depth at which each value appeared. For each current node, the valid ancestor boundary is one past the maximum latest occurrence of its value, so the longest valid path ending there starts at the deepest permissible ancestor. Use a segment tree or equivalent structure over path depths to query the minimum depth satisfying the uniqueness boundary, allowing each node to be processed in \(O(\log n)\). Track the maximum distance and, among ties, the minimum node count, while restoring all state during DFS backtracking.
