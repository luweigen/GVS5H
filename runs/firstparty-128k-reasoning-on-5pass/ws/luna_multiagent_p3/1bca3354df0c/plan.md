Characterize legal moves using bipartite connected components: an edge may be added within a component only between opposite color classes, while any edge between distinct components is legal. Derive a game-theoretic invariant or winning criterion that determines the outcome without simulating exponentially many move sequences. Use DSU with parity (or BFS coloring) to obtain each component’s bipartition sizes and combine them according to the derived criterion. Implement the resulting O(N+M) algorithm with 64-bit arithmetic and output the winner.
