Model the final common sum as an integer \(S\). For each fixed \(B_i\), the paired value from \(A\) must be \(S-B_i\), which must be non-negative and must match an available fixed \(A\) value whenever that position is not freely replaceable; values at \(-1\) positions can absorb arbitrary non-negative requirements. Since \(A\) may be rearranged, feasibility reduces to checking whether the fixed \(A\) multiset can be matched against the required values induced by fixed \(B\) entries, while choosing \(S\) large enough. Derive an efficient characterization over possible \(S\), then implement it in \(O(N\log N)\) or \(O(N^2)\), which is sufficient for \(N\le 2000\).
