Build a trie of all words and record, for every word, the trie nodes on its root-to-terminal path. A prefix of length `d` can be shared by at least `k` remaining words exactly when some trie node at depth `d` has count at least `k` after removing the selected word. Maintain the depths of all currently valid trie nodes in a segment tree or ordered structure, and for each removal temporarily invalidate only nodes on that word’s path whose count is exactly `k`; the maximum remaining valid depth is the answer. Restore those nodes before processing the next index, yielding near-linear complexity in the total input length.
