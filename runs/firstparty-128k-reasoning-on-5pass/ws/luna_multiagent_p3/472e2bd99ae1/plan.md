Sort each sequence in descending order so the value \(f(a,b,c)=ab+bc+ca\) is non-increasing when any one index moves forward. Use a max-heap initialized with the tuple of three largest elements, and repeatedly extract the currently largest unprocessed index triple. After extracting a triple, insert its three neighboring triples obtained by incrementing one coordinate, avoiding duplicates with a visited set. The value extracted on the K-th iteration is the K-th largest among all \(N^3\) combinations, and the algorithm runs in \(O((N+K)\log K)\) time.
