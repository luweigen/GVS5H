For a fixed total number of purchased units \(K\), minimize the cost by distributing units among product types according to their prices. Since each product’s marginal costs are \(P_i(2k-1)\), the globally cheapest \(K\) marginal purchases can be selected using a binary search on a marginal-cost threshold. For a threshold \(X\), each product contributes \(\left\lfloor (X/P_i+1)/2 \right\rfloor\) affordable units, capped only by the required total \(K\), and the corresponding total cost can be computed with arithmetic-series formulas. Binary search the largest feasible \(K\), using 128-bit-safe intermediate arithmetic in languages where necessary.
