Process the string from left to right, treating each position as the ending index of a substring. For every modulus \(m \in [1,9]\), maintain how many substrings ending at the previous position have each remainder modulo \(m\); when reading a new digit, update these remainder counts by appending the digit and include the one-digit substring. If the current digit is nonzero \(d\), add the number of newly ending substrings whose remainder modulo \(d\) is zero. This yields \(O(9n)\) time and \(O(9^2)\) space, suitable for \(n \le 10^5\).
