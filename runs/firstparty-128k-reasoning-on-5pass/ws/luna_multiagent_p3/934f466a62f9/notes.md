- **Baseline assignment:** For each cake, assign it to a coordinate attaining its maximum value. Its baseline contribution is `w_i = max(X_i, Y_i, Z_i)`. A pair is valid when both cakes are assigned to the same coordinate; then its price equals the sum of their assigned values.
- **Parity condition:** For a selected set of `2K` cakes, baseline assignments can be paired without reassignment exactly when every coordinate class has even size. The parity state is represented by a three-bit mask.
- **Top subset:** The maximum baseline sum over all `2K` cakes is obtained by selecting the `2K` largest baseline values.
- **No-reassignment correction:** If the top subset has exactly two odd coordinate classes, fix parity by exchanging one selected cake from one odd class with one unselected cake from the other odd class. Both exchange orientations are tested using the minimum selected baseline value and maximum unselected baseline value in the relevant classes.
- **One reassignment:** For every cake and every alternative coordinate, consider assigning that cake to the alternative coordinate. The resulting target parity has two coordinate bits. If the current subset parity differs in two bits, one selected/unselected exchange fixes it; both exchange directions are tested.
- **Subset containing a mandatory cake:** If the reassigned cake is outside the top subset, the best baseline subset containing it replaces the boundary selected cake. Thus the subset changes by at most one removal and one insertion.
- **Extrema maintenance:** Per coordinate, sorted selected and unselected lists are used. Checking the first three entries is sufficient because at most two items are excluded when finding a minimum selected value.
- **Complexity:** Sorting dominates at `O(N log N)` per test case. All reassignment candidates are processed in `O(N)`, and memory usage is `O(N)`. Values fit comfortably in Python integers.
- **Edge cases:** Duplicate cakes are distinguished by indices; ties in a cake’s maximum coordinate are resolved consistently. The method handles `K=1`, `2K=N`, zero coordinates, and identical cakes.
