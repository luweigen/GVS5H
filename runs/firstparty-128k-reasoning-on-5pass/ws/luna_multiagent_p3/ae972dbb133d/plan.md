Represent each cell by four binary edge-incidence variables; neighboring cells must agree on their shared edge. A Type A cell forces each horizontal and vertical pair of sides to differ, while a Type B cell forces each pair to agree and additionally requires exactly one horizontal and one vertical pair to be present. Propagating edge values around rows and columns reduces all choices to one binary variable per row and one per column, with each Type B cell imposing a parity relation between its row and column variables. First verify that the XOR of Type A indicators is even on every row and column; then solve the resulting parity-constraint graph with a weighted DSU, giving \(2^{\text{number of components}}\) if consistent.
