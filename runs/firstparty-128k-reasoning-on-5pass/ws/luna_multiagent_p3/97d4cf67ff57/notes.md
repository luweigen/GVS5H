- **Branch state:** `branch[u]` is the maximum size of a valid selected subtree containing `u` and the edge from `u` to its parent. Since `u` already has one selected incident edge, it must select either zero children (degree 1) or exactly three children (degree 4).
- **Good state:** `good[u]` is the maximum size of such a branch containing at least one degree-4 vertex. The only way to create a good branch at `u` is to select three child branches, making `u` degree 4; hence `good[u] = 1 +` the three largest child `branch` values when at least three children exist.
- **Transitions:** `branch[u] = max(1, 1 + three largest child branch values)`. Only the four largest child values are retained because no transition needs more than four.
- **Top vertex:** A selected subtree’s highest vertex has no selected parent. It can be degree 4 by selecting four child branches, or degree 1 by selecting exactly one child whose branch already contains a degree-4 vertex. These give candidates `1 + four largest branch values` and `1 + max(good[child])`.
- **Correctness:** In a rooted tree, child branches are disjoint and interact only through their parent. Therefore the optimal branches can be independently maximized, and selecting the largest required child values is optimal. Every alkane has a unique highest selected vertex, covered by one of the two top-vertex cases.
- **Complexity:** Iterative rooting avoids recursion depth issues. Each edge is processed constantly many times, so time complexity is `O(N)` and memory complexity is `O(N)`.
- **Edge cases:** A single vertex, or any tree with no possible degree-4 vertex, yields `-1`. A 5-vertex star yields `5`. The DP handles degree-1 top vertices whose child contains the required degree-4 vertex.
