Model the constraints as an undirected graph where each edge requires \(A_x \oplus A_y = Z\). Traverse every connected component, assigning each vertex a relative XOR potential from its root; detect contradictions whenever an already assigned vertex receives a different potential. Every valid assignment in a component is obtained by XORing all potentials with one common offset, so each bit can be optimized independently. For each bit, choose the offset bit that yields fewer 1s among the component’s values, then combine the selected bits to obtain the minimum-sum sequence.
