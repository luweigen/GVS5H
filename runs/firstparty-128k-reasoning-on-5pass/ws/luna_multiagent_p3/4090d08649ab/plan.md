For any subarray, one operation can erase exactly one maximal consecutive run of distinct values, so \(f(L,R)\) equals the number of values \(x\) that appear in the subarray while \(x-1\) does not. Fixing the right endpoint \(R\), if `last[x]` is the latest position of value \(x\), the number of valid left endpoints contributed by \(x\) is \(\max(0,\text{last}[x]-\text{last}[x-1])\). Maintain the sum of these quantities while scanning \(R=1\ldots N\); updating `last[v]` only changes the terms for \(x=v\) and \(x=v+1\). Accumulate the maintained sum over all right endpoints using 64-bit integers.
