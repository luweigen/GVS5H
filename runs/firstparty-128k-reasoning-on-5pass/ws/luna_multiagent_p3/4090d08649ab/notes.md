- **Key characterization:** For any subarray, the distinct values form maximal consecutive blocks. One operation can erase values from only one such block because the chosen interval must contain every integer between its endpoints. Conversely, each block can be erased in one operation. Therefore, `f(L, R)` equals the number of maximal consecutive blocks among the values present in the subarray.
- **Per-value contribution:** A value `x` starts a block exactly when `x` appears in the subarray and `x-1` does not. Thus `f(L, R)` is the number of values `x` satisfying these conditions.
- **Right-endpoint sweep:** For a fixed right endpoint `R`, let `last[x]` be the latest position at or before `R` containing `x`, with zero meaning unseen. For a left endpoint `L`, value `x` appears iff `L <= last[x]`, while `x-1` is absent iff `L > last[x-1]`. Hence the number of valid left endpoints contributed by `x` is `max(0, last[x] - last[x-1])`.
- **Dynamic update:** When processing `A[R] = v`, only contributions for `x=v` and `x=v+1` can change, because only `last[v]` changes. Remove their old contributions, update `last[v]`, then add their new contributions.
- **Accumulation:** The maintained `cur` equals the sum of `f(L, R)` over all `L <= R` for the current `R`. Summing `cur` over all right endpoints gives the required answer.
- **Complexity:** `O(N)` time and `O(N)` memory. Python integers safely handle the answer, which can be quadratic in `N`.
