Process queries offline by sorting the values in each queried prefix of \(A\) and \(B\) conceptually via a persistent data structure over value coordinates. For each prefix, maintain a persistent segment tree storing counts and sums of values. Given roots for prefixes \(X\) and \(Y\), compute \(\sum_{i\le X,j\le Y}|A_i-B_j|\) by traversing the value tree and combining counts/sums from both roots, or equivalently by querying each value contribution against the opposite prefix. Use 64-bit integers throughout, and answer each query independently in \(O(\log N)\) time after \(O(N\log N)\) preprocessing.
