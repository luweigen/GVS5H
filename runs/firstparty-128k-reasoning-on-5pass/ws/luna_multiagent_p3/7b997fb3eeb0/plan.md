For each query interval, the maximum number of pairs can be found by greedily matching the smallest available mochi with the smallest possible larger mochi that is at least twice its size. Because the array is sorted, this matching is equivalent to finding the longest valid alignment between a left half and a right half of the interval. Preprocess a range-query structure over the validity of adjacent candidate matches so every query can be answered in \(O(\log N)\), yielding \(O((N+Q)\log N)\) total complexity.
