Use bitmask DP over the at most four target values, where each mask records which targets already have a multiple in some incremented `nums` elements. For any nonempty subset of targets, compute its LCM; an element can cover that subset by being incremented to the smallest multiple of the LCM, costing `(-nums[i]) % lcm`. Process each `nums` element once, either skipping it or assigning it to cover any subset, and update the minimum cost for every covered-mask state. The answer is the DP value for the full target mask.
