- **Potential formulation:** For a target distance \(D\), assign each vertex an integer label \(d_v\), with \(d_1=0\) and \(d_N\ge D\). Every edge \(u\to v\) must satisfy \(d_v\le d_u+w(u,v)\). If \(d_v=d_u+1\), that edge must have weight 1; otherwise it may have weight 0.
- **Threshold variables:** Use Boolean variables \(X_{v,i}\) for \(1\le i\le D\), meaning \(d_v\ge i\). They are nested: \(X_{v,i+1}\Rightarrow X_{v,i}\).
- **Edge constraints:** The inequality \(d_v\le d_u+1\) becomes \(X_{v,i+1}\Rightarrow X_{u,i}\) for \(1\le i<D\).
- **Cost encoding:** For an original edge \(u\to v\), a cut edge \(X_{v,i}\to X_{u,i}\) of capacity 1 charges exactly when \(d_v\ge i\) but \(d_u<i\). Due to the edge constraints, this can happen for at most one \(i\), precisely when \(d_v=d_u+1\). Thus the cut cost is the number of edges that must be selected.
- **Fixed labels:** Force all \(X_{1,i}\) false by edges to the sink, and all \(X_{N,i}\) true by edges from the source. Infinite capacity is \(M+1\), which is larger than the relevant budget \(K\).
- **Correctness:** Any feasible weight assignment yields shortest-path labels satisfying the constraints, so the minimum cut is no larger than the needed number of selected edges. Conversely, a finite cut defines labels satisfying all inequalities; assigning weight 1 to every upward edge makes every path to \(N\) have weight at least \(d_N\ge D\).
- **Exactly \(K\) edges:** If at most \(K\) edges suffice, select arbitrary additional edges to reach exactly \(K\). Increasing edge weights cannot decrease a shortest-path distance.
- **Complexity:** Each feasibility test uses \(O(ND)\) flow vertices and \(O((N+M)D)\) edges. Since \(D\le N-1\le29\), Dinic is easily sufficient. Binary search over \(D\) takes \(O(\log N)\) tests. Parallel edges are inserted independently and therefore counted independently.
