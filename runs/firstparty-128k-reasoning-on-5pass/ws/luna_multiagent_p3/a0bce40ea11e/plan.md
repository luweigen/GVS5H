Use the expansion of each entry of \(B^p\) as a sum over length-\(p\) walks in the directed graph of matrix indices. For every zero entry, apply the finite-field identity \(\sum_{x=1}^{p-1}x^e\equiv -1\pmod p\) exactly when \(p-1\mid e\), which eliminates almost all walks. For primes \(p>3\), only walks using no replaced entries survive, so the answer is \((-1)^K A^p\) modulo \(p\). Handle \(p=2\) directly using the fact that every replacement is forced to equal \(1\), and handle the exceptional \(p=3\) walk pattern with one zero edge appearing twice and one fixed reverse edge appearing once.
