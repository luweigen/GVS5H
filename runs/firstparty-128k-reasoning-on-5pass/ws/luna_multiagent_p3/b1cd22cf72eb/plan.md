Observe that after grinding, each pair must sum to a common integer height \(H\), so the final upper length \(A_i\) must satisfy \(\max(0,H-D_i)\le A_i\le U_i\), while the lower length is \(H-A_i\). For a fixed \(H\), determine feasibility by propagating the interval of possible \(A_i\) values from left to right, expanding the previous interval by \(X\) and intersecting it with the current bounds. Feasibility is monotone in \(H\), so binary search for the maximum feasible \(H\), bounded by \(\min_i(U_i+D_i)\). Since the final total length is \(NH\), the minimum cost is the initial total length minus \(NH\), using 64-bit integers.
