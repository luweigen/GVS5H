Model the current graph orientation using a parity bit: parity 0 denotes the original directions, and parity 1 denotes all directions reversed. Build an implicit graph with states `(vertex, parity)`, where traversing an edge costs 1 and reversing all edges toggles parity at cost `X`. Run Dijkstra’s algorithm from `(1, 0)`, efficiently relaxing original outgoing edges in parity 0 and original incoming edges in parity 1. The answer is the minimum distance to either `(N, 0)` or `(N, 1)`, using 64-bit integers.
