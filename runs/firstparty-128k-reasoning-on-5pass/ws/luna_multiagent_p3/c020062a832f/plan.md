Compute the inversion count for \(k=0\) using a Fenwick tree over values \(0,\ldots,M-1\). As \(k\) increases by one, each element’s transformed value either increases by one or wraps from \(M-1\) to \(0\); only wrapped elements change their relative ordering with other elements. For each value \(x\), precompute how many elements smaller/larger than \(x\) occur before and after each occurrence, then update the answer in \(O(1)\) per value. This yields all \(M\) answers in \(O((N+M)\log M)\) time.
