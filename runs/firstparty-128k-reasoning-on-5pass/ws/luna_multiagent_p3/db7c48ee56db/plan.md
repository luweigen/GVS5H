Use the complement identity: XOR of a chosen set of size \(K\) equals the XOR of all elements combined with the XOR of its omitted set, so enumerate subsets of size \(r=\min(K,N-K)\). Since \(\binom Nr\le 10^6\), exhaustive enumeration is feasible. For each subset, compute its XOR and update the maximum, applying the total XOR when \(K>N/2\). Handle \(r=0\) directly, and use `itertools.combinations` for efficient subset generation.
