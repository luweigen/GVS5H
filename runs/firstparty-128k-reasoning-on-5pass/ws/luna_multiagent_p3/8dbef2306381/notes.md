- **Reachability recurrence:** For each square \(x>1\), `dp[x]` is false on bad squares. On free squares, `dp[x] = OR(dp[x-A], ..., dp[x-B])`.
- **Compact state:** Store the previous \(B\) values in an integer. Bit 0 is the most recent position, and bit \(k\) represents the position \(k\) squares earlier. Appending one free square shifts the state left and inserts whether any bit corresponding to offsets \(A\) through \(B\) is set.
- **Free-run transition when \(A=B\):** The recurrence copies the value exactly \(A\) positions earlier, so the state rotates with period \(A\). Only `length % A` steps are needed.
- **Free-run transition when \(A<B\):** If the current state is nonzero, some reachable square exists. Since both step sizes \(A\) and \(A+1\) are allowed, every integer at least \(A(A-1)\) can be represented as a sum of allowed steps. Consequently, after at most \(A(A-1)+B\) free positions, all of the latest \(B\) positions are reachable and the state becomes all ones. Thus each free gap requires only \(O(A^2+B)\), at most a few hundred iterations under the constraints.
- **Bad intervals:** Appending a bad run inserts only zeros. A run of length at least \(B\) erases the entire state; shorter runs are handled by shifting left and masking.
- **Processing:** Iterate through sorted disjoint bad intervals, advance across the free gap before each interval, append the interval's zeros, then process the final free suffix through square \(N\).
- **Complexity:** \(O(M(A^2+B))\) time and \(O(1)\) extra space. With \(A,B\le 20\), this is easily within limits.
