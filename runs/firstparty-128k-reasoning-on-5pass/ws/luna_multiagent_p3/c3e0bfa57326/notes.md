- **Structural model:** Interpret each matched parenthesis pair as a rooted tree node, with the pairs directly inside it as its ordered children. The complete sequence is an ordered forest of such trees.
- **Effect of an operation:** A valid substring consists of consecutive trees at some common nesting level. Reverse-and-complement transforms a forest \(T_1T_2\cdots T_k\) into \(\operatorname{mir}(T_k)\cdots\operatorname{mir}(T_1)\), where mirroring reverses the child order recursively. Thus the underlying unordered rooted forest is invariant.
- **Reachability:** A valid substring containing one child tree can mirror that child. A substring containing two adjacent children swaps them while mirroring both. After such a swap, internal operations can independently transform each child to any desired embedding by induction on tree height. Therefore adjacent swaps and internal rearrangements allow every ordering and every plane embedding of the same unordered rooted forest.
- **Canonical types:** For a node, its unordered rooted-tree type is identified by the sorted tuple of its child type IDs. Equal tuples represent isomorphic unordered rooted trees. IDs are assigned when closing parentheses, so all child IDs are already known.
- **Counting embeddings:** If a node has \(k\) children with multiplicities \(c_1,c_2,\ldots\) among equal types, its distinct child orderings contribute \(k!/\prod c_i!\). Its total count is this multinomial factor times the product of the embedding counts of all children.
- **Forest handling:** Treat the top-level roots as another unordered sibling multiset and apply the same multinomial formula. Equal root trees must not be counted as distinct permutations.
- **Complexity:** Sorting each child list gives \(O(N\log N)\) total time in the worst case, with \(O(N)\) memory. Factorials and inverse factorials are precomputed modulo \(998244353\).
