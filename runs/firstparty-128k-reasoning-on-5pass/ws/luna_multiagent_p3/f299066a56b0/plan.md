Use the sorted order of the mochi sizes and binary search the maximum number \(K\) of pairs. For a fixed \(K\), pair the smallest \(K\) mochi as the top pieces with the largest \(K\) mochi as the bottom pieces; feasibility is exactly whether \(A_i \times 2 \le A_{N-K+i}\) for every \(i=0,\dots,K-1\). This feasibility condition is monotonic in \(K\), so binary search yields the answer in \(O(N\log N)\) time and \(O(1)\) extra space after input storage.
