- **Row thresholds:** Let \(R_x\) be the number of black cells in row \(x\). The row condition is exactly that row \(x\) consists of black cells in columns \(1\) through \(R_x\), followed by white cells.
- **Column condition equivalence:** All columns are prefixes of black cells if and only if \(R_1 \ge R_2 \ge \cdots \ge R_N\). If the row thresholds are nonincreasing, then for every column \(y\), the rows with \(R_x \ge y\) form a prefix.
- **Constraints from observations:** A black cell \((x,y)\) requires \(R_x \ge y\). A white cell requires \(R_x < y\). Therefore each constrained row has an allowed interval \([L_x,U_x]\), where \(L_x\) is the largest observed black column and \(U_x\) is one less than the smallest observed white column.
- **Greedy feasibility test:** Process constrained rows from top to bottom. Maintain the largest threshold allowed for the current row by monotonicity. Set \(R_x=\min(\text{previous threshold},U_x)\). This is the largest possible valid choice, so it maximizes freedom for all later rows. If it is below \(L_x\), no feasible sequence exists.
- **Unconstrained rows:** They can take any threshold between \(0\) and \(N\); skipped rows can retain the previous threshold, so they require no explicit processing.
- **Complexity:** Store one interval per observed row, sort the at most \(M\) constrained rows, and scan them. Time is \(O(M\log M)\), memory is \(O(M)\).
