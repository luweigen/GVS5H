Represent each row as a bitmask of width \(W\). For any chosen set of column flips, each row can independently be either left unchanged or complemented by a row flip, so its minimum contribution is \(\min(\operatorname{popcount}(r\oplus c),\, W-\operatorname{popcount}(r\oplus c))\). Enumerate all \(2^W\) column-flip masks and sum these minimum row contributions; choose the smallest total. Since \(W\le18\), this takes \(O(H2^W)\) time and can be optimized by aggregating identical row masks.
