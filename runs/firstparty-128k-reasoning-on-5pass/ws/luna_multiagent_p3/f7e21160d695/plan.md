Construct a Kruskal reconstruction tree: sort graph edges by weight and merge DSU components, creating an internal tree node whose weight is the edge weight. In this tree, the minimum possible maximum-edge path value \(f(x,y)\) equals the weight of the lowest common ancestor of vertices \(x\) and \(y\). At every subtree, only the imbalance between the number of \(A\)-items and \(B\)-items matters, because all possible pairs inside the subtree are cheaper than pairs crossing its parent merge. During a bottom-up traversal, match as many opposite residual items as possible across each merge and add the merge weight multiplied by the number of such pairs.
