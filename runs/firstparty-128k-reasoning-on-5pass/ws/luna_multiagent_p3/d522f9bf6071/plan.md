Sort intervals by start position while retaining original indices, and compute for each interval the next interval whose start is strictly greater than its end using binary search. Use dynamic programming over sorted intervals and number of selected intervals (up to 4), comparing candidates first by total weight and then by lexicographic order of their original-index lists. Since selected indices must be returned in increasing lexicographic order, normalize each candidate list before comparison; also allow skipping intervals and selecting fewer than four. Implement the DP iteratively or with memoization in the required `Solution.maximumWeight` method, with \(O(n \log n \cdot 4)\) time and manageable memory.
