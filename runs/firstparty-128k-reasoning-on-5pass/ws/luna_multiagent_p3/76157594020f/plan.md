Binary search the smallest possible maximum uniform-run length \(L\). For \(L=1\), the final string must be alternating, so compute the minimum flips needed to match either `"0101..."` or `"1010..."`. For \(L\ge2\), scan each maximal run in the original string; a run of length \(k\) requires \(\lfloor k/(L+1)\rfloor\) flips to ensure all resulting runs have length at most \(L\). Return the smallest \(L\) whose required flips do not exceed `numOps`.
