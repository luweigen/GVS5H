Model each constraint as an XOR graph edge, where assigning a potential \(P_v\) from an arbitrary component root requires \(P_x \oplus P_y = Z\). Traverse every connected component with BFS/DFS, detect contradictions whenever an already assigned vertex receives a different potential. For each consistent component, every valid assignment has the form \(A_v=P_v\oplus T\); choose each bit of \(T\) independently to minimize the component’s total sum, setting it to 1 exactly when more than half of the corresponding potential bits are 1. Output the resulting values, or \(-1\) if any contradiction is found.
