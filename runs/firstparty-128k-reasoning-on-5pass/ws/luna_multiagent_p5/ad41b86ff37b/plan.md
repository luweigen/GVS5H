Model the retained Snowflake Tree by choosing a center, a set of neighboring intermediate vertices, and a common leaf count \(y\); all retained vertices must lie within distance at most two from the center. For each possible center, compute the best achievable structure by selecting intermediate neighbors and deleting excess vertices, while enforcing that every selected intermediate has the same number of retained leaf neighbors. Optimize over all positive \(x,y\), including the \(x=y=1\) path case. Develop an \(O(N\log N)\) or \(O(N)\) tree DP/degree-based algorithm suitable for \(N\le 3\cdot10^5\), then implement it with iterative traversals to avoid recursion limits.
