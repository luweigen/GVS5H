Model the process as repeatedly selecting a value, bringing some occurrences of that value to the front using adjacent swaps, and deleting them in one operation. Derive a dynamic programming formulation that captures the minimum swap cost together with the number of deletion groups, exploiting the fact that only relative order and equal-value occurrences matter. Optimize the DP to near-linear or \(O(N\log N)\) total time across all test cases, then validate it against edge cases and the supplied examples.
