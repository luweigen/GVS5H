Compute the inversion count for \(k=0\) using a Fenwick tree over values \(0,\ldots,M-1\). When increasing \(k\) to \(k+1\), each element whose value equals \(M-1-k\) wraps from \(M-1\) to \(0\), changing its inversion contribution based on elements before and after it. Precompute for every value the total number of elements before and after its occurrences, then update the answer in \(O(1)\) per occurrence while iterating through all \(M\) shifts. The overall complexity is \(O((N+M)\log M)\) due to the initial inversion computation.
