Represent each row as a \(W\)-bit mask and count how often each mask occurs. For a fixed set of flipped columns \(c\), each row can independently be flipped or not, so its minimum contribution is \(\min(\operatorname{popcount}(r\oplus c),\,W-\operatorname{popcount}(r\oplus c))\). Thus, the answer is the minimum XOR-convolution of the row-frequency array with the function \(f[d]=\min(\operatorname{popcount}(d),W-\operatorname{popcount}(d))\). Compute this convolution for every column mask using a Walsh–Hadamard transform in \(O(W2^W)\) time, then output the minimum result.
