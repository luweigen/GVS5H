- **Basic invariants:** The number of zeroes is preserved. If the moved block is \(0^X1^Y\), each of the \(X\) involved zeroes moves right by \(Y\); in the reverse operation they all move left by \(Y\). Therefore, the positions modulo \(Y\) of the zeroes, listed in zero-order, are preserved individually.
- **Aggregate invariant:** Each operation changes the sum of the positions of all zeroes by exactly \(XY\) or \(-XY\). Hence the zero-position sum modulo \(XY\) is also invariant.
- **Reachability criterion:** For strings that admit at least one operation, equality of the zero count, equality of the ordered zero-position residues modulo \(Y\), and equality of the zero-position sum modulo \(XY\) characterize the same connected component. This can be obtained by repeatedly moving an eligible block left to a canonical form; the residue sequence is unchanged, while the sum modulo \(XY\) selects the required canonical phase.
- **Frozen strings:** A move exists exactly across adjacent maximal runs \(0^a1^b\) with \(a\ge X,b\ge Y\), or \(1^a0^b\) with \(a\ge Y,b\ge X\). If either endpoint is frozen, it cannot be connected to a different string, so the answer is Yes only when the strings are already identical.
- **Counterexample to sum-only criterion:** Take \(N=7,X=2,Y=2\), \(S=\texttt{0011001}\), and \(T=\texttt{1001100}\). Both have four zeroes and zero-position sums \(14\) and \(18\), respectively, which are equal modulo \(XY=4\). Both are movable. However, the zero residues modulo \(2\) are \((1,0,1,0)\) for \(S\) and \((0,1,0,1)\) for \(T\), so they are unreachable from one another.
- **Complexity:** Run detection, counts, sums, and residue comparison all take \(O(N)\) time. The implementation uses \(O(1)\) auxiliary memory apart from the input strings.
