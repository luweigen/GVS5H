- **Bottleneck interpretation:** For a floor level \(t\), Takahashi can use walkways while staying at level \(t\) exactly through the connected component of blocks whose buildings have at least \(t\) floors.
- **Edge weights:** Give adjacent blocks \(u,v\) the edge weight \(\min(F_u,F_v)\). The maximum possible minimum edge weight on a path between two blocks is their bottleneck level \(B\).
- **Maximum spanning tree:** Any maximum spanning tree preserves every pairwise bottleneck value: the minimum edge weight on the tree path equals the maximum bottleneck over all original graph paths.
- **Cost for a fixed common level:** If Takahashi connects the endpoint buildings through walkways at level \(t\le B\), the staircase cost is \(|Y-t|+|Z-t|\). Minimizing over \(t\le B\) gives \(\max(|Y-Z|,\,Y+Z-2B)\).
- **Cases:** If \(B\ge\max(Y,Z)\), choose a level between \(Y\) and \(Z\), giving cost \(|Y-Z|\). If \(B\) lies between \(Y\) and \(Z\), the same cost is achieved by using level \(B\). If \(B<\min(Y,Z)\), both endpoints must descend to at most \(B\), giving \(Y+Z-2B\).
- **Lower-bound proof:** Every route has staircase cost at least \(|Y-Z|\). If its total cost were below \(Y+Z-2B\), the minimum floor reached on the route would exceed \(B\); all buildings used by the walkway portions would then support a connected route above \(B\), contradicting the definition of \(B\).
- **Complexity:** The grid has \(N=HW\) vertices and \(O(N)\) edges. Kruskal takes \(O(N\log N)\), preprocessing takes \(O(N\log N)\), and each query takes \(O(\log N)\). Memory is \(O(N\log N)\).
