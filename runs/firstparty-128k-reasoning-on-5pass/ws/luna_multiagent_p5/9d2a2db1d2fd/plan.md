Model each building as a node weighted by its floor count, with walkway edges between adjacent buildings. For any query, the relevant quantity is the maximum possible bottleneck floor \(B\): the largest level at which the source and destination blocks remain connected using only buildings with at least that many floors. Construct a maximum spanning tree of the grid, where each adjacent edge has weight \(\min(F_u,F_v)\); the minimum edge weight on the tree path gives \(B\). The query answer is \(\max(|Y-Z|,\;Y+Z-2B)\), obtained by choosing the best common floor level not exceeding \(B\).
