- **Matching model:** Every sequence of adjacent removals corresponds to a noncrossing matching of the original indices; for odd \(N\), exactly one index is unmatched.
- **Parity:** Every matched pair has endpoints of opposite index parity, because the interval enclosed by a pair contains an even number of indices. Therefore, when \(N\) is odd, the unmatched index must have odd 1-based position.
- **Even-length segment value:** For a segment of length \(2k\), define \(F\) as the sum of its \(k\) largest values minus the sum of its \(k\) smallest values.
- **Upper bound:** Orient each matched pair toward its larger value. Each pair contributes the positive endpoint minus the negative endpoint. Since every pair contributes one endpoint of each sign, the total is at most the sum of the largest \(k\) values minus the sum of the smallest \(k\) values, namely \(F\).
- **Achievability:** Any balanced sequence of \(+\) and \(-\) labels has a noncrossing perfect matching pairing opposite labels: repeatedly remove any adjacent pair with different labels and recurse. Thus assigning \(+\) to the largest half and \(-\) to the smallest half achieves \(F\).
- **Odd \(N\):** If position \(u\) is unmatched, all pairs lie wholly in the prefix before \(u\) or suffix after \(u\); both segments have even length. Their maximum contributions are independently \(F(\text{prefix})+F(\text{suffix})\). Maximize this over odd \(u\).
- **Complexity:** Two heap sweeps compute all even-prefix and even-suffix values in \(O(N\log N)\) time and \(O(N)\) memory. Values and answers use Python integers.
