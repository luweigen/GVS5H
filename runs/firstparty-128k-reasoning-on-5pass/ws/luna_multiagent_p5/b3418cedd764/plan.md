View the directed graph defined by \(i \to A_i\) as a functional graph, whose components each contain one directed cycle with in-trees attached. Every cycle must have a common value because the inequalities around the cycle imply equality; for each possible cycle value \(v\), independently count assignments in every attached tree using bottom-up dynamic programming and prefix sums. Multiply the resulting counts over cycle vertices, sum over \(v=1\ldots M\) for each component, and multiply component totals modulo \(998244353\). The overall complexity should be \(O(NM)\) time and \(O(NM)\) memory, or less with careful storage.
