For each value \(x\), determine how many times it must be divided by 4 before reaching zero: \(f(x)=\lfloor\log_4 x\rfloor+1\). A query therefore contributes a total of \(S=\sum_{x=l}^{r} f(x)\) individual reductions, and since each operation reduces two selected values, the minimum operations are \(\lceil S/2\rceil\). Compute \(S\) efficiently using prefix sums over ranges where \(f(x)\) is constant, then sum each query’s result in \(O(\log_4 10^9)\) time.
