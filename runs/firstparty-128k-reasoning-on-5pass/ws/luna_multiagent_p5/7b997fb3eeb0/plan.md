For each position \(i\), compute \(p_i\), the first index \(j>i\) such that \(A_j\ge 2A_i\), and define \(B_i=p_i-i\). For a query interval \([L,R]\) of length \(n\), \(k\) pairs are possible exactly when \(\max(B_L,\ldots,B_{L+k-1})\le n-k\); this follows by pairing the \(k\) smallest selected mochi with the \(k\) largest. The condition is monotone in \(k\), so binary search the answer for every query. Use a sparse table or segment tree for range maximum queries on \(B\), yielding \(O(N\log N+Q\log^2N)\) time with a sparse table.
