Use a right-to-left sliding window, maintaining the minimum number of increments needed to make the current window non-decreasing. A monotonic stack will represent contiguous groups of equal required final values, allowing the cost to be updated efficiently when a new element is added on the left. While the cost exceeds `k`, remove elements from the right and update the stack/cost accordingly. For each left endpoint, all valid windows ending within the maintained range are counted, yielding an overall \(O(n)\) solution with 64-bit integer arithmetic.
