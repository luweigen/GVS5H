A 400 number is exactly the square of an integer whose prime factorization contains two distinct primes: \(N=(p^a q^b)^2\) with \(a,b\ge1\). Precompute every integer \(x\le10^6\) having exactly two distinct prime factors, store \(x^2\), and sort the resulting values. For each query \(A\), use binary search to find the largest precomputed square not exceeding \(A\), which answers each query in \(O(\log M)\).
