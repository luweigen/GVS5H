Expand each entry of \(B^p\) as a sum over length-\(p\) walks, then sum each monomial independently over the values assigned to zero entries. For odd prime \(p\), \(\sum_{x=1}^{p-1}x^c\equiv -1\) when \(p-1\mid c\), and \(0\) otherwise; since every walk has length \(p\), the only additional surviving walks beyond those using no zero entries are constant walks at a diagonal zero, contributing \(-A_{ii}\) to the \((i,i)\) entry. Thus compute \(A^p\bmod p\), treating zeros as zero, and apply this diagonal correction. For \(p=2\), every zero is forced to become \(1\), so directly compute the square of the resulting matrix.
