Find the longest palindromic suffix of `S`; only the prefix before this suffix needs to be mirrored and appended. Compute this suffix length in linear time using the KMP prefix-function on `reverse(S) + separator + S`, where the final prefix-function value gives the longest suffix of `S` matching a reversed prefix of `S`. Append the reverse of the remaining prefix to `S` and print the result. This runs in `O(|S|)` time and uses `O(|S|)` memory.
