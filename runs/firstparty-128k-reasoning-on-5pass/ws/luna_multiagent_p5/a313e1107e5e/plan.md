Process the array prefixes offline by increasing \(R\), while answering each query as its elements become available. The desired value is the length of the longest increasing subsequence in the current prefix whose final value is at most \(X\), which equals the maximum LIS DP value among active endpoints with value \(\le X\). Maintain these endpoint DP values in a coordinate-compressed structure supporting point updates when each new array element arrives and prefix-maximum queries by value. Use a Fenwick tree or segment tree for \(O((N+Q)\log N)\) time.
