Binary search the smallest possible maximum run length \(L\). For a fixed \(L\), compute the minimum flips needed to transform the string so that every maximal run has length at most \(L\), and check whether this cost is at most `numOps`. Use dynamic programming over positions and the current run character/length, yielding an \(O(nL)\) feasibility check and an \(O(n^2\log n)\) overall approach, which is suitable for \(n \le 1000\).
