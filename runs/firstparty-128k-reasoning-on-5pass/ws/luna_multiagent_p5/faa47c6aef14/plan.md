Model each box as a vertex with a red edge \(i\to P_i\) and a blue edge \(i\to Q_i\), and view each ball as independently following edges when its current box is operated. An operation is useful only when the chosen box currently contains at least one ball, and all balls at that box move simultaneously along their color-specific edges. Derive the minimum number of nonempty vertex operations needed to route every initial ball to \(X\), while detecting impossible configurations caused by cycles or balls that can never reach \(X\). Use reverse reachability and dynamic programming/graph traversal to compute the required activation order and minimum count in \(O(N)\) or \(O(N\log N)\).
