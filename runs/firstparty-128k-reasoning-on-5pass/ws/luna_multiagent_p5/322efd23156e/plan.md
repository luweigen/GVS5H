Group foods by vitamin and run a 0/1 knapsack for each group, where `dp[c]` stores the maximum vitamin intake achievable using at most `c` calories. Since no solution can use more than `X` calories, each DP takes `O(NX)` time. For a candidate target `T`, determine the minimum calorie cost needed to obtain at least `T` units of each vitamin by scanning the corresponding DP arrays. Binary-search the largest `T` whose three minimum costs sum to at most `X`.
