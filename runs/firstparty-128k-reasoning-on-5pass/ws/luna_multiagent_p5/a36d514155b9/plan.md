Decompose the total Manhattan distance into independent contributions from row and column coordinates. For every unordered pair of cells, count how many valid \(k\)-cell arrangements contain that pair: this is \(\binom{mn-2}{k-2}\). Compute the sum of absolute row differences over all cell pairs and similarly for columns using the standard sorted-coordinate formula, then multiply their sum by the combination factor modulo \(10^9+7\). Implement modular combinations efficiently using factorials and inverse factorials up to \(mn\).
