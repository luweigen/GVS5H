Use a recursive dynamic programming approach on the ternary tree induced by the repeated majority operations. For each node, compute the minimum number of leaf bit changes needed to make its resulting value 0 or 1. At a leaf, the cost is 0 for retaining its current bit and 1 for flipping it; at an internal node, evaluate all combinations of child output values and choose the minimum cost for each parent majority value. The answer is the minimum cost to force the root to the opposite of its original computed value.
