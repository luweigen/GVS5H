For every length-`x` window, compute the minimum cost to make all its elements equal; this is the sum of distances to the window median. Select at least `k` non-overlapping windows with minimum total cost using dynamic programming, where `dp[j]` represents the minimum cost of selecting `j` windows among processed indices. Since windows ending at successive positions overlap, enforce non-overlap by transitioning from the state before the chosen window starts. Use prefix DP or a recurrence over window starts to achieve `O(nk)` time after median costs are computed efficiently with a sliding-median data structure.
