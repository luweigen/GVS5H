Use the identity \(f(x)=x-\sum_{k\ge1}[2^k\mid x]\cdot x/2^k\), so the answer is \(S_0-\sum_{k\ge1}S_k/2^k\), where \(S_k\) is the sum of \(A_i+A_j\) over all \(i\le j\) such that \(2^k\mid A_i+A_j\). For each power of two, group values by their residue modulo \(2^k\); a pair is valid exactly when its residues are complementary. Maintain the count and sum of values in each residue class, allowing \(S_k\) to be computed in linear time in the number of occupied classes. Process all powers up to the largest relevant sum, yielding an \(O(N\log \max A)\) solution.
