Model each shared grid edge as a binary variable indicating whether the line crosses that edge; torus compatibility then means every edge has one consistent value for its two incident cells. Each Type A cell must have exactly two occupied edges that are adjacent, while each Type B cell must have two occupied opposite edges. Derive a global characterization of these local constraints that reduces the count to a small number of parity/consistency cases rather than exponential state enumeration. Implement the resulting counting method in \(O(HW)\) time per test case, using modular arithmetic and careful handling of toroidal boundaries.
