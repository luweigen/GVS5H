Scan the string left to right and maintain, for each modulus \(1\) through \(9\), how many substrings ending at the previous position have each possible remainder. When reading a new digit, extend every existing substring and add the one-digit substring, updating all remainder counts. If the current digit is nonzero \(d\), add the number of newly ending substrings whose remainder modulo \(d\) is zero to the answer. This handles leading zeros naturally and runs in \(O(9n)\) time with \(O(9^2)\) memory.
