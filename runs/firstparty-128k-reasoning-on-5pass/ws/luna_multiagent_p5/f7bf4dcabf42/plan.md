Model the LCS computation between fixed \(S\) and a generated length-\(M\) string as a finite-state automaton whose state is the LCS DP row after processing the generated prefix. Since \(N\le 10\), each row is a nondecreasing vector with bounded entries, so the number of reachable states is small enough to enumerate. For every state and each of the 26 appended letters, compute the next row, then use dynamic programming over \(M\) positions to count strings ending in each state. Finally, aggregate counts by the final LCS value, namely the last entry of each row, modulo 998244353.
