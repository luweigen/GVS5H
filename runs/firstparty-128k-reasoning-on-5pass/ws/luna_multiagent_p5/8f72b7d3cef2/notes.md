- **Initial interval:** For start position `i`, while the size is `A[i]`, exactly the consecutive slimes strictly smaller than `A[i]` can be absorbed. Nearest values `>= A[i]` on both sides determine this interval, computed in linear time with monotone stacks.
- **Cartesian tree:** Build a max Cartesian tree with parent values `>=` child values. For any threshold `S`, the connected component containing a node and consisting only of values `< S` is the subtree of the highest ancestor reachable by repeatedly climbing through parents with value `< S`.
- **Transition:** After the initial interval has sum `S`, if `S == A[i]`, both initial blockers are still `>= S`, so the process stops. Otherwise `S > A[i]`; the current component becomes the Cartesian subtree rooted at the highest ancestor reachable under threshold `S`.
- **Subtree state:** Let `F[u]` be the final size when the current absorbed interval is exactly the Cartesian subtree of `u`. Its size is `sub_sum[u]`. If the parent of `u` has value at least `sub_sum[u]`, no further absorption is possible and `F[u] = sub_sum[u]`. Otherwise climb to the highest ancestor `v` whose value is below `sub_sum[u]`; the process becomes state `v`, hence `F[u] = F[v]`.
- **Weighted ancestor queries:** Binary lifting finds the highest ancestor with value below a given threshold in `O(log N)`. Each Cartesian node is processed once, so the total complexity is `O(N log N)` with `O(N log N)` memory.
- **Strict inequalities:** Values equal to the current size are blockers. All ancestor climbs use `value < threshold`, matching the absorption rule.
- **Correctness with equal values:** Equal-valued descendants may appear in the Cartesian tree, but the only state transition from an initial singleton-component occurs when the new sum is strictly greater than `A[i]`; thereafter the threshold is strictly greater than the subtree maximum, so equal values are correctly included.
