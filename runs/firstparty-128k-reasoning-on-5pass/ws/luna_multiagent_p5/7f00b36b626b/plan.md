Use a DSU to represent connected components, initially treating every number as a separate component. Any value greater than `threshold` is isolated because every LCM involving it exceeds the threshold. For each distinct value `x <= threshold`, iterate through its multiples `m = x, 2x, ... <= threshold`; maintain one representative number for each multiple and union `x` with that representative. Two values are unioned exactly when they share a common multiple no greater than `threshold`, which is equivalent to their LCM being at most `threshold`. The total complexity is approximately `O(threshold log threshold + n α(n))`.
