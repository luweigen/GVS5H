- **Directed message semantics:** Let `F(u -> v)` be the maximum number of retained vertices in the component on the `u` side when edge `(u,v)` is retained. All vertices other than `u` already satisfy selected degree `1` or `4`; vertex `u` has its one selected edge toward `v` and must be either a leaf or degree `4`.
- **Message recurrence:** Vertex `u` may be a leaf, giving value `1`. Otherwise it must select exactly three incident directions other than `v`, making its selected degree `4`. Thus `F(u -> v) = 1` if fewer than three other neighbors exist; otherwise it is `1 +` the sum of the three largest values `F(w -> u)` over neighbors `w != v`. The internal option always exceeds the leaf option when available because every message is at least `1`.
- **Why all messages are valid:** Selecting only `u` on its side makes `u` a leaf once the designated edge to `v` is included. Hence no negative infinity or other invalid message representation is necessary.
- **Final answer recurrence:** Choose any retained degree-4 vertex `u` as a center. It must select exactly four incident branches, so its best alkane size is `1 +` the sum of the four largest incoming messages `F(w -> u)`. This is feasible only if `deg(u) >= 4`. Taking the maximum over all vertices automatically ensures the required existence of a degree-4 vertex; if no such configuration exists, answer is `-1`.
- **Rerooting implementation:** Root arbitrarily. Bottom-up `down[u]` computes `F(u -> parent[u])` using child messages. Top-down `up[u]` stores `F(parent[u] -> u)`. At each vertex, collect all incoming messages from its neighbors, sort descending, evaluate the four-branch center candidate, and for each child exclude that child from the top-three selection to compute `up[child]`.
- **Complexity:** Each adjacency list is sorted once while processing its vertex. Total time is `O(sum(deg(u) log deg(u)))`, at most `O(N log N)`, and memory is `O(N)`.
