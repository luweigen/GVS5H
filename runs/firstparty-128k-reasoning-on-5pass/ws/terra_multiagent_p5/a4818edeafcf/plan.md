Compute prefix and suffix distinct counts, then optimize the middle segment contribution over all valid split positions. Process the right split point from left to right while maintaining how adding the current value changes distinct counts of all possible middle segments. Use a lazy segment tree to store the best value of `prefixDistinct[i] + middleDistinct(i+1..j)` for each first split `i`, then add the suffix distinct count for the current `j`. This yields an `O(N log N)` solution suitable for `N = 3×10^5`.
