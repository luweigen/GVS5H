- **Local variables:** Assign one Boolean variable to every shared toroidal grid boundary. For cell `(i,j)`, let `t, r, b, l` denote occupancy of its top, right, bottom, and left boundary respectively. Horizontal boundary `X[i][j]` is the right edge of `(i,j)` and vertical boundary `Y[i][j]` is the bottom edge of `(i,j)`. Thus `r=X[i][j]`, `l=X[i][(j-1) mod W]`, `b=Y[i][j]`, and `t=Y[(i-1) mod H][j]`.
- **Boundary matching:** Using one variable per shared boundary enforces the no-dead-end condition automatically: both neighboring tile endpoints exist exactly when their shared variable is `1`.
- **Type A equations:** A tile must use an adjacent pair. This is exactly characterized by `t XOR b = 1` and `l XOR r = 1`. Each opposite pair then has exactly one selected edge, so exactly two edges are selected total: one vertical and one horizontal. Any vertical edge and horizontal edge are adjacent, yielding exactly the four Type-A rotations.
- **Type B equations:** A tile must use an opposite pair. This is exactly characterized by `t XOR b = 0`, `l XOR r = 0`, and `t XOR r = 1`. The first two equations make vertical ports equal and horizontal ports equal; the third makes the two directions different. Hence either both vertical ports are selected or both horizontal ports are selected, giving exactly the two Type-B rotations.
- **Global reduction:** Every local condition is an affine parity equation `x XOR y = c`. The full problem is therefore consistency and counting solutions of a graph of XOR constraints.
- **Counting:** In each connected component of a consistent XOR-constraint graph, choosing one root variable freely determines all other variables, so every component contributes a factor of two. The answer is `2^(number of DSU components)` modulo `998244353`. Any contradictory parity cycle makes the answer zero.
- **Degenerate torus handling:** Even when `H=2` or `W=2`, directional boundary segments remain distinct variables. The indexing above preserves them correctly; it does not incorrectly merge the left and right boundaries of a cell merely because they lead to the same neighboring cell.
