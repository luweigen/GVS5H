- **Deterministic cut rule:** Root the tree arbitrarily. For every non-root vertex `v`, let `s(v)` be the number of vertices in its rooted subtree modulo `K`. In any valid decomposition, the edge from `v` to its parent is used by a path if and only if `s(v) != 0`.
- **Why the rule is necessary:** If the parent edge is cut, the entire subtree is a union of whole paths of `K` vertices, so its size is divisible by `K`. If the parent edge is used, exactly one path crosses it. The part of that path inside the subtree has between `1` and `K-1` vertices, while all other vertices are whole `K`-vertex paths; hence the subtree size is not divisible by `K`.
- **Bottom-up remainder computation:** `rem[v] = (1 + sum(rem[child])) mod K`. This follows because every child with zero remainder contributes only completed internal paths, while every nonzero-remainder child contributes its unique unfinished component.
- **Constructed partition:** Keep precisely the parent-child edges whose child remainder is nonzero; cut all other edges. The retained-edge components are connected subtrees. Their sizes are exactly `K`: a component not crossing its parent has size divisible by `K`, and local remainder arithmetic plus at most two retained incident edges prevents it from exceeding `K`.
- **Path condition:** Since the original graph is a tree, every retained connected component is also a tree. It is a path exactly when each vertex has retained degree at most `2`. Therefore, after determining the forced retained edges, checking all retained degrees is necessary and sufficient.
- **Local transitions:** At a vertex with nonzero remainder, its parent edge is retained, so it may retain at most one child edge. At a vertex with zero remainder, its parent edge is cut, so it may retain at most two child edges. These are exactly captured by a global retained-degree check `<= 2`.
- **Special case `K=1`:** All remainders are zero, no edges are retained, and every singleton vertex is a valid path. The general algorithm handles this automatically.
- **Complexity:** Rooting, bottom-up DP, and degree counting each take `O(NK)` time and `O(NK)` memory.
