We need append the fewest characters to the end of `S` so that the result becomes a palindrome. This is achieved by finding the longest suffix of `S` that is already a palindrome; then append the reverse of the remaining prefix. To find this suffix in linear time for length up to 500000, use the KMP prefix-function on `reverse(S) + separator + S`. The final prefix-function value gives the length of the longest palindromic suffix.
