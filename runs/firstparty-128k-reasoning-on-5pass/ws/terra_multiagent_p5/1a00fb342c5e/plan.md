Model the constraints as a graph where each edge `(X_i, Y_i)` has XOR weight `Z_i`. For every connected component, assign temporary values `dist[v]` representing XOR from an arbitrary root; DFS/BFS verifies consistency whenever an already visited vertex is encountered. Every valid assignment in one component has the form `A[v] = dist[v] XOR t` for one common non-negative integer `t`. Minimize the component sum independently bit by bit: for each bit, choose the corresponding bit of `t` so that the number of ones among resulting `A[v]` is minimized. Isolated vertices can simply receive `0`.
