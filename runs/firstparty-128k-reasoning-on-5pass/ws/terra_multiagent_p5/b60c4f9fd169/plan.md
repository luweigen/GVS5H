Use the fact that the edit distance is at most K only if the string lengths differ by at most K. Compute a banded Levenshtein dynamic program restricted to diagonals where `|i-j| <= K`, since any valid edit sequence of at most K operations never leaves this band. Store only the previous and current DP rows/diagonal states, yielding `O(K * min(|S|, |T|))` time and `O(K)` memory. If the final distance is at most K, print `Yes`; otherwise print `No`.
