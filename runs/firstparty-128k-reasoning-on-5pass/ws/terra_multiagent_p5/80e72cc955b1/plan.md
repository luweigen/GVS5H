For each integer \(x\), compute how many divisions by 4 are needed before it becomes zero; this is its individual workload. Since each operation processes two elements simultaneously, the query answer is the maximum of: half the total workload rounded up, and the largest individual workload. Sum these answers across all ranges efficiently by grouping numbers according to powers of 4, where every number in a group has the same workload. Use arithmetic-series counting per group so each query takes only \(O(\log_4 r)\) time.
