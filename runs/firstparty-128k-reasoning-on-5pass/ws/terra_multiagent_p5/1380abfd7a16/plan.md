Process insertions in reverse order: when placing value `i`, its final position corresponds to the `P_i`-th currently available slot from the left. Maintain the set of unfilled positions using a Fenwick tree, initialized with all positions available. For each `i` from `N` down to `1`, find the `P_i`-th available position, place `i` there, and mark that slot unavailable. This yields an \(O(N \log N)\) solution suitable for \(N \le 5 \times 10^5\).
