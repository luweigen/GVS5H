Use the sorted order to greedily match small mochi as tops with sufficiently large unused mochi as bottoms. For a candidate number of pairs \(K\), only the first \(K\) mochi need be considered as tops and the last \(K\) as bottoms; check whether each corresponding top is at most half its bottom. Binary search the maximum feasible \(K\), since feasibility is monotonic. This yields \(O(N \log N)\), which is fast enough for the constraints.
