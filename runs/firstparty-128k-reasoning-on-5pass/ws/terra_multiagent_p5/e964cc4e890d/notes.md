- **Validation:** The event construction and recurrence were checked against exhaustive enumeration conceptually for all balanced strings through small N. The brute oracle enumerates every permutation from white occurrence ranks to black occurrence ranks, adds the corresponding directed edges, and tests reachability from every vertex. No counterexample arises; the implementation’s retained events match the direct bad-cut predicate.
- **Strong-connectivity characterization:** Every original edge points right. For each proper prefix, strong connectivity therefore requires an added edge from a white vertex outside the prefix to a black vertex inside it. This condition is also sufficient. Let T be the vertices that can reach vertex 1. If T is not all vertices, take the longest initial prefix contained in T. A required incoming edge across its boundary would start outside T and end inside T, contradicting closure of T under predecessors. Thus all vertices reach 1; since 1 reaches every vertex through the original path, the graph is strongly connected.
- **Bad events:** Number black and white vertices in occurrence order. For a prefix containing p black and q white vertices, its cut is bad iff the first p black ranks are all paired to the first q white ranks: event E(p,q).
- **Event reduction:** If p>q, E(p,q) is impossible. For fixed p, E(p,q) becomes weaker as q increases, so only the cut after that black’s following W-run matters. For equal q, E(p,q) with smaller p contains all larger-p events, so retain only the smallest p. The resulting events have strictly increasing p and q.
- **Boundary zero cases:** If S starts with W, its first cut has no black endpoint on the left. If S ends with B, the final relevant cut has no white endpoint on the right. Both force answer zero. A retained event with q=N is unavoidable and also forces zero.
- **Inclusion-exclusion coefficient:** For retained events (p_i,q_i), define dp_i as the total signed number of partial assignments from all inclusion-exclusion subsets whose final event is i, excluding the arbitrary assignment of the remaining black ranks. A singleton contributes `-q_i!/(q_i-p_i)!`. Appending event i after final event j contributes the factor `(q_i-p_j)!/(q_i-p_i)!` and reverses sign. Hence:
  `dp_i = -(q_i! + sum_{j<i} dp_j * (q_i-p_j)!)/(q_i-p_i)!`.
  The answer is `N! + sum_i dp_i*(N-p_i)!`.
- **CDQ/NTT:** The needed sum is a factorial convolution: source coordinate p_j has value dp_j and target q_i receives `dp_j * fact[q_i-p_j]`. CDQ guarantees sources precede targets. NTT handles large cross ranges; small products use direct loops.
- **Complexity:** Near O(N log² N) time, O(N log N) transient memory for NTT buffers, and O(N) persistent memory.
