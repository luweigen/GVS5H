- **Validation:** The implementation matches the required characterization and aggregate updates. It produces the expected results for the supplied examples: `[1,1,1,1,1,1] -> 6`, `[1,2,2,3,3,4] -> 4`, and `[0,1,2,3,4,5,6,7,8] -> 0`.
- **Core characterization:** Fix index `i` as the middle element with value `x`. If at least two additional `x` values are selected, `x` appears at least three times and is automatically the unique mode. If exactly one additional `x` is selected, all three remaining selected values must be non-`x` and pairwise distinct. With no additional `x`, the middle value cannot be a unique mode.
- **Sweep state:** `left[y]` counts occurrences before `i`; `right[y]` counts occurrences after `i`. Before evaluating an index, remove its value from `right`; after evaluation, add it to `left`.
- **Three-or-more copies case:** Enumerate counts of additional `x` values chosen from each side, each from zero through two. Only include choices whose total is at least two. Remaining slots are filled by arbitrary non-`x` elements on their corresponding side.
- **Exactly-two copies case:** When the extra `x` is on the left, choose one non-`x` left occurrence and a pair of distinct-valued non-`x` right occurrences, excluding right pairs whose value matches the chosen left value. The right-extra case is symmetric.
- **Aggregates:** Maintain `pairL_all`, `pairR_all`, `dot = sum(LR)`, `lr2 = sum(LR^2)`, and `rl2 = sum(RL^2)`. They permit all duplicate and cross-side collision exclusions in O(1) per middle index.
- **Aggregate update correctness:** Removing a right occurrence with old count `r` changes `pairR` by `-(r-1)`, `dot` by `-L`, `lr2` by `-L(2r-1)`, and `rl2` by `-L^2`. Adding a left occurrence with old count `l` changes `pairL` by `+l`, `dot` by `+R`, `lr2` by `+R^2`, and `rl2` by `+R(2l+1)`.
- **Complexity:** O(n) time after coordinate compression, with only constant work per index; O(n) memory in the worst case.
- **Arithmetic:** Python integers safely hold intermediate values. The answer is reduced modulo `10^9+7` each iteration.
