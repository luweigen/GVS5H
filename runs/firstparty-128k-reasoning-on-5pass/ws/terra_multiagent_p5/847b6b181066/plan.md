Track the cumulative wind displacement after each time step. Smoke generated at the origin at an earlier time remains at positions equal to the current cumulative displacement minus some previous cumulative displacement. Thus, at time `t`, `(R,C)` contains smoke exactly when the point `(current_row-R, current_col-C)` has appeared among cumulative positions up through time `t-1`. Maintain all prior cumulative displacements in a hash set and build the answer in `O(N)` time.
