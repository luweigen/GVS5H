- **Prefix displacement invariant:** Let \(D_t\) be the cumulative wind displacement after the first \(t\) winds, with \(D_0=(0,0)\). Thus \(D_t\) is updated by \((-1,0),(1,0),(0,-1),(0,1)\) for `N,S,W,E`, respectively.
- **Smoke source representation:** Smoke generated at time \(g\), after the \(g\)-th wind, is at the origin then. At time \(t \ge g\), it has been moved by winds \(g+1,\ldots,t\), so its position is \(D_t-D_g\). The initial smoke is equivalently a source at time \(g=0\).
- **Which source times occur:** A new source is generated at time \(t\) exactly when \(D_t\) has not appeared among previous prefix displacements. Inductively, there is one source for every distinct previously seen prefix displacement. After wind \(t\), smoke is at the origin iff some earlier source has \(D_g=D_t\), which holds iff \(D_t\) was seen earlier. Therefore a new source is created precisely at first occurrences of prefix displacement values.
- **Query condition:** At time \(t+0.5\), smoke is at \((R,C)\) iff there is a prior source index \(g<t\) satisfying \(D_t-D_g=(R,C)\), equivalently iff \(D_t-(R,C)\) is among distinct prefix displacements \(D_0,\ldots,D_{t-1}\).
- **Insertion order:** Maintain a set containing prefix displacements through time \(t-1\). After computing \(D_t\), query whether `(row - R, col - C)` is in the set, then insert \(D_t\). This exactly matches the invariant. Since \((R,C)\ne(0,0)\), inserting first would incidentally give the same query result, but querying before insertion is the clearest timing-correct formulation.
- **Complexity:** Each step does expected \(O(1)\) hash-set work. Total time is \(O(N)\), memory is \(O(N)\).
