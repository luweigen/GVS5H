- **BFS-layer characterization:** Rooted BFS layers \(L_0,L_1,\ldots\) uniquely describe every graph. Valid edges are only within one layer or between consecutive layers, and every vertex in a non-root layer must have a neighbor in the preceding layer. These conditions are also sufficient.
- **Parity condition:** For even \(N\), there must be \(N/2\) even-distance and \(N/2\) odd-distance vertices. Apart from root 1, this means \(E=N/2-1\) even vertices and \(O=N/2\) odd vertices.
- **Fixed-pool DP:** The state DP treats the \(E\) non-root even vertices and \(O\) odd vertices as predetermined pools. When adding a layer of size \(b\), it chooses labels only from the remaining vertices of that parity pool.
- **Missing label factor fixed:** The actual labels in the two parity pools are not predetermined. There are \(\binom{N-1}{E}\) ways to choose which labels among vertices \(2,\ldots,N\) are even-distance. The final coefficient array is multiplied by this factor modulo \(P\).
- **Transfer polynomial:** For previous layer size \(a\), new layer size \(b\), each new vertex needs a nonempty subset of predecessor edges and arbitrary internal edges are allowed. After extracting one mandatory predecessor edge per new vertex, the optional-edge transfer is \((1+x)^{\binom b2}(((1+x)^a-1)/x)^b\).
- **Edge indexing:** Every graph has exactly \(N-1\) extracted mandatory edges, so optional degree \(k\) corresponds to total edge count \(M=N-1+k\). The output array therefore directly corresponds to the requested range.
- **Interpolation:** Evaluate the degree-\(D\) optional-edge polynomial at integers \(0,\ldots,D\), where \(D=(N-1)(N-2)/2\), run scalar DP for each point, then recover monomial coefficients via forward differences and Newton basis polynomials. Since \(D< P\), all required inverses exist.
- **Complexity:** Roughly \(O(D\cdot T+D^2)\), where \(T\) is the number of layer-state transitions; this is safe for \(N\le 30\).
