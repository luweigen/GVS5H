Model each state as `(vertex, orientation)`, where orientation indicates whether the graph has been reversed an even or odd number of times. Moving along an edge costs `1` within the same orientation, while reversing all edges switches orientation at the same vertex with cost `X`. Build this implicit graph of `2N` states using original outgoing and incoming adjacency lists, then run Dijkstra from `(1, normal)`. The answer is the minimum distance among the two states corresponding to vertex `N`.
