Process the string left to right and count valid substrings ending at each position. For each possible non-zero last digit `d` from 1 to 9, maintain counts of remainders modulo `d` among all prefixes seen so far. When processing a digit, update each modulus state; if the current digit is non-zero, the number of divisible substrings ending here equals the count of prefixes whose remainder matches the current prefix remainder modulo that digit. This yields an `O(45n)` solution, easily within limits.
