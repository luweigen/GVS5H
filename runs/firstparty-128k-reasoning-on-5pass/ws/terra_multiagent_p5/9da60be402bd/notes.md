- **Pair-state meaning:** State `(u, v)` represents that there exists a palindromic labeled path from `u` to `v` of the stored minimum length.
- **Base cases:** `(i, i)` has distance `0` because the empty path is a palindrome. Every direct edge `i -> j` has distance `1`, since any one-character string is a palindrome.
- **Transition:** If `(u, v)` has a palindromic path and there are edges `a -> u` and `v -> b` carrying the same character, then placing those edges around the existing path creates a palindrome from `a` to `b`, with length increased by `2`.
- **Completeness argument:** Repeatedly remove the equal first and last characters of any palindrome. An even-length palindrome eventually reaches an empty path at one vertex; an odd-length palindrome eventually reaches one central edge. Thus every valid palindrome is generated from one of the initialized base states by the transition.
- **Shortest-path argument:** All transitions add exactly `2`. The queue is initialized with all distance-`0` states followed by all distance-`1` states, and generated states are appended. Therefore states are popped in nondecreasing distance, so assigning a state on first discovery gives its shortest possible distance.
- **Efficient transition generation:** For each character and vertex, store incoming neighbors and outgoing neighbors as Python integer bitsets. For `(u, v)` and a common character, valid outer endpoints are the Cartesian product of incoming neighbors of `u` and outgoing neighbors of `v`.
- **Avoiding dense-graph blowup:** Maintain one bitset of unvisited destination states for every source vertex. For each possible outer left endpoint `a`, intersect the right-neighbor bitset with `unvisited[a]`; only newly discovered states are enumerated. This prevents repeatedly iterating through already finalized pair states.
- **Complexity:** There are at most `N^2 = 10000` states. For each processed state, the total number of predecessor-bitset iterations over all characters is at most `N`; bitset intersections are word-level integer operations. Each pair state is discovered and enqueued at most once. This is practical for `N <= 100`, including dense same-label graphs.
- **Output:** Unreached states retain `-1`.
