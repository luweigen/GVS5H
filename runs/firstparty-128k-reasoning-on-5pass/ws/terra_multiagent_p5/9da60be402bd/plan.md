Model palindrome construction by working inward from both ends: a state `(u, v)` represents needing a palindromic path from `u` to `v`. Initialize all `(i, i)` with distance `0` and every direct edge `(i, j)` with distance `1`, then run multi-source BFS on pair states. From `(u, v)`, extend symmetrically by choosing an incoming edge to `u` and an outgoing edge from `v` with the same label, producing a path two edges longer. The resulting shortest distances for all pair states are exactly the required answers.
