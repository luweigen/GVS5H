Sort all three sequences in descending order; because every value is positive, the expression is nondecreasing in each selected element. Start from the maximum triple `(0,0,0)` and use a max-heap to repeatedly extract the currently largest expression value. From each extracted triple, generate its three neighboring triples obtained by incrementing one index, avoiding duplicates with a visited set. After extracting K states, the last extracted value is the K-th largest.
