- **Rewrite model:** Orient Operation B as `1^Y 0^X -> 0^X 1^Y`; Operation A is its inverse. Each B rewrite decreases the inversion count by `X*Y`, so it terminates. The left side has no nontrivial self-overlap because every nonempty prefix starts with `1` while every nonempty suffix ends with `0`; hence the rewrite system is locally confluent and terminating normal forms characterize reachability.
- **Pile representation:** Index zero piles by the number of preceding ones. A B rewrite moves one block of `X` zeros from pile `p` to pile `p-Y`, requiring the intermediate piles to be empty. A destination pile may already contain zeros.
- **Blockers:** A pile's count modulo `X` never changes. A nonzero residue is permanent, but whole `X`-blocks arriving at that pile can still pass through whenever its lower path is available. Therefore each blocker stores a `sink`, the final terminal pile reached by any movable blocks arriving there.
- **Normal-form sweep:** Process initially nonempty piles from low to high index. For each pile, find the nearest already known lower blocker using Fenwick predecessor queries. Movable blocks stop at the current pile if it is fewer than `Y` positions above that blocker; otherwise they jump downward in increments of `Y`. If the jump lands exactly on a blocker, use that blocker's precomputed sink. If it lands strictly above the blocker, it forms a new terminal blocker.
- **Late generated blockers:** A generated terminal blocker cannot invalidate processing of an earlier nonempty pile. If an earlier nonempty pile lay between it and the prior lower blocker, that pile would itself have been within distance `< Y`, hence would already have become the nearer blocker.
- **Complexity:** Building piles is `O(N)`. Each nonempty original pile makes one Fenwick predecessor query and at most two updates, for `O(N log N)` time and `O(N)` memory.
- **Validation:** The accelerated logic covers residues, exact distance `Y`, terminal positions created from divisible piles, and chains of blockers separated by multiples of `Y`. Comparing normal forms is valid after checking equal zero counts; equal lengths then also imply equal one counts.
