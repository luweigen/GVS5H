Model each operation as swapping adjacent uniform blocks \(0^X1^Y \leftrightarrow 1^Y0^X\), preserving both the total number of zeros and a more detailed structure determined by \(X,Y\). Derive an invariant or canonical representation of a binary string under these block swaps, then compare it for \(S\) and \(T\). The intended algorithm must run in \(O(N)\) or \(O(N \log N)\), since \(N\) is up to \(5 \times 10^5\). Carefully handle degenerate cases such as \(X=Y\), strings too short for any operation, and unequal numbers of ones.
