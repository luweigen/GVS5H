Exploit that foods contribute to exactly one vitamin, so the calorie budget can be split independently among the three vitamin groups. For each vitamin, compute a 0/1 knapsack DP where `dp[c]` is the maximum intake obtainable using at most/exactly `c` calories. Convert each DP into the minimum calories needed to achieve any target intake, then binary search the largest common target achievable by all three vitamins within total budget `X`. The feasibility check sums the minimum required calories for the target across the three groups.
