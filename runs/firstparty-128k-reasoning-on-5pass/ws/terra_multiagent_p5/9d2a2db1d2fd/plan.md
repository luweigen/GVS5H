Model each floor level as inducing connected components among blocks whose buildings reach that level. For a query, the optimal route can be characterized by the highest floor at which the two endpoint blocks are connected through walkways; the answer is then the necessary descent/ascent cost relative to that level. Build a maximum spanning tree over grid blocks, where each adjacent edge has weight equal to the minimum of its endpoint heights, so the maximum mutually reachable walkway level between two blocks is the minimum edge weight on their tree path. Preprocess binary-lifting LCA tables storing minimum edge weights, then answer every query in logarithmic time.
