- **Connectivity threshold:** At floor level `x`, walkway movement is possible exactly inside connected components of the grid induced by buildings of height at least `x`. These components only merge as `x` decreases.
- **Critical level:** For endpoint blocks `s,t`, let `T` be the highest floor at which they are walkway-connected. Equivalently, on the grid graph with edge capacity `min(F[u], F[v])`, `T` is the widest-path bottleneck value between `s,t`.
- **Lower bound for a route:** Project any arbitrary route onto the sequence of blocks visited by walkways. This gives a block path from `s` to `t`. Since no such path has all edge capacities greater than `T`, the route must traverse some walkway at a floor at most `T`. Therefore its floor sequence starts at `Y`, ends at `Z`, and visits a level at most `T`.
- **Exact query formula:** If `T >= min(Y,Z)`, descend only from the higher endpoint to the lower endpoint floor and walk horizontally there, costing `|Y-Z|`. If `T < min(Y,Z)`, both endpoint floor values must descend to at most `T`, so any route costs at least `(Y-T)+(Z-T)`, and this is attained by walking at floor `T`. Thus the answer is `|Y-Z| + 2*max(0, min(Y,Z)-T)`.
- **Union reconstruction tree:** Activate cells in descending building height. When two active components merge while processing height `h`, create a new tree node labelled `h` and make both component roots its children. The LCA of two original cell leaves has label exactly their critical level `T`.
- **LCA preprocessing:** The reconstruction tree has at most `2HW-1` nodes. Parent pointers always go from an earlier node to a later merge node, allowing depths to be computed in reverse node order. Binary lifting answers each LCA in `O(log(HW))`.
- **Complexity:** Sorting cells costs `O(HW log(HW))`; union construction is near-linear; binary lifting costs `O(HW log(HW))`; each query costs `O(log(HW))`. Compact `array('i')` storage is used for the large tables.
