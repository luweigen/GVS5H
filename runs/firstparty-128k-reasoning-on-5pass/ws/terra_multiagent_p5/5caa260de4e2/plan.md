Rewrite the partition cost using prefix sums, separating the contribution of each cut from the fixed total contribution. This yields a dynamic programming recurrence where `dp[i]` is the minimum extra cost after partitioning the first `i` elements. The transition has the form `dp[i] = min(dp[j] + X[j] * Y[i])`, which can be optimized with a monotonic convex hull trick because all values are positive and prefix-cost sums are increasing. Use a deque of lines to compute all states in linear time after prefix sums.
