Model each starting slime’s achievable expansion as consuming contiguous intervals whenever their boundary values are below the current sum. Use prefix sums and monotonic jump structures to find, for every position, the maximal interval it can eventually absorb without simulating every start independently. A divide-and-conquer or Cartesian-tree-based approach can propagate reachable total sums efficiently, exploiting that all absorbed values are positive. The final answer for each position is the sum of its maximal reachable interval.
