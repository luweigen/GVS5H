Model each subarray by the set of distinct values it contains: one operation can erase any contiguous interval of values fully present in that set, so the minimum number of operations equals the number of connected components in the sorted distinct-value set. Therefore, sum the number of value-components over all subarrays. Process right endpoints incrementally while maintaining, for every left endpoint, the component count of the distinct values in its current subarray; use last occurrences and range updates to account for adding a new value and merging adjacent value-components. A lazy segment tree can maintain the sums needed across all left endpoints efficiently.
