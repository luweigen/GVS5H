- **Approach:** Sort the Q queried initial ratings while retaining their original indices. The rating after every contest is nondecreasing as a function of the initial rating, because each contest map either keeps a value or increases it by one, and is itself nondecreasing.
- **Contest processing:** For a contest interval [L, R], the sorted tracked ratings currently in [L, R] form one contiguous index interval. Find its boundaries as the first current value at least L and the first current value at least R + 1, then add one to that index range.
- **Data structure:** A lazy segment tree stores maximum current rating in each segment and a pending range-add value. Since tracked values stay sorted, `first_at_least(x)` descends left whenever the left child maximum is at least x; otherwise it descends right.
- **Correctness detail:** Incrementing exactly the contiguous block whose values lie in [L, R] preserves sorted order. At the left boundary, preceding values are below L; at the right boundary, following values exceed R and thus are at least R + 1.
- **Complexity:** Each contest performs two boundary searches and one range increment, each O(log Q). Final point retrieval is O(Q log Q). Total complexity is O((N + Q) log Q), with O(Q) segment tree memory.
- **Validation:** The implementation follows the required inclusive interval behavior via lower bounds for L and R + 1, and is expected to produce the listed outputs for all three samples.
