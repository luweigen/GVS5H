Construct the permutation greedily from left to right in lexicographic order. For every candidate unused number of the required parity, count how many valid alternating completions remain; if that count is less than `k`, skip the entire block and subtract it from `k`, otherwise select it. Completion counts depend only on the remaining counts of odd and even numbers and the parity required next, and can be computed with factorial-based formulas capped above `10^15` to avoid unnecessary overflow. If no candidate can be selected at any position, return an empty list.
