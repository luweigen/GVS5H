- **Walk expansion:** For a length-\(p\) walk contributing to an entry of \(B^p\), let a formerly-zero edge variable occur \(c\) times. Summing that variable over \(\mathbb F_p^\*\) gives \(\sum_{x\ne0}x^c=-1\) if \(p-1\mid c\), and \(0\) otherwise. This includes unused variables (\(c=0\)).
- **Global factor:** Every surviving walk gets one factor \(-1\) for each originally-zero matrix entry, including unused entries. Thus all surviving-walk sums are multiplied by \((-1)^K\), where \(K\) is the number of zero entries.
- **Case \(p=2\):** Every replacement is necessarily \(1\), and every original nonzero value is also \(1\). Hence the sole matrix \(B\) is the all-ones matrix \(J\), and \(B^2=NJ\pmod2\). Output is all ones if \(N\) is odd, otherwise all zeros.
- **Case \(p=3\):** A used zero edge must occur exactly twice; no two distinct zero edges can both be used twice in a walk of length three. Let \(C=A\), treating zero positions as zero, and \(E=E_{uv}\) for one zero position. The surviving fixed-edge walks are \(C^3+CE^2+ECE+E^2C\), summed over zero positions. For nonloops, \(E^2=0\) and \(ECE=C_{v,u}E_{uv}\). For loops \(u=v\), add \(CE+EC+ECE\). Finally multiply by \((-1)^K\).
- **Case \(p>3\):** A used zero edge must occur \(p-1\) times, so there can be only one such edge and one remaining fixed edge. A nonloop matrix unit has \(E^2=0\), so it cannot occur \(p-1\ge3\) times. For every zero diagonal position \(i\), the allowed word placements yield \(CE_{ii}+E_{ii}C+(p-2)E_{ii}CE_{ii}\). Since \(p-2\equiv-2\), this is \(CE_{ii}+E_{ii}C-2C_{ii}E_{ii}\). Add these to \(C^p\), then multiply by \((-1)^K\).
- **Validation:** For a \(1\times1\) zero matrix with odd prime \(p\), formulas give zero, matching \(\sum_{x\ne0}x^p=\sum x=0\). With no zero entries, \(K=0\) and all correction terms vanish, yielding ordinary \(A^p\). The \(p=2\) sample gives \(J^2=3J=J\pmod2\). The formulas directly reproduce the walk classifications needed by the provided \(p=3\) sample.
- **Complexity:** For \(p>3\), binary matrix exponentiation costs \(O(N^3\log p)\); correction work is \(O(N^2)\). For \(p=3\), only two matrix multiplications plus \(O(N^2)\) corrections are used.
