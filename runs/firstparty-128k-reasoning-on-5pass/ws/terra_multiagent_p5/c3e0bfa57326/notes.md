- **Model:** Interpret a valid parenthesis sequence as an ordered rooted forest. Each matched pair is a node, and its immediately enclosed primitive balanced blocks are its ordered children. A virtual root has the top-level primitive blocks as children.
- **Operation effect:** A valid substring is a consecutive sequence of sibling subtrees at some depth. Reverse-and-swap reverses their sibling order and mirrors every selected subtree. Mirroring preserves the unordered rooted-tree type.
- **Invariant:** Therefore every operation preserves the unordered forest obtained by forgetting all sibling orders recursively.
- **Reachability:** For adjacent sibling subtrees `X, Y`, operate on the valid substring `XY`. This produces `mirror(Y), mirror(X)`. Then operate separately on each resulting subtree, restoring their original orientations and obtaining `Y, X`. Thus arbitrary adjacent sibling swaps are possible at every node. Repeating this recursively reaches every ordered embedding of the same unordered forest.
- **Counting:** For an unordered node type with child-type multiplicities `m_t` and total child count `k`, its number of ordered embeddings is `k! / product(m_t!) * product(E(t)^m_t)`. The virtual root uses the same formula. This counts distinct parenthesis strings.
- **Implementation:** Parse with a stack. On `)`, sort the completed node's child type IDs and intern that tuple as its canonical unordered type. Type IDs are created postorder, so embedding counts of child IDs already exist. The same interning is also used for the virtual root.
- **Complexity:** Sorting all child lists costs `O(N log N)` in the worst case; parsing and memory are `O(N)`. Factorials and inverse factorials are precomputed up to `N/2`.
- **Modulo:** All embedding counts and multinomial factors are computed modulo `998244353`.
