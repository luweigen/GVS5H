Model each row and column operation as choosing a binary flip flag; the final value of cell `(i,j)` is `A[i][j] XOR row_flip[i] XOR col_flip[j]`. Since `W ≤ 18`, enumerate all `2^W` possible column-flip masks. For each fixed column mask, every row can independently either remain unchanged or be flipped, contributing the minimum of the number of ones in its transformed bitmask and its complement. Sum these row-wise minima and take the global minimum.
