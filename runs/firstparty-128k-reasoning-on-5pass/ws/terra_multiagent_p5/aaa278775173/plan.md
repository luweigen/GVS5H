Model the four diagonal directions and observe that a clockwise 90-degree turn maps each direction to one specific other diagonal direction. Precompute, for every cell and direction, the maximum alternating `2,0,2,0,...` suffix length beginning at that cell with each possible expected value. Then enumerate every `1` as a start and every initial direction, combining its straight valid prefix with the best valid continuation after zero or one clockwise turn. This yields an \(O(nm)\) dynamic-programming solution suitable for grids up to \(500 \times 500\).
