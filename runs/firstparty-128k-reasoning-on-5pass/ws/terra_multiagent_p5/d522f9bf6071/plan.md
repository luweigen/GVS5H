Sort intervals by start coordinate and use binary search to find the next interval whose start is strictly greater than the current interval’s end, enforcing the “no shared boundary” rule. Perform dynamic programming over sorted intervals and remaining selection capacity from 0 to 4, where each state stores both the best total weight and its chosen original indices. For equal weights, compare the sorted index lists lexicographically to retain the required answer. Since only up to four intervals are selected, copying/comparing candidate lists is constant-time, giving \(O(n \log n)\) time and \(O(n)\) memory.
