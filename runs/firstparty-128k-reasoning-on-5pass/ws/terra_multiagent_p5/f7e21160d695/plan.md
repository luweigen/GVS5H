Construct a minimum spanning tree (MST) of the graph, since the minimax distance \(f(x,y)\) equals the maximum edge weight on the unique path between \(x,y\) in any MST. Process MST edges in increasing weight order with DSU; whenever components merge, greedily match as many unmatched occurrences of A and B inside the newly merged component as possible, charging the current edge weight for each match. This is optimal because a pair can be matched at weight at most \(w\) exactly when its endpoints belong to the same component using edges of weight at most \(w\). Maintain, for each DSU component, unmatched counts of A-occurrences and B-occurrences; after merging, add \(w \cdot \min(\text{countA},\text{countB})\) and cancel those counts.
