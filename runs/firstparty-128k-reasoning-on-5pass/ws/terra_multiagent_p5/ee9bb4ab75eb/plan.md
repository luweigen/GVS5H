Build a trie over all words, storing at each node how many words pass through it. A prefix of depth `d` is valid for a query after removing word `i` if some trie node at that depth still has count at least `k`. Only nodes on the removed word’s trie path can have their counts decreased, so precompute globally valid depths and efficiently determine the best depth affected by each removal. Handle the special case `n - 1 < k` by returning all zeros.
