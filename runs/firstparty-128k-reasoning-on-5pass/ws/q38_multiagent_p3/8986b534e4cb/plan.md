Model each person as an interval [l,r] with a sign: left-to-right requires the endpoint prefix value to be a strict minimum over the interval, right-to-left a strict maximum. A set of people is feasible exactly when it contains no bad pair: same-sign crossing intervals, overlapping intervals that share an endpoint, or opposite-sign identical intervals. Because feasibility is monotone, use a two-pointer sweep over the person order to find, for every L, the smallest R that makes [L,R] infeasible. Maintain the current feasible window with O(log N) add checks: endpoint arrays for shared endpoints, a lazy-heap segment tree for the minimum right endpoint covering a point, and a segment tree over left endpoints for the maximum right endpoint in a range. Answer each query by comparing R with the precomputed first_bad[L].
