Partition A into index blocks with size S chosen so S*K is bounded, and process blocks from left to right. Maintain acc[k] as the total contribution of all completed A-blocks to query k's B-prefix Y. For each block, compute its full contribution to every query by sorting the block's A values, computing for each unique B value the sum of absolute differences to the block in linear time, and scanning B once to record prefix values at the queries' Ys. For queries whose X falls inside the current block, compute the remaining partial sum offline using a 2D suffix-difference over sorted block A values and sorted query Ys to get counts/sums of B_j <= A_i in each B-prefix. Answer each query as acc plus its partial, then add the current block's full contribution to acc for future blocks.
