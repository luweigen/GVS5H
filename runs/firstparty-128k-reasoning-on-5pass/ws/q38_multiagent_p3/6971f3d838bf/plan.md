Treat the operation as choosing one value `v` to ignore inside a chosen original segment, so the answer is the maximum subarray sum over the original array and over arrays with all occurrences of one `v` removed. Compute the no-operation answer with Kadane. Only negative `v` need be considered as deletion candidates, because removing a non-negative value cannot increase any subarray sum. For each negative `v`, its occurrences split the array into blocks of non-`v` elements; query each block's sum, max prefix, max suffix, and max subarray using a segment tree, then combine the blocks in linear time to get the best subarray after deleting `v`. Since the total number of blocks over all `v` is `O(n + distinct)`, the overall complexity is `O(n log n)`.
