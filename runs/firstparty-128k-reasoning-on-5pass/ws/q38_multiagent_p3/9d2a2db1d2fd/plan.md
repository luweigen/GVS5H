Model a journey as a sequence of blocks; horizontal walkways are free at any floor not exceeding the minimum height of the two blocks, while stairs pay the total vertical variation. For a fixed block path, the optimal stair count depends only on the minimum building height m on that path and equals max(|Y-Z|, Y+Z-2m). Hence each query only needs M, the maximum possible bottleneck (largest m) over all paths from start to end, i.e. the maximum x such that the two blocks are connected using only blocks with F>=x. Build a Kruskal reconstruction tree by sorting blocks in descending F, activating them, and unioning active neighboring components, creating an internal node of weight current F for each successful union; the weight of the LCA of two block leaves is exactly M. Answer all queries by LCA on this tree and apply the formula, giving O(HW log HW + Q log HW) time and O(HW+Q) memory.
