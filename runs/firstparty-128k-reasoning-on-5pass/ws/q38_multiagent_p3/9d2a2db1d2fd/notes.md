- **Core reduction:** For a fixed block path, let m be the minimum building height on that path. Any walkway sequence along that path must at some point use a floor at most m. The minimum stair count for that path is min over x <= m of |Y-x| + |Z-x|, which equals max(|Y-Z|, Y+Z-2m). This is nonincreasing in m, so only the maximum possible bottleneck M matters.
- **Bottleneck M:** M is the largest x such that start and end blocks are connected using only blocks with F >= x. This is a vertex-weighted widest-path query on the grid.
- **Krusal reconstruction tree:** Sort blocks by descending F. Activate a block, union it with already active neighboring components. For each successful union, create a new internal node whose weight is the current block height and whose children are the two component roots. The LCA weight of two block leaves is exactly M.
- **Equal heights:** Processing equal-height blocks one by one is safe; all internal nodes created at that height have the same weight, so LCAs among components connected at that threshold still have weight equal to that height.
- **Same-block queries:** Answer directly as |Y-Z|. This also avoids undefined/self LCA issues.
- **Query storage:** Use flat adjacency arrays head/to/qid/nxt instead of per-node lists. Each different-block query adds two directed edges. This keeps memory predictable and avoids many small list objects.
- **Iterative Tarjan LCA:** The reconstruction tree can be deep, so recursion is unsafe. Use an explicit stack with encoded events: non-negative x is enter node x; negative odd -(2u+1) is after-left; negative even -(2u+2) is after-right. Leaves are blackened immediately on enter to reduce event count.
- **Tarjan DSU details:** Use a separate DSU over tree nodes during DFS. On enter, make-set and ancestor[u]=u. After a child subtree finishes, union child with current node and set ancestor[find(current)] = current. Mark node black, then answer queries whose other endpoint is already black using ancestor[find(other)].
- **Union by size:** Use a size array in the LCA DSU to keep find operations shallow. Path halving is used in all find loops.
- **Answer computation:** Once LCA node is known, M = weight[lca]. Answer is max(abs(Y-Z), Y+Z-2M). The second term can be negative; the max handles it.
- **Edge cases:** N=1 works because all queries are same-block and Tarjan is skipped if no different-block queries exist. All-same-block queries also skip Tarjan. Deep trees are handled by the iterative stack. Grid is always connected, so the final reconstruction tree has one root.
- **Complexity:** Building the tree is O(N log N) due to sorting plus near-linear DSU work. Tarjan LCA is O(N + Q alpha(N)). Memory is O(N + Q).
