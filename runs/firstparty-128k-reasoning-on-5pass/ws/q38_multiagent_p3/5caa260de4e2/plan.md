Compute prefix sums of `nums` and `cost` so any subarray cost can be expressed using endpoint indices. Use DP where `dp[t][i]` is the minimum cost to partition the first `i` elements into exactly `t` subarrays, with the `t`-th subarray ending at `i`. The transition is `dp[t][i] = (P[i] + k*t)*Q[i] + min_{j<i}(dp[t-1][j] - (P[i] + k*t)*Q[j])`. For each fixed `t`, each previous `j` defines a line `y = -Q[j]x + dp[t-1][j]`, and the query point is `x = P[i] + k*t`; because `P` and `Q` are increasing, maintain a monotone convex hull (or Li Chao tree) to evaluate the minimum efficiently. Initialize `dp[0][0]=0`, keep other states infinite, and return the minimum `dp[t][n]` over all valid `t`.
