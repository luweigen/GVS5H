- **Game abstraction:** Treat each index as releasing `A_i - 1` pass moves after its first touch. A state is determined by the number of untouched indices, the pass pool `P`, and the parities of the untouched `A_i`. The game ends immediately when the last untouched index is touched, so remaining tokens on that last index are irrelevant.
- **Parity notation:** Let `k` be the number of untouched indices with odd `A_i`. Touching an odd `A_i` leaves the parity of `P` unchanged; touching an even `A_i` flips the parity of `P`. For `N >= 4`, only `P mod 2` and `k` matter, with the special case that `P = 0` means no pass move is available.
- **Base N=1:** The player to move touches the only index and wins immediately, so Fennec wins.
- **Base N=2:** After any first touch, the opponent touches the last index and wins. Equivalently, with two untouched indices the state behaves like a pass heap; initial `P = 0` is losing, so Snuke wins.
- **Base N=3:** If the untouched parities are mixed, the player to move can force a win. If all `A_i` are odd, the player to move wins from even `P`; if all `A_i` are even, the player to move wins from odd `P`. Initially `P = 0`, so Fennec wins exactly when at least one `A_i` is odd.
- **Induction for N >= 4:** Claim: with `m >= 4` untouched indices, `k` odd `A_i` among them, and pass pool parity `p`, the player to move wins iff `p != (k mod 2)`. If `p != k mod 2`, a winning first touch exists: if an even `A_i` exists, touch it; otherwise all are odd and touch any odd `A_i`. In both cases the opponent reaches a losing state by the induction hypothesis. If `p == k mod 2`, no first touch wins; if `P = 0` there is no pass, and if `P > 0` a pass gives the opponent the winning `p != k mod 2` state. Thus the claim holds.
- **Initial state:** Initially `P = 0`, so `p = 0`. For `N >= 4`, Fennec wins iff `0 != (odd_count mod 2)`, i.e. `odd_count` is odd.
- **Final rule:** Fennec wins if `N == 1`, or `N == 3` and `odd_count > 0`, or `N >= 4` and `odd_count % 2 == 1`; otherwise Snuke wins. In particular, `N == 2` is always Snuke.
- **Samples:** Sample 1: `N=3`, `odd_count=2 > 0`, output Fennec. Sample 2: `N=2`, output Snuke. Sample 3: `N=6`, `odd_count=4` even, output Snuke. All three match the expected outputs.
- **Implementation:** Read all tokens, count `a & 1` for the `N` values, apply the rule, and print the answer. Complexity is `O(N)` time and `O(1)` extra space beyond the input tokens.
