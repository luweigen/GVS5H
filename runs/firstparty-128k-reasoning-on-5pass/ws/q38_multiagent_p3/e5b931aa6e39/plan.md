Let d = x - y > 0. Then x^3 - y^3 = d(3y^2 + 3dy + d^2) = N, so d must divide N. Since y is positive, 3y^2 + 3dy + d^2 > d^2, hence d^3 < N and d is at most about 10^6 for N <= 10^18. Iterate d from 1 up to the integer cube root of N and only consider divisors of N. For each divisor d, solve 3y^2 + 3dy + d^2 = N/d by checking whether the discriminant Δ = 12(N/d) - 3d^2 is a nonnegative perfect square. If so, compute y = (-3d + sqrt(Δ)) / 6 and accept it when y is a positive integer; then output x = y + d. If no d works, print -1.
