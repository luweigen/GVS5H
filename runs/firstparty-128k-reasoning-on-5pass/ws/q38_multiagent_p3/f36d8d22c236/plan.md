Parse the input and build the required mapping from each character in S to the character it must become in T, rejecting the case where one source character would need two different targets. Treat only non-self mappings as directed edges a -> b in a 26-node functional graph; the base minimum is the number of such edges because each source letter must be substituted at least once. Find all directed cycles of length at least two, and mark a cycle as isolated if no edge enters it from a node outside the cycle. An isolated cycle needs one extra operation using a buffer letter, while a cycle with an incoming tree edge can be resolved without extra cost. A buffer is available if some letter does not appear in S or some non-cycle letter has a non-self mapping; if an isolated cycle exists and no buffer is available, output -1, otherwise output base_count + isolated_cycle_count.
