- **Reduction:** A global rename merges all current occurrences of one letter into another; original letters with different final targets can never be separated. First enforce that each original S character has a single target in T; any conflict makes the answer -1.
- **Graph model:** For each present S letter c, edge c -> mp[c] when mp[c] != c. `base` is the number of such edges, i.e. present letters that must change. Each such original label must be used as the source x at least once, so base is a lower bound and achievable for acyclic parts.
- **Nontrivial cycles:** Only cycles of length at least 2 among present S letters matter. Self-loops and edges to absent letters are not cycles. A cycle with an incoming edge from a present letter outside the cycle can be resolved without extra cost by using that incoming letter as a temporary holder.
- **Cycle with incoming construction:** If u -> v0 and the cycle is v0 -> v1 -> ... -> v_{k-1} -> v0, do v_{k-1} -> u, then v_{k-2} -> v_{k-1}, ..., v1 -> v2, v0 -> v1, u -> v0. All merged bins share the same final target, and the cost is exactly the base edges involved.
- **Isolated cycles:** A cycle with no present outside letter mapping directly into it needs one extra operation. One cycle node must be moved to a buffer, the cycle rotated, and the buffer moved back into the cycle; the last buffer-to-cycle operation is not counted in base.
- **Buffer availability:** A usable buffer is a letter initially absent from S or finally empty, meaning present in S but absent from T. Such a letter exists iff not all 26 letters appear in S and not all 26 letters appear in T. If an isolated cycle exists and no buffer exists, the answer is -1.
- **All-26 case:** If S and T both contain all 26 letters, the consistent mapping is a permutation. Any nontrivial cycle is isolated, and no operation can merge two bins without making final singleton bins impossible, so any nontrivial cycle gives -1.
- **Multiple cycles:** One buffer can be reused for every isolated cycle, but each isolated cycle still contributes one extra operation. A non-isolated cycle can also produce a finally empty buffer after its base-cost resolution if needed.
- **Verified cases:** samples; S=T gives 0; conflict gives -1; swap with an absent letter gives 3; all-26 swap with fixed letters gives -1; all-26 with one T letter missing and an isolated cycle gives base+1; cycle with incoming edge gives base; multiple isolated cycles with a buffer give base+count.
- **Implementation:** Constant alphabet 26, O(N + 26^2). Use presence arrays ps and pt. Walk from each present node with a local seen map to find the repeated segment and mark cycle nodes. For each cycle, scan present outside nodes to test direct incoming edges.
