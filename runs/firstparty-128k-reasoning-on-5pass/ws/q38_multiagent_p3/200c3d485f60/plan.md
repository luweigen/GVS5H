Model the n-1 adjacent pairs as edges and choose which k of them are equal. A chosen set of k equal edges partitions the array into n-k constant runs. For any fixed set, adjacent runs must have different values, so the number of valid value assignments is the number of proper colorings of a path with n-k vertices and m colors: m * (m-1)^(n-k-1). Therefore the total answer is C(n-1, k) * m * (m-1)^(n-k-1) modulo 10^9 + 7. Handle the m=1 and n=1 cases naturally by using pow(0, 0, MOD) = 1 and returning 0 when the exponent is positive. Precompute factorials and inverse factorials up to n-1 to compute the binomial coefficient efficiently.
