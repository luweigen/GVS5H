Model the rim in-degrees as the output of a position-dependent 2-state NFA whose state is the orientation bit of the cycle edge entering the next vertex; at position i a transition t_{i-1}->t_i emits d_i = 1 + t_{i-1} - t_i + p_i, where p_i ∈ {0, s_i} is the spoke contribution. A full in-degree sequence is uniquely determined by the rim sequence, since d_N = N + K - sum_{i<N} d_i, so we only need to count distinct rim label sequences that can be produced by a cyclic path (start state equals end state). Count distinct accepted label sequences by determinizing the NFA: maintain the 2x2 Boolean relation of possible start-to-current states as a 16-bit mask, starting from the identity mask 9; a final mask is accepting iff it has a diagonal bit. For each character s_i, update the 16-mask DP using precomputed counts of labels (0..3) that move each mask to each next mask; this adds one count per distinct label, so each rim sequence is counted once. Answer is total label strings 3^{#0}4^{#1} minus the counts in reject masks 0,2,4,6, modulo 998244353, giving O(N) time and O(1) memory.
