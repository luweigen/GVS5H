Split the foods by vitamin type, since each food contributes to only one of the three vitamins. For each vitamin, compute a knapsack DP over calories where dp[c] is the maximum total amount of that vitamin obtainable with at most c calories. After processing all foods, make each dp array nondecreasing by taking prefix maxima. Binary search the answer T: for each vitamin, find the minimum calories needed to reach at least T units using binary search on its dp array. A value T is feasible iff the sum of these three minimum calorie requirements is at most X.
