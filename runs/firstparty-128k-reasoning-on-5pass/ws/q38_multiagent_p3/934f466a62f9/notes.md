- **Equivalence:** For each chosen pair, color both cakes by a dimension attaining the pair’s maximum. Then total price equals the sum of chosen dimension values, and each color count is even. Conversely, any even coloring of 2K cakes can be paired inside each color, and each pair’s price is at least its colored sum. Thus the problem is exactly maximizing an even 3-coloring of 2K cakes.
- **WQS setup:** Let F(r) be the maximum colored sum using exactly 2r cakes. F(r) is concave in r because it is the maximum-weight matching value as a function of matching size (standard exchange/M-concavity property). For penalty P per pair, maximize 2F(r) - 2Pr. Equivalently, each selected cake assigned to dimension d contributes 2*value - P and toggles parity bit d.
- **DP encoding:** Use BASE = 2^17, larger than max N = 1e5. Encode (value, count) as value*BASE + count. A contribution of (2v - P) per cake is encoded as (2v - P)*BASE + 1. Items store 2v*BASE as x<<18. For penalty P, use ps = P*BASE - 1 and add item_value - ps. Plain integer max gives lexicographic order by value, then maximum count.
- **DP transitions:** For mask m, new[m] = max(old[m], old[m^1]+A, old[m^2]+B, old[m^4]+C), where A/B/C are X/Y/Z contributions. The code unrolls all 8 masks to avoid loop overhead and uses old states only, so each cake is used at most once.
- **Unreachable states:** NEG = -1<<70 is a multiple of BASE and far below any real value. It acts as a valid but extremely bad state, so no special None handling is needed and it cannot affect the final optimal state.
- **Binary search:** B = max_d(top1_d + top2_d) bounds every pair price, so F(r) <= rB. Therefore P=0 is feasible and P=B+1 is infeasible. Find the largest P whose DP count is at least 2K. This P is the K-th marginal of F, and the answer is (H(P) + P*2K)//2, where H(P) is the DP’s doubled penalized value.
- **Shortcuts:** K=1 is answered directly by B. If B=0, all values are zero and the answer is 0. These avoid unnecessary DP passes.
- **Validation:** Samples match. A local brute force over 4^N colorings for N <= 8, checking even color counts and total 2K, was used to verify parity handling, tie-breaking, concavity, and the recovery formula on random small cases.
- **Complexity:** O(N log B * 24) per test case, with total N <= 1e5, so about 31 passes over all items in the worst case. Memory is O(N) for the encoded items.
