For each pair, choose the dimension attaining the maximum; this is equivalent to coloring 2K selected cakes by one of three dimensions with an even number of cakes in each color, maximizing the sum of the chosen dimension values. This is a maximum-weight K-matching problem, and the optimal value as a function of K is concave, so we can use the Aliens trick with a penalty C per pair. For a fixed C, compute the best net value and the maximum number of selected cakes among optimal solutions by a DP over the 3-bit parity of color counts: each cake is either unused or assigned to X/Y/Z, adding 2*value - C and toggling the corresponding parity bit. Binary search the integer penalty C in [0, 2*max_value+1] for the largest C whose optimal selected-cake count is at least 2K. Recover the answer as (net_value + C*2K)//2 from the DP at that C; total complexity is O(N log V * 24) over all test cases.
