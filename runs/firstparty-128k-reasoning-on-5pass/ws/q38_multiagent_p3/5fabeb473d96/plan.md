Treat all \((N-1)!\) parent sequences as a random recursive tree and compute \((N-1)!\) times the expected distance. By linearity, sum over edges \(i\) the weight \(A_i\) times the probability that edge \(i\) lies on the \(u\)-\(v\) path, i.e. separates \(u\) and \(v\). For fixed \(i\), the indicators that later vertices are in \(i\)'s subtree form a Pólya urn with one initial descendant and \(i-1\) non-descendants, giving simple probabilities: \(1\) if \(i=v\), \(1-1/u\) if \(i=u\), \(1/i\) if \(u<i<v\), \(2(i-1)/(i(i+1))\) if \(i<u\), and \(0\) if \(i>v\). Precompute modular inverses, \((N-1)!\), and prefix sums of \(A_i/i\) and \(A_i\cdot 2(i-1)/(i(i+1))\) modulo \(998244353\). Answer each query in \(O(1)\) by combining \(A_v\), the \(u\)-edge correction, the prefix sum for \(i<u\), and the prefix difference for \(u<i<v\), then multiplying by \((N-1)!\).
