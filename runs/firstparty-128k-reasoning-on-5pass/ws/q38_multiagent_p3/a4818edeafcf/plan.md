Maintain for each possible second cut position `j` the value `B_i(j) = distinct(A[i+1..j]) + distinct(A[j+1..N])` for the current first cut `i`. Initialize `B_1(j)` using prefix distinct counts from position 2 and suffix distinct counts from `j+1`, and store it in a lazy segment tree supporting range add and range maximum queries. For each `i` from 1 to `N-2`, the best total for that first cut is `prefix_distinct[i] + max(B_i(j))` over valid `j` in `[i+1, N-1]`. When moving from `i` to `i+1`, removing `A[i+1]` from the middle decreases `B_i(j)` by 1 exactly for `j` before the next occurrence of `A[i+1]`, so apply a `-1` range update on `[i+2, next_pos[i+1]-1]` clamped to `N-1`. Track the maximum candidate over all `i`, giving `O(N log N)` time and `O(N)` memory.
