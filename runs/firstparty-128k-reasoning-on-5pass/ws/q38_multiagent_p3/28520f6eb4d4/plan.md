For a height h, building i is invisible iff some earlier building j forces the sight line to be at or below H_j for every point on i, which is equivalent to h <= (H_j X_i - H_i X_j)/(X_i-X_j), the y-intercept of the line through the tops of j and i; equality is still blocked. Therefore the required maximum height is the maximum of these intercepts over all pairs j<i, or -1 if that maximum is negative (all buildings visible at height 0). For any three ordered points, the intercept of the outer pair lies between the intercepts of the two adjacent pairs, so by induction the global maximum is attained by a pair of consecutive buildings. Thus we only need to scan consecutive pairs, compute each rational intercept exactly with integers, keep the maximum by cross-multiplication, and print -1 or the best fraction with high precision.
