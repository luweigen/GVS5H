- **Visibility condition:** For target building i and earlier building k, aiming at the top of i gives the highest possible sight line at every intermediate coordinate. It clears building k iff `h + (H_i - h) * X_k / X_i > H_k`; equality touches the top and is still blocked.
- **Sequence criterion:** Rearranging the clearing condition gives `(H_i - h) / X_i > (H_k - h) / X_k` for every `k < i`. Define `a_i(h) = (H_i - h) / X_i`. All buildings are visible iff `a_1(h) < a_2(h) < ... < a_N(h)`.
- **Adjacent pairs only:** A finite sequence is strictly increasing iff every adjacent pair is strictly increasing. For adjacent buildings i and i+1, `a_i < a_{i+1}` iff `h > (H_i * X_{i+1} - H_{i+1} * X_i) / (X_{i+1} - X_i)`.
- **Answer threshold:** Let `b_i` be the adjacent rational thresholds. All buildings are visible exactly when `h > max(b_i)`. Therefore the largest non-negative height where not all buildings are visible is `max(b_i)` if `max(b_i) >= 0`. If `max(b_i) < 0`, height 0 already sees all buildings, so print `-1`. If `max(b_i) = 0`, print `0`.
- **Exact maximum computation:** Denominators `X_{i+1} - X_i` are positive. Compare `num / den` with `best_num / best_den` using `num * best_den > best_num * den`. Python integers safely handle the products, and no floating point is used for the maximum comparison.
- **Output formatting:** For a non-negative maximum, print 18 decimal places using Python float division: `f"{best_num / best_den:.18f}"`. This replaces the previous manual 30-digit exact decimal output.
- **Float output tolerance:** The float conversion is used only for printing. Its relative error is about 1e-16, well within the accepted absolute or relative error of 1e-9 for the constraint range.
- **Sample 4 match:** The maximum is `120 / 7`. Python's nearest double to `120 / 7` is slightly below the exact rational, and formatting with `.18f` yields `17.142857142857142350`, matching the sample exactly.
- **Sample checks:** Sample 1 gives `3 / 2` and prints `1.500000000000000000`. Sample 2 has a negative maximum and prints `-1`. Sample 3 has a zero maximum and prints `0.000000000000000000`. Sample 4 prints `17.142857142857142350`.
- **Complexity and memory:** One pass over the input, O(N) time and O(1) extra memory beyond the input buffer, easily handling N up to 2e5.
- **Edge cases:** N = 1 prints `-1`. A negative best fraction prints exactly `-1`, not `-1.0`. A zero best fraction prints `0.000000000000000000`. Large coordinates and heights remain safe for exact integer comparison.
