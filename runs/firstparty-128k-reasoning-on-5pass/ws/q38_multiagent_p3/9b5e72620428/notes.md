- **Feasibility for a fixed sum S:** S must be at least T, the maximum fixed value. Let P and Q be the numbers of fixed A and B values, and cA and cB the numbers of -1 entries. If x fixed A values are paired with fixed B values whose sum is S, then P-x fixed A values must go to B=-1 slots and Q-x fixed B slots must be filled by flexible A values. This is possible iff x >= L = max(0, P-cB) = max(0, P+Q-N).
- **Match count M(S):** The maximum possible x is M(S) = sum_v min(cntA[v], cntB[S-v]). Therefore S is feasible iff S >= T and M(S) >= L.
- **L <= 1 shortcut:** If L = 0, choose S = T (or 0 if there are no fixed values). If L = 1, one exact fixed-to-fixed match is enough; pair the maximum fixed value T with any fixed value from the other sequence. Hence the answer is always Yes.
- **All fixed case:** When P = Q = N, A must be exactly the multiset {S-b}. This is equivalent to sorted A[i] + sorted B_desc[i] being constant. Check this directly and return.
- **Candidate sums:** For L > 1, any feasible S has a matching of size L. At most cB fixed A values are unmatched, so among the largest cB+1 fixed A values at least one is matched; thus S is a sum of a topA value and some fixed B value. Symmetrically, S is also a sum of a topB value and some fixed A value. Build cand from the cheaper of topA x cntB and topB x cntA, keeping only sums >= T.
- **Enumeration:** Sort distinct values. For each fixed A value a, use bisect_left on sorted B values to start at b >= T-a. For each pair, if s = a+b is in cand, add min(cntA[a], cntB[b]) to cand[s]. Stop immediately with Yes when a candidate reaches L; otherwise print No.
- **Complexity:** Distinct values are at most 2000, so pair enumeration is at most 4e6. The candidate dictionary size is bounded by the smaller top product, at most about 1e6 for N = 2000, which is practical in Python.
- **Pitfalls:** Do not replace the min-count matching by ordinary convolution or products. Do not forget the S >= T restriction. Avoid slicing inner lists in loops. The all-fixed case is handled separately for speed and clarity.
