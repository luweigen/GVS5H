Let r and c be the numbers of -1 in A and B, and let P=N-r, Q=N-c. For a common sum S, every fixed value must be <=S, and a fixed A value can be placed in a fixed B slot only if a+b=S; otherwise it must use a B=-1 slot. Since only c B=-1 slots exist, at least L=max(0,P-c)=max(0,N-r-c) fixed A values must be matched to fixed B values with the same sum S (and symmetrically at least L fixed B values). For a given S, the maximum number of such exact matches is M(S)=sum_v min(cntA[v],cntB[S-v]). Therefore the answer is Yes iff L=0 (then S=max fixed value works) or there exists S>=max_fixed with M(S)>=L. It remains to check all candidate sums S=a+b from fixed values, accumulating min counts until one reaches L.
