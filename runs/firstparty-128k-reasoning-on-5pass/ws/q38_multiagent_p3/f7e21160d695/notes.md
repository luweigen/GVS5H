- **Problem reduction:** f(x, y) is the smallest threshold T such that x and y are connected using edges of weight at most T. This makes the cost relation an ultrametric, so the permutation problem is a minimum-sum matching between A-tokens and B-tokens under an ultrametric distance.
- **Imbalance invariant:** For any partition into connected components, let d_c be (#A in c) - (#B in c). The minimum possible number of matched pairs whose cost is at least the current threshold is (sum |d_c|) / 2. Initially this is K; after all edges it is 0.
- **DSU accumulation:** Sort edges by weight. Maintain parent, size, the net diff of each root, and sum_abs = sum |diff[root]|. When a union at weight w merges roots with diffs a and b, sum_abs drops by |a| + |b| - |a+b|, so the unavoidable count drops by (old_sum_abs//2 - new_sum_abs//2). Add w times that drop.
- **Equal weights:** Processing edges one by one in nondecreasing order is safe. All successful unions inside the same weight group have the same multiplier w, and their total drop equals the drop from before the group to after the group. Grouping by weight would give the same result.
- **Why it is optimal:** The merge history is a laminar hierarchy. Matching as many opposite tokens as possible inside each child component and passing the excess upward achieves the threshold lower bounds simultaneously. The drop at a merge is exactly the number of pairs that must be matched at that merge weight, so the accumulated sum is the optimal total.
- **Implementation details:** Vertices are 0-indexed. diff[v] is built by adding 1 for each A occurrence and subtracting 1 for each B occurrence. find uses iterative path halving; union by size keeps the tree shallow. sum_abs is always even, so integer division by 2 is exact.
- **Complexity:** Sorting dominates: O(M log M) time, O(N + M) memory. DSU operations are near-linear. The answer can be as large as K * 10^9, so Python integers are used.
- **Edge cases:** Duplicate A or B values at the same vertex are handled by net diff. If A and B shared a vertex, net diff would implicitly allow zero-cost matching, though the statement forbids cross equality. Redundant edges are skipped. The graph is connected, so the final component has diff 0.
- **Input handling:** The code reads all whitespace-separated tokens, parses edges and the two sequences, deletes the token list before sorting/DSU to reduce peak memory, and prints the answer.
