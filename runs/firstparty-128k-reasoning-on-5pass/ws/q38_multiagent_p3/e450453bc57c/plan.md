Compute the independent cost of making each length-x window internally equal, then select k non-overlapping windows with minimum total cost. For each window, the optimal target value is a median, so use a sliding median structure (Fenwick over compressed values or two heaps) to get sum absolute deviations in O(n log n). Store cost[start] for all possible window starts. Run a DP over prefix length and number of chosen subarrays: dp[t][i] = min(dp[t][i-1], dp[t-1][i-x] + cost[i-x]), where taking the window ending at i-1 enforces non-overlap. Since costs are nonnegative, exactly k windows is sufficient for "at least k". Return dp[k][n].
