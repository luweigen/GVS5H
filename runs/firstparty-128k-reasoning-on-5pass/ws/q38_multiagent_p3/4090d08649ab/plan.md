Observe that an operation can erase exactly a consecutive block of currently present values, so the minimum number of operations for a subarray is the number of maximal consecutive value intervals among its distinct values. This equals (# distinct values) - (# adjacent value pairs x,x+1 both present). Therefore the required sum is D - E, where D sums distinct-value counts over all subarrays and E sums co-occurrences of adjacent value pairs. D is computed by first-occurrence contributions using previous occurrence. E is computed per adjacent pair by counting subarrays containing at least one occurrence of each value, using total subarrays minus subarrays avoiding each value plus subarrays avoiding their union; the union-avoidance count is obtained by merging the two sorted position lists. The total work is O(N) because each position participates in at most two adjacent pairs.
