- **Characterization:** A valid grid is determined by row black-prefix lengths a_r. The column prefix condition is equivalent to a_1 >= a_2 >= ... >= a_N, because column c is black exactly in rows with a_r >= c, and that set is a top prefix iff the a_r sequence is nonincreasing.
- **Constraints as intervals:** A given black cell (x,y) forces a_x >= y, so L_x is the maximum y over black cells in row x. A given white cell (x,y) forces a_x <= y-1, so U_x is the minimum y-1 over white cells in row x. Rows not in input have L=0 and U=N.
- **Feasibility condition:** A nonincreasing sequence inside [L_r,U_r] exists iff for every row r, max_{s>=r} L_s <= U_r. Necessity: a_r must dominate all lower bounds in rows at or below r and cannot exceed U_r. Sufficiency: choose a_r = max_{s>=r} L_s; this sequence is nonincreasing, satisfies all lower bounds, and the condition guarantees it satisfies all upper bounds.
- **Sparse sweep:** Only rows appearing in the input need to be checked explicitly. Unconstrained rows have U=N, and all L values are at most N, so their condition is automatic. Sort constrained rows in decreasing row order, maintain max_l as the maximum L seen so far (the suffix maximum), update it with the current row's L, then fail if max_l > U of the current row.
- **Off-by-one and same-row conflicts:** White at column y gives upper bound y-1, not y. Black at column y gives lower bound y. Updating max_l before checking the current row catches conflicts within the same row, such as a black cell to the right of a white cell in that row.
- **Implementation:** Use a dictionary mapping row to (L,U), initialized to (0,N) on first sight. Parse with sys.stdin.buffer.read().split() for speed. Compare color token to b'B'. Sort dictionary keys in reverse order. Output Yes only if no violation is found.
- **Complexity:** O(M log M) time due to sorting at most M constrained rows, and O(M) memory. This handles N up to 1e9 without materializing the grid.
- **Status of approach:** The row-length interval check is implemented and complete; it is equivalent to the forbidden southeast dominance condition between given white and black cells.
