- **Walk expansion:** Expand each entry of B^p as a sum over length-p directed walks. For a zero edge used c times, the sum over its replacement in F_p^* is -1 if c = 0 or c is a positive multiple of p-1, and 0 otherwise.
- **Odd p structure:** Since total walk length is p, for odd p a zero edge can appear only 0 or p-1 times, and at most one zero edge can appear. Surviving walks are: all-fixed walks, one zero self-loop used p-1 times plus one fixed edge, and for p=3 one zero non-self edge used twice plus its fixed reverse edge.
- **Corrections:** Let F be A with zeros kept as 0. Compute P = F^p. For each zero diagonal (i,i), add column i of F to C column i and row i of F to C row i. If p=3, for each zero off-diagonal (i,j), add F[j][i] to C[i][j]. The final answer is (P + C) * (-1)^K modulo p.
- **Small p:** p=1 is all zeros modulo 1. p=2 has only one completion; under the constraints B becomes the all-ones matrix, so B^2 mod 2 is N mod 2 in every entry. The code explicitly builds B and squares it.
- **Exponentiation:** Compute F^p left-to-right: start with result = F, then for each remaining bit of p, square result, and if the bit is set multiply by F. Since all factors are powers of F, use F * result for the set-bit multiplication to keep the original F as the first operand and exploit its zero entries.
- **Matmul details:** Use i-k-j order, skip zero aik, do not modulo inside the k-loop, and modulo each row after all k iterations. Special-case aik = 1 and aik = p-1 (treated as -1) to avoid multiplication. Row entries stay around N*p^2, which is safe for Python integers.
- **Pitfalls:** Do not apply the odd-p formula to p=2. Do not forget the global sign (-1)^K. The p=3 off-diagonal correction orientation is C[i][j] += F[j][i]. A zero diagonal has F[i][i] = 0, so no fixed self-loop correction is added there. Avoid multiplying by the identity matrix.
