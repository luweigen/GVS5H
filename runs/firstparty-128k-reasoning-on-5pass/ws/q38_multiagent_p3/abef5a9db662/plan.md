Read all input first and let M be the maximum queried initial rating. Maintain an array A over possible initial ratings where A[x] is Takahashi's current rating after the contests processed so far, initially A[x]=x. Each contest applies the nondecreasing map y -> y+1 if L_i <= y <= R_i, otherwise y, so A remains nondecreasing and the indices x with A[x] in [L_i,R_i] form a single contiguous interval. Use a lazy segment tree over indices 1..M storing maximum values and supporting range add, first index with value >= L, and first index with value > R. For each contest, add 1 to that contiguous index interval, and after all contests answer each query X by point querying A[X]. This runs in O((N+Q) log M) time and O(M) memory.
