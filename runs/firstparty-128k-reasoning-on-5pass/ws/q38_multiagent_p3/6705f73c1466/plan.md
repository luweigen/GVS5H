Collect the positions of all 1s in the string. For each 1 at position p_i, subtract its index i to get q_i = p_i - i, which represents the starting position of the final contiguous block if this 1 is the i-th 1 in that block. The minimum number of adjacent swaps is the minimum over all possible block starts of sum |q_i - start|. This is minimized when start is any median of the q_i values. Compute the median and sum the absolute differences, using 64-bit integers.
