Sort the intervals by right endpoint, keep original indices, and precompute for each interval the count of intervals that end strictly before its left endpoint. Run a weighted-interval-scheduling DP for exact counts k = 0..4, where each state stores the maximum weight and the lexicographically smallest sorted tuple of original indices achieving that weight. For each interval and count, compare skipping it with taking it; taking combines the best (k-1)-interval state from its compatible prefix and inserts the interval's original index into the tuple in sorted order. On equal weight, keep the lexicographically smaller tuple, which is valid because adding the same interval to equal-length index sets preserves lexicographic order. After all intervals, choose the maximum weight among k = 1..4 and break ties by lexicographic tuple order, then return the tuple as a list.
