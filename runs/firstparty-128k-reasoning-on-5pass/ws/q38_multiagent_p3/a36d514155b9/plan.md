Use linearity over unordered cell pairs: each pair of cells appears in exactly C(mn-2, k-2) valid arrangements, so total is that factor times sum of Manhattan distances over all unordered cell pairs. Manhattan distance separates into row and column contributions. For rows, each pair of rows distance d contributes n^2 cell pairs, and sum of distances over all row pairs is m(m^2-1)/6; similarly columns contribute m^2*n(n^2-1)/6. Compute the pair-distance sum modulo 1e9+7, multiply by the binomial coefficient modulo 1e9+7, and return result. Since mn <= 1e5, precompute factorials and inverse factorials up to mn for O(mn) time, or use a multiplicative O(min(k, mn-k)) combination.
