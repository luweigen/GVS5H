Model the final string as runs and cap run length at 3, since only whether a run has reached 3 matters. Define DP[i][c][l] as the minimum additional cost to finish positions i..n-1 when the current run before i has character c and length l in {1,2,3}; base at i=n is 0 only for l=3. Compute these tables backwards in O(26n) by forcing continuation for l<3 and, for l=3, taking the minimum of continuing c or switching to any d!=c using precomputed smallest/second-smallest values of |caption[i]-d|+DP[i+1][d][1]. The initial answer cost is min_d |caption[0]-d|+DP[1][d][1], and if it is INF (which also covers n<3) return empty. For lexicographic tie-breaking, greedily build the answer left to right, at each position choosing the smallest allowed character whose transition cost plus the stored suffix DP equals the remaining optimal cost. This yields the minimum-cost good caption and the lexicographically smallest one among all optimal captions.
