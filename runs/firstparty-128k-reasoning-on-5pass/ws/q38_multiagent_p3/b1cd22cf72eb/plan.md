The cost for a target common sum H is total initial length minus N*H, so minimizing cost is equivalent to maximizing feasible H. For fixed H, each upper tooth length must lie in the interval [max(0, H-D_i), min(U_i, H)], and adjacent upper lengths must differ by at most X. Feasibility for H can be checked in O(N) by propagating the possible range of the current upper length and intersecting it with the next interval expanded by X. Feasibility is monotone: if H is feasible, any smaller H is feasible by capping upper lengths at the smaller H, so binary search H. Use 64-bit integers and return total_sum - N*H_max.
