Because target length is at most 4, treat the set of targets as a small bitmask and let each nums element optionally be incremented to a common multiple of any subset of remaining targets. For a subset S, the cost for a nums value x is the distance to the smallest multiple of lcm(S) that is >= x, computed as (lcm - x % lcm) % lcm. Process nums elements one by one with DP over covered target masks, allowing each element to be unused or assigned to one subset, which enforces that a single original element is used at most once. The answer is dp[full_mask] after all nums, with large costs capped to avoid useless huge lcm transitions. This yields O(n * 3^t) time and O(2^t) memory, easily within constraints.
