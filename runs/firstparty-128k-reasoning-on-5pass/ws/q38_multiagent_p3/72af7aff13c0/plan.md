Transpose the grid if H<W so that the number of columns W is min(H,W) (at most 447), and map the start and directions accordingly. Maintain forward DP F (from (1,1)) and backward DP G (to (H,W)) for all rows, but only guarantee that F is correct for rows up to the current row and G is correct for rows from the current row down. For each query, first move to the destination and restore the invariant by recomputing one row if the move is vertical; then update the destination cell. The answer changes by (new-old)*(F[h-1][w]+F[h][w-1])*(G[h+1][w]+G[h][w+1]) with virtual 1 at the start and end, so no division by zero is needed. After setting the value, recompute the current row's F from the updated column rightwards and G leftwards. This gives O(HW + Q*min(H,W)) time modulo 998244353.
