Let M be the maximum value in A. For each d from 1 to M, compute cnt[d], the number of array elements divisible by d, by summing frequencies over multiples of d. For a fixed index i, the maximum possible GCD is exactly the largest divisor d of A_i such that cnt[d] >= K, because we need at least K elements divisible by d including A_i. Precompute ans[x] for every possible value x by scanning d from M down to 1 and assigning d to all multiples of d that have not yet been assigned; the first assignment is the largest valid divisor. Then output ans[A_i] for each i in the original order. This runs in O(M log M + N) time and O(M + N) memory, which is efficient for M <= 10^6.
