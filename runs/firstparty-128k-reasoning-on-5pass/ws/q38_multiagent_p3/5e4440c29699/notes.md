- **Model:** The town is the full lattice rectangle [0,W] x [0,H] with the inclusive forbidden rectangle F = [L,R] x [D,U] removed. A path is any monotone right/up sequence of blocks, with arbitrary start and end, including length zero.
- **Suffix/prefix count:** For a point with a right and b up remaining in the full grid, the number of full-grid continuations is S(a,b) = sum_{i=0..a, j=0..b} C(i+j,i) = C(a+b+2, b+1) - 1. The same formula counts full-grid paths ending at a point with x=a, y=b when summed over starts.
- **Total full paths:** Summing S(x,y) over all full-grid points gives T = C(W+H+4, W+2) - (W+2)(H+2) - 1. This includes singleton paths.
- **First bad point decomposition:** Every invalid full path has a unique first forbidden point. It either starts inside F, or first enters F from its left side (L,y), y in [D,U], or from its bottom side (x,D), x in [L,R]. Top/right first entry is impossible because moves only increase coordinates.
- **Start inside F:** For start (x,y) in F, suffix count is S(W-x, H-y). Let A = W-x, B = H-y. A ranges from W-R to W-L, B ranges from H-U to H-D. The prefix sum of C(a+b+2,b+1) over a=0..A, b=0..B is P(A,B) = C(A+B+4, B+2) - A - B - 4, with P=0 if A<0 or B<0. Since S = C - 1, the rectangle sum of S is the P-rectangle minus the number of points, i.e. minus (R-L+1)(U-D+1).
- **Left entry:** First bad point (L,y), previous point (L-1,y). Prefix count is S(L-1,y) = C(L+y+1, L) - 1. Suffix count is S(W-L, H-y) = C(W-L+H-y+2, W-L+1) - 1. Sum over y=D..U only if L>0.
- **Bottom entry:** First bad point (x,D), previous point (x,D-1). Prefix count is S(x,D-1) = C(x+D+1, D) - 1. Suffix count is S(W-x, H-D) = C(W-x+H-D+2, W-x+1) - 1, equivalently using fixed second parameter H-D+1. Sum over x=L..R only if D>0.
- **Implementation:** Precompute factorials and inverse factorials up to W+H+5. The modulus is prime and larger than all needed n, so ordinary factorial binomials are valid. Use inline comb as one modulo of fact[n] * invfact[k] * invfact[n-k]. Boundary loops keep fixed k values and move n/j indices; accumulate products without modulo inside the loop and mod once at the end, keeping the running sum small enough (about 1e24 for 1e6 terms).
- **Complexity:** Time O(W+H + (U-D+1) + (R-L+1)), memory O(W+H). Worst-case loops are about 2e6 iterations plus 2e6 factorial precomputation steps.
- **Edge cases:** L=0 skips left entry, D=0 skips bottom entry. The forbidden rectangle may touch outer borders; negative A/B in P return 0. Inclusive boundaries are handled by the +1/+2 offsets in binomial arguments. Singleton forbidden paths are subtracted via start_bad, and length-one entry paths are subtracted via boundary products.
- **Validation:** Sample 1 was checked by hand DP and matches 192. Small 2x2 and 3x3 brute-force cases match the complement formula. The same formulas are used for samples 2 and 3.
