- **BFS layering:** In any connected graph, distances from vertex 1 form nonempty consecutive layers. Layer 0 is {1}. Edges can only appear inside a layer or between consecutive layers, and every vertex in layer i>0 must have at least one edge to layer i-1. These conditions are also sufficient for the distances to be exactly the layer indices.
- **Parity condition:** Vertex 1 is even. Since N is even, the required condition is that the number of even-distance non-root vertices is E = N/2 - 1.
- **Layer-size generating function:** For a fixed layer-size sequence s_1,...,s_D, labels contribute (N-1)! / prod s_i!. For a new layer of size s after previous layer size a, the edge polynomial is invfact[s] * (1+x)^{C(s,2)} * ((1+x)^a - 1)^s. The factor ((1+x)^a - 1)^s enforces that each new vertex chooses a nonempty subset of previous-layer vertices.
- **Scalar DP state:** State is (used non-root vertices u, even non-root count e, last layer size a, next layer parity p). Start is (0,0,1,odd). Final states have u=N-1 and e=E. Transition adds a positive layer size s, flips parity, and adds s to e iff the new layer is even.
- **Pruning:** A state is kept only if the remaining vertices can still supply the needed even/odd counts. For next parity odd, remaining even max is R-1; for next parity even, remaining even min is 1. Also use current odd count O=u-e: if next parity is even and e=0 then a=u; if e>0 then a<=O-1. If next parity is odd and O=1 then a=e; if O>=2 then a<=e. This makes the state space small and mostly exactly reachable/extendable.
- **Evaluation points:** The answer polynomial A(x) has minimum degree N-1 and maximum valid degree C(N,2)-N/2+1. Let G(x)=A(x)/x^{N-1}. Its degree is K-1 where K = max_valid-(N-1)+1. For N<=30, K<=393.
- **Weight evaluation:** For each x=1..K, set y=1+x. Precompute W[a,s] = invfact[s] * y^{C(s,2)} * (y^a-1)^s mod P. The DP then uses only scalar multiplications/additions.
- **DP implementation:** Process states by increasing u in one array. All incoming transitions to a state come from one smaller u, so accumulated values stay small; mod only when a state is processed. This avoids modulo in the inner transition loop.
- **Interpolation:** Values G(1)..G(K) are obtained by multiplying A(x) by inverse x^{N-1}. Use finite differences for H(z)=G(1+z): H(z)=sum h[k] C(z,k). Then G(x)=sum h[k] C(x-1,k). Convert C(x-1,k) to power basis iteratively by multiplying by (x-k)/k.
- **Output:** Coefficients of G give answers for M=N-1, N, ... max_valid. Append zeros for M=max_valid+1..C(N,2). N=2 works as a one-layer case and outputs 1.
- **Verification:** N=4 gives 12 9 3 0. N=6 minimum-edge count and total sum match the sample: min M=5 count 810, total valid graphs 13000.
