- **Problem reduction:** The answer is the maximum D such that at most K edges can be marked so every directed 1-to-N path has at least D marked edges. Feasibility is monotone in D, so binary search is valid.
- **Upper bound:** D <= min(L, K), where L is the unweighted shortest path length from 1 to N. Any 0/1 weighting has distance at most the all-ones distance L, and some simple 1-N path must contain at least D distinct marked edges.
- **Level dual:** D is feasible iff there are integer levels r(v) in [0, D] with r(1)=0, r(N)=D, r(v) <= r(u)+1 for every edge u->v, and at most K edges satisfy r(v) > r(u). Marking exactly those upward edges forces every path to have at least D marked edges; conversely, any valid marking gives such levels by taking the minimum marked-edge count from 1, capped at D.
- **Cut encoding:** Use threshold nodes x_{v,i} meaning r(v) >= i for i=1..D. Source side means true. Force N-level nodes to source and 1-level nodes to sink with INF. Add INF implication arcs x_{v,i+1} -> x_{v,i} and x_{v,i+1} -> x_{u,i} for each original edge u->v. Add unit arcs x_{v,i} -> x_{u,i} for each original edge and level i. The +1 constraint ensures at most one unit arc crosses per original edge, so finite cut value equals the number of upward edges.
- **Implementation details:** Node id is v*D + (i-1). Use INF = K+1 and stop max flow at K+1; feasible iff flow <= K. D=0 is trivially feasible.
- **Complexity:** N <= 30, D <= 29, M <= 100. Each check builds O((N+M)D) edges and runs Dinic; only about five checks are needed, easily within limits.
- **Edge cases:** Parallel edges get separate unit arcs and are charged separately. Cycles are handled by the implication constraints. Extra marked edges beyond the minimum can always be added arbitrarily because increasing edge weights cannot decrease the shortest distance.
- **Sample behavior:** Sample 1 gives D=1 with cut 2 <= 2. Sample 2 gives D=2 with cut 3 <= 3. Sample 3 gives D=1 with cut 2 > 1, so answer 0.
