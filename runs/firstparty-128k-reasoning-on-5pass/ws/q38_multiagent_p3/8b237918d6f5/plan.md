The goal is to find the largest D for which we can mark at most K edges so that every directed path from 1 to N contains at least D marked edges. For fixed D, introduce integer labels r(v) in [0,D] with r(1)=0, r(N)=D, and r(v)<=r(u)+1 for every edge u->v; then any edge with r(v)>r(u) must be marked, and marking exactly those edges makes every path have cost at least D. The minimum number of such marked edges is a minimum s-t cut problem on a layered graph of threshold variables x_{v,i}=1 iff r(v)>=i. Use infinite-capacity edges to enforce monotonicity and the +1 constraint, and unit-capacity edges to charge each original edge for each level where its head is at least i and its tail is below i. Binary search D from 0 to N-1, since a shortest path can be taken simple, and return the largest D whose min-cut cost is <=K; extra marked edges can be added to reach exactly K.
