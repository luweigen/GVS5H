Treat the required placement as a simple cycle whose edges are colored by the tail piece: red edges are orthogonal unit steps and blue edges are diagonal unit steps. A red edge flips the parity of r+c while a blue edge preserves it, so R must be even; if R=0, a blue-only closed walk also requires B even. These conditions are sufficient and can be met by explicit small-grid constructions. For R=0 with even B, output a blue-only cycle as a rectangle perimeter in the transformed (a,b) coordinates where blue moves become axis moves. For R>0 with B=0, output a red-only rectangle perimeter (or a 2-cycle when R=2). For R>0 even and B>0, build two internally disjoint paths from (0,0) to a chosen endpoint C: a red path of length R and a blue path of length B, using C=(1,1) for odd B and C=(2,0) for even B; output the red path with C colored blue followed by the reversed blue path internals, then shift all coordinates into the board.
