Sort A, B, and C in non-increasing order; since all entries are positive, f(i,j,k)=A_iB_j+B_jC_k+C_kA_i is monotone non-increasing when any index increases. The maximum triple is (0,0,0), and a max-heap best-first search can enumerate triples in non-increasing order. To generate each triple exactly once without a visited set, use the unique parent rule: parent(i,j,k) is (i-1,j,k) if i>0, otherwise (0,j-1,k) if j>0, otherwise (0,0,k-1). Pop K states from the heap, pushing the children of each popped state according to this parent rule; the K-th popped value is the K-th largest value. Encode states in 60-bit integers and pack heap keys to keep memory and time within limits for K up to 5e5.
