- **Graph model:** Treat each index i as a node with an edge i -> A_i. This is a functional graph: every node has outdegree 1, so each weak component contains exactly one directed cycle, and all other nodes form directed trees feeding into that cycle.
- **Inequality direction:** The condition x_i <= x_{A_i} means values are nondecreasing along edges toward the cycle. Thus A_i is the parent of i in the tree/cycle structure.
- **Cycle equality:** For a directed cycle c1 -> c2 -> ... -> ck -> c1, the inequalities give x_c1 <= x_c2 <= ... <= x_ck <= x_c1, so all vertices on that cycle must have the same value.
- **Tree DP definition:** For a non-cycle node u, define F_u(t) as the number of valid assignments in the non-cycle subtree rooted at u, where x_u <= t. If x_u is fixed to exactly t, each child v may be assigned any valid subtree assignment with x_v <= t, so the exact-value count is product over children v of F_v(t).
- **Prefix recurrence:** Therefore F_u(t) = F_u(t-1) + product_v F_v(t). This is the key recurrence used by the value sweep.
- **Value sweep:** Maintain cur[u] = F_u(current threshold) for non-cycle nodes. Initialize cur[u] = 0. For each t = 1..M, process non-cycle nodes in leaf-to-root order and update cur[u] += product(cur[v] for children v). Leaves have empty child product 1, so their cur becomes t after t iterations.
- **Leaf-to-root order:** Use indegree peeling. Here indegree means the number of incoming edges, i.e. the number of children. Repeatedly remove nodes with indegree 0 and decrement the indegree of their parent. The removal order is topological from leaves toward cycle roots. Nodes left with indegree > 0 are exactly the cycle nodes.
- **Cycle contribution:** For a cycle C and common cycle value t, every direct non-cycle child v of any cycle node in C must satisfy x_v <= t. Its contribution is cur[v]. Hence the cycle’s contribution at threshold t is the product of cur[v] over all such direct non-cycle children. The component’s total contribution is the sum of this product over t = 1..M.
- **Component independence:** Different functional-graph components have no constraints between them, so the final answer is the product of the contributions of all cycle components, modulo 998244353.
- **Implementation details:** Build reverse adjacency rev[p].append(i). Peel indegree-zero nodes with a deque. Mark is_cycle from the mutated indegree array. Extract cycles by following A from unvisited cycle nodes. For each cycle, collect all direct non-cycle children into one flat list. If that list is empty, the component is a pure cycle and contributes exactly M, so count it in pure_count and multiply by pow(M, pure_count, MOD) at the end.
- **Modulo handling:** Keep cur and sums in the range [0, MOD). For additions, use val = a + b; if val >= MOD: val -= MOD. Products are reduced modulo MOD at each multiplication to keep integers small.
- **Edge cases:** Self-loops are cycles of length 1; the self-edge is excluded from attached children. Pure cycles with no non-cycle children contribute M each. Multiple components multiply. M = 1 always gives answer 1 because the only possible sequence is all ones.
- **Complexity:** Peeling and cycle extraction are O(N). Each of the M sweeps processes each non-cycle node once and each non-cycle edge once as a child factor, giving O(NM) time and O(N) memory. With N, M <= 2025, this is comfortably fast in Python.
- **Sample checks:** Sample 1 gives 6. Sample 2 is a self-loop with three leaves, giving sum_{t=1}^9 t^3 = 2025. Sample 3 has one pure cycle contributing 5 and one active cycle contributing sum_{t=1}^5 t^2 * sum_{s=1}^t s^2 = 2002, total 10010.
