Model the input string as a complete ternary tree of height N, where each internal node is the majority of its three children. For every node, compute the minimum number of leaf flips needed to force that node to be 0 and to be 1. For a leaf, these costs are trivial from its bit. For an internal node, forcing value v requires at least two children to be v, so take the cheapest cost for each child and add the two smallest extra costs needed to make two children equal to v. Process the tree bottom-up level by level to keep memory usage low. The original root is the value whose cost is 0, and the answer is the cost for the opposite value.
