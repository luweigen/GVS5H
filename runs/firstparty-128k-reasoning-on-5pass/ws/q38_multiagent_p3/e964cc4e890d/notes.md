- **Reduction:** The base graph is the directed path 1 -> 2 -> ... -> 2N. Added edges go white -> black. Strong connectivity is equivalent to every proper prefix having at least one added edge from the suffix to the prefix. For the cut before black y+1, let R[y] be the number of white vertices before that black. The cut is bad iff the first y black vertices are all matched to the first R[y] white vertices.
- **Inclusion-exclusion recurrence:** Let T[0]=1. For y=1..N with R[N]=N, if R[y] < y then T[y]=0; otherwise T[y] = -invfact[R[y]-y] * sum_{b<y} T[b] * fact[R[y]-b]. The answer is -T[N] modulo 998244353.
- **First-occurrence compression:** If R[y]=R[y+1]=r, then T[y+1]=0 by cancellation: the new term T[y]*fact[r-y] cancels the previous sum. Thus only the first y for each r with y<=r can be nonzero, plus the sentinel (N,N). Store states (a_i, r_i) and compute T_i = -invfact[r_i-a_i] * sum_{j<i} T_j * fact[r_i-a_j].
- **CDQ convolution:** Recursively solve index intervals. For a node [l,r) with mid, add contributions from j in [l,mid) to i in [mid,r). Let A_len = a[mid-1]-a[l]+1, B_len = r[r-1]-r[mid]+1, base = r[mid]-a[mid-1]. Build A[x]=T_j at x=a_j-a[l], and G[s]=fact[base+s] for s=0..A_len+B_len-2. The needed value for i is coefficient A_len-1+(r_i-r[mid]) of A*G. This shifted construction avoids depending on the large offset base in the convolution length.
- **Complexity:** At each CDQ level, the sum of A_len over left halves and B_len over right halves is O(N), so total NTT work is O(N log^2 N). Direct summation is used for small blocks and small cross products.
- **Fast paths:** Return 0 if S[0]!='B' or S[-1]!='W'. If there are no proper states, every bijection works and the answer is N!. For M<=3000 use direct O(M^2). If proper states are dense a_i=i for i<=K and r_i=i+c for all proper i, compute T_0..T_K as the inverse of K_c(x)=1+sum_{n>=1} invfact[c]*fact[c+n] x^n, then answer = sum_{j=0}^K T_j * fact[N-j]. This covers all-d=0 dense cases and constant-offset dense cases.
- **NTT implementation:** Modulo 998244353 with primitive root 3. Uses forward DIF and inverse DIT without explicit bit-reversal. Twiddle factors are precomputed lazily up to the needed power of two (at most 2^19 for N=2e5).
- **Validation:** The recurrence and state compression were checked against brute-force enumeration for small N and against the provided samples. The special FPS path matches the direct recurrence on dense constant-d cases.
- **Pitfalls:** The sentinel is valid only when the last character is W; otherwise the answer is 0. In CDQ, base = r[mid]-a[mid-1] is nonnegative because a[mid-1] < a[mid] <= r[mid]. The full convolution length is A_len + G_len - 1 = 2*A_len + B_len - 2, while only the first G_len coefficients are needed.
