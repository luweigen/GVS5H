Only values `<= threshold` can participate in edges; any larger value is isolated. For two active values, an edge exists exactly when both divide some `L <= threshold`, namely their lcm. Thus, for every `L <= threshold`, all present divisors of `L` must be connected. We can avoid checking pairs by sweeping each present divisor `d` over its multiples `L` and maintaining one representative present divisor for each `L`. Union each new divisor with that representative, which connects all present divisors of every `L`. The result is `O(threshold log threshold)` time and `O(threshold)` memory, and the answer is the initial node count minus successful unions.
