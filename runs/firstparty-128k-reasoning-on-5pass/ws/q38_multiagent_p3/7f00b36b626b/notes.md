- **Core reduction:** Any value greater than `threshold` is isolated because `lcm(x, y)` is a multiple of `x`, hence at least `x > threshold`. Only values `<= threshold` can participate in edges.
- **Edge equivalence:** For two active values `a` and `b`, an edge exists iff `lcm(a, b) <= threshold`. Equivalently, there exists some `m <= threshold` divisible by both `a` and `b`. If both divide `m`, then `lcm(a, b)` divides `m`, so the lcm is also `<= threshold`.
- **Sweep by multiples:** For each active value `d`, visit all multiples `m = d, 2d, 3d, ... <= threshold`. For each `m`, all active divisors of `m` must be in the same connected component. Keeping one representative `rep[m]` and unioning every later active divisor with it connects exactly the required clique for that `m`.
- **Correctness of representative union:** If `a` and `b` have `lcm(a, b) = m <= threshold`, then both are active divisors of `m`. When the second of them is processed for `m`, it is unioned with the current representative of `m`, which is already connected to all previously seen active divisors of `m`. Thus every true edge is represented, and no false edge is added because any two divisors of the same `m` have lcm dividing `m`.
- **Component counting:** Start with `len(nums)` components. Each successful union among active values merges two components, so subtract successful unions. Inactive values are never unioned and remain isolated.
- **Complexity:** Let `T = threshold`. The total number of visited multiples is at most `sum_{d=1}^{T} T/d = O(T log T)`. With `T <= 200000`, this is easily fast enough. Memory is `O(T)` for `parent`, `rank`, and `rep`.
- **Implementation details:** Use iterative find with path halving and union by rank to keep DSU operations near constant. Early return when there are no active values. The input constraint says all `nums` are unique, so one DSU node per active value is sufficient.
- **Verified cases:** Example 1 yields one successful union among active values `{2, 3, 4}`, giving `5 - 1 = 4`. Example 2 yields four successful unions among active values `{2, 3, 4, 8, 9}`, giving `6 - 4 = 2`. All values greater than `threshold` return `len(nums)`. `threshold = 1` leaves only value `1` active, with no unions. If `1` is present, it connects to every active value because it divides every multiple.
