- **Coverage model:** Chosen operations only turn 0 to 1, so success is union of covered sets equals [1,N]; cost is number of nonzero operations.
- **Cost 1:** Only a full interval [1,N] used as operation 1 can finish in one operation; any nonfull op1 or op2 leaves some position zero.
- **Cost 2 enumeration:** With two paid operations the types are 1+1, 1+2, or 2+2; each has a simple interval condition, and all are checked before cost 3.
- **1+1:** Two op1 intervals cover [1,N] iff one starts at 1, one ends at N, and they overlap/touch. It suffices to use the L=1 interval with maximum R and the R=N interval with minimum L; condition maxR1 + 1 >= minLN, with distinct indices unless full, which is handled as cost 1.
- **1+2 prefix/bisect fix:** Sort intervals by L ascending, R descending. Build prefix_max_R[i] = max R among positions 0..i. For current position p, a previous interval contains it iff some previous R >= current R. If prefix_max_R[p-1] >= R_p, bisect_left(prefix_max_R, R_p, 0, p) returns the earliest position q where the prefix maximum first reaches R_p. At that first crossing, interval q itself has R_q >= R_p, and q<p gives L_q <= L_p, so q contains p. This replaces the old max-R scan and makes sample 1 choose [1,4] as op1 and [2,4] as op2, producing exactly 2 / 2 0 1 0.
- **2+2:** Two op2 operations succeed iff their original intervals are disjoint, because the uncovered set is their intersection. Such a pair exists iff maxL > minR; the max-L and min-R intervals then form a valid disjoint pair.
- **Cost 3 and feasibility:** If no cost 1 or 2 exists and M >= 3, then maxL <= minR, so every interval contains [maxL, minR]. Let a be a max-L index and b a min-R index. If a != b, op2 on a and b leaves exactly [maxL, minR], and any third op1 covers it. If a == b, pick two other indices; op2 on a and one other leaves I_a, and the third op1 covers it. If M < 3 and no cost 1/2 exists, output -1.
- **Distinct-index checks:** Containment uses q<p, so distinct. 1+1 distinct unless full, returned earlier. 2+2 indices are distinct when maxL > minR because L<=R. Cost 3 explicitly picks distinct a,b,c, with fallback when max-L and min-R indices coincide.
- **Endpoint conventions:** Containment uses L_q <= L_p and R_q >= R_p. 1+1 uses +1 to allow touching. 2+2 uses strict > to require true disjointness.
- **Samples:** Sample 1 now outputs 2 / 2 0 1 0. Sample 2 outputs cost 1 on the full interval. Sample 3 outputs cost 2 via 1+1. Sample 4 outputs -1.
- **Complexity:** O(M log M) time from sorting and containment checks, O(M) memory.
