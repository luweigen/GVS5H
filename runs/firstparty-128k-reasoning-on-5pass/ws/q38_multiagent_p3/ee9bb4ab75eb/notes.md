- **Core reduction:** For a trie prefix node with original count c, deleting index i reduces its count by 1 exactly when i is in that node's subtree. The node can support k remaining strings iff the reduced count is at least k. Thus c >= k+1 is always usable, c == k is usable only outside the subtree, and c < k is never usable.
- **Trie build:** Insert every original index, increment count on every visited node, store depth, and append original indices to the terminal list of the final node. Duplicates remain as separate indices in the same terminal list.
- **Global base:** `global_best` is the maximum depth over nodes with count >= k+1. Since n > k after the early return, the root qualifies, so the base is at least 0.
- **Marked nodes:** Nodes with count == k are marked and inserted into a max-heap keyed by depth. An `active` flag means the marked node is not currently on the DFS path.
- **DFS invariant:** When processing terminal node u for word i, exactly the marked ancestors of u are inactive. Therefore, after lazily popping inactive heap entries, the heap top is the deepest marked node whose subtree does not contain i, i.e. the best count == k prefix usable for that deletion.
- **Iterative traversal:** Use a stack with nonnegative enter markers and `~node` exit markers. On enter, deactivate a marked node, clean the heap, answer all terminal indices at that node with max(global_best, heap top depth), push the exit marker, then extend children. On exit, reactivate the marked node and push it back.
- **Lazy heap details:** If an inactive entry is popped while the node is on the path, pushing it back on exit restores it. If it was not popped, the exit push creates a duplicate active entry. Duplicates are harmless because each node is entered once and never deactivated again. Each inactive entry is popped at most once.
- **Edge cases:** n <= k returns all zeros. k = 1 works because count >= 2 nodes form the global base and count == 1 nodes represent unique prefixes or words; a deleted word's own terminal node is deactivated, while longer descendant words remain active. Prefix-of-another-word cases are handled because a word ending at an ancestor is not in a descendant's subtree.
- **Implementation choices:** Use `None` for absent children and terminal lists to save memory. Use `bytearray` for marked/active flags. Use bitwise complement `~node` for exit markers to avoid tuple stack entries. Delete `count` after marking to reduce memory.
- **Complexity:** Trie build is O(total word length). DFS visits each node once and each terminal index once. Heap operations are O(number of marked nodes log number of marked nodes). Memory is O(total word length + n).
- **Verification:** The program includes the two given examples, targeted edge-case asserts, and 500 seeded random small tests against a brute-force prefix-counter. The brute force is only for verification and is guarded by `__main__`.
