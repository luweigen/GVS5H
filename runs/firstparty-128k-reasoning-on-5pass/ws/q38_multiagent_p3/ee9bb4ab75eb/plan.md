Build a trie of all words, storing each node's depth and the number of words in its subtree, and record the terminal node for every input index. For a removed index i, a trie node is usable exactly when its subtree count minus 1 if i is inside the subtree is at least k, so the answer is the deepest usable node. Nodes with count >= k+1 are usable for every i and give a global base answer. Nodes with count == k are usable only for indices outside their subtree, so they can be processed as range-max updates over the Euler tour outside each node's interval. For each word, take the maximum of the base and the point query at its terminal Euler position, returning zeros when n <= k.
