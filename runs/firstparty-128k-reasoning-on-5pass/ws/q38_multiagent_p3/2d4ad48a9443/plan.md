For a subarray [l, r], the minimum increments needed are obtained by raising each element to the running prefix maximum, so cost(l, r) = sum_{i=l}^r max(nums[l..i]) - sum(nums[l..r]). Cost is monotone when a subarray is extended, so for each right endpoint the valid left endpoints form a suffix and the left boundary can be maintained with a two-pointer scan. In a current window [L, R], an index i is a running-max record iff its previous greater-or-equal position pg[i] is before L; it contributes nums[i] to the prefix-max sum for positions i through min(ng[i]-1, R), where ng[i] is the next strictly greater position. Maintain the window prefix-max sum and a slope S, the sum of nums[i] over active records with ng[i] > R. When R advances, remove active records with ng[i] == R from S, add the new index R to S if pg[R] < L, and increase the prefix-max sum by S; when L advances, remove the old left record's current contribution and activate all indices with pg[i] == L, adding their current contribution and updating S if ng[i] > R. This yields an O(n) time, O(n) memory solution.
