- **Interpretation:** K is the number of vertices in each path, not the number of edges. The input tree has M=N*K vertices, and we need a vertex-disjoint cover by N paths of K vertices.
- **Rooted state:** Root the tree at 1. For any subtree, at most one path can use the edge to the parent because vertices are disjoint. If such a path exists, the part inside the subtree must end at the subtree root. Closed paths contribute multiples of K vertices, so the open part length is forced by subtree size modulo K. Therefore only two states are needed: full (no open path, possible only when size mod K is 0) and open (one open path ending at the node, length size mod K, possible only when nonzero).
- **Child forcing:** For a child c with r=size_mod[c], if r=0 it must be full; if r>0 it must be open and its open segment must be connected through v. There is no optional choice. If the required state is false, v is impossible.
- **Transition:** Let bad be the number of children with r>0, and b1,b2 the first two such r values. Let s=(1+sum r) mod K. For K=1, v is full iff all children are full. For K>1, open is possible only when s>0 and either bad=0 (then s=1) or bad=1 and s=1+b1, which is equivalent to 1+b1<K. Full is possible only when s=0 and either bad=1 with b1=K-1, or bad=2 with b1+b2=K-1. bad=0 full only for K=1; bad>2 is impossible because the path containing v can use at most two child branches, or only one if it also goes to the parent.
- **Implementation:** Use iterative DFS to build parent and a preorder list, then process reversed order. Arrays size_mod, full, open_ store the DP. Accumulate s with one subtraction because both s and r are below K. The answer is full[1].
- **Edge cases:** K=1 is always Yes and is handled by the K==1 branch. M=1 works. The root must be full. Invalid children propagate to the parent. A node with three or more positive-mod children is impossible. Sample 2 fails because a node has two leaf open paths of length 1 for K=2, but a 2-vertex path through the node can absorb only one.
- **Complexity:** O(NK) time and O(NK) memory.
