Root the given tree at vertex 1 and process it bottom-up. For each subtree, the length of the only possible unfinished path that must be extended to the parent is forced by the subtree size modulo K, so each node needs only two booleans: fully decomposable, or decomposable with one open path ending at the node. A node may leave an open path only by using itself alone or by extending exactly one child's open path; it may close a K-vertex path by using one or two child open paths whose lengths plus the node equal K. All other child subtrees must be fully decomposable, so the transition depends only on the count and modulo lengths of children that are not fully decomposable. This gives a linear-time DP, and the answer is Yes exactly when the root is fully decomposable.
