The graph is bipartite, so each connected component has a fixed 2-coloring up to flipping. A move either adds a missing edge inside one component or merges two components. For odd N, every terminal complete bipartite graph has an even number of edges, so the parity of the total number of moves is fixed and equals M mod 2. For even N, the key invariants are: P, the parity of the total number of missing edges inside components; X, the number of odd-sized components; and whether any odd-sized component has at least one edge. If an odd-sized non-isolated component exists, the first player can force a win. Otherwise all odd components are isolated vertices, and the position is losing exactly when P + X/2 is even.
