Use the sorted order and match small mochi with large mochi. Treat the first half as potential tops and the second half as potential bottoms, because any valid pair must use a smaller/equal top and a larger bottom. Advance a pointer over tops and a pointer over bottoms; when the current top fits on the current bottom, form a pair and advance both, otherwise discard the current bottom by advancing it. This greedy maximizes the number of pairs because using the smallest possible top for the smallest feasible bottom never hurts. The answer is the number of successful matches, at most floor(N/2).
