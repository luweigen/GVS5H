- **Core invariant:** Labeled pieces preserve order. The final B ones correspond to partitioning the A pieces into K nonempty contiguous blocks. Exactly K-1 initial A gaps become the B gaps; all other A gaps collapse to 0.
- **Gap feasibility:** A matched A gap d and B gap h require d >= h. Let r be the required reduction: r = d - h for matched gaps, r = d for collapsed gaps. Endpoint-operation parities c_j satisfy r_j ≡ c_j + c_{j+1} (mod 2), and r_j = 0 forces c_j = c_{j+1} = 0. Since A gaps are positive, only matched equal gaps d = h can have r = 0.
- **Parity state:** For start parity p = c_1 mod 2, before processing an A gap and after r B gaps have been matched, the left endpoint parity is p ^ parity(previous A gaps) ^ parity(first r B gaps). An equal matched gap d = h is allowed only when this value is 0.
- **Greedy feasibility:** For fixed p, the set of achievable matched B-gap counts after any prefix is always 0..R. Only state R can increase the maximum, so one scan of A gaps is enough: match the next B gap when d >= h and either d > h or the equal-gap parity condition holds. This decides feasibility for that p.
- **Cost formula:** D = spanA - spanB, C = b1 - a1. For a feasible p, minimal endpoint parities are e1 = p and eM = p ^ (D & 1). Span-reducing operations are t = (D + e1 + eM) // 2. During these operations the leftmost piece moves right by t - e1, so the remaining whole-configuration shift is abs(C - (t - e1)). Total cost is t + that shift.
- **Edge cases:** K > M or spanA < spanB is impossible. M = 1 is just |a1 - b1|. K = 1 has no B gaps; both p values are feasible and the minimum cost is taken. D = 0 is handled naturally and usually gives a pure shift when p = 0 is feasible.
- **Implementation details:** The final solver uses bytes count/find/rfind for counts and endpoints, builds only the B gap list, and scans A twice (once per p) to avoid storing A gaps. Complexity is linear in the total input size, O(sum N).
- **Validation:** Small brute-force BFS checks on tiny N were used during development and agree with this solver; sample outputs are 3, -1, 5. The submitted program contains only the linear solver.
