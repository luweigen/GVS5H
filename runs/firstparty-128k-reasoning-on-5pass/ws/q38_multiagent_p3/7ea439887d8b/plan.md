Model the process as a shortest path problem on a graph with two layers: one layer for the original edge directions and one layer for the reversed edge directions. A state is `(vertex, layer)`, where layer 0 means edges are currently in their original direction and layer 1 means they are reversed. In layer 0, moving along an edge follows the original outgoing edges with cost 1; in layer 1, moving follows the original incoming edges with cost 1. Reversing all edges is represented by an edge from `(v, 0)` to `(v, 1)` and from `(v, 1)` to `(v, 0)` with cost X. Run Dijkstra from `(1, 0)` and return the minimum distance to either `(N, 0)` or `(N, 1)`, equivalently the first popped state whose vertex is N. Use 64-bit or arbitrary-precision integers because the answer can exceed 32-bit range.
