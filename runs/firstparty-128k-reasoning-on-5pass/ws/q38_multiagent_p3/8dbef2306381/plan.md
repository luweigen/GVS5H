Maintain a B-bit mask for the last B squares, where bit k represents square cur-B+1+k and cur is the last processed square. For the next square, if it is safe the new bit is the OR of mask bits 0 through B-A (the positions reachable by jumps A..B); if it is bad the new bit is 0, then shift the mask right and append the new bit. Process the line in blocks: initial square 1 is reachable, then for each interval apply the safe gap before it and the bad interval itself, and finally the safe gap to N. Fast-forward blocks instead of stepping to N: a bad block of length L shifts the mask right by L (zero if L>=B); a safe block with A==B is a rotation, so advance by L mod B; a safe block with A<B is simulated for at most a small constant THRESH = B + A + A*(A-1) + 5, and if the gap is longer and the mask is nonzero, set the mask to all ones because a reachable square can generate all later squares after a bounded offset. Output Yes iff the newest bit is set after processing N.
