- **Model:** Let a_ij = 1 for A and 0 for B. Let x_ij be the bit on the vertical shared edge between (i,j) and (i,j+1), and y_ij the bit on the horizontal shared edge between (i-1,j) and (i,j). The torus no-dead-end condition means each shared edge has one common bit.
- **Tile equations:** For A: y_ij xor y_i+1,j = 1 and x_i,j-1 xor x_i,j = 1. For B: both differences are 0, and y_ij xor x_i,j-1 = 1. These exactly encode the four A rotations and two B rotations.
- **Row cycles:** For fixed row i, the x-equations around the torus are consistent iff xor_j a_ij = 0. Then one free bit s_i = x_i,-1 remains, and x_i,j-1 = s_i xor prefix_left, where prefix_left is the xor of a_i,0..j-1.
- **Column cycles:** For fixed column j, the y-equations are consistent iff xor_i a_ij = 0. Then one free bit r_j = y_0,j remains, and y_i,j = r_j xor prefix_top, where prefix_top is the xor of a_0..i-1,j.
- **Reduced constraints:** For each B cell, y_ij xor x_i,j-1 = 1 becomes s_i xor r_j = 1 xor prefix_top xor prefix_left. While scanning row i left to right, left_ref is prefix_left and col_ref[j] is prefix_top, so union row i with column H+j using weight 1 ^ col_ref[j] ^ left_ref.
- **Parity DSU:** Maintain XOR potentials to roots. find returns the root and the xor from the node to the root. union enforces val[u] xor val[v] = w. If the roots are equal, check the existing potential; if different, attach by size and set the child root parity to w ^ pu ^ pv.
- **Answer:** If any row prefix is nonzero after a row, any final col_ref is nonzero, or DSU finds a contradiction, the answer is 0. Otherwise every connected component of the row/column constraint graph has one free bit, so the answer is 2^(component count) modulo 998244353.
- **Complexity:** O(HW alpha(H+W)) per test case and O(H+W) DSU memory. The total HW over all cases is at most 1e6, so this is easily fast enough.
- **Implementation details:** Use sys.stdin.buffer.read().split() for fast input. Bytes values are 65 for A and 66 for B. For A cells, only flip left_ref and col_ref[j]; for B cells, perform the DSU union and leave prefixes unchanged. If a case is already bad, skip processing remaining rows but still advance the input index.
- **Find correctness:** The iterative find stores the original xor to the root before path compression, because the compression loop mutates a running xor. This avoids returning 0 for non-root nodes.
- **Edge cases:** H=1 or W=1 are handled by the same cycle parity checks; a single-cell cycle forces a_ij = 0. Isolated row or column vertices remain DSU components and contribute free bits. All-A valid cases give 2^(H+W), and all-B valid cases give 2.
- **Verification:** Sample cases evaluate to 2, 0, 2. The reduced equations match brute-force enumeration of all rotations for tiny grids, and an explicit 4x5 pattern with even row/column parities but an inconsistent B-cycle is caught by the DSU.
