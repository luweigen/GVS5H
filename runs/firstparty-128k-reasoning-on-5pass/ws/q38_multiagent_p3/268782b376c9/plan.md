Binary search the target minimum score X, because feasibility is monotone. For a fixed X, compute required visits c_i=ceil(X/points[i]); for X>0 the walk must reach n-1, so choose the final index t and use the minimal base walk that reaches n-1 and ends at t, costing 2n-1-t moves. The base walk gives each vertex 1 or 2 visits; all further visits are added in pairs on edges, and the minimum number of such pairs needed to cover the deficits equals the maximum-weight independent set of the deficit weights on the path. Since each vertex's deficit is low for t<=i and high for t>i, compute the MWIS for every t in O(n) by combining a prefix DP over high weights with a suffix DP over low weights. Feasibility is true when min_t (2n-1-t + 2*MWIS_t) <= m; binary search up to min(m*min(points), m*max(points)//n).
