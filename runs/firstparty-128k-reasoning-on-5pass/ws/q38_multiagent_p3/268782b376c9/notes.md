- **Binary search bounds:** Feasibility is monotone. If m < n, no positive minimum is possible, return 0. Otherwise the n-move sweep 0..n-1 gives minimum min(points), so lo=min(points). An exclusive upper bound is min(m*min(points), m*max(points)//n)+1: the min-point index can be visited at most m times, and total score is at most m*max(points).
- **Visit requirements:** For X>0, required visits c_i=ceil(X/points[i]). Use h_i=(X-1)//points[i]=c_i-1. A quick necessary check is sum c_i=sum h_i+n <= m; during the suffix fill, if the partial sum of h_i exceeds m-n, return False immediately.
- **Skeleton for endpoint t:** For X>0 the walk must reach n-1. If it ends at t, the cheapest base walk goes 0..n-1 then back to t, costing base=2n-1-t moves. It visits i once for i<t and i=n-1, and twice for t<=i<=n-2. Thus deficits are high h_i for i<t and i=n-1, and low max(0,h_i-1) for t..n-2.
- **Extra moves as edge bounces:** Any additional traversal of an interior edge comes in pairs y_i, costing 2*sum y_i moves and adding y_{i-1}+y_i visits to vertex i. Covering deficits minimizes sum y_i subject to y_{i-1}+y_i>=d_i. The dual is a maximum-weight independent set on the path with weights d_i, so min moves for t is base + 2*independent_set_value(d(t)).
- **O(n) independent set scan:** For each t the weight sequence is high prefix 0..t-1, low middle t..n-2, high last. Precompute suffix states for S_t=[low_t,...,low_{n-2},high_{n-1}]: A_i=best with first vertex not chosen, B_i=best with first chosen, using B_i=w_i+A_{i+1}, A_i=max(A_{i+1},B_{i+1}). Scan t forward maintaining prefix high DP P0/P1 (last not chosen/chosen). Combine as max(P0+max(A_t,B_t), P1+A_t). Update prefix with h_t after checking t.
- **Boundary cases:** t=0 has empty prefix, so P1 is a negative sentinel. t=n-1 has suffix only the high last vertex. Endpoint t<n-1 is low because the skeleton returns to it; the last index is always high. The outside edge before 0 cannot be used for bounces. At most m moves means minimal cost <=m is sufficient.
- **Implementation details:** Preallocate h, A, B and reuse them for each feasibility call. Use integer division only. The total-visit early exit also keeps DP values bounded by about m-n for fully checked candidates. Skip cost computation when base cost alone exceeds m.
- **Validation:** Small brute-force walk enumeration for small n and m matches the formula, including n=2 parity cases, m=n, m=n+1, all-equal points, and asymmetric points. Edge cases such as m<n and large upper bounds behave as expected.
