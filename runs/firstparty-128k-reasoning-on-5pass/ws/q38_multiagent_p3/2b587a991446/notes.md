- **Model:** The state is two labeled tokens. A lower bound is `2d`, where `d = dist(S, T)`. The real question is the minimum extra cost needed to let the tokens pass.
- **Shortest path count:** BFS from `S` and `T`. In the DAG of edges with `distS[v] = distS[u] + 1` and `distS[u] + 1 + distT[v] == d`, count S-T paths capped at 2. If at least two shortest paths exist, answer is `2d`: one token can use one shortest path and the other the other, with a zero-extra passing segment.
- **Unique path:** If the count is 1, reconstruct the unique shortest path `P` by following the unique neighbor with `distS = i` and `distT = d - i`. Mark its vertices.
- **Detour cost:** For a walk in `G \ P` from `P_i` to `P_j`, the extra over the corresponding P segment is `length - (j - i)`. Edge weight `1 - (distS[v] - distS[u])` telescopes to this value. Since adjacent BFS distances differ by at most 1, weights are only 0, 1, 2.
- **Endpoint restriction:** A useful passing excursion must start at some `P_i` with `i < d` and end at some `P_j` with `j > 0`. Loops only at `S` or only at `T` cannot let the pieces pass a unique shortest path, so source `T` and target `S` are excluded. Any feasible swap must contain such an excursion, and its cost is at most the total extra, so the minimum such cost is optimal.
- **Dijkstra:** Multi-source on outside vertices. Initialize outside neighbor `x` of `P_i` (`i < d`) with `1 - (distS[x] - i)`. Relax outside edges with `1 - (distS[v] - distS[u])`. A candidate answer comes from outside neighbor `x` of `P_j` (`j > 0`): `dist[x] + 1 - (j - distS[x])`. If none exists, print `-1`; otherwise print `2d + best`.
- **Small-weight Dijkstra:** Because weights are 0, 1, 2, use three deques as Dial buckets aligned with current distance modulo 3. Stale entries are skipped by checking `dist[u] == cur`.
- **Achievability:** For a found walk `Q` from `P_i` to `P_j` (the optimal orientation can be assumed `i <= j`), let one token follow `P` and the other follow `P + Q`. Move the P-token to the far endpoint, then let the detour token leave while the P-token steps away; finish along `P`. This works for `i < j` and for internal loops.
- **Edge cases:** `N = 2` pure edge gives `-1`; `d = 1` triangle gives `3`; endpoint-only branches are impossible; an internal branch gives extra `2`; an S-T tunnel gives extra `length - d`; multiple shortest paths give `2d`.
- **Implementation:** Free large arrays before Dijkstra; use a `bytearray` for path marking; path reconstruction scans each path vertex once, total `O(M)`. Overall complexity is `O(N + M)` for BFS/DP plus `O(M)` for the small-weight Dijkstra.
