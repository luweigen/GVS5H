For each given N, use the explicit construction A = N + 1 and M = N^2. By the binomial theorem, (N + 1)^N ≡ 1 (mod N^2), so N is a valid exponent. For any 1 ≤ k < N, (N + 1)^k ≡ 1 + kN (mod N^2), which is not congruent to 1 because kN is not divisible by N^2. Therefore the smallest valid n is exactly N. The bounds are safe because N ≤ 10^9 gives M ≤ 10^18 and A ≤ 10^9 + 1. The case N = 1 also works with M = 1, since every n is valid and the smallest positive n is 1.
