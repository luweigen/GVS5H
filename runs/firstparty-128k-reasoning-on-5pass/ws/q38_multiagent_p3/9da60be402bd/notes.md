- **State model:** A palindromic walk is built from its center outward. A state `(u, v)` means the already built inner palindrome goes from `u` to `v`. Base states are `(i, i)` with length `0` and direct edges `(i, j)` with length `1`. If there is an edge `i -> u` with label `c` and an edge `v -> j` with label `c`, then state `(u, v)` extends to state `(i, j)` with length increased by `2`.
- **BFS order:** Every transition adds exactly `2`. Enqueue all diagonal `0` states first, then all direct-edge `1` states. FIFO processing then visits states in nondecreasing distance order, so the first time a pair is marked is its shortest palindromic walk length. Marking a pair before enqueueing prevents duplicate queue entries.
- **Bitset reporting:** For each vertex `u`, store `in_edges[u]` as pairs `(c, i)` for incoming edges `i -> u`. For each vertex `v`, store `out_mask[v][c]` as a bitmask of outgoing neighbors `j` with label `c`. For state `(u, v)`, for each `(c, i)` in `in_edges[u]`, the newly reachable pairs in row `i` are `out_mask[v][c] & row_unvisited[i]`. Clear that whole mask from `row_unvisited[i]`, then enumerate its bits to assign distances and enqueue states.
- **Complexity:** Each of the `N^2` pairs is assigned at most once, so bit enumeration is `O(N^2)`. The number of `(state, incoming edge)` iterations is at most `N * E`, where `E <= N^2`; for `N = 100` this is at most about `1,000,000` cheap integer-bit operations. This is easily fast in Python.
- **Orientation pitfall:** Outward extension from inner `(u, v)` must use an incoming edge to `u` (`i -> u`) and an outgoing edge from `v` (`v -> j`). Reversing either direction is incorrect.
- **Initialization pitfalls:** Diagonal answers are always `0`, even if self-loops exist, so self-loop direct edges should not overwrite them with `1`. All `0` states must be enqueued before any `1` state; otherwise a length `2` answer could be missed or a longer answer could be marked first.
- **Self-loops and repeated vertices:** Self-loops are included in `in_edges` and `out_mask`, so they can be used as outer edges. Non-simple walks are allowed. The state graph has only `N^2` nodes, so shortest state paths can be assumed simple in state-space, which keeps distances bounded.
- **Edge cases:** `N = 1` outputs `0`. A complete directed graph outputs `0` on the diagonal and `1` off-diagonal. With no edges, only diagonal entries are `0`. Unreachable pairs remain `-1`.
