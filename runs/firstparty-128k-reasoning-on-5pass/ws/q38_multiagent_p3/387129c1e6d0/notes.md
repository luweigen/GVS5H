- **Core idea:** Santa’s route is the union of closed axis-aligned segments. Group horizontal segments by their fixed y-coordinate and vertical segments by their fixed x-coordinate, then answer point-on-union queries for each house.
- **Simulation:** Keep the current point as Python integers. For each move, record the old and new endpoints. Horizontal moves append the x-interval to `horizontal[y]`; vertical moves append the y-interval to `vertical[x]`. The final point is simply the simulated position.
- **Merging:** For each coordinate key, sort intervals by left endpoint and merge while `next.start <= current.end`, extending `current.end` as needed. This gives disjoint intervals for the continuous union. Adjacent integer intervals such as `[0,1]` and `[2,3]` may be left unmerged and are still correct because all house coordinates are integers; merging them with `start <= end + 1` would also be safe.
- **House query:** For a house `(hx, hy)`, it is hit horizontally if `hy` exists in `horizontal` and `hx` lies in one of its merged x-intervals. It is hit vertically if `hx` exists in `vertical` and `hy` lies in one of its merged y-intervals. Count the house once if either condition is true, which avoids double counting intersections and repeated visits.
- **Binary search:** Store each merged group as two parallel lists, `starts` and `ends`. Use `bisect_right(starts, point) - 1` to find the last interval whose start is at most the point, then check whether the point is at most the corresponding end.
- **Complexity:** Sorting all interval groups costs `O(M log M)` in the worst case, and the N house queries cost `O(N log M)`. Memory is `O(N + M)` for houses, raw intervals, and merged interval lists.
- **Edge cases:** Final coordinates can reach about `2e14`, so Python integer arithmetic is important. Segment endpoints are inclusive. Overlapping, duplicate, and backtracking segments are handled by merging. A house lying on both a horizontal and a vertical segment is counted only once. Negative coordinates and large gaps are handled naturally by sorting and binary search.
- **Implementation notes:** Read all tokens with `sys.stdin.buffer.read().split()` for speed, then delete the token list after parsing to reduce memory. Use bytes comparisons for directions. Convert merged interval lists into `(starts, ends)` pairs to make binary search fast.
