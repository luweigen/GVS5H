A Snowflake kept as an induced subgraph is fully specified by its center c, the set B of its kept neighbors (the x middle vertices), and a common y. A neighbor b of c can be in B for a chosen y iff deg_T(b)-1 >= y, because it needs y other neighbors to become leaves. For fixed c and y, taking every such b is optimal, so the kept size is 1 + (y+1) * count_c(y). Thus we need max_c max_{y>=1} (y+1) count_c(y), where count_c(y) counts neighbors b with deg_T(b)-1 >= y. For each c this maximum is obtained by sorting the positive values deg_T(b)-1 of its neighbors descending and checking (value+1)*rank. The total length of all lists is O(N), so sorting per vertex gives O(N log N) time.
