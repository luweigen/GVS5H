- **Automaton:** Use the KMP prefix function for `str2`. States are `0..m`, where state `m` means the last `m` characters are exactly `str2`. Build transitions by copying `trans[pi[q-1]]` for `q > 0`, then overriding the matching character to `q+1` when `q < m`. State `m` only uses the fallback row.
- **Constraint timing:** The condition for `str1[i]` is checked at position `pos = i + m - 1`, i.e. after writing `word[pos]`. A `T` allows only state `m`; an `F` allows all states except `m`; unconstrained positions allow all states.
- **Backward DP:** `dp[pos]` is a Python integer bitmask of KMP states before `word[pos]` that can still complete the suffix. `dp[L]` is all states. The recurrence is `dp[pos] = {q | next_mask[q] intersects (dp[pos+1] & filter[pos])}`. If any required mask is empty, or state `0` is not in `dp[0]`, return `""`.
- **Shortcuts:** If the allowed next-state mask is `all_mask` or `nonfull_mask`, then every current state is feasible because at least one lowercase character avoids the full state. If the allowed mask is exactly `full_mask`, use the precomputed `can_full` preimage. These keep the worst case around 5.3M state checks for the limits.
- **Greedy reconstruction:** Start in state `0`. At each position, choose the smallest character `a..z` whose transition lands in `dp[pos+1] & filter[pos]`. This is lexicographically optimal because valid completions are partitioned by the first character, and the DP guarantees a completion exists for the chosen next state.
- **Complexity:** Worst-case time is `O((n + m) * m)` for the backward DP plus `O(26 * (n + m))` for reconstruction. Memory is `O((n + m))` big-int masks plus `O(m * 26)` for the automaton.
