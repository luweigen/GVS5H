Maintain nine small tables, one for each possible non-zero last digit `d`, where table `d` stores counts of residues modulo `d` for all substrings ending at the previous position. When reading a new digit `x`, extend every previous substring by `x`, mapping residue `r` to `(10*r + x) % d`, and also add the new one-character substring `x` to each table. If `x` is non-zero, the number of valid substrings ending here is exactly the updated count in table `x` for residue `0`, so add it to the answer. This naturally handles leading zeros and avoids `O(n^2)` enumeration. The algorithm runs in `O(9*9*n)` time and `O(81)` memory, easily within constraints.
