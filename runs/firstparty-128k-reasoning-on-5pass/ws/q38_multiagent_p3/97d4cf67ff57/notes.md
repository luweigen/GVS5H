- **Reduction:** In any valid alkane, vertices of degree 4 (call them carbons) form a connected set C in the original tree. The path between two carbons in the alkane is also the unique path in the original tree, and every internal vertex on that path has degree at least 2 in the alkane, hence must have degree 4.
- **Carbon constraints:** Every carbon has original degree at least 4, and it can have at most 4 carbon neighbors. All non-carbon selected vertices are leaves, and each leaf is adjacent to exactly one carbon.
- **Converse construction:** If C is any connected set of vertices with original degree at least 4 and induced degree at most 4, it can be extended to an alkane. For each v in C, attach exactly 4 - deg_C(v) neighboring vertices outside C as leaves. The tree structure guarantees these leaf neighbors can be chosen distinctly, and original degree at least 4 guarantees enough of them.
- **Size formula:** Since C is connected and acyclic, |E_C| = |C| - 1. The total alkane size is |C| + sum_v (4 - deg_C(v)) = 3|C| + 2. Therefore maximize |C|.
- **Optimization problem:** Find the largest connected subgraph of the forest induced by vertices with original degree at least 4, subject to maximum internal degree at most 4.
- **DP state:** Root each marked component. Let dp[u] be the maximum carbon count in a connected chosen set inside u's subtree that contains u, assuming the edge to u's parent is also chosen. Then u may choose at most 3 marked child edges. If u is the highest chosen carbon, it may choose at most 4 marked child edges.
- **Transition:** For each marked child v, the best contribution is dp[v]. Since all contributions are positive, choose the largest up to the allowed number. Thus dp[u] = 1 + sum of top 3 child dp values, and top[u] = 1 + sum of top 4 child dp values. The answer is max top[u].
- **Implementation:** Build adjacency and original degrees. Mark vertices with degree at least 4. If none exist, output -1. Iteratively DFS the marked forest to obtain a parent array and a preorder. Process the reversed preorder so children are processed before parents. Maintain the top four child dp values with four variables for O(1) per child.
- **Edge cases:** A single marked vertex gives C size 1 and answer 5. A marked vertex with more than 4 marked children is handled by the top-3/top-4 caps. Marked vertices not included in C may still be used as leaves; unmarked vertices can only be leaves.
- **Samples:** Sample 1 has marked vertices 2 and 3 connected, so C size 2 and answer 8. Sample 2 has no degree-4 vertex, so -1. Sample 3 has marked vertices 1, 5, 9 forming a path, so C size 3 and answer 11.
- **Complexity:** O(N) time and O(N) memory. Iterative traversal avoids recursion depth issues.
