Root the given tree arbitrarily and process vertices in postorder. For a vertex u, if the edge to its parent is used, u must have either 0 selected child edges (making u a leaf of size 1) or 3 selected child edges (making u degree 4); denote the best size of the latter by f3[u]. For each child v, the best size of a branch hanging from v is max(1, f3[v]), because v can either be a leaf or a degree-4 vertex. The highest vertex of a valid alkane has no parent edge, so it must have either 1 selected child, in which case that child's branch must already contain a degree-4 vertex, or 4 selected children, in which case the highest vertex itself is degree 4. Therefore the answer is the maximum over all vertices of these two top-vertex candidates, or -1 if none exists.
