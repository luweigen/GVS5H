Compute the inversion count for k=0 directly using a Fenwick tree over values 0..M-1 in O(N log M). Observe that moving from k to k+1 only changes the relative order of pairs where one element has current value M-1, because all other values just increase by 1. For a fixed original value p that becomes M-1 at step k (p = M-1-k mod M), the total change equals the sum over positions i with A_i=p of (number of earlier non-p elements) - (number of later non-p elements). Precompute this delta for every p in O(N) by scanning positions and maintaining counts of p seen, or using prefix counts. Then start from ans[0] and apply deltas in the order p=M-1,M-2,...,0 to obtain all M answers in O(M).
