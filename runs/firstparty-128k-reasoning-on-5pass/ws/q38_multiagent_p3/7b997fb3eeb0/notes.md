- **Core reduction:** For a query interval [l, r] of length C, if K pairs can be made, the K tops may be assumed to be the K smallest elements and the K bottoms the K largest. Pairing them in sorted order is necessary and sufficient, so K is feasible iff A[l+t-1] <= A[r-K+t]/2 for every t=1..K.
- **nxt and gap:** Use 0-based indices. nxt[i] is the first index j with A[j] >= 2*A[i], or N if none. gap[i] = nxt[i] - i. For top i to be usable in a K-pair solution, we need nxt[i] <= r-K+i-l+1, equivalent to K <= C-gap[i].
- **Feasibility predicate:** K is feasible iff K <= C//2 and max gap over [l, l+K-1] <= C-K. This predicate is monotone, but the final solution evaluates the maximum K directly.
- **M reformulation:** For each i in [l, r], if K > i-l then i is among the first K tops and must satisfy K <= C-gap[i]; if K <= i-l, i imposes no gap constraint. Hence K must be <= max(i-l, C-gap[i]) for every i. The minimum of these upper bounds equals C - max_i min(gap[i], r-i+1). Let M be that maximum; the answer is min(C//2, C-M).
- **Computing M:** Because A is sorted, nxt is nondecreasing. For fixed r, split by nxt[i] <= r+1. If nxt[i] <= r+1, then gap[i] <= r-i+1 and min(gap[i], r-i+1) = gap[i]. Otherwise the minimum is r-i+1. Let s = bisect_right(nxt, r+1). The first contribution is a range maximum of gap over [l, min(r, s-1)]. The second contribution is the maximum of r-i+1 over [max(l, s), r], which is r+1-max(l,s) when s <= r.
- **Two-pointer:** Compute nxt in O(N) with a nondecreasing pointer j. Before i, set j = i+1 if j <= i, then advance while j < N and A[j] < 2*A[i]. Store nxt[i]=j and gap[i]=j-i.
- **Data structure:** Build an iterative max segment tree over gap. Each query does one bisect and at most one O(log N) inclusive range maximum. Total time is O(N + Q log N) after O(N) preprocessing; memory is O(N).
- **Edge cases:** Sentinel N is correct because the threshold for the split is r+1. Equality nxt[i] = r+1 can be assigned to either side since gap[i] = r-i+1 there. If s <= l, the second term is C and the answer becomes 0. The half-length cap C//2 is still needed when C-M is larger.
- **Implementation notes:** Convert L,R to 0-based. Use bulk integer input and joined output. The segment tree leaves are filled from gap; unused leaves are 0. The range maximum loop is inclusive and uses bit operations. No recursion is used.
