- **Model:** Represent the parenthesis string as an ordered rooted forest: add a dummy root, make each opening parenthesis a node, and let the top-level balanced components inside it be its ordered children. A valid contiguous substring is exactly a consecutive block of siblings under one parent.
- **Operation effect:** Reverse-complementing such a block reverses the sibling order and applies the mirror transformation to each child subtree. The mirror is an involution and preserves the unordered rooted-forest isomorphism class.
- **Reachability:** Mirroring one sibling is possible by choosing its whole subtree. Two adjacent siblings can be swapped by mirroring both, then operating on their two-sibling block; the mirrors cancel, leaving a pure adjacent swap. Therefore arbitrary sibling permutations and all internal ordered variants are reachable, so the orbit is exactly all ordered forests in the same unordered class.
- **Counting:** For an unordered class with child class multiplicities and total child count, the number of ordered representatives is the multinomial coefficient for arranging child classes times the product of child class counts raised to their multiplicities. Leaves have count one. The dummy root uses the same formula on top-level components.
- **Implementation:** Parse with a dummy-root stack. On closing parenthesis, sort child class ids, canonicalize the tuple, compute the class count using precomputed factorials and inverse factorials, and append the class id to the parent. At the end, canonicalize the dummy root’s children and print its count.
- **Pitfalls:** The operation is reverse-complement, not ordinary reversal. The dummy root is needed for top-level components. Identical child classes must be divided by their multiplicities. Each ordered forest corresponds to exactly one parenthesis string.
