Model each deletion operation as a monochromatic batch; the total cost is the number of batches plus the number of inversions between the batch order and the original sequence. There is an optimal solution where every batch is created at its first occurrence as the newest batch, so each element either continues its value's current batch or starts a new batch at its position. Process the sequence left to right; for a value whose current batch has version v, let w be the number of already processed elements in batches newer than v. If w=0 continue, if w>1 start a new batch, and if w=1 start a new batch exactly when the next occurrence of this value is earlier than the next occurrence of any value in a newer batch. Maintain w with a Fenwick tree over batch versions and the needed next-occurrence minimum with a segment tree, giving O(N log N) per test case.
