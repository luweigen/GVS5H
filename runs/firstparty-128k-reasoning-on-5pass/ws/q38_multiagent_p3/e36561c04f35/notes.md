- **Selftest:** Ran `python3 solution.py --selftest`; it printed PASS, so there is no mismatching sequence, exact answer, or greedy answer to report.
- **Model:** Each deletion removes one monochromatic batch. For a fixed batch partition and deletion order, the minimum adjacent swaps needed is the number of inversions between the original sequence and the batch order. Total cost is `#batches + inversions`, and this bound is achievable by sorting to the batch order and then deleting batches.
- **Canonical batches:** In an optimal solution, batches of the same value are consecutive in that value’s occurrence list and are deleted in occurrence order. A newly started batch can be assumed to be pushed on top of the batch stack.
- **Stack greedy:** Scan left to right. For current value `v`, let `B` be its latest batch and `w` be the number of already processed elements in batches above `B`. If `w = 0`, continue `B` for free. If `w >= 2`, start a new batch because paying 1 is better than at least 2 inversions. If `w = 1`, the only newer element is the top batch `T` of size 1; continuing and starting both cost 1. Tie-break by next occurrence: start iff the next occurrence of `v` is strictly earlier than the next occurrence of `T`’s value.
- **Why the tie-break works:** In the `w = 1` case, the choice is which value keeps the top slot. The first future occurrence of the chosen value can be processed free, while the other would cost 1. Choosing the value with the earlier next occurrence is optimal by an exchange argument; other intervening values push themselves to the top in both options and do not change the comparison.
- **Implementation:** One right-to-left pass computes `nxt`. One left-to-right pass maintains the stack. `w = 1` is detected by `idx == top - 1 and sizes[-1] == 1`. Use `INF = N + 1`. Complexity is `O(N)` per test case and `O(N)` memory.
- **Exact verifier:** The old per-state BFS was replaced by a reverse BFS from the empty sequence. Reverse operations are adjacent swaps and prepending a non-empty monochromatic run. Since every forward edge has a reverse edge of the same cost, the reverse distance from empty to a small sequence equals the exact answer.
- **Selftest scope:** Checks the samples, all sequences of length up to 7 over alphabets of size 1, 2, and 3, all length 8 sequences over alphabet size 2, all length 8 and 9 sequences over alphabet size 3, and 500 seeded random sequences of length 8-9 over alphabet size 3. It prints PASS if all match, otherwise prints FAIL with mismatches and exits with code 1.
- **Complexity:** Main solver is `O(sum N)`. The selftest precomputes all states up to length 9 over alphabet size 3, which is only 29524 states, and checks about 30k small sequences, so it is fast.
