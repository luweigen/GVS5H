- **Model:** A deletion order is a noncrossing matching of original positions; nested edges are allowed and correspond to deleting inner pairs first. If one element survives, its 1-indexed position must be odd, and no edge may cross it, so the left and right sides are independent even segments.
- **Even segment value:** For an even segment of length 2k, every matching gives k positive and k negative coefficients, so its score is at most the sum of the k largest values minus the sum of the k smallest values. This bound is attainable: mark the k largest values positive and the k smallest negative. Any balanced binary string has a noncrossing perfect matching between opposite marks (inductively pair an adjacent opposite pair and recurse), and every positive value is at least every negative value, so the total equals the bound. Thus f(segment) = sum(largest half) - sum(smallest half), depending only on the multiset.
- **Answer formula:** If N is even, answer is f(whole array). If N = 2M+1 is odd, the survivor can be at 1-indexed position 2k+1 for k=0..M; answer is max_k f(A[0:2k]) + f(A[2k+1:]). Let F[k] be f of the first 2k elements. Let R[t] be f of the first 2t elements of reversed(A), which equals f of the last 2t original elements. Then answer is max_{k=0..M} F[k] + R[M-k].
- **Heap maintenance:** prefix_f(seq, n) scans seq and maintains low as a max-heap of the smallest half and high as a min-heap of the largest half, with running sums. Invariant: all low values <= all high values, and len(low) == len(high) or len(low) == len(high)+1. Insert into low if x <= current max low, else into high, then move one element from the larger side to the other if needed. After every even count, record sum_high - sum_low. Empty segment has value 0.
- **Complexity:** Two scans for odd N, one for even N. Each element causes O(log N) heap work, so O(N log N) time and O(N) memory. Python ints handle the maximum score around 1.5e14.
- **Edge cases:** N=2 returns the single absolute difference. All-equal arrays give 0. Duplicates at the median are harmless because any split of equal values gives the same sum. Suffix values are obtained by reversing, since f is invariant under order.
- **Validation:** The program has an optional selftest mode (`python program.py selftest`) that checks the three samples and compares solve_array against a cached tuple brute force for N<=8 on deterministic patterns, all-equal arrays, duplicate-heavy random arrays, and general small random arrays. Normal execution with no arguments reads stdin and prints only the answer.
- **Pitfalls avoided:** Do not assume the survivor can be at an even position; do not combine left and right halves into one f for odd N; do not allow a matching edge to enclose the survivor; keep heap sizes balanced after every insertion, not only at even positions.
