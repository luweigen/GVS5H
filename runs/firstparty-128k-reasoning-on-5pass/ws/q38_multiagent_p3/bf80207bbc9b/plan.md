Model row and column flips as binary vectors r and c; the final cell value is A_{i,j} xor r_i xor c_j. For a fixed column-flip mask c, each row independently chooses r_i to minimize ones, giving cost min(popcount(row_i xor c), W - popcount(row_i xor c)). Thus the answer is the minimum over all 2^W column masks of the sum of these row costs. Since W <= 18, represent each row as a W-bit mask and compute the sum for every c as an XOR convolution of the row-frequency array with the kernel h[d] = min(popcount(d), W - popcount(d)). Use the Fast Walsh-Hadamard Transform to evaluate all c in O(H + W 2^W), then take the minimum.
