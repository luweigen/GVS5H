- **Identity:** Use |a-b| = a+b-2min(a,b). Precompute original-order prefix sums of A and B. The only nontrivial part is G(X,Y)=sum_{i<=X,j<=Y} min(A_i,B_j).
- **Min contribution formulas:** For sorted values V and threshold t, sum_{v in V} min(v,t) = pref[p] + (len(V)-p)*t, where p=bisect_right(V,t). For one value a against sorted P, sum_{p in P} min(a,p) = prefP[q] + (len(P)-q)*a, where q=bisect_right(P,a).
- **Block size:** S = isqrt((2*N*N)//K)+1 clamped to [1,N], which is the exact floor of N*sqrt(2/K). Blocks are over A indices, nb=ceil(N/S).
- **Full blocks:** A query with X has full blocks b < X//S. For each block, sweep B in original order up to the maximum Y among queries needing that block. Maintain the running block min-sum and add it to G for queries in that Y bucket whose full_count > b.
- **Partial block:** If L=X%S>0, the partial block is c=X//S. Group partial queries by block and sort by Y. Maintain g[pos] for the block’s original positions up to last_y. For each Y group, flush B[last_y:Y]: if length is 1, add min directly; otherwise sort P, build prefix sums, and update every A in the block using bisect_right. If the group contains any L>1, build the block prefix in the same pass; otherwise skip it. Answer L=1 via g[0], otherwise via prefix_g[L].
- **Edge cases:** X at a block boundary has no partial part. The last block may be shorter. b=0 and b=nb are handled by full_count and suffix maxima. Equal values are fine with bisect_right. Zero values are fine. Python integers safely hold values up to about 2e18.
- **Complexity:** Full work is O(N^2/S log S + nb*K). Partial work is O(K*S log N) plus sorting pending B intervals; total interval length per block is at most N. With the chosen S, the maximum constraints give roughly 7e6 full B steps and about 1.4e7 partial element updates, which is feasible.
- **Implementation details:** qbyY is 1-indexed while B slices are 0-indexed. Grouping equal Y values avoids repeated flushing. A prefix_valid flag avoids unnecessary prefix rebuilds. Special cases mP=1 and block length 1 avoid bisect overhead. accumulate is used for prefix sums.
