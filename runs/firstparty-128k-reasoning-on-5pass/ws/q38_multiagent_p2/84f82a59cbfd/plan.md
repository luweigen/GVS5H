A 400 number has exactly two distinct prime factors, each with an even exponent, so it can be written as \(N = (p^a q^b)^2\) where \(p,q\) are distinct primes and \(a,b \ge 1\). Thus the problem reduces to finding the largest integer \(M \le \lfloor \sqrt{A} \rfloor\) that has exactly two distinct prime factors, then returning \(M^2\). Since \(A \le 10^{12}\), we only need to precompute up to \(10^6\). Read all queries first, sieve up to \(\lfloor \sqrt{\max A} \rfloor\), collect all squares of numbers with exactly two distinct prime factors, and answer each query by binary search. This gives efficient preprocessing and fast per-query lookup.
