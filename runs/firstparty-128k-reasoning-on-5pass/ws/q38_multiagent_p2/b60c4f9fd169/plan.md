First reject immediately if the length difference exceeds K, since each insertion or deletion changes length by one. Otherwise compute the Levenshtein distance using Ukkonen's banded DP, keeping only states (i,j) with |i-j| <= K and capping all values at K+1. Iterate over the shorter string as rows and maintain two small arrays for the previous and current active diagonal band, applying the standard insert/delete/replace recurrence. This gives O(K * min(|S|,|T|)) time and O(K) memory, which is safe for lengths up to 500000 and K <= 20. Finally output Yes if the DP value at (|S|,|T|) is at most K, otherwise No.
