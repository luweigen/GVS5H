- **Reduction:** We need the largest induced subgraph that is a Snowflake Tree; the answer is N minus its size. A Snowflake with center c, x branches, and y leaves per branch has size 1 + x(y+1), with x,y >= 1.
- **Center choice:** The definition-center is not necessarily the highest-degree vertex. When x=1 the resulting tree is a star and the definition-center can be any leaf, so every vertex must be tried as c.
- **Fixed center criterion:** For fixed c and y, a neighbor b can be a branch iff it has at least y neighbors other than c, i.e. original deg(b) >= y+1. In a tree, the other-neighbor sets of different neighbors of c are disjoint, and no chosen leaf can be adjacent to c, another branch, or another leaf except through its own branch. Hence choices are independent and every eligible neighbor should be used for that y.
- **Formula:** Put d = y+1 (d >= 2). For center c, the best size is 1 + max_{d>=2} d * count{b in N(c) : deg(b) >= d}. If neighbor degrees are sorted ascending and d first appears at index i, the count is m-i, so the candidate is d*(m-i). Equivalently, with descending order, the candidate for position k is k * d_k.
- **Implementation:** Read input with sys.stdin.buffer, build adjacency and original degrees. For each c, handle one-neighbor and two-neighbor cases directly. For larger degree, build the list of neighbor degrees, sort ascending, iterate distinct d >= 2, and update best with d*(m-i). Finally print N - (best + 1).
- **Complexity:** The sum of neighbor-list lengths is 2N-2. Sorting per vertex costs sum m_c log m_c, bounded by O(N log N). Memory is O(N) for adjacency and degrees.
- **Pitfalls:** Do not use degrees after deletions; original degrees are upper bounds and sufficient. Do not allow d=1 because that would mean y=0. Do not restrict centers to high-degree vertices. When using ascending order, count >= d is m - first_index; with descending order, using m - first_index would overcount duplicates and smaller values.
- **Achievability:** For any c and d, keep c, all neighbors with degree >= d, and choose d-1 other neighbors for each such branch. Tree acyclicity guarantees the kept vertices induce exactly a Snowflake Tree, so the upper bound is attainable.
