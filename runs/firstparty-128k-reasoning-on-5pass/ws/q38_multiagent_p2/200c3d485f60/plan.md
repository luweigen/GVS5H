Model the array as runs of equal values. Exactly k equal adjacent pairs means there are r = n - k runs, obtained by choosing k of the n - 1 gaps to be equal. For a fixed set of equal gaps, adjacent runs must have different values, giving m choices for the first run and m - 1 choices for each subsequent run. Thus the count is C(n - 1, k) * m * (m - 1)^(r - 1) modulo 10^9 + 7. Compute the binomial coefficient with factorials and modular inverses up to n - 1, and use fast modular exponentiation for the power. Handle m = 1 by letting pow(0, 0, MOD) = 1 and pow(0, positive, MOD) = 0.
