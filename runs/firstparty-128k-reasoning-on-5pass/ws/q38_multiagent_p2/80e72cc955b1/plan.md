For each integer x, define c(x) as the number of floor-divisions by 4 needed to make it zero; this is the smallest k with x < 4^k. One operation can reduce the remaining c-value of two elements by 1, so the minimum operations for a query are max(max c in the range, ceil(sum c / 2)). Because c(x) is nondecreasing, the maximum over [l, r] is simply c(r). Precompute or compute prefix sums of c(x) over the small number of power-of-4 blocks up to 1e9 to get range sums in O(15) per query. Sum max(c(r), (range_sum + 1)//2) over all queries.
