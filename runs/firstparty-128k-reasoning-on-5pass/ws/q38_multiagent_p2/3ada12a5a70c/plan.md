Binary search the answer D, since feasibility is monotone. Map each boundary point to u=x+y and height f=min(u,2*side-u), splitting it into an upper chain (bottom/right) and a lower chain (left/top); within one chain Manhattan distance is |Δu|, and between chains it is max(|Δu|, f1+f2). For a fixed D, run a DP over the number of chosen points, where a state ending at point p stores the smallest relevant u-coordinate of the last chosen point on the opposite chain (or -inf if none). Transitions use the fact that if any valid endpoint is at least D behind the new point, the new state is -inf; otherwise only opposite-chain endpoints in the current D-window can be used, queried by a segment tree over f. Handle same-u upper/lower pairs separately, and return true when k points can be formed.
