- **Invariant check:** The final program first checks that the number of zeros is equal. If `X + Y > N`, or there are fewer than `X` zeros, or fewer than `Y` ones, no operation can ever be applied, so it returns Yes iff `S == T`. Otherwise it compares the 1-indexed positions of the k-th zero modulo `Y` and the k-th one modulo `X` for all k.
- **Necessity:** Operation A changes `0^X1^Y` to `1^Y0^X`, and Operation B is the reverse. Labeling zeros and ones left-to-right, each operation shifts the involved labeled zeros by `+Y` or `-Y` and the involved labeled ones by `-X` or `+X`; all other labels stay fixed. Hence counts and the ordered residue sequences are invariant.
- **Sufficiency:** Orient only `0^X1^Y -> 1^Y0^X`. This rewrite decreases the number of zero-before-one pairs by `X * Y`, so it terminates. The left side `0^X1^Y` has no nontrivial border, so two redexes cannot overlap; independent redexes commute, giving local confluence and therefore a unique normal form for each connected component.
- **Normal form determined by invariants:** In the level representation `b_c` = number of zeros with exactly `c` ones before them, a move transfers `X` zeros from level `c` to `c + Y` only when levels `c + 1, ..., c + Y - 1` are empty. One residues fix `b_c mod X`; zero residues fix the level modulo `Y` of each labeled zero and their order. In a normal form, every level containing a full `X`-chunk must be followed within distance `< Y` by an occupied level, or by the right boundary. This forces the placement of all chunks from right to left, so the normal form is uniquely determined by the invariants. Equal invariants therefore imply reachability.
- **Validation:** The optional brute-force self-test was run with `python program.py test`; it checked all `N <= 8`, all `X, Y`, and all string pairs, and found no counterexamples. The self-test code was removed from the final program. Sample 1 outputs Yes and Sample 2 outputs No.
- **Complexity:** The judge solution is `O(N)` time and `O(N)` memory for the residue lists. The early no-operation case avoids building the lists.
