- **Conflict check:** For each letter a appearing in S, all corresponding T letters must be identical; store f[a]. A second different target makes it impossible because operations only merge letter classes and never split them.
- **Forced mapping counts:** P is the set of letters present in S. M is the number of a in P with f[a] != a. Each such letter a must be the source x of at least one operation to disappear, so M is a lower bound and is achievable except for closed cycles.
- **Image and special case:** img is the set of f[a] for a in P, equal to the letters present in T. If |P| = 26, |img| = 26, and M > 0, f is a non-identity permutation of all 26 letters. There is no initially empty label, no final-empty label, and no tree edge into any cycle, so every non-self cycle is closed and cannot be broken; print -1. If M = 0, answer is 0.
- **Pure cycles:** Build edges a -> f[a] for a in P. Only directed cycles of length at least 2 matter. A cycle is pure when every node in it has indegree exactly 1 from P, i.e. only its cycle predecessor points to it. Then no outside source has a forced target inside the cycle, so no source operation can act as a temporary buffer; one extra operation is needed.
- **Non-pure cycles:** If a cycle node has an additional incoming edge from outside, the outside node (or a node on the path entering the cycle) can be used as a buffer. Moving the cycle predecessor into that outside label, then shifting the rest of the cycle, and finally moving the outside label to its target resolves the cycle using only the M operations of the involved sources.
- **Buffer availability:** Outside the all-26 permutation case, a buffer label always exists: either a letter absent from P (initially empty) or, when P has all 26 letters, a letter absent from img (final empty). One buffer can be reused for all pure cycles, but each pure cycle still requires one extra operation that moves the buffered cycle node to its final target.
- **Answer formula:** If consistent and not the all-26 non-identity permutation case, answer is M + pure_count, where pure_count is the number of pure non-self cycles.
- **Cycle detection:** With only 26 nodes, use state 0/1/2. Follow f while the current letter is present and unvisited. If a state-1 node is hit, the cycle is the suffix of the current path starting at that node. Ignore length-1 cycles. Check indeg[v] == 1 for all v in the cycle.
- **Indegree details:** Count only edges from present letters to present targets. Edges to absent targets do not create indegree and cannot make a cycle non-pure. For a non-self cycle, the cycle predecessor always contributes one indegree, so indegree 1 exactly means no outside incoming edge.
- **Samples and edge cases:** Sample 1 has four changed letters and no cycles, answer 4. Sample 2 has M=0. Sample 3 has a conflict. Sample 4 is a pure 3-cycle, answer 3+1=4. A 2-cycle with an outside node targeting it needs no extra; a 2-cycle with only fixed letters and no buffer in a full 26 permutation is impossible.
- **Pitfalls:** Count distinct source letters, not positions. Do not count self-loops. Do not treat fixed occupied letters as free buffers. Do not apply the -1 special case when M=0. Do not count a cycle as non-pure because of an indirect path; direct indegree >1 is the test.
