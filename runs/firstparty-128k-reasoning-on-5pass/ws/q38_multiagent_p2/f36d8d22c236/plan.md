First build the forced mapping from each letter of S to the letter it must become in T; if one S-letter would need two different targets, output -1. Count M, the number of S-letters whose target differs from themselves, and build a directed graph on the 26 letters using these mappings for letters that appear in S. Find all directed cycles of length at least two; a cycle is pure if no cycle node has an incoming edge from outside the cycle. If S and T both use all 26 letters and M>0, the mapping is a non-identity permutation and no safe buffer exists, so output -1. Otherwise a buffer is available, and the minimum number of operations is M plus the number of pure cycles.
