- **Model:** Row and column flips are involutions and commute, so only flip parities matter. For a fixed column-flip mask c, each row r independently contributes min(popcount(r xor c), W - popcount(r xor c)).
- **Convolution form:** Let cnt[r] be the frequency of row mask r, and g[x] = min(popcount(x), W - popcount(x)). The answer is min_c sum_r cnt[r] g[r xor c], which is the XOR convolution cnt * g evaluated at all c.
- **FWHT:** Use the unnormalized Walsh-Hadamard transform with butterfly (x+y, x-y). It is self-inverse up to factor N = 2^W, and H(a*b) = H(a)H(b) pointwise. Thus transform cnt, multiply by H(g), transform again, and divide by N.
- **Radial kernel optimization:** g depends only on popcount, so H(g)[k] depends only on t = popcount(k). Precompute Fhat[t] using the Krawtchouk sum: sum_s min(s, W-s) * sum_j (-1)^j C[t][j] C[W-t][s-j], with j bounded so both binomial indices are valid. This avoids transforming a full 2^W kernel.
- **Implementation details:** Read all tokens, count int(row, 2). Precompute binomial coefficients up to W. Run in-place FWHT twice. Multiply transformed cnt[i] by Fhat[popcount(i)]. The final array is N times the desired costs, so take min and integer-divide by N.
- **Edge cases:** W=1 gives Fhat all zero and answer 0. All final costs are nonnegative exact integers, so min before division is valid. Bit ordering is irrelevant because the kernel is radial and the minimum is over all masks.
- **Complexity:** O(H + W^3 + W 2^W) time and O(2^W) memory. For W=18 this is about 4.7 million butterflies total, which is feasible in Python.
