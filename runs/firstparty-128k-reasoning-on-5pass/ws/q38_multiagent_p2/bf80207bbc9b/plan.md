Model row and column flips as binary choices: each row may be flipped or not, and each column may be flipped or not. For a fixed column-flip mask, each row pattern independently contributes the smaller of the number of ones after applying that column mask or after also flipping the row. Count how many times each W-bit row pattern appears, then the total cost for every column mask is an XOR convolution of these counts with a kernel depending only on popcount. Since W ≤ 18, compute all column-mask costs using a Fast Walsh-Hadamard Transform in O(H + W·2^W). Finally, take the minimum value over all column masks.
