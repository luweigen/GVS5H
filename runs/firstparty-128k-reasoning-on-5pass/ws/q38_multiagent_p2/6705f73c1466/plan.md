Treat the ones as indistinguishable but preserve their relative order, since adjacent swaps only move them past zeros. If the ones are at sorted positions p_i, making them contiguous starting at position l costs sum |p_i - (l+i)|. This is equivalent to choosing l to minimize sum |(p_i - i) - l|, which is minimized when l is the median of the values p_i - i. Compute these values in one pass, take the median, and sum absolute deviations using 64-bit arithmetic. The result is the minimum number of adjacent swaps.
