View each interval as an element of the interval order \(i \prec j\) iff \(R_i < L_j\); the given graph is the undirected comparability graph of this order. With positive vertex weights, a minimum-weight path can be assumed chordless, and comparability graphs of interval orders contain no induced \(P_5\), so every minimum path has at most three edges. If the two query intervals are disjoint, the direct edge is already optimal. If they overlap, orient them by increasing left endpoint; a 2-edge path requires a vertex completely left of both or completely right of both, while a 3-edge path decomposes into an independent minimum-weight vertex with \(L\) in \((R_{\text{left}}, R_{\text{right}}]\) and an independent minimum-weight vertex with \(R\) in \([L_{\text{left}}, L_{\text{right}})\). Precompute prefix/suffix minima and range-min structures over \(L\) and \(R\) coordinates to answer all queries in \(O(\log N)\) each.
