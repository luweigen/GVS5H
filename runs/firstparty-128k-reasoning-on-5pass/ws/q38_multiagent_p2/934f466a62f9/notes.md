- **Reduction:** A pair price is the maximum of three coordinate sums, so each pair can be charged to one coordinate attaining the maximum. Thus the problem is equivalent to choosing exactly 2K cakes, coloring each with one of 3 attributes, requiring each attribute count to be even, and maximizing the sum of chosen attribute values.
- **Base solution:** Let s_i = max(X_i,Y_i,Z_i). Without parity constraints, the optimum is the top 2K cakes by s_i, with value B. Any tie-breaking and any argmax base color is valid.
- **Repair operations:** Relative to the base, a feasible solution differs by recoloring selected cakes and swapping selected cakes with unselected cakes. Recolor selected cake i from base color c to d: cost s_i - v_{i,d}, parity c^d. Swap selected j (base color c) with unselected i colored d: cost s_j - v_{i,d}, parity c^d. All costs are nonnegative because selected s-values dominate unselected s-values.
- **At most two operations:** Operation parity vectors lie in the 4-element even subgroup of GF(2)^3. Any multiset of such vectors with xor equal to the base parity p can be reduced to at most two vectors by canceling equal pairs and triples of distinct vectors. Since costs are nonnegative, the optimal loss is achieved by 0, 1, or 2 operations.
- **Enumeration:** Track selected-side actions: removals (r=1) and recolors (q=1), with r+q<=2. Track unselected-side additions (a=1). Combine only when r=a and selected parity xor unselected parity equals p.
- **Top-two safety:** For each action state, each cake appears at most once. Therefore, when pairing two states, keeping the two cheapest candidates per state is enough to resolve item conflicts. This is used for two removals, removal+recolor, two recolors, and two additions.
- **State layout:** Selected states are indexed by (r,q): offsets 0,8,16,24,32,40 for (0,0),(1,0),(2,0),(0,1),(1,1),(0,2). Unselected states are by addition count: offsets 0,8,16. Parity masks use bits 1,2,4.
- **Ties:** Top-two updates must accept equal costs to keep two distinct candidates. Base colors among ties and the top-2K set among ties may be arbitrary; the repair step handles zero-cost swaps/recolors.
- **Edge cases:** If K=N/2, there are no unselected cakes, so only recolors are possible. If base parity is already even, loss is 0 and the answer is B. Two swaps can be optimal, so r=2 must be considered.
- **Complexity:** Sorting dominates: O(N log N) per test case, with O(N) small-constant top-two maintenance. Total N is at most 1e5.
