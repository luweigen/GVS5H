First transform the problem: a pair's price is the maximum of the three coordinate sums, so the total is equivalent to choosing 2K cakes and assigning each chosen cake one of the three attributes, with each attribute used an even number of times. Let m_X,m_Y,m_Z be the numbers of pairs of each attribute; the maximum value for fixed (m_X,m_Y,m_Z) is the value of a 3-color b-matching, which is M-concave, so repeatedly adding one pair of the attribute with the largest marginal increase is optimal. Maintain an optimal assignment for the current pair counts. In the residual network for adding two cakes to a fixed attribute, only the three attribute nodes matter, and an augmenting path uses at most two reassignments; the best two-unit augmentation can be found by a constant-size DP over these paths using heaps of the best unused and switchable cakes. Apply the best augmentation, update the assignment and heaps, and repeat K times, giving O((N+K) log N) per test case.
