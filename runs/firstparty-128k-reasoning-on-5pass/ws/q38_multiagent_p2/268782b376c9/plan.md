Binary search the answer x, because feasibility is monotone: if a minimum score x is reachable, any smaller x is reachable. For a candidate x, compute req[i]=ceil(x/points[i]), the minimum number of visits to index i. The hard part is the minimum number of moves needed to visit each i at least req[i] times on a path starting at -1 and ending at some p. For a fixed end p, the base walk gives one visit to indices 0..p; extra visits can be modeled as back-and-forth traversals of edges, and the minimum extra traversals equals the maximum weight independent set on a path with weights req[i]-1 for i<=p and req[i] otherwise. The total moves for end p is 1+p+2*that MWIS weight, so check(x) asks whether min_p of this value is <=m. Evaluate all p in O(n) by precomputing suffix MWIS DP for the unmodified req weights and scanning p while maintaining a prefix DP for the decremented weights, combining them in O(1).
