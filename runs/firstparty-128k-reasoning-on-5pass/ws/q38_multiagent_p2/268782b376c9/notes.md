- **Binary search:** The answer is an integer and feasibility is monotone. Search over `0 <= x <= m * min(points)` with exclusive high `m * min(points) + 1`. If `m < n`, return `0` immediately because a positive minimum requires visiting every index at least once, which needs at least `n` moves.
- **Feasibility for x:** For `x > 0`, every index needs `req[i] = ceil(x / points[i])` visits. If `sum(req) > m`, return false because each move creates exactly one visit.
- **Endpoint model:** Fix the final index `p`. For `x > 0`, all vertices must be visited. The minimal edge traversals with correct parity are: if `p < n-1`, edges `i < p` once and edges `i >= p` twice; if `p = n-1`, all edges once. Base move count is `2n - 1 - p` for `p < n-1`, and `n` for `p = n-1`.
- **Base visits:** For `p < n-1`, vertices `i < p` are visited once, vertices `p <= i < n-1` twice, and vertex `n-1` once. For `p = n-1`, every vertex is visited once.
- **Extra visits:** Additional traversals of an internal edge must come in pairs. Let `y_i` be extra pairs on edge `i`. Extra visits to vertex `i` are `y_{i-1} + y_i`, with boundary `y = 0`. Demands are `d[i] = max(0, req[i] - base_visits[i])`.
- **MWIS reduction:** Minimizing `sum y_i` subject to `y_{i-1} + y_i >= d[i]` is a path edge-cover problem. Its LP dual is maximum-weight independent set on the path with weights `d[i]`. Thus minimum extra moves is `2 * MWIS(d)`.
- **Weight pattern:** Define `a[i] = req[i] - 1` and `b[i] = max(0, req[i] - 2)`. For `p < n-1`, the demand weights are `a[0..p-1]`, `b[p]`, `b[p+1..n-2]`, `a[n-1]`. For `p = n-1`, they are all `a[i]`.
- **O(n) check:** Precompute suffix two-state MWIS DP for `c[i] = b[i]` for `i < n-1` and `c[n-1] = a[n-1]`. `suf0[i]` / `suf1[i]` mean best on `i..n-1` with first vertex not selected / selected. Scan `p = 0..n-2` while maintaining prefix DP for `a[0..p-1]`. Combine left, middle `b[p]`, and suffix: `mid0 = max(pref0, pref1)`, `mid1 = pref0 + b[p]`, `best = max(mid0 + max(suf0[p+1], suf1[p+1]), mid1 + suf0[p+1])`. If `2n - 1 - p + 2 * best <= m`, feasible. Then update prefix with `a[p]`.
- **Endpoint n-1:** After the scan, prefix contains `a[0..n-2]`. Add `a[n-1]` to get MWIS of all `a`, and test `n + 2 * best <= m`.
- **Pitfall:** A base walk of length `p + 1` is invalid for `p < n-1` because the walk must still reach `n-1` and return to `p`. The corrected base length is `2n - 1 - p`.
- **Numerics:** When `sum(req) <= m`, all DP values are at most `m`, so Python integers stay small. Invalid selected state for an empty prefix is `-1`; all real weights are nonnegative.
- **Validation:** Brute-force DFS enumerates all walks for small `n` and `m`, comparing against the solution on fixed examples, exhaustive `n=2,3` with points `1..3` and `m<8`, and seeded random `n<=5`, `m<=10`.
