From (0,h), building i is visible iff (H_i-h)/X_i is strictly greater than every earlier (H_j-h)/X_j, so all buildings are visible exactly when the sequence A_i(h) is strictly increasing. A height where visibility fails is determined by an inversion A_i(h) >= A_j(h); the critical height for a pair is the intersection of the two lines A_i(h), which equals the y-intercept of the line through their tops. The maximum failing height is therefore the maximum pair intersection, and because the lines are sorted by slope, any non-adjacent intersection is a positive weighted average of adjacent intersections, so it suffices to check consecutive buildings. Compute the maximum fraction (H_i X_{i+1}-H_{i+1} X_i)/(X_{i+1}-X_i) exactly, output -1 if it is negative, 0 if zero, and its decimal value otherwise.
