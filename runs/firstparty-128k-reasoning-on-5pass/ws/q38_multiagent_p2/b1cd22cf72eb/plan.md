The minimum cost is the total initial tooth length minus \(N\) times the final common sum \(H\), so we need to maximize the feasible \(H\). For a fixed \(H\), the final upper tooth length at position \(i\) must lie in the interval \([\max(0, H-D_i), \min(H, U_i)]\). Feasibility for that \(H\) is whether we can choose one value from each interval such that adjacent upper lengths differ by at most \(X\), which can be checked greedily by propagating a reachable interval. Feasibility is monotone: if \(H\) is feasible, then \(H-1\) is feasible by reducing every upper tooth of length \(H\) by 1. Therefore we can binary search the largest feasible \(H\) in \([0, \min_i(U_i+D_i)]\). Finally, output \(\sum_i(U_i+D_i) - N \cdot H_{\max}\) using 64-bit arithmetic.
