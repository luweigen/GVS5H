- **Core sweep:** Fix second cut j=idx+1 (0-index idx). For a first cut i, the middle distinct count is the number of values whose last occurrence up to j is > i. When A[idx] is processed, if its previous 1-index position is p (0 if none), it adds 1 to first cuts i in [p, idx] 1-index, i.e. leaf range [p-1, idx) 0-index; if p=0 this is [0, idx).
- **Precomputations:** Leaf k (first cut i=k+1) starts as distinct(A[0..k]) for k=0..N-3. suff[pos] is distinct(A[pos..N-1]); for j=idx+1 the right part is suff[idx+1].
- **Difference form:** Maintain D so that value_i = prefix_distinct_i + sum_{t=0..i} D[t]. A range add [l,r) becomes D[l]+=1 and D[r]-=1. D[0] is a uniform add to all leaves, so it is kept in gadd instead of the tree. Thus l=0 updates do gadd+=1 and only D[idx]-=1 when idx<n; l>0 updates do D[l]+=1 and D[idx]-=1 when idx<n.
- **Segment tree monoid:** Each node stores sum of D in its segment and best = max(arr_i + sum of D from segment start to i). Combine left/right: sum=sL+sR, best=max(bestL, sL+bestR). Leaves have sum=D[i], best=arr_i+D[i]; unused leaves have best=NEG.
- **Updates:** Point updates change a leaf's sum and best, then recompute ancestors. When two point updates are needed, recompute the two root paths level by level in parallel, skipping the node once the paths merge.
- **Prefix query:** To query [0,r), climb from i=size+r. Whenever i is a right child, its left sibling is a canonical segment to prepend. If res is the best of segments to the right, new res = max(node.best, node.sum + res). No separate carry sum is needed because segments are always prepended. If r==n, use root best. Add gadd and suff[idx+1].
- **Indexing and edge cases:** last stores 1-indexed previous positions. The sweep runs idx=1..N-2 (range(1, N-1)); idx=0 only initializes last. For idx=n there is no D[idx] subtraction. N=3 has one leaf and works via the root query.
- **Pitfalls:** Do not query idx=0; suffix index is idx+1 in 0-index; repeat update range is [p-1, idx), not [p, idx); extra leaves must stay NEG; gadd must be added to the tree query result.
- **Complexity:** O(N log N) time and O(N) memory. Python lists are used for the two segment-tree arrays; size is the next power of two at most 524288 for N=3e5.
