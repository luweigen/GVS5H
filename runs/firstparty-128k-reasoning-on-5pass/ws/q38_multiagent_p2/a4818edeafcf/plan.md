Precompute the number of distinct values in every suffix so the right part can be added in O(1). Maintain a lazy segment tree over possible first cut positions i, where the value at i after processing prefix j equals distinct(1..i)+distinct(i+1..j). When A_j is first seen, it contributes 1 to every i, so add +1 to the whole tree; when A_j is seen again with previous last position p, it contributes one extra distinct to exactly cuts i in [p, j-1], so add +1 to that range. For each valid second cut j=2..N-1, query the maximum stored value over i=1..j-1 and add the precomputed suffix distinct count after j. The maximum over all j is the answer. This gives O(N log N) time and O(N) memory.
