First run a BFS/DFS to bipartition every connected component and record, for each component, the two color-class sizes, its edge count, and whether it is isolated. If N is odd, every terminal complete bipartite graph has an even number of edges, so the parity of the total number of moves is fixed to M mod 2; answer immediately. For N even, the parity of the terminal edge count is the parity of one final part, so the only strategic question is which of the two parities the first player can force. This question depends only on the counts of four component types (even-even, odd-odd, odd-even non-isolated, isolated) modulo 4 and on a constant number of categories for the total missing-edge count; the resulting finite-state game can be precomputed/hardcoded. Evaluate the initial state to obtain the parity the first player can force, and print Aoki iff that parity equals (M mod 2) xor 1.
