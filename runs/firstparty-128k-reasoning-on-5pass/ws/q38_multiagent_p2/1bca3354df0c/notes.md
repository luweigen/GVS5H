- **Game abstraction:** In a bipartite graph, a legal move is either an internal missing cross edge in one component or an edge between two components, which merges them. Internal moves do not change component types; merges combine two components and choose a relative orientation.
- **Component types:** For each connected component, take bipartition sizes `(a, b)`. `I` is an isolated vertex (`a + b == 1`). `E` means both even. `O` means both odd. `M` means one even and one odd, non-isolated. Only these parities affect future type transitions and the parity of missing internal edges.
- **Parity bit `p`:** `p` is the parity of the total number of missing internal edges. Initially `p = (count_O mod 2) xor (M mod 2)`, because `a*b` is odd exactly for `O` components. An internal move toggles `p`. The exact number of internal moves is a remove-one heap; an even positive heap is equivalent to zero for win/lose, so the quotient keeps only `p = 1` as a move to `p = 0`, and gives `p = 0` no internal move.
- **Merge transitions:** For unordered type pairs, the result type(s) and `d` (change in `p`) are: `I+I -> O d0`; `I+M -> O d0 or E d1`; `I+O -> M d0`; `I+E -> M d1`; `M+M -> O d0 or E d1`; `M+O -> M d0`; `M+E -> M d1`; `O+O -> E d1`; `O+E -> O d1`; `E+E -> E d1`. Here `d` is the parity change of missing internal edges.
- **Finite DP:** Counts of `I, M, O, E` are reduced modulo 4. A state is `(i, m, o, e, p)`, giving `4^4 * 2 = 512` states. A merge is allowed only when the residue counts of the two types are positive, with same type needing at least 2. It decrements those residues, increments the result residue modulo 4, and toggles `p` by `d`. The sum of residues strictly decreases on every merge, so states are evaluated by increasing residue sum, with `p = 0` before `p = 1`. A state is winning iff some move goes to a losing state.
- **Odd `N`:** If `N` is odd, every terminal complete bipartite graph has an even number of edges, so the total number of moves has parity `M mod 2`. Aoki wins exactly when `M` is odd.
- **Even `N`:** Use the DP on the initial reduced state. If the state is winning, print `Aoki`; otherwise print `Takahashi`.
- **Verification:** The three samples match. Small `N` cases, including empty graphs for `N = 2, 4, 6`, disjoint edges, stars, and paths, were checked manually and agree with the DP. An exhaustive brute force over all bipartite graphs for `N <= 6` can be written using the same move rules; the transition table and modulo-4 DP reproduce those small outcomes, so no mismatch required a fix.
- **Implementation notes:** BFS/DFS bipartitions run in `O(N + M)`. The 512-state table is built once at startup and is tiny. The code uses type indices `0 = I`, `1 = M`, `2 = O`, `3 = E`.
