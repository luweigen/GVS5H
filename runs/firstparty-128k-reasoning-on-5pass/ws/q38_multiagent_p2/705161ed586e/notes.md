- **State:** `F_i(l,c)` is the minimum cost to finish positions `i..n-1` when the run immediately before `i` has letter `c` and length `l` in {1,2,3}; 3 means at least 3. Base: `F_n(1,c)=F_n(2,c)=inf`, `F_n(3,c)=0`.
- **Transitions:** length 1 and length 2 must continue with `c`; length 3 may either continue `c` or start a new run with any `d != c`. The initial answer is `min_d cost_0(d)+F_1(1,d)`.
- **Lexicographic tie:** all completions from a state have the same remaining length. For length 1/2 the next character is forced. For length 3, the possible next characters are `c` for continuing and `d` for starting a new run, and these are distinct, so the smallest next character among minimum-cost options is sufficient. Store one byte per `(i,c)` for the length-3 choice.
- **Min over d != c:** for `S[d]=cost_i(d)+F_{i+1}(1,d)`, scan the 26 letters once and keep the best value/char, the second smallest char with the same best value, and the next distinct value/char. If `c` is the best char, use the second best char if present, otherwise the next distinct value; otherwise use the best char.
- **Implementation:** backward rolling arrays `dp1, dp2, dp3` of length 26. `choices` is a flat `bytearray(n*26)`, indexed by `i*26+c`. `inf=10**12`, `big=10**18`. At `i=0`, `first` and `initial_cost` are taken from the best `S[d]`. If `initial_cost >= inf` or `first < 0`, return `""`.
- **Reconstruction:** start with `first` and run length 1. For each next position, if length < 3 force the same letter; otherwise read the stored choice. If the choice equals the current letter, keep length 3; otherwise start a new run with length 1. Decode the bytearray.
- **Verification:** examples 1-3 match. `n=1,2` return `""`; `n=3..6` match exhaustive enumeration over `{a,b,c}`. All strings over `{a,b,c}` up to length 8 and random lowercase strings up to length 12 were checked against an independent brute force over valid run partitions and letters; no mismatch was found. A 50000-length random string runs comfortably within limits with O(26*n) time and O(26*n) bytes for choices.
