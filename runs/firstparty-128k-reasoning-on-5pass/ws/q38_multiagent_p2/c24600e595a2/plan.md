Show that an optimal walk can be rearranged so that all 1→0 flips happen before all 0→1 flips, and that only indices with A_i=B_i=1 are ever flipped more than once (exactly twice, off then on). For a chosen set S of such unchanged 1-bits to toggle, the optimal removal order is decreasing C over X∪S and the optimal addition order is increasing C over Y∪S. For a fixed number k of toggled unchanged 1-bits, an exchange argument proves S should be the k largest C values among A_i=B_i=1. Therefore sort the three groups and evaluate the total cost for k=0..|Z|, updating the two sorted-merge costs incrementally as each largest Z value is inserted.
