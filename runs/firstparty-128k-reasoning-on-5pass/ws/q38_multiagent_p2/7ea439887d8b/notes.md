- **State model:** The only persistent effect of reversing all edges is a binary orientation parity. A state is `(vertex, parity)`, where parity 0 means the original graph orientation and parity 1 means all edges are reversed. The start state is `(1, 0)`, and the goal is either `(N, 0)` or `(N, 1)`.
- **Transitions:** In parity 0, moving follows original outgoing edges with cost 1. In parity 1, moving follows original incoming edges with cost 1, because an original edge `u -> v` becomes `v -> u` after reversal. At every vertex, toggling parity costs `X`.
- **Algorithm:** Run Dijkstra on the implicit two-layer graph with `2N` states. Encode a state as `2 * vertex + parity`. From a popped state, relax the toggle edge and all movement edges. Stop as soon as a state whose vertex is `N` is popped, because Dijkstra pops states in nondecreasing final distance and both parities at `N` are accepting.
- **Complexity:** There are `2N` states and `2M + 2N` directed transitions: `M` original moves in layer 0, `M` reversed moves in layer 1, and two toggle directions per vertex. Time is `O((N + M) log N)`, memory is `O(N + M)`.
- **Implementation details:** Use 0-indexed vertices. Build both `out_edges` and `in_edges`. The reversed layer must use `in_edges`, not `out_edges`. Distances are stored in a flat array of length `2N`. The toggle of state `s` is `s ^ 1`. For movement, if parity is 0 the next state is `to << 1`; if parity is 1 it is `(to << 1) | 1`.
- **Integer range:** Python integers are arbitrary precision, so large answers such as sample 3 are safe. An `INF` of `10**30` is far above any possible shortest path under the constraints.
- **Sample checks:** Sample 1 is solved by four original moves, cost 4. Sample 2 is solved by move, reverse, reversed move, cost 3. Sample 3 forces alternating reversals and moves along a chain, giving `7 * X + 7 = 4294967299`. Sample 4 has a path with cost 21 using moves and three reversals, matching the expected output.
- **Pitfalls avoided:** The target can be reached in either orientation, so both target states matter. Early stopping is done only after a state is settled, not when it is first relaxed. Parallel edges and self-loops are harmless because they only produce redundant or non-improving relaxations.
