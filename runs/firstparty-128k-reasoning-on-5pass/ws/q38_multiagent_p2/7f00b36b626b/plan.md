Values greater than threshold can never be connected because lcm(a, b) >= max(a, b), so count them as isolated. For values at most threshold, an edge exists exactly when the two values share some common multiple not exceeding threshold, since their lcm is the smallest such multiple. Use a DSU over value labels 1..threshold, marking which values appear in nums. For each present value x, scan its multiples m <= threshold and union x with the previously seen divisor of m, storing x as the latest divisor for m; this transitively connects all present divisors of every m.
