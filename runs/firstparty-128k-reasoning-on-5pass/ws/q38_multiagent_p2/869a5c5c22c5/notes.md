- **Sample byte match:** The (2,3) special case now emits the second line as "R 3 2" plus one trailing space, implemented as `"R 3 2" + " "` so the source does not rely on invisible whitespace. - **Impossibility:** A red outgoing move flips the parity of r+c, while a blue outgoing move preserves it. Therefore a valid cycle requires R to be even. If R=0, every blue move flips row parity, so B must also be even. The program prints No exactly for R odd, or R=0 with B odd, or R+B<2.
- **Red base for R>0:** Let K=(R-2)//2. Raw red cells are (0,0), (0,-1), ..., (0,-K), (1,-K), (1,-K+1), ..., (1,0). This is a simple orthogonal path of R cells; when B=0 its last cell is orthogonal to the first.
- **Blue attachment for R>0:** The last red cell is (1,0), and the first red cell is (0,0). For B=1 use (1,1). For odd B=2m+1 with m>=1, use (x,x) for x=1..m, then (x-1,x+1) for x=m..0. For even B=2m, use (x+1,x-1) for x=1..m, then (x,x) for x=m..1. In each case the first blue is orthogonal from (1,0), consecutive blues are diagonal, and the last blue is diagonal to (0,0).
- **All-blue case:** For R=0 and B=2m, use (x,x) for x=0..m-1, then (x+1,x-1) for x=m-1..0. This forms a simple diagonal cycle.
- **Disjointness:** Red cells occupy rows 0 and 1 with columns <=0. Blue cells for R>0 lie in columns >0, except the even-B point (2,0), which is in row 2, and the odd-B endpoint (-1,1), which is in row -1. All-blue cells are internally simple. Thus no square is repeated.
- **Bounds:** Raw coordinates are within roughly [-100000, 100001]. Adding SHIFT=10^6 to both coordinates keeps every coordinate inside [1, 10^9] while preserving all move differences.
