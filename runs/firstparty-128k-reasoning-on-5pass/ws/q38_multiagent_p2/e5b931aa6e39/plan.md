Use the identity \(x^3-y^3=(x-y)(x^2+xy+y^2)\). Let \(d=x-y\); since \(y\ge 1\), the second factor is greater than \(d^2\), so \(d^3<N\) and \(d\le 10^6\) for the given constraints. Enumerate all possible \(d\) from 1 while \(d^3<N\), keeping only divisors of \(N\). For each such \(d\), set \(M=N/d\) and solve \(3y^2+3dy+d^2=M\) by checking whether \(\Delta=12M-3d^2\) is a perfect square and whether \(y=(\sqrt{\Delta}-3d)/6\) is a positive integer. If valid, output \(x=y+d\) and \(y\); otherwise output \(-1\). This gives an \(O(N^{1/3})\) integer-only solution.
