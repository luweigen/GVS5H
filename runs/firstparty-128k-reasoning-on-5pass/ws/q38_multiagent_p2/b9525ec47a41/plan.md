Shift the first N in-degrees by -1 and call them e_i; the last in-degree is then m - sum(e_i), so it is enough to count distinct e sequences. A sequence e is obtainable iff there is a circular binary choice x_i for the cycle edges and p_i ∈ {0, s_i} for spokes such that e_i = x_{i-1} - x_i + p_i. This is a 2-state NFA over outputs -1, 0, 1, 2, where the state is the previous x bit and the transition relation depends on s_i. Determinize it by tracking the 2x2 reachability relation (16 bit masks) from each possible start state to current states; a word is valid exactly when the final relation has a diagonal pair. Process the given string with an O(16·4·N) DP over these masks and sum the counts of diagonal final masks modulo 998244353.
