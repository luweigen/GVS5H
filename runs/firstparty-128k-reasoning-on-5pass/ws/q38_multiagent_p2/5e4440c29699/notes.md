- **model:** The town is the full lattice rectangle `0..W, 0..H` with the inclusive forbidden rectangle `[L,R] x [D,U]` removed. We count all monotone right/up paths of any length, including length zero, whose every visited point is available.
- **full-grid endpoint count:** For a point `(x,y)` in a full grid, the number of monotone paths ending there from any start is `G(x,y) = C(x+y+2, x+1) - 1`. The total over a full `a x b` rectangle is `S(a,b) = C(a+b+4, a+2) - a - b - 4 - (a+1)(b+1)`.
- **main inclusion-exclusion:** Count all full-grid paths `S(W,H)`, then subtract paths whose first forbidden point is `q`. For each `q` in the hole, the start-at-`q` contribution is `G(W-qx, H-qy)`. Entry from the left is possible only at `qx=L`, with prefix count `G(L-1,qy)`; entry from the bottom only at `qy=D`, with prefix count `G(qx,D-1)`.
- **J1:** The start-at-`q` sum is a rectangle sum of `G(W-x,H-y)` over the hole. Using `S` as the 2D prefix sum of `G`, it is `S(W-L,H-D) - S(W-R-1,H-D) - S(W-L,H-U-1) + S(W-R-1,H-U-1)`, with `S(a,b)=0` if `a<0` or `b<0`.
- **boundary sums:** `J2 = sum_{y=D..U} G(L-1,y) G(W-L,H-y)` if `L>0`; `J3 = sum_{x=L..R} G(x,D-1) G(W-x,H-D)` if `D>0`.
- **recurrences:** Store `H(a,b)=G(a,b)+1=C(a+b+2,a+1)`. Then `b -> b+1`: multiply by `(a+b+3)/(b+2)`; `b -> b-1`: multiply by `(b+1)/(a+b+2)`; `a -> a+1`: multiply by `(a+b+3)/(a+2)`; `a -> a-1`: multiply by `(a+1)/(a+b+2)`. The early off-by-one trap is using `b+1` or `a+b+3` in the wrong places.
- **implementation:** Precompute factorials and inverse factorials up to `W+H+4`. Compute needed modular inverses as `inv[i] = fact[i-1] * invfact[i]` only up to the maximum denominator actually used by the boundary recurrences. Boundary loops maintain numerator/denominator pairs and use one modulo per recurrence update.
- **edge cases:** `L=0` disables left-entry, `D=0` disables bottom-entry. Single-row or single-column holes make the corresponding loop empty but still require the final term. The formula also gives 0 for the invalid empty-town case.
- **samples:** Sample 1 was hand-checked and gives 192; the code does not hardcode or directly test samples.
