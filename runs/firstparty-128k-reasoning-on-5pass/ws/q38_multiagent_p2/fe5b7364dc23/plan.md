Use prefix sums \(P_0=0, P_i=A_1+\cdots+A_i\), so each subarray sum is \(P_r-P_{l-1}\). Expand \((P_r-P_{l-1})^K\) with the binomial theorem, which separates into terms depending only on the current prefix and aggregate powers of earlier prefixes. Since \(K\le 10\), maintain running sums \(M_m=\sum_{i<current} P_i^m\) for \(m=0..K\), where \(M_0\) is the count of previous prefixes. For each new prefix, compute its powers up to \(K\) and add \(\sum_{t=0}^K \binom{K}{t}P^t(-1)^{K-t}M_{K-t}\) to the answer. Then update the moments with the new prefix. This yields \(O(NK)\) time and \(O(K)\) memory, easily within limits.
