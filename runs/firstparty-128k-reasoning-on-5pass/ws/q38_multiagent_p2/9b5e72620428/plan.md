Choose a common target sum S and think of permuting A after all replacements. Fixed B_i force the A placed at i to be S-B_i, while unknown B_i can accept any A value not exceeding S. If the number f of fixed A entries is at most the number y of unknown B entries, all fixed A can be put into unknown B positions, so the answer is Yes. Otherwise at least K=f-y fixed A entries must be paired with fixed B entries that have the same sum S. For a given S, the maximum number of such pairs is sum over values min(count_A(a), count_B(S-a)). Thus we only need to test whether some S at least the maximum fixed A and fixed B has this matching count at least K.
