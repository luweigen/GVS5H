- **Model:** A paid operation chooses either its interval (type 1) or the complement of its interval (type 2). Since values only change from 0 to 1, the final state is all ones exactly when the chosen sets cover [1, N]. The cost is the number of paid operations.
- **Cost 1:** Only a full interval [1, N] chosen as type 1 can finish in one paid operation.
- **Check order:** The full-interval cost-1 check is done first. Then the containment cost-2 check is done before the type-1 cover check. This makes sample 1 hit the containment pair and output the expected valid solution: cost 2 with operations 2 0 1 0.
- **Containment scan:** Intervals are stored and sorted by (L, R, idx) ascending. A previous interval contains the current one if its L is at most the current L and its R is at least the current R. Prefix maximum R catches all such previous intervals with smaller L. For the same L, the larger interval appears later, so prefix max alone would miss strict same-L containment. Therefore, if no previous interval contains the current one but the current interval is not the first interval with that L, output the current interval as type 1 and the first previous interval with that L as type 2. That first previous interval has R <= current R and is contained in the current interval.
- **Type-1 cover:** Two type-1 intervals cover [1, N] iff one starts at 1, one ends at N, and they overlap or are adjacent. Use the maximum R among intervals with L = 1 and the minimum L among intervals with R = N. They form a valid pair iff max_r_l1 + 1 >= min_l_rn.
- **Disjoint type-2 cover:** Two type-2 operations cover [1, N] iff their original intervals are disjoint. In L-ascending order, a previous interval is disjoint from the current one iff its R < current L. Prefix minimum R detects this.
- **Cost 3 fallback:** If no cost 1 or cost 2 exists and M >= 3, then no pair is disjoint and no pair contains another. After sorting by L, R is strictly increasing and the first and last intervals overlap. Choosing type 1 on the first and last intervals and type 2 on the second interval covers the second interval by the two type-1 intervals and everything outside it by the complement.
- **Impossible case:** If M < 3 and no cost 1 or cost 2 case exists, the goal is impossible.
- **Complexity:** O(M log M) time and O(M) memory, which is easily within the limits for M = 200000.
