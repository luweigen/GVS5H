Process the string left to right and count valid substrings by their ending index, ignoring endings with digit 0. For last digits 1, 2, and 5, every substring ending at that position is valid, so add i+1. For last digits 4 and 8, use the standard last-two/last-three digit divisibility rules: check the short suffixes and, when the full 2- or 3-digit suffix is divisible, add all longer starts in O(1). For last digits 3, 6, 7, and 9, maintain prefix-residue counters: modulo 3 for 3 and 6 (6 is automatically even), modulo 9 for 9, and modulo 7 with normalized prefixes using inverse powers of 10. At each position, query the relevant counter for the target residue before inserting the current prefix, giving O(n) time and O(1) memory.
