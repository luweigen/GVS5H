If K=1, answer Yes; otherwise root the tree and process nodes in postorder. In any subtree, a non-complete partial decomposition can leave only one open path segment, and its length is forced to be the subtree size modulo K, so each node only needs states complete, open, or impossible. For a node, if any child is impossible, the node is impossible; otherwise count children in the open state. If the node's subtree size modulo K is 0, it is complete iff the open-child count is 1 or 2; if the modulo is positive, it is open iff the open-child count is 0 or 1, because the modulo automatically guarantees the required path lengths. The tree is decomposable iff the root's state is complete.
