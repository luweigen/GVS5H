- **Core transformation:** Swap the order of summation from arrangements to unordered cell pairs. For any fixed pair of distinct cells, it is included in exactly C(N - 2, k - 2) valid arrangements, where N = m * n. This avoids enumerating C(N, k) arrangements.
- **Unordered pairs:** Pieces are identical, and the examples confirm that arrangements are subsets of cells. The pair sum inside each arrangement is over unordered piece pairs, so each occupied cell pair contributes exactly once. Do not multiply by 2 or by k!.
- **Manhattan separation:** Distance |dx| + |dy| splits into independent row and column contributions. For a fixed pair of distinct rows, the two cells may choose any of the n columns independently, giving n^2 cell pairs. For a fixed pair of distinct columns, the row choices give m^2 cell pairs.
- **1D distance sum:** For L positions, sum_{i<j} (j - i) = sum_{d=1}^{L-1} d(L - d) = L(L - 1)(L + 1) / 6. Use this for rows with L = m and columns with L = n.
- **Final formula:** ans = C(N - 2, k - 2) * (n^2 * m(m^2 - 1)/6 + m^2 * n(n^2 - 1)/6) modulo 10^9 + 7.
- **Modular arithmetic:** The modulus is prime and N <= 10^5 < modulus, so factorial and inverse-factorial binomial coefficients are safe. Division by 6 is performed using the modular inverse of 6.
- **Implementation details:** The Solution class keeps a lazy factorial cache. The first call precomputes up to at least 100000, matching the constraint bound, so repeated calls do not repeatedly recompute. `_comb` safely returns 0 for invalid r.
- **Edge cases:** k = 2 gives C(N - 2, 0) = 1. k = N gives C(N - 2, N - 2) = 1. If m = 1 or n = 1, the corresponding 1D distance sum is zero. N = 2 works with C(0, 0) = 1. m = n = 1 is outside constraints because k >= 2 and k <= N.
- **Verification:** The included main guard checks the provided examples, simple line edge cases, and brute-force cross-checks all small grids with 1 <= m, n <= 3 and valid k. The brute force enumerates all cell subsets and sums unordered pair distances.
- **Pitfalls:** Forgetting the n^2 and m^2 multiplicative factors, using C(n, 2) instead of n^2 for independent column choices, double-counting ordered pairs, applying integer division after modular reduction, or using an unordered-pair formula with an ordered-pair coefficient.
