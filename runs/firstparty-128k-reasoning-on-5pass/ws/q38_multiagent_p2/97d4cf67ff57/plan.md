Root the tree arbitrarily and solve with a bottom-up tree DP. For each vertex, maintain two states: one where the edge to its parent is selected, so the vertex must choose 0 or 3 child edges to have degree 1 or 4; and one where the parent edge is not selected, so the vertex must choose 1 or 4 child edges. If a child edge is selected, we can add the child's best “parent edge selected” value. Since at most four child edges can be selected, only the top four child DP values are needed for each vertex. The maximum valid alkane is the maximum “parent edge not selected” value over all vertices, and if this maximum is less than 5 we output -1 because the smallest alkane has 5 vertices.
