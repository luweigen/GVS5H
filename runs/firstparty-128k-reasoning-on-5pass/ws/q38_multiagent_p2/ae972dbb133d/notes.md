- **Core model:** Put a bit on each shared edge midpoint, 1 if a tile endpoint touches it. The torus no-dead-end rule is equality of the two bits on every shared edge. For a cell, Type A forces top xor bottom = 1 and left xor right = 1; Type B forces top xor bottom = 0, left xor right = 0, and top xor left = 1.
- **Variable reduction:** Let C_j be the top-edge bit of cell (0,j) and R_i the left-edge bit of cell (i,0). Moving down a column, an A flips the top bit and a B does not; moving right, an A flips the left bit and a B does not. Hence top(i,j)=C_j xor parity of A above, left(i,j)=R_i xor parity of A left.
- **Wrap condition:** Going once around the torus requires every row and every column to contain an even number of A tiles. In the scan, colpref[j] after the last row is exactly the column A parity, and rowpar is the current row A parity.
- **B equations:** For a B cell at (i,j), top xor left = 1 gives R_i xor C_j = 1 xor colpref[j] xor left, where left is the parity of A strictly to the left in row i. A cells only update left, rowpar, and colpref.
- **Counting:** The equations are xor constraints on H+W variables. A parity DSU solves them. If a contradiction appears, answer 0. Otherwise each connected component of the bipartite equation graph has one free bit, so the answer is 2^components modulo 998244353. Isolated row/column variables count as components. Inconsistency can occur even when all row/column A parities are even, so the DSU check is necessary.
- **Implementation:** Read all tokens with sys.stdin.buffer.read().split(); rows are bytes and A is 65. DSU nodes are 0..H-1 for rows and H..H+W-1 for columns. find is iterative two-pass path compression returning (root, xor-to-root); union by size links roots with parity px xor py xor w and decrements components. Break early on contradiction or odd row parity; check any(colpref) only if still ok.
- **Complexity:** O(HW alpha(H+W)) time per case and O(H+W) extra memory beyond input; total HW over cases is at most 1e6.
