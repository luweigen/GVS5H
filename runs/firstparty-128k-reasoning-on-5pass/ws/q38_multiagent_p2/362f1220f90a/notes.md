- **Problem mapping:** Output length is `L = n + m - 1`. The constraint for `str1[i]` is checked when the length-`m` window ending at position `i + m - 1` is complete, so positions `0..m-2` are unconstrained and positions `m-1..L-1` carry one T/F constraint each.
- **Automaton:** KMP prefix function for `str2`. States `0..m` are built, where state `m` means a full match just occurred. For future processing, a full match immediately falls back to `pi[m-1]`, so feasibility masks only store states `0..m-1`.
- **Backward feasibility:** `ok[pos]` is a bitset of KMP states before position `pos` from which the suffix can be completed. `ok[L]` is all states `0..m-1`. For T, only state `m-1` can complete the match, and `pi[m-1]` must be feasible after the position. For F, transitions entering state `m` are excluded. For unconstrained positions, all transitions are allowed, with state `m` mapped to `pi[m-1]`.
- **Greedy construction:** If state `0` is not feasible at position `0`, return empty. Otherwise scan left to right, trying `'a'..'z'`, and take the first character whose local T/F requirement is satisfied and whose next state is in `ok[pos+1]`. This yields the lexicographically smallest valid string.
- **Complexity:** Transition table is `O(26*m)`. Backward DP is `O(L*m)` bitset checks, about 5.25 million for max limits. Greedy is `O(26*L)`. Memory is `O(L)` big-int masks plus `O(26*m)` transition table.
- **Edge cases:** `m=1` works because state `1` is a full match; T forces the pattern character, F forbids it. All-T is possible only when overlapping occurrences of `str2` are compatible; the automaton enforces this. All-F is locally satisfiable because 26 letters exist, but future T constraints can make some states infeasible.
- **Pitfalls:** Constraint index is `pos - (m - 1)`, not `pos`. State `m` must transition via `pi[m-1]`, not reset to `0`. F forbids only entering state `m`, not partial matches. T requires entering state `m` exactly at that position.
