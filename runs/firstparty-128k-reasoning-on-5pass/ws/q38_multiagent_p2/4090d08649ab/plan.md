The value of f(L,R) depends only on the set of distinct values in A[L..R]. One operation can erase exactly a contiguous interval of values that is fully present, so the minimum number of operations is the number of contiguous value-components in that set. For any set of values, the number of components equals the number of present values minus the number of adjacent value pairs (x,x+1) that are both present. Therefore the required sum is the sum of distinct-value counts over all subarrays minus the sum, over x, of the number of subarrays containing both x and x+1. The distinct-value sum can be computed in one pass using previous occurrences. For each adjacent value pair, count subarrays containing both values by inclusion-exclusion using the numbers of subarrays avoiding x, avoiding x+1, and avoiding their union; the union-avoidance count is obtained by merging the two sorted position lists. This gives an O(N) time and O(N) memory solution with 64-bit integer arithmetic.
