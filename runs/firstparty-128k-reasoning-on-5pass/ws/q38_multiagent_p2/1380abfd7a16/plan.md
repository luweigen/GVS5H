The forward insertion process is difficult to simulate directly for large N, but it can be reversed. When processing elements from N down to 1, the positions of elements 1 through i in the final array are exactly the still-unassigned slots, in order. Element i must be placed in the P_i-th unassigned slot. Use a Fenwick tree over N positions, initially all available, to repeatedly find the P_i-th available position and mark it used. This gives an O(N log N) solution, which is efficient for N up to 5×10^5. Finally, output the values assigned to positions 1 through N.
