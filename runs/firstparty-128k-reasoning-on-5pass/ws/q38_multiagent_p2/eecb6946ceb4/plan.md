Represent the set as an indicator array f over values up to 10^6. A fine triplet (A, B, C) is exactly a choice of B in S and an unordered pair {A, C} in S with A + C = 2B and A ≠ C. Compute all pair-sum counts h[s] = Σ_x f[x]f[s−x] by one convolution of f with itself using NTT at a power-of-two length greater than 2·10^6. For each B in S, the number of valid A, C is (h[2B] − 1) // 2, where the −1 removes the self-pair (B, B). Accumulate these contributions in a 64-bit integer and print the result.
