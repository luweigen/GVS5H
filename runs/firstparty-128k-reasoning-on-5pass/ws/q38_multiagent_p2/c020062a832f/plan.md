Compute the inversion count for k=0 with a Fenwick tree over values 0..M-1, while recording for each value its occurrence count and the sum of its 1-based positions. When k increases by 1, only elements whose current value is M-1 wrap to 0, so only pairs involving original value c=(M-1-k) mod M can change their inversion status. For a value c with t occurrences and position sum S, the net change is 2S - t(N+1): each wrapping element loses inversions with later non-wrapping elements and gains inversions with earlier non-wrapping elements. Starting from ans_0, iterate k=0..M-1, output the current answer, then apply the update for c=M-1-k to obtain the next answer. This gives O(N log M + M) time and O(M) memory, with 64-bit integers for counts.
