The shortest palindrome with S as a prefix is obtained by appending the minimum number of characters to S. This is equivalent to finding the longest suffix of S that is already a palindrome, because that suffix can serve as the mirrored center/end. A suffix of S of length k is palindromic exactly when it equals the first k characters of reverse(S). We can find this longest k efficiently using the KMP prefix function on reverse(S) + separator + S. The last prefix-function value gives k, and the answer is S plus the reverse of the remaining prefix of S.
