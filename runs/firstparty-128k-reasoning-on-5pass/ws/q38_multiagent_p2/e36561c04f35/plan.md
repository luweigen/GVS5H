Treat any strategy as performing all adjacent swaps first and then deleting the resulting runs, so the cost is the number of swaps plus the final number of runs. Compress the sequence into runs; a swap can lower the total only if it reduces the run count by 2, which happens exactly for four consecutive runs y,x,y,x where the two middle runs have length 1. Such a swap rewrites y,x,y,x into y,x, costs 1, reduces runs by 2, and therefore reduces the objective by 1, while the two outer runs become non-single. The maximum number of these beneficial reductions is obtained by a left-to-right stack: push runs and repeatedly reduce the last four runs whenever they match the pattern and the middle two are single. The answer is the initial run count minus the number of reductions.
