Model each valid permutation by its parity pattern and independent orderings of the remaining odd and even numbers. For any fixed prefix, the number of completions depends only on how many odds and evens remain and the parity required next: it is fact[odds]*fact[evens] if the alternating pattern can use exactly those counts, otherwise 0. Precompute factorials capped at 10^15 so counts never exceed the maximum k. Unrank lexicographically by scanning remaining numbers in increasing order, subtracting the block size for each incompatible or too-small candidate until the block containing k is found. If the total number of valid permutations is less than k, return an empty list. Since n <= 100, this O(n^2) unranking is easily fast enough.
