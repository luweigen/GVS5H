- **Parity structure:** Valid permutations must alternate parity. Odd n forces an odd-start pattern; even n allows both odd-start and even-start patterns. Once the parity pattern is fixed, odd values can be assigned independently to odd slots and even values to even slots.
- **Counting completions:** After a valid prefix, if the next required parity has c_p remaining values and the other parity has c_q, every candidate of the required parity has fact[c_p - 1] * fact[c_q] completions. Candidates of the other parity have zero completions because they would break alternation.
- **Direct unranking:** Because all valid candidates at a position have the same block size, the k-th suffix can be found by idx = (k - 1) // block among the sorted remaining values of the required parity, then setting k = (k - 1) % block + 1.
- **First position handling:** For odd n, the first value must be odd, with block fact[o - 1] * fact[e]. For even n, every first value from 1 to n has the same block size fact[m - 1] * fact[m], where m = n // 2, so the first value is idx + 1.
- **Capping:** Use cap = k + 1. Products are capped at cap. Values below cap remain exact; values at least cap are treated as "at least cap". This makes the total check safe: if the true total is below k, it is exact and returns []; if the true total is at least k, the capped total is also at least k.
- **Tests:** The provided examples pass. Exhaustive brute force for n = 1 through 8 generated all alternating permutations, sorted them lexicographically, and matched permute for every valid rank. Out-of-range checks for total + 1 and k = 10^15 returned [] for those small n. Edge cases n = 1 and n = 2 were checked explicitly.
- **Large sanity checks:** For n = 99 and n = 100, k = 1 returns [1, 2, ..., n]. k = 2 and k = 10^15 return length-n permutations of 1 through n with alternating parity, and k = 2 differs from k = 1.
- **Complexity:** Factorial precomputation is O(n). Unranking makes n selections, each using O(1) arithmetic and an O(n) list pop, so total time is O(n^2) and memory is O(n). This is easily sufficient for n <= 100.
- **Pitfalls:** Do not rank the odd and even subsequences independently; lexicographic order interleaves choices by position. For even n, odd-start and even-start permutations interleave by first numeric value rather than forming two separate large blocks. For odd n, an even first value is incompatible with the remaining parity counts.
- **Self-test:** The guarded main block runs brute-force and sanity checks when the file is executed directly, while import-based grading is unaffected.
