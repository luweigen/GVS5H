- **State model:** Each ordered pair (u, v) is a state, and its distance is the shortest palindromic walk length from u to v. Base distances are 0 for (i, i) and 1 for an existing edge i -> j. A self-loop keeps distance 0 because 0 dominates 1.
- **Transition rule:** From an inner state (x, y) with distance d, any matching outer edges u -> x and y -> v with the same label produce state (u, v) at distance d + 2. This corresponds to peeling the first and last equal characters of a palindrome.
- **BFS order:** All distance-0 states are enqueued before all distance-1 states. Every transition adds 2, so a FIFO queue pops states in nondecreasing distance. The first time a state is assigned is therefore its shortest distance.
- **Bitset optimization:** inc[x] stores all (u, c) for edges u -> x. out[c][y] is a bitset of all v such that y -> v has label c. For popped (x, y), for each (u, c), new = out[c][y] & ~mask[u] gives all unassigned v in row u. Then mask[u] is updated and each set bit is assigned and enqueued.
- **Why one distance per state is enough:** If a state also has a longer palindromic walk of opposite parity, using its shortest palindromic walk as the middle always yields an outer palindrome no longer than using the longer one. Thus longer visits to the same state are dominated and need not be processed.
- **Complexity:** There are at most N^2 states. Each popped state scans inc[x], which has size at most N, giving O(N^3) bit operations in the worst case, plus O(N^2) total bit assignments. Memory is O(N^2 + 26N).
- **Implementation details:** Use 0-based indices, Python integers as bitsets, a list queue with a head index, and print -1 for unreachable pairs.
