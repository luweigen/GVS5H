Treat every ordered pair (u,v) as a state representing the endpoints of the still-unmatched middle of a palindromic walk. A state has base cost 0 when u=v (empty walk) and base cost 1 when there is a direct edge u->v. For any longer palindromic walk, the first and last edge labels must match, so a state (u,v) can be reduced to (x,y) by taking a matching labeled edge u->x and y->v, adding 2 to the length. Run a multi-source BFS over the N^2 pair states in increasing distance, starting from all base states and using reversed transitions from (x,y) to its predecessors (u,v). Use per-letter predecessor lists and successor bitsets, together with row masks of already assigned pairs, to generate and mark predecessor states efficiently. After the BFS, output the distance matrix, with -1 for unreachable pairs.
