- **Core reduction:** For a fixed block path, let m be the minimum walkway capacity, equivalently the minimum building height on that path. The minimum stair count is |Y-Z| + 2*max(0, min(Y,Z)-m): if both endpoint floors are above m, one must descend to m and later climb back; otherwise one can cross at min(Y,Z). Thus each query only needs M, the maximum bottleneck path value between the two blocks.
- **Bottleneck via superlevel sets:** M is the largest height t such that the two cells are connected using only cells with F>=t. Edge capacity between adjacent cells is min(F_u,F_v), so connectivity at threshold t is exactly connectivity in the active-cell subgraph.
- **Kruskal reconstruction tree:** Sort cells by F descending. Activate a cell v at height h, union it with already active neighbors. Each successful union creates a new internal node of weight h whose children are the current reconstruction nodes of the two DSU components. Leaves are cells with weight F. The LCA weight of two leaves is M; for the same leaf, weight F gives the correct |Y-Z|.
- **DSU implementation:** DSU is over original cells only. `dsu` uses 0 for inactive, negative size for roots, and parent index for non-roots. `comp[root]` stores the current reconstruction node for that component. Union by size keeps find fast.
- **Tree parent/depth trick:** When creating internal node x, set `tree_parent[child]=x` for the two component nodes. New node ids increase, so every parent id is larger than its child id. After all unions, root is `total_nodes-1`; set its parent to itself and compute depth by iterating ids downward, avoiding DFS/recursion.
- **Binary lifting:** Build `up[k][v]` for `LOG = total_nodes.bit_length()` levels using compact `array('I')`. Root parent is root. LCA lifts the deeper node, then lifts both from high to low.
- **Answer formula:** With B = weight[LCA(u,v)], answer = abs(Y-Z) + 2*max(0, min(Y,Z)-B). Same-cell queries use B=F_cell.
- **Edge cases:** N=1 (no internal nodes, root leaf), H=1 or W=1 (neighbor bounds), equal heights (same-weight union chains still give correct LCA weight), same block different floors.
- **Complexity/memory:** O(N log N + N log N + Q log N) time. N<=250000, total tree nodes <=499999, LOG<=19. Use `array('I')` for input, weights, parents, depths, and lifting tables; delete F/order/DSU/comp/active before building the lifting table to reduce peak memory.
