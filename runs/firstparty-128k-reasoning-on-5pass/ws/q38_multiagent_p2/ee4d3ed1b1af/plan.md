Split p into three literal parts A, B, C around the two '*' characters; a matching substring is formed by ordered occurrences of these literals with the stars covering the gaps. If a part is empty it imposes no literal constraint, and if all parts are empty the answer is 0. Find all occurrences of each nonempty part in s using KMP or Z in linear time. Precompute, for every position, the rightmost start of an A occurrence ending before that position and the earliest start of a C occurrence beginning after that position. Evaluate each B occurrence (or the B-empty variants) by adding the left gap, the literal lengths, and the right gap, then return the minimum valid length or -1.
