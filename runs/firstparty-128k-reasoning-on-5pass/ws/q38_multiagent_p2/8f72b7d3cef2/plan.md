Reframe the process in terms of stable intervals: an interval is stable if its total size is at most both adjacent outside slimes, and the answer for a slime is the sum of the smallest stable interval containing it. Stable intervals are laminar, and a max-Cartesian tree naturally represents the nested structure of possible intervals. For a node that is the maximum of its subtree, any proper stable interval containing it is either the singleton or the whole subtree, so its answer can be decided locally. Traverse the tree top-down, carrying the outside boundary values and the nearest good ancestor sum, and assign each node in O(1). This gives an O(N) algorithm with O(N) memory.
