- **State model:** For a fixed start, absorbed slimes always form a contiguous interval containing the start; current size is the interval sum. Expansion is possible exactly when an adjacent outside value is strictly smaller than this sum.
- **Stable intervals:** Call an interval stable if its sum is at most both immediate outside slimes, treating boundaries as infinity. A terminal reachable interval is stable, and the answer is the sum of the smallest stable interval containing the start.
- **Reachability of minimal stable interval:** If S is the smallest stable interval containing the start, any proper subinterval containing the start is not stable. Its smaller adjacent blocker cannot be outside S because outside S is at least sum(S), which is larger than the subinterval sum; hence the blocker is inside S, so expansion can continue until S is reached.
- **Laminar property:** Stable intervals cannot cross. Crossing intervals would force their sums to be equal through outside elements lying inside the other interval, contradicting positive sizes for non-singleton overlap.
- **Cartesian tree:** Build a max Cartesian tree with leftmost maximum as the higher tie-break by popping while strictly smaller. Each node’s subtree is a contiguous interval where that node is the leftmost maximum.
- **Non-singleton stable intervals:** For a stable interval of length greater than one, outside values are strictly greater than the interval maximum because the sum exceeds the maximum. Therefore the interval is exactly the subtree of its leftmost maximum. Mark a non-leaf node stable when its subtree sum is at most both immediate outside values.
- **Singletons:** A singleton is stable iff its value is at most both immediate neighbors, with boundaries as infinity. Equal neighbors block absorption, so a singleton can be stable even when its Cartesian subtree is larger; override the answer to its own value in that case.
- **Top-down DP:** Postorder computes subtree sums and boundaries. Then traverse parent-before-child carrying the sum of the deepest stable ancestor. For each node, use its own stable subtree sum if stable, otherwise the carried value; override with the singleton value if the singleton is stable; pass the carried value to children.
- **Implementation details:** All traversals are iterative. The whole array is a stable non-singleton interval for N > 1, so every node has a valid stable ancestor. Reuse boundary arrays for best/ans to save memory. INF = 10**18 exceeds the maximum possible total sum of 5e14.
- **Pitfalls:** Use <= for stable outside comparisons because absorption requires strict smaller; handle equal values with leftmost tie; do not let a singleton-stable node suppress propagation of its stable subtree to descendants; avoid recursion for 5e5 nodes.
