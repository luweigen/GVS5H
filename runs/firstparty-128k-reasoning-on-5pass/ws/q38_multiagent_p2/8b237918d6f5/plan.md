For a candidate distance D, use a potential h(v) with h(1)=0, h(N)=D, and h(v) <= h(u)+1 for every edge u->v. Such a potential certifies shortest distance at least D if every edge with h(v)=h(u)+1 is assigned weight 1, so D is feasible exactly when some labeling has at most K such upward edges. Represent the labeling by binary variables y_{v,i} meaning h(v)>=i for i=1..D. Build a min-cut network with infinite arcs enforcing y_{v,i+1}=>y_{v,i} and y_{v,i}=>y_{u,i-1}, and unit arcs (v,i)->(u,i) that are cut precisely when edge u->v is upward. The min-cut capacity is the minimum number of forced weight-1 edges; check D=0..N-1 (or binary search) and output the largest D with capacity <=K.
