Model the process as a forward boolean DP: a good square x is reachable if any reachable square in [x-B, x-A] exists. Because B<=20, maintain only a B-bit sliding window of the last B squares, with bit 0 representing the current square. Reject immediately if a single bad interval has length at least B, since no jump can cross it; otherwise the total number of bad squares to simulate is small. For long good stretches, precompute powers of the one-step good transition as B-bit row masks and apply them with binary exponentiation to fast-forward the window. Process the row left to right, fast-forwarding good gaps, simulating short bad squares with a zero-current transition, and finally check the current bit at N.
