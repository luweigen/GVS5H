- **Model:** Label pieces by initial order. The operation never changes order and never increases any adjacent gap, so a target B is reachable only by cutting the A-gaps into L-1 cuts, one per B-gap, with each cut A-gap at least the corresponding B-gap. The first and last A pieces must go to the first and last B ones.
- **Endpoint cost:** Let a0,aK,b0,bL be first/last positions, d1=b0-a0, dn=bL-aK, D=spanA-spanB=d1-dn, E=d1+dn. Any solution needs at least M=(D+|E|)//2=max(d1,-dn) operations. If L=1 this is always sufficient after count/span checks.
- **Phase bit:** For a fixed valid partition, the only extra condition is a phase bit p1. The phase that can be done in M operations is pM=(M+d1)&1 (equivalently 0 if D even, else 0 if E>0 else 1). The other phase costs M+1.
- **Zero-reduction cuts:** If a cut uses α_i=β_j, that gap is never reduced; the phase on both sides must match. This forces p1 = (a_{i+1}-a_1)-(b_{j+1}-b_1) mod 2. Define S_i=(a_{i+1}-a_1)&1 and R_j=(b_{j+1}-b_1)&1; then the condition is S_i ^ R_j = p. If α_i>β_j, the positive reduction can absorb either phase, so no parity restriction.
- **Greedy feasibility:** For a fixed p, we need a subsequence of A gaps matching B gaps in order: α_i>β_j is always allowed; α_i=β_j is allowed only if S_i^R_j=p. Earliest allowed cut is optimal because future only depends on the next A index. Therefore feasibility(p) is a single left-to-right scan over A gaps, maintaining the current B gap j. This makes the old segment-tree/hash-table plan unnecessary; O(N) total is simpler and faster.
- **Algorithm per case:** Scan A and B to get counts, first/last, gap lists alpha/beta, and parity bytearrays S/R. If K<L or spanA<spanB return -1. Compute M. If L==1 return M. Else if feasible(pM) return M; else if feasible(1-pM) return M+1; else -1.
- **Edge cases:** K=L forces all gaps to be used; the scan naturally fails if any is too small or parity-wrong. M=0 works for A=B; extra internal pieces with M=0 are rejected by gap/parity checks. Negative displacements are handled by the M formula and Python &1.
- **Samples:** Case1 pM=0, scan matches gaps 3>2 then 2>1 -> 3. Case2 K<L -> -1. Case3 pM=0, scan matches all seven B gaps -> 5.
- **Complexity:** One scan of A and B plus at most two scans of A gaps per case. Sum N <= 1e6, so O(total N) time and O(N) temporary memory per case.
