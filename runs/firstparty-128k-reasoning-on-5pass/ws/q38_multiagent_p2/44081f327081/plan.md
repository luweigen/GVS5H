For each index i, the answer is the largest divisor d of A_i such that at least K elements of A are divisible by d. Compute frequency counts of values up to M = max(A), then compute cnt[d] = number of array elements divisible by d using a multiple-sum sieve. Build an array best[x] by iterating d in decreasing order and assigning d to all unassigned multiples of d whenever cnt[d] >= K; the first assignment gives the maximum valid divisor. Finally output best[A_i] for every i. This gives O(M log M + N) time and O(M + N) memory, which is efficient for M <= 10^6.
