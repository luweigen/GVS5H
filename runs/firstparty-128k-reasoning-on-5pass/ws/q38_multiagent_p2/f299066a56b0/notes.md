- **Problem structure:** The array is sorted nondecreasing. A pair is valid when the top size `t` and bottom size `b` satisfy `2 * t <= b`. Each mochi can be used at most once, so the answer is at most `N // 2`.
- **Role split:** For any feasible `K`, `K <= N // 2`. The `K` smallest mochi can be used as tops and the `K` largest as bottoms without making feasibility harder. Since `K <= N // 2`, those `K` smallest lie in the first half and those `K` largest lie in the second half. Therefore it is enough to match candidates from `A[0:N//2]` as tops against `A[N//2:N]` as bottoms.
- **Feasibility characterization:** For a fixed `K`, the easiest choice is the `K` smallest tops and the `K` largest bottoms. `K` is feasible exactly when `2 * A[i] <= A[N - K + i]` for all `i = 0..K-1`. The two-pointer method finds the maximum such `K` directly.
- **Greedy rule:** Keep `left` for the smallest unused top and `right` for the smallest unused bottom. If `2 * A[left] <= A[right]`, pair them, increment both, and count. Otherwise `A[right]` is too small for the smallest remaining top, hence too small for every remaining top, so discard that bottom by incrementing `right`.
- **Correctness intuition:** Top thresholds are nondecreasing because the array is sorted. Pairing the smallest top with the smallest bottom that can support it never wastes a larger bottom unnecessarily. If a bottom cannot support the current smallest top, it cannot support any later top. If it can, using it for the current top is safe by an exchange argument.
- **Complexity:** One pass over at most `N` elements, `O(N)` time and `O(N)` memory for the input list. Python integers avoid overflow when doubling sizes up to `10^9`.
- **Implementation details:** Read all integers from stdin. Use `half = N // 2`, `left = 0`, `right = half`, `ans = 0`. Stop when `left == half` or `right == N`. Print `ans`. The input is already sorted, so no explicit sort is required.
- **Samples:** The three provided samples produce `3`, `0`, and `6` with this implementation.
- **Pitfalls:** Do not start `right` at `0`, do not pair adjacent elements blindly, and do not use a strict inequality; the condition is inclusive, meaning at most half.
