- **Monotonicity:** After sorting A, B, and C in nonincreasing order, f(i,j,k)=A_iB_j+B_jC_k+C_kA_i is nonincreasing in each coordinate because all entries are positive. The maximum is at (0,0,0).
- **Truncation:** Let M=min(N,K). If N>K, any triple with a coordinate at least K is dominated by K triples inside the first M coordinates: fix that coordinate to each of 0..K-1 and cap the other coordinates at K-1. Thus the K-th largest value is unchanged after truncating each array to M.
- **Parent tree:** Use 0-index. Parent of (i,j,k) is (i-1,j,k) if i>0, else (i,j-1,k) if j>0, else (i,j,k-1). The parent value is at least the child value. Children of a popped cell are exactly (i+1,j,k), plus (i,j+1,k) if i=0, plus (i,j,k+1) if i=0 and j=0. Each cell has one parent, so no visited set is needed.
- **Best-first invariant:** The largest unpopped cell is always in the heap. If an unpopped cell is not in the heap, follow its parent chain until an unpopped cell whose parent has already been popped; that ancestor is in the heap and has value at least as large. Therefore popping K times gives the K-th largest value.
- **Encoding:** Use b=(M-1).bit_length() bits per coordinate and id=(i<<2b)|(j<<b)|k. Child ids are obtained by adding 1<<2b, 1<<b, or 1. Decoding uses shifts and masks.
- **Heap key:** Store key=(diff<<3b)|id, where diff=root_value-current_value. A min-heap pops smallest diff, tie smallest id. Decode diff=key>>3b and id=key&((1<<3b)-1).
- **Incremental deltas:** To i+1: (A_i-A_{i+1})(B_j+C_k). To j+1 (only i=0): (B_j-B_{j+1})(A_0+C_k). To k+1 (only i=0,j=0): (C_k-C_{k+1})(A_0+B_j). Precompute adjacent differences; child diff = current diff + delta.
- **Heap operation optimization:** For a non-leaf popped cell, use heapreplace to remove it and insert the i-child in one sift, then heappush the remaining j/k children. Leaves use heappop. This is equivalent to pop plus pushes but saves one sift per non-leaf.
- **Early exits:** K=1 can be answered by the maxima of the three arrays. If K=M^3, the answer is the minimum triple, using the last elements after sorting/truncation.
- **Complexity:** Sorting O(N log N). The heap contains at most 2K+1 entries and performs O(K) removals/insertions, so O(K log K) time and O(N+K) memory. K<=5e5 and M<=2e5.
