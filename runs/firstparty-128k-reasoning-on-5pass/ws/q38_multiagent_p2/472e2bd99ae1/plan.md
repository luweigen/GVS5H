Sort A, B, and C in nonincreasing order and keep only the first M = min(N, K) elements, since any triple with a coordinate rank greater than K is dominated by K triples that replace that coordinate by smaller ranks. The function f(i,j,k)=A_iB_j+B_jC_k+C_kA_i is monotone nonincreasing in each index because all array values are positive. Therefore the desired values form a 3D monotone grid whose maximum is at (1,1,1). Run a max-heap best-first search over this grid, starting from (1,1,1) and repeatedly popping the largest discovered triple while pushing its unvisited immediate successors (i+1,j,k), (i,j+1,k), and (i,j,k+1). The value popped on the K-th iteration is the K-th largest value. This yields O(N log N + K log K) time and O(K) memory, with encoded state IDs to keep the visited set compact.
