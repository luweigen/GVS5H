Track the cumulative wind displacement after each time step, denoted P_t. A smoke particle created at time k is located at P_t - P_k at time t, and new smoke is created exactly when P_t is a prefix position not seen before. Therefore, smoke exists at (R,C) at time t+0.5 iff P_t - (R,C) has appeared among P_0, P_1, ..., P_t. Simulate the walk once while maintaining a hash set of visited prefix coordinates. For each t, check membership of P_t - (R,C) in that set, giving O(N) expected time and O(N) memory.
