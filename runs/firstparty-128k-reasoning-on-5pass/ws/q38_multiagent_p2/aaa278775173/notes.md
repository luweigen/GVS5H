- **Directions:** Use flat index `r * m + c`. Direction order is `0 = NE (-1, +1)`, `1 = SE (+1, +1)`, `2 = SW (+1, -1)`, `3 = NW (-1, -1)`. Clockwise is `+1 mod 4`, so if the second leg direction is `b`, the first leg direction is `a = (b + 3) % 4`.
- **No-turn DP:** `base_dp` stores `1` at every cell with value `1`. For each direction, process only cells whose previous diagonal cell is in bounds, in topological order. Extend only when the current value is the required next value: `2` after an odd length, `0` after an even length. A straight segment ending at a fixed cell and direction is unique because `1` appears only at position 0 of the required pattern.
- **Straight runs after turn:** `base_run2` and `base_run0` store `1` at cells matching the required first value `2` or `0`. For each second direction `b`, process cells whose next diagonal cell is in bounds in reverse topological order. Then `run2[idx] = 1 + run0[next]` if `vals[idx] == 2`, and `run0[idx] = 1 + run2[next]` if `vals[idx] == 0`.
- **Turn combination:** For turn cell `idx` and second direction `b`, take `A = dp0[a][idx]`. If `A > 0`, the next cell in direction `b` is `nidx`. Add `run2[nidx]` if `A` is odd, otherwise `run0[nidx]`. Total length is `A + add`. This covers all one-turn V segments because the prefix is a valid straight segment and the suffix is the best matching straight continuation.
- **No overlap:** Adjacent clockwise diagonal pairs share one monotone coordinate over both legs, so the prefix and suffix cannot intersect except at the turn cell. This also bounds any valid length by `max(n, m) <= 500`, so unsigned short arrays are safe.
- **Bounds and compactness:** Valid row/column ranges avoid per-cell boundary checks. The `dp_params` and `run_params` ranges were checked for all four directions and for `n = 1` or `m = 1`; all previous/next indices stay in bounds.
- **Edge cases:** No `1` returns `0`. A single `1` returns `1`. Cells with value `1` never extend a segment and stop runs. Immediate turn cases with `A = 1` only reproduce valid straight segments, so they do not create invalid lengths.
- **Complexity:** O(nm) time and O(nm) memory with small constants: four no-turn passes and four turn passes over the grid.
