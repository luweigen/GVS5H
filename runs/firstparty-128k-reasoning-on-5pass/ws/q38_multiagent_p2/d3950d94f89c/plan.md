Root the undirected tree at 0 and traverse it with an iterative DFS, maintaining the current root-to-node path as a stack of distances and node counts. For each value, track its deepest and second-deepest occurrence distance on this path; the maximum second-deepest distance is the threshold such that any valid start must lie strictly below it. For each node as the end of a downward path, binary search the path stack for the shallowest ancestor with distance greater than the threshold, which yields the longest unique-value path ending at that node. Update the global answer by maximum length, and on ties keep the minimum node count. Use enter/exit events to add and remove the current node from the path and value-occurrence structures, giving O(n log n) time and avoiding recursion-depth issues.
