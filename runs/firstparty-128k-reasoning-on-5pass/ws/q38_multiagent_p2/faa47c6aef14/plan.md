Model each color separately: a red ball can reach X only if its box is on the P-cycle containing X, and a blue ball only if its box is on the Q-cycle containing X; otherwise the answer is -1. For a feasible color, let M be the maximum distance to X (along that permutation) among boxes initially containing that color; the operations needed for that color are exactly the boxes on the path from the farthest such box to X, in that order, excluding X. Any valid global operation sequence must contain both color-specific sequences as subsequences, so the minimum number of operations is the length of their shortest common supersequence. Because each sequence has distinct boxes, this length equals len(R)+len(B)-LCS(R,B), and the LCS can be found by converting one sequence to positions and computing an LIS.
