For each possible length-x window, the cheapest way to make it internally equal is to change all elements to a median, so precompute its cost as the sum of absolute deviations from the median. Compute these costs for all windows in O(n log n) using a sliding-window median structure, e.g., coordinate-compressed Fenwick trees for counts and sums or two heaps with lazy deletion. Since all window costs are nonnegative, requiring at least k is equivalent to choosing exactly k. Then the problem becomes choosing k non-overlapping length-x intervals with minimum total precomputed cost. Use a DP over prefix length and number of chosen subarrays: dp[j][i] = min(dp[j][i-1], dp[j-1][i-x] + cost[i-x]), where cost[i-x] is the window ending at i-1. Return dp[k][n], keeping only the previous j layer for O(n) memory.
