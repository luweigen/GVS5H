- **Reduction:** Work modulo p. Let C be A with zeros as 0 and let x_e be variables for zero positions. B = C + sum x_e E_e. For p > 2, summing over F_p^* kills monomials unless every variable exponent is 0 or p-1; each surviving variable contributes -1, giving a global factor (-1)^K.
- **Degree constraint:** B^p is a product of p factors. For p > 2, p-1 >= 2, so at most one variable can have exponent p-1. Thus only C^p and terms with one zero-edge variable survive.
- **One-zero terms:** For a zero at (i,j), insert p-1 copies of E_{ij} and one C. If i=j, E^m=E for m>=1 and E C E = C_{ii}E = 0, leaving C E_{ii} + E_{ii}C. If i != j, E^2=0; only p=3 can avoid adjacent E's, giving E C E = C_{ji}E_{ij}. For p>3 off-diagonal zeros contribute nothing.
- **Final formula:** For p > 2, answer = (-1)^K (C^p + V) mod p. V adds row i and column i for each diagonal zero; for p=3 it also adds C[j][i] to V[i][j] for each off-diagonal zero (i,j).
- **p=2 special case:** A entries are only 0 or 1, and zeros are replaced by 1, so B is the all-ones matrix. B^2 has every entry N, hence output N mod 2 everywhere. The (-1)^K monomial rule does not apply for p=2.
- **Implementation:** Read all ints. If p==2, print N%2 matrix. For p>2, build C, zero parity, and all-zero flag. All-zero C gives zero matrix. N==1 gives a if a != 0 else 0. Compute C^p with result=C, base=C, exponent p-1; binary squaring with conditional final square.
- **Matmul:** Use transposed Y and sum(map(mul, row, col)) % p; this keeps the inner dot product mostly in C-level loops. Complexity is O(N^3 log p), with N <= 100 and log p <= 30.
- **Pitfalls:** Do not mutate C during exponentiation; matmul returns new lists. Do not forget the p=3 off-diagonal correction. Do not apply the p>2 sign formula to p=2.
