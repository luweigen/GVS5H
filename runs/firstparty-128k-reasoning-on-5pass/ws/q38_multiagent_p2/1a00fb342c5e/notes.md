- **Model:** Treat each constraint as an undirected edge with an XOR label. For a connected component, choose a root and define `dist[v]` as the XOR of labels along any path from the root. If every edge satisfies `dist[u] ^ dist[v] == z`, the component is consistent; otherwise no solution exists.
- **Solution form:** In a consistent component, every valid assignment has the form `A[v] = base ^ dist[v]` for one arbitrary base value. Different components have independent bases.
- **Minimization:** The total sum is additive over bits. For bit `b`, if `c` vertices in a component have `dist` bit 1 and the component size is `s`, choosing base bit 0 gives `c` ones, while choosing base bit 1 gives `s - c` ones. Choose base bit 1 exactly when `c > s // 2`; ties choose 0. This is the bitwise majority of the `dist` values.
- **Implementation:** Read all integers at once, build an adjacency list with 0-based indices, and use an iterative stack search. Mark a vertex when pushing it to avoid duplicate visits. Verify every edge whose endpoint is already assigned. Maintain the component size and 32 per-bit counters while visiting vertices. After finishing a component, compute its optimal base and store it in `bases`.
- **Edge cases:** Self-loops require `z == 0`; multiple edges are checked individually; `M == 0` outputs all zeros; isolated vertices are handled directly with base 0; inconsistent cycles or parallel edges print `-1`.
- **Complexity:** Time is `O(N * 32 + M)` and memory is `O(N + M)`. `B = 32` is safe because `Z_i <= 10^9 < 2^30`, and higher optimal base bits are always 0.
