Use the construction A = N + 1 and M = N^2 for every test case. By the binomial theorem, (N + 1)^N - 1 is divisible by N^2, so n = N works. For any 1 <= d < N, (N + 1)^d - 1 is congruent to N*d modulo N^2, which is not divisible by N^2, so no smaller n works. The edge case N = 1 gives A = 2 and M = 1, which is valid because every positive power satisfies the condition and the smallest n is 1. All values fit the limits since A <= 10^9 + 1 and M <= 10^18.
