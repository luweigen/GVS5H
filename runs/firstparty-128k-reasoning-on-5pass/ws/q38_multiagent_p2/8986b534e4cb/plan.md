Convert road strengths to prefix sums P_0,...,P_{N-1}; person i with a=min(S_i,T_i), b=max(S_i,T_i) gives l=a-1, r=b-1, equality P_l=P_r, and if S_i<T_i then P_l is strictly below all interior P's, otherwise strictly above them. A set of people is feasible iff the equality/inequality graph is acyclic, and this is equivalent to the absence of a bad pair: same-sign strict crossing, any-sign shared single endpoint with overlap, or opposite-sign identical interval. Feasibility over person-index intervals is monotone, so a query [L,R] is Yes exactly when no bad pair is fully contained in [L,R]. Therefore compute for each person i the smallest later index j that forms a bad pair with i, take suffix minima over i, and answer each query by comparing R with that minimum. The earliest bad partner is found by group scans for identical/shared-endpoint cases and by two orientation-specific segment-tree sweeps for same-sign strict crossings.
