- **Prefix model:** Let P_0,...,P_{N-1} be road-strength prefix sums. For person i, a=min(S_i,T_i), b=max(S_i,T_i), l_i=a-1, r_i=b-1. Requirement is P_{l_i}=P_{r_i}, and if S_i<T_i then P_x>P_{l_i} for l_i<x<r_i; if S_i>T_i then P_x<P_{l_i}.
- **Feasibility criterion:** After contracting equal prefix positions, strict inequalities form a directed graph. The set is feasible iff this graph is acyclic. Infeasibility reduces to local bad pairs.
- **Bad pairs:** (1) same-sign strict crossing: l_i<l_j<r_i<r_j or symmetric; (2) same l or same r with different other endpoint, for any sign; opposite-sign identical interval is also bad and is covered by same l/r. Important correction: same-sign shared endpoint is bad because the longer interval’s interior contains the shorter interval’s endpoint, forcing P_x>P_l and P_x=P_l simultaneously. Therefore endpoint scans must be any-sign, not opposite-only.
- **Query reduction:** Feasibility over person-index intervals is monotone. Compute nxt[i]=earliest later index j forming a bad pair with i. A query [L,R] is Yes iff no i in [L,R] has nxt[i]<=R. Build suffix minima suf[i]=min(nxt[i],suf[i+1]); answer Yes iff suf[L-1]>R-1 using 0-based indices.
- **Endpoint bad pairs:** Right-to-left scan maintaining last_l[l] and last_r[r] over all signs. For current i, candidate is last_l[l_i] and last_r[r_i]; take min into nxt[i], then update last_l/l_r with i.
- **Same-sign crossing sweep:** Process each sign in increasing index order. Maintain active intervals not yet removed by a strict crossing. The active family remains laminar (touching/nested allowed). For current [l,r], earlier strict crossings are Type A: p<l<rv<r, and Type B: l<p<r<rv. Remove all active Type A and Type B intervals, setting nxt[old]=min(nxt[old],current).
- **Why removals are complete:** In a laminar family, intervals containing a point form a chain. For Type A, the rightmost start p<l with some active r>l is the innermost candidate; if its smallest active r>l is >=r, no earlier start can have r<r. Repeating removes all Type A. Type B is symmetric using point r and rightmost start p<r with active r>r, requiring p>l.
- **Data structures:** Segment tree over start coordinate l stores max active r at each l. find_prefix(x,th) returns the rightmost p<=x with max active r>th in O(log N), using canonical prefix nodes and descending to the rightmost leaf. Per-l compressed Fenwick trees store active r values, supporting successor(th)=smallest active r>th and max active r. Each interval is inserted once and removed at most once per sign.
- **Implementation details:** Strict inequalities are essential: use bisect_right for successor and segment-tree threshold >. Coordinates are prefix indices 0..N-1. Use a bit-shift key (l<<SHIFT)|r with SHIFT=N.bit_length() for id_map. Special-case K=1 Fenwick lists for speed. The segment tree needs a special case for full prefix [0,size).
- **Self-test:** Running with argument test executes sample checks and random brute-force validation. The brute force builds DSU equalities and directed strict-inequality edges, then checks for cycles.
