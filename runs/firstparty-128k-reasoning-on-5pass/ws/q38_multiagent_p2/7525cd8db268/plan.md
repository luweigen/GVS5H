Model each conflicting pair as an interval `[min(a, b), max(a, b)]` on the positions `1..n`; a subarray is invalid exactly when it fully contains at least one such interval. For a fixed set of intervals, for each right endpoint `r`, let `M(r)` be the maximum left endpoint among intervals with right endpoint `<= r`; then the valid subarrays ending at `r` are exactly those starting after `M(r)`, contributing `r - M(r)`. Sweep `r` from `1` to `n`, inserting intervals when their right endpoint is reached, to compute the original valid count. Removing one interval only changes `M(r)` when that interval is the unique active maximum, and the gain at that `r` is the current maximum minus the second maximum left endpoint. Accumulate these gains per interval during the same sweep, then return the original count plus the largest per-interval gain.
