Only deleting a negative value can improve the answer, because for any x >= 0 a subarray in the array after deleting x corresponds to an original subarray with sum at least as large. Represent the array in a segment tree where positions of the currently deleted value are inactive zeros and all other positions are active with their original values. Each node stores total sum, best prefix, best suffix, and best subarray, with prefix/suffix/best defined only for segments containing at least one active element; inactive leaves use -inf for those fields. For each distinct negative x, temporarily mark its positions inactive, query the root best as the maximum subarray sum after deleting x, then restore the positions. If a deletion would leave no active element, the root best is -inf and is ignored, so the original answer remains valid. The total number of leaf updates is O(n), giving O(n log n) time.
