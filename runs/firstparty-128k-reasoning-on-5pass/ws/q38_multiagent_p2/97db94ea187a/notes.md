- **BFS layering:** A connected graph has a unique layering by distance from vertex 1. Layer 0 has size 1, later layers are positive. Edges may exist only inside a layer or between adjacent layers, and every vertex in layer i+1 must have at least one neighbor in layer i. This gives a bijection to layer-size compositions plus independent edge choices.
- **Edge generating function:** For fixed layer sizes, labels contribute `(N-1)! / prod(l_i!)`. Between previous layer size `a` and new layer size `b`, each new vertex chooses a nonempty neighbor subset: `((1+x)^a - 1)^b`. Inside the new layer: `(1+x)^{C(b,2)}`.
- **Shifted variable:** Let `x` mark extra edges beyond the minimum `N-1`. The shifted transition is `invfact[b] * (1+x)^{C(b,2)} * (((1+x)^a - 1)/x)^b`. At `x=0` its value is `invfact[b] * a^b`.
- **EGF DP:** Store the exponential generating function factor `1/prod(l_i!)` in the DP and multiply by `fact[N-1]` at the end. State is `(s, e, p, a)`: total vertices `s`, even-distance count `e`, last-layer parity `p`, last-layer size `a`.
- **Finish pruning:** Let `r=N-s`, `d=half-e`. If the next layer is odd (`p=0`), valid next sizes are: `d=0` -> only `b=r`; `1<=d<=r-1` -> `1<=b<=r-d`. If the next layer is even (`p=1`): `d=r` -> only `b=r`; `1<=d<=r-1` -> `1<=b<=d`. This condition is necessary and sufficient because the remaining vertices can be placed in one or two layers.
- **State construction:** Use bitmasks of possible last-layer sizes for each `(s,e,p)`. Propagate only finishable targets. Then build explicit states and transitions. Transitions increase `s`, so processing states in increasing `s` is topological.
- **Multipoint evaluation:** The polynomial degree is at most `(N-1)(N-2)/2`, so use `D = (N-1)(N-2)/2 + 1` points `t=0..D-1`. Since `P > D`, all `t>0` are invertible. Precompute `W_{a,b}(t)` for all `a,b,t`.
- **Scalar DP per point:** For each `t`, run a scalar DP. Accumulate `dp[to] += val * W` without modulo in the inner loop; reduce `val` modulo `P` when reading a state. This is safe because each state has small indegree and values stay small.
- **Interpolation:** Newton forward differences at `0..D-1` give coefficients in the binomial basis `C(x,k)`. Convert to monomial coefficients using signed Stirling numbers of the first kind: `C(x,k) = (1/k!) sum_j s(k,j) x^j`. Finally multiply all coefficients by `fact[N-1]`.
- **Complexity:** `N<=30`, `D<=407`. Pruned states/transitions are small; the main cost is `D` scalar DPs over the transition graph, plus `O(D^2)` interpolation.
