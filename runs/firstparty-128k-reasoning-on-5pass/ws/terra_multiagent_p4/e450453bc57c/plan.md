Compute the minimum cost to turn every length-`x` window into equal values; this cost is the sum of distances to the window median. Then select at least `k` pairwise non-overlapping windows with minimum total cost using dynamic programming over positions and number of selected segments. Efficiently maintain each sliding window’s median and deviation sum using two balanced halves / heaps or coordinate-compressed Fenwick trees. Since all operation costs are nonnegative, optimizing for exactly `k` windows is sufficient.
