Rewrite each 400 number as \(x^2\), where \(x\) has exactly two distinct prime factors. Thus, for each query \(A\), we need the largest integer \(x \le \sqrt{A}\) whose number of distinct prime factors is exactly two, then answer \(x^2\). Precompute all such valid \(x\) up to \(10^6\), sort their squares, and answer each query with binary search. A sieve can compute the number of distinct prime factors for every integer efficiently.
