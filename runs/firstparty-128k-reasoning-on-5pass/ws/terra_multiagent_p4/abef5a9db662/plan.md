Process all possible initial ratings simultaneously using a mapping from each rating to its current final rating. Since a contest only changes ratings within an interval by +1, maintain this mapping efficiently with a lazy segment tree supporting range increment and point queries. Build the tree over ratings from 1 through \(5 \times 10^5\), apply each contest as a range add on \([L_i, R_i]\), then answer every query by retrieving the final value at its initial rating. This works because all ratings evolve under exactly the same sequence of interval-based increments.
