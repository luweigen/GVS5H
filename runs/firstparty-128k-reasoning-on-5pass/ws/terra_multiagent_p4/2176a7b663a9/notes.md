- **Bounded-hop lemma:** A minimum-weight path can be assumed induced: if two nonconsecutive vertices on the path are adjacent, replacing the subpath between them by that edge removes one or more positive-weight vertices and strictly improves the path. The disjointness graph of intervals is a co-interval graph and has no induced path on five vertices. Indeed, an induced `P5` in the disjointness graph would give an induced complement of `P5` in the interval-overlap graph; that complement contains an induced `C4`, impossible because interval graphs are chordal. Hence every induced path has at most four vertices, so every optimum has at most two internal vertices.
- **Direct paths:** If endpoint intervals are disjoint, their edge has weight `W_s + W_t` and is optimal because every other path includes positive-weight internal vertices.
- **Overlapping endpoint classification:** Suppose `s,t` overlap. A single internal interval disjoint from both must be either strictly left of both (`R_i < min(L_s,L_t)`) or strictly right of both (`L_i > max(R_s,R_t)`).
- **Two-internal classification:** For a path `s-i-j-t`, each internal interval is left or right of its adjacent endpoint. If both are on the left, whichever is farther left is disjoint from both endpoints, producing a cheaper one-internal path; the same holds if both are on the right. Thus only opposite-side cases can be optimal: `i` left of `s` and `j` right of `t`, or vice versa. Since `s,t` overlap, the two selected intervals are automatically disjoint. Their minimum costs are respectively `leftMin[L_s] + rightMin[R_t]` and `rightMin[R_s] + leftMin[L_t]`.
- **Preprocessing:** `leftMin[x]` stores the minimum vertex weight with `R < x`, built as a prefix minimum over right endpoints. `rightMin[x]` stores the minimum weight with `L > x`, built as a suffix minimum over left endpoints. Endpoint coordinates are at most `2N`, so preprocessing is `O(N)`.
- **Complexity:** Each query uses four constant-time candidates. Total complexity is `O(N + Q)` time and `O(N)` memory.
- **Strict inequalities:** Adjacency requires empty integer interval intersection, so use exactly `R < L`; intervals touching at an endpoint overlap and are not adjacent.
