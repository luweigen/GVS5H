Model each state as `(vertex, parity)`, where parity indicates whether the graph has been reversed an even or odd number of times. Moving along an available edge costs `1`, while toggling parity at the same vertex costs `X`. Build a doubled graph with `2N` states: original-direction transitions for parity `0`, reversed-direction transitions for parity `1`, and reversal transitions between the two copies. Run Dijkstra’s algorithm from `(1, 0)` and take the minimum distance to `(N, 0)` or `(N, 1)`.
