Characterize \(f(L,R)\) in terms of the distinct values present in the subarray: each operation removes one contiguous interval of currently present integer values, so the minimum equals the number of connected components of the set of distinct values. Rewrite this as a contribution over value gaps: a subarray contributes one base component if nonempty, plus one for every adjacent value pair \(x,x+1\) such that \(x\) is present and \(x+1\) is absent. Sum these contributions over all subarrays efficiently by counting, for each value/gap, subarrays satisfying the required occurrence constraints. Use offline occurrence-position processing and a data structure to aggregate counts in \(O(N\log N)\) or similar.
