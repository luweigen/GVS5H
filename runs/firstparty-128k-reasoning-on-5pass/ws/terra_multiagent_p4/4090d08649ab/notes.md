- **Characterization:** For a fixed subarray, only its set of distinct values matters. One operation can erase any contiguous integer interval entirely contained in that set. Thus the minimum number of operations equals the number of connected components of the distinct-value set.
- **Component charging:** Charge every component to its largest present value `x`. This occurs exactly when `x` is present and `x+1` is absent. Use virtual value `N+1`, permanently absent, so that a component ending at `N` is counted.
- **Fixed-right formula:** Fix right endpoint `R`, and let `last[x]` be the latest occurrence position of value `x` in positions `1..R`, or zero if absent. For a left endpoint `L`, value `x` is present iff `last[x] >= L`; value `x+1` is absent iff `last[x+1] < L`. Therefore `x` is charged for exactly `max(0, last[x]-last[x+1])` possible left endpoints.
- **Sweep invariant:** Hence `S_R = sum(x=1..N) max(0, last[x]-last[x+1])` equals `sum(L=1..R) f(L,R)`. Adding `S_R` for every `R` produces the required sum over all subarrays.
- **Constant-time update:** When processing `A_R=a`, only `last[a]` changes. Consequently only summands indexed `a-1` (if `a>1`) and `a` can change. Subtract their old contributions, set `last[a]=R`, then add their new contributions.
- **Complexity:** The sweep takes `O(N)` time and `O(N)` memory. The final answer may be `Theta(N^2)`, but Python integers safely handle it.
- **Validation detail:** If `a=N`, the `a` contribution uses `last[N+1]=0`; if a value has never occurred, its last occurrence is zero, correctly giving no valid left endpoint where it is present.
