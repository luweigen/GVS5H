Model walkways available at each floor level as connectivity in the grid induced by buildings of height at least that level. For a query, if the two blocks are connected at a certain level, movement can be performed horizontally for free at that level; the optimal stair cost is determined by the highest level at which their blocks remain connected. Preprocess a merge tree (Kruskal reconstruction tree) by activating cells from highest to lowest height and unioning adjacent active cells, so each pair’s maximum common-connectivity level is obtainable by LCA. Then compute each answer from the start floor, destination floor, and this connectivity threshold.
