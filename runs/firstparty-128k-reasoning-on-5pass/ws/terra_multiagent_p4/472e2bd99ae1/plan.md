Sort all three sequences in descending order. Since every value is positive, the expression is nondecreasing in each selected value, so the largest combinations can be explored from `(0,0,0)` using a max-heap. Repeatedly pop the current largest triple and push its three index-increment neighbors if unvisited; after exactly K pops, the popped value is the answer. The heap contains only O(K) states, making the algorithm efficient for the constraint `K ≤ 5×10^5`.
