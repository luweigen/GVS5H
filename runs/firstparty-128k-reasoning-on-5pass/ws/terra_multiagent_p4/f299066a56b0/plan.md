Use the sorted order to model each kagamimochi as pairing a smaller unused mochi with a larger unused mochi satisfying \(2 \cdot small \le large\). The maximum number of pairs can be found by binary searching the answer \(K\), then greedily checking whether the smallest \(K\) candidates can each be paired with distinct sufficiently large mochi. For a fixed \(K\), pairing the \(i\)-th smallest selected mochi with the \(i\)-th mochi among the final \(K\) elements is sufficient and necessary. This yields an \(O(N \log N)\) solution, suitable for the constraints.
