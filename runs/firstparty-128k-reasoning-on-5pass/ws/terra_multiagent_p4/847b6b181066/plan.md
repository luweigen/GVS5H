Represent the cumulative wind displacement after each time step as a prefix coordinate. Smoke generated at time \(k\) is located at the current prefix displacement minus the prefix displacement at generation time, so smoke is at \((R,C)\) at time \(t\) exactly when a previously seen prefix coordinate equals `current_prefix - (R,C)`. Maintain a hash set of all prefix positions up through the previous time, update the current displacement for each wind direction, query the required translated coordinate, then insert the current prefix position. This gives expected \(O(N)\) time and \(O(N)\) memory.
