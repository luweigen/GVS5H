Reinterpret each pair by choosing which of the three coordinates attains its maximum; then both cakes in a pair contribute their value in that chosen coordinate. This reduces the problem to selecting exactly \(2K\) distinct cakes, assigning each selected cake one of three coordinate labels, maximizing the assigned-coordinate sum, with every label used an even number of times. Start from each cake’s best coordinate and the globally best \(2K\) cakes, then derive the minimum-loss modifications needed to make the three label counts even. Use the fact that only parity states matter (four feasible parity configurations because the total selected count is even), enabling a constant-sized correction computation after sorting and maintaining candidate exchanges.
