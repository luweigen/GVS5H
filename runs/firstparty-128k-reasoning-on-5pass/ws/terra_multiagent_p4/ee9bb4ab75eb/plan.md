Build a trie over all words, storing at each node how many words pass through it. A prefix of depth `d` is feasible when its trie node has count at least `k`; after removing one word, only nodes along that word’s path can lose feasibility. Compute the global deepest feasible prefix depth, then for each word temporarily account for the possible loss of nodes whose count is exactly `k`. Efficiently answer each removal by tracking the best unaffected depth and the best still-valid depth on the removed word’s path.
