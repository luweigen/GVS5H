Use prefix sums \(S_0=0,\ S_r=\sum_{i=1}^r A_i\), so every subarray sum is \(S_r-S_{l-1}\). For each right endpoint \(r\), expand \((S_r-S_j)^K\) using the binomial theorem, where \(0\le j<r\). Maintain for every exponent \(t\in[0,K]\) the running sum \(\sum_{j<r} S_j^t\), allowing each endpoint contribution to be computed in \(O(K)\). Since \(K\le 10\), this yields \(O(NK)\) time and \(O(K)\) extra space modulo 998244353.
