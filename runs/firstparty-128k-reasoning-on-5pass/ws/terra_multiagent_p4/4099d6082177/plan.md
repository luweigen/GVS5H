Root the tree arbitrarily and use a bottom-up DFS to track unfinished path fragments inside each subtree. Each fragment is represented by its number of vertices modulo/within the target path size K; at every vertex, child fragments must be combined through that vertex so that all completed paths have exactly K vertices. Since a vertex can belong to only one final path, at most two incident unfinished fragments may be connected through it. Validate these local conditions during iterative postorder traversal and accept exactly when no invalid fragment remains at the root.
