For each possible divisor \(d\), count how many array elements are divisible by \(d\). A value \(d\) can be the GCD of a chosen set containing \(A_i\) exactly when \(d\mid A_i\) and at least \(K\) elements are divisible by \(d\). Compute all divisibility counts using a sieve-style loop over multiples, then mark every feasible divisor. Finally, for each distinct value, find the largest feasible divisor among its divisors and output that result for each occurrence.
