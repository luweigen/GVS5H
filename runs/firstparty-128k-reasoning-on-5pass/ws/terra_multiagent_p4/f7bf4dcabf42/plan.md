Use dynamic programming over the standard LCS DP state vector against the fixed string S. Since N≤10, a state can be represented by the sequence of LCS values for all prefixes of S after processing a constructed string prefix; there are at most 2^(N+1) relevant monotone states. Precompute, for every state and each character, the next LCS state using the usual LCS transition. Then perform M steps of DP over these automaton states, grouping the 26 character transitions, and sum counts by the final LCS value with the full S.
