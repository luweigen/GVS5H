Model the final upper lengths as variables \(u_i\), with final lower lengths forced to \(d_i=H-u_i\). For a fixed common total \(H\), each \(u_i\) has an interval constraint from only being allowed to decrease teeth: \(H-D_i \le u_i \le U_i\), plus adjacent values must differ by at most \(X\). The total grinding cost is the original total length minus \(N \cdot H\), so we need to maximize feasible \(H\). Derive a linear-time feasibility check for a candidate \(H\) by propagating the allowable interval for each upper tooth, then binary search the maximum feasible \(H\).
