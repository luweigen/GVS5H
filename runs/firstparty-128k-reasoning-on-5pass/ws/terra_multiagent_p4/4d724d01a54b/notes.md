- **Insertion characterization:** Scan the original permutation from left to right. Before processing position `i`, the first `i-1` processed elements are sorted. Insert `P_i` by repeatedly swapping it left across every earlier element larger than it. If `k` earlier elements are smaller, it finishes at prefix position `k+1`, using edges `k+1, k+2, ..., i-1`. Its cost is `sum(k+1..i-1) = T(i-1)-T(k)`, where `T(x)=x(x+1)/2`.
- **Fenwick formula:** While scanning, maintain frequencies of already seen values. For current value `x`, `k = count(seen values < x) = bit.sum(x-1)`. Add `T(i-1)-T(k)` and insert `x` into the Fenwick tree. This is `O(N log N)` time and `O(N)` memory.
- **Why only reduced words matter:** Regard an adjacent swap at edge `j` as Coxeter generator `s_j`. Sorting requires a word representing the permutation inverse. Any non-reduced expression can, by the deletion property for symmetric groups, have two generators deleted while preserving its product. Since all swap costs are positive, an optimum must be reduced. Thus every initially inverted pair crosses exactly once.
- **Weighted reduced-word lemma:** For generator costs `cost(s_j)=j`, among all reduced sorting words, the stable forward-insertion word has minimum total weight. Reduced words for the same permutation are connected by commutations `s_a s_b = s_b s_a` for `|a-b|>1` and braid moves `s_j s_{j+1} s_j = s_{j+1} s_j s_{j+1}`. Commutations preserve cost. The braid word on the left costs `3j+1`, while the right costs `3j+2`; hence orient every braid as `s_{j+1}s_j s_{j+1} -> s_j s_{j+1}s_j`.
- **Normalization argument:** The standard left-greedy normalization of reduced words repeatedly commutes independent generators as needed and applies the cost-decreasing braid orientation above. Induction on the processed prefix shows its normal form is exactly stable insertion: when the next original item is appended, its required crossings are moved as far left as possible, giving the descending block `s_{i-1}s_{i-2}...s_{k+1}`. Therefore every reduced sorting word can be transformed to the insertion word through cost-preserving commutations and cost-decreasing braids, proving global optimality.
- **Bounds:** The answer can be cubic in `N`, so 64-bit arithmetic is required in languages with fixed-width integers. Python integers are safe.
