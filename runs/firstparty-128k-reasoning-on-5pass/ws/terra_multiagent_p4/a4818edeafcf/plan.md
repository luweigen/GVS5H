Process the first split position while maintaining the distinct count of the left subarray. For every possible start of the third subarray, maintain the best value of `distinct(left) + distinct(middle)` over all valid first splits using a range-add/range-maximum segment tree. Moving the middle/right boundary one step right updates all first-split candidates according to whether the newly included value was already present in their middle segment. Precompute suffix distinct counts, then combine the maintained best two-part score with the suffix count to obtain the answer in \(O(N \log N)\).
