- **Source/target blocks:** Label initial pieces by increasing source positions `x`. Every reachable final support assignment maps sources monotonically to occupied target positions `y`; every target receives one nonempty consecutive block of sources.
- **Non-expansion condition:** If consecutive target blocks are separated after source indices `r` and `r+1`, then `x[r+1]-x[r] >= y[s+1]-y[s]`. This is necessary because every pull operation is non-expanding, and it is used as the transition condition.
- **Distance condition:** With exactly `k` operations, every source assigned to target `y[s]` must lie in `[y[s]-k, y[s]+k]`. The corresponding valid source-index interval is computed with binary search.
- **Parity condition:** For a completed assignment, count sources whose source/target parities differ. If `k` is even, this odd-displacement count must be at most `k`; if `k` is odd, the number of even-displacement sources must be at most `k`. The DP tracks both the minimum and maximum attainable odd-displacement count.
- **DP state:** A state is a possible boundary after target `s`, storing min/max odd counts for all blocks through that target. The transition only accepts prior boundaries before the new one whose source gap dominates the relevant target gap. Heaps aggregate the best valid prior states while scanning boundaries left to right.
- **Search:** Feasibility is monotone separately for even and odd operation counts. Binary search each parity and take the smaller result.
- **Structural rejection:** If there are fewer pieces than required occupied squares, or if no increasing selection of source gaps can dominate all target gaps even without distance/parity restrictions, answer is `-1`.
