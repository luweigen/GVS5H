- **Characterization:** The pieces can be swapped exactly when the graph has two distinct internally vertex-disjoint simple paths from `S` to `T`; if so, the answer is the minimum sum of their lengths.
- **Schedule from paths:** Move A along one path until just before `T`, move B along the other path from `T` to `S`, then move A into `T`. Choose the non-direct path for A when one path is the edge `S-T`. This uses exactly the combined path length.
- **Network model:** Split every vertex `v` into `vin -> vout`. Give internal vertices capacity one and `S,T` capacity two. For every undirected edge, add both directed transitions `uout -> vin` and `vout -> uin`, each with capacity one and cost one. Send two units from `Sout` to `Tin`.
- **Direct-edge case:** Capacity one on the transition `Sout -> Tin` prevents both units from using the sole edge `S-T`, so the graph of two vertices and one edge correctly yields `-1`.
- **Undirected-edge capacity:** Separate capacities for both directions are sufficient here. Two internally vertex-disjoint simple `S-T` paths cannot share an edge except possibly `S-T`; in that exceptional case both paths use the same `S -> T` direction, whose capacity is one.
- **Min-cost flow:** Two successive shortest augmenting paths compute the minimum combined length. Original costs are nonnegative, and reverse residual edges permit rerouting after the first augmentation.
- **Potential correctness fix:** Dijkstra must process all reachable residual vertices. Stopping as soon as `sink` is popped and updating potentials only for settled vertices can leave an invalid reduced-cost potential for later residual edges. The implementation exhausts the priority queue, then adds `dist[v]` to every reachable vertex potential.
- **Complexity:** The residual network has `2N` vertices and `O(N+M)` edge pairs. Two Dijkstra runs give `O((N+M) log N)` time and `O(N+M)` memory.
- **Validation targets:** Compare against configuration-space BFS on all small connected graphs and ordered pairs `(S,T)`. Important cases are trees, triangles, cycles, a direct edge plus an alternate route, and articulation-separated endpoints.
