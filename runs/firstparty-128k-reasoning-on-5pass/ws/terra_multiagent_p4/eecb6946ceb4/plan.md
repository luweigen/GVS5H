Use the fact that a fine triplet is a 3-term arithmetic progression, so for each possible middle value \(B\), we need to count offsets \(d>0\) such that both \(B-d\) and \(B+d\) are present. Since values are at most \(10^6\), exploit a boolean presence array and a fast convolution/FFT approach to count pairs whose sum is \(2B\). The resulting coefficient for each even sum gives the number of unordered endpoint pairs around that middle value. Sum these counts only for middle values contained in the set.
