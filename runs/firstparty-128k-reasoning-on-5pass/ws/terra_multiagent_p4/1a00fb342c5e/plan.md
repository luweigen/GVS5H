Model the constraints as an undirected graph where edge `(x, y)` has XOR weight `z`. In each connected component, assign every vertex a provisional XOR-distance value from an arbitrary root and verify every edge is consistent; any inconsistency means no solution exists. Every valid assignment in a component has the form `A_v = dist_v XOR t` for one shared non-negative integer `t`. Minimize the component sum independently by choosing each bit of `t` according to whether fewer than half of the component’s distance values have that bit set.
