Model the game as a race to make the first move on every index, while players may spend extra moves decrementing already chosen indices to control turn parity. Derive the winning condition by sorting the values and analyzing how many “delay moves” can be made before each new index must be claimed. The result should be computable in \(O(N\log N)\), handling duplicate minimum-relevant values carefully because they affect whether a player can force the final claiming move. Implement the derived criterion using 64-bit integer arithmetic.
