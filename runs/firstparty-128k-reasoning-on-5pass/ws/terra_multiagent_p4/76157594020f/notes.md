- **Algorithm:** Binary search the minimum feasible maximum equal-character run length in `[1, n]`. Feasibility is monotonic, since any solution satisfying a limit also satisfies every larger limit.
- **Limit 1:** The final string must be one of the two globally alternating binary strings. Count mismatches against `0101...`; mismatches against `1010...` equal `n - mismatches_start_zero`. The smaller count is the exact minimum flip cost.
- **Limits at least 2:** For every maximal original run of length `r`, the minimum required flips is `r // (limit + 1)`. Sum this over all original runs.
- **Run-cost confirmation:** The formula was checked against representative boundary cases. A run of length at most `limit` costs zero. A run of length `limit + 1` costs one, by flipping an interior character and splitting it into two runs of length at most `limit`. More generally, each flip can be placed as an interior separator between groups of at most `limit` unchanged characters, requiring exactly one separator per full block of `limit + 1` characters. For `limit >= 2`, separators can be kept away from original run boundaries, so flipped characters do not merge with adjacent original runs; costs therefore add independently across runs.
- **Special-case necessity:** The independent-run formula is invalid for limit `1`, because all characters must obey one global alternating parity pattern. Direct mismatch counting handles this.
- **Sample results:** `"000001", 1` gives `2`; `"0000", 2` gives `1`; `"0101", 0` gives `1`.
- **Key edge cases:** A one-character string returns `1`; zero operations returns the original maximum run length; an already alternating string returns `1`; a uniform run uses the stated floor formula for every limit at least `2`.
- **Complexity:** Each feasibility check is `O(n)`, binary search uses `O(log n)` checks, for `O(n log n)` time and `O(1)` extra space.
