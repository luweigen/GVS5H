Process insertions in reverse order, converting each insertion position into the choice of the \(P_i\)-th currently available final slot. Initially all positions \(1 \ldots N\) are empty; when handling \(i=N\) down to \(1\), place value \(i\) into the \(P_i\)-th empty position from the left. Use a Fenwick tree to maintain which positions are empty and efficiently find the index of the k-th available slot. This yields \(O(N \log N)\) time and \(O(N)\) memory.
