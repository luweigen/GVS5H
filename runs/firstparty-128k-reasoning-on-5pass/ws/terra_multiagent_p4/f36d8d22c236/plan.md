Model required character changes as a directed graph on 26 letters: for every position, the source letter must consistently map to exactly one target letter, otherwise it is impossible. Each nontrivial mapping edge requires one operation, but directed cycles cannot be resolved directly because replacing a letter merges all occurrences. A cycle of length \(k\) needs one additional temporary letter, so it costs \(k+1\) operations instead of \(k\). Count all required edges plus one for every directed cycle, provided there is an unused letter available to serve as temporary storage.
