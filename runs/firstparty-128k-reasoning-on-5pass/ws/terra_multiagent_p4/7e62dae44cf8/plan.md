Model Takahashi’s occupied cells as an expanding connected region. Maintain all currently adjacent unabsorbed slimes in a min-heap by strength; whenever the minimum slime satisfies `strength * X < current_strength`, absorbing it is always optimal because it only increases strength and exposes more candidates. Pop absorbable cells, add their strengths, and push their unvisited four-directional neighbors into the heap. When the minimum candidate is not absorbable, no adjacent slime can be absorbed, so the process terminates with the maximum strength.
