- **Structural characterization:** A valid coloring has a north-west closed black region. If cell `(r, c)` is black, then every cell `(r', c')` with `r' <= r` and `c' <= c` must be black, because row prefixes force cells to the left black and column prefixes force cells above black.
- **Conflict criterion:** A prescribed white cell `(rw, cw)` and prescribed black cell `(rb, cb)` are incompatible exactly when `rw <= rb` and `cw <= cb`. The black cell would force the white cell to be black.
- **Sufficiency proof:** If there is no white point north-west of any black point, color black exactly the north-west closure of all prescribed black cells, and color every other cell white. No prescribed white lies in this closure by the criterion. The closure is a north-west closed shape, so every row is a black prefix followed by white cells and every column is a black prefix followed by white cells.
- **Sweep algorithm:** Sort constraints by row ascending. Maintain the minimum column among all white constraints in rows processed so far. For every black constraint `(x, y)`, if the minimum seen white column is at most `y`, then that white is north-west of this black and the answer is `No`.
- **Same-row handling:** For each row, first incorporate all white cells into the minimum, then check all black cells. This correctly handles `rw = rb`, since equality is included in the conflict condition.
- **Complexity:** Sorting costs `O(M log M)` and the sweep costs `O(M)`. Memory usage is `O(M)`. `N` is not otherwise used, so values up to `10^9` are safe.
