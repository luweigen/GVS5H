Process queries offline by increasing \(R\), maintaining LIS dynamic-programming information for the prefix processed so far. For each position, compute its LIS length ending there and organize values by that length so queries constrained by \(X\) can be answered efficiently. The key observation is that the answer is the largest subsequence length whose minimum feasible tail value is at most \(X\). Use coordinate compression and Fenwick/segment-tree based updates and prefix queries to achieve \(O((N+Q)\log N)\).
