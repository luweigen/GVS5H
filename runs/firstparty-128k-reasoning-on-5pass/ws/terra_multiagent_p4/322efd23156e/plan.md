Exploit that foods affect only one vitamin, so for each vitamin independently compute the maximum intake attainable for every calorie budget up to \(X\) using 0/1 knapsack DP. For a target minimum intake \(m\), determine the minimum calories needed to obtain at least \(m\) of each vitamin from these three DP tables. The target is feasible exactly when the sum of those three minimum calorie costs is at most \(X\). Binary search the largest feasible target value.
