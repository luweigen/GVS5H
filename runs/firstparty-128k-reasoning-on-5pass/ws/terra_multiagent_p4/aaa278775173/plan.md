Model each valid segment as a path beginning at a `1`, moving diagonally while matching the alternating expected values `2, 0, 2, ...`, with an optional single clockwise turn. Precompute, for every cell and each diagonal direction, the maximum valid alternating continuation length for each expected parity/value state. Then enumerate possible starting `1` cells and initial directions, combine the straight prefix with the best continuation after a clockwise turn. This yields an \(O(nm)\) or small-constant-factor \(O(4nm)\) solution suitable for a \(500 \times 500\) grid.
