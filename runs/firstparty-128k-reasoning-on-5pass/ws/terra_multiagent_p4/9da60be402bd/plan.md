Model each state as a pair of vertices `(u, v)`, representing that we still need to build matching palindrome layers around a path from `u` to `v`. Run multi-source BFS backwards from all valid palindrome centers: `(x, x)` has distance `0`, and every direct edge `(x, y)` gives distance `1`. From a state `(u, v)`, transition to `(a, b)` by choosing edges `a -> u` and `v -> b` with the same label, increasing the distance by `2`. The first distance assigned to each pair is its shortest palindrome-path length.
