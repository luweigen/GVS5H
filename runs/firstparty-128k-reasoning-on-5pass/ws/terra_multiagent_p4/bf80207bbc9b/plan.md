Model each row/column operation by a binary toggle choice; the final value of a cell is its original value XOR its row toggle XOR its column toggle. Since \(W \le 18\), enumerate all \(2^W\) possible sets of column toggles. For each fixed column mask, every row can independently choose whether to flip, contributing the minimum of the row’s number of ones and zeros after the column toggles. Precompute frequencies of row bitmasks to evaluate each column mask efficiently.
