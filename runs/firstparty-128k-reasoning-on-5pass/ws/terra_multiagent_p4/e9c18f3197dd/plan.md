Use bitmask DP because `target.length <= 4`. A modified `nums[i]` can serve multiple targets exactly when it is made a multiple of the LCM of their corresponding target values. For every number and every nonempty target subset, compute the cost to increment that number to the next multiple of that subset’s LCM, then update a DP over covered target masks. Deduplicate targets first, since repeated target values impose no additional requirement.
