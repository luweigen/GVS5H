Represent the configuration by consecutive gaps between sorted pieces. One operation reverses three consecutive gaps, which is equivalent to swapping the first and third gaps; therefore, gaps can be permuted arbitrarily among positions of the same parity, while never changing parity classes. Express the total coordinate sum as \(N X_1 + \sum_{j=1}^{N-1}(N-j)\cdot g_j\), then minimize it independently for odd-indexed and even-indexed gaps using the rearrangement inequality. Assign larger gaps to earlier positions within each parity class, since those positions have larger coefficients.
