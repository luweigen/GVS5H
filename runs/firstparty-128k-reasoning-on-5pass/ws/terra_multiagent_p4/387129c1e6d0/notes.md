- **Approach:** Construct every movement segment offline while updating Santa's final coordinates. Horizontal segments are stored as `(y, min_x, max_x)` and vertical segments as `(x, min_y, max_y)`, with both endpoints included.
- **House representations:** Store each house twice: `(y, x, id)` for horizontal matching and `(x, y, id)` for vertical matching. A boolean array indexed by house ID deduplicates houses reached by both types of segments or by multiple segments.
- **Sweep algorithm:** Sort houses and segments by their fixed coordinate, then by interval start. For each fixed-coordinate segment group, merge overlapping intervals and scan the corresponding sorted house group once. Mark every house whose varying coordinate lies inside a merged inclusive interval.
- **Correctness details:** Segment starts and ends are inclusive. Left and down movements normalize endpoint order before storage. Houses encountered at a later segment's start are still included. A house may be marked repeatedly in principle, but boolean marking ensures it contributes once.
- **Complexity:** Sorting costs `O((N+M) log(N+M))`. Each house and segment is scanned a constant number of times after sorting, so sweep time is `O(N+M)`. Memory usage is `O(N+M)`.
- **Integer safety:** Python integers safely handle accumulated coordinates beyond 32-bit range, such as repeated moves of length `10^9`.
