Compute the inversion count for \(k=0\) using a Fenwick tree over values \(0,\ldots,M-1\). As \(k\) increases by one, each element’s residue changes from \(x\) to \(x+1\) unless \(x=M-1\), in which case it wraps to \(0\). For an element changing from \(x\) to \(x+1\), only its comparisons with elements of residue \(x+1\) can change; for a wrapped element, only comparisons with residue \(0\) can change. Precompute positional counts for every value so each transition is updated in \(O(1)\) amortized time, yielding \(O(N\log M+M)\) time.
