Sort all three sequences in descending order; because every element is positive, the expression \(ab+bc+ca\) is non-increasing when any one index moves forward. Treat the values as an implicit 3D monotone grid and use a max-heap best-first search starting from \((0,0,0)\). Each popped state contributes one candidate, and its three forward neighbors are inserted if not visited. After exactly \(K\) pops, the last popped value is the required K-th largest value.
