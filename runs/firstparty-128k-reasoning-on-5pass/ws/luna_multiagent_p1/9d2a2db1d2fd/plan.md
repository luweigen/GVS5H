Model each query’s route as a sequence of buildings, where the floor used when crossing a walkway must be no greater than every building’s floor capacity on that route. For a fixed spatial route, the minimum stair cost depends only on its minimum building height \(M\): the answer is \(|Y-Z|\) if \(M\ge\min(Y,Z)\), otherwise \(Y+Z-2M\). Thus each query reduces to finding the maximum possible bottleneck value between its two blocks, using edge weights \(\min(F_u,F_v)\). Build a maximum spanning tree of the grid, preprocess binary-lifting/LCA minimum-edge values, and answer each bottleneck query in \(O(\log(HW))\).
