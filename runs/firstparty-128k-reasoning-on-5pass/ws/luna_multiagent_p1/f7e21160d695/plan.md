Use Kruskal’s algorithm to build the connectivity hierarchy of the graph: two vertices become connected at threshold \(w\) exactly when their minimax distance is at most \(w\). For each DSU component, maintain how many occurrences of vertices from sequences \(A\) and \(B\) it contains, along with the number of pairs already matchable within that component. When two components merge at edge weight \(w\), the increase in the maximum possible number of internally matched \(A\)-\(B\) pairs contributes \(w\) times that increase to the answer. Process equal-weight edges consistently so all connections formed at the same threshold receive the same cost, and output the total after all components merge.
