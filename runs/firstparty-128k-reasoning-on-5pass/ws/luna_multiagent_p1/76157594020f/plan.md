Binary search the minimum possible maximum run length \(L\) from 1 to \(n\). For a fixed \(L\), compute the minimum flips needed to ensure every resulting run has length at most \(L\). If \(L \ge 2\), use a greedy scan that flips the character at the end of any run reaching length \(L+1\); this is optimal because each flip breaks the current excessive run. For \(L=1\), the resulting string must be alternating, so compute the flips needed for both alternating patterns and take the smaller value.
