Model each state \((u,v)\) as the problem of finding the shortest palindromic path from \(u\) to \(v\). A palindrome can be formed by adding equally labeled edges to the front and back, so from \((u,v)\) transition to \((u',v')\) whenever \(u\to u'\) and \(v'\to v\) have the same label. Initialize answers with \(0\) for \(u=v\) and \(1\) for every existing direct edge, then run a shortest-path computation over the \(N^2\) state graph, using the matched-edge transitions with cost \(2\). Since all costs are \(0\), \(1\), or \(2\), use a priority queue or an equivalent multi-source Dijkstra approach and output the resulting distances.
