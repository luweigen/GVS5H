Let the final common pair-sum be \(H\); then the total grinding cost is \(\sum_i(U_i+D_i)-NH\), so we maximize feasible \(H\). For a fixed \(H\), each final upper tooth must lie in the interval \([\,\max(0,H-D_i),\,U_i\,]\), while consecutive upper lengths differ by at most \(X\). Scan from left to right, maintaining the interval of possible values for the current upper tooth after intersecting its allowed interval with the previous possible interval expanded by \(X\). Feasibility is monotone in \(H\), so binary search the largest feasible \(H\), using 64-bit integers for the answer.
