Process values in descending order, treating each larger value as already fixed at its final position. For a value \(x\) initially at position \(p_x\), its current position is \(p_x\) minus the number of already-processed larger values that initially appeared before it; this count can be maintained with a Fenwick tree. Move \(x\) to position \(x\), paying the sum of the crossed boundary indices, namely \(\sum_{k=q_x}^{x-1} k\), where \(q_x\) is its current position. Sum these costs for all values and implement the computation in \(O(N\log N)\) using 64-bit integers.
