- **Canonical order:** An optimal reduced adjacent-swap sorting sequence can be chosen by fixing values in descending order. At the stage for value \(x\), all larger values are already at their final positions, so the remaining sequence consists of \(1,\ldots,x\), and \(x\) is moved right to the last remaining position.
- **Why this order is optimal:** Reduced sorting sequences differ through commuting independent swaps and local three-element braid transformations. For adjacent boundaries \(i\) and \(i+1\), the two braid orders have costs \(i+(i+1)+i\) and \((i+1)+i+(i+1)\). Since \(i<i+1\), the former is cheaper. Repeatedly applying this exchange gives the descending-value bubble normal form, so that form is minimum-cost.
- **Current rank:** Let \(p_x\) be the original position of \(x\). After removing all already-fixed larger values, its rank among the remaining values is the number of active positions up to \(p_x\). A Fenwick tree maintains these active positions.
- **Cost for one value:** If its current rank is \(q\), moving it to rank \(x\) crosses boundaries \(q,q+1,\ldots,x-1\). The cost is \(\sum_{k=q}^{x-1}k=(q+x-1)(x-q)/2\).
- **Complexity:** Position construction is \(O(N)\); each value performs one Fenwick query and one update, giving \(O(N\log N)\) time and \(O(N)\) memory. Python integers safely handle the maximum answer.
- **Edge cases:** Already sorted permutations contribute zero. For every processed value, its current rank is at most its target rank, so only rightward movement is needed in the canonical sequence.
