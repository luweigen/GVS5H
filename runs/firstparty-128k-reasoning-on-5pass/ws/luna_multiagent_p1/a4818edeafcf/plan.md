Compute distinct counts for all prefixes and suffixes in linear time. For each possible second split position \(j\), maximize the distinct count of the middle segment over all valid \(i<j\), then combine it with the suffix count starting at \(j+1\). Maintain the middle-segment optimum efficiently while sweeping boundaries, using last occurrences and a segment tree or equivalent range-update structure. The final algorithm should run in \(O(N\log N)\) time and \(O(N)\) memory.
