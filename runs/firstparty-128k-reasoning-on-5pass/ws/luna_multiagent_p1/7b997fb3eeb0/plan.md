Precompute for each mochi index \(i\) the first index \(p_i\) whose size is at least \(2A_i\), using binary search, and define \(D_i=p_i-i\). For a query interval of length \(m=R-L+1\), \(k\) pairs are feasible exactly when the first \(k\) mochi can be paired with the last \(k\) mochi, which is equivalent to \(\max(D_L,\dots,D_{L+k-1})\le m-2k+1\). Build a range-maximum query structure over \(D\), then binary-search the largest feasible \(k\) for each query; monotonicity makes each query \(O(\log N)\). Prove the exchange argument that any feasible matching can be transformed into this first-\(k\)/last-\(k\) pairing without decreasing feasibility.
