For a viewpoint \((0,h)\), building \(i\) is visible exactly when its top angular slope \((H_i-h)/X_i\) is strictly larger than every preceding building’s top slope. Therefore, visibility fails for some pair \(j<i\) precisely when \(h\le (X_iH_j-X_jH_i)/(X_i-X_j)\). The answer is the maximum such pairwise intercept over all \(j<i\); if this maximum is negative, height \(0\) already sees every building, so output \(-1\). Compute the maximum intercept in \(O(N\log N)\) using an incremental convex-hull/secant-query structure, then print it with sufficient precision.
