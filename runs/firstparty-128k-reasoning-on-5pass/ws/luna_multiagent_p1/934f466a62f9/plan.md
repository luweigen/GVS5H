Reduce each pair’s price to the coordinate whose two cake values attain the maximum, so every matching becomes an assignment of selected cakes to one of three coordinates with even-sized color classes. Conversely, any such assignment can be paired arbitrarily within each color, giving the same objective value, so the problem becomes selecting exactly \(2K\) cakes with one coordinate choice per cake and even counts for all three coordinates. Derive an \(O(N\log N)\) parity-aware optimization for this colored selection problem, then implement it using 64-bit integers and validate the equivalence and edge cases.
