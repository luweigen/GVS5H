Model each operation as flipping one position and paying the weighted number of 1s after the flip. Only positions where \(A_i \ne B_i\) must be flipped an odd number of times; extra flips are unnecessary because all costs are positive. Let \(S\) be the current weighted sum of 1s, and process required flips in an order that minimizes the sum of intermediate values of \(S\): flip 1→0 positions before 0→1 positions, while ordering each group appropriately by cost. Derive the exact ordering rule and implement the resulting computation in \(O(N \log N)\) time with 64-bit integers.
