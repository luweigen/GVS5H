Build a trie containing all words, storing at each node the number of words passing through it. For every depth, count how many trie nodes have frequency at least `k`; these are the prefixes achievable before any removal. For a removed word, only trie nodes on its path can lose validity, and a node becomes invalid exactly when its original frequency is `k`. Temporarily decrement the valid-node count at those depths, query the greatest depth with a positive count using a segment tree or equivalent max structure, then restore the changes.
