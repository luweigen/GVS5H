We need maximize the minimum number of selected edges on any path from vertex 1 to vertex N. For a candidate distance threshold \(D\), characterize feasibility by assigning integer levels to vertices so that vertex 1 has level 0, vertex \(N\) has level at least \(D\), and every edge increases the level by at most 1; each edge whose level increases must be selected. Compute the minimum number of mandatory selected edges for each threshold, observe that feasibility is monotone in \(D\), and binary-search the largest feasible value. Construct the resulting polynomial-time optimization using a suitable min-cut/closure formulation, then implement it while allowing arbitrary additional edges to be selected to reach exactly \(K\).
