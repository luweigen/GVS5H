- **Particle model:** List the initial occupied positions as `x_1 < ... < x_m` and target occupied positions as `y_1 < ... < y_k`. Pieces preserve their order, so each target must receive a nonempty contiguous group of source pieces.
- **Gap invariant:** For adjacent source particles, their distance never increases. If a boundary separates groups assigned to consecutive targets `y_q, y_{q+1}`, the corresponding source gap must satisfy `x_{j+1}-x_j >= y_{q+1}-y_q`. Internal group gaps need only reduce to zero.
- **Displacement characterization:** For a fixed assignment of every source piece to a target position, the minimum number of operations is `max_i |x_i - z_i|`, provided every adjacent final gap is at most the corresponding initial gap. The operation centers can realize this bound by repeatedly reducing the remaining maximum displacement while never increasing a gap.
- **Binary search:** Feasibility for a bound `L` requires each source piece assigned to target `y_q` to lie in `[y_q-L, y_q+L]`. For each target, compute the eligible source-index interval `[lo_q, hi_q]`.
- **Greedy cuts:** Choose the earliest possible source boundary for each target transition. A cut after source index `j` must leave the next block starting at least at `lo_{q+1}`, end within `hi_q`, and have source gap at least the target gap. Earliest valid cuts preserve maximum flexibility for later groups.
- **Complexity:** Each feasibility check is linear in the number of source and target pieces. Binary search gives `O(N log N)` per test case and `O((sum N) log N)` overall, with `O(N)` temporary memory.
