Model each nonzero operation as choosing a set of positions that becomes 1; operation 1 selects an interval, while operation 2 selects its complement. Since setting positions to 1 is monotone, the problem reduces to finding a minimum-cardinality collection of these sets whose union is all positions. Develop an efficient dynamic-programming or greedy characterization exploiting the interval/complement structure, then reconstruct the selected operations and assign operation 0 to all unused steps. Validate the method on edge cases such as using only intervals, using complements, and impossible instances.
