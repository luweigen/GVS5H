- **State definition:** For each vertex `v`, `best_attached[v]` is the maximum size of a valid selected subtree containing `v` when the edge from `v` to its parent is selected. `best_with4[v]` is the same maximum restricted to subtrees containing at least one degree-4 vertex.
- **Attached transition:** Since the parent edge already contributes one incident selected edge, `v` must select either zero children (degree 1) or exactly three children (degree 4). The zero-child option has size 1 and no degree-4 vertex. The three-child option uses the three largest `best_attached` values among children and makes `v` itself degree 4, so its status is `with4`.
- **Top-vertex transition:** A selected connected subtree has a unique vertex nearest the arbitrary rooting parent direction. This top vertex has no selected parent, so it must select exactly one child (degree 1) or exactly four children (degree 4). One child is allowed only when that child branch already contains a degree-4 vertex. Four children are chosen by taking the four largest attached branch values; the top vertex itself then supplies the required degree-4 vertex.
- **Correctness of child choices:** Every child branch is independently valid and branches are disjoint except at their parent, so maximizing the total size for a fixed child count is equivalent to selecting the largest contributions.
- **Traversal:** The tree is rooted iteratively, producing a parent-before-child order. Dynamic programming is evaluated in reverse order to ensure all child states are ready.
- **Complexity:** Each edge is processed a constant number of times. Time complexity is `O(N)` and memory complexity is `O(N)`.
- **Failure case:** If no top-rooted transition is possible, no alkane subgraph exists and the answer remains `-1`.
