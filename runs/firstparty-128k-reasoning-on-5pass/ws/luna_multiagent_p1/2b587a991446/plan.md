Model the configuration as an ordered pair of distinct vertices \((a,b)\), where A is at \(a\) and B is at \(b\); a move changes exactly one coordinate along an edge while preserving \(a\neq b\). The target is \((T,S)\), so a direct BFS over all \(O(N^2)\) configurations is too large. Derive and implement the graph-theoretic characterization of the shortest “swap” walk, handling separately whether the graph contains an odd cycle and whether the relevant distance parity permits synchronization. Validate the resulting formula/algorithm against edge cases such as trees, bipartite graphs, and the two-vertex graph.
