Process partitions from right to left so that when a new leading subarray is added, every already-existing subarray’s order increases by one. This increases the existing suffix partition cost by `k` times the total `cost` of that suffix, which is fixed by its boundary. Define `dp[l]` as the minimum cost for partitioning `nums[l:]` with local subarray numbering starting at 1, and try every ending index `r` for the first subarray. Use prefix sums to evaluate each transition in O(1), yielding an O(n²) time and O(n) space solution.
