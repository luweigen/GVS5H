Characterize \(f(L,R)\) as the number of connected components of the set of distinct values appearing in \(A_L,\ldots,A_R\), equivalently the number of present values \(x\) such that \(x-1\) is absent. Process right endpoints \(R\) from left to right while maintaining the latest occurrence position `last[x]` of every value. For a fixed \(R\), the number of subarrays ending at \(R\) containing \(x\) is `last[x]`, while the number containing both \(x\) and \(x+1\) is \(\min(last[x], last[x+1])\). Maintain the sum of these quantities under each `last[A_R]` update, and accumulate their difference into the answer.
