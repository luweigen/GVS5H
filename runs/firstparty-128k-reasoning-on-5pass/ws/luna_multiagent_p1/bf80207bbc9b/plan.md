Represent each row as a W-bit mask and let the chosen column flips be another mask `m`. For a fixed `m`, each row is optimally handled by either leaving it unchanged or flipping the entire row, contributing `min(popcount(row xor m), W - popcount(row xor m))`. Count the frequency of every row mask, then compute all objective values as the XOR convolution of this frequency array with the cost array using the Walsh–Hadamard transform. The answer is the minimum value among the resulting values, with total complexity `O(H + W·2^W)`.
