For each value \(x\), compute the number of reductions needed to reach zero: \(d(x)=\lfloor\log_4 x\rfloor+1\). Since each operation reduces two selected elements once, the minimum operations for a query is \(\lceil \sum_{x=l}^{r} d(x)/2\rceil\). Build a prefix-sum function for \(d(x)\) by processing powers-of-four ranges, then evaluate each query in \(O(\log_4 10^9)\) time. Sum all query answers using 64-bit integer arithmetic.
