Process the string from left to right while maintaining, for every modulus \(1\) through \(9\), how many substrings ending at the previous position have each possible remainder. For each new digit, extend every existing substring and also start a new one-digit substring, updating all remainder counts in \(O(9^2)\) time per character. If the current digit is non-zero, add the number of substrings ending here whose remainder modulo that digit is zero. Leading zeros are handled naturally because substring values are updated numerically.
