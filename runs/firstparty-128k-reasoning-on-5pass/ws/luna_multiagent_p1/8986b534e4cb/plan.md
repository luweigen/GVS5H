Represent each town by a potential \(P_v\), where road strengths are differences of adjacent potentials. A person requires equal endpoint potentials and requires every internal potential to lie strictly above or below that common value depending on travel direction. Thus, each person contributes equality constraints plus strict ordering constraints between potential-equivalence classes. Develop an offline algorithm for contiguous person ranges that detects whether these constraints contain a contradiction, targeting near-linear or \(O((M+Q)\log^2 N)\) complexity using interval processing and rollback data structures.
