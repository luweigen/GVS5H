- **Path structure:** For two overlapping intervals, any path of minimum weight has at most three edges. A direct edge is possible only when the intervals are disjoint. Otherwise, a two-edge path uses one interval disjoint from both endpoints. If no such interval exists, a three-edge path is possible only in the proper-crossing configuration.
- **Common neighbor:** An interval is disjoint from both query intervals iff it lies completely to the left of both (`R < min(Ls, Lt)`) or completely to the right of both (`L > max(Rs, Rt)`). The minimum weight of such an interval is obtained from prefix minima by right endpoint and suffix minima by left endpoint.
- **Proper crossing:** After ordering the overlapping query intervals so `La <= Lb`, a nontrivial three-edge path exists only when `Ra < Rb`. It uses an interval with `L > Ra` and another with `R < Lb`; these two intermediate intervals are automatically disjoint. Their minimum weights are independent and are obtained from suffix/prefix minima.
- **Containment:** If the ordered intervals satisfy `Ra >= Rb`, the first interval contains the second (including equal-endpoint cases). Every neighbor of the outer interval is also a common neighbor. Therefore, when no common neighbor exists, the vertices are disconnected.
- **Preprocessing:** Coordinates are bounded by `2N`. Build `pref[x]`, the minimum weight among intervals with `R <= x`, and `suff[x]`, the minimum weight among intervals with `L >= x`. This takes `O(N)`.
- **Queries:** Each query uses only constant-time minimum lookups, so total complexity is `O(N + Q)` time and `O(N)` memory. Vertex weights are added for both endpoints and every selected intermediate vertex exactly once.
