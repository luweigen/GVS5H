Process insertions in reverse order, where each number `i` must occupy the `P_i`-th currently available position in the final array. Maintain free positions using a Fenwick tree that supports finding the k-th available slot in logarithmic time. Initially all positions are free; for `i = N` down to `1`, locate the `P_i`-th free position, place `i` there, and mark it occupied. This yields an `O(N log N)` solution suitable for `N = 5×10^5`.
