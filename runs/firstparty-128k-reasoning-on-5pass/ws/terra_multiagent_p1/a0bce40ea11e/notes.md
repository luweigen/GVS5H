- **Walk-sum reduction:** Expand each entry of \(B^p\) as length-\(p\) directed walks. For each originally zero matrix position used \(e>0\) times, \(\sum_{x=1}^{p-1}x^e\) is \(0\) unless \(p-1\mid e\), when it is \(-1\) modulo \(p\). Unused zero positions also contribute \(p-1=-1\). Thus every surviving walk has common global factor \((-1)^K\), where \(K\) is the total number of zero entries.
- **Zero-free walks:** Let \(C_{ij}=A_{ij}\) for nonzero entries and \(0\) for originally zero entries. Walks using no zero entries sum to \(C^p\).
- **Case \(p=2\):** There is exactly one replacement, as every zero becomes \(1\). Since all nonzero entries modulo \(2\) are also \(1\), \(B\) is the all-ones matrix and \(B^2\) has every entry equal to \(N\bmod2\).
- **Classification for \(p>3\):** A surviving walk using zeros must use exactly one zero position exactly \(p-1\) times, plus one fixed nonzero edge. Since \(p-1\ge4\), a non-loop edge cannot be traversed this many times with only one intervening edge. Hence the zero edge must be a diagonal loop \(v\to v\). The fixed edge can only be first, contributing \(C_{a,v}\) to output \((a,v)\), or last, contributing \(C_{v,b}\) to output \((v,b)\). If \(D\) is diagonal with \(D_{vv}=1\) precisely when \(A_{vv}=0\), the correction is \(CD+DC\). A possible interior fixed edge would need to be \(v\to v\), but this is zero rather than a fixed nonzero edge, so contributes nothing.
- **Exceptional case \(p=3\):** Here a surviving zero edge appears twice. Besides the diagonal-loop first/last cases \(CD+DC\), an off-diagonal zero edge \(u\to v\) can occur in the pattern \(u\to v\), \(v\to u\), \(u\to v\), provided the reverse edge is fixed nonzero. This contributes \(C_{v,u}\) to output entry \((u,v)\). Add this for each off-diagonal zero position.
- **Final formula:** For \(p>3\), answer is \((-1)^K(C^p+CD+DC)\). For \(p=3\), additionally add the off-diagonal matrix with entry \((u,v)\) equal to \(C_{v,u}\) when \(A_{u,v}=0\).
- **Complexity:** Binary exponentiation computes \(C^p\) in \(O(N^3\log p)\) time and \(O(N^2)\) memory. Remaining corrections are \(O(N^2)\).
