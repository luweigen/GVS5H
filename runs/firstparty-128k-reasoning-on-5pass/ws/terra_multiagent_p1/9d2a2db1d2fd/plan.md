Model movement at each floor as connectivity among blocks whose building heights reach that floor; walkways are free, while changing floors costs the vertical distance. For a query, the optimal route can be characterized by the highest floor at which the two relevant free-movement components connect, together with unavoidable ascent/descent from the endpoint floors. Build a maximum spanning tree over the grid, where each adjacent edge has weight equal to the minimum of the two building heights; the bottleneck value between two blocks is the maximum possible common floor connectivity threshold. Preprocess this tree for LCA/binary lifting so each query obtains the maximum bottleneck floor on the path quickly, then derive the minimum stair count from that threshold and endpoint floors.
