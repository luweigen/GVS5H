Model the constraints as a graph where each edge `(u, v, z)` requires `A[u] XOR A[v] = z`. For each connected component, assign each vertex a provisional XOR-distance value from a chosen root and verify consistency on every traversed edge. Every valid assignment in a component has the form `A[v] = dist[v] XOR t` for one shared non-negative integer `t`; minimize the component sum independently bit by bit by choosing each bit of `t` according to whether more provisional values have that bit set or unset. Isolated vertices should be assigned `0`, and any contradictory edge causes output `-1`.
