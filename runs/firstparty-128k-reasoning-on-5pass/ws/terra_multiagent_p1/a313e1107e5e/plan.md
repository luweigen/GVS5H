Process queries offline using a persistent data structure over prefixes of the sequence. For each position, compute the LIS DP value ending at that element, and maintain a persistent segment tree keyed by values, where each node stores the maximum LIS length for that value range. For a query \((R, X)\), use the persistent version after processing the first \(R\) elements and query the maximum DP value among values at most \(X\). Coordinate-compress all \(A_i\) values and use binary search to locate the compressed upper bound for each \(X\).
