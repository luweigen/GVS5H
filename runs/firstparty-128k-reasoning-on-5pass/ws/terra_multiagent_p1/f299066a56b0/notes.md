- **Greedy algorithm:** Use indices `top = 0` and `bottom = ceil(N/2)`. The first `floor(N/2)` mochi are candidate tops, while the latter part contains candidate bottoms. Scan bottoms from left to right.
- **Matching rule:** If `2 * A[top] <= A[bottom]`, pair them and advance both pointers. Otherwise, the current bottom is too small for the smallest currently unmatched top, so it cannot be used for any remaining top; advance only `bottom`.
- **Why lower-half tops suffice:** In any set of K disjoint pairs, each top is smaller than its corresponding bottom. Therefore, after sorting all selected pair members by role, the K tops can be replaced by no-larger mochi among the first K positions without harming feasibility. In particular, no optimal solution needs a top outside the first `floor(N/2)` elements.
- **Why greedy is optimal:** At each step, if the current smallest unmatched top fits the earliest available bottom, pairing them preserves all later, larger bottoms for later tops. If it does not fit, that bottom cannot fit any remaining top because remaining tops are at least as large, so discarding the bottom is mandatory. Thus every greedy decision is safe and the number of pairs is maximum.
- **Complexity:** Both pointers move only forward, so time complexity is `O(N)` and extra space is `O(N)` for input storage.
