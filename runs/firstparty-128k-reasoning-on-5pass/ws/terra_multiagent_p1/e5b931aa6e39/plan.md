Rewrite the equation using the difference \(d=x-y>0\): \(N=(y+d)^3-y^3=d(3y^2+3dy+d^2)\). Since \(d^3 \le N\), enumerate all possible positive differences \(d\) up to \(\lfloor \sqrt[3]{N}\rfloor\). For each divisor \(d\) of \(N\), solve the resulting quadratic equation in \(y\) and verify the candidate with integer arithmetic. This takes \(O(\sqrt[3]{N})\), which is feasible for \(N\le10^{18}\).
