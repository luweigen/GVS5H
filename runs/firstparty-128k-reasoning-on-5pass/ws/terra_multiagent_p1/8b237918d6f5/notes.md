- **Threshold decision problem:** For a target distance `D`, minimize the number of edges that must receive weight 1 so every path from vertex 1 to vertex N has total weight at least `D`. It is feasible for exactly `K` selected edges iff this minimum is at most `K`, because additional edges can be changed from 0 to 1 without decreasing any shortest-path distance.
- **Label characterization:** Use integer labels `L(v) in [0,D]`, with `L(1)=0`, `L(N)=D`, and `L(v) <= L(u)+1` for each edge `u -> v`. Select every edge satisfying `L(v)=L(u)+1`. For every edge, its selected weight is at least `L(v)-L(u)`, so summing over any 1-to-N path gives weight at least `D`.
- **Converse:** Given any successful selected-edge set, define `L(v)=min(D, dist(1,v))`, treating unreachable vertices as label `D`. Then `L(1)=0`, `L(N)=D`, and every edge satisfies `L(v)<=L(u)+1`. If `L(v)=L(u)+1`, that edge must be selected; otherwise a zero-weight edge would contradict shortest-distance optimality. Thus the minimum label cost equals the minimum required number of selected edges.
- **Cut variables:** For each vertex `v` and level `i=1..D`, create a node `(v,i)` meaning `L(v)>=i`. Source-side nodes mean true; sink-side nodes mean false.
- **Infinite-capacity implications:** Add `(v,i) -> (v,i-1)` for `i>=2`, enforcing threshold monotonicity. For every original edge `u -> v`, add `(v,i) -> (u,i-1)` for `i>=2`, enforcing `L(v)<=L(u)+1`. Add `(1,i) -> T` to force source label 0, and `S -> (N,i)` to force sink label D.
- **Cost arcs:** For each original edge `u -> v` and each `i=1..D`, add a unit-capacity arc `(v,i) -> (u,i)`. It crosses the cut exactly when `L(v)>=i>L(u)`. The implication constraints ensure this can happen for at most one level, precisely when `L(v)=L(u)+1`. Parallel original edges get separate unit arcs and are therefore counted separately.
- **Bounds and complexity:** The answer is at most `N-1`, since any reachable simple path has at most `N-1` edges and weights are at most 1. Binary search over `D` uses `O(log N)` min-cuts. A cut graph for one `D` has `N*D+2` nodes and `O((N+M)D)` arcs. `INF=M+1` is sufficient because every finite valid solution selects at most `M` edges.
