- **State meaning:** A pair state `(u, v)` represents a palindrome-labeled path from `u` to `v` already constructed from its center outward.
- **Centers:** Even-length palindromes start from every `(i, i)` with distance `0`. Odd-length palindromes start from every directed edge `(i, j)` with distance `1`.
- **Transition direction:** From solved `(u, v)`, choose `p -> u` and `v -> q` with the same character. This constructs a palindrome from `p` to `q`, so the transition is `(u, v) -> (p, q)` and adds `2`.
- **Parity separation:** Two independent BFS traversals avoid any ordering issue between zero-length and one-length initial centers. Every transition preserves length parity, so each BFS has uniform edge cost in units of one expansion.
- **Adjacency representation:** Incoming neighbors are grouped as `incoming[vertex][letter]`. Outgoing neighbors are also grouped, and additionally represented as bit masks `out_mask[vertex][letter]`.
- **Bit-mask optimization:** For fixed state `(u, v)`, letter `c`, and predecessor `p` of `u`, all valid right endpoints are the outgoing `c` neighbors of `v`. The mask difference `out_mask[v][c] & ~seen_mask[p]` discovers all not-yet-visited states `(p, q)` in a batch.
- **Complexity:** For each visited pair state, total incoming-list iterations across all letters are at most `N`. Thus the main traversal work is `O(N^3)` Python-level iterations per BFS, plus at most `O(N^2)` state insertions. Bit operations use integers of at most `N=100` bits.
- **Correctness:** Removing matching first and last edges from any nonempty palindrome yields a smaller palindrome. Repeating reaches either an empty center or a single-edge center, exactly matching the BFS sources and reverse construction transitions. BFS first-discovery within one parity gives the shortest path of that parity; taking the minimum of both answers gives the global shortest palindrome path.
