Model each ordered vertex pair \((u,v)\) as a state representing the unresolved inner portion of a palindrome path. Run multi-source BFS backward from all center states: \((i,i)\) has answer 0, and every direct edge \((i,j)\) gives answer 1. From a solved state \((u,v)\), prepend and append edges carrying the same label, producing states \((p,q)\) where \(p\to u\) and \(v\to q\) have equal labels; this increases length by 2. BFS guarantees the first discovered distance for every pair is the shortest palindromic path length.
