Build a trie over all words, storing at every node how many words pass through it. A prefix of depth `d` is valid if its trie node has count at least `k`; after removing one word, only nodes on that word’s trie path can lose validity. Compute the globally deepest valid prefix, then for each word temporarily account for reducing counts along its path and determine the best remaining valid depth efficiently using per-depth counts of valid trie nodes. Handle `n - 1 < k` by returning all zeros immediately.
