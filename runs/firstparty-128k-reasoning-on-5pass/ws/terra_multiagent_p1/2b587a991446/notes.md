- **Validation result:** No conceptual mismatch was found in the current decomposition formula. The configuration-space state graph has ordered states `(A,B)` with `A != B`; its BFS minimum agrees with the two maneuver classes represented by the solver: parking off an S-T shortest path, or passing within one vertex-biconnected block on the block-cut route.
- **Configuration BFS oracle:** For small graphs, use `N*(N-1)` states. From `(x,y)`, add `(nx,y)` for each neighbor `nx != y` and `(x,ny)` for each neighbor `ny != x`. Compare distance from `(S,T)` to `(T,S)` against the solver for every connected simple graph and every ordered distinct `(S,T)`.
- **Impossibility characterization:** `dist(S,T) = N-1` implies an S-T shortest path contains every vertex. Any non-path edge would be a chord and shorten the path, so the graph is exactly a path. Tokens cannot change order on a path. Conversely, if `dist(S,T) < N-1`, an omitted vertex/component can park a token and yields a valid exchange in `2*dist(S,T)+2` moves.
- **Block-cut route:** Any genuine passing of the two pieces must occur in one block on the unique S-T path of the block-cut tree. For a selected block with entry `a` and exit `b`, both exterior portions are necessarily traversed once by each piece, contributing `2*(dist(S,a)+dist(b,T))`.
- **Cycle contribution:** With pieces at `a,b`, exchanging them inside a block costs the shortest simple cycle through `a,b`. Given two internally vertex-disjoint `a-b` paths of total length `L`, move A almost fully along one, move B along the other to `a`, then make A's final move to `b`, for exactly `L` operations.
- **Flow computation:** The cycle length is found as two units of min-cost flow. Internal vertex capacity one enforces internally vertex-disjoint paths; a shared edge gadget with capacity one prevents both paths using the same original edge. The residual-network second augmentation is required, so potentials plus Dijkstra are used.
- **Complexity:** Tarjan, BFS, and block-cut-tree construction are linear. Route blocks are edge-disjoint, and total sizes of all flow networks over route blocks are `O(N+M)`. Two Dijkstra augmentations per route block give `O((N+M) log(N+M))` overall, with compact arrays used for the potentially large flow graph.
- **Implementation caveat:** The recursive Tarjan DFS uses a raised recursion limit. If an execution environment has a restrictive native stack, replacing it with an iterative Tarjan DFS is a robustness-only change, not an algorithmic correction.
