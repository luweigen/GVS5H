Represent each row as a W-bit mask. Fix a set of column flips, then each row can independently either stay as-is or be row-flipped, contributing the smaller of its number of ones and zeros after the column flips. Enumerate all \(2^W\) column-flip masks; this is feasible since \(W \le 18\), and sum the optimal contribution for every row. Use frequencies of equal row masks to reduce repeated work, then take the minimum over all column masks.
