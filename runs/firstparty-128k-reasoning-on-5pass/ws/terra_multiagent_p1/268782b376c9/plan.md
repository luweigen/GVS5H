Binary search the answer `x`, representing the minimum score every index must achieve. For a fixed `x`, compute how many visits each index needs: `ceil(x / points[i])`, then greedily simulate the minimum moves needed to satisfy these visits while traversing the array from left to right. The key is that extra required visits at an index are handled by bouncing between adjacent positions, and the final index has a slightly different cost because no return is needed. If the required move count is at most `m`, `x` is feasible; binary search for the maximum feasible value.
