- **Characterization:** The insertion-sort / leftmost-adjacent-descent candidate is correct. Process the original permutation from left to right, maintaining the processed prefix in sorted order. When processing original position `j`, let `k` be the number of previous values smaller than `P_j`; insert `P_j` from position `j` into position `k+1`.
- **Cost formula:** This insertion crosses adjacent edges `k+1, k+2, ..., j-1`, so its cost is `sum(k+1..j-1) = (j+k)(j-1-k)//2`. Sum this over all `j`.
- **Lower-bound proof:** Any optimal sorting sequence can be assumed reduced: it has exactly one swap per inversion, since every swap has positive cost and insertion sort attains the inversion count. For an element initially at position `j`, the number of required left moves equals the number `A = j-1-k` of earlier elements greater than it. Before its `t`-th left move, it has made `t-1` left moves and possibly some right moves, so its position is at least `j-(t-1)`. Thus that left swap costs at least `j-t`. Summing gives the unavoidable lower bound `(j-1)+(j-2)+...+(j-A) = sum(k+1..j-1)`. Charging every swap to its left-moving element proves the total lower bound. Left-to-right insertion realizes it because each element makes all required left moves before any later element can move it right.
- **Exhaustive verifier design:** For tiny `n`, exact costs can be computed by recurrence on permutations: `f(q) = min(i + f(q with adjacent descent i swapped))`, with `f(sorted)=0`. Only adjacent descents need be considered because a reduced sorting sequence decreases inversion count at every step. Comparing this recurrence for every permutation against the Fenwick formula validates the characterization on small sizes.
- **Implementation:** Maintain a Fenwick tree over values. Before inserting `x=P_j`, query `k = count(previous values < x)` as `prefix_sum(x-1)`, add the formula contribution, then insert `x`.
- **Complexity:** `O(N log N)` time and `O(N)` memory. The answer can be `Theta(N^3)`, so use 64-bit-capable integer arithmetic; Python integers are sufficient.
