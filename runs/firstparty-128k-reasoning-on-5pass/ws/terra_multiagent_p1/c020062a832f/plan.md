Compute the inversion count for \(k=0\) using a Fenwick tree over values. When increasing \(k\) to \(k+1\), exactly the elements whose current value is \(M-1\) wrap to \(0\); equivalently, these are original elements with value \(M-1-k\). For every occurrence at position \(i\), its inversion contribution changes from being larger than all other values to being smaller than all other values, producing a delta based on counts before and after that position. Precompute the total delta for each original value, then update and output answers in \(O(N \log M + N + M)\).
