- **Invariant:** Root the tree arbitrarily. For each subtree, all vertices must already belong to completed size-\(K\) paths except possibly one unfinished path segment containing the subtree root, represented by its number of vertices. A zero value means no segment needs the parent edge.
- **Child handling:** An unfinished segment from a child must connect through the current node; it cannot be discarded because it has fewer than \(K\) vertices. More than two such children is impossible because a final selected component must be a simple path.
- **Transitions:** With zero unfinished children, the node starts a length-1 segment. With one, it extends that segment by one vertex. If this reaches \(K\), it closes; otherwise it remains open. With two, the two segments must join at the node and their combined size plus one must be exactly \(K\); otherwise the node would either form an oversized path or require degree three to continue upward.
- **Root condition:** The root must have no open segment after postorder processing. Since all \(NK\) vertices are processed and every closed component has exactly \(K\) vertices, this yields exactly \(N\) paths.
- **Complexity:** Iterative DFS plus postorder DP scans each adjacency list a constant number of times, using \(O(NK)\) time and memory.
- **Edge cases:** \(K=1\) works without special handling: every node's newly formed length-1 segment closes immediately. Iterative traversal avoids recursion-depth failure on a path-shaped tree.
