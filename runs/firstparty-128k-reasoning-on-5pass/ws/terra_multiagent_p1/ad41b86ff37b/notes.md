- **Model:** Choose a retained snowflake center `c`. Every selected branch vertex must be a neighbor of `c`, and each branch must retain exactly `y >= 1` of its other neighbors as leaves.
- **Capacity:** For a neighbor `b` of center `c`, its usable leaf capacity is `deg(b) - 1`, because the edge from `b` to `c` cannot also be a leaf edge.
- **Fixed center and y:** A neighbor can be selected as a branch exactly when `deg(b) - 1 >= y`. It is always optimal to select every eligible neighbor: each adds `y + 1` retained vertices, namely itself and its `y` leaves.
- **Retained size formula:** For center `c` and positive `y`, if `k(c,y)` neighboring vertices have capacity at least `y`, the largest snowflake using those parameters has size `1 + (y + 1) * k(c,y)`.
- **Candidate y values:** For a fixed center, `k(c,y)` changes only when `y` passes a neighbor capacity. Between consecutive capacities, the expression increases as `y` increases, so it suffices to evaluate `y` equal to each distinct positive capacity.
- **Implementation:** For every possible center, build capacities `deg(neighbor)-1` for its neighbors with positive capacity, sort descending, and process equal values in groups. After processing a group ending at index `j`, exactly `j` neighbors have capacity at least the current value `y`; evaluate `1 + (y+1)*j`.
- **Correctness:** Every retained snowflake has some center and leaf count `y`, so its branches are among the eligible neighbors counted by the formula; hence its size is at most the evaluated size for those parameters. Conversely, for every evaluated center and `y`, selecting all eligible neighbors and any `y` non-center neighbors of each creates a valid connected snowflake. Distinct branches cannot share a chosen leaf in a tree, since such a shared neighbor would create a cycle. Therefore the maximum evaluated size is exactly the maximum retainable snowflake size.
- **Complexity:** The total number of collected capacities is `2(N-1)`. Sorting separately at each vertex costs `O(sum deg(v) log deg(v))`, bounded by `O(N log N)`. Memory usage is `O(N)` besides temporary per-center lists.
