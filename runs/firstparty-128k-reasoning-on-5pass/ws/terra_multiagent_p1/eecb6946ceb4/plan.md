Represent the set with a boolean presence array up to \(10^6\). A fine triplet is exactly a 3-term arithmetic progression, so for each possible difference \(d \ge 1\), count starting values \(A\) such that \(A\), \(A+d\), and \(A+2d\) are all present. Iterate efficiently over valid differences and starts; the total work is about \(\sum_{d=1}^{M/2} M = O(M^2)\) if naive, so instead exploit the bounded universe with bitset operations or an optimized convolution/FFT-based approach. Count each progression once by its ordered endpoints.
