- **Reduction:** A fine triplet is a nondegenerate three-term arithmetic progression, equivalently \(A+C=2B\). Let \(f[x]\) be the presence indicator and let \(g=f*f\). For each present middle value \(B\), \(g[2B]\) counts ordered endpoint pairs \((A,C)\). It contains the degenerate pair \((B,B)\) once and each desired triplet twice, so its contribution is \((g[2B]-1)/2\).
- **Exactness:** The convolution coefficients are at most \(N\le 10^6\), strictly below 998244353. Therefore one NTT modulo 998244353 is sufficient; no CRT is needed.
- **Transform size:** If the largest input value is \(M\), convolution degree is at most \(2M\), so use the smallest power of two strictly greater than \(2M\): `1 << (2*M).bit_length()`. Since \(M\le10^6\), this is at most \(2^{21}\), supported by 998244353.
- **Inverse transform:** Instead of storing separate inverse twiddles, use the identity that applying forward NTT to entries reversed at indices `1..n-1` yields the inverse transform multiplied by `n`. Thus only one forward-root table is needed.
- **Complexity:** Two forward NTTs cost \(O(L\log L)\), where \(L\le2^{21}\), plus linear scans. Memory is \(O(L)\).
- **Implementation concern:** Pure Python NTT at \(2^{21}\) is demanding but avoids floating point errors. The implementation uses iterative bit reversal, precomputed powers of the primitive \(L\)-th root, and local-loop arithmetic. Input tokens are deleted before large NTT arrays are constructed to reduce peak memory.
- **Formula application:** The inverse scaling is only computed for indices `2*B` where `B` is present, rather than scaling every convolution coefficient.
