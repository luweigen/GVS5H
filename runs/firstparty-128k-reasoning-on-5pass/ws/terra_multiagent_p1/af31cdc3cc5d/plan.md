Model the removal process as forming noncrossing pairs of indices, with exactly one unpaired element when N is odd. Derive the structural property that an optimal solution can be represented using only pairings between elements of opposite parity positions, except for the possible unmatched element. Reduce the objective to a maximum-weight matching problem on a path-like bipartite structure and seek an O(N log N) or O(N) dynamic programming/greedy formulation suitable for N up to 3×10^5. Validate the derived recurrence against both even- and odd-length cases.
