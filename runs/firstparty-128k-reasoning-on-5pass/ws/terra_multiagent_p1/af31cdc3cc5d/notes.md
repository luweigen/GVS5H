- **Structural model:** Every removal plan induces a noncrossing matching of original indices. A pair can be removed only after every index strictly between its endpoints has already been removed, so pairs cannot cross.
- **Even-length optimum:** For any complete matching, orient each pair from its larger value to its smaller value. The total score becomes the sum of values assigned `+` minus the sum assigned `-`, with exactly half of the elements in each group. This is at most the sum of the largest half minus the sum of the smallest half.
- **Achievability of the bound:** Assign `+` to the largest half and `-` to the smallest half. In any balanced sign sequence, there is an adjacent opposite-sign pair; remove such a pair repeatedly. This creates a valid noncrossing matching. Since every `+` value is at least every `-` value, each removed pair scores exactly its `+` value minus its `-` value. Thus the upper bound is attained.
- **Odd-length decomposition:** The lone unremoved element must have an odd 1-based index, since both sides must have even length. No pair can cross that element: removing a pair enclosing it would require removing the unmatched element first. Therefore, fixing unmatched position `u` gives independent even segments `1..u-1` and `u+1..N`.
- **Heap DP:** For each growing prefix, maintain the largest `floor(length/2)` values in a min-heap `upper`, and all others in a max-heap `lower`. Track both sums. At every even length, `sum(upper)-sum(lower)` is the desired largest-half minus smallest-half value. Running the same procedure on the reversed array provides suffix values.
- **Complexity:** Each element enters and moves between heaps only logarithmically many times. Time is `O(N log N)` and memory is `O(N)`.
- **Sample validation:** The algorithm gives `5` for sample 1, `14` for sample 2, and `0` for sample 3.
