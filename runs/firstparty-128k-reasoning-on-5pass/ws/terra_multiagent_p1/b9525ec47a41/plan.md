Model each edge orientation by a binary variable indicating which endpoint receives the incoming edge. The indegree sequence on cycle vertices is determined by adjacent cycle-edge variables plus, at positions with `s_i=1`, the spoke orientation variable; the center indegree is the total number of spokes oriented toward the center. Derive a transfer-matrix / generating-function DP around the cycle that counts distinct attainable degree vectors rather than orientations, carefully merging orientation assignments that yield the same sequence. Exploit the local structure and cyclic boundary condition to obtain an \(O(N)\) or near-linear algorithm modulo 998244353, suitable for \(N\le 10^6\).
