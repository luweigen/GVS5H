- **BFS characterization:** Every connected graph has unique BFS layers \(L_0,L_1,\ldots\) from vertex 1. Edges may only be inside one layer or between consecutive layers. Every vertex in \(L_i\), \(i>0\), needs at least one neighbor in \(L_{i-1}\). These conditions are also sufficient for the chosen layers to be the BFS layers.
- **Balance condition:** Since \(N\) is even, retain states only when the number of vertices accumulated in even-indexed layers and in odd-indexed layers is at most \(N/2\). At termination both must equal \(N/2\).
- **State:** Process by total used vertices. A state is `(last_layer_parity, even_count, last_layer_size)` and stores the edge generating polynomial for all partial BFS layerings with those parameters.
- **Label counting:** When appending a layer of size \(b\) after using \(u\) vertices, multiply by \(\binom{N-u}{b}\). Over an entire layer-size sequence this gives exactly the multinomial number of assignments of labels \(2,\ldots,N\) to layers.
- **Transition polynomial:** For old layer size \(a\), new layer size \(b\), predecessor edges contribute \(((1+x)^a-1)^b\), because each new vertex chooses a nonempty subset of the \(a\) predecessor vertices. Arbitrary internal new-layer edges contribute \((1+x)^{\binom b2}\). Thus the transition factor is \(((1+x)^a-1)^b(1+x)^{\binom b2}\).
- **Sparse basis trick:** Set \(t=1+x\). Then the transition is \(\sum_{j=0}^{b}(-1)^{b-j}\binom bj t^{aj+\binom b2}\). Therefore multiplying a polynomial represented in the \(t^q\) basis only requires sparse shifts and additions, avoiding costly dense polynomial convolution.
- **Initialization and termination:** Start from \(L_0=\{1\}\), represented by state `(even, 1, 1)` with polynomial 1. Sum terminal states with exactly \(N/2\) even-layer vertices. Convert \(\sum_q c_q(1+x)^q\) back by \([x^m]=\sum_{q\ge m}c_q\binom qm\), then print degrees \(N-1\) through \(\binom N2\).
- **Complexity:** Polynomial degree never exceeds \(\binom N2\le435\). The DP has \(O(N^3)\) structural states/transitions and uses sparse transition factors of at most \(N+1\) terms. This is practical for \(N\le30\), while memory is bounded by stored state polynomials of degree at most 435.
