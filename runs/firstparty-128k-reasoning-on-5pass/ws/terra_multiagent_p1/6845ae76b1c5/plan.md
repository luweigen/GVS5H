Use offline processing of prefix-rectangle queries: each query asks for the sum over the first `X` elements of `A` and first `Y` elements of `B`. Process queries sorted by `X`, incrementally inserting `A_i` values into a coordinate-compressed Fenwick tree as `i` advances. For a fixed inserted prefix of `A`, compute the total distance to every `B_j` for all `j ≤ Y` using Fenwick-maintained counts and sums, then accumulate these values in a second prefix structure over positions of `B`. This yields approximately `O((N+K) log N)` or similar offline complexity with 64-bit arithmetic.
