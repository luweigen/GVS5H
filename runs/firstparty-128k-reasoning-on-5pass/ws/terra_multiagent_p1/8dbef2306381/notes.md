- **State DP:** After processing square `x`, use a `B`-bit mask. Bit `k` is 1 iff square `x-k` is reachable, for `0 <= k < B`. To process the next square, shift the mask left by one. If the new square is good, its reachability is `1` exactly when one of bits `A-1` through `B-1` of the old mask is set. If it is bad, the new low bit is 0.
- **Bad runs:** A run of `t` bad squares simply shifts the mask left by `t`; if `t >= B`, every previous reachable square leaves the stored window and the result is zero.
- **Equal jump lengths:** If `A=B=d`, on a good square the recurrence is `new_bit_0 = old_bit_(d-1)`. Thus a good step rotates the `d`-bit mask, and a good run of arbitrary length is handled by one rotation modulo `d`.
- **Unequal jump lengths:** If `A<B`, it is enough to use jump lengths `A` and `A+1`. Every integer at least `A(A-1)` is representable as a nonnegative sum of these lengths. Let `C=A(A-1)`.
- **Good-run saturation:** Suppose a nonzero mask enters a good run. Some reachable source is within the preceding `B` positions. It can jump directly to a good square at most `A` positions into the run: choose a jump length in `[A,B]` large enough to cross the boundary. From that first good landing square, every distance at least `C` is reachable using only `A` and `A+1`, with all intermediate landings remaining in the good run. After `C+A+B-1` good squares, all positions represented by the mask are therefore reachable, so the mask is all ones. This bound is at most 380 under the constraints.
- **Complexity:** There are `O(M)` runs. Each short good run takes at most 379 bit-DP steps; long good runs are saturated in `O(1)`. Total time is `O(M * 400)` and memory is `O(1)`.
