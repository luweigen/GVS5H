Exploit that foods of different vitamin types are independent except for the shared calorie budget. For each vitamin, compute a 0/1 knapsack DP where `dp[v][c]` is the maximum intake of vitamin `v` achievable using exactly (or at most) `c` calories. Convert each DP into prefix maxima so it gives the best intake within any calorie limit. Then enumerate calorie allocations between vitamins 1 and 2, assign remaining calories to vitamin 3, and maximize the minimum of the three obtained intakes.
