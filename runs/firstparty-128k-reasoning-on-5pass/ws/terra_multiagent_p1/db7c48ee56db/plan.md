Exploit the guarantee that \(\binom{N}{K}\le 10^6\), so every valid selection can be enumerated directly within acceptable time. Generate all size-\(K\) index combinations (or equivalently combinations of values), compute the XOR incrementally for each chosen set, and retain the maximum result. Python’s `itertools.combinations` provides efficient combination generation, while `functools.reduce` or a small loop computes each XOR. Since each combination has at most \(N\) elements but the total number is bounded, this straightforward approach is sufficient.
