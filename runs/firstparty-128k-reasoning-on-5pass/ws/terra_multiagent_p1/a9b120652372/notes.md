- **Exact finite-state characterization:** For a support mask \(S\), define \(F_p(S)\) as the support after choosing pivot \(p\). Breadth-first search over masks gives exact shortest operation counts, because every edge corresponds to one legal globally shared pivot operation.
- **Small-instance solver:** The code uses exact BFS for \(N \le 18\). This is fully correct for those sizes but exponential in \(N\), so it is not a valid final contest-scale method by itself.
- **Structural facts:** Occupied runs never split, though runs may shrink and merge. Order of labeled pieces is preserved until pieces merge. The support count and number of runs cannot increase.
- **Equal-number-of-pieces case:** If no pieces merge, the ordered matching is forced. Let source and target one-positions be \(x_i,y_i\), and \(d_i=y_i-x_i\). Necessarily \(d_i\) is nonincreasing. For a fixed duration \(D\), a particle requires a wait parity correction iff \(D-d_i\) is odd. In one operation at most one distinct unmerged particle can wait, so a necessary condition is that the number of parity corrections is at most \(D\). The current code uses this characterization for equal cardinalities.
- **Known counterexample to displacement-only bound:** \(A=1101\), \(B=1110\) needs two operations, although each piece can be assigned a displacement of absolute value at most one. A shortest pivot sequence is right endpoint then left endpoint. This proves that maximum displacement alone is insufficient.
- **Current limitation:** The large-\(N\), unequal-cardinality branch in the code is only a heuristic representative selection, not a proven reachability/minimum characterization. It must not be considered a definitive contest solution.
- **Needed breakthrough:** A scalable exact method must account for merging groups and the shared-pivot temporal schedule. It likely needs a dynamic characterization over initial and target occupied runs, rather than independent particle displacement bounds.
