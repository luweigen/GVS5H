For each integer `x`, determine its required number of divisions by 4 to reach zero; this is its individual “work” count. Since every operation performs one division on exactly two selected elements, the minimum operations for a query is `ceil(total_work / 2)`, provided zero-work slots can pair with remaining work as needed. Use a prefix-work function to calculate the sum for each query in `O(log_4 r)` time.
