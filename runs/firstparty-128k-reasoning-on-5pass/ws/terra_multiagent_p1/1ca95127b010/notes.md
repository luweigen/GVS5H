- **Characterization:** The complete reachability invariant is: for every zero, in left-to-right occurrence order, its position modulo `Y` is preserved; for every one, in left-to-right occurrence order, its position modulo `X` is preserved. Thus `S` reaches `T` iff their zero-residue sequences modulo `Y` are equal and their one-residue sequences modulo `X` are equal.
- **Necessity:** In an operation, the selected `X` zeros move exactly `Y` positions right or left, and zero order is never changed. The selected `Y` ones move exactly `X` positions left or right, and one order is never changed. Therefore the stated residue sequences are invariant.
- **Sufficiency theorem:** Interpret a binary word as a monotone lattice path, with `0` a horizontal step and `1` a vertical step. An operation flips the boundary of an `X` by `Y` rectangle: `0^X1^Y <-> 1^Y0^X`. Horizontal steps have fixed height modulo `Y`, and vertical steps have fixed horizontal coordinate modulo `X`; these colors are exactly the two residue sequences above, up to the fixed occurrence index offset. The standard rectangle-flip connectivity argument for monotone paths says two paths with the same ordered colored horizontal and vertical steps are connected by such rectangle flips. One can repeatedly flip an available rectangle that decreases the enclosed area/inversion count toward a common extremal path; matching colors ensure the same extremal path.
- **Rewrite orientation:** Orienting `0^X1^Y -> 1^Y0^X` decreases the `0-before-1` inversion count by exactly `XY`, hence terminates. A redex is uniquely tied to a `0 -> 1` run boundary: it must use the final `X` zeros before that boundary and first `Y` ones after it. Consequently distinct simultaneously present redexes are disjoint. This supports local commutation, though direct normal-form simulation can still require quadratic many flips and is not used.
- **Algorithm:** Scan `S`, store one residue per character: zero positions modulo `Y`, one positions modulo `X`. Scan `T` and compare corresponding residues online. Mismatched counts or residues imply `No`; otherwise print `Yes`.
- **Complexity:** Time `O(N)`. Memory `O(N)` for the stored sequences; at most `N` Python integers.
