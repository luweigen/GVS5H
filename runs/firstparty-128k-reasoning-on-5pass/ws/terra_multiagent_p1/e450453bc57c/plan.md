Compute the cost of converting every length-`x` window into equal values; the optimal target for a window is its median, and the cost is the sum of absolute deviations from that median. Maintain these sliding-window median costs efficiently using two heaps (or balanced multisets) plus running sums, since `n` is up to `1e5`. Then use dynamic programming to select at least `k` non-overlapping windows with minimum total cost. Because costs are nonnegative, selecting exactly `k` windows is sufficient.
