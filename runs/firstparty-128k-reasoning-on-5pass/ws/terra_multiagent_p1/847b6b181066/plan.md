Represent the cumulative wind displacement after each time step as a prefix coordinate. Smoke generated at time \(k\) will be at the current prefix displacement minus the displacement at its generation time, so cell \((R,C)\) contains smoke at time \(t\) exactly when prefix position \((x_t-R, y_t-C)\) has appeared among valid prior prefix positions. Maintain a hash set of prefix positions corresponding to smoke-generation times, updating it when the origin would otherwise lack smoke. Process all steps in \(O(N)\) time with coordinate pairs in a set.
